# 制作前・納品前チェック

作業冒頭に全文を読み、該当項目をプロット、概念表、執筆計画へ先に組み込む。本文完成後は同じ項目で全体を再確認し、問題を見つけたら該当箇所を直す。

## 学習設計

- [ ] 対象読者、前提知識、到達目標、扱わない範囲が一貫している。
- [ ] 核心概念では、課題、素朴な案、反例、原因の言語化、修正、検算が成立している。
- [ ] `###` の各節と独立した幕間・終幕・対話演習の会話本文が、話者表示と改行を除くUnicode文字数でおよそ1,200〜1,800字に収まっている。数式・表・コードが多い節は読解負荷も考慮している。
- [ ] 核心概念の節に6〜10個の意味のある会話ビートがあり、条件、予想、計算、矛盾、原因、修正、検算、感情のいずれかが発言ごとに前進している。空疎な相槌や同義反復で発言数を水増ししていない。
- [ ] 同一話者の連続ブロックを畳み込んだ実効往復で、核心概念の節が4往復を下回っていない。往復数にかかわらず、課題提起、正答、教師のまとめだけの節になっていない。18往復を超える節では、二つの核心概念が競合していないか確認している。
- [ ] 発言長を節内で役割に応じて混ぜ、最低一度は発言長または劇の速度が変化している。1発言が7行を超えておらず、220字超は感情の頂点または不可分な導出として必要か確認している。
- [ ] 短い応酬の連鎖では、各発言が理解、計算、感情、コメディのいずれかを更新し、高速区間の後にやる夫による発見または次の一手の言語化がある。既知事項の問いと即答を細切れにしていない。
- [ ] 前提知識や補助用語に不要な完全サイクルを強制していない。
- [ ] 素朴な案が初学者にも一見もっともらしく、藁人形になっていない。
- [ ] 生徒が知識予算を超えた知識を突然披露していない。
- [ ] 新しい判定装置を、可能なら合格例と不合格例の両方で試している。
- [ ] 反復トイ例が実際の計算・判定に再利用されている。

## 因果とドラマ

- [ ] 冒頭に「はじめに」「この教材について」「対象読者」「扱う範囲」のような全体説明の節や導入文が無く、登場人物紹介の直後から第1幕の具体的な場面が始まっている。
- [ ] 各幕・節が具体的な課題や前の解決策の限界から始まる。第1幕の最初の節もテーマ紹介や主題の宣言でなく、具体的な出来事から入っている。
- [ ] 生徒が失敗の原因を言語化し、教師が答えを先に開示していない。
- [ ] 教師の質問へ生徒が正答を即答せず、迷い、想起、計算、自己修正、導出のいずれかを経ている。
- [ ] やらない夫は、やる夫の発言内容や感情を因果的に受けて次へ進んでいる。明示的な相槌を毎回挿入せず、遮り、反復、訂正、数字、沈黙、突っ込みを場面に応じて使っている。
- [ ] 正解が前の失敗を回収し、次の未解決課題へつながっている。
- [ ] 同じビート、同じ速度、短問短答、教師の一括開示が連続していない。同じ感情曲線を隣接する三節で反復していない。
- [ ] 各節に、その内容に即した感情または関係性の変化がある。やる夫の大成功への早合点は導入・終幕を除く各主要幕で最低一度あり、全節を同じ慢心と転落へ揃えていない。
- [ ] 各節を教師の総括で閉じず、節末までにやる夫へ理解の所有権を返している。発見、失敗原因、未解決課題、次の行動、感情的余波、冗談の回収を使い分け、毎節同じ要約問答で閉じていない。
- [ ] 教材全体の結び（終幕）が機械的な要点整理や教師の講義的総括でなく、情緒的な対話で閉じ、冒頭への呼応や残した問いの余韻を持ち、末尾に `---` と `**── 完 ──**` がある。
- [ ] ドラマ、コメディ、安堵が学習上の仕事を持ち、安全に描かれている。
- [ ] 伏線が保留時と回収時の両方で明示されている。

## 構成と検証

- [ ] 長編・サーベイでは、各主要幕の終盤に同形式のコラム的コーナーがあり、その幕までの道具を新しい対象へ累積適用している。
- [ ] 長編・サーベイでは、2〜4幕ごとの区切りに幕間があり、本全体でまとめ、発展、対話式理解度クイズをすべて実施している。
- [ ] コラムと幕間が要点の再掲や分量稼ぎではなく、前幕の回収、学習の転移、次幕の始動のいずれかを担っている。
- [ ] 道具構築が最も厚く、ツアー部分が全体の20%以内である。
- [ ] クライマックスで条件列挙、候補棄却、答えの絞り込みを省略していない。
- [ ] 最終幕で既知の結果、実験、極限、具体値のいずれかと照合している。
- [ ] 末尾の演習も対話形式で、各演習にやる夫の誤答または不完全な案、手掛かり、推論・計算、自己修正、正答がある。
- [ ] 歴史的事実、固有名詞、年号、実験値を検証でき、未確定の時事へ依存していない。
- [ ] 参考文献の各脚注に、本文に呼応した簡単な解説をできるだけ添えている（出典表記だけで終えていない）。
- [ ] 脚注に未使用も未定義もない。節を削除・統合した改訂では、`[^n]` の使用と定義の差分を取って孤立した脚注を除いている。
- [ ] 節を削除・統合した改訂で、節番号の連番、本文中に残った削除済み節への参照、前後の接続（直前が残した問いを直後が受けているか）を確認している。
- [ ] 分量のための空疎・定型的な相槌、同義反復、不要な概念を削っている。必要な反応表現は後続内容と結び付き、会話の感情や理解の進展を示している。
- [ ] 話者表示、句読点、数式、見出しが `style-guide.md` の書式に従っている。
- [ ] 金額を `100万円`、`1,000円` のような半角算用数字で、割合を `40%` のような半角算用数字と半角 `%` で表記している。
- [ ] リポジトリ直下から `python3 .claude/skills/yaruo-rediscovery/scripts/check_dialogue_constraints.py <教材.md>` が違反なしで終了する。

## 数式と計算

- [ ] 核心となる導出で、論理的に必要な途中式と各変形の理由を示している。
- [ ] 記号、添字、符号規約、単位、近似条件を必要な時点で定義している。
- [ ] 概念的な跳躍を「計算すると」で隠していない。長い機械計算を省略した場合も、出発式、操作、結果を示している。
- [ ] 中心となる展開・代入・計算を生徒が担当し、教師の長広舌だけで導出していない。
- [ ] 重要な式を、次元・単位、符号、既知の極限、特殊ケース、具体値のいずれかで検算している。
