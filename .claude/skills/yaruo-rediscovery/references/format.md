# Markdown書式

本文を初めて執筆するとき、または書式を大幅に直すときに読む。ここの違反の多くは `yaruo-format` のスクリプトが機械的に検出・修正する。

## 発言

- 話者名は `**やる夫**：` を独立行に置く。注記は `**やる夫**（老いて）：` の形。
- 発言を外枠の `「` `」` で囲まず、継続行を全角空白で字下げしない。意味を持つ引用語のカギカッコは残す。
- 複数文の発言は文末の `。` ごとに改行する。発言ブロックの最後の自然文も終止約物で閉じる。`？`・`！`・`……`・`──` で終わる場合と、コード・数式・表・箇条書きで終わる場合を除き、末尾に `。` を付ける。
- 台詞だけでは時系列を誤読する場面転換では、`〜〜 翌朝 〜〜` のような短い時間・場面カードを話者外の独立行に置いてよい。カードは発言ブロックの境界であり、末尾の句点は付けない。出来事や感情はカードへ書かず台詞で表現する。

## 構造

- 幕タイトルには `##`、節タイトルには `###` だけを使う（`####` 以下は使わない）。幕は `## 第N幕　タイトル`、節は `### N-M　小見出し ── 概念名`。各 `##` / `###` の直前は「空行1行、`---`、見出し」とし、直後は `---` を置かず空行1行とする。ただし、次の `##` / `###` の直前を兼ねる `---` は、直後の空行の後に置く。
- `## 幕間　タイトル`、`## 付録　タイトル`、`## 演習　タイトル`、`## 索引　タイトル`、`## あとがき　タイトル`、`## エピローグ　タイトル` 等の補助見出しは使ってよい。配下の `###` 見出しも許可するが、本編の `第N幕` / `N-M` 番号と混在させない。
- 節番号は幕番号と一致させ、幕ごとに1から連番にする。
- 最後は終幕本文と `---` で区切って `**── 完 ──**` を独立行に置き、その直後にも `---` を置く。`完` だけ、`── 完 ──`（太字なし）などの揺れを作らない。分冊の部完結は `**── I部 完 ──**`。
- 参考文献は `## 参考文献` とする。本文脚注の定義に加え、本文から参照されない番号付き文献紹介を置いてよい。

## 専門用語の英語併記

- 専門用語（学術用語・概念名・物質名・手法名）は、**本文での初出1回だけ** `長期増強（long-term potentiation）` のように全角括弧で英語を併記する。2回目以降は付けない。
- **幕・節のタイトルには付けない。** 見出しは日本語だけにし、併記はその節の本文（台詞）側で行う。
- 略語まで示すときは `（long-term potentiation, LTP）` とするか、併記の直後の台詞で「略して LTP だ」と導入する。**台詞に既に英語綴りが書いてあるなら重ねて併記しない**（`エングラム、engram。` のような重複を作らない）。
- 送り手／受け手のように対で導入する語は、同じ行でまとめて併記してよい（`送り手（presynaptic）`・`受け手（postsynaptic）`）。同義の別表記（神経細胞／ニューロン）は、揃える一文の中で両方に付ける。
- 対象は専門用語だけ。一般語、比喩、キャラクターの言い回しには付けない。`カルモジュリンは物理量を翻訳する装置だ` の「翻訳」のような比喩用法へ付けず、生物学的な意味で初出する箇所へ付ける。

## 数値・数式

- 金額は `100万円`・`1,000円`・`70ドル`、割合は `40%`・`0.13%` のように半角算用数字で書く。漢数字の金額、「パーセント」、全角数字・全角 `％` は使わない。「何十兆円」のような概数の慣用表現と通常の個数は変換しない。
- 丸囲み数字（①②③…）は使わない。環境依存で表示が崩れるため、`(1)(2)(3)…` のように半角括弧の算用数字で書く。
- メートル・グラム系の単位は `m`・`km`・`g`・`kg`・`cm`・`mm`・`μm` のようにアルファベット表記で書く。「メートル」「キログラム」のようなカタカナ表記は使わない（`プログラム`・`ヒストグラム`・`エングラム` のように単位でない語は対象外）。
- ディスプレイ数式は `$$...$$`、台詞中の短い式は `$...$`。
- 重要な到達点は太字、最終結果は `\boxed{}`。

## 崩れやすい3箇所

- **強調 `**…**`**：閉じる `**` の直前が日本語の約物（`」`・`）`・`』`・`。`・`：` など）だと、CommonMark の flanking 規則で強調として解釈されず `**` がそのまま表示される。約物を強調範囲の外へ出す（`**快楽の踏み車**（…）`）か、閉じ `**` の直後へ半角スペースを1つ置く。
- **表**：GFM ではヘッダ行の直後に `|---|---|` の区切り行が必須。無いか列数が合わないと表にならない。発言中に置く表も、直前に空行を1行入れる。
- **ディスプレイ数式 `$$...$$`**：開始・本体・終了を複数行に分けて書くと、docsify のレンダラで崩れる。`$$` から `$$` までを改行なしの1行に収める。項を並べる長い式でも `$$J = w_1 \times X + w_2 \times Y$$` のように1行で書き、見た目の整形は行わない。
