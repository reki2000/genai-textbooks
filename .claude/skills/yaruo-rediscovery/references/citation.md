# 参考文献・脚注の規約（正本）

やる夫式教材の脚注書式は、このファイルが唯一の正本とする。`yaruo-rediscovery`（執筆時）と `yaruo-proofread`（校正時）の双方がここを参照し、同じ規則を各 SKILL へ複製しない。

## 配置と番号

- 教材末尾に `## 参考文献` 節を置く（直前に `---` 区切り）。見出しはこの表記に統一し、`参考文献・脚注`・`参考文献・公的資料` のような揺れを作らない。
- 脚注番号はファイル全体の通し番号。**同一ソースは同じ番号を再利用する。** 欠番・重複を作らない。
- 純粋な導入・思考実験が中心で外部出典を要しない教材には、無理に付けない。

## 形式（分野に応じて選ぶ。一冊の中で混在してよい）

- **Web出典**：`[^N]: [サイト名『ページタイトル』](URL), YYYY年M月D日参照.`
  サイト名は運営主体（国立天文台、NASA、日本銀行など）。**権威ある一次情報源・公的資料・学術誌を優先する。** Wikipedia は事実確認の下敷きとして使い、可能なら一次資料へ差し替える。Wikipedia を出典にする場合、サイト名は `Wikipedia` に統一する。
- **原典・古典**：URL のない古典・原典は書誌情報で示す。例：`[^N]: 「万物のアルケーは水である」──アリストテレス『形而上学』A巻3で、タレスの説として伝えられる。` 哲学・思想・古典分野ではこの形式が適切で URL は不要。
- **定番教科書・書籍**：分野の標準的な教科書を挙げるなら、脚注ではなく末尾に番号付き書誌を置いてよい。例：`1. 著者, *書名*, 出版社.`

## 解説を添える

**各脚注には、本文に呼応した簡単な解説をできるだけ添える。** 出典表記だけで終えず、その脚注が本文のどの主張を裏づけるか、要点となる事実・数値・年号・人物名、または本文の文脈での意味を一文程度で補う。読者が脚注だけを読んでも本文との対応が分かる状態を目指す。

```
[^1]: [Wikipedia『Nicolas Minorsky』](URL), YYYY年M月D日参照. 1922年、軍艦の自動操舵の設計で、操舵手の動作の観察からPID制御則を初めて定式化した。
[^2]: [日本銀行『量的緩和政策』](URL), YYYY年M月D日参照.（2001年の世界初の量的緩和。本文の残高推移はこの公表統計に基づく。）
```

補足は文末の `.` の後に続けても `（…）` で囲んでもよい。原典・古典形式は書誌記述自体が解説を兼ねる。特定テーマの完成済み脚注を固定テンプレートとして流用しない。

## URL の扱い

- 参照日は作業当日（`date "+%Y年%-m月%-d日"`）。
- **記載する URL は実在と内容を確認したものだけを書く。開けない URL や捏造した出典を書いてはならない。** これは最悪の失敗にあたる。
- 出典の実在確認、一次資料への格上げ、内容の裏取りは `yaruo-proofread` の担当。執筆時に未確認の URL を仮置きしない。
