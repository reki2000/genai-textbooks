# 長編・サーベイの縦糸

分量帯が長編（8.5万字〜）またはサーベイ（13.6万字〜）のときだけ読む。標準教材には適用しない。

長編では、幕が独立した読み物として並んでしまい、全体が「章の詰め合わせ」になりやすい。それを防ぐ反復構造をプロットの段階で組み込む。

## 幕末の反復コーナー

導入・終幕を除く**各主要幕の終盤に、同じ名前と同じ形式**を持つ短いコラム的コーナーを置く。

- その幕で得た道具を、現実の事例、観察、別のトイ例、小さな判定問題へ適用する。
- **幕が進むほど過去の道具も重ねて使う。** 第5幕のコーナーでは第2〜4幕の道具も動員される、という累積構造にする。
- 単なる要点の再掲にしない。適用して初めて分かることを置く。

## 幕間

2〜4幕ごとの大きな区切りに `## 幕間` を置き、次の3つの機能を組み合わせる。**本全体でこの三つをすべて最低一度は行う。**

1. これまでの発見をやる夫がまとめる。
2. 別事例へ転移して発展させる。
3. やらない夫のクイズを、やる夫が迷い・誤りを経て解く。

## 付録にしない

コーナーと幕間を分量調整の付録にしない。**前の幕を回収して、次の幕の未解決課題を立ち上げる接続部**として働かせる。これらも節として扱い、section-card の作法（6段の型、即答・教師総括の禁止、理解の所有権）を適用する。

## 構造の参照例

`docs/books/chemical-plant/README.md` の「工場を読む①〜⑥」（幕末の累積適用）、「幕間　量産化の博物館」（歴史事例への転移）、「8-4　最後のテスト」（全幕の統合クイズ）。

```bash
rg -n '^### .*工場を読む|^## 幕間|^### 8-4' docs/books/chemical-plant/README.md
```

で位置を特定し、該当箇所だけを読む。内容・固有名詞は流用せず、構造だけを参照する。

## 状態管理

長編では状態台帳に次も加える。

- 幕末コーナーで使った題材と、累積適用の履歴
- 幕間の配置と、実施済みの機能（上記1〜3のどれを使ったか）
