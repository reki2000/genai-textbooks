# 展開が弱いときの手札

構成・大幅改訂・単調さの修正で、該当する困りごとだけを見る。毎節の義務や回数のノルマにはしない。

| 困りごと | 試すこと |
|---|---|
| やる夫が聞き役・優等生になる | 欲や焦りから極端な案を出し、人数・価格・時間に当てる。教師は案の欠陥と、解決すべき不満を分ける。既習事項まで忘れさせない |
| ボケとツッコミが固定する | 教師があえて案に乗って帰結を計算する、前提を崩す事実を出す、着眼の正しい部分を認める。教師を不自然に無知にせず主導権を変える |
| 教師の出題だけで進む | 当事者の選択、現物調査、脇役の異議、別条件で通じなくなった成功から問いを生む。脇役にも望みと拒否する理由を持たせる |
| 具体例が羅列になる | 当時の制約、数字の生活上の意味、原料から製品へのつながりを追う。予想と史実、同じ目的の別制度を比較する |
| 中盤が同じ小山の連続になる | 前の道具へ条件を加える、小さな成功の限界を見せる、個人の問題を制度へ広げる。前の幕が次の幕を必要にするようにつなぐ |
| 舞台・小道具が飾りになる | 食べ物・帳面・試作品を問い、反例、検算、感情の手掛かりに使う。後で同じ物を見る意味を変える。全小道具の回収は不要 |
| 節末が毎回総括になる | 次の行動、答えの一部、判断の代償、冗談の回収、余韻で閉じる。終幕は学んだ人物が何を守り、何を引き受けるかを選ぶ |

短縮を求められていなければ、詳説や具体例は問いとの接続を直す。笑いの親しみ・息抜き、告白や喪失の余韻も残す。発言長のばらつきや新しい締切の後付けだけでは起伏にならない。
