# 縮約改訂 ── 既存教材の分量を削減する

分量削減を頼まれたときだけ読む。

## 先に数字で合意を取る

書き直す前に、節数と1節あたりの情報量から逆算し、達成可能な削減率を提示する。往復数だけを減らしても字数は減らない。節を統合すると統合先の発言へ内容が集まるため、**字数は往復数ほどには減らない**。

1. 節ごとの字数、実効往復数、発言長の分布を `scripts/yaruo_lint.py --check --verbose` で実測して一覧にする。
2. 原寸で残す固定部（冒頭の節、終幕、参考文献、登場人物）を確定して目標から引く。**削減率の分母に参考文献を含めるかもここで決めて共有する**（数ポイント動く）。
3. 残す節へ内容を割り付ける。目標が情報量を維持した圧縮の下限を下回るなら概念または節の削除が必要で、削除候補の節名と字数を並べて指示を仰ぐ。
4. 案を複数出すときは「全概念を残す案」と「概念を削る案」を分け、それぞれの到達率を数字で示す。**到達できない率を約束しない。**

## 削りやすい順

1. **幕間の総復習。** 直前の幕末コーナーと内容が重複していることが多い。
2. **節末の「分かったのは三つだお」形式の総括。** 発見と残った疑問の1〜2行へ縮める。
3. **同型計算の2回目。** 手順は既出なので、条件と結果と一行の含意だけにする。
4. **近接して反復する同型の慢心・転落・承認・要約。** 同じ感情曲線を一つにまとめる。
5. **帳簿・台帳・一覧の全行列挙。** 上位3行と「その他」へ丸めるか、表へ落とす。
6. **末尾の演習。** 本編で同じ判定を一度通していれば重複度が高い。

削るときに1発言へ内容を積み上げない。短かった発言が6行、8行になれば字数は減らず、読み味だけ悪くなる。単なる情報列挙なら内容を落とす。落とせないなら、その節は統合の対象ではない。

## 縮約後

`scripts/yaruo_lint.py` と `python3 scripts/generate_site.py` を実行する。脚注の孤立と節番号の破れは前者が検出するので、残る確認は節や幕間を落とした箇所の前後接続（直前の節末が残した問いを、直後の節冒頭が受けているか）だけでよい。
