# ChatGPT画像生成の受け渡し雛形

- 作業記録

## 初回生成プロンプト

`{...}` を実案件の値へ置き換える。図の数とファイル名を先に確定し、各図の該当本文を要約せず「図ごとの仕様」へ入れる。

````text
日本語教材「{教材タイトル}」に掲載する科学教育図版を作成してください。

最重要の納品条件：
- 作る図は次の{N}枚です。必ず各項目を別々のPNGファイルとして生成してください。
{番号付きのファイル名一覧}
- 複数の図を1枚へ統合しないでください。
- 総覧図、コラージュ、コンタクトシート、複数図を並べたページを作らないでください。
- 1ファイルには、対応する1つの図の仕様だけを描いてください。仕様内で明示した比較パネルは、その1図の一部なので例外です。
- 生成後、上記{N}個のPNGがすべて個別ファイルとして存在することを確認してください。

共通仕様：
- 用途：scientific-educational
- 出力：各画像 {WIDTH}×{HEIGHT} px のPNG
- 背景：白
- 画風：精密で清潔な2D模式図。空間配置が理解対象なら、箱と矢印だけのフローチャートにしない。
- 青 #1f6fd0：{この教材での意味}
- 橙 #e07b1f：{この教材での意味}
- 赤 #cf3b2d：{この教材での意味}
- 灰 #8d8d8d：構造と補助情報
- 主方向は左から右。階層または拡大は上から下。
- 接続線を交差させない。無駄に折り曲げない。
- 色だけで区別せず、実線・破線、形、矢印・T字端などでも区別する。
- ラベルは対象の近くへ置き、短い名詞句にする。
- 指定したラベルを一字も変えない。指定していない説明文を追加しない。
- 本文にない対象、反応、数値、比率を追加しない。
- 装飾的な3D、遠近法、影、光沢、発光、グラデーション、レンズ効果、写真風表現は禁止。
- 人物、ウォーターマーク、ロゴ、図番号、キャプションは入れない。
- 360px幅でもタイトル、主対象、主経路、結論を判別できる太さと文字サイズにする。

図ごとの仕様：
{下の雛形で、ファイルごとに区切った仕様を列挙する}

納品前チェック：
1. ファイル名一覧と実際のPNGを照合し、{N}個すべてがあることを確認する。
2. 各PNGが別々の図であり、複数の要求を統合していないことを確認する。
3. 各PNGについて、必須要素、禁止事項、ラベル、矢印の向きを照合する。
4. 誤りがあれば、そのファイルだけを修正してから梱包する。

ZIP納品：
- 最後に、全{N}個のPNGを1個のZIP「{教材ID}-figures.zip」へまとめてください。
- ZIP内部のパスは、例外なく「{教材ID}/{ファイル名}.png」にしてください。
- ZIP内部には次の{N}ファイルだけを入れてください。
{`{教材ID}/{ファイル名}.png` の完全な一覧}
- PNGをZIPのルート直下へ置かないでください。
- `{教材ID}` の下に追加のサブディレクトリを作らないでください。
- README、PDF、JSON、サムネイル、総覧画像、元画像、途中生成物、隠しファイルを入れないでください。
- 個別画像だけを返して終了せず、必ずダウンロード可能なZIPファイルを最終成果物として提示してください。
````

ChatGPTが一度に全図を生成できない場合も、同じ会話で1枚ずつ生成を続け、最後に全PNGを集めて完全なZIPを作らせる。「2枚にまとめてよい」などの代替を許可しない。

## 図ごとの仕様

1ファイルにつきこのブロックを1個作る。`本文` にはアンカー周辺の原文をそのまま入れ、仕様が本文にない語彙を持ち込んでいないか照合できるようにする。

````text
### {連番}. `{ファイル名}.png`

この図が答える問い：
{問いを1つだけ}

該当本文：
"""
{図を置く箇所の本文原文。要約しない}
"""

構図：
- {視点、主対象、パネル、空間配置}

必須要素：
- {本文理解に不可欠な要素}

反応・接続・方向：
- {始点 → 中間 → 終点}
- {抑制ならT字端、移動なら矢印など}

ラベル（この表記に完全一致）：
- 「{ラベル}」

禁止：
- {本文と矛盾する描写}
- {誤生成されやすい向き、数、位置}
````

## ZIP受領後の判定

ユーザーへ次のように依頼する。

```text
ChatGPTからダウンロードしたZIPを、展開せずにリポジトリルートの `tmp/` 配下へ置いてください。初回なら例：`tmp/{教材ID}-figures.zip`、修正版なら例：`tmp/{教材ID}-figures-fix-{連番}.zip`。置いたらファイル名を知らせてください。
```

受領後は次の順で判定する。

1. ZIP原本を変更せず、`check_image_zip.py` で内部パス、全件性、余分なファイル、PNG形式、寸法を確認する。
2. 安全な一時ディレクトリへ展開し、全ファイルを原寸で見る。
3. 約360px幅でもタイトル、主対象、主経路、結論が分かるかを見る。
4. 図ごとの該当本文、必須要素、禁止事項、ラベル、矢印の向きと照合する。
5. 合格画像だけを `docs/books/{教材ID}/figs/` へコピーする。不合格画像を取り込まない。
6. 判定と修正指示を `scripts/figs/{教材ID}.md` に記録する。

ZIPが壊れている、内部パスが違う、ファイルが統合されている、欠落がある場合も「画像品質」とは分けて不合格理由を書く。

## 修正プロンプト

不合格時は、新規ChatGPTセッションへそのまま投入できる自己完結したプロンプトを作る。過去の会話、元画像、初回プロンプトを参照させない。「前回と同じ」「他は維持」のような、新規セッションでは解決できない指示を書かない。

各不合格図について、初回生成時の共通仕様と図ごとの完全仕様を再掲し、さらに検査で判明した誤生成を禁止事項へ加える。修正対象だけを個別PNGとして生成させ、修正ZIPにも修正対象だけを入れさせる。合格済みファイルは再生成も再納品も求めない。

````text
日本語教材「{教材タイトル}」に掲載する科学教育図版のうち、次の{M}枚だけを生成してください。この依頼は新規セッション用です。過去の会話や画像は前提にしないでください。

生成・納品するファイル：
{不合格ファイルだけの番号付き一覧}

重要：
- 上記{M}枚以外は生成しないでください。
- 他の合格済み画像は、このセッションには存在しません。要求も納品もしません。
- 複数の図を統合しないでください。1図1PNGにしてください。
- 総覧図、コラージュ、コンタクトシートを作らないでください。

共通仕様：
{初回プロンプトの共通仕様を省略せず再掲する}

図ごとの完全仕様：

### `{不合格ファイル名}.png`
- この図が答える問い：{問いを1つだけ}
- 該当本文：
  """
  {図を置く箇所の本文原文。要約しない}
  """
- 構図：{視点、主対象、パネル、空間配置を完全に書く}
- 必須要素：{本文理解に不可欠な要素をすべて書く}
- 反応・接続・方向：{始点から終点まで完全に書く}
- ラベル：{完全一致させる全文字列}
- 検査で見つかった誤り：{実際に見えた誤り}
- 必ず正す点：{正しい形、位置、方向}
- 禁止：{元の禁止事項と、再発防止条件をすべて書く}

納品前チェック：
1. 指定した{M}枚だけが、別々のPNGとして存在することを確認する。
2. 各PNGの必須要素、ラベル、矢印の向き、禁止事項を照合する。
3. 検査で見つかった誤りが再発していないことを確認する。

ZIP納品：
- ZIP名：`{教材ID}-figures-fix-{連番}.zip`
- ZIP内部は「{教材ID}/{ファイル名}.png」の形を維持してください。
- ZIPには今回生成した不合格修正版{M}枚だけを入れてください。
- 合格済み画像や、今回指定していない画像を入れないでください。
- ZIP内部には指定したPNG以外を入れないでください。
- 最後にダウンロード可能なZIPファイルを提示してください。

期待するZIP内部の一覧：
{不合格ファイルだけの `{教材ID}/{ファイル名}.png` 一覧}
````

パッケージだけが不正で画像内容は検査できている場合は、同じChatGPTセッションに限り、画像を再生成させず次を使う。新規セッションには画像がないため、この短縮指示は使わない。

```text
画像内容は変更も再生成もしないでください。このセッションで生成済みの修正対象PNGだけをそのまま使い、指定一覧どおりの内部パスで `{教材ID}-figures-fix-{連番}.zip` を再作成してください。合格済み画像、総覧画像、追加資料、隠しファイルは入れないでください。
```
