# 歴史教材の図版規約

`conventions.md` と `recipes.md` を歴史教材へ適用する際の追加規約。歴史図版は
「雰囲気を出す挿絵」ではなく、史料の性格、空間、同時代性のいずれかを本文へ
持ち込むために使う。

## 三つの層

- **史料層**：同時代の文書・器物・絵画・写真と、後世に作られた肖像・歴史画を
  区別する。後世の想像図を本人の容貌や事件現場の記録として扱わない。
- **空間層**：領域図は特定年または期間を明記し、支配領域、朝貢圏、軍事的影響圏、
  現代国境を混同しない。境界が不確かな時代に現代国家の実線国境を投影しない。
- **同時代層**：横軸を共通の年代、縦軸を地域とする。各地域を文明の発展段階で
  揃えず、同じ年に併存した政体・社会を並べる。長期間を一枚に収める場合は出来事を
  点で詰め込まず、時代区分の帯と少数の同期点に絞る。

## 史料批判をキャプションへ入れる

画像の説明は「誰／何が写るか」だけでなく、次のうち必要なものを短く明記する。

1. 制作年代と、描かれた対象の年代が同じか。
2. 作者・発注者・所蔵者が分かるか。
3. 何の証拠になり、何の証拠にはならないか。
4. 地図なら基準年と、色が表す支配関係。

人物画は「○○の肖像」だけで本人の顔を証明しない。たとえば元代の宮廷肖像は
皇帝像の制度を考える史料、後世の秦始皇像は後世の君主表象を考える史料である。

## 手段の選択

- 歴史的事件の絵画、人物画、公文書、ポスター、写真、遺物は**外部引用一択**。
  生成画像で代替しない。
- 境界や地名そのものが論点なら、査読可能な既存地図を引用する。自作地図は、
  本文と典拠から座標・境界を検証できる場合だけにする。
- 比較年表は決定的に描画する。期間データをコード内に列挙し、横位置を年代から
  計算する。帯の幅を年代差に比例させる。
- 引用画像はファイルページで作者・ライセンス・制作年代を確認する。所蔵館の
  オープンアクセス画像または Wikimedia Commons を優先し、画像直リンクだけでなく
  恒久的な資料ページを帰属欄へ置く。

## 避けること

- 生成AIで「当時の戦場」「皇帝の顔」「古地図風」を再現して史料のように置く。
- 数世紀後の歴史画を、同時代の目撃記録であるとの注記なしに置く。
- 最大版図を王朝の全期間にわたる固定領域として見せる。
- 地域ごとの帯を「未開→文明→近代」という単線的な段階へ揃える。
- 現代の民族色を古代の領域へそのまま割り当てる。
