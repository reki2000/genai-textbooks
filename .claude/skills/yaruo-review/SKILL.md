# 教材を読者の立場で評価する

執筆ルールへの適合を品質の代わりにしない。レビューだけの依頼では本文を編集しない。修正も依頼されていれば、合意された範囲で改訂まで進める。

## 読む

題名・`catalog.yml` の問いと対象本文を確認し、全体評価では通読する。次の4点を、良い場面と改善したい場面の両方から判断する。

| 観点 | 読み取ること |
|---|---|
| 学び | 読者が何を説明・計算・判断できるようになるか。根拠や途中過程を追え、別条件でも使えるか |
| 魅力 | 何を知りたくて先へ読むか。人物・場面・笑い・余韻のどこが効いているか |
| 流れ | 人物の目的と知識、時間、数値、因果がつながるか。選択や失敗が後に残るか |
| 会話 | 同じ反応・主導権・総括が続いて足踏みしていないか。発言が直前の相手に応答しているか |

即答、教師の説明、静けさ、反復自体は欠陥ではない。既習の応用や意図的な復習か、理解を進めない繰り返しかを区別する。再発見の手順に空欄があるだけで不合格にせず、読者が理解できない具体的な飛躍を指摘する。意図された誤答と、正解として残る誤りも区別する。

## 機械で確かめること

```bash
python3 scripts/yaruo_lint.py docs/books/<id>/README.md --check --verbose
```

error は書式上の欠陥として扱う。warning / info は品質の合否に使わない。反復箇所の絞り込みが必要なら `scripts/yaruo_beat_repetition.py --show`、話者バランスなら lint の `--stats` を使う。候補が0件でも通読を省略しない。ラベルを付ける場合だけ [beat-labels.md](references/beat-labels.md) を読む。

数値的な頻度を報告するなら、母数と採用した一致を確認する。検出器の severity や苦労率をそのまま評価へ転記しない。事実・数式の疑いは `yaruo-proofread` で確認するか、未確認と明記する。

## 読解で確かめること

機械検査の結果とは別に、次を本文から判断する。モデルを使う場合も自動検査の確定結果として扱わない。

- **意味**：問いと応答が噛み合い、人物がその時点で知る情報から考えているか。意図した暴論の魅力を保ちながら、教材の結論との区別が伝わるか。
- **面白味**：やる夫の欲や短絡が話を動かし、教師や脇役にも固有の応答や利害があるか。笑い、意外な具体、人物への親しみ、余韻の効いている箇所を先に拾う。
- **盛り上がり**：冒頭の問いが育ち、重要な発見や選択で見え方・行動・関係が変わるか。前の失敗、小道具、冗談の回収が山を支えているか。
- **中だるみ**：同じ結論・役割・強度が続き、読む動機が弱まる区間はどこか。前後を含めて、必要な詳説・静けさ・伏線の溜めとの違いを説明する。

改善の手法が必要なら [面白味と起伏の手札](../yaruo-rediscovery/references/anti-patterns.md) を使う。手札の未使用を欠陥にせず、その教材で生じている読者体験を根拠にする。

長い教材や大幅改訂でLunaを一次読者に使う場合は [Lunaを使う一次レビュー](references/low-cost-review.md) に従う。方法の提案だけを依頼された場合は起動しない。

## 報告する

全体の評価、残すべき魅力、優先する改善を示す。指摘には **本文の位置と引用断片／読者への影響／具体的な改訂案** を付ける。反復・矛盾なら比較する箇所を、不在なら調べた範囲を示す。好みと明確な不整合を分け、必要なものから順に報告する。

修正した場合は、前後の接続に加え、具体例・数字・詳細・人物の持ち味を削って読みごたえを失っていないか旧版と比べ、検証結果も伝える。行番号は変わるので、改稿後は引用から位置を取り直す。

## 二者レビューを依頼された場合

Codex ⇄ Claude の書面協議は `discuss` を使う。招待には対象・問い・修正範囲だけを書き、双方が独立した評価を固定してから開示する。観点を分担せず、同じ本文を読む。

各指摘を本文の証拠で照合し、一致を多数決の正しさとみなさない。不一致と理由を残す。修正する場合は適用項目を双方で確定し、開始側だけが編集、相手が差分を確認してから終了する。通信・終了手順は `discuss` を正本とする。

定量評価の pilot を明示的に依頼された場合だけ [試行ルーブリック](references/entertainment-learning-rubric.md) と対応 schema を使う。通常のレビューへ採点表やゲートを持ち込まない。
