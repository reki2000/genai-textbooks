# Lunaを使う一次レビュー

長い教材や大幅改訂では、Lunaに幕単位の自由記述レビューを1回ずつ任せ、主担当が原文で採否を決める。短い修正は直接確認する。Lunaが利用できなければ主担当で進め、未実施と明記する。全行採点は初回試行で有効な改善候補を出せず、高得点にも見落としがあったため使わない。全件の二重読解も標準にしない。

## 入力と依頼

本文版と行番号を固定する。全体評価は全幕、部分改訂は変更した幕と接続が対象。長すぎる幕だけ節で分割し、既習状態を引き継ぐ。過去の指摘・主担当の結論・会話履歴・全スキルを重ねて渡さない。

```text
対象読者：〈読者像〉／中心の問い：〈問い〉
対象版と範囲：〈本文版・幕・行範囲〉
入力：対象幕全文、前節までのoutline、接続に必要な完結した発言。
outlineには既習概念・人物の知識・数値・未解決の問いと原文位置を記す。

編集せず、次を評価する：前段からの継続性と学習の蓄積、
発見と場面・周辺情報の一体化、伏線回収の合理性と意外性、会話のテンポ、
やる夫が未習の知識を先に言っていないか、やらない夫が命令で会話を駆動していないか、
やる夫・やらない夫以外が主導権を持っていないか、
できる子・できる夫以外の人物や、識別子・記号的な装置が出ていないか。
静けさや詳説、後で訂正される仮案、しつこいギャグの繰り返しを、それだけで欠陥にしない。
残す場面2件まで、改善候補3件まで、幕の起伏を一文で返す。
各項目は「行番号・話者／理由／残すもの、または改善方向」。
矛盾は両方の箇所、指示語は参照先、中だるみは区間と前後を示す。
outlineにないことを欠落と断定せず、不明なら要確認とする。
全行採点・全文要約・外部検索・本文編集はしない。
全体800〜1,200字程度。問題がなければ件数を埋めない。
```

## 主担当の確認

- 候補の前後と参照先を原文で照合し、採用・棄却・保留と理由を記録する。指摘のなかった区間も各幕一箇所確認する。数式・外部事実は別途検証する。
- 幕をまたぐ判断（蓄積、総括や主導権の反復、全体の起伏）は、Lunaの幕単位の結果に任せず主担当が行う。
- 再評価は修正区間と接続だけ。本文・文脈・基準の版が一致する結果は再利用する。形式の修復やその場で決められる判断を再依頼しない。第二読者は重要な不一致や指定された比較に限定する。
- 費用を比較する場合は、モデル・呼び出し回数・入出力トークンと実費・採用指摘・見落とし・主担当の確認負担を記録する。未計測は未計測とする。自由記述の費用上の最適性は未実証なので、確認負担を減らさない追加依頼はやめる。
