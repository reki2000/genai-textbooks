# エンタメ学習教材 評価ルーブリック（pilot v0.1.0）

やる夫式教材の「物語としての面白さ」と「再発見による学習」が、別々に存在するだけでなく因果的に結合しているかを評価する。

この版は **pilot 用**。0〜4の値は順序尺度であり、点差を等間隔とみなさない。新規の閾値・反復回数・割合は診断仮説であり、人手校正が終わるまで受け入れ合否に使わない。単一の100点満点は作らない。

## 1. 評価対象と単位

評価は、発話・イベントを証拠単位、`section` / `bare_act` を一次判定単位、幕と教材全体を系列・集約単位とする。

- `section`: `###` を持つ幕の各 `###`。幕見出し直後から最初の `###` までに本文があれば、最初の `section` の先頭へ含める。
- `bare_act`: `###` を持たない `##` 幕の本文全体。
- 登場人物、参考文献、題名などは理由付きの `excluded_ranges` とする。
- 細分率、単位字数、単位種別は診断値であり評価軸ではない。

集約の主表示は、各単位を幕内で集約し、その幕値を教材全体で集約する「幕先行方式」。単位直接集約と文字量重み付け集約は感度分析にのみ使う。

## 2. evidence envelope

局所的な主張は次の形式で記録する。

```json
{
  "claim_type": "presence",
  "line": 123,
  "quote": "本文に実在する最小限の断片",
  "region_kind": "prose",
  "scope": {"start_line": 120, "end_line": 130, "unit_ids": ["act-02.section-01"]},
  "compared_lines": [],
  "expected": null,
  "note": "この証拠が何を示すか"
}
```

`claim_type` ごとの必須条件：

| 種類 | 必須 |
|---|---|
| `presence` | `line`、単一行に実在する `quote`、実際の領域と一致する `region_kind` |
| `absence` | 検査した `scope` と、存在を期待したものを表す `expected` |
| `comparison` | `scope` と2件以上の `compared_lines` |
| `sequence` | `scope.unit_ids` 2件以上と、必要に応じて `compared_lines` |

`region_kind` は `prose / speaker_label / heading / table / math / code / other`。数式やコードを証拠に使う場合は明示的に型を指定する。暗黙に散文として扱い、非散文領域を引用する票は無効。

行番号だけ、引用だけ、検査範囲を示さない不在主張は無効。改稿後も照合できるよう、行番号と引用断片を併記する。

## 3. core concept inventory

inventory はメタデータから確定してはならない。

1. `catalog.yml` の問い・プロット、題名、見出し、結論から候補を仮置きする。これは着手点であり inventory ではない。
2. 全文を通読し、実際に導入・格闘・適用される概念を本文証拠付きで追加する。
3. 名前が与えられていなくても、教材の問いへ答える過程の中心を占める概念は拾う。
4. 見出しにあっても本文で機能しない語は落とす。本文証拠を1件も示せない概念を inventory に残さない。
5. 各概念について、複数単位にまたがってよいので `attempt / friction / diagnosis / revision / test` を対応づける。
6. `section_role` の付与とは別パスで行う。同じモデルを使う場合も、inventory を役割ラベルから推定しない。

節・幕の役割は `core_discovery / setup / test / bridge / reflection` のいずれか。全単位に再発見サイクルの完結を求めない。

各単位について、全文通読中に次の簡略 event ledger を1回だけ作る。

- `problem / attempt / friction / diagnosis / revision / test`: 該当イベントのevidence列。無ければ空配列。
- `affect`: 前後の感情、強度変化、根拠。
- `initiative`: 誰が問いを開き、誰が転換し、誰が閉じたかと根拠。
- `enrichment`: `history / person / source / gag / toy / other` ごとの学習上の仕事、次の問い、根拠。
- `hook`: 次の問いと部分開示、その根拠。

ledgerは事実の構造化であってスコアではない。空欄を自動的な欠陥にせず、単位役割とcore concept cycleの文脈で判断する。

## 4. 共通アンカー

| 点 | 共通意味 |
|---:|---|
| 0 | 該当機能がない、または逆機能 |
| 1 | 形式的に置かれるが、教師説明または装飾の代替に留まる |
| 2 | 部分的に機能するが、欠落・不均衡・偶然性が明確 |
| 3 | 明確に機能し、本文証拠と改稿の打ち手を示せる |
| 4 | 後の再利用・成長へ接続するか、先行する伏線・モデル・問いを回収・転換し、累積効果を生む |

4は3より長いことを意味しない。終盤は先行要素の回収・転換によって4を取れる。

## 5. 軸別ルーブリック

### E1 場面・設定・人物介入の因果

舞台、小道具、人物の立場・介入が、課題・反例・検算・感情・伏線を駆動するか。

| 点 | アンカー |
|---:|---|
| 0 | 場面がなく説明だけ、または設定が推論を妨げる |
| 1 | 舞台や人物は描かれるが、別テーマへ移植しても内容が変わらない |
| 2 | 一部の場面要素だけが課題や例に使われ、人物介入の必然性は弱い |
| 3 | 舞台・立場・介入が複数の学習イベントを実際に発生させる |
| 4 | 同じ設定要素が後で意味を変えて再利用されるか、先行する設定を回収して学習とドラマの両方を進める |

- 高得点証拠：導入位置と、後の課題・反例・検算での使用位置を2点以上示せる。
- 失格反例：豪華な描写だが、会話を教室へ移しても推論が同じ。登場人物が情報を追加するだけで、介入しなくても展開が同じ。

### E2 起伏と発見頂点の整合（幕・全体のみ）

感情型、速度、主導権、発見の重要度、モデル回収の系列を見る。単位ごとのE2は付けない。

| 点 | アンカー |
|---:|---|
| 0 | 平板、または無秩序な転換で発見と感情が無関係 |
| 1 | 同じ小山が反復し、重大な発見にも感情・主導権の変化がない |
| 2 | 局所的な変化はあるが、頂点の配置や幕間の累積が弱い |
| 3 | 主要発見と感情・速度・主導権の転換が対応し、全体の山を説明できる |
| 4 | 小さな発見が大きな再発見へ累積し、過去の失敗・モデル・伏線の回収が頂点を作る |

- 高得点証拠：発見前後の感情・主導権と、過去要素の設置・回収を複数位置で示せる。
- 失格反例：遷移種類や感情語が多いだけ。毎節「案→否定→納得」が同じ強度で並ぶ。

### E3 会話のリズムと受けの多様性

発言長だけでなく、戸惑い、反発、興奮、笑い、沈黙、人物ごとの主導権が変化するか。

| 点 | アンカー |
|---:|---|
| 0 | 教師の連続講義、または同型問答が支配する |
| 1 | 生徒の短い相槌を挟むだけで、受け方と主導権が固定 |
| 2 | 長短や感情反応に変化はあるが、話者・節ごとに型が固定される |
| 3 | 内容に応じて速度・反応・主導権が変わり、学習者の考えが会話を曲げる |
| 4 | リズム変化自体が伏線・反例・感情的報酬を担い、後の会話型を転換・回収する |

- 高得点証拠：瞬発的応答と長い思考、問い返し、主導権交代を内容上の転換点で示せる。
- 失格反例：文字数分散は大きいが、教師は常に長く生徒は常に短い。「なるほど」が多いだけ。

### L1 再発見サイクルと段階性

`attempt / friction / diagnosis / revision / test` が、核心概念ごとに因果的につながるか。

| 点 | アンカー |
|---:|---|
| 0 | 完成知識の説明だけで、試行がない |
| 1 | 形式的な試行はあるが、教師が破綻・原因・修正を代弁する |
| 2 | サイクルの一部は学習者が担うが、重要段の飛躍または検算不足がある |
| 3 | 学習者の試行から外的摩擦、原因言語化、修正、具体的検算までつながる |
| 4 | 複数サイクルが前の失敗を足場に成長し、別条件への転移や限界確認まで行う |

- 高得点証拠：各段を別々の本文位置へ対応づけ、実行主体を示せる。
- 失格反例：「その案は破綻する」→「なるほど」で反例と検算を埋めたことにする。

### L2 苦労の実在と初学者らしさ

正答前の誤答・迷い・手計算・自己修正が実在し、素朴案が藁人形でないか。

| 点 | アンカー |
|---:|---|
| 0 | 学習者が容易に正答を乱発する |
| 1 | 誤りを一発言内ですぐ自己訂正する、または誰も採らない案を潰す |
| 2 | もっともらしい案は出るが、摩擦や修正の主体が主に教師 |
| 3 | 学習者が妥当な案を実行し、世界・計算・モデルから反証を受け、自分で修正する |
| 4 | 失敗が後の局面で再利用され、学習者が以前の誤りを比較・一般化して新しい案を作る |

- 高得点証拠：素朴案の実行主体、外的摩擦、本人の修正文を示せる。
- 失格反例：「いや待てよ」で摩擦なしに正答へ到達。わざと愚かな案だけを出す。

### L3 深さ・知識予算・問いへの応答

宣言した問いへ機構レベルで答え、概念を到達前に使わず、知識ツアーで終わらないか。

| 点 | アンカー |
|---:|---|
| 0 | 問いに答えない、または説明が重大に逆方向 |
| 1 | 用語・歴史・分派を並べるだけで「なぜ」へ降りない |
| 2 | 機構の一部は説明するが、定義前使用、飛躍、結論との断絶がある |
| 3 | 問いに機構で答え、必要概念を到達順に導入し、具体例で検証する |
| 4 | 機構の適用範囲・限界・別条件への転移まで、先行理解を回収して示す |

- 高得点証拠：問い、機構説明、結論、転移例の対応を示せる。
- 失格反例：正しい一般論だが宣言した問いに答えない。生徒が後の幕の知識を先に使う。

### S1 エンタメと学習の結合

笑い、舞台、トイ、歴史、人物、文献が、伏線・素朴案・反例・検算・部分開示・次の問いのいずれかを担うか。副項目は `toy_model_growth` と `curiosity_bridge`。

| 点 | アンカー |
|---:|---|
| 0 | エンタメ要素が学習と無関係、または学習を遮る |
| 1 | 面白い装飾や知識の言い換えに留まり、学習上の仕事がない |
| 2 | 一部は課題・例に使われるが、使い捨てが多い |
| 3 | 主要なエンタメ要素が学習上の仕事を持ち、トイまたは挿話が再利用される |
| 4 | トイが制約・変数・限界を加えて成長するか、挿話・笑い・文献が後の問いや発見を累積的に開く |

- 高得点証拠：導入行、学習上の担当、再利用・成長・次の問いを対応づける。
- 失格反例：質の高いギャグだが削除しても推論と感情曲線が変わらない。「この例で考える」と宣言した後に例が消える。

## 6. ゲート

- L1：核心概念に対応するサイクルで `attempt / friction / diagnosis / revision / test` の必須段が欠ける。
- L2：核心再発見全体で「学習者自身が試す→外的摩擦を受ける→修正する」が欠ける。

ゲート状態は `pass / fail / uncertain`。診断スコアとは別に記録し、他軸で補償しない。単発の即答だけでL2をfailにしない。

## 7. 退屈区間

平均へ畳まず、`axis / unit_ids / defect_type / severity / evidence` を別表にする。意図的な溜め・静けさかを全体文脈で判断する。同型ビート4連続などの数値は候補検出の仮値であり、自動不合格にしない。

## 8. 評価出力と独立pilot

- 教材全体：7軸。E2は幕・全体系列だけで評価。
- サンプル単位：E1/E3/L1/L2/L3/S1。先頭・中央・最終・`sha256(book_id)`で選ぶ擬似無作為単位。重複時は未選択単位へlinear probingする。
- warning/infoは重点読解の手がかりで、品質判定の根拠にしない。
- pilot対象は10教材（`bureaucracy`, `weather-forecasting`, `global-history`, `japan-food-policy`, `philosophy`, `taxonomy`, `skyscraper`, `ultimate-detergent`, `statistics`, `merit-and-luck`）。Codex/Claudeは互いの評価を見ずに10 JSONを固定し、book id昇順にファイルbytesを連結したSHA-256を先に公開する。両ハッシュ固定後に本文を開示する。

照合で点数を平均しない。不一致は次へ分類する。

1. 証拠の見落とし
2. 軸境界の解釈差
3. 重要度の差
4. 合理的な多視点
5. schema不備
6. ルーブリック文言の解釈差（双方合意時だけ教材ぶれの分母から除外し、改訂候補へ送る）

必ず人が照合する診断トリガー：

1. 同じ核心概念のL1/L2ゲート不一致。
2. 同じscopeの同じ軸で2点以上の差。
3. 一方の欠落主張に対し、他方が同じscopeで存在証拠を示す。
4. inventory差だけでゲートが片側発火する。
5. 同一軸の10教材順位で、一方の最上位が他方の最下位になる。
6. 一方の退屈区間の全単位を他方が対応軸で3以上とし、他方の証拠・備考に系列反復が記録されない。

トリガー発火は自動的に致命的という意味ではない。両方の証拠が妥当な異なる読みなら、複数レビューの利点として残す。繰り返し起きる軸境界の曖昧さ、証拠規則の不一致、schema不備により、手順上両立しない結論が出る場合を致命的なぶれとする。

不一致トリガーとは別に、scaffoldの除外範囲と単位境界を評価開始前に目視し、両者が同じparser前提の誤りへ一致していないかを監査する。照合報告には「共有前提の失敗」を独立欄として設け、一致率を手順の正しさの証拠とはみなさない。
