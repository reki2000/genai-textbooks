# ビートラベルと同型反復の検出

会話の同型反復を、語の一致ではなく**直前の発言に対して何をしたか**で調べる。層2は機械による候補抽出、層3は読み手による意味判断であり、検出だけで合否を決めない。

## 層2 表層（機械・語彙非依存）

```bash
python3 scripts/yaruo_beat_repetition.py docs/books/<id>/README.md
python3 scripts/yaruo_beat_repetition.py docs/books/<id>/README.md --show   # 会話の具体つき
```

発話ターンを「役割ID（書内の総発話量順位）× 長さ級 × 終端型 × 非散文の有無」の1記号に落とし、

- **単位内単調度 M**：周期反復が列を占める割合。`ABABAB` を直接捉える。
  周期の上限は固定3ではなくターン数に応じて可変（最大6）。3ターンより長い
  型の反復（摩擦→導出→提示、など）も拾うため
- **単位間新規性 N**：隣接単位の正規化編集距離。**その教材自身の中央値で正規化する**

を出す。教材ごとに地の文体が違うため、書間で共通の閾値は意味を持たない。
`N` が書内下位に3単位以上連続で留まる区間を `same-beat-run` の候補として出す。

長さ級・終端型が境界1文字で変わるため、型が同じでも新規性を高く誤判定することがある。役割と非散文の有無だけの `loose_symbols` でも検定し、厳密ランにない区間を `loose-novelty-candidate`（`?` 行）として出す。こちらは3単位未満も除外しない。

例：`weather-forecasting` 第4幕は厳密記号で `runs=0` でも、`act-04.section-02…act-04.section-04` が候補になる。候補が0件でも通読は省略しない。

## 層3 ビートラベル（読み手が付ける）

候補区間と、比較のための対照区間（同じ教材の非候補区間）にだけ付ける。全文には付けない。
判定基準は**どんな語が出たかではなく、直前のターンに対して何をしたか**。

| 側 | ラベル | 意味 |
|---|---|---|
| 教師 | **指示** | 命令形で次の作業を与える |
| 教師 | **問い** | 答えを生徒に探させる問いかけ |
| 教師 | 摩擦 | 反例・反証・失敗の提示 |
| 教師 | 提示 | 正式名・整理・答え合わせ |
| 生徒 | 提案 | 自発的な素朴案 |
| 生徒 | **質問** | 生徒から教師への問い返し。主導権が生徒に渡る |
| 生徒 | **誤答** | 素朴な誤答・的外れな断定 |
| 生徒 | **逡巡** | 迷い、言い淀み、保留、答えられない |
| 生徒 | **単純正答** | 摩擦を経ずに正解を返す |
| 生徒 | 検算 | 手計算・具体例での検査 |
| 生徒 | 診断 | なぜ失敗したかの言語化 |
| 生徒 | 修正 | 案の作り直し |
| 共通 | 情動 / 脱線 | |

`{unit_id: [ラベル, ...]}` の JSON にして渡す。ターン数と要素数は一致させる。

```bash
python3 scripts/yaruo_beat_repetition.py docs/books/<id>/README.md --beats beats.json --units
```

## 指標の読み方

| 指標 | 定義 |
|---|---|
| 指示率 | 指示 ÷（指示＋問い） |
| 単純正答率 | 単純正答 ÷ 全ビート |
| 苦労率 | （誤答＋逡巡＋摩擦）÷ 全ビート |
| 生徒主導率 | （提案＋質問）÷ 全ビート |
| 指示→単純正答 | 「指示 or 問い」の直後に「単純正答」が来る隣接ペア数 |

これらは会話の構成を調べる記述値で、目標値ではない。生徒の問い返しと、答えられない逡巡を区別する。

`instruction-and-plain-answer` や `no-struggle` が出ても、それだけで欠陥にしない。既習事項を使えている場面なら即答は自然である。未知の結論へ根拠なく飛んでいる場合や、学びが進まない問答を反復している場合に、本文の該当箇所と影響を報告する。苦労率を上げるための誤答・逡巡の追加はしない。

## 校正されていない点（指摘票へ書くときの注意）

- **severity は未校正。** ラベル付きの事例が少なく、`bureaucracy` を手動 minor と判定した区間を
  検出器は critical と出す。**深さ・単位数・苦労率の生値を票に書き、severity 文字列を根拠にしない。**
- 意図的な溜め・静けさの可能性を全体文脈で判断する。**同型ビートN連続を自動不合格にしない。**
- 層2の記号列（`ASASAS…`）は証拠の要約であって証拠ではない。**票には必ず行番号と引用を書く。**
