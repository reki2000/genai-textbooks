# 評価用の台帳

蓄積・継続性・やる夫の知識量・伏線は、一場面を読んでも判定できず、前後の比較が要る。長い教材を一度に読んで印象で答えないよう、判定の前に事実だけを節ごとに拾う。台帳は評価ではなく、欠陥の断定は原文の前後を読んで行う。

## 節ごとに拾うもの

各項目に行番号と、本文に実在する短い引用を付ける。該当がなければ空欄でよい。

| 欄 | 拾うもの |
|---|---|
| 入口 | この節が何から始まるか（前段の未解決の問い・失敗・約束・やる夫の不満、または新しい話題）と、それが前段のどこに対応するか |
| 新出概念 | この節で初めて出た概念・用語・数値と、誰が最初に口にしたか |
| 再利用 | 既出の概念・数値・失敗・小道具を使った箇所と、その初出位置。使い方が初出と同じか、別条件への適用か |
| やる夫の語 | やる夫が使った専門用語・正式名・結論のうち、その時点で本文に出ていなかったもの |
| 発見 | この節で得られる理解と、それを生んだ場面の出来事・具体物・人物の欲や失敗。記憶の手掛かりになる周辺情報（歴史の当事者、数字の規模、意外なつながり） |
| 伏線 | 仕込み（後で意味が変わりそうな物・冗談・約束・数値）と回収（どの仕込みの、何がどう変わったか） |
| 出口 | 節の終わりに残る問い・課題と、次の節の入口との対応 |

## 台帳から出す候補

- **蓄積**：再利用がほとんどない節、後で一度も再利用されない新出概念、同じ概念を同じ使い方で説明し直す箇所。
- **継続性**：入口が前段のどこにも対応しない節、出口と次の入口が食い違う箇所。
- **やる夫の知識量**：「やる夫の語」の欄に載った発言。既習の言い換えか、日常語として自然なら候補から外す。
- **伏線**：回収のない仕込み、仕込みのない回収、回収の直前に追加された情報。

候補は原文の前後を読んで確定・棄却し、棄却した理由も短く残す。台帳の空欄を欠陥とみなさない。
