# やる夫式教材 比喩検査スキル

対象は yaruo-rediscovery が生成した会話形式の教材。検出したいのは、**その分野の語彙でない具体物が、導入も説明もなく比喩として持ち込まれる**箇所（例：資産運用の教材に前置きなく現れる「三つの封筒」「商品のパスポート」）。

**教材を通読しない。** 全30冊で約122万字あり、通読は総量が20倍以上になるうえ、長文の中盤に埋もれた1語への注意が落ちて精度もむしろ下がる。代わりに3段のふるいを使い、モデルが読むのは (a) 語彙リスト、(b) 候補語の周辺だけに限る。

## 検査の3段

### 第1段：候補語の抽出（スクリプトのみ、モデルは読まない）

リポジトリルートで実行する。

```bash
python3 .claude/skills/yaruo-metaphor/scripts/detect_metaphors.py candidates --book asset-management
```

`--book` は繰り返し指定でき、省略すると全冊。文書頻度は指定に関わらず常に全30冊で計算する（1冊だけでは「その本にしか出ない語」が定義できないため）。

原理は、**唐突な比喩の語は、他のどの教材にも出てこない語になる**こと。全冊を横断して文書頻度 df を数え、df の小さい語だけを残す。本来の専門語（`債券`、`証拠金`）も同じく df が小さいので、この段だけでは分離できない——分離は第2段のモデルが行う。この段の役目は、1冊2,800語の語彙を数百〜2,000語の**語だけのリスト**に落とし、本文をコンテキストへ持ち込ませないことにある。

既定は最大リコール（`--min-count 1 --max-df 3`）で、全冊合計25,484語・約36万字。教材本文の約1/10に収まる。1回しか出てこない語も残るので、取りこぼしを恐れて緩める必要はない。トークンを削りたいときだけ `--min-count 3 --max-df 1`（全冊で約2,900語）へ絞る。

参考文献・登場人物・コードフェンス・TeX数式・話者表示行は集計から除く。参考文献は19冊にあり、書誌の固有名詞はすべて df=1 になるので、残すと候補が埋もれる。

### 第2段：語彙リストだけを見て異物を選ぶ（モデル、本文は読まない）

第1段の出力（`## <book id>  <タイトル>` と語のリスト）だけを見て、**その教材の主題の語彙に属さない具体物・日常物・別分野の語**を選ぶ。頻度順に並んでいるので、専門語の列に混じった異物として目に付く。

```
債券(36) 配当(31) 原油(30) 保管(27) 株価(27) … 出来高(18) 封筒(18) 購買力(18) …
```

選ぶ基準：

- **具体物・日常物**であること（封筒、パスポート、財布、浴槽、札束、油田）。抽象語・関係語は比喩の乗り物になりにくい。
- **主題の語彙でない**こと。カタログのタイトルが示す分野の教科書に索引語として載らない語。
- 判断に迷う語は**落とさず残す**。第3段で本文を見れば安く棄却できるが、ここで落とすと二度と拾えない。

ここで拾いすぎても構わない。1冊あたり10〜30語まで残してよい。

**この段では本文を読まない。** 語だけで「主題外の具体物か」は判断でき、本文を開いた時点でこのスキルの利点が消える。

### 第3段：該当箇所だけを読んで唐突さを判定（モデル）

第2段で残した語について、初出前後だけを取り出す。

```bash
python3 .claude/skills/yaruo-metaphor/scripts/detect_metaphors.py context \
  --book asset-management --terms 封筒,パスポート,浴槽
```

出現回数・初出行・導入マーカーの有無・初出前後±12行（`--window` で調整）・他の出現行が出る。判定は次で行う。

**不自然（報告する）**：

- 初出でいきなり比喩として使われ、なぜその物に見立てるのかの説明がない。
- その物の性質（封筒は分けて封をする、パスポートは身元を証明する）を読者が知っている前提で、本文がその前提を作っていない。
- 分野の外から来た見立てで、同じことを主題の語彙で言えるのに置き換える必然がない。

**自然（報告しない）**：

- 導入マーカー（「〜とは」「〜に例えると」「〜と呼ぼう」「見立てて」）とともに提示され、対応関係が明示されている。
- 会話の流れの中から必然的に出てくる。例：原油の現物をどこへ置くかという問答から出る「浴槽」は比喩ではなく、その場の具体例である。
- やる夫の素朴な誤解・ボケとして置かれ、直後にやらない夫が扱いを正している。**再発見サイクルの物語装置は訂正対象にしない**（yaruo-proofread と同じ原則）。

初出が自然でも、以降の幕で説明抜きに使い回されていれば、その使い回し自体は報告してよい。他の出現行が離れた幕に散っている語（`封筒` の L241〜L3421 など）は、教材全体を貫く用語として定着しているかを確認する。

### 補完パス：明示的な比喩マーカー

第1〜3段は「主題外の珍しい語」で作られた比喩しか拾えない。`水`・`道`・`家` のような高頻度の一般語による比喩は df が大きく通り抜ける。これは別に拾う。

```bash
python3 .claude/skills/yaruo-metaphor/scripts/detect_metaphors.py markers
```

「〜のようなもの」「〜に例えると」「見立てて」「いわば」などを含む行だけを出す。全30冊で199行しかないので、全件そのまま読んで判定してよい。

## 報告

ユーザーに次を報告する。

- 検査した教材と、第1段の候補語数・第2段で残した語数
- **不自然と判定した箇所の一覧**：教材／語／初出行番号／該当行の引用／なぜ唐突か
- 第2段で拾ったが第3段で自然と判定して棄却した語（判断の根拠つきで簡潔に）
- 補完パスで見つかった比喩の問題

修正は行わない。修正するかどうかと、比喩を消すか導入文を足すかはユーザーが決める。求められた場合のみ、キャラクターの語尾・文体を保ったまま導入の一文を補う形で直す。

候補が0件だった教材も「検査して問題なし」と明示する（検査していないのと区別がつくように）。

## 限界

- 平仮名だけの語は候補に上がらない（比喩の乗り物は漢字かカタカナの具体名詞という前提）。
- 5文字を超える漢字連続は分割して数えるため、長い複合語の一部が候補に混じる。ノイズなので無視してよい。
- 3冊以上で共有される比喩（既定 `--max-df 3`）は第1段を通り抜ける。テンプレート的な言い回しが全教材へ広がっている疑いがあるときは `--max-df` を上げる。
