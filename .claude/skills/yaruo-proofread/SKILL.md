# 根拠とつながりを校正する

対象と依頼範囲を確認する。評価のみなら指摘を報告し、校正・修正を依頼されていれば直す。人物の語尾や意図された誤答を保ち、教材が正解として残す主張を検証する。誤答が後で訂正されず誤解を残す場合は、その接続も直す。

## 事実と出典

- 主張を本文の位置と対応づける。冒頭の驚き、核心概念、結末を支える数値・歴史・因果説明から確認する。仮想データ、概算、観測事実、解釈を区別する。
- 重要な主張は公式統計、原典、研究論文などの一次資料を優先し、本文がその主張を支えるか読む。百科事典や検索結果は資料を探す手掛かりに使う。主張は出典ごとにまとめて確認し、無関係な全文を集めない。
- 数値の年度、母集団、単位、指標の定義を照合する。出来事の前後関係や一事例だけから、一般的な因果や唯一の政策解を断定しない。
- 確認できなければ未確認として残すか削除する。「と言われる」への言い換えだけで裏付け済みにしない。代替資料を探す場合も、依頼された検証範囲を守る。
- 脚注の書式は [citation.md](../yaruo-rediscovery/references/citation.md)。既存出典を引き継いだだけなら、参照日を更新して再確認済みに見せない。

## 論理と数式

- 問いへの応答、定義と使用の順、前後の参照、説明と結論を照合する。枠組みを言い換えるとき、項目の意味を途中で変えていないかを見る。
- 数値例は再計算する。与えられた数を割るだけでなく、その入力が内訳・桁・範囲と整合するか確認する。
- 記号、対象領域、単位、時間幅、近似条件を確かめ、途中式から結果を追う。保存式では内部移動と領域外への流出、確率では条件と分母を混ぜない。必要な検算はスクリプトに残す。
- 人物が知る情報、現実と模型の時間、締切、伏線の設置と回収も確認する。構造を修正した後に数値と参照を再確認する。

専門用語の英語併記・訳語・数式の書式は [format.md](../yaruo-rediscovery/references/format.md) を参照する。書式の機械修正には `yaruo-format` を使う。

## 検証と報告

```bash
python3 scripts/yaruo_lint.py docs/books/<id>/README.md --check --verbose
```

本文を変更したらサイトもビルドする。確認した範囲、主要な訂正と根拠、未確認事項を報告する。部分検証を全件確認として報告しない。
