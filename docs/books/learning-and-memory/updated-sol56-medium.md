# 改稿記録（sol56-medium）

`review-opus-medium.md` の指摘と皆瀬案を軸に、教材の既存構造を保ちながら終盤の因果と回収を強化した。

## 主な変更

- 3-4 の「0.41」を効果量として説明し、正答率や相関係数ではないこと、小さいが無視できない群間差を表すことを会話内で確認させた。脚注も同じ説明に合わせた。
- 7-6 のチェックリスト研究に、導入前後比較では同時期の変化を切り分けにくいという批判を追加した。効果量を確定値として扱わず、八病院で低下方向がそろったことと機序を検討材料として残した。
- 第5・6幕の節末ラベルを「今日買った手と、今日捨てた手」、第7・8幕を「設計書への追記」へ変更した。第7幕冒頭から設計書を書き始める設定にし、9-3で突然現れる印象を弱めた。
- 7-7 の引き継ぎに「今月末」という期限を置き、9-4 の設計書へ、後輩との比較・判定・答え合わせを三回行う具体策を追加した。
- 幕間2で設計した自転車練習を第9幕冒頭で実行した。足着き回数が学習者を萎縮させる失敗を経て、目盛り自体が行動を変えること、試して直すことを描いた。ビジネス妄想も一度だけ小さく実行へ移した。
- 9-3 の探索・活用を、競馬の熟達者とタクシー運転手の例へ接続し、既習の「熟達の利益と代償」を時間配分として言い直す概念にした。
- 終幕では、現実のやらない夫が四枚目のカードを置いて帰った痕跡を残し、夢の装置への問いに行為で答えた。

## 工夫した点

- 新しい正解を教師が即答する形を避け、やる夫が既習の道具で数字や設計を疑い、測定の意味を言い直す往復を増やした。
- 成功談だけにせず、自転車では「改善した数字」と「悪化した学習者の反応」を衝突させ、設計が実地で壊れて更新される過程を置いた。
- 元の強みである三枚のカード、仮説の回収、参考文献、次教材への接続は維持した。

## 残した判断

- 第1〜4幕の診断型の節末まとめは、初学者が仮説と反証を追う助けになるため維持した。
- 第5・6幕の節末本文は、学習内容の照合に必要な情報を落とさず、導入句を変える範囲に留めた。
- 夢の歴史上の人物を逐一説明する設定は加えず、四枚目のカードという物証だけで、やらない夫の関与を示す余白を残した。
