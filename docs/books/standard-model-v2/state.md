# `standard-model-v2` 状態台帳

## 制作条件

- 作業種別：全面再設計後の新規長編本文。
- 完成形：8幕＋終幕、参考文献まで執筆。
- 物語の期限：午前0時03分から開館時刻の午前9時まで。
- 人物関係：科学館の生解説員やる夫と巡回検出器保守技師やらない夫は、未知粒子説と読出し故障説を賭ける対戦相手。
- 最終判定：両者の最初の断定を反例で退け、E-17を標準模型の $W\rightarrow e\nu$ 候補事象とする。
- E-17、検出器応答、教育用探索の件数はすべて架空。実在の衝突事象とは結び付けない。

## E-17固定値

- 電子候補横運動量：$p_T^e=46.0\,\mathrm{GeV}$。
- 電子候補の横ベクトル：$\vec p_T^{\,e}=(46.0,0.0)\,\mathrm{GeV}$。
- ハドロン反跳と軟質成分：$\vec u_T=(-20.1,-35.6)\,\mathrm{GeV}$、大きさ約 $40.9\,\mathrm{GeV}$。
- 可視横運動量和：$(25.9,-35.6)\,\mathrm{GeV}$。
- 欠損横運動量：$\vec p_T^{\,\mathrm{miss}}=(-25.9,35.6)\,\mathrm{GeV}$、大きさ $44.0\,\mathrm{GeV}$。
- 電子候補と欠損横運動量の方位角差：$\Delta\phi=2.20\,\mathrm{rad}$。
- 単一ニュートリノ、電子・ニュートリノ質量無視の仮定で $m_T=80.2\,\mathrm{GeV}$。
- 欠損方向の局所セルは前後の較正パルスへ正常応答。隣接セルの時刻、読出し飽和、飛跡由来軟質成分にも決定的異常なし。
- 宇宙線仮説に対し、電子候補の飛跡と時刻はビーム衝突点に整合。

## 検出器と理論対象の区別

- 観測記録：飛跡検出器、電磁・ハドロンカロリメータ、ミューオン検出器の応答。
- 再構成物体：電子候補、ジェット、軟質成分、欠損横運動量。
- 理論対象：電子場の励起、クォーク、グルーオン、W、ニュートリノ、ヒッグス場とヒッグス粒子。
- 欠損横運動量は未検出粒子の直接測定ではなく、可視再構成物体の横運動量和の負。
- 理論クォーク、ハドロン化後の粒子、カロリメータ応答、再構成ジェットを同一視しない。
- E-17の「ニュートリノ」は単一未検出成分という仮定に基づく候補であり、直接の飛跡ではない。

## 全幕の到達点

- 第1幕：独立な検出器応答から電子候補を再構成し、欠損横運動量を可視和の負として計算。未知粒子確定と単純読出し故障をともに後退させる。
- 第2幕：$L=100\,\mathrm{fm}$ と $50\,\mathrm{fm}$ の局在概算で、粒子数固定の記述が対生成尺度で破れると確認。場の生成・消滅、反粒子、フェルミオン・ボソンへ進む。
- 第3幕：連続対称性と保存則を結び、複素スカラー場のU(1)電流を導出。初期パートン分率 $x_1,x_2$ が未知なので縦でなく横成分を使うと回収。
- 第4幕：局所位相変換で通常微分に出る余分な項を共変微分で相殺。交換子から場の強さ、質量項の非不変性、非可換場の自己相互作用を得る。
- 第5幕：$\Delta^{++}$ の交換対称性から色自由度の必要を示し、$\dim SU(3)=8$、QCDの漸近自由、閉じ込め、ハドロン化、ジェットへ進む。E-17のQCD背景を具体化。
- 第6幕：左カイラル弱相互作用、$SU(2)_L\times U(1)_Y$、荷電・中性カレントを導入。E-17の横質量 $80.2\,\mathrm{GeV}$ を得てW候補へ絞る。ニュートリノ質量を最小標準模型の限界として残す。
- 第7幕：ヒッグス二重項のポテンシャル、非零真空、W・Zと光子の質量差、自由度12の会計、湯川結合を導出。E-17がヒッグス発見事象ではないと分離。
- 第8幕：W、QCD、装置、宇宙線を同じ表で比較。$N=\sigma\mathcal LA\varepsilon$、統計揺らぎ、系統誤差、5σ、局所・大域有意度、盲検、独立再現を扱い、一件を発見と呼ばない。
- 終幕：二枚の断定字幕を両者で撤去。痕跡から限界までの推論経路を展示し、重力・暗黒物質・三世代・物質非対称を未解決の空席として残す。

## 核心式と検算

- 欠損横運動量：$\vec p_T^{\,\mathrm{miss}}=-\sum_i\vec p_{T,i}^{\,\mathrm{vis}}$。
- 局在概算：$\Delta p\,c\geq\hbar c/(2L)$。$L=100\,\mathrm{fm}$ で約 $0.99\,\mathrm{MeV}$、$L=50\,\mathrm{fm}$ で約 $1.97\,\mathrm{MeV}$。
- U(1)電流：$j^\mu=iq[(\partial^\mu\phi^*)\phi-\phi^*\partial^\mu\phi]$。実場を代入するとゼロになる合否例を確認。
- 共変微分：$D_\mu=\partial_\mu+iqA_\mu$、$A'_\mu=A_\mu-\partial_\mu\alpha$、$D'_\mu\psi'=e^{iq\alpha}D_\mu\psi$。
- 非可換生成子数：$\dim SU(N)=N^2-1$、SU(3)では8。
- 横質量：$m_T^2=2p_T^ep_T^\nu(1-\cos\Delta\phi)$。固定値から $m_T^2=6.43\times10^3\,\mathrm{GeV}^2$、$m_T=80.2\,\mathrm{GeV}$。$\Delta\phi\to0$ で0、$\Delta\phi\to\pi$ で最大。
- ヒッグス機構：$m_W=gv/2$、$m_Z=v\sqrt{g^2+g'^2}/2$、$m_\gamma=0$。
- 自由度：破れ前 $4\times2+4=12$、破れ後 $2+6+3+1=12$。
- 湯川質量：$m_f=y_fv/\sqrt2$、ヒッグス結合 $g_{hff}=m_f/v$。$y_f$ の階層は標準模型内で予言しない。
- 期待件数：$N_{\mathrm{sig}}=\sigma\mathcal LA\varepsilon$。教材値 $0.05\,\mathrm{pb}\times10\,\mathrm{fb}^{-1}\times0.20=100$ 件。
- 統計例：背景4,900、観測5,012、超過112、統計幅70、3%系統幅147、粗い合成幅163、$Z_{\mathrm{rough}}=0.69$。

## マクガフィンとトイの推移

- E-17：全幕で同じ数値を使い、未知粒子の印象からW候補へ主張を縮める。
- 八角形の事件盤：検出器、保存量、場、対称性、相互作用、真空、統計、限界を幕ごとに累積。
- 三色リボン：第1幕の謎、第5幕の色一重項・閉じ込め・ハドロン化、終幕の未解決性へ回収。正確なQCDポテンシャルの模型とは主張しない。
- 位相時計：第4幕で局所基準と接続を示し、終幕で基準が違っても換算できるという理解へ回収。
- 空席H：第1幕の四本脚、第7幕の四実自由度から三縦偏極＋一ヒッグス、第8幕以後の未解決空席へ意味を変える。
- 巨大字幕：「発見！／故障！」から「発見？／故障？」、最終的に「W候補／背景・装置を要調査」へ弱め、終幕で両方消灯。
- 電子札のL/R：第6幕のカイラリティで回収。

## 人物の失敗と修正

- やる夫：欠損を未知粒子の直接観測と誤認、粒子を小球とみなす、群を属性相性表にする、単独クォークを探す、横質量一件を確定扱い、ヒッグスを全質量の一語説明にする、5σを自動判定とみなす。各段階で観測・仮定・代替説を分ける。
- やらない夫：異常を読出しへ寄せ、単純な局所故障を予想する。独立層、較正パルス、時刻、方向安定性の反例で撤回し、装置理解を系統不確かさの評価へ接続する。
- できる子：数値、誤差、仮説表を提示し、最終判定を両者の勝敗でなく反例への耐性で行う。
- できる夫：二択演出を毎幕弱め、終幕で速報字幕を消し、推論経路の表示へ作り替える。

## 緩急と反復

- 第1幕は公開前夜の賭けと欠損表示で高速に開始。
- 第2幕は暗い展示室で場の直観を作り、局在概算で静かに深める。
- 第3・4幕は事件盤と位相時計で式を手作業し、第5幕は三色リボンの身体ギャグで緩める。
- 第6幕の $m_T=80.2\,\mathrm{GeV}$ を事件の絞り込み、第7幕の自由度会計を理論上の頂点にする。
- 第8幕は統計で熱を冷まし、終幕は来館者の「直接見たのか」という問いへ戻る。
- 「群作用は相性表ではない」「まず帳尻を閉じろ」「CGで空白を埋めない」を意味を変えながら反復。
