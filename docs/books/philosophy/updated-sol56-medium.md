# 改稿記録

## 工夫した点・主な変更

- 第1幕のヘラクレイトス節にワインの杯を登場させ、後世の「第1幕の杯」という参照と、同一性をめぐる全編のモチーフを接続した。
- 普遍論争で、やる夫がオッカムの剃刀を神にまで向けて周囲から孤立する場面を追加した。オッカム本人の主張とは区別しつつ、序幕で予告された「早すぎる問いの代価」を、説明ではなく体験として描いた。
- ヘーゲル、フレーゲ、ソシュールの即答を崩し、素朴案・反例・再考を挟んだ。特に弁証法は「勝者だけが残る自然淘汰」という誤答から、否定されたものが次の立場に保存されることへ気づく流れにした。
- 第10幕から第13幕の冒頭に、その時代の常識や期待をやる夫が内面化する短い場面を追加し、「成り代わり」設定を後半でも働かせた。
- ショーペンハウアー節では、欲望と苦の関係をやる夫自身に導かせ、仏教との類似と相違を本文内で明示した。他教材への参照だけで効果を主張する形は避けた。
- 後期ウィトゲンシュタインには大規模言語モデル、ゲティア問題にはAIの偶然の正答を接続した。現代の道具を題材に、「使用と理解」「正答と知識」の違いを読者自身が考えられる問いへした。

## 残した判断

- 第11幕の人名・節構成は大幅には削らなかった。全体の哲学史としての参照性を保ちつつ、レビューで特に即答が問題視された箇所の往復を厚くする方を優先した。
- オッカム節の孤立は架空の教育的場面として明確に演出し、オッカム自身が無神論を唱えたとの誤解が生じないよう、やらない夫の留保を直後に置いた。
- AIの例は特定製品や一時的な性能評価に依存させず、認識論上の構造が見える思考実験として記述した。
