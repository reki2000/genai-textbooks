# 寸評：やる夫がイスラム世界を一枚岩だと思っていたようです ── 神の教え、法、共同体、宗派、国家を分解する

約130KB／全9幕。市役所の多文化共生担当が「3分で分かる完全対応マニュアル」を作ろうとして失敗を重ね、信仰／実践／法学／社会／国家の5層モデルと窓口の判断手順へ到達する教材。

## 良い点

**道具が一晩で4回壊れる過程を、そのまま本文にしている。** 1-2 で「宗教／文化」の2列から始め、トルコの事例で国家列を足し（181行目）、名誉殺人で「一事例が一箱」という前提自体を捨てて透明シート方式へ移り（198–203行目）、イスラム金融で法学の層を足し（213–222行目）、最後に信仰と実践を割って5層になる（229–243行目）。「道具は、正解を思いついた回数じゃなくて、壊れた回数の分だけ丈夫になる」（280行目）が空疎でない、再発見型の見本となる節。

**5層ボードが説明装置で終わらず、介入設計の道具へ転用される。** 7-2 末尾で宗派化を止める政策を層ごとに割り当て（2021–2025行目）、「宗教対話をしても警察が偏っていれば恐怖は消えない」（2031行目）と、モデルが不足箇所の検出器に変わる。導入した枠組みを終盤で別用途に使い直す設計は強い。

**鏡が自分の社会に返ってくる。** 日本文化を禁止事項だけで記述させて「監視と禁忌に満ちた息苦しい民族」を作らせ（42–48行目）、5-1 では「無宗教」を自称するやる夫に初詣の手順を列挙させて全部宗教行為だと気づかせる（1121–1123行目）。5-2 の「憲法上の自由を行使しますと言うか」→「翌日の空気が怖いお」（1267–1271行目）まで一貫する。

**やる夫の一般化を、教師でなく実務資料が壊す。** 「日本人は世間を見て、ムスリムは神を見る」パネルの直後、窓口記録の最多相談理由が「親族に何と言われるか」だった（1205–1212行目）。8-1 では交流会の質問票6人分の自由記述が、はい・いいえ2択を溶かす（2082–2099行目）。

**9-1 の6案件が、手続き設計の失敗として一撃で決まる。** イマームへ丸投げした6件のうち3件が「家庭の判断」として市へ戻り（2404–2406行目）、6件目に至っては当のイマーム自身が申請者だった（2421–2424行目）。「審判に判定を頼んだら、選手が出てきた」は本書で最良の一行で、しかも人でなく設計を責めている。

**参考文献が本文対応つきで10点。** 各注に対応節を明記し（2701–2719行目）、Pew 調査には「調査結果は2011年前後の態度を中心とし、現在の全ムスリムを固定的に代表するものではない」（2717行目）と限界まで書いている。

## 欠点

**期限が名目だけで、何も切らせていない。** 「明日の部長会議」（23行目）、「6時間だお」（2014行目）と時計は回るが、時間切れゆえに何かを諦める、間に合わせに不正確な資料を出すといった圧力が一度も発生せず、78ページの資料が全部そのまま生き残る（2329行目）。締切が判断を歪める力を持っていない。

**列挙が導出なしにやる夫の口から出る箇所が多い。** 2-2 の「厳しさの4因子」（571–583行目）は「4つに分けてみろ」の一言で完成形が出る。6-2 の紛争分解レンズ8枚（1591–1601行目）も同様。1-2 のような作って壊す往復がなく、正解の目次を読み上げるに近い節が幕ごとに1つは混じる。

**振り子が型として見え透いている。** 「三大宗教は兄弟」ポスター（1402–1404行目）、「全員選挙で仲良く」（1799–1800行目）、「宗教は無実」（1876–1880行目）。やらない夫自身が「片方の単純化から反対の単純化へ」と2度指摘しており（1407行目、1883行目）、自覚を書いても反復は解消せず、中盤以降は次の失敗の形が予測できる。

**第3層を背骨にする教材なのに、法学の中身が空欄に近い。** 908行目で4法学派の名が並ぶが、結論がどう違うかの実例が最後まで一つも出ない。ハディースの真正性も「どれが信頼できるか判定が要る」（430行目）で止まり、伝承経路の検証に触れない。歴史上の事件はカルバラー（901行目）がほぼ唯一。

**制度カードA〜Eの正体が明かされない。** 1696–1709行目の5件は本書で最も鮮やかな仕掛けだが、国名は伏せたまま終わる。7-1 の6分類へ写像した時点（1756–1762行目）が開示の好機だった。

**「一本の物差しに並ばない」が3回繰り返される。** 4-2 の多軸記述（1021–1024行目）、8-1 の6人（2104–2109行目）、8-2 の4カード（2254–2260行目）が同じ構造・同じ結論に達し、8-2 のカードDの切れ味が減衰している。

## 改善案

1. **締切に実害を持たせる。** 9-1 冒頭（2360–2367行目）で6件のうち水泳授業と運動会に「今週中」の期限を付け、やる夫が全件へ5層分析を回す時間を奪う。2件を先に処理し残りを保留する判断を迫れば、9-1 の「市民配慮6段階」（2478–2486行目）が机上の手順でなく時間予算の中で回る手順として検証される。

2. **制度カードA〜Eを開示する。** 1762行目の直後にできる子の一行で対応国を明かし、同時に「同じ国でも時期により当てはまる形が変わる」と添える。伏せたまま終わるのは仕掛けの取りこぼし。

3. **法学派の差を一件だけ具体化する。** 2-1 の 486行目（リバーの適用範囲）か 9-1 の給食（2438–2441行目）に、同一問題への2学派の異なる結論を1往復で入れる。「学派が複数ある」は既に4回書かれているのに、読者は一度も違いを見ていない。

4. **2-2 の4因子を、作って壊す形へ変える。** 568行目の前に、やる夫が「権威／慣習」の2因子で説明を試み、628行目の反例（同じ法学説の2国で警察が動くか否か）を先に提示して2因子では説明できないことを示す。それを受けて第3・第4因子を足させれば、1-2 と同じ型に揃う。

5. **8-1 と 8-2 の重複を圧縮する。** 8-1 の「信仰心の順に並べ替える」試み（2102–2109行目）を削り、並ばない体験は8-2 の4カードに集約する。同じ驚きを2回使わないほうがカードDが立つ。

6. **できる夫に別の機能を与える。** 現状の登場3回（737–743行目、1447–1451行目、2678–2683行目）はすべて「派手な語を持ってきて叱られる」同一パターン。1回を予算や他部署の圧力を持ち込む役に転じ、9-1 の「市行事での説教」（2401–2402行目）で推進側に回らせれば、市の内部対立として立ち上がる。
