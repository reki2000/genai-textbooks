# 改稿記録

`review-opus-medium.md` の6つの改善案に沿って改稿した。全9幕の構成、5層ボード、出典ラベル、制度カードA〜E、6件の相談案件という骨格は維持し、指摘のあった「導出のない列挙」「機能しない締切」「使い捨てのできる夫」を作り直した。

## 主な変更

- **9-1 の締切に実害を持たせた。** 6件のうち水泳授業を明後日、運動会を今週末に置き、残り4件は来月以降とした。市民配慮6段階を提示した直後に、やらない夫が「明後日へ間に合わせろ」と要求する。やる夫は段階4（代替手段）で長袖水着の取り寄せに1週間かかること、段階5（一般制度化）が来年度の指導計画からしか動かせないことに突き当たり、手順が揃うのを待てば当日は無配慮で終わると気づく。結論は暫定決定＋期日つきの宿題＋保留3件への回答予定日の先出しで、6段階は「全部終わらせる条件」ではなく「どこまで終わったかを記録する欄」へ意味が変わる。急ぐ案件を選ぶこと自体を手順に含めた。
- **制度カードA〜Eを開示した。** 7-1 で6分類へ写像した直後、できる子がサウジアラビア／イラン／レバノン／トルコ／チュニジア（2011年以降の一時期）と明かす。同時に「いずれも時期を切って見た形」「Eはその後の制度変更で同じ記述が使えなくなった例」と限界を添えた。やる夫が「国名を先に見ていたらサウジとイランを同じ棚に入れていた」と自分の誤りを確認し、資料には国名と形の両方を、いつ時点かとセットで書くという実務判断へ落とした。
- **法学派の差を給食で一件具体化した。** 9-1 で「第3層を具体的に言え。献立表のどの一行で学説の差が出る」と問われ、やる夫が答えられないところから、できる子が海のものの扱い（シャーフィイー派・マーリキー派の広い許容と、ハナフィー派の魚類限定）を出す。該当行は来月のエビフライ。これにより「厳しい家庭」という記録の書き方が「避けたい材料」へ変わる。学派名の羅列だけで中身を見せない状態を解消し、同時に窓口記録の設計へ接続した。
- **2-2 の4因子を、作って壊す形へ組み替えた。** やる夫はまず「神の権威」「法学的継承」の2因子で足りると宣言する。やらない夫が、同じ学説を採る2国で私人の良心と警察取り締まりに分かれる例（旧版では節末に置かれていた検査）を先に出し、2因子が説明できないことを示す。やる夫が「誰が施行するか」に気づいて第3因子（近代国家の強制）を足し、続いて国家が施行していない少数派環境での規則強調という反例で第4因子（共同体の境界）を足す。1-2 の道具が壊れて丈夫になる型に揃えた。節末の検査は、同じ2国の法文比較で何を見落とすかという別の問いへ差し替え、反例の重複を消した。
- **8-1 の「信仰心の順に並べ替える」試みを削除した。** 並ばない体験は 8-2 の4カードへ集約し、8-1 では「いいえと答えた4人を資料で何と呼ぶつもりだったか」という問いに変えた。通勤時間、職場の設備、医師の指示、家の習慣という別々の理由が「いいえ」の1文字へ潰れることを示し、質問票が答えを集めるのでなく潰す道具だったという結論に着地させた。8-2 のカードDの切れ味を確保するため、同じ驚きの二度使いをやめた。
- **できる夫を市の内部圧力役へ転じた。** 3-1 のブロックチェーンのギャグ（登場と叱責の一往復）を削除し、代わりにやらない夫の「エンジニアらしい比喩になったな」を受けて、比喩は調べ始める入口にはなるが調べ終わった印にはならない、という往復へ置き換えた。削除したギャグの振り（「できる夫が持ってきそうだから削除するお」）も併せて消し、やらない夫の直前・直後の台詞と噛み合うようにした。できる夫はその分、9-1 の「市行事での説教」で企画課の協賛金と市長公約の評価指標を持ち込む推進側に回る。やる夫は「協賛金の最大拠出先だから」と決定通知に書けないことに気づき、団体単位の判断を条件を先に決めた一般枠へ移す。やらない夫が「配慮の量を寄付の額で決める制度は、寄付できない住民から先に配慮を奪う」と締め、6件目だけが本人の困りごとでなく団体の要求だったという分解へつなげた。

## 残した判断

- 9-2 末尾のできる夫（5層分散型イスラム理解アーキテクチャ）は、3-1 のギャグを削って登場の型を崩したため、最後の一撃として残した。
- 8-2 の4カードと 4-2 の多軸記述はいずれも「一本の物差しに並ばない」に着地するが、対象（個人の政治意見／運動と思想の分類）が異なるため両方残した。圧縮したのは 8-1 の重複のみ。
- ハディースの伝承経路の検証、カルバラー以外の歴史事件は、5層モデルと窓口手順という本筋を太らせすぎるため追加していない。法学の中身は給食の一件を実例として入れる形に絞った。
- lint は error 0件。9-1 の「18実効往復超」と長大発言の warning は、6件の案件処理と締切下の判断という節の性格上そのままとし、できる夫の応答1つと給食の台詞を圧縮して増分を抑えるにとどめた。
