# 改稿記録

`review-opus-medium.md` の6つの改善案をすべて反映した。第1〜4幕の「暴走→数字で潰される→自分で気づく」の三拍子はそのまま残し、第5幕でその型が壊れていた点と、物語的な圧力の不在を中心に直した。

## 主な変更

- **第5幕に失敗を一つ実装した（5-3）。** 「一年で10万人へ届く話が来たら挑むか」を仮定でなく実際の依頼に変えた。登録者12万人のチャンネルから「初心者向け解説を毎日1本、3か月」という条件が来て、やる夫が飛びつき、一週間後にベンチへ戻ってくる。7本で撮影1時間・編集2時間半・題名とサムネ30分、毎日4時間、睡眠4時間、再生はのべ780回で7本目は62回。そのうち名前を知っている相手は5人×7＝35回で、4-5で数えたギルドの5人。3日前の新人の質問に気づかず、別の古参が「最近やる夫さん忙しそうだから」と答えていた。この実物から「払わない上限」を引かせ、宣言だった睡眠・近い人との約束・内容の嘘が、それぞれ7日目の書き出しミス、1週間で壊れた信頼、5日目に題名へ「絶対」と書きたくなった衝動という具体的な出来事に接続された。最後は「大きい称賛が要らないから断るのではなく、この値段では買えないから断る」で締め、量への欲は残したままにした。
- **5-1を家計の実数で潰した。** 「値札という概念を廃止する」の直後に、できる夫の手取り20万円を基準に家賃6万・光熱通信1万5千・食費3万5千・交通日用品1万を引かせ、残り8万円を自分で計算させた。そこへ本1万円、旅行30万÷12＝2万5千円、車300万÷60＝5万円を並べさせて8万5千円。家電も備えも進学もまだ1円も置いていない状態で、すでに足りない。不足分を払う「未来のやる夫」が1-1の生存者バイアスと同じ形（落ちた未来は計算に出てこない）だと本人に言わせ、そこから「遅らせられる欲と、遅らせると人生が細くなる欲」の区別へ進めた。
- **田中をできる夫に置き換え、人物をやる夫に語らせた。** 全37箇所を機械的に改名したうえで、3-3の初出でやらない夫が「どういう男だ」と聞き、やる夫が隣の席、テストだけ上にいる、部活でもないのに部の連中と帰る、去年入社して今年マンション、親は自分と同じ団地の3階、と語る。最後の一行が三日分の理由だとやらない夫が指摘し、「出発点が近い」という比較の条件を、教師の解説でなくやる夫自身の説明から取り出す形へ変えた。登場人物欄にも「本編には一度も現れず、やる夫の口からだけ語られる」として追加した。
- **第1幕に期限を置き、第5幕と終幕で回収した。** 1-1に父親の「今年度いっぱい」＝あと11か月を置いた。5-6の3年の仮契約は「最初の期限は自分で決めたものではない。11か月で生活費を入れられなければ、3年の契約はそもそも始まらない。床が先で賭けが後」と接続。終幕では「親父の期限は来年3月、まだ5か月あるが先月から生活費を入れている。家を出ろとは言われなくなった。夕食は2人分のままだ」とし、4-5で数えた母の夕食2人分を回収した。
- **4-5の生存率の記述を修正した。** 「生き延びる確率がおよそ1.5倍」を「生存する**オッズ**がおよそ1.5倍」に改め、やる夫に「オッズって、確率とは違うのかお」と言わせて、1-2の逆確率の議論とつないだ。あわせて観察研究であり因果の向きを決めないこと（健康な人ほど人と会いやすい可能性）をやる夫自身に言わせ、それでも無視できる大きさではないという着地に変えた。脚注[^27]も、オッズ比1.50であること、確率1.5倍ではないこと、因果を確定しないことを明記する形へ書き換えた。
- **6-1を圧縮し、6-3を厚くした。** 6-1の5候補は各3行に圧縮し、内容は5-1の計算結果と5-3の7日間を参照する形にして再要約を避けた。末尾に「一つも捨てなかったな」「捨てる必要が無かった。置き場所が無かっただけ」の短い応酬を足した。6-3では、やらない夫の「分からん」の後に、やる夫が反転可能性テストの削除を宣言する往復を追加。やらない夫が「削除する前に3-6のお前を残り二つで採点しろ」と要求し、自分を唯一撃った部品から先に外そうとしていたことに気づいて撤回する。

## 残した判断

- 5-3の失敗の相手はギルドの5人にした。レビューは「公民館の約束」と書いているが、公民館の話は第7幕で初めて出るため、時系列上ここでは成立しない。4-5で数えた5人を壊す形にすることで、有意味感の章との接続も強くなる。
- 6-1の「4実効往復未満」warning は、圧縮の結果として往復数が減ったもの。ここは配分作業の実行であり、同じ内容を往復で薄めるより短くする判断を優先した。
- lint は error 0件。残る warning は長大発言の診断で、いずれも配分の列挙や終幕の報告にあたるため分割していない。
