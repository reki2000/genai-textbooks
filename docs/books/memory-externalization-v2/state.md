# 執筆状態台帳

## 制約

- 新規長編。対象は、個人メモから組織の手順・検索システムまでを設計したい初学者。
- 前提知識は四則演算と、一般的なファイル検索の経験まで。
- 到達点は、保存量と利用可能性を分け、表現・索引・検索・版・技能・責任を一つの運用として設計できること。
- 市民天文台の一夜だけで全幕をつなぐ。現実の望遠鏡を無資格者が独断操作することは勧めない。
- 保存先は `docs/books/memory-externalization-v2/README.md`。アウトラインと plot-memo を正本とする。

## 固定設定

- 彗星の公開観望は23時47分。望遠鏡は旧型 `AZ-4` から現行 `AZ-5` へ交換済み。
- カードIDは `OBS-RED-017`。内容を上書きせず K-0〜K-7 を版として残す。
- 七段ゲートは存在、発見、同定、理解、信頼、実行、更新。
- 三判定者は未来の本人、初参加者、検索機械。
- 反復資料は一万枚の写真、赤色灯、`heavy.wav`、壁の矢印、レンズキャップ写真。
