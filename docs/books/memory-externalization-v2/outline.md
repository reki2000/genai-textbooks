# やる夫が天文台の記憶を一晩で引き継ぐようです ── 「赤い星を追うな」から外部知識を作る の新アウトライン

## 再設計の方針

旧版のブックマーク墓場を捨て、市民天文台で引退者の知識を引き継ぎ、23時47分の彗星観望会を成功させる一夜へ置き換える。一枚の曖昧なカード「赤い星を追うな」を、保存、発見、解釈、検証、実行、更新、責任の七条件で八回書き直す。個人ノート術に閉じず、認知的オフローディング、分散認知、情報検索、RAG、版管理、暗黙知、チェックリストを同じ観測業務で接続する。

## 第1幕　一万枚の写真と、一枚の役に立たないカード

- やる夫が操作盤、棚、画面を一万枚撮影して引継ぎ完了を宣言し、望遠鏡の起動順を一枚も見つけられない。
- 「保存した」と「必要な時に使える」を、10分探索、誤った旧画面、似た配線写真で分ける。
- カードK-0「赤い星を追うな」が見つかるが、対象、条件、理由、時点、行動が不明で役に立たない。
- 外部記憶の成功を、存在、発見、同定、理解、信頼、実行、更新の七段で定義する。
- 彗星までの作業を、望遠鏡起動、導入、追尾、ドーム、観客対応、異常時停止へ分ける。

## 第2幕　頭から出すと、考えなくなるのか

- 全部外へ置けば頭を空にできる案を、検索語を作れない、品質を判断できない、例外に気づけない反例で壊す。
- 認知的オフローディング、作業記憶、検索手掛かり、生成効果、想起練習を、観測手順の覚え方で比較する。
- 地図を持つと道を覚えない場合と、地図がなければ到達不能な場合を分け、置換と拡張を区別する。
- 「誰が何を知っているか」を覚えるトランザクティブ・メモリーを、整備、観測、受付の三人チームで導く。
- 頭、紙、道具、他人、手続きへ何を置くかの初期分担を作り、K-1へ検索語と担当を足す。

## 第3幕　説明書、チェックリスト、地図は同じではない

- 400ページの望遠鏡説明書を起動時に先頭から読み、彗星へ間に合わない。
- 原理説明、標準手順、チェックリスト、判断表、トラブルシュート、地図、ログ、原文証拠を用途で分ける。
- レシピの順序、路線図の接続、星図の座標、障害ログの時系列を入れ替え、何が壊れるか検算する。
- 一枚一概念へ細分化しすぎると手順の流れが切れ、巨大文書だと一点アクセスが死ぬ。粒度を利用単位で決める。
- K-2を、平常時の判断表と異常時の停止手順へ分けるが、出所がまだない。

## 第4幕　名前、住所、リンク、出所

- 「赤い星」「追う」「望遠鏡」の語が多義的で、全文検索が大量ノイズを返す。
- 一意ID、階層座標、タグ、索引、同義語辞書、相互参照を、探し方の異なる三人で比較する。
- コピーを各フォルダへ置いて更新がずれ、正本一つと複数入口へ修正する。
- 「なぜこの手順か」が切れ、操作カードから事故記録、機器仕様、判断者へ根拠リンクを張る。
- 出典、作成者、確認者、観測時点、適用機種、確信度を付け、K-3を監査可能にする。
- 幕末の「カード帰還試験(1)」で、未来の自分、初参加者、検索機械がK-3を見つけられるか測る。

## 第5幕　検索機械は「似ている逆」を拾う

- 語検索で「赤い星」が多すぎ、ベクトル検索で「赤い対象を自動追尾せよ」という逆の手順が上位に来る。
- 適合率と再現率、同義語と多義語、文書ベクトルと余弦類似度を小さな語頻度表で計算する。
- 否定、数値条件、機種、時点、例外に弱い類似検索を、構造化条件と後段検証で補う。
- 知識グラフへ全部形式化する案を、入力費、更新、暗黙条件で壊し、閉じた高反復領域だけへ使う。
- RAGを検索、根拠提示、生成、検証へ分け、答えが自然でも根拠が別機種なら不合格にする。
- K-4を散文、表、規則、リンクの複数表現へし、機械が使う範囲と人が判断する境界を明記する。

## 第6幕　正しかったカードが、今夜だけ嘘になる

- K-4が昨年の機種交換前には正しく、現在の望遠鏡では追尾方向が逆だと判明する。
- 上書き更新で過去判断が消える案と、旧版を残して混ぜる案を両方壊す。
- 有効時点、記録時点、版、状態、適用範囲、廃止理由を持つ主張へ変える。
- リンク切れ、利用頻度、法的・安全上の保存、再現性を基準に保存・移行・廃棄を分ける。
- 更新所有者不在で全カードが静かに古びるため、レビュー契機、期限、異常報告からの更新路を作る。
- K-5では「赤い星」が恒星色でなく旧制御盤の赤色警告ランプを指すと分かるが、体で覚えた微調整が残る。

## 第7幕　書けない手触りをどう渡す

- ベテランの「音が少し重い」を文章へ完全変換しようとして、録音も数値も条件依存で失敗する。
- 宣言知、手続き知、知覚技能、例外判断、責任・権限を分け、文書化可能性を一つにしない。
- 実演、模倣、シミュレーション、段階的実地、ペア作業、事後レビューを外部記憶系の一部にする。
- チェックリストを長文化して思考を止める反例と、重要停止条件だけを短くする合格例を比較する。
- 誰でも更新できるwikiを、出典、レビュー、差分、異議、エスカレーションの手続きで支える。
- K-6を、読めば終わるカードでなく、音サンプル、練習課題、停止権限、連絡先へ接続する。

## 第8幕　23時47分のカード帰還試験

- 彗星導入直前に赤色警告ランプが点灯し、K-6の条件が実際に成立する。
- やる夫は全文検索やベテランへの電話へ逃げず、ID、現行版、根拠、停止条件、実演で得た音の違いを順に使う。
- 原因は追尾軸の負荷で、停止、再バランス、低速導入、再検算を既知手順で行う。
- 初参加者、未来のやる夫、検索機械の三者がK-7を使い、同じ条件で同じ停止判断へ届く。
- 一万枚の写真を全削除せず原文アーカイブへ移し、現行手順への入口、保持期限、所有者を付ける。

## 終幕　覚えていないから、思い出せる

- 観望会後、子どもが「全部覚えたの」と尋ね、やる夫は覚えた内容より、どこを疑い誰と確かめるかを答える。
- 引退した観測員からK-0の裏面が届き、「赤い星」は古い盤の警告灯だったと確認されるが、K-7はその一文だけに依存していない。
- レンズキャップの写真だけが一万枚中83枚あると分かり、やる夫が次の観測ログへ「撮影前確認」を追加して閉じる。

## 依存と検算

- K-0〜K-7は同じcard_idを持ち、内容を上書きせず版として並べる。
- 七条件は第1幕で未完成の問いとして設置し、第4〜7幕で一つずつ満たし、第8幕で三者判定する。
- 「赤い星」の多義性は第1幕の謎、第4幕の検索、第5幕の似ている逆、第6幕の機種変更、終幕の手紙で回収する。
- 写真一万枚は第1幕の墓、第4幕の正本問題、第8幕のアーカイブ、終幕のレンズキャップへ戻る。
- 外部化で内部知識不要という案は第2幕で壊し、第5幕の検索語・品質判定、第7幕の技能、第8幕の停止判断で再検算する。
- 第8幕は新概念を加えず、K-6までに作った道具のみで処理する。
