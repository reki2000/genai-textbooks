# やる夫が天文台の記憶を一晩で引き継ぐようです ── 「赤い星を追うな」から外部知識を作る

---
## 登場人物

**やる夫** ── 移動プラネタリウムを営む科学解説者。今夜の公開会を天文台と共同主催する。

**やらない夫** ── 天文台が保守を委託する共同工房の望遠鏡技術者。

**できる子** ── 大学天文部の学生リーダー。今夜の公開観望会を手伝う初参加者。

**できる夫** ── 市役所の検索システム担当。天文台の文書検索を試験運用している。

**OBS-RED-017** ── 「赤い星を追うな」とだけ書かれた操作カード。書き直すたび、K-0から版番号が増える。

**七段ゲート** ── 存在、発見、同定、理解、信頼、実行、更新。通れない段には赤い磁石を置く。

### 1-1　完全な暗黒観測 ── 保存量

〜〜 18時02分　市民天文台・主観測室 〜〜

**やる夫**：
撮ったお！
操作盤の正面、右、左、斜め上、念のため床も撮ったお！
これで引継ぎは完全だお！！

**やらない夫**：
その黒い写真は何だ。

**やる夫**：
宇宙の深淵だお。

**やらない夫**：
レンズキャップだろ。

**やる夫**：
ぐぬぬ……だが一万枚あるお。
九千九百九十九枚が働けば勝ちだお。

**やらない夫**：
では23時47分の彗星に向けて、現行望遠鏡の起動前点検を始めよう。
最初に何を確認する。

**やる夫**：
写真を見れば分かるお。
検索窓に「起動前」と……該当なし。
「電源」は六百十二枚、「最初」は九十八枚、`IMG_` は一万枚だお。

**やらない夫**：
撮った本人なら、どの辺りか思い出せるんじゃないか。

**やる夫**：
昨日撮った操作盤は七千枚目くらい……いや、配線棚を先に撮ったかお？
サムネイルが全部、灰色の操作パネルと黒い配線だお。
宇宙より識別しづらいお。

**やらない夫**：
一万枚あることと、今使えることは同じか。

**やる夫**：
……違うお。
**保存量は、利用できる知識の量じゃない**お。
存在しても、必要な一枚へ着けなければ、今夜のやる夫には無いのと同じだお。

**やらない夫**：
最初の磁石を置け。

**やる夫**：
七段ゲートの「存在」は青だお。
一万枚とも、ありはするお。
でも「発見」に赤磁石だお。

**やらない夫**：
捨てるのは後だ。
まず一万枚に何ができて、何ができないかを見誤るな。

**やる夫**：
写真は証拠の原料にはなるお。
でも、入口も順序も説明もない写真の山は、手順の代わりにはならないお。

**やらない夫**：
念のため、保存量が役立つ場面も言え。

**やる夫**：
装置の傷がいつ増えたか比べる、配線の昔の位置を確かめる、消えた銘板を読む、という問いなら写真が役立つお。
未来の問いを全部予測できないから、元の資料を残す価値もあるお。

**やらない夫**：
なら一万枚という数そのものが悪か。

**やる夫**：
違うお。
保存した物へ、撮影時刻、対象、撮影者、前後の作業を結び付けなかった設計が悪いお。
量を減らすだけでは、残った百枚が同じ墓になるお。

**やらない夫**：
試しに三枚だけ説明してみろ。

**やる夫**：
一枚目は操作盤……たぶんだお。
二枚目は配線棚……似た棚が三つあるお。
三枚目は真っ黒……これはレンズキャップだと自信を持って同定できるお！

**やらない夫**：
唯一の高確信が失敗写真か。

**やる夫**：
笑えないお。
でも失敗写真にも、撮影前確認が欠けていた証拠という別の用途があるお。
資料の価値は、撮った時の目的だけで固定されないお。

**やらない夫**：
では今の段階で、削除の判断が早い理由は。

**やる夫**：
どの問いに使えるか、他の記録とどうつながるか、再取得できるかをまだ調べてないからだお。
使えない山と決めつける前に、現行手順の入口と原文証拠を分けるお。

**やる夫**：

**やらない夫**：

**やる夫**：

**やらない夫**：

**やる夫**：
やる夫の記憶も怪しいけど、それだけじゃないお。

同じ棚から「受付の雨天対応」を探せ。

**やる夫**：
「雨」で十二件、「中止」で五件、「曇天」で八件だお。

**やらない夫**：
対象は違っても病気は同じか。

**やる夫**：
同じだお。
作った人の語と、困って探す人の語が違うお。
しかも候補へ着いてから、今日の天候と観望会へ当てはまるか同定し直す必要があるお。

**やらない夫**：

**やる夫**：
部分成功だお。
存在場所まで着いたけど、対象と条件を確定できないお。
七段を一つの合否に潰すと、どこを直すべきか見えなくなるお。

**やらない夫**：
その紙を壁へ貼れ。

**やる夫**：

### 1-3　七つの止まり木 ── 利用可能性

**やる夫**：
この一文を太字にして、赤枠で囲めば記憶に残るお。
フォントを三倍にすれば事故も三分の一だお！

**やらない夫**：
そんなわけねぇだろ、常考。
誰が、いつ、何を見て、どう動く文なんだ。

**やる夫**：
それが分からないから目立たせるんだお。

**やらない夫**：
では判定してもらおう。
そのカードは存在するか。

**やる夫**：
するお。壁に貼ったお。

**やらない夫**：
5分後、別室から見つけられるか。

**やる夫**：
部屋を知らなければ無理だお。

**やらない夫**：
見つけた紙が、自分の扱う機器のものだと同定できるか。

**やる夫**：
機種名も部品名もないから無理だお。

**やらない夫**：
意味を理解できるか。

**やる夫**：
「赤い星」と「追う」が曖昧だお。

**やらない夫**：
内容を信頼できるか。

**やる夫**：
作成者、理由、日付がないお。

**やらない夫**：
正しく実行できるか。

**やる夫**：
何をやめて、代わりにどうするかがないお。

**やらない夫**：
装置が変わった後、更新できるか。

**やる夫**：
持ち主も正本もないお。
……一文が短いことと、使いやすいことは別だお。

**やらない夫**：
今の七問を壁に並べろ。

**やる夫**：
存在、発見、同定、理解、信頼、実行、更新。
K-0は存在だけ青で、残り六つは赤磁石だお。

**やらない夫**：
外へ置いた記憶が働くには、保存後の道のりがある。

**やる夫**：
じゃあ外部記憶の成功は、保存したかどうかの一発判定じゃないお。
**必要な人が、必要な場面で、七段を最後まで通れること**だお。
今夜、K-0を七段の先まで運ぶお。

**やらない夫**：
七段の順序は常に一方通行か。

**やる夫**：
発見してから同定し、理解してから信頼するのが基本だお。
でも根拠を見て理解を修正したり、実行結果から更新へ戻ったりするお。
門は検査項目であって、二度と戻れない一本道じゃないお。

**やらない夫**：
一つ例を作れ。

**やる夫**：
傘立てに「赤い傘を持つな」と書くお。
紙は存在して見つかっても、赤い傘が誰の物か同定できないお。
自分の傘だと分かっても、持出禁止なのか、忘れ物だから受付へ運べという意味なのか理解できないお。

**やらない夫**：
続けろ。

**やる夫**：
意味が分かっても、誰が書いたか不明なら信頼できないお。
信頼できても、代わりの傘や連絡先がなければ行動できないお。
持ち主が変わったのに札が残れば更新で失敗するお。

**やらない夫**：
天文台固有の話ではないな。

**やる夫**：
メモ、規程、地図、検索回答、どれも七段のどこかで止まるお。
「読めた」だけで使えたと思わないための診断器になるお。

**やらない夫**：
K-0の赤磁石を数えろ。

**やる夫**：
六個だお。
赤磁石ゼロを目指すけど、分からない門を青く塗る不正はしないお。

### 1-4　彗星を六つに割る ── 仕事の単位

彗星を見せるお。

それで手順を書けるか。

**やる夫**：
「彗星を見せる。以上」なら一行だお。
やる夫、もう完成したお！

来場者が着いた時、ドームは閉じたまま、望遠鏡は待機中、空には薄雲がある。

**やる夫**：
ええと、望遠鏡を起動するお。
彗星の座標へ導入するお。
動きに合わせて追尾するお。

**やらない夫**：
誰が全部やる。

**やる夫**：
やる夫が六本腕になれば……。

**やらない夫**：
観望会まで5時間45分だ。進化は間に合わん。

**やる夫**：
作業を、起動、導入、追尾、ドーム、観客対応、異常時停止の六つに分けるお。

**やらない夫**：

**やらない夫**：
K-0はどうする。

まだ書き換えないお。
意味の分からない警告を、想像で完成させたら危ないお。

**やらない夫**：
六作業の依存を、時刻順だけで並べてみろ。

**やる夫**：
起動、ドーム、導入、追尾、観客対応、停止……いや、停止は最後だけじゃないお。
どの段階にも割り込むお。

**やらない夫**：
観客対応は開始後だけか。

**やる夫**：
入場前の注意、機器確認中の説明、観望中の誘導、終了案内まで続くお。
一本の時系列に押し込むと、並行する仕事と割込みを表せないお。

**やらない夫**：
誰へ何を渡す。

**やる夫**：

**やらない夫**：
引継ぎ資料は作業の百科事典か。

**やる夫**：
百科事典だけじゃないお。

**やらない夫**：
一万枚の写真は、どの受け渡しをしていた。

**やる夫**：
何もしてないお。
撮った本人の頭の中に「なぜ撮ったか」を置き去りにしたお。

### 2-1　空っぽの頭、満杯の棚 ── 認知的オフローディング

〜〜 18時42分　天文台・会議卓 〜〜

**やる夫**：
七段も六作業も全部カードへ書くお。
頭を完全に空にすれば疲れないお。
脳内空室を月極で貸して大儲けだお！

**やらない夫**：
では、この操作卓にある五つの無記名キーを使え。
割り当ては、停止、導入、受付、飲み物、清掃だが、今は表示が消えて順番も入れ替わっている。
「赤い警告が出た時に要るキー」を押せ。

**やる夫**：
ラベルが見えないなら検索語を作れないお。
全部を押すしかないお。

**やらない夫**：
カードを読んで「これは今の警告だ」と判断するのは誰だ。

**やる夫**：
やる夫の頭だお。

**やらない夫**：
例外の音に気づくのは。

**やる夫**：
それも頭だお。
……外へ全部置くには、外の情報を選ぶための中身が要るお。

**やらない夫**：
頭の中で保持したり計算したりする短期的な場を、作業記憶（working memory）という。
その負担を、紙、端末、配置、他人へ逃がす行為が認知的オフローディング（cognitive offloading）だ。

**やる夫**：
じゃあ外部化は、脳を捨てることじゃないお。
今ここで保持しなくていい物を外へ出して、判断へ空きを回すことだお。

**やらない夫**：
それが拡張になる場合も、能力の置換になる場合もある。
見分ける実験をしよう。

**やる夫**：
空室の又貸し計画は中止だお。
でも一部屋くらい空けたいお。

**やらない夫**：
この六桁の数字を覚えながら、受付用の短い説明を作れ。

**やる夫**：
`381742` だお。
説明は「今夜の彗星は……」ええと、数字が逃げるお。

**やらない夫**：
数字を紙へ書け。

**やる夫**：
書いたお。
「今夜の彗星は淡いため、順番に望遠鏡をのぞいてください」と考えられたお。

**やらない夫**：
外部化が拡張になったか。

**やる夫**：
数字の保持に使っていた作業記憶を、説明を考える方へ回せたお。
でも紙の数字が予約番号か警告コードかを判断する知識は、紙から生えないお。

**やらない夫**：
外へ出す費用はないか。

**やる夫**：
書く時間、持ち歩く手間、紛失、古い紙を見る危険があるお。
外部化は無料の追加脳じゃないお。

**やらない夫**：
何を基準に出す。

**やる夫**：
正確さが必要、頻繁に変わる、複数人で共有する、作業記憶を圧迫する物は外へ出す価値が高いお。
瞬時の違和感や意味判断は、外部資料と一緒に内部でも育てるお。

### 2-2　地図を見た者、着けない者 ── 置換と拡張

**やらない夫**：
観測室から倉庫までの構内図を見て歩け。
分岐は、左、右、右、階段下だ。

**やる夫**：
端末の矢印どおり……着いたお。
地図さえあれば道を覚える必要はないお。

**やらない夫**：
端末を伏せて戻れ。

**やる夫**：
右、左……あれ、資材室だお。
行きは到着できたのに、道順はほとんど残ってないお。

**やらない夫**：
地図が悪いか。

**やる夫**：
違うお。
目的が「一度着く」なら成功だお。
目的が「次は地図なしで往復する」なら、矢印を追うだけでは練習が足りないお。

**やらない夫**：
では地図なしで、初見の地下配管を全部覚えてから歩くべきか。

**やる夫**：
それも無茶だお。
地図がなければ到達すらできない複雑さなら、外部化は能力を広げるお。

**やらない夫**：
置換と拡張の境を、今夜の作業へ移せ。

**やる夫**：
彗星の座標、機器の型番、連絡先は、正確に外へ置いた方がいいお。
でも警告の意味を比べる力、止まるべき違和感、検索語を作る基礎は頭にも要るお。

**やらない夫**：
手順を外へ出したから、学習が不要になるわけではない。

**やる夫**：
外へ置く目的を先に決めるお。
「今だけ到着」なら置換でもよくて、「後で独力判断」なら内部の練習も組み合わせるお。

**やらない夫**：
同じ地図でも、使い方を変えて戻ってみろ。

**やる夫**：
分岐へ着く前に次の方向を予想して、地図で答え合わせするお。
帰り道では目印を一つずつ言うお。

**やらない夫**：
倉庫から会議卓へ戻れたか。

**やる夫**：
戻れたお。
一回だけでは断言できないけど、矢印を受動的に追うより、地図と内部の予想を往復できたお。

**やらない夫**：

**やる夫**：

### 5-2　完全に似た正反対 ── 文書ベクトルと余弦類似度

**できる夫**：

**やる夫**：

完全一致だお。

**やらない夫**：
候補B「赤い表示なら追尾するな」も、「赤」「追尾」だけ数えれば $(1,1)$ だ。

**やる夫**：

「せよ」と「するな」の差を軸から捨てたから、同じベクトルになったお。

**できる夫**：

**やる夫**：
ベクトル検索が嘘なんじゃないお。
似た話題を集める仕事には強いお。

**やらない夫**：

**やる夫**：
問いを $(1,1,1)$、候補Bを $(1,1,1)$ にすれば禁止文が近くなるお。
候補Aは $(1,1,0)$ だから少し遠ざかるお。

**やらない夫**：

**やる夫**：
「禁止」と「するな」が両方あって、単純な数え上げでは二重否定の意味を作れないお。

**できる夫**：
数値条件も試しましょう。

**やる夫**：
数字と比較向きを落としたら正反対だお。

**やらない夫**：

**やる夫**：
