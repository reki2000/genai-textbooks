## 主な変更

- **人物表にできる子とできる夫を追加した。** できる子＝運転指令所の実績集計担当（ストップウォッチと集計表を持ち、感想を言わず数値だけ置く）、できる夫＝設備・システムの提案担当（費用と実行可能性の見積もりが常に一桁ずれる）と明記した。
- **できる子を第2幕から登場させ、以後3回数値を出させた。**
  - 2-2の停車時間110秒を、やる夫の自己申告から40本の実測（中央値110秒、最大155秒、駆け込み発生12/40本）に変えた。「気合いで20秒」と言った翌日から毎朝ホームに立っている、という初登場にして、やる夫の見積もりが5倍以上ずれていたことを本人に言わせた。
  - 4-1では、先月1,240本の走行時分実測を出させた。ダイヤより速く走れた列車は11本・すべて20秒以内で、「最高速度を1割上げれば2分取り戻せる」が実測で潰れる。
  - 5-1では、予備2両編成の検査期限・保安装置の対応区間・最高速度85km/h（特急基準は95km/h前提）を出し、投入すれば所定より4分20秒延着することまで示した。「車庫にあって動いて検査も切れてないのに使えない」が数字で確定する。
  - これにより、第7幕でのできる子の反論（空の列車と満員列車を同じ価値で数えた）が唐突でなくなる。7-1の「いつからいたんだお」は、初登場ギャグから「また出たお。今度はどこで測ってたんだお」に変えて笑いを残した。
- **第9幕でやる夫に一度失敗させた。** 駅滞留対応で、まず「ホームの広い東町駅へ中央駅の乗客を集めて一括輸送する」案を出させた。できる子が東町の折返し能力（1時間4本×380人＝1,520人）と滞留2,700人から所要1時間47分を計算し、6-2で学んだ「制約を移動させただけ」を繰り返していることを突く。やらない夫の「6-2で何をやった」で自分で気づき、「ホームの広さは溜められる量であって捌ける量じゃない」「今回溜まっているのは列車ではなく人間で、人は待たせられない」と訂正して、乗客を移動させず駅の外の一時滞在施設へ逃がす判断に至る。「駅は輸送する場所で滞在する場所じゃない」という理由づけまで本人に言わせた。
- **金額を単位表記にした。** 800億円／8億円とし、「100年分の売上を『わずか』と呼ぶな」が暗算で確かめられるようにした。追加した数値もカンマ区切り（1,240本、1,800人、2,700人、1,520人）に統一した。

- **終幕の総括を1回に絞った。** 三層整理を各3行に圧縮したうえで、単なる再掲にならないよう「3層に分けた意味」を追加した——やる夫の失敗は毎回どこかの層を別の層で代用しようとしたことで、計画で吸収すべき変動を実行で頑張らせたのが第4幕、実行の判断を計画に戻そうとしたのが第6幕、評価指標が実行指標のままだったのが第7幕、という形で9幕を層の枠組みに写像した。未扱い論点は8つから2つ（保守作業計画と需要変動）に減らし、やる夫による9幕の再列挙は削除した。削除にあわせて、続く「失敗の種類が多かった」がやらない夫の締めの直後に来るよう接続を直した。

## 残した判断

- **ボケと真面目な誤りの混在は整理しなかった。** 「気合いで20秒」については、実測でできる子に潰させたことで学習ポイント側に寄った。残る「縦方向も活用するお」「乗客を積層するな」などは、やらない夫の即座の否定が笑いの受けとして機能しており、削るとテンポと銅像ギャグの土台まで痩せる。レビューもこの点には改善案を出していないため、指摘として記録するに留めた。
- 9-1は追記で21実効往復になり lint の warning が出るが、この幕は「安全確保→滞留→運行可否→情報提供」と論点が積み上がる構造で、核心概念が競合しているわけではない。内容を確認したうえで残した。
- lint は error 0件、warning 5件。いずれも長さに関する診断で、追加した実測データの列挙と終幕の三層整理が該当する。
