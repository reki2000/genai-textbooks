# 寸評：やる夫で学ぶ電磁気学 ── 見えない力から光を作る

約62KB／全7幕＋終幕。こすった下敷きが紙を吸う現象から出発し、電荷・電場・電流・磁場・誘導・変位電流を積み上げて、マクスウェル方程式から光速が出るところまで到達する。

## 良い点

**電場の導入が「計算をサボるための小細工」から出てくる。** 386–428行目。101個目の電荷を100種類試すには1万回の計算が要る→2回分の式を見比べると変わるのは $q$ だけ→$q$ を括り出す→残った量には $q$ がどこにも入っていない→「101個目をまだ置いていなくても、この量は各点で決まってしまうお」（425行目）。定義から入らず、手抜きの副産物として空間の量が現れる。教材中で最良の再発見。

**逆二乗が3次元空間の必然だと自分で気づく。** 486–507行目。電場が1/4、面積が4倍、掛けると $r$ が消える。しかも502行目で「逆三乗の法則だったらどうなっていた」と反実仮想を置き、507行目の「面積が $r^2$ で広がることと、力が $r^2$ で弱まることが、同じ事実の裏表」に到達する。

**変位電流の動機づけが正しい。** 1409–1426行目。同じ閉曲線に2つの面（導線を横切る面と、コンデンサの隙間を通る面）を張り、$\mu_0 I$ と $0$ という矛盾する答えが出ることをやる夫自身が言う。「何かを見落としている」（1429行目）から変位電流へ進むので、追加項が天下りにならない。

**積分形→微分形の移行を同じ型で2回やる。** 836–860行目で「閉曲面を縮める→体積で割る→各点の湧き出し密度」、1459–1469行目で「閉経路を縮める→面積で割る→各点の渦の密度」。852行目「$\oint$ が箱全体でいくらなら、$\nabla\cdot$ は各点でいくら」、1469行目「$\oint_C$ がループ一周でいくらなら、$\nabla\times$ は各点でどれだけ渦を巻くか」と対句で提示され、反復によって定着する。

**永久機関をマイナス符号で殺す運び。** 1152–1166行目。符号をプラスにした世界をやる夫に最後まで辿らせ、「外からエネルギーを与えたか」→「与えていない」→エネルギー保存が破れる、を本人に言わせてから測定で潰す。1186行目の「自然は変化を嫌うというより、変化を強める向きなら永久機関になるため」という説明は、擬人化を避けていて正確。

**第1幕の対照実験が具体的。** 風説をアクリル板で（76–87行目）、熱説を熱いマグカップで（97–98行目）潰す。128行目の「名前を知っていることと、仕組みを説明できることは違う」が、教材全体の姿勢を宣言している。

**参考文献6点がすべて書籍・原典。** Griffiths、Purcell、Feynman、Maxwell、Faraday、Jackson（1979–1989行目）。

## 欠点

**末尾に制作メモが残っている。** 1991行目「この初稿では直観と物語を優先しています。次の改稿では、ガウスの法則による具体的な電場計算、RC・RL回路、ポテンシャル、ベクトルポテンシャル、相対論的統一を増補できます。」──公開教材の本文に作業メモが混入している。他の教材にはない瑕疵で、無条件に除くべき。

**数を入れる場面が全編で1箇所しかない。** 1641–1642行目の $1/\sqrt{\mu_0\varepsilon_0}\approx3.00\times10^8$ だけ。クーロン力も、電池の電圧も、直線電流の磁場も、LC回路の共振周波数も、式を書いて終わる。同リポジトリの教材（熱力学のワッシャー段数、制御工学の倍化時間0.22秒）にある「数を入れて驚く」瞬間が、光速の一発を除いて存在しない。

**「通信機を作る」という目標が推進力になっていない。** 各幕の頭でやる夫が通信機に言及する（36・535・780・1232・1712行目）が、作られた装置の性能は一度も数値化されない。1-1の「3cm」（45行目）以降、到達距離の記録がないため、1895行目の「徒歩5秒に敗北」というオチが、比較対象を持たない。

**できる子の発言が測定器の表示そのものに縮んでいる。** 1068・1075・1081行目の「0」、810行目の「切った」、80行目の「透明なアクリル板」。単位も分解能もないため、4-1の「磁石を10個にしても0」（1078–1081行目）が「本当に検出限界以下なのか」を読者が判断できない。人物紹介（16行目）の「見落とした前提を指摘する」役割が、ほぼ果たされていない。

**できる夫が一度も登場しない。** 18–20行目の人物紹介に「今回はほとんど退場させられている」と書かれており、実際に全編で発言ゼロ。紹介文が不在の言い訳になっている。

**3-3のローレンツ力の暴走に動機がない。** 991行目の「磁場を強くすれば、電荷をどんどん加速して無限のエネルギーを得られるお」は、直前の外積の議論からの繋がりが薄く、次の発言で即座に否定される。第4幕の永久機関のような、やる夫が最後まで辿ってから潰される構造になっていない。

**第2幕の再発見の密度が低い。** 679行目の $V=IR$ はやる夫がいきなり書き、導出も反例もない。689行目でダイオードと電球の非線形性に触れるが、それは書いた後の但し書きになっている。

## 改善案

1. **1991行目の制作メモを削除する。** 増補計画を残したいなら `catalog.yml` か別ファイルへ移す。

2. **数を入れる場面を3つ作る。** (a) 1-3（491行目付近）で、こすった下敷きの電荷を $10^{-8}\,$C 程度と置き、3cm 先の紙片に働く力を計算して紙片の重量と比べさせる。45行目の「3cm」が数として生きる。(b) 2-1（546行目）の「100万倍の電荷」を実際に見積もらせ、火花放電の限界電圧から不可能だと自分で結論させる。(c) 7-2（1795行目）で、目標周波数を1MHzと決めて $L$ と $C$ を逆算させる。共振の式が設計に使われる。

3. **通信機の性能を幕ごとに記録する。** 45行目の3cmを起点に、各幕末で到達距離（と通信速度）を1行で記録し、終幕の1902行目の総括に並べる。距離の記録があって初めて、1895行目のオチが数字の落差として効く。

4. **できる子の測定に単位と分解能を与える。** 1068行目を「電流計、0.0 mA。分解能0.1 mA」のように書く。101行目の「ほとんど測定できない」も温度計の分解能を添える。4-1で磁石を10個に増やしても0であることの意味が変わる。

5. できる夫は登場人物から外す。

6. **3-3の暴走に動機を与える。** 1017–1024行目の円運動（加速器で使える）を991行目より前に移し、「加速器で粒子を加速できるなら、磁場だけでエネルギーを増やせるのでは」という形でやる夫に言わせる。$P = \mathbf{F}\cdot\mathbf{v} = 0$ で潰される流れは同じだが、誤りの出所が本人の前段の理解になる。

7. **2-2にオームの法則の反例を先置きする。** 679行目の前に、電球に電圧を変えながら電流を測る実験を置き、比例しないことをできる子に読ませる。そのうえで「金属線のように抵抗値がほぼ一定とみなせる素子では」と条件つきで $V=IR$ を書かせれば、689行目の但し書きが導出の一部になる。
