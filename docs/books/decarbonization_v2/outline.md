# やる夫が一斤のパンへ炭素の値札を付けるようです ── LOT-2050の48時間 の新アウトライン

## 再設計の方針

旧版の企業広報と幽霊の筋を捨て、スーパーから商品カーボンフットプリントを要求された町のパン屋と契約農家の48時間へ置き換える。窯を止めたくないパン屋やる夫と、肥料だけを悪者にされたくない小麦農家やらない夫は、発注側でも監督側でもない対等な取引相手として、看板食パンLOT-2050の仕込みを畑まで逆向きに歩く。1,000斤を単位に、温室効果の物理、CO2換算、組織境界、製品LCA、削減投資、再エネ、オフセット、主張、移行リスクを同じ黒いレシートへ累積する。

## 第1幕　緑のシールを貼ればゼロになる

- スーパーから48時間後までに根拠付き排出値を求められ、パン屋のやる夫が「カーボンニュートラル」シールを先に発注する。
- 小麦農家のやらない夫は、原料欄を業界平均で埋めれば自分の節肥努力が消え、実測すれば肥料排出だけが目立つという利害から共同計算を要求する。
- 前年値、境界、係数、削減策がない宣言を、残高不明のレシートにゼロと印字する矛盾で壊す。
- LOT-2050の小麦、酵母、水、窯、冷却、包装、配送、売れ残りを工程カードへ分ける。
- 活動量×排出係数の初期式を作り、一次データ、二次データ、推定、不明を色分けする。
- 黒い炭素レシートC-0を発行し、数字より先に境界と基準日を印字する。

## 第2幕　なぜ一斤の気体を量るのか

- 大気中のCO2が微量だから無視できる案を、放射吸収と地球のエネルギー収支で壊す。
- 排出フロー、濃度ストック、温度応答、累積炭素予算を、窯の投入と倉庫在庫の違いで導く。
- CO2、メタン、亜酸化窒素、冷媒を同じkgで足せず、時間軸を明記したCO2eへ変換する。
- 平均気温1.5℃を小さいと見る案を、分布の裾、熱波、収量、供給網の同時障害で壊す。
- 一斤の精密値だけで地球を救った気になる誤りを退け、製品値を意思決定の縮尺として限定する。

## 第3幕　工場の塀とパンのゆりかご

- Scope 1・2・3を組織の責任追跡、原料採取から廃棄までを製品ライフサイクルとして分ける。
- 工場門まで、店頭まで、廃棄までの境界で一斤値が変わることを三枚のレシートで示す。
- 小麦栽培の肥料、製粉歩留まり、酵母、包装、冷蔵、配送、家庭トーストを上流・下流へ遡る。
- 配分方法を重量、価格、エネルギーで変え、パンと副産物ふすまの負担が動く反例を置く。
- 平均電力係数と時刻別限界電源を混同せず、報告用算定と追加運転の意思決定を分ける。
- やる夫の「工場門で切る」とやらない夫の「畑の外へ出たら知らない」を同じ境界逃げとして壊し、境界を責任逃れでなく用途から選ぶ。
- C-1にデータ品質、配分、除外、感度範囲を足し、「小数点以下」を信頼の代わりにしない。

## 第4幕　煙突を止めても小麦が残る

- ガス窯だけを主犯と決め、全電化で工場排出は減るが、原料・電源・ピーク費用が残る。
- 1,000斤の仮想データで、窯、電力、小麦、包装、配送、廃棄の寄与率をパレート図へする。
- 小麦では肥料由来N2O、土地利用、収量変動、配送では積載率と空車回送を具体例にする。
- 再生材包装を重くして輸送排出が増える反例、薄肉化で食品廃棄が増える反例を交差させる。
- スコープ間へ排出を移すだけの施策を、物理総量と報告境界の両方で検算する。
- C-2は一点値でなく寄与上位、変動幅、データ改善優先順位を示す。

## 第5幕　安い削減から、工程を作り直す削減へ

- 全施策を同時実施する案を、資金、停止時間、設備寿命、技能、電力契約で壊す。
- 省エネ、断熱、熱回収、ヒートポンプ、電気窯、再エネ調達、原料変更、物流、廃棄削減を限界削減費用曲線へ置く。
- 負の費用の省エネが放置された理由を、投資上限、担当分断、停止リスク、短い回収年数基準で読む。
- 平均削減単価だけで決めず、不可逆性、学習、ロックイン、電力網との時機を足す。
- reboundを、効率化で窯稼働が増え総排出が戻る注文増で検算する。
- 施策を「今すぐ」「次回更新」「実証」「保留」に分け、C-3へ実行責任と期限を付ける。

## 第6幕　再エネ証書と森の向こう

- 証書購入で工場電力をゼロと書き、同じ再エネを二社が主張する二重計上で壊す。
- location-basedとmarket-based、追加性、時間・地域一致、PPA、自家発電を用途別に比較する。
- オフセットを排出削減と同じ列へ足す案を、ベースライン、追加性、恒久性、漏出、検証で止める。
- 植林、土壌、DAC、地中貯留を、除去速度、貯蔵期間、逆転リスク、費用で比較する。
- 残余排出を先に大きく定義して相殺する案を棄却し、削減階層の後段へ除去を置く。
- 四つの秤へ同じ製粉100 kg CO2eの工程札を載せ、物理排出、組織の関係ラベル、製品への配分、契約・除去の主張が答える問いを実演で分ける。
- C-4では物理排出、契約上の主張、除去、回避クレジットを別行にする。

## 第7幕　炭素ゼロの広告を検査する

- やる夫が「一斤0 g」を広告へ載せようとし、境界、年、削減量、残余、オフセットが欠ける。
- greenwashingを意図の悪さだけにせず、曖昧語、比較対象、選択的開示、将来約束、検証不能として検出する。
- 製品比較は同じ機能単位、品質、保存性、廃棄率、地域を揃えないと成立しない。
- 目標を基準年、中間点、総量／原単位、対象範囲、資本計画、監督で移行計画へ変える。
- 公正な移行を、光熱費、雇用、取引農家、地域電力制約の分配として検討する。
- 窯更新の費用をパン屋だけ、節肥による収量リスクを農家だけへ負わせる案を退け、価格契約、実証費、失敗時の再交渉を組み込む。
- C-5は「ゼロ」ではなく、現状、削減済み、残余、次の投資、検証者を一枚で示す。

## 第8幕　停電の夜の脱炭素

- 嵐で系統電力が止まり、電化案を脱炭素の失敗と決めつける。
- 蓄電、熱貯蔵、需要調整、二重燃料、近隣マイクログリッド、手動縮退を、排出と回復力の二軸で比較する。
- 化石バックアップをゼロにする日付だけでなく、使用頻度、代替燃料、廃止条件を管理する。
- 1,000斤すべてを焼く案を捨て、学校給食分、予約分、一般分の順に縮退運転する。
- 脱炭素設備がレジリエンスを弱める／強める条件を、単一設備でなくシステム構成から判定する。
- 実測活動量でC-6を更新し、推計と実績の差を次年度の学習へする。

## 終幕　白いパン、黒いレシート

- スーパーへ一点値だけでなく境界、範囲、上位排出、削減工程、不確実性を添えたレシートを渡す。
- 緑のシールは廃棄せず、「ゼロ」部分を切り取り、QRから公開台帳へつながる小さなラベルへ作り直す。
- やる夫は焼き上がる音を聞きながら畑から窯までを指で辿り、やらない夫は原料の数字を小さく見せるより減らせる条件を次作の契約へ書く。
- 次の原料ロットで収量低下が通知され、レシートは完成品でなく更新する経営道具として閉じる。

## 依存と検算

- LOT-2050、1,000斤、C-0〜C-6は固定し、各幕で同じ活動量表を更新する。
- 工場境界と製品境界は第3幕で分け、第4・6・7幕の帳簿ゼロ判定へ再利用する。
- 黒いレシートは第1幕の宣言不足、第3幕のデータ品質、第5幕の施策、第7幕の主張、終幕の公開へ累積する。
- 緑シールは第1幕のギャグ、第6幕の証書混同、第7幕の広告監査、終幕の切り直しで回収する。
- 停電は新概念の見世物にせず、第2〜7幕の物理、境界、施策、主張を同時使用する統合試験にする。
