# 改稿記録

`review-opus-medium.md` の指摘7点に沿って改稿した。

## 工夫した点・主な変更

- **BWTの $F$ の誤りを、修正で終わらせずに教材の主題へつないだ（指摘1）。** $F=\texttt{aaabnn}$ を $F=\texttt{\$aaabnn}$ に直したうえで、やらない夫に「その1文字を落とすと $C[c]$ が全部1ずれる。$C[\texttt{a}]$ はいくつだ」と問わせ、やる夫に $C[\texttt{a}]=1$ を出させた。さらに「1ビットを削る教材なのに、1文字落として全部壊すところだった」と言わせている。この教材は最終盤のオチが「`rank` の定義が1ずれて全検索が壊れた」であり、$F$ の脱落はその伏線と同じ型の事故なので、修正箇所自体を伏線の一部に転用した。$L$ と $F$ の対応の説明にも「先頭の `$` の1行を飛ばした位置から始まる。$C[\texttt{a}]=1$ がその1行分だ」を追記し、式の値が図の1行と結びつくようにした。

- **カタラン数の添字を、規約を変えずに揃えた（指摘2）。** 漸近式を $C_m\sim 4^m/(m^{3/2}\sqrt\pi)$ と中立な文字で書き、$m=n-1$ を代入して $\log_2 C_{n-1}\approx 2(n-1)-\frac32\log_2(n-1)+O(1)=2n-\frac32\log_2 n+O(1)$ とした。$-2$ が $O(1)$ に吸われ、$\log_2(n-1)$ と $\log_2 n$ の差が $O(1/n)$ で消えることを1行ずつ書かせたので、添字のずれが結論に効かない理由まで読者が確認できる。

- **やる夫が自分で潰す場面を2つ作った（指摘3）。** 2-1 では、累積和 400MB を出した直後、ビットくんの警告を待たずに「これは索引じゃない、索引のほうが本体だ。辞書を引くために辞書の32倍ある付箋を貼るのと同じだ」と言わせ、警告が出たあとは「先に言ったから今日は刺さらない」で流す。5-1 では、やらない夫の「値域は？」を全部削り、やる夫が種別8種で満足しかけた瞬間に「この列に入れたいのは種別だけじゃない、自治体コードも入れると自分で言った」と気づき、$\sigma=3000$ で1要素3000ビット（元の12ビットの250倍）、空のビット列が2900本以上できることまで自力で列挙させた。やらない夫の返しは「今日は俺の出番がないな」だけにして、素朴案の提出者と棄却者が同一になる回を作った。

- **第9幕の現場試験に1件だけ失敗を入れた（指摘4）。** 全文locateを 52ms で落とし、count（1.9ms）との差から標本間隔に原因があることをやる夫に特定させた。8-2 で容量を詰めた際に接尾辞配列の標本間隔を 32 → 64 に粗くしていた、という設定を 8-2 側にも1行追記して伏線化してある。「標本が半分になれば標本にぶつかるまでの平均歩数が倍」「中央値では見えない、locateする1%だけが遅くなる」と診断させ、6-2 の「標本間隔と復元コストの綱引き」を明示的に回収した。修正は 2MiB 差し出して 18ms、総使用量 461→463MiB。直前に自分で「余白は無駄じゃない」と言った本人が、その余白から2MiBを出し渋っていたという自己認識を添えた。最終メーターの表示も 463MiB／99パーセンタイル 24ms に更新している。

- **総括リスト4つを2つに畳んだ（指摘5）。** 第5幕末の問い合わせ一覧（6項目の箇条書き）を3行の散文に縮め、第9幕の「必要になりやすい条件」6項目・「不要になりやすい条件」6項目・「構造の選択表」9行を、4列（課題／有力な構造／使う条件／使わない条件）の表1枚に統合した。統合にあたって「使わない条件」列は元の不要条件リストを構造ごとに割り付け直し、一般論の羅列ではなく各行の裏返しになるようにした。表の後には「この表全体が無効になる条件は」を置き、規模とメモリ上限の2つが揃わなければ右3列を読む前に終わり、という上位の判定を残した。

- **できる夫に一度だけ誤った推薦をさせた（指摘6）。** 8-2 の測定結果読み上げの直後に「推薦は圧縮中心版です！ 403MiBで最小です！ この教材は『1ビットも無駄にできない』でしたよね！」と主張させ、やる夫が要件（検索50ms以内）を突きつけて反論する形にした。反論の中身は容量ではなく、(a) 一部のlocateが88msで要件を1つ落としている、(b) 55MiBの余白は無駄ではなく、更新できない構造が再構築までを生きるための余地である、の2点。できる夫は「私は最小値を探す競技をしていました。競技が違いましたね！」で引き取り、既出の持ち芸を自分に向けて使う形にした（やる夫の「2回目だお、それ」で受けている）。8-2 の結論が、地の文の宣言ではなく対話の決着になった。

- **ビット予算メーターを「ビットくん」に改名した（指摘7）。** 人物表・本文・全読み上げを一括で置換した。もともと本文にやる夫が計測器を作って命名する場面があり、「名前は？」「ビットくんだお！」がそのまま成立する。以後の読み上げも「ビットくん：推定使用量、18.7GB」の形で、くっつく君・どこで死んだ君と同系統の命名になっている。
