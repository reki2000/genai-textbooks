# やる夫が政令指定都市の市長になるようです ── 大都市経営を再発明する の骨格

人口150万の政令市「中原市」（一般会計7,500億、市税3,200億、9区、庁舎築60年）の新人市長やる夫の就任初日から年度末（4月1日0時）まで。公約は「給食費完全無償化 年28億（中学25億＋小学校の国基準5,200円超の差額3億）」と「豪華庁舎より子ども＝600億新庁舎の凍結」。記者に「100日で公約を形にする」と宣言。市長印が「決める印」でなく「動かす印」だと分かるまでの話。

人物：やる夫（新人市長）／やらない夫（前副市長、財布を12年握り、600億庁舎計画と一律シーリングを作った当人。無給の相談役）／できる子（財政課の査定担当、前任は港北区の子ども家庭支援課。資料と現場の数字を持ってくる）／できる夫（港北区選出の市議、第三会派。第6幕の質問者）。

## 第1幕　市長印では何も決まらない
- 1-1　初日に給食28億を市長印で決裁。予算の議決は議会（自治法96条）、提案権は市長のみ（112条）。当選＝公約承認ではない。議員も直接選挙＝二元代表制（議院内閣制との対比、与党がいない）。庁舎凍結も設計費・積立を外すなら予算＝議会。600億計画の作者はやらない夫と承知で呼んだ。印を引き出しにしまう。
- 1-2　専決処分（179条）の要件を読み、「否決も議決しない」の誤読を自分で修正。阿久根市（2010）の専決乱用→リコール失職→2012年法改正で副市長選任が対象外・不承認時の報告義務。場面表 甲（災害で議員が集まれず今夜要る）／乙（否決）／丙（待てる改装）で甲だけ。自分の「100日」は法律の緊急ではない。不信任（178条、2/3出席・3/4賛成、辞職か解散、再不信任は過半数）。「専決は一生使わない」→「一生とは言うな」（2-4 の伏線）。
- 1-3　五つの権限を仕分け（予算＝議会、議決済み執行・規則・一般人事＝単独、副市長＝同意）。市長の芯は提案権と執行権、要るのは説得力。できる子の予算日程表（1月市長査定、2月議会、3月予算特別委）。「7,500億はどこから来る金か」を保留して政令市の話へ。

## 第2幕　同じ「市」ではない
- 2-1　深夜の虐待通告：政令市は児相設置義務、一時保護の判断も市長の部下。市内の国道（直轄除く）・県道も市が管理。252条の19、全国20市、2017年度の県費負担教職員の移譲（所得割2%）。できる子が一時保護所の定員超過（定員32、平均41）を報告するが、やる夫は「所長の運用」と流す（5-1 で回収）。知事と市長は横並び。
- 2-2　区ごとに予算・区長公選案。特別区（東京23区、公選・課税）と行政区（法人格なし、区長は職員）。できる子の区役所経験：市民が最初に触る市役所は区役所。市議選は区単位＝区の声は区選出議員から来る（できる夫の伏線）。
- 2-3　二重行政（大阪のWTCとりんくうゲートタワー）、指定都市都道府県調整会議（2016）、都構想は2015・2020年に否決。知事には命令できない「隣の国」。
- 2-4　12月16日未明の震度5強。築60年庁舎4階の本部室にひび、非常用発電機に浸水対策なし→消防局指令センターへ本部移転。県道17号（埠頭東端→市街地）陥没、管理者は市。同夜の一時保護の移送が迂回で67分（通常30分台）、保護所は43人。応急復旧8億＋庁舎補強2億＋避難所2億＝12億、臨時会は招集できず専決処分＝場面甲。財政調整基金を12億取り崩し。初日は何も起きなかった印が、今夜は道路を直す。庁舎4階立入禁止で凍結公約が揺らぐ（「今朝は言わなくていい。寝ろ」）。

## 第3幕　市の金は市の金ではない
- 3-1　歳入内訳（市税43%、交付税700億、国庫支出金1,400億、県支出金、地方債600億ほか）。国庫支出金は紐付きで年度途中に回せない。災害復旧は国の査定後。一時保護所増設30億は対象経費20億の1/2で国10億、市持ち20億（半分でなく2/3）。給食も国基準月5,200円と中原市5,600円の差400円が形の外。庁舎の国補助はゼロ。
- 3-2　地方財政法5条：地方債は投資的経費のみ。「食べてない未来の市民が払う」から世代間負担の公平。庁舎は借りられるが「全額とは限らない」（5-2 で回収）。
- 3-3　市民税2倍案：標準税率（所得割8%、うち政令市移譲2%）・制限税率、足による投票で税源が逃げる、法定外税は数億〜数十億。歳入の他律性。
- 3-4　交付税は一般財源で数式で決まる（4-1 へ）。保留その1＝臨時財政対策債「借金なのに国が面倒を見る」。保留その2＝市は破産するのか、唯一の実例の20年返済が2026年度末に終わる（7-2 で回収）。「数式をよこせ」「お前が発明するんだ」。

## 第4幕　市長査定までの道具箱
- 4-1　交付額＝必要支出−実際の税収 案がモラルハザード（徴税サボり、需要の盛り）→両辺を理論値に。基準財政需要額3,050億、標準的な市税収入3,000億×0.75＋譲与税等100億＝収入額2,350億、差700億が決定通知と一致。財政力指数0.77、不交付団体。
- 4-2　0.75の理由：100%算入なら税収+100億で手取りゼロ（頑張り損）、75%なら+25億が残る＝留保財源。逆に減収は75%を国が吸収するサスペンション（7-2 で使う）。
- 4-3　保留その1回収：2001年度の財源不足、需要額削減案・国債満額案を棄却、折半して地方分は各市名義で借り元利償還を後年度の需要額に全額算入。形は市の借金・中身は国の借金。不交付団体では空手形、返済の現金は市が用意。2025年度から新規発行ゼロ、全国残高40兆円近く。中原市残高900億。
- 4-4　財調基金288億（地震で12億取り崩し後）を「安泰」と言い、毎年30億の赤字なら10年もたない→ストックとフロー。経常一般財源と経常経費の比を自力で組み立て経常収支比率。中原市3,830/3,950＝97.0%、自由財源は年120億（7,500億のうち）。90%の市なら395億で3倍以上。「まだ約束していない金が市長の本当の武器」（5-4・7-3 の伏線）。
- 4-5　残高の絶対額で判定する罠を回避。標準財政規模4,000億（標準税収入額等3,300＋交付税700、経常一般財源や実際の市税と別の箱）。元利償還480億のうち交付税措置124億を引いて実質公債費比率8.9%。線18%（許可制）・25%（早期健全化）・35%（再生）、D市27.1%の演習。将来負担比率（将来負担1兆1,200億−控除8,000億）80%、政令市基準400%。診断「借金は軽いが日々の家計がカツカツ」。比率の法律は2007年、なぜその年か（保留その2へ）。
- 4-6　要求一覧に給食28億が入っていない。7月シーリング→10月要求→11月査定で、11月末の決裁は終盤。当選前の夏に大半が決まっていた。経常経費内訳（人件費1,150／扶助費1,530／公債費480／物件費等670）でシーリングが効くのは17.5%だけ。「物件費を一律3%削って20億」案に、やらない夫も毎年そうしてきたと同調。できる子：保護所夜間の委託補助員3人は0.97人にできず2人の夜＝33%減、港北区窓口の短縮で子育て相談待ちが2日→5日。やらない夫「一律が楽だったのは何を止めるか選ばずに済んだから」。市長の道具は予算編成方針と総合計画。

## 第5幕　公約・庁舎・保護所
- 5-1　市長査定の三件：A 給食（経常+28億、やめられない）／B 新庁舎600億（4階立入禁止）／C 一時保護所増設（建設30億、経常+8億）。「全部即時」。建てれば公約違反、建てなければ次の地震。Cは政令市だから市長の机に来る、2-1 の「頭を下げるのはお前」は自由な120億の使い道の話だった。Cは選べない支出＝120億は最初から120億ではない。条件1恒久財源／2健全性／3世代間公平／4議決可能性／5法令適合。
- 5-2　Cを先に引いて112億。候補案1（A・B即時、庁舎全額起債）：一般単独事業債は充当率75%で150億現金→基金138億、450億の返済年17億で経常収支比率98.3%、条件2違反。候補案2（給食を基金から）：条件1違反の時限爆弾、基金は議会が開けない夜の金。候補案3（公約断念・庁舎フル規格）：条件4違反。残るのは「既存事業を削ってその分だけ給食を広げる、中3から1学年ずつ」。
- 5-3　一律でなく名前を付けて削る。削減候補表（物件費の名指し▲7.5億／外郭団体▲3億／公民館34→24館▲4億・合意2年／市単独上乗せ扶助費▲5億・3年経過措置）。文化財団廃止は移管費2.4億で純0.6億、統合なら初年度▲1億・2年目▲2.5億＝名前を消すことが削減ではない。平日午後2時の説明会に夜の子ども食堂の母親は来ない→夜と週末に再開催。初年度は8.5億で1学年（8.3億）だけ。公約の速度を決めるのは合意にかかる年数。
- 5-4　庁舎：多目的ホールと展望フロアをやらない夫が擁護→ホール建設90億＋60年運営110億の試算（ライフサイクルコスト）でやらない夫自身が外す、450億へ。断熱を落とす案は13年で逆転するので落とさない（使わない場所を削り、使う場所の質は削らない）。起債330億（上限337.5億）＋基金に毎年40億×3年で着工3年後、その間の自由財源は72億。防災機能部分だけ交付税措置つき起債を切り出し、全額措置を前提にしない。保護所：やらない夫の「3年調べてから」と「今41人いる」の対立→引き返せること（夜間増員、埠頭東端から近い施設との一晩預かり協定30日）は今、引き返せない本体は調べてから3年目開所。5年後試算で28億全部は願いだったと気づき補助金総ざらい▲6億で削減25億・中学3学年、小学校差額3億は届かず、比率97.5%（上がった0.5ptは保護所と借金返済、給食は差し引きゼロ）。自由財源約98億から使途未定の10億を条件公開で残す（災害／税収下振れ／保護所の安全基準）。表紙「給食費完全無償化の段階実施」の「完全」を消すか一晩考える。

## 第6幕　予算特別委員会
- 6-1　2月議会初日、地震の夜の専決12億を内訳で説明し全会一致で承認＝議会が後から検算。できる夫「中3の1学年だけは公約違反では」。この4年では実現できないと認め、97.0/97.9/98.3%と充当率75%で説明。速度を決めるのは財源より合意の年数、削減実績に連動、早めたいなら削る側の議論を。削減候補一覧の提出を求められ、公民館10館廃止と扶助費見直しを公言したことになると指摘され、出す。
- 6-2　できる夫の「9区に1億ずつ」修正案（地元港北区の67分を挙げて）。区に平等／人に平等／困っている度合いの区別。9区の夜間到達時間（12〜48分、平均27分で目標30分内だが3区超過、港北区内でも駅前29分・埠頭東端67分）。平均は67分の子を隠し、よその区の速さで相殺してはいけない線。できる夫は取り下げ、東端の2か所目の施設との協定に移送協定予算+1億の増額修正を提案（議会は提案権を侵さない範囲で増額修正できる）。やる夫は異議なし（使途未定10億とは別に手当て）。
- 6-3　新庁舎450億の根拠質問：凍結公約は地震の夜に自分で取り下げ、削った150億の内訳、断熱13年、措置つき起債は防災機能に限り全額措置を前提にせず実質公債費比率9.4%未満。できる夫が所信表明の「初年度に完全実施」を指摘、撤回して詫びる。増額修正つきで可決、付帯決議（削減進捗の半年ごと報告／起債対象額確定後の再説明／保護所は金額でなく区ごとの夜間到達時間と定員超過日数で報告）。説得力とは「反対する人が検算できる形で数字を置くこと」。就任100日目、記者に「100日で公約達成」と書かないよう頼む。

## 第7幕　年度末の夜
- 7-1　3月31日21時、給食費条例改正の公布文に署名、各中学校長への通知に押印＝「決まったことを動かす印」。港北区最大の自動車部品工場が市外移転、来年度市税見込み−40億。2学年目が消える。
- 7-2　一時借入で年度をまたいでつなぐ案。まず交付税0.75で穴は $-40+30=-10$ 億（サスペンション、精算は後年度）。保留その2を開ける：夕張市（2006、赤字約353億÷標準財政規模約45億≈7.8倍、中原市換算3兆1千億）、決算は黒字に見えていた。健全化法は2007年＝指標がなかったから夕張が起き、夕張が起きたから指標ができた（4-5 の問いの回収）。ジャンプ方式＝やる夫の一時借入案そのもの。四指標で全会計・フローとストックを測る。財政再生団体、再生振替特例債約322億、全国最高の負担と最低のサービス、人口半減以下。つけを払うのは後に住む市民＝世代間公平の最も残酷な形。一時借入案を消す。
- 7-3　使途未定の10億を条件2（税収下振れ）で使う。ただし予備は一度きりで穴は毎年続くので2学年目を1年延ばし、削減の積み増しをまず穴埋めに。半年後の報告を待たず4月の委員会で自分から言う（黙るのは帳簿の外に隠すのと同じ）。やらない夫が未解決問題を置く：政令市の多くは交付団体（不交付は川崎など一部）、権限は県並み・財源は市のまま・制度は未完成、人口減少と施設の一斉老朽化の中で縮む都市をどう運転するか。4月1日0時、夕張の20年返済が年度として終わる。本物の決算カードを読みに行く。印は議会が決めた日だけ使う。
- 付録：中原市財政ダッシュボード（指標・値・何を数えた額か・登場節）。架空の市である旨と、実在事実は2026年9月時点の公開情報に基づく旨の注記。

## 依存
- 市長印：1-1（何も起きない、引き出しへ）→ 2-4（専決処分書に押す）→ 7-1（公布後の通知に押す、決める印でなく動かす印）→ 7-3（引き出しへ）。三回の押印の意味の違いが題の芯。
- 専決処分：1-2 の場面表 甲乙丙と「一生使わない」「一生とは言うな」→ 2-4 で甲として使う → 6-1 で承認（議会の検算）。阿久根の例と 2012 年改正の記述を変えるなら 2-4 の台詞も直す。
- 一時保護所（定員32・平均41）：2-1 で流す → 2-4 で67分・43人 → 4-6 で夜間3人→2人 → 5-1 で選べない支出 → 5-4 で先行策と本体の分離 → 6-2 で分布と到達時間 → 6-3 付帯決議の報告指標。67分と9区の到達時間表は 6-2 の平均27分と整合させること。
- 中原市の数値は付録ダッシュボードが正本。7,500億／3,200億／交付税700億／需要額3,050億／標準市税3,000億×0.75＋100億／標準財政規模4,000億／経常一般財源3,950億／経常経費3,830億（内訳4項目）／97.0%・120億／元利償還480億・措置124億・8.9%／将来負担80%／基金300→288億。どれかを変えたら 4-1〜4-6、5-2、5-4、6-1、6-3、付録をすべて検算する。
- 5-2 の 97.9%・98.3%、5-4 の 97.5%、6-1 の答弁の数字は同じ計算の再掲。庁舎の充当率75%は 3-2 の「全額とは限らない」の回収。
- 留保財源0.75（4-2）は 7-2 で工場撤退の40億を10億に縮める根拠。サスペンションの比喩は両所で同じ。
- 保留その1（3-4）→ 4-3 回収、臨財債の「措置の有無で実質負担が違う」は 4-5 の分子と 5-4 の防災起債の切り出しで再使用。保留その2（3-4）→ 4-5 末の「なぜ2007年か」→ 7-2 夕張で回収。7-2 の一時借入案は夕張のジャンプ方式と同型でなければならない。
- 一律削減（4-6）の否定が 5-3 の「名前を付けて削る」と 6-2 の「区に1億ずつ」の否定（同じ額≠同じ痛み、平均が分布を隠す）に通じる。
- 「まだ約束していない金が武器」（4-4）→ 5-4 の使途未定10億 → 7-3 で条件どおり使う。
- やらない夫は 600億計画・一律シーリング・ホール擁護・保護所の3年調査で都度やる夫と対立し、4-6・5-4 で自分の前提を改める。この変化を消さないこと。
- できる夫は 2-2 の「区選出議員」で予告され、6-1〜6-3 だけに登場。6-2 で自分の区の数字を突きつけられ増額修正に転じる流れが「反対する人が検算できる数字」の実演。
- 公約「100日」：1-1 の宣言 → 1-2「自分で作った締切は緊急ではない」→ 1-3 市長査定が100日以内と喜ぶ → 4-6 ラインの最後の検品 → 6-3 就任100日目に「書かないでくれ」。
