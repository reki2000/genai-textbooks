# 改稿記録

`review-opus-medium.md` の7つの改善案をすべて反映した。第1〜4幕の保留と回収の構造、交付税の式の導出、留保財源の両面検算はそのまま維持し、指摘された「議会が不在」「公約が消える」「第5幕の自案が無審査」「数値の重複」を直した。

## 主な変更

- **第5幕に議会を実装した（5-3を新設）。** できる夫を中原市議会議員として登場人物に追加し、予算特別委員会の答弁場面を書いた。質疑は3点。①5年で6学年は公約違反ではないか、②その速度は財源が理由か、③450億の根拠と有利起債の対象額。やる夫は公約が4年では実現できないことを自分の口で認め、削減候補3件の一覧提出を約束し、起債は「450億全体に措置が付く前提では計算していない」と答える。最後にできる夫が所信表明の「初年度に完全実施」を引き、やる夫が撤回と謝罪をする。可決だが付帯決議（削減進捗の半年ごとの報告、起債対象額確定時の再説明）が付く。第1幕の「市長の最重要スキルは説得力」は、ここで「反対する人が検算できる形で数字を置くこと」として回収した。条件4が想像でなく実戦で試される形になった。
- **削る10億の中身を具体化し、削減コストで実施スケジュールを規定した。** 「既存事業の見直しで毎年10億削る」の一行を、やらない夫が4-6を引いて差し止める。削減候補を3件（外郭団体補助▲3億／老朽公民館34館→24館▲4億／市単独上乗せ扶助費▲5億）表にし、反対する当事者（市OBの団体役員、地元自治会と区の連合会長、現に受給している市民）と実行までの年数（今年度から／2年／条例改正＋3年の経過措置）を明記した。合計12億でも初年度に生めるのは3億だけ、という非対称から「最初の年が一番削れない」を導き、公約の実現速度を決めているのは財源ではなく**9区の説明会にかかる年数**だという転回に着地させた。学年拡大を削減実績と連動させる設計にし、5年後の検算も98.3%→削減▲25億でも98.0%と、やる夫自身が「このままでは通さない」と言う形にした。自案だけ無審査で通る問題を解消している。
- **給食費60億を第5幕へ戻した。** 案件Aを子ども医療費45億から公約の給食費60億（小35億・中25億）へ差し替え、第1幕の起点が第5幕・第6幕で決着するようにした。「完全無償化」に届かないことを明言させ、5年で9学年中6学年、残る3学年は次期の課題として計画に明記する、という説明責任まで書いた。
- **指定都市であることを決断に効かせた。** 案件Cとして児童相談所の一時保護所（定員32人／平均入所41人、建設30億、経常+8億）を追加。やる夫が「これ県の仕事じゃないのか」と言うのに対し、やらない夫が「隣の人口40万の市なら市長室に書類は来ない」と返す。第2幕の「児相の判断で子どもが死ねば頭を下げるのはお前だ」が、心構えではなく自由財源120億の使い道の話だったと本人に気づかせた。Cは「やらない選択肢が机の上に無い」ため、120億から先に8億を引いてからAとBを議論する構造にし、6-2の「権限は県並み、財源は市のまま」を数字で裏打ちした。
- **4-6に人件費と定数を接ぎ木した。** 経常経費3,830億の内訳表（人件費1,150／扶助費1,530／公債費480／物件費・補助費等670）を出し、シーリングで実際に動くのは物件費等670億だけ＝経常経費の17.5%をやる夫に計算させた。「比率が高いことより、高い部分が触れない費目でできていることが問題」というやらない夫の総括、定数条例・人事委員会勧告・労使交渉という別ラインの存在、退職者不補充で児童福祉司も保健師も減るという第2幕との接続を加えた。ここが5-2の削減議論の土台になっている。
- **数値の重複を解消した。** 基準財政需要額3,200→3,050、標準的な市税収入3,200→3,000、経常一般財源4,000→3,950、経常経費充当分3,880→3,830に振り直し、普通交付税700億・自由財源120億・経常収支比率97.0%は維持した。4-1では「実際に取った額ではなく理論値だ、混ぜるな」と明示し、4-5でも標準税収入額等3,300億が経常一般財源とも実際の市税とも別の箱であることを断った。付録表には「何を数えた額か」の列を追加し、各値の定義と算式を並べた。財政力指数は0.78→0.77（2,350÷3,050）。
- **参考文献を新設した。** 法令5件（地方自治法96条・112条・179条・180条、地方財政法5条・33条の5の2、地方交付税法10〜14条、財政健全化法、教職員・児相・国道の移譲根拠）、統計・公表資料5件（地方財政白書、地方財政状況調査と決算カード、地方債計画、夕張市財政再生計画、指定都市市長会要望書）を、それぞれ本編のどの幕・どの数値に対応するかを添えて列挙した。あわせて、中原市の数値が架空の設定値であること、交付税措置つき起債の適用可否は年度の要綱によることを注記した。

## 残した判断

- 削減の3件目「市単独の上乗せ扶助費の見直し」は、受給者に直接不利益が及ぶ最も重い削減だが、経常経費の40%が扶助費であるという4-6の構造上、避けて通ると削減の議論が成立しないため残した。経過措置3年と条例改正という手続の重さを併記している。
- できる夫は与党でも野党でもない立場にした。二元代表制では市長に与党が存在しないという1-1の設定と矛盾させないため。
- lint は error 0件（emphasis-flanking と structure-delimiter は `--fix` で解消）。6-3の warning は振り返りの列挙で、往復にほぐすと回収の一覧性が落ちるため残した。
