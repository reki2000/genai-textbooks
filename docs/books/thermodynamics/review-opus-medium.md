# 寸評：やる夫で学ぶ熱力学 ― 永久に氷を作る工場

約74KB／全9幕。製氷工場を舞台に、永久機関の企てが第二法則へ順番に負けていく過程で、第1法則・エントロピー・相平衡・エクセルギーを再発見する教材。

## 良い点

**設定が理論の要求と完全に噛み合っている。** 製氷工場という舞台は、(a) 冷凍機の屋外側に低品位排熱が実在する、(b) 氷が潜熱の実物として常に手元にある、(c) 温度差の管理がそのまま電気代になる、の3点を同時に満たす。第1幕の「92+38=130」（51–61行目）から第9幕の凝縮温度・蒸発温度の改善（1836–1838行目）まで、同じ工場の同じ数字が9幕を貫いている。舞台が装飾ではなく論証の器になっている稀な例。

**「氷の秤」と「仕事の階段」という2つの自作計測器が全体の背骨。** 259行目でやる夫自身が「0℃の氷を融かす」を思いつき、480行目で「氷は答えじゃなくて会計帳の紙」と自己定義し、8-2で「11万段のうち30段しか拾えてない」（1706行目）へ結実する。0.098J というワッシャー1段の単位が最初（156行目）から最後まで生きていて、抽象量が常に段数へ換算できる。この一貫性は教材全体の可読性を大きく上げている。

**やる夫が本当に間違う。** 遠心分離で温度差を復元しようとして両方0.4℃上がる（544–562行目）、輪っか配管で圧力が均一化してタービンが止まる（854–875行目）、火力1.5倍で両方上がって安全弁作動（886–893行目）、氷蓄熱で電力量が2割増える（1391–1408行目）。いずれも「失敗しました」で終わらず、できる子の測定値が敗北を数値で確定させる。特に氷蓄熱の2割増は、省エネの常識に反する結果を実測で突きつける良い設計。

**できる子という役の発明。** 淡々と数値だけを読み上げるキャラクターを置いたことで、やる夫が都合の悪い数字を無視できない構造ができている（人物紹介18行目に明記）。教師役が反論すると説教になるところを、測定値が反論する形にできている。二者対話の教材にはない強み。

**期限が物語を駆動している。** できる夫が完成前に横断幕を刷ってしまう（488–491行目 → 1035行目「刷ってしまいました」→ 1768–1770行目「あと3日」）。これにより第9幕が「原理的に不可能と分かった後、3日で何をするか」という実務判断の幕になり、「断熱改修は2週間かかるので祭りに間に合わない」（1818行目）→「熱力学的に正しくても3日で終わらないなら今回は0点」（1823行目）という、理論教材が普通は書かない着地に到達している。

**6-2の直結実験が第二法則の証明として機能している。** 可逆熱機関と可逆冷凍機を直結し、釣り合わせれば何も出ず、傾ければ温度差を食う（1285–1321行目）。そして「これ、第1幕の廃熱エレベーターと同じだお」で最初の装置へ戻る。円環構造として美しく、かつ「戻ってきたが、最初と同じか?」という問いで、理解の前後差を明示している。

**参考文献が本文の対応箇所つきで付いている。** Carnot、Clausius 2本、Gibbs、Callen、Moran、Çengel の7点（1983–1995行目）に、それぞれ本書のどの幕に対応するかが書かれている。

## 欠点

**第7幕が本筋から浮いている。** 7-1（氷蓄熱）は工場の話として繋がるが、7-2（過冷却→相平衡→ギブズ自由エネルギー→クラペイロン）は永久機関という主題とほぼ独立している。1575–1580行目で「この話は永久機関と何につながる?」と作者自身が接続を試みているが、返答は「相転移を利用して熱を運びやすくはできるが、第二法則を迂回はできない」という一般論で、7-2で学んだ $\mu$ の一致条件やクラペイロンの式が使われていない。水の融解線が逆向き（1566–1572行目）に至っては、製氷工場との関係が本文中に一切ない。

**過冷却エピソードの因果が弱い。** 「温度計を挿した瞬間に凍った」（1450–1458行目）は劇的だが、その直前に過冷却を予期させる伏線がなく、事故として突然発生する。他の失敗（遠心分離、輪っか配管）が全て「やる夫が何かを企てた結果」なのに対し、これだけは外から降ってくる。4%という数字を検算させる（1470–1473行目）のは良いが、やる夫の企ての失敗ではないため、他の幕と手触りが違う。

**中盤でやる夫が賢くなりすぎる場面がある。** 983–995行目のカルノー定理の証明（高効率機関で可逆機関を逆回転させる背理法）は、やらない夫の「なぜこの機関が最高だと言える?」という一言だけで、やる夫がほぼ完全な形で組み立てている。ここは熱力学で最も非自明な論証の一つで、他の箇所（遠心分離で3往復かかる）と比べて抵抗がなさすぎる。同様に 1517–1543行目のギブズ自由エネルギーと $(\partial G/\partial T)_P = -S$ も、初学者設定のやる夫が導出なしで書き下している。

**エントロピーの導入が「割り算の発見」で止まっている。** 5-2で $Q_H/T_H = Q_C/T_C$ からエントロピーを定義する流れ（1074–1102行目）は論理的に正しいが、なぜ他ならぬ $Q/T$ が状態量になるのか（任意の可逆サイクルで $\oint \delta Q_{rev}/T = 0$ であること）は示されていない。カルノーサイクル1つの関係式から $dS = \delta Q_{rev}/T$ へ飛んでおり、「状態量である」という最も重要な主張が跳ばされている。1105–1109行目でやる夫が「乱雑さの別名だと思ってた」と言うが、統計力学的解釈との接続もそのまま放置される（それ自体は範囲外として妥当だが、言及して回収しないのは中途半端）。

**できる夫の造形が単調。** 全登場箇所（73行目、618行目、737行目、878行目、1214行目、1385行目、1954行目ほか）で「!!」を連発して過大な期待を述べ、やる夫を煽る、という同一機能しか果たしていない。「これはもう半分くらい無限では!?」（1388行目）のようなセリフは笑えるが、13回ほぼ同じパターンが繰り返されると効果が減衰する。物語に期限を作るという役割は序盤と第9幕で果たされており、中盤の登場は削るか、別の機能（コスト側の圧力をかける等）を与える余地がある。

**8-1の並べ替えクイズの答えが即座すぎる。** 1596–1601行目でやる夫が「1番は500℃の蒸気、電池は静かだから弱い」と直感で答え、次のできる子の発言で正解が全部出てしまう。ここは教材のクライマックス（エクセルギー概念の導入）なので、やる夫自身に $1-T_0/T$ を4つに適用させて、自分の直感が崩れる瞬間を作るべき箇所。

**第3幕でマクスウェルの悪魔を避けたのが惜しい。** 573–578行目で「今は情報熱力学まで逃げないお」と明示的に打ち切っている。判断としては妥当（分量制御）だが、悪魔は「巨視的装置なら不可能」の理由を最も鋭く照らす題材でもあり、末尾で開いた問いとして再提示する等の扱いはできたはず。

## 改善案

1. **第7幕を再構成し、相平衡を工場へ接続する。** 7-2の相平衡を、製氷ラインの実務問題に紐づける。例えば「なぜ製氷は常圧で0℃なのに、真空製氷という方式があるのか」をやる夫に問わせ、クラペイロンの式で三重点近傍の挙動を計算させる。あるいは水の融解線の逆傾斜を「圧力をかけて融点を下げれば冷凍機なしで氷が作れるのでは?」という新しい永久機関案として提示し、$dP/dT$ の値を入れて必要圧力が非現実的であることを自分で潰させる。後者なら主題（永久機関を順番に殺す）と完全に整合する。

2. **過冷却に伏線を張る。** 7-1の氷蓄熱運転の記録の中に、できる子の一行として「一部の製氷管で凍結開始が遅れる傾向」を仕込んでおく。やる夫がそれを「効率が良い証拠」と誤解し、その誤解が7-2の配管閉塞として跳ね返る形にすれば、他の失敗と同じ「やる夫の企ての結果」の型に揃う。

3. **カルノー定理の証明でやる夫を一度失敗させる。** 983行目の前に、やる夫が「高効率機関があったら何が困るのか」を最初は言語化できず、やらない夫が「その機関で得た仕事を、可逆機関を逆に回すのに使ったら?」と道具立てだけを渡す往復を1つ挟む。現状の一発正解は、この教材で最も惜しい省略。

4. **$Q/T$ が状態量であることを一段補う。** 5-2で、任意のサイクルを微小なカルノーサイクルの集まりで近似できる（PV図上でカルノーサイクルのタイル張りをする）という絵をやる夫に描かせ、$\oint \delta Q_{rev}/T = 0$ を経由してから $dS$ を定義する。10〜20行で済み、エントロピーが「便利な割り算」から「状態量」へ格上げされる。

5. **8-1でやる夫に4つ全部を計算させる。** 1601行目のできる子の一括回答を分割し、やる夫に $1-308/773$ と $1-308/313$ を自分で計算させてから、電池と圧縮空気が関所を通らないことに気づかせる。順位の予想（1596–1601行目）を先に紙に書かせておけば、崩れ方が体感できる。

6. **できる夫の役割を中盤で変える。** 中盤の登場を2〜3回削り、代わりに1回だけ「予算」の圧力を持ち込む役に転じさせる（例：8-2で膨張弁のタービン置換を提案されたとき、コストと保守の話を持ち込む）。1744–1750行目の「熱力学は上限を示す、採用は工学と経済の判断」という良い着地が、キャラクターの行動で裏打ちされる。

7. **末尾の開いた問いを一つ置く。** 現状の締め（1964–1974行目「理論より先に積み込むお」）はコメディとして良いが、weather-forecasting 教材が持つような「まだ誰も答えを持っていない問い」がない。統計力学との接続（なぜ $S = k\ln W$ が同じ量なのか）か、非平衡系（生物や地球はなぜ秩序を保てるのか）を一言置くと、教材の外へ扉が開く。
