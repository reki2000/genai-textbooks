# 改稿記録

`review-opus-medium.md` の指摘を軸に、既存の9幕構成と「氷の秤」「仕事の階段」を残しつつ、やる夫が予想し、測定・計算で誤りに気づく流れを強めた。

## 主な変更

- 第5幕のカルノー定理を一発回答から、誤答、可逆機関の逆運転、高温側の熱収支の相殺、単一熱源からの仕事という背理法を段階的に組み立てる対話へ変更した。
- 任意の可逆サイクルを微小カルノーサイクルで近似する考えを挟み、$\oint\delta Q_{\mathrm{rev}}/T=0$ からエントロピーを状態量として導入した。統計力学的な意味との関係も、範囲を区切って回収した。
- 氷蓄熱の運転記録に過冷却の伏線を置き、やる夫がそれを利用しようとして配管閉塞を招く因果へ変更した。
- 第7幕の相平衡を工場の永久機関探索へ接続した。ギブズ自由エネルギーの式を教師の足場かけから導き、水の融解線を使った圧力製氷案を、向き・約40MPaの必要圧力・潜熱排出・復帰工程の会計で棄却した。
- 第8幕の順位クイズでは、やる夫自身に500℃と40℃の熱の最大仕事を計算させた。電池と圧縮空気にカルノー係数をそのまま適用できないこと、圧縮空気は状態指定なしでは最大仕事が決まらないことも明確にした。
- できる夫を一度だけ予算・保守の制約を持ち込む役に変え、熱力学的上限と設備採否の違いを行動で示した。
- 終幕に、局所的秩序と非平衡系のエントロピー生成という未解決の入口を置いた。

## 残した判断

- 製氷工場、夏祭りまでの期限、全9幕の大枠、仕事の階段と氷の秤、熱機関と冷凍機の直結実験、3日で実行可能な改善へ着地する終盤は、本教材の強みとして維持した。
- マクスウェルの悪魔は本編を情報熱力学へ拡散させないため、既存の短い言及に留めた。開いた問いは非平衡熱力学側に置いた。
- lint の warning は会話内の不可分な数式導出や既存節の長さに関する診断であり、内容を確認したうえで残した。error はない。
