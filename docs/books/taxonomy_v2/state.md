## 幕ごとの到達点と現在位置

- 第1幕：見た目の総合点を棄却し、分類の目的を識別・命名・系統・予測・保全へ分離する。
- 第2幕：生物学的種概念の推移律破れと適用不能を経験し、複数の種概念を用途別に使う。
- 第3幕：名前・分類仮説・対象を分離し、タイプ、二名法、先取権、同物異名、ランクの不均等を扱う。
- 第4幕：相同／相似、共有派生形質、外群、最節約法、ブートストラップで形態系統仮説を作る。
- 第5幕：配列距離、多重置換、遺伝子樹と種樹、バーコーディングを扱い、DNAを判決でなく証拠にする。
- 第6幕：三ドメイン、水平伝播、細胞内共生、複合個体、生命の作業定義へ進む。
- 第7幕：対照と参照DBを用いてΩを解き、eDNA検出から存在・定着を短絡しない調査計画を作る。
- 第8幕：七札を観察・同定・配置・代替仮説・用途・次の検査・版で監査し、一語ラベルを更新可能な説明へ直す。
- 終幕：証拠・代替仮説・用途・更新可能性を含む展示を来館者へ手渡す。
- 現在位置：全幕・二つの幕間・累積巡回の本文を完了。lint error 0を確認し、人手点検済み。

## 定義・記号・数値

- 島ヤモリ：A=120、B=80、C=100。隣接交配成功率 A-B=72%、B-C=68%、A-C=2%。閾値を50%とするトイ判定。
- 形質行列：外群カエル、トカゲ、ワニ、ハト、コウモリ。羊膜・鱗質・羽毛・毛・翼・恒温を0/1で扱う。
- 配列トイ：12塩基、差の個数を単純距離とする。後に同じ座位の複数回置換で限界を示す。
- 支持値トイ：6形質を復元抽出するカードくじを10回行い、同じ枝の出現回数/10を簡易支持値とする。
