# `taxonomy_v2` ブロックメモ

## 制約と到達点

- 新規長編。中学生以上を想定し、進化・DNAの予備知識は作中で組み立てる。
- 約7万〜9万字。歴史人物の列挙は全体の15%以内とし、七標本の判定に必要な範囲だけ扱う。
- 読了後は、分類名、同定、命名、系統仮説、保全上の単位を区別し、証拠と代替仮説を添えて説明できる。

## 人物設定

- やる夫：特別展の公開トークと大壁画を請け負った博物画家。犬と恐竜には詳しいつもりだが、似ているものを近くへ描きたがる。
- やらない夫：七島の野外調査を続ける系統分類研究者。やる夫に展示を発注する立場ではなく、「伝わる絵」と「証拠に耐える樹」という異なる利害を持つ共同登壇者。
- できる子：館に協力する環境DNA研究室の技術員。第5幕以降、配列と対照試験の結果を簡潔に持ち込む。

## マクガフィンとトイ

- マクガフィン：ラベルの消えた試験管Ω。暗い池水にしか見えず、誰も「何の標本か」を答えられない。
- 反復トイ：可動式パネル「夜の樹」。磁石の標本札S1〜S7を証拠ごとに動かし、移動前の位置も薄い線で残す。
- 形質カード：翼、毛、乳、羊膜卵、核、細胞壁など。表裏で「祖先／派生」が固定されておらず、外群により向きが決まる。
- 七つの復旧投影灯：漏水で落ちた回路を、乾燥センサが通るたびに一系統ずつ再開する。濡れた展示壁に古い観察図や写真が浮かび、各幕の始動事件になる。答えではなく、目前の配置を壊す追加証拠だけを照らす。

## 伏線と回収

- Ωのラベル跡に「POND-4」「500 mL」「filter」の断片。第1幕では採集地記号に見せ、第7幕で濾過水試料と分かる。
- 陰性対照の空チューブをできる子が何度も気にする。第7幕で混入仮説を判定する鍵になる。
- 夜の樹の裏側に網目のフックがある。第6幕で水平伝播を表す横線を掛けるためだったと回収する。
- 地衣類標本のラベルが二つ重なっている。第3幕では書き損じに見せ、第6幕で共生体の命名問題へ戻す。
- 開館ポスターの「生命を七つの王国へ」を、固定ランクの慢心として配置し、終幕では「更新中の生命史」へ貼り替える。

## 繰り返すギャグ

- やる夫が迷う標本を全部「魚の棚」へ仮置きし、棚が魚以外で満員になる。
- 学名を唱えると賢く見えると思い、語尾だけラテン語風にする。命名規約を学ぶほど短くなる。
- 標本札を動かすたび磁石が一枚だけ床へ落ち、やらない夫が「その枝の支持値はゼロだな」と返す。
- カモノハシを例外カードとして出しすぎ、後半ではやる夫が「今日はカモノハシ禁止だお」と自制する。

## 緩急と息抜き

- 第1幕は漏水と誤配架の高速な騒動。終盤で暗い標本庫に七札だけを並べる静寂へ。
- 第2幕は交配表と島モデルを短い計算で進め、リング種の輪を実際に床へ並べる身体的な場面にする。
- 第3幕は古いラベルを読む博物館的な息抜き。名前の詩情を出すが人物史講義へ流れない。
- 第4幕は推理ゲームの知的高潮。形質表の数え間違いをコメディにし、支持値の低さで一度落とす。
- 第5幕は解析結果が連続して常識を裏切る速度感。多重置換と遺伝子樹の場面で一度ゆっくり計算する。
- 第6幕は樹に横線を引く視覚的クライマックス。生命定義ではギャグを抑えて余白を作る。
- 第7幕はΩの正体を解く探偵劇。第8幕は開館直前の七札監査で、一語ラベルの速さと更新可能な説明の責任を衝突させる。終幕は子どもへの説明で静かに閉じる。

## 各ブロックの再発見ルール

各節で、やる夫が札の置き場所を予想として先に記録する。やらない夫は反証材料を一つだけ渡し、やる夫が形質表、交配表、配列距離、対照試験のいずれかを手で判定する。原因を「例外だった」で済ませず、「目的の違い」「証拠の非独立」「祖先形質」「混合試料」など構造として言わせる。新しい名前はその後に付ける。
