# 寸評：やる夫は億り人の夢を見る ―― 資産運用を学ぶ

約174KB／第0幕〜第12幕＋幕間3＋終幕＋演習10問。「五つ買えば一つ当たる」から出発し、商品の中身・価格の作られ方・自分の家計という三系統を、素朴案を潰し続けて一本の運用設計書に着地させる教材。

## 良い点

**第0幕で作った五問が、全12幕の物差しとして最後まで生き続ける。** 「何を持つ／誰が払う／利益の源／いつ現金に戻る／何が壊れる」（183–187行目）をやる夫自身に作らせ、以後これが幕間の「商品のパスポート」表（2373–2381行目）へ拡張され、第9幕の金ETF・原油ETF（2385–2399行目）、第10幕のステーブルコイン（2737–2739行目）、第12幕の最終テスト（3106–3108行目）まで同じ枠で読み直される。個別商品の羅列になりがちな主題を、一つの再利用可能な道具で貫いた設計は強い。

**三つの宿題を封筒に入れて終幕で開ける構造が機能している。** 211–215行目で出題し、やる夫の初回答（218–221行目）を228–229行目で封筒へ封印、3125–3133行目で開封して「全部ひっくり返ったな」まで持っていく。初期の自分の答えが文字として残っているため、成長が読者の記憶頼みにならない。

**計算が毎回、直感と衝突する数字に着地する。** 算術平均0%なのに残高75万円（694–708行目）、同額ロールで数量が5.41%減る（2467–2476行目）、日次2倍が往復相場で96になる（2577–2581行目）、2%の為替変動で証拠金の50%が消える（2766–2769行目）。どれも「計算のための計算」ではなく、直前のやる夫の宣言を殺す反例そのものになっている。

**注文板を机上に再現して、現在値の正体を自力で言わせている。** 1321–1332行目で売買板を並べ、250株の成行が板を一段食べる過程を計算させ（1348–1354行目）、そこから「現在値は最後に成立した限界的な取引の価格を残りの株にも仮の値札として当てている」（1373行目）へ到達する。時価総額・ローソク足・ニュース記事という後続の話題が、すべてこの一件の約定から派生する形になっている。

**「風呂場の原油」が第9幕で回収される。** 冒頭50–54行目の浴槽の心配が、2464行目「第0幕の浴槽を回収する時が来たな」で先物のロールへ接続される。教材冒頭のギャグを最終盤の技術論の入口に使う仕掛けは効いている。

**参考文献と免責が実務教材として揃っている。** 金融庁・財務省・日銀・JPX・SEC・CFTCの19点（3658–3680行目）に、それぞれ本文のどの主張へ対応するかが明記され、冒頭15行目に商品推奨でない旨の断りもある。数値（預金保険1,000万円、NISA枠1,800万円、レバレッジ25倍以下）が出典と対応している。

## 欠点

**やる夫の「○○王になるお！」が構造的に摩耗している。** 190行目「金融名探偵として講演料」、273行目「雑誌の表紙」、355行目「銀行の前に銅像」、386行目「ノーベル封筒賞」、428行目「永久住宅機関」、470行目「守銭奴界の世界遺産」、498行目「購買力防衛軍の最高司令官」──ここまでで冒頭500行に7回。同じビート（誇大宣言 → やらない夫の一行ツッコミ → 反例 → 修正 → 次節へ渡す一文）が全編で100回近く回る。個々のフレーズは達者だが、パターンが完全に固定されているため、第7幕あたりから読者は反例の中身より「次はどんな肩書きか」を待つ読み方になる。

**物語的圧力がゼロ。やる夫は12幕を通して一円も動かさない。** 第1幕で「半年以内の引っ越し30万円」（256行目）という期限つきの支出が提示されるのに、これが以後ドラマとして一度も作動しない。1-2の強制売却（328–345行目）も「三か月後の場面を置こう」という仮想で、実際に起きない。最終幕12-3も「最初の日の注文画面を再現した」（3095行目）で、やはり注文は出ない。熱力学教材の「横断幕を刷ってしまった／あと3日」に相当する外部からの圧力が存在せず、全編が安全な演習室の中で完結している。

**やる夫の人格が節ごとに初心者と上級者を往復する。** 冒頭で「五等分すれば一つ当たる」と言う人物が、同じ第0幕の終わりに五問（183–187行目）を自力で立て、第9幕では原油連動商品の収益分解式（2490–2496行目）を自分で書き下す。にもかかわらず次節の頭では毎回また白紙の初心者に戻って極端案を言う。これは造形ではなく節の型に人格を合わせた結果で、成長曲線が読み取れない。

**演習10問の大半が本編の再演で、しかも人格が巻き戻る。** 演習1（3245行目「現在値というくらいだから現在の定価」）は4-1と同じ論点・同じ構図、演習2（3287行目）は2-2の追加失敗例と同一の数字、演習6（3453行目「原油は原油だから100単位のままだお」）は9-1と同じ70/74ドル、演習7・8も11-1・11-2の焼き直し。終幕で「自分のお金の運行管理者になるお」（3202行目）と宣言した直後の人物が、同じ誤答を最初から繰り返す。分量は約450行あり、教材末尾の負担として重い。

**反例がすべて仮想で、実データ・史実が一件もない。** 「やる夫ジュース社」（1004行目〜）を中心に、価格は1,000円・100万円・10%といった丸い数字で統一されている。読みやすさの代償として、実際にいつどれだけ人が損をしたか（過去の大幅下落からの回復年数、高インフレ期の預金の目減り、仕組債の販売問題など）が一つも出てこない。第7幕でドローダウンを教える（2024–2034行目）のに、現実の市場が記録した最大下落率を一度も見せていない。

**分量に対して数学的な到達点が低い。** 本書で最も高度な式は期待損益 $E=pG-(1-p)L$（1831–1835行目）で、第7幕の分散も好況・不況の2状態を手で足すだけ（2052–2066行目）に留まる。標準偏差を「万能検査機ではない」と否定する（2042行目）のに、その標準偏差を一度も計算させないまま話が進むため、否定が体感を伴わない。相関係数、ポートフォリオの分散、リスク当たり収益といった、本書の主題（分散は役割分担である）を数値で裏づける道具が欠けている。

## 改善案

1. **引っ越し30万円を物語の時計として作動させる。** 256行目で提示した「半年以内」を実際の締切として使い、第6幕（1720行目付近）と第7幕の間に、引っ越し日が前倒しになり口座が下落中という一節を置く。1-2で仮想的に説明した強制売却（328–345行目）を、やる夫自身が実際に安値で売る場面へ変える。以後の第7幕（シーケンスリスク、2089–2116行目）が、教訓ではなく傷の分析になる。

2. **やる夫に実際の口座を持たせ、毎幕その評価額を提示する。** 第1幕末（416行目付近）で余剰25万円の具体的な内訳を実際に買わせ、以後の各幕冒頭に一行だけ現在の評価額と含み損益を置く。読者が「教材の主張」と「やる夫の口座」を突き合わせられるようになり、熱力学教材のできる子（測定値が反論する役）に相当する客観の軸が生まれる。

3. **演習を本編の再演から差し替える。** 3238行目以降のうち、演習1・2・3・6・7・8は本編と同じ数字・同じ誤答なので、(a) 誤答役を「相談に来た第三者」へ移し、やる夫を指摘する側に置く、(b) 単一論点ではなく複合問題にする（外貨建てレバレッジETFをコンタンゴ局面で1年保有し、費用・為替・ロールを全部込みで損益を出す、など）の二点を同時に行う。終幕の成長が演習で無効化される現状の問題も同時に解ける。

4. **実データを最低3か所差し込む。** 第2幕の実質リターン（598行目付近）に日本の高インフレ期または2022年以降のCPI実績を、第7幕のドローダウン（2034行目直後）に世界株式指数の過去の最大下落率と回復年数を、第11幕の仕組債（2864行目付近）に実際に問題化した販売事例の概要を、それぞれ脚注つきで置く。仮想の1,000円だけでは「起こりうる」が「起きた」にならない。

5. **標準偏差と相関を一度だけ手計算させる。** 7-1で標準偏差を否定する前（2003–2013行目のあたり）に、A株・B株の好況／不況2状態（2052–2066行目）から各資産の標準偏差と組合せ後の標準偏差を実際に出させ、「数字は下がったが信用リスクは1ミリも減っていない」という形で否定へつなぐ。10〜20行で、否定が実感になる。

6. **「○○王」宣言を後半で意図的に減衰させる。** 第8幕以降（2190行目以降）はやる夫の誇大宣言の頻度を半分にし、代わりに「言いかけて自分で止める」型（3060行目「全員に世界株式インデックス……と言いかけたお」、1906行目「いや、また未来を足しかけたお」がすでに好例）へ寄せる。同じ笑いの型を最後まで等頻度で回すより、型が自壊していく過程そのものが成長の表現になる。

7. **第0幕の浴槽をもう一段深く回収する。** 2464行目の言及は「先物には期限がある」に留まっているので、ここで現物受渡し義務のある限月を保有し続けたらどうなるかを一度やる夫に想像させ（実際に原油が届く条件は何か）、ロールが儀式ではなく受渡しを回避するための取引であることまで詰める。冒頭のギャグの回収強度が上がり、9-1の主張の根拠も明確になる。
