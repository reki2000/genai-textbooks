# 改稿記録

## 工夫した点・主な変更

- 第1幕で余剰資金25万円のうち15万円を実際に少額運用させ、第7幕直前で引っ越しの前倒しと費用超過を発生させた。下落中に2万円を売り、5,000円の損失を確定することで、強制売却とリスク許容度を本人の経験へ変えた。
- 第12幕で実口座を再確認し、相場が回復しても売却した持分と確定損は戻らないことを回収した。
- 第7幕に標準偏差と相関係数の手計算を追加した。二資産の組合せで標準偏差が20%・10%から5%へ下がる一方、計算外の信用リスクは減らないことまでつないだ。
- 第8幕以降の誇大な「○○王」型ギャグを大幅に減らし、「言いかけて自分で止める」反応へ置き換えた。後半でも初心者へ巻き戻らず、自己修正が速くなる成長曲線を示した。
- 原油先物では、現物受渡しと差金決済の違い、受渡場所・品質・数量・期日を追加し、浴槽ギャグをロールの必要性まで掘り下げた。
- 演習1〜3・6〜8を相談者の複合問題へ差し替えた。やる夫は誤答役ではなく、期限・板・金利・取り崩し・ロール・為替・レバレッジを組み合わせて注文を止める側に置いた。演習10も未確認事項を最初から申告する形へ変更した。

## 残した判断

- 商品比較を貫く「五つの質問」、三つの宿題と封筒、注文板、商品のパスポート、終幕の運行管理者という骨格は、レビューで評価された長所なので維持した。
- 実口座の表示は毎幕には置かず、買付・強制売却・最終回収の三つに絞った。各幕で同じ残高表示を反復するより、判断が変わる局面だけを物語上の客観的な軸にするためである。
- 実データ・史実の追加案は、今回の根拠を README.md と review-opus-medium.md、リポジトリ規約に限る指定に従い、未検証の数値や事例を新たに持ち込まなかった。既存の公的参考文献に裏づけられた制度・商品説明は維持した。
