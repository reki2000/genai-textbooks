# `fp-category-theory-v2` ブロックメモ

## 制約と到達点

- 8幕＋終幕、約9万〜11万字。圏論と特定言語を同一視せず、同期障害の構造監査から抽象へ上がる。
- 高度な概念を観光リストにせず、R-17の障害解決に二度以上使うものを中心にする。
- コードは短く型が見える例にし、特定言語の制約と数学的構造を分ける。

## 人物設定

- やる夫：共同配送用の地図アプリを作った独立開発者。本番切替の延期を避けたく、全APIが成功なら統合も成功だと考える。
- やらない夫：市の路上利用を監査する形式手法研究者。別組織から、二重予約を根拠に切替停止を要求する対立当事者。
- できる子：共同配送の運行指令員。現地時刻、道路区画、車両位置だけを示し、抽象案が三分間を直すか判定する。
- できる夫：統合事業の広報担当。障害名へ用語を足して解決した気になる。

## マクガフィンとトイ

- 消えた路上予約R-17。20:17〜20:20という時間関係であり、物の所在や内容を扱わない。
- 光る都市時刻線。旧版／新版、区域先行／時刻先行の二経路を異なる色で重ねる。
- 三拍メトロノーム。合成順と括り方、文脈付き合成の検算に繰り返し使う。
- 有限圏の磁石盤：対象5枚、射12本。合成、可換図式、普遍性を手で確かめる。
- 小さな型付きコード。同じ図式をコードと数式で往復する。

## 伏線と回収

- R-17だけ旧区域ID。第3幕で日付境界、第4幕で一様でない例外、第8幕で版付き変換へ回収。
- 復路線R-18の矢印が反対を向く。終幕で全ての射が可逆でないと回収。
- 三拍目だけ赤く遅れる。第2幕で外部効果の混入、第6幕でログを失わない合成へ。
- 二経路の光跡は右下だけずれる。第3幕の非可換、第4幕の自然性、第8幕のテストへ三段回収。
- 路側灯が点かない一方で課金だけ始まる。第5幕の引戻しで許可時刻と実行時刻を結ぶ。

## 繰り返すギャグ

- 「可換」を通勤できることと取り違え、やる夫が鉄道路線検索を始める。
- できる夫が用語を障害チケット名へ足し、題名だけが一行を越える。
- 三拍目でやる夫が勝手に四拍目を足し、恒等射と余計な処理の違いを突かれる。
- `map`が出るたび道路地図を拡大し、関手が地理とは限らないと戻される。

## 緩急と息抜き

- 第1幕は二重予約の接近を高速で、第2幕は磁石盤とメトロノームの身体作業にする。
- 第3・4幕は二本の光跡を追う推理、第5幕は条件交差のパズルで息を抜く。
- 第6・7幕は抽象度の頂上だが、R-17の三分間と有限圏へ頻繁に戻す。
- 第8幕はコードと現地信号のクライマックス、終幕は20:17の青い点灯と消灯で静かに閉じる。

## ブロック運用

各節は「具体の時刻不一致→二本の射→保存すべき法則→抽象名→R-17で再検査」の順にする。比喩は必ず破れる例を添え、定義の代わりにしない。可換図式は画像なしでも始域・終域・二経路を台詞で追えるように書く。高度概念は効能だけでなく適用限界と実装費用を示す。

## 状態台帳の初期値

- 5サービスの型、区域ID、時刻系、日付境界、R-17のログ時刻、変換関数、点灯結果を固定する。
- プロパティテスト例は実行可能な小コードまたは擬似コードと明記し、言語機能を捏造しない。
- 圏論的に同じであることと、性能・可用性・セキュリティ・道路安全が同じであることを混同しない。
- 参考文献は標準教科書・原論文中心にし、未確認URLを置かない。
