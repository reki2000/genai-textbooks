## 定義・法則・有限検算

- 圏：対象、射、型の合う合成、恒等射。五対象を一列につなぐ有限例は生成射4、合成射6、恒等射5の計15射。$h\circ(g\circ f)=(h\circ g)\circ f$。
- 可換図式：二経路$s\circ u=v\circ t$。R-17初期値はB-07とA-12で不合格。
- 同型：$g\circ f=1_A,f\circ g=1_B$。A-12とB-07は予約必須情報を往復保存せず非同型。
- 関手：$F(1_A)=1_{F(A)}$、$F(g\circ f)=F(g)\circ F(f)$。
- 自然変換：$G(f)\circ\eta_A=\eta_B\circ F(f)$。
- 積：任意の$f:X\to V,g:X\to P$が一意な$\langle f,g\rangle$へ因子化。2要素と3要素なら積6組、タグ付き余積5件。
- 引戻し：$Z\times_KT=\{(z,t)\mid p(z)=q(t)\}$。4組の積から版一致2組、枠406固定で1組。R-17は版不一致で初期点灯候補なし。
- 随伴：$\mathrm{Hom}(FX,Y)\cong\mathrm{Hom}(X,UY)$がX、Yに自然。
- モナド：$T=UF$、unitと乗法。実装トイはResultとログ列のflatMapで左右単位・結合律を検査。上書き結合は右単位、逆順結合は結合律に違反。
- 米田：$\mathrm{Nat}(\mathrm{Hom}(-,R),F)\cong F(R)$。$\alpha\mapsto\alpha_R(1_R)$と$x\mapsto(f\mapsto F(f)x)$で往復。
- 極限：図式への全円錐が一意に因子化する普遍円錐。積、等化子、引戻しを特殊例として回収。
