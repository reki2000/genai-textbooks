# 寸評：やる夫が水の都をデバッグするようです ── 治水と上下水道の失敗史

約56KB／全8幕。都市開発ゲームの開発者やる夫が、自作の水インフラの「バグ」を歴史キャンペーンで踏み直し、水量・水質の保存則と多層防御へ到達する教材。

## 良い点

**「ゲームのバグ」というフレームが主題と一致している。** 第1幕で治水・上水・下水を独立3ゲージにしたのが最初のバグとされ（69–70行目、113行目）、それが第8幕の8条件（1241–1255行目）と2本の保存式（1300–1318行目）へ結晶する。「設備の効果を即時値だけで判定したのがバグ」（199行目）「設備ツリーと法制度ツリーを分けてたのがまたバグ」（915行目）と各時代の失敗が同一の実装ミスとして名指しされ、1326行目「別々の歴史事件が、物質を消したつもりになる同じバグだった」で回収される。歴史教材が陥る事例カタログ化を、この軸が防いでいる。

**同じ水都マップの同じ50mm雨で開幕と終幕が閉じる。** 第1幕の流出3万1千m³（63行目）が、第8幕で貯留8,000＋12,000＋排水10,800＝30,800m³（1341–1348行目）として同じ数字で再テストされる。直後に100mm雨を流し「浸水は起きるが人命と基幹機能は守る」（1360行目）へ着地させ、成功の定義自体を更新している。

**保留と回収が明示的に管理されている。** 282–284行目「なぜ人類は汚水を処理せず川へ逃がしたのか。答えは第4幕で見つける」→ 503–506行目で自力回収。613–615行目では第1幕の内水・外水の区別を自分から再適用し、やらない夫が「学習が転移したな」（618行目）と明示する。

**やる夫の誤りが実在の誤りと重なる。** 灌漑で真水を増やして薄める案（183行目）、悪臭に石灰をまく瘴気説の実装（449–459行目）、汚水を最速で川へ送る（483–484行目）、塩素の大量投入で凝集ろ過を省く（766行目）。いずれも一度は正解に見え、数値か画面で潰される。

**史実の単純化を明示的に拒否している。** スノウのポンプの柄（472–473行目）、江戸のし尿循環を美化も貶しもしない（420–422行目）、テトンダムを「ダムは危険」カードにするな（726行目）、カヤホガ川は1969年に突然燃えたのではない（907行目）。参考文献22点（1526–1547行目）も対応箇所つき。1085–1099行目の役割逆転（やらない夫が極端案、やる夫が容量計算で反証）も良い。

## 欠点

**幕の駆動ビートが同一で、中盤以降が反復に沈む。** ほぼ全節が「最強案 → やらない夫が『N年進めろ』 → 破綻」で動く。152、160、309、411、452、543、853、967、1020行目。演出は変えているが判断の型が9回同じで、3幕目には結末が読める。

**苦労の過程が薄く、失敗の直後に完全な正解が出る。** 190–191行目で塩害の原因を一往復で言い当て、322–325行目で輪中・霞堤・遊水地に相当する配置を一発で構想し、759行目で凝集・沈殿・ろ過・消毒を淀みなく列挙する。間違いはするが、立ち直りが速すぎて正解に近づけない時間がない。

**「再発見」でなく「史実の紹介＋要約」の箇所が多い。** 第4幕以降、原理はやらない夫が事例とともに与え、やる夫は一段抽象化して言い直す役に回る。470–473行目（スノウ）、498–500行目（大悪臭）、863行目（地盤沈下）、1037–1038行目（フリント）はいずれも解説。核である保存式（1300–1318行目）すら「式にしろ」の一言で一発で書き下される。

**合理式が天下りで、単位換算が検証されない。** 809–811行目で $Q=0.278CiA$ が係数ごと与えられ、815行目で代入するだけ。0.278 が mm/h・km² を m³/s へ直す $1/3.6$ であることは本文のどこにもない。1m³＝1,000L（513行目）や1立方フィート＝0.0283m³（715行目）は丁寧なのに、最重要の式だけ素通り。

**物語的な圧力が第1幕以降ほぼ消える。** 冒頭の「同時視聴者三万人」（19行目）と5年の開発（21行目）の緊張は、1334行目で配信へ戻るまで約1300行放置される。歴史ステージには締め切りがなく（394行目の鐘三つが唯一の例外）、失敗しても失うものがない。

**判定役が不在で、数字の重みをやらない夫が一人で背負う。** 反証役と解説役が同一人物のため説教が密になる。1013行目の住民宅へのカメラ移動や1198行目の公聴会カードは良い緩和だが一過性。第7幕も5節が相互参照薄く独立エピソードの列で、特に7-4の停電（1148–1182行目）は水都マップの数値と接続がない。

## 改善案

1. **保存式を第1幕へ前倒しし、全幕で使い倒す。** 1300–1305行目の $\Delta S=P+I-R-E-Q-O$ を、63行目直後に $P$ と $Q$ しかない粗い版として置く。第2幕で塩収支 $M_k$、第6幕で不可逆な状態変数（地盤高）、第7幕で時刻依存を追加していく。第8幕は式の完成でなく「テストが緑になる」だけになり、8-2の一発書き下ろしの不自然さも消える。

2. **合理式を導出させる。** 809行目の提示を係数なしの $Q=C\,i\,A$ に留め、mm/h と km² を m と s へ直させて $1/3.6=0.278$ を自分で出させる（10行程度）。815行目の「平時の450倍」が自前の計算になる。

3. **発売日カウンタを全幕に通す。** 21行目付近で「発売まで90日、1ステージ7日」と明示し、各幕頭に残日数を1行入れる。第7幕（1004行目付近）で残り10日とし、7-1〜7-5のうち3つしか実装できない取捨選択をさせる。7-5の公平性（1185–1223行目）を「削れば売れるが削ってよいか」という葛藤に立て、1223行目「最後のバグは目的関数だった」へ自分の利害を賭ける重みを与える。

4. **プレイテスター役を1人追加する。** 数値と苦情だけを読み上げるできる子を人物紹介（6–10行目）へ加え、449行目の石灰散布、484行目の暗渠放流、1113行目の排水ランキングで、やる夫が勝ち誇る直後に測定値だけで潰させる。やらない夫が兼務する「反証」と「解説」が分離される。

5. **「N年進めろ」の変奏を3か所入れる。** 第3幕（309行目）は年送り禁止で破堤位置を予測させてから流す。6-1（853行目）は逆に気づかせないまま10年進め、地盤高レイヤーの表示をやる夫自身に要求させる。4-1（452行目）は時間を止めて地図だけで推論させる。時間の扱い方そのものを幕ごとに変える。

6. **第7幕を4節へ圧縮し、7-4を水都の数字へ接続する。** 配水池3,000m³と給水制限120L/人日（1367–1373行目）の計算を7-4側へ移し、停電中に「あと何日もつか」を先に出させる。8-3は復旧順序（1381–1383行目）に集中できる。

7. **未解決の問いを1つ残す。** 1481–1488行目の締めは強いが持ち帰る問いがない。「気候変動下では、過去の観測から決める計画規模がそもそも定義できるのか」（632行目の論点の現代版）を、8-5でプレイヤーからの2つ目の質問として置く。
