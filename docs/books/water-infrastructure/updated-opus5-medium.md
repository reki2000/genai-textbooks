# 改稿記録

`review-opus-medium.md` の改善案7点に沿って改稿した。

## 工夫した点・主な変更

- **保存式を第1幕へ前倒しし、全幕で1本ずつ育てた（改善案1）。** 内水氾濫の直後、やらない夫が「ゲージの本数の話ではない。お前はプログラマだろう、**不変条件**を書け」と要求する。やる夫は $\Delta S = P - Q$ という2項だけの粗い版を書き、排水能力2m³/s×2時間＝14,400m³を引いて $\Delta S = 35{,}600\ \mathrm{m^3}$ を得る。「ゲージが緑でも、式は最初から赤だった」「今のエンジンは水の3分の2以上をなかったことにしている」で第1幕を締め、`assert(P + I - R - E - Q - O == deltaS)` を項名だけ書いた空のテストとして残させた。教材全体が、この空欄を埋める作業になる。

- **物質収支と不可逆状態を、それぞれ失敗した場所で追加させた。** 第2幕の塩害の直後に $\Delta M_k = L_{k,\mathrm{in}} - L_{k,\mathrm{out}}$ を置き、「薄めても $M_k$ は1kgも減らない。濃度が下がるだけだ。**出口を作らないと物質は絶対に減らない**」と言語化させた。やらない夫の「この先お前は同じ間違いをあと4回する」が、第4幕・第6幕・第7幕への予告になる。第6幕の地盤沈下では $\Delta z \le 0$ を追加し、「全部の変数に元へ戻すボタンがある前提で作っていた」「ロールバックできない量が世界にあると実装したことがなかった」を出させ、不可逆な状態変数の例に「失われた信頼」を挙げさせて第7幕へつないだ。

- **8-2 を「式の発明」から「テストが緑になる」場面に変えた（改善案1の帰結）。** 90日前に書いた空のアサーションを開き、6項それぞれをどの幕のどの失敗で拾ったかを対応表として言わせた（$P$＝第1幕、$I$＝第3幕の玉川上水、$R$＝第4幕の人口密度、$E$＝第2幕の塩、$Q$＝第1幕の排水能力、$O$＝第4幕の急送）。実行結果は「WATER_BALANCE: PASS」で、「5年かけたゲームの一番地味な行が緑になっただけ。なのに90日で一番うれしい」で受けた。物質側も、第2幕の2項に $G_k$（第6幕の工場排水）と $T_k$（汚泥）が加わる形にして、一発書き下ろしの不自然さを消した。

- **合理式の 0.278 を導出させた（改善案2）。** やらない夫は $Q = C\,i\,A$ だけ渡し、単位の不整合をやる夫に指摘させる。mm/h → m/s と km² → m² を1行ずつ直させ、$10^{3}/3600 = 1/3.6 = 0.2778$ を自力で出させた。締めは「**0.278は物理でも経験係数でもなくて、ただの単位換算だった**。水工学の定数だと思って暗記するところだった」。やらない夫の「導ける定数を暗記すると、単位系が変わったときに気づけない」で一般化している。既存の 1m³＝1,000L や 1立方フィート＝0.0283m³ の丁寧さと足並みが揃った。

- **発売日カウンタを全幕に通した（改善案3）。** 第1幕で「発売まで90日、マスターアップは10日前、歴史キャンペーンは7ステージ」を明示し、以後 83／76／69／57／24／10日を各幕頭に置いた。第5幕では「予定より2日遅れている」と入れて、遅延が蓄積することを見せている。カウンタはできる子が読み上げる形にして、やる夫の主観から切り離した。

- **第7幕を工数の取捨選択の場にした（改善案3）。** 残り10日に対し4ステージの見積もりが合計18日で8日足りない、という状況から始め、やる夫に「全部やって全部半端になるより動くものを出す」「削る前に見ないと、何を捨てたのかも分からない」と言わせて4つとも通させた。幕末で、販売部の調査結果（公聴会と補償の画面は68%が「面倒」と回答）を できる子 に読ませ、公平性ステージが**削れば売れる・工数も最重**という条件を作った。やる夫はそれを切らず、理由を「いま切ったら、被害額を最小化すれば正解と教えるゲームになる。プレイヤーはAI探索ボタンを押して金色のゼロを見て上手くなった気になる。やる夫が90日前にやってたことと同じだ」「目的関数を出荷するんだ」と述べる。代わりに豪雨と鉛の演出工数を削り、それでも足りない分を第8幕のエンジン再実装を先行させることで解決させた（「いまは各ステージが独立に水を扱っているから同じ処理を4回書いている」）。既存の「最後のバグは目的関数だった」に、自分の売上を賭ける重みが乗った。

- **プレイテスター役のできる子を追加した（改善案4）。** 感想を言わず、測定値と不具合票だけを読み上げる役として人物紹介に加え、第1幕で重大度Aの起票（「水量が保存されない」、期待値と実測値つき）から登場させた。以後、(1) 石灰散布では臭気指数62→8に対し患者数14→15人を並べ、(2) 暗渠放流では市街地の指標が全部改善したことを認めたうえで「測定範囲は市街地に限定されている」と付け加え、(3) 地盤沈下では描画班が「モデルの原点がずれた」として閉じた重大度Cの票を読み上げる。いずれも、やる夫が勝ち誇る直後に測定値だけで潰す形にした。やらない夫が兼務していた反証役と解説役が分離されている。

- **「N年進めろ」の型を3か所で変奏した（改善案5）。** (a) 第3幕は年送りを禁止し、「どこが切れるか、流す前に言え。当てられたら30年進めてやる」とした。やる夫は地形レイヤーから勾配の変化点と蛇行の外側を挙げ、$(4,6)$ を予測して的中させたうえで「切れる場所が分かっていたのに、そこも他と同じ堤防にしていた」「**均一に守ることは、公平に守ることではない**」に着地する。(b) 4-1 は三日進めた後に時計を止め、「動かせるのは地図だけだ」としてレイヤーを総当たりさせた。臭気・人口密度・標高・職業が全部外れ、「どのレイヤーも多いところに多いまでしか言わない」で行き詰まらせてから、「病気は住所から入ってくるのか」の一言で給水経路レイヤーへ到達させた。(c) 6-1 は逆に、地盤高レイヤーを指示せずに10年進め、やる夫に「特に問題ない、次へ行く」と言わせた。できる子が読み上げる「建物が地面へめり込む・描画バグ・修正済みで閉じた」不具合票から、やる夫自身が標高レイヤーの差分を要求する。「バグは、めり込んだ絵じゃなくて、**地面を定数にした設計**だった」で締めた。

- **第7幕を4節へ圧縮し、7-3（現7-2後半）を前段と接続した（改善案6）。** 「雨水を追い出す速さを競うな」の見出しを外して 7-2 に統合し、節題を「五十年前と同じ雨か ── そして誰が遅らせるのか」とした。統合の継ぎ目では、やる夫が「それだけに背負わせない」と言った直後に排水ランキングを提案するので、やらない夫が「いま自分で言った直後に、また一つの指標へ全部背負わせたな」と指摘できる。量→タイミング→負担の三段が1つの議論になった。

- **停電節を水都の数字へ接続した（改善案6）。** 8-3 にあった配水池3,000m³と給水制限120L/人日の計算を 7-3 へ移し、停電中に「発電機が止まってから何日もつか」を先に出させた。平時2,000m³/日なら1.5日、120L制限で2.5日＝60時間、72時間まで**12時間足りない**。「『非常時に備える』じゃなくて『12時間分足りない』なら値札がつけられる」と言わせ、やらない夫が「漠然とした不安には予算がつかないが、12時間には予算がつく」で受ける。8-3 側はその数字を参照するだけになり、復旧順序に集中できるようになった。

- **未解決の問いを持ち帰らせた（改善案7）。** 8-5 で、プレイヤーからの二つ目の質問をできる子に読ませた。「計画規模は過去の観測から決めると書いてあった。気候が変わっているなら過去の観測は使えないのでは。このゲームの50mm/hは何年の50mm/hか」。やる夫は答えられず、「第5幕でやったのは『設計を超える雨が来たときどうするか』の話で、いまの質問は**そもそも設計規模という数を定義できるのか**だ」と論点を分離する。結論は答えを出さないことを画面に出すことで、雨量スライダーの横に「この数値は過去の観測から作られている、未来の雨がこの分布に従う保証はない」と表示させた。「ゲームの説明文としては最悪だ。誰も喜ばない。でも90日で覚えたのは、**分からないことを分からないまま画面に出す**ことだった。臭気ゲージを白くして安心したり、被害額を金色のゼロにして満足したのは、全部その逆だった」で、第4幕と第7幕を同時に回収している。

## 残した判断

- 「ゲームのバグ」というフレームと各時代の失敗を同一の実装ミスとして名指しする軸、開幕と終幕を同じ50mm雨で閉じる構成、史実の単純化を明示的に拒否する箇所（スノウのポンプの柄、江戸のし尿循環、テトンダム、カヤホガ川）、参考文献22点は、レビューで評価された骨格なので変更していない。

- 「苦労の過程が薄い」という欠点は改善案に個別項目がなかったが、4-1 のレイヤー総当たり（4つ外して1つ当てる）、第3幕の破堤位置予測、6-1 の「問題ないと言って通り過ぎる」の3か所で、正解に至るまでの空白時間を作った。5-4 の凝集・沈殿・ろ過の淀みない列挙などは、その節の主題が別にあるため手を入れていない。

- 追加した数値（排水能力2m³/s、臭気指数と患者数、地区別の工数見積もり、事前調査の68%）はいずれも作中のゲーム内データで、実在の統計ではない。既存の実データ由来の数値（メソポタミアの塩、テトンダム、フリント、地盤沈下）には手を触れていない。
