# 改稿記録

## 工夫した点・主な変更

- **壊れていた集合記号のTeXを全部直した。** `\bigcup_{x\in[0,1]}{x}` → `\{x\}`、`\mu({x})` → `\mu(\{x\})`、`\mathbb{Q}=\frac{p}{q}\mid\ldots` → `\mathbb{Q}=\left\{\frac{p}{q}\;\middle|\;p,q\in\mathbb{Z},\ q\neq0\right\}`、デデキント切断の $A$・$B$ を `\{q\in\mathbb{Q}\mid q^2<2\}` 形へ。第2幕の測度論と第3幕の切断は、集合が集合に見えないと議論そのものが読めない箇所なので最優先で処理した。他の `{...}` 表記も一括確認済み。

- **できる子を第7幕に投入し、ランダウアーの原理を数字にした。** $k_{\mathrm B}T\ln2$ を書いただけで終わっていた箇所を、できる子が定数を読み上げ、やる夫が $2.9\times10^{-21}$ J を計算する形に変えた。そのうえで **冒頭の5年前の動画そのもの** を素材に使い、4GB $=3.2\times10^{10}$ ビット × 理論下限 $=9.3\times10^{-11}$ J に対し、実際の書き込みは 6W × 60秒 $=360$ J、比で **4兆倍** を出させた。落としどころは「無駄ではない」というできる子の一言で、理論下限ぴったりで書けば熱雑音に埋もれて数秒で壊れる、5年間読めた理由がその4兆倍だ、と反転させた。**余分な熱は記録を壊れなくするための代金** という形で、第1幕の動画が第7幕の熱力学に直結する。

- **7-2で過去仮説を「名前だけ」から使える道具にした。** その360ジュールがどこから来たかを遡らせ、コンセント → 発電所 → 化石燃料 → 光合成 → 太陽の核融合 → 初期宇宙の低エントロピー、と **6段** をやる夫に数えさせた。できる子が光合成1%・火力40%という変換効率を置き、段ごとに大半を捨てながら渡ってきた末に記録が1つ残る、という構図にした。未来の記憶ができない理由も、「未来側から低エントロピー在庫を引くことになるが過去仮説がそれを許さない」という形で、過去仮説を実際に使った結論へ変えた。

- **5-2にGPSの数値計算を入れた。** 「式を4本書いてまだ一度も数を入れていない」とやらない夫に指摘させ、できる子が諸元を読み上げ、やる夫が2つ別々に計算する。特殊相対論分 $v^2/2c^2=8.3\times10^{-11}$ → 1日 $7.2\,\mu$s の遅れ、重力分 $\frac{GM}{c^2}(1/r_\text{地}-1/r_\text{衛})=5.3\times10^{-10}$ → 1日 $46\,\mu$s の進み、差し引き **$+38\,\mu$s/日**、距離に直して **1日11km**。$g_{00}\approx-(1+2\Phi/c^2)$ が「哲学ではなく毎日11km分の実務」になり、双子時計も思考実験でなく頭上を飛んでいることになる。

- **やる夫に一度、言い切って実際に負けさせた。** 6-2の「未来が存在するなら努力しても無意味だお」を口論で終わらせず、実際に資格試験の勉強を一日サボらせ、模試が62点から48点へ落ちた結果を本人に報告させた。そこから「壊れたのは『未来が存在する』から『努力は無意味』への矢印だ」「サボりを含む未来は48点、サボらない未来は62点、どちらも存在する未来だ」と、決定論と宿命論の区別を **14点の代償を払った後で** 言わせている。やらない夫の受けも「14点で買った教訓としては安い方だ」に変え、講義的な承認句を避けた。

- **できる夫を2回登場させ、2回ともやる夫に潰させた。** 人物紹介にあった「宇宙規模の事業へ展開したくなる」設定を、テンションの高い早口の提案として実装した。
  - 6-1末：ブロック宇宙を聞いて「未来観測研究所」を起業しようとする。ここではやる夫が **反論できない**。「存在と読み出しの間に壁があると示す道具をまだ持っていない」と認めさせ、第7幕へ進む動機そのものに変えた。
  - 7-1：光円錐を書いた直後に、やる夫が自力で潰す。未来光円錐からは $P$ へ信号が来ない、存在しても痕跡が作れない、壁は存在論ではなく因果構造だった、という順で決着する。さらに「仮に届いたら閉じた因果の輪ができ、観測した瞬間に観測した未来が壊れる」まで詰めた。
  - 8-2：できる夫が「隣の枝なら同時刻だから因果構造に引っかからない」と再挑戦する。やる夫はデコヒーレンスで潰す ── **枝が分かれたと言えることと隣の枝が読めないことは同じ一つの事実**。読めるほど干渉が残っていればそもそも分岐していない。
  - 直後にやらない夫が「2回とも何を使ったか言え」と問い、やる夫が「存在論には一度も踏み込まず、届くかどうかだけを答えた」「答えられる問いに翻訳してから答えていた」と自覚する。教材全体の方法論が、他人への反論として2回実演される構造になった。

- **やらない夫に一度「知らん」と言わせた。** 10-1の「意識の時間経験を完全に説明したわけではない」を一往復に広げ、やる夫が「状態が更新されるだけなら、なぜ動いていると感じるのか」と正面から聞き、やらない夫が **そこは俺も知らん** と答える場面にした。理由も明示させている ── 10幕で教えたのは時間という一語を測れる構造へ分解する手続きであって、「状態の更新になぜ経験が伴うか」はその道具のどれにも掛からない。「知らないことを『まだ分解できていない』と言えるようになったのが成果だ」で受け、承認句の連続で固まっていた上下関係をここで一度崩した。

- **節冒頭の要約を17か所から8か所へ減らした。** 幕をまたぐ箇所（第3・4・6・7・8・9・10幕の頭など）は読者の迷子防止として残し、幕内2節目の9か所（2-2、4-2、5-1、5-2、6-2、7-2、8-2、9-2、10-2）は「前の節で〜と分かったお」を削って直接本題から入るようにした。削除ではなく書き換えで、失われる情報がないことを1つずつ確認している。

## 残した判断

- 無限後退の罠を2度踏ませる構造、「1秒毎秒」の解体、点の長さ0と区間の長さ1の測度論的解決、プランク時間への一撃、9-1の分岐点の計算は、レビューで評価された核なので手を入れていない。
- 「やる夫が間違いきる前に自分で止める」型は、6-2で実際の代償を伴う失敗を1つ入れ、6-1でできる夫に反論できない場面を作ることで全体の圧力を上げたが、後半の自己修正型の言い回し自体は残した。この教材の主題が「答えられる問いへ翻訳する訓練」である以上、やる夫が言い切る前に立ち止まること自体は身についた技能の表示でもあるため、全部を外から潰す形に変えるのは主題に反すると判断した。
- 追加した数値（$k_{\mathrm B}$、GPS諸元、$GM$、HDDの消費電力、光合成と火力の効率）は、いずれも標準的な物理定数か広く公表されている代表値に限り、既存の参考文献の射程を超える主張は足していない。模試の点数のみ物語上の設定値である。
- 期限や費用といった外形的な切迫は、この教材の「時間実在判定機」が比喩的な装置であるため導入せず、代わりに **14点の失点** と **できる夫の事業提案** という2つの具体的な圧力で代替した。
- lint は error 0件。10-1・10-2 の長大発言 warning は、やらない夫が「知らん」と答える場面と終幕の着地であり、切ると効果が消えるため残した。
