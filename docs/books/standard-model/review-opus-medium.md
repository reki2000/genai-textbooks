# 寸評：やる夫で学ぶ標準模型 ── 力を再発明する

約106KB／全6幕。相対論的量子力学の破綻から出発し、ゲージ原理を「位相の基準は場所ごとに自由」という一言に凝縮して、QED・ヤン・ミルズ・ヒッグス機構・電弱理論を順に組み上げる。一般相対論編の続編として、対応表を育てながら進む構成。

## 良い点

**第3幕の問いの立て方が教材全体を支えている。** 「『全宇宙で一斉に』って、誰がやるんだお？」（517–529行目）は、ゲージ原理を天下りでなく物理的な違和感から導入する最短経路になっている。しかも「250万光年先と一斉には不可能」「位相の原点を共有する理由がない」の2段で、道A・道Bの選択（571–584行目）まで自然に降りる。ゲージ理論の教科書が最も苦労する動機付けを、20行で片付けている。

**捨てたものが正体を変えて戻る構造。** 第1幕で「確率密度としては失格」（431–432行目）と切り捨てた $j^0$ が、第2幕で電荷密度として復活する（439–449行目）。同じ量が、読み方を変えるだけで欠陥から粒子・反粒子の区別へ転じる。この「回収」は第4幕の張り紙（1118–1119行目）→第5幕の「4-5の張り紙、回収だお」（1706行目）でも反復され、伏線の使い方が全体で一貫している。

**4-3の診断が本教材の白眉。** 「基準の違う2つの数を、そのまま引き算してた」「円とドルを換算せずに引き算するようなもの」（789–797行目）。寄生虫項 $i(\partial_\mu\alpha)\phi$ の正体を、計算ではなく概念で言い当てさせている。しかもその直前に、やる夫自身の素朴案（767行目の $D_\mu\phi \equiv \partial_\mu\phi - i(\partial_\mu\alpha)\phi$）を「$\alpha$ は理論の中に存在する量じゃない」（775–779行目）と自己添削させる往復を挟んでおり、正解に至る前に必ず1回転ぶ型が守られている。

**1424行目の一行が教材の要になっている。** 「本当にそれを証明したか？　証明した命題を、一言一句正確に言え」から、やる夫が「ラグランジアンに関する命題だけだお」（1433行目）へ自力で到達する。ヒッグス機構の本質は「法則の対称性と状態の対称性は別物」であり、それをやらない夫が説明するのではなく、やる夫に自分の証明を読み直させて発見させた。物語上の最大の山場が、新しい計算ではなく既出命題の精読で開くのは見事。

**自由度の会計検査。** 破れの前後で 2+2=4 と 1+3=4 を数えさせ、「$\chi$ はゲージ場の縦偏極に転職した」（1647–1661行目）へ着地させる。「食われる」という比喩が、勘定という検証可能な形で裏打ちされている。

**退化検算が習慣として繰り返される。** 非可換の変換則を U(1) に潰して 4-3 に戻ることを確認（1163–1165行目）、$F_{\mu\nu}$ の交換子項が 1×1 で消えることを確認（1216–1218行目）。上位互換であることを毎回自分で確かめる作法が、読者の足場になっている。

## 欠点

**電弱理論の核心をやる夫が計算していない。** 1685–1703行目、$SU(2)\times U(1)$ の設定を「構成だけ与える」でやらない夫が並べ、破れのパターンも「手を動かした結果だけ言えば」で結果だけが列挙される。1692行目でやる夫が「これ計算すると……4方向のうち3方向が真空を動かして」と言うが、実際には何も計算していない。真空 $(0, v)^T$ に $\sigma^a$ と超電荷を作用させ、どの組み合わせだけが真空を消すか──$Q = T^3 + Y/2$ が残る──は、この教材のクライマックスそのもの。ここが伝聞なのは致命的で、直前まで丁寧に積んだ「自分の手で潰す」型が最後で崩れている。

**非可換ゲージ場の変換則も天下り。** 1160行目の $A_\mu \to UA_\mu U^\dagger - \frac{i}{g}(\partial_\mu U)U^\dagger$ が、「導出は同じ手順だ、$U$ が行列になっただけ」の一言で与えられる。U(1) では 832–840行目でやる夫に逆算させているのに、行列版で手を離すのは順序が逆。ここでの非可換性の効き方を体で覚えないから、直後の $[A_\mu, A_\nu]$（1203行目）の重みが薄れる。

**第6幕が答え合わせではなく年表になっている。** 1827–1895行目、やる夫の発言は「実測値は？」（1836行目）「後出しじゃない、正真正銘の予言だお」（1856行目）「結果は」（1869行目）と、ほぼ相槌のみ。第5幕まで数値を自分で出してきた（246 GeV、80 GeV：1722–1727行目）のに、検証の幕で一度も計算しない。$a_e$ の12桁一致を語りながら、1ループの $\alpha/2\pi$ すらやる夫に出させていないのは惜しい。

**強い力が宣言だけで終わっている。** 1799–1815行目。SU(3)、グルーオン8本、閉じ込め、すべてがやらない夫の10行の口頭発表で、「この機構の詳細は今日は踏み込まない」で閉じる。タイトルが「標準模型」である以上、$SU(3)$ の扱いがこの分量なのは構成上の不均衡で、しかも漸近自由（なぜ非可換だと高エネルギーで結合が弱まるのか）は本教材が積み上げた自己相互作用の話と直結するのに触れられない。

**参考文献が全16点すべて Wikipedia。** 1952–1967行目。$G_F = 1.17\times10^{-5}\,\mathrm{GeV}^{-2}$（1302行目）、$a_e$ の12桁一致（1839–1840行目）、光子質量上限 $10^{-18}$ eV（1089行目）といった数値が、一次資料（PDG、原論文）に一切紐づいていない。Dirac 1928、Yang–Mills 1954、Higgs/Englert–Brout 1964、Weinberg 1967 は、本文が名前と年で言及している以上、文献として挙げるべき。

**物語の圧力が皆無。** 登場人物は2名のみ（6–8行目）、舞台も期限も利害もない。パウリがヤンを講演で潰す挿話（1256–1262行目）は本教材で唯一の劇的な場面だが、これは歴史の紹介であってやる夫の身に起きたことではない。「やる夫が困る」の内容が最初から最後まで「計算が合わない」に限定されており、96KBを通した緊張の変化が乏しい。

**ビートが同型反復に近い。** 「では判定してもらおう」（551行目、930行目、1156行目）、「では聞く」（117行目、770行目）、「不合格だお。ぐぬぬ」（937行目、1193行目）。やる夫が素朴案を出す→やらない夫が代入を命じる→余計な項が残る→ぐぬぬ、の型が、4-4・4-6・5-2でほぼ同じ手触りで繰り返される。

## 改善案

1. **1689–1703行目を、やる夫の手計算に置き換える。** やらない夫は真空 $\langle\phi\rangle = \frac{1}{\sqrt2}(0, v)^T$ と超電荷の割り当てだけを渡し、「4つの生成子のうち、この真空を消すものはどれだ」と問う。やる夫に $\sigma^1, \sigma^2, \sigma^3, Y$ をそれぞれ作用させて、$\sigma^3$ と $Y$ の特定の和だけがゼロになることを確かめさせ、そこから $Q = T^3 + Y/2$、ワインバーグ角 $\tan\theta_W = g'/g$、$m_Z = m_W/\cos\theta_W$ を自分で書かせる。20–25行で、教材最大の山場が伝聞から再発見に変わる。

2. **1160行目の変換則をやる夫に逆算させる。** U(1) の 832–845行目と同じ形式で、$D_\mu\psi \to UD_\mu\psi$ の要求から $\delta A_\mu$ を解かせる。やる夫がまず「$A_\mu + \frac{1}{g}\partial_\mu\alpha^a\sigma^a/2$ でいいお」と完コピ案を出し、$UA_\mu U^\dagger$ の項が要ることに気づいて転ぶ往復を1つ入れれば、直後の交換子項の必然性が跳ね上がる。

3. **第6幕にやる夫の計算を1つ入れる。** 1839行目の前に、シュウィンガーの1ループ $a_e = \alpha/2\pi$ をやる夫に暗算させる（$1/(2\pi\cdot137) \approx 0.00116$）。実測 0.00115965… の先頭4桁が「$\mathcal{L}_{\rm QED}$ の1行目」から出ることを自分の手で確認してから、12桁の話に進む。相槌の幕が検算の幕になる。

4. **参考文献に一次資料を足す。** 1952–1967行目の各項に、対応する原論文（Dirac 1928, Proc. R. Soc.／Yang & Mills 1954, Phys. Rev.／Englert–Brout, Higgs 1964, PRL／Weinberg 1967, PRL）と、数値については PDG の該当年版を併記する。本文が年号と人名を出している箇所（184行目、1143行目、1638行目、1852行目）と1対1に対応させる。

5. **1766–1768行目の湯川項を段階化する。** いまは「全部の変換がちょうど相殺するゲージ不変な項を作ると……この形だお」で完成形が出る。まず $\bar\psi_L\psi_R$ が SU(2) 添字を1本余らせることをやる夫に確認させ、「余った添字を潰す相手が要る」→「ダブレットの $\phi$ がちょうど余分な添字を持っている」の順で組ませる。5行の追加で、湯川結合が偶然でなく添字の勘定の帰結になる。

6. **強い力を1節に昇格させるか、タイトルを絞る。** 1811–1815行目の「非可換性の帰結」を受けて、$g^2A^4$ 項（1229行目）がグルーオン自身に色荷を持たせ、それが遮蔽ではなく反遮蔽（漸近自由）を生む筋を15行ほど入れる。分量を増やしたくないなら、タイトルを「力を再発明する」から電弱に軸足を明示した表現に改める方が誠実。

7. **ビートの単調さを崩す。** 4-4（925行目の素朴案）か 5-2（1360行目の開き直り案）のどちらかを、やらない夫の「判定しろ」ではなく、やる夫が自分で計算を始めてしまい途中で気づく形に変える。同じ「不合格」でも、命じられて転ぶのと勝手に転ぶのとでは手触りが違う。

8. 勉強のできる中学生の姪っ子、できる子に教えてやると豪語してあわてて学ぶという他でも使っている圧力を導入する。
