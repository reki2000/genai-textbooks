# やる夫で学ぶ標準模型 ── 力を再発明する の骨格

**前作『一般相対性理論を一晩で再発明する』（`general-relativity`）の続編という設定**。やる夫は特殊相対論・量子力学を学び、一般相対論を再発明し終えた学生。**一般相対論との対応表が第4幕を通して育つ**のが本作最大の構造で、序幕と終幕が「二つの物語は同じ崖の上で終わる」で呼応する。

**登場人物と役割**：
- **やる夫** ── 各節で安直な案を出し、**自分で計算して自分で潰す**。「シンプルイズベストだお」→「不合格だお」→「ぐぬぬ」が定型。後半では**やらない夫の判定を待たずに自分で転べる**ようになる（4-4で明示的に評される）。
- **やらない夫** ── 教師。判定と歴史の補足。「では聞く」「では検収だ」「判定しろ」で計算を渡す。**答えは言わず、保留の張り紙を貼る**（3幕末の「打ち消し係の正体」、4-5の「なぜWは重いのか」）。
- **できる子** ── やる夫の姪、中学生。**序幕で三問を出し、終幕でその三問の答えを採点する**。標語を拒否し「いま何を証明していないか」を要求する。登場は序幕・3幕末・4-4末・5-4末・終幕の5回のみだが、**そのすべてが「言い過ぎの訂正」を強制する関門**になっている。
- **できる夫** ── 科学教室の企画役。**内容の完成より先に告知や投影資料を確定させる**。「標準模型、再発明成功」「力の正体は対称性」「ゲージ原理から電磁気学が導かれる」「80と91」を先に印刷し、そのたびできる子に止められる。

**序幕の三問**（終幕で回収）＝**(1) なぜ力は四つで、なぜその形なのか／(2) 質量はどこから来るのか／(3) その理論が思いつきでないことをどう確かめたのか**。

## 序幕　残り三つの力を、日曜までに

できる夫が続編『残り三つの力を、日曜までに』を勝手に告知。できる子の三問。やらない夫の警告＝**「重力のときは出発点の等価原理を一日で腹に落とせた。今回は出発点にたどり着くまでに、お前の常識が三回死ぬ」**。

## 第1幕　シュレーディンガーが壊れる日

- シュレーディンガー方程式の出発点 $E=p^2/2m$ が非相対論的（時間1階・空間2階）。
- **試作1＝クライン・ゴルドン方程式**。$E^2=p^2c^2+m^2c^4$ を量子化。連続の式から $\rho = \frac{i\hbar}{2mc^2}(\psi^\ast\partial_t\psi - \psi\partial_t\psi^\ast)$、平面波で $\rho = \frac{E}{mc^2}|N|^2$ → **$E<0$ で確率密度が負**。「捨てればいい」が二つの理由（完全系にならない／相互作用で遷移が起き底がない）で却下。**シュレーディンガー本人が先に転んだ**歴史。
- **試作2＝平方根を直接取る**。$\sqrt{-\hbar^2c^2\nabla^2+m^2c^4}$ をテイラー展開すると**無限階微分＝非局所**で死ぬ。
- **試作3＝ディラック方程式**。$E = c\boldsymbol\alpha\cdot\mathbf p + \beta mc^2$ の1次式化。反交換条件 $\alpha_i^2=\beta^2=1$、$\{\alpha_i,\alpha_j\}=0$。**「普通の数では矛盾 → 順序を入れ替えられないもの＝行列」**。パウリ行列では4つ目が座れず**最小4×4**。$\rho = \psi^\dagger\psi$ で正定値、おまけに**スピンと $g=2$** が出る。
- だが**負エネルギー解は4成分中2つとして残る**。ディラックの海（真空＝負エネルギー状態が電子で満杯）→ やる夫が**穴＝正電荷の粒子を自力で予言** → 1932年アンダーソンの陽電子、対生成・対消滅。
- **真の病巣**：箱を $\Delta x \sim \hbar/(m_ec) \approx 4\times10^{-13}\mathrm{m}$（0.4pm、コンプトン波長）まで絞ると閉じ込めエネルギーが電子・陽電子対を生む。**「1粒子の波動関数」という枠組み自体が相対論と両立しない** → 場の量子論へ。「粒子は場の励起」。

## 第2幕　誰も見ていない回転 ── 対称性と保存則

- **自然単位系** $\hbar=c=1$、換算率 $\hbar c \approx 197\,\mathrm{MeV\cdot fm}$。やる夫が電子質量0.5 MeVから第1幕の$4\times10^{-13}$mを再現して換算機として検算。
- 全体位相 $e^{i\alpha}\psi$ は観測できない → やる夫は「文字通り何も言ってない」と切り捨てる → **ネーターの定理**。既知のペア（空間並進→運動量、時間並進→エネルギー、回転→角運動量）。
- **第1幕でゴミ箱に捨てた $j^\mu = i(\phi^\ast\partial^\mu\phi - \phi\partial^\mu\phi^\ast)$ の復活**。$\partial_\mu j^\mu=0$ を検算 → **「符号が両方あって困らない量」＝電荷**。位相回転対称性→電荷保存が辞書に加わる。パウリ・ワイスコップの1934年の読み替え。
- **実場の検算**：$j^\mu \equiv 0$ → 位相対称性がない → 電荷が定義できない → **中性粒子は実場、荷電粒子は必ず複素場（＝反粒子を伴う）**。
- 幕末に**「$\alpha$ が定数だという意味を、宇宙のスケールで想像してみろ」**という次幕への振り。

## 第3幕　「一斉に」への疑い

- **「『全宇宙で一斉に』って、誰がやるんだお」**。アンドロメダ（250万光年）と位相の基準を共有する物理的理由がない。一般相対論の座標選択の自由と同じ匂い。
- 大域変換と局所変換。$\partial_\mu\phi \to e^{i\alpha}(\partial_\mu\phi + i(\partial_\mu\alpha)\phi)$ の**寄生虫**。
- **道A（局所対称性は成り立たないと認める）と道B（成り立つべきだと要請し理論を作り替える）の分岐**。やる夫は道Bを選ぶ → **ゲージ原理**。
- **三つの問い**：問1 微分の修理／問2 打ち消し係の場の運動法則／問3 打ち消し係の正体（**保留：「お前がすでに何年も前から知っている場だ」**）。
- **できる子の第一関門**：できる夫の「力の正体は対称性」を止め、「いま何を証明していないか」を言わせる。やる夫「その何かが力の正体だという保証は、この時点では一つもないお」。

## 第4幕　道具の構築 ── 対称性を担ぐ数学

- **4-1 場のラグランジアン**。「運動方程式があれば十分では」に対し、**方程式だけから対称性を網羅できるか**という試験で必要性を示す。$\mathcal L = \partial_\mu\phi^\ast\partial^\mu\phi - m^2\phi^\ast\phi$ から場のEL方程式でKG方程式を検算。ディラック場 $\mathcal L = \bar\psi(i\gamma^\mu\partial_\mu - m)\psi$ を部品表として渡す。
- **4-2 ネーターの定理の一般形**。$\delta\mathcal L$ を展開しEL方程式を代入 → $j^\mu \equiv \frac{\partial\mathcal L}{\partial(\partial_\mu\phi)}\Delta\phi$。**「保存流の自動販売機」**。第2幕の電流を製造機から再出荷（全体符号は電荷の正負の約束の違い）。実場は「入れる硬貨がない」。時空並進を入れると $T^{\mu\nu}$（一般相対論で使った量の出生地）。
- **4-3 共変微分の再発明**。**やる夫の安直案 $D_\mu\phi \equiv \partial_\mu\phi - i(\partial_\mu\alpha)\phi$ を「$\alpha$ は理論の中に存在する量じゃない」と自己添削**。微分の定義に戻り**「基準の違う2つの数をそのまま引き算していた」＝円とドルの換算なしの引き算**。ゲージ場 $A_\mu$ を接続として $D_\mu\phi = \partial_\mu\phi - ieA_\mu\phi$。$A_\mu \to A_\mu + \frac1e\partial_\mu\alpha$ を逆算 → **「打ち消し係の正体は電磁ポテンシャル」で第3幕の保留を回収**。見え方の逆転（ゲージ不定性は欠陥や便宜でなく、位相基準の選択自由の影）。**最小結合**でネーター電流との結合 $eA^\mu j_\mu$ が自動で生える。

- **4-4 場の強さ＝内部空間の曲率**。やる夫の $-\frac12\partial_\mu A_\nu\partial^\mu A^\nu$ 案が $\partial_\mu\partial_\nu\alpha$ の対称性で死ぬ → **死因が次の一手を指す（反対称に組め）** → 一般相対論の $[\nabla_\mu,\nabla_\nu]$ を思い出して $[D_\mu,D_\nu]\phi = -ieF_{\mu\nu}\phi$。$F_{\mu\nu}=\partial_\mu A_\nu - \partial_\nu A_\mu$ はゲージ不変。**「電磁場は位相という内部空間の曲率」**。ビアンキ恒等式に対応する $\partial_{[\lambda}F_{\mu\nu]}=0$ がソースなしマクスウェル2本。$\mathcal L_A = -\frac14 F_{\mu\nu}F^{\mu\nu}$ から残り2本。

## 第5幕　質量の危機 ── 真空が対称性を隠す

- **5-1** フェルミ理論 $G_F \approx 1.17\times10^{-5}\,\mathrm{GeV^{-2}}$。次元解析 → $\sigma \sim G_F^2E^2$ → **300 GeV でユニタリティ破綻**。到達距離 $10^{-18}$m から $m_W \sim 200$ GeV（**100 GeV級**）。
- **5-2 二つの素朴案の死**。案1（質量項を手で書く）＝4-5の判定で死ぬ。案2（**開き直ってゲージ不変性を捨てる**）＝縦偏極 $\varepsilon_L^\mu \approx p^\mu/m_W$ で $\mathcal M \sim g^2E^2/m_W^2$、**1 TeV でまた破綻**（「病巣を切除したつもりが転移していた」）。くりこみ可能性も壊れる。
  - **要求仕様(1)〜(4)**：(1) SU(2)ゲージ不変（ユニタリティとくりこみ可能性のため妥協不可）／(2) Wは約100 GeV／(3) 光子は厳密にゼロ／(4) フェルミオンにも質量。
  - **転回点**：やらない夫「本当にそれを証明したか？　証明した命題を一言一句正確に言え」→ **証明したのは「ラグランジアンに書けない」であって「真空まわりの励起が質量を持てない」ではない**。
  - **鉄の棒の磁化**（法則は回転対称、基底状態は特定方向を選ぶ）＝**対称性の自発的破れ**。
- **5-3 メキシカンハット**。**「第1幕で病気にかかり、第2幕で電荷を運び、第3幕で微分を壊され、第4幕でずっと共変微分の練習台にしてきた」複素スカラー場が主役に昇格**。$\mu^2<0$、$\rho^2 = -\mu^2/2\lambda \equiv v^2/2$。$\phi = \frac{1}{\sqrt2}(v+h+i\chi)$ → $m_h^2 = -2\mu^2>0$、$m_\chi = 0$（**谷底に沿う方向は完全に平ら＝復元力ゼロ**）。**ゴールドストーンの定理**が新たな危機（質量ゼロスカラーは未発見）。やらない夫の突き返し＝**「お前が破った対称性は大域的か、局所的か」**。
- **5-4 ヒッグス機構**。極座標表示 $\phi = \frac{1}{\sqrt2}(v+h)e^{i\chi/v}$ → **局所対称性なら $\alpha(x)=-\chi(x)/v$ で $\chi$ を丸ごと吸収できる**（ユニタリーゲージ）。$(D_\mu\phi)^\ast(D^\mu\phi)$ から $\frac{e^2v^2}{2}A_\mu A^\mu$ → **$m_A = ev$、ラグランジアンには指一本触れていない**。「質量とは、真空にまとわりつかれる度合い」。**自由度の会計検査：破れの前 2+2=4、後 1+3=4** →「$\chi$ は消滅したのでなくゲージ場の縦偏極に転職した」。
  - **電弱理論**。$SU(2)\times U(1)$、$W^{1,2,3}_\mu$ と $B_\mu$ の計4本、$\langle\phi\rangle=\frac{1}{\sqrt2}(0,v)^T$。**「4つの生成子のうち、この真空を消すものはどれだ」→ やる夫は4つとも動かすと結論し不合格 → 「4つのうち1つかとは言っていない」→ 生成子の一次結合 $T^3+Y/2$ だけが真空を消す**。破れた3方向→$W^\pm,Z$、残った1方向→光子、残るスカラー1個→ヒッグス粒子。**「電荷とは、生き残った対称性の名前」**。

  - 混合：$A_\mu, Z_\mu$ の定義、$\tan\theta_W = g'/g$、$m_W = gv/2$、**$m_Z = m_W/\cos\theta_W$（質量比が予言になる）**。$v = (\sqrt2 G_F)^{-1/2} \approx 246$ GeV、$g\approx0.65$ → $m_W \approx 80$ GeV、$\sin^2\theta_W\approx0.23$ → $m_Z \approx 91$ GeV。

## 第6幕　理論の答え合わせ

**検証は4本立て（精密検証1本＋事前予言の的中3本）**。
1. **電子の異常磁気モーメント**。やる夫が $a_e^{(1)} = \alpha/2\pi \approx 1/861 \approx 0.001161$ を手計算し、実測 $0.00115965218\ldots$ と**3桁目まで一致**。総力戦では**12桁目まで一致**（東京・ロサンゼルス間を髪の毛の太さ以下の誤差で）。
2. **中性カレント**。1967年の提案時点で観測ゼロ、1973年 CERN ガーガメル。やる夫「足さないと勘定が合わない」。
3. **W・Z の質量**。1983年 UA1・UA2、$m_W\approx80.4$、$m_Z\approx91.2$ GeV。翌年ノーベル賞。
4. **ヒッグス粒子**。48年間未発見、2012年7月4日 ATLAS・CMS、125 GeV。**質量は予言しない（$\lambda$ が未知）が結合の仕方は完全に指定する**。

- **やる夫の総括**：死因の列挙＝「負確率だから捨てる」は捨て方が間違い、「$\sqrt{\ }$」は非局所、「$(\partial A)^2$」はゲージ変換、「U(1)の完コピ」は非可換性、「質量項を強行」はユニタリティ。**「一個ずつ死因を確定させていったら、生き残った道が標準模型しかなかった」**。
- **4つの力が全部「人間の記述の自由」を担保する接続の理論**という気づき → やらない夫「**この教材でお前が組み上げた標準模型に、重力だけが入っていない**」→ 二つの物語は同じ崖の上で終わる。
- **できる子の最終採点**：序幕の三問に答えさせ、**「三つ目に一つ足りない。当たった話しかしていない」** → やる夫が**外れる可能性がどこにあったか**（$m_W/m_Z$ の比、ヒッグスの結合の比例性、重力が組めていないこと）を追加 → 合格。
- できる夫が投影資料の最後を**「標準模型、再発明成功」→「四つの力のうち三つ。残り一つは、まだ誰も」**へ差し替える。

- **「安直案 → 自分で計算 → 自分で不合格判定 → 死因の言語化 → 死因が次の一手を指す」という反復様式が本書の学習単位**。主なもの：KG方程式（負確率）、平方根の級数（非局所）、$-\frac12(\partial A)^2$（$\partial_\mu\partial_\nu\alpha$ の対称性）、U(1)完コピ（非可換性）、質量項の強行（ユニタリティ）、4つの生成子（一次結合を忘れる）。**4-4 でやらない夫が「判定を待たずに転べるようになったのは進歩だ」と明示的に評価する**ので、この様式は成長の指標として機能している。前半で判定を待ち、後半で自分で潰す、という順序を崩さないこと。
- **退化検算（特別な場合に戻ることの確認）が二か所**：4-6 の $U$ が1×1のとき4-3の変換則に戻る、$[A_\mu,A_\nu]=0$ のとき4-4の $F$ に戻る。「上位互換だお」という言い回しで統一されている。
- **できる子の関門は4回（3幕末・4-4末・5-4末・終幕）で、いずれも「言い過ぎの訂正」を強制する**。4-4「導かれる→一意に決まる」、5-4「二つの予言→一つの理論への二重の検査」、終幕「当たった話しかしていない→外れる可能性を言え」。**この訂正が本書の科学方法論の主張そのもの**なので、一つ削ると主張が弱くなる。できる夫の先走り（標語・告知・投影資料）と必ずペアで出るので、片方だけ消せない。
