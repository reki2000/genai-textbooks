# 改稿記録

`review-opus-medium.md` の指摘8点に沿って改稿した。

## 工夫した点・主な変更

- **物語の圧力を、前作と同じ装置で導入した。** 序幕を新設し、できる夫が続編『残り三つの力を、日曜までに』を勝手に告知、できる子が三問（力が四つでその形になる理由／質量の出どころ／思いつきでないことの確かめ方）を出す形にした。本教材は一般相対論編の直接の続編なので、登場人物の紹介文と口調を前作と同一にして、二作を同じ舞台の連作として読めるようにした。できる子は断定と短文だけで話し、できる夫は告知と投影資料の話しかしない。

- **できる子の出番を「褒める場所」ではなく「主張を削る場所」に置いた。** 第3幕末では「いま何を証明していないか」を言わせ、4-4末では「電磁気学を1ミリも仮定していない」というやる夫の高揚に対して入れた仮定を四つ数えさせ、「導かれる」を「一意に決まる」へ訂正させた。5-4末では $m_W$ と $m_Z$ が独立な二つの予言ではなく一つの理論への二重検査であることを言わせた。終幕では三問への答えに対し「当たった話しかしていない」と差し戻し、どこで負けるはずだったかを追加させている。教材が最も自画自賛に傾く4か所に、正確さを要求する声を置いた。

- **電弱理論の山場を伝聞から自分の計算に変えた（指摘1）。** やらない夫は真空 $\langle\phi\rangle=\frac{1}{\sqrt2}(0,v)^T$、生成子 $T^a=\sigma^a/2$、超電荷 $Y=1$ だけを渡し、「4つの生成子のうち、この真空を消すものはどれだ」と問う。やる夫は4本を一つずつ作用させて全部ゼロにならず一度不合格を出し、「1つとは言っていない」と指摘されて一次結合に気づき、$T^3+Y/2$ だけが真空を消すことと、$T^1,T^2$ は上成分を作るので打ち消す相手がいないことまで自分で確認する。そこから $Q=T^3+Y/2$、$\tan\theta_W=g'/g$、$m_Z=m_W/\cos\theta_W$ を書かせた。$\phi^+,\phi^0$ の肩の記号が自分の計算の答え合わせになる、という回収を仕込んだ。

- **理論名を後出しにした。** 改稿前は「電弱理論だ」と名前を先に告げてから構成を並べていた。名前を出す位置を計算のあとへ移し、「いま15分で通した道を、彼らは10年かけて通っている」に変えた。名乗りが先にあると、その後の計算は答え合わせにしかならないため。

- **非可換ゲージ場の変換則を逆算させた（指摘2）。** U(1) では逆算させているのに行列版で手を離していた箇所を、完コピ案 $A_\mu \to A_\mu+\frac{1}{g}(\partial_\mu\alpha^a)\sigma^a/2$ を出させ、$D_\mu\psi\to UD_\mu\psi$ に代入して $U$ を右からしか剥がせないことに気づかせる往復に置き換えた。死因を「$A_\mu$ と $U$ を勝手にすれ違わせて $UU^\dagger=1$ で消せると思い込んだ」と本人に言語化させ、既存の退化検算を「完コピ案は可換な場合にだけ正しい式だった」という位置づけに読み替えた。直後の $[A_\mu,A_\nu]$ の必然性が上がる。

- **第6幕を年表から検算に変えた（指摘3）。** シュウィンガーの1ループ $a_e=\alpha/2\pi$ をやる夫に暗算させ、$1/861\approx0.001161$ と実測 0.0011597 を並べて3桁一致を自分で確認させてから12桁の話へ進む形にした。W・Z の質量も、やらない夫が値を告げる形をやめ、第5幕でやる夫が出した 80 GeV と 91 GeV を検査票として持ち出させた。中性カレントについても「後出しじゃない、正真正銘の予言だお」という相槌を、5-4の自由度勘定に戻る発言（$Z$ を出さずに済ませる選択肢がない）に差し替えた。

- **参考文献を全16点の Wikipedia から一次資料へ差し替えた（指摘4）。** Klein/Gordon/Schrödinger、Dirac 1928、Anderson 1933、Noether 1918、Heisenberg 1932、Yang–Mills 1954、Fermi 1934、Goldstone 1961、Englert–Brout / Higgs / Guralnik–Hagen–Kibble 1964、Glashow 1961 / Weinberg 1967 / ’t Hooft–Veltman 1972、Wu 1957、Schwinger 1948、Gargamelle 1973、UA1/UA2 1983、ATLAS/CMS 2012、Gross–Wilczek / Politzer 1973。数値（光子質量上限、核子質量、$G_F$、$m_W$、$m_Z$）は PDG の該当節に紐づけ、各項に対応する幕を明記した。前作と同じ書式に揃えている。

- **湯川項を添字の勘定の帰結にした（指摘5）。** 完成形をいきなり出す形をやめ、$(\bar\psi_L)_i\psi_R$ で $i$ が1本余ることを確認 → 余った添字を潰す相手が要る → ダブレットの $\phi_i$ がちょうどその添字を持っている、の順に組ませた。「質量項が禁止されたのは、相手が足りなかったから」という一文で、禁止と処方を同じ言葉で結んだ。

- **強い力を宣言から導出へ昇格させた（指摘6）。** QED の真空偏極（遮蔽）を足場にして、グルーオンが色荷を持つ以上グルーオン対の寄与が加わることをやる夫に言わせ、ベータ関数 $-\frac{g^3}{16\pi^2}(\frac{11}{3}N_c-\frac{2}{3}n_f)$ に $N_c=3,\ n_f=6$ を入れて $11-4=7>0$ を計算させた。符号が正だから結合は高エネルギーで減る、という一行で漸近自由と閉じ込めを同じ計算から出している。4-6で自分が見つけた $g^2A^4$ 項の回収になるよう、やらない夫の振りをその項への参照から始めた。

- **ビートの単調さを崩した（指摘7）。** 4-4 の運動項の素朴案を、やらない夫の「では判定してもらおう」で始まる型から、やる夫が「判定は待たなくていいお」と自分で代入を始めて途中で手が止まる型へ変えた。さらに死因（$\partial_\mu\partial_\nu\alpha$ が対称で逃げ場がない）を自分で言わせ、そこから「対称なゴミが消えないなら反対称に組めばいい」という次の一手へ直結させたので、$F_{\mu\nu}$ の導入が電磁気の記憶からの連想ではなく死因からの帰結になった。

## 残した判断

- 一般相対論との対応表（接続・曲率・自己相互作用）、捨てた $j^0$ が電荷密度として戻る回収、4-3の「基準の違う2つの数を引き算していた」、1424行目相当の「証明した命題を一言一句正確に言え」は、レビューで白眉と評価された骨格なのでそのまま維持した。

- タイトルは「力を再発明する」のままとした。指摘6で「強い力を1節に昇格させるか、タイトルを絞るか」の二択が示されていたので、前者を採った。漸近自由を計算として入れたことで、$SU(3)$ が宣言だけで終わる不均衡は解消している。

- ヒッグス粒子の結合が質量に比例することの精査結果、$a_e$ の12桁、$G_F$ などの数値は、いずれも本文が既に持っていた内容を一次資料に紐づけただけで、新しい数値や事例は持ち込んでいない。
