# 寸評：やる夫で学ぶ電力系統 ── 電力会社CTOになって電気を作り直す

約78KB／プロローグ＋全8幕。「電気は在庫を持てない」の一言から始め、周波数制御・送電・無効電力・信頼度・日本の50/60 Hz・脱炭素・市場設計までを、やる夫の素朴案を毎幕殺すことで一本に通した教材。

## 良い点

**3本の伏線が幕をまたいで実際に効いている。** 「貯められない」（23行目）、「直流は送電では死んだ」（395行目）、「慣性は第7幕で失う」（145行目・215行目）の3本が、それぞれ 1125–1129行目（間接的な在庫）、941–944行目（FCで直流が蘇る）、1060–1066行目（インバータで慣性ゼロ）で回収される。しかも 1295–1299行目でその3本を明示的に束ね直しており、読者が「バラバラの知識ではない」と確認できる。宣言した伏線を全部払っている教材は少ない。

**離島グリッド（3台×100 MW、需要150 MW、60 Hz）という反復トイ例が計算の共通座標になっている。** 10行目で定義され、178行目のRoCoF 1.9 Hz/s、256行目のドループ 0.6 Hz、693行目のN-1判定、1074–1078行目の慣性喪失後のRoCoFと、4回同じ舞台で数値が積み上がる。抽象概念が毎回同じ系統の同じ数字に落ちるので、幕をまたいだ比較が読者側でできる。

**「速さごとに担当を分ける」という発見のさせ方が上手い。** 電話案を殺すのに人間の応答時間（分）と事故の時間スケール（秒）が3桁違うことを、RoCoFの計算値1.9 Hz/sから やる夫自身に言わせている（180–194行目）。その結果として得られる4層構造（315–318行目）が、天下りの分類表ではなく「一人に全部やらせた失敗の修正」として立ち上がる。

**Q-Vデカップリングを数値で二度確かめさせている。** 613行目の2式を睨ませて 619–624行目で分離を言わせた後、636–647行目で $X=10\,\Omega$、$V=100$ kV に実際の数字を入れ、無効50 Mvarでは5%の電圧降下、有効50 MWでは位相2.9度だけ、と両方を計算させる。「主に決めるのは別の変数」という主張が標語で終わっていない。

**三大停電の教訓を「発端」と「致命傷」に分けて整理させている。** 871–878行目で、木の枝／計画停止／嵐という発端はいずれもありふれており、殺したのは見えなかったこと・勘で操作したこと・設定と低慣性であると やる夫にまとめさせる。単なる事故年表になっていない。さらに 857–865行目で「再エネが悪い」と「ライドスルー設定の不備」を峻別させており、政治的に荒れやすい題材を扱う手つきが慎重。

**8-3の要請駆動設計が第5幕の候補棄却法を再利用している。** 1223–1229行目で要請7項目を並べ、候補A/B/Cを順に殺し（1237–1246行目）、「一つの電源では全要請を満たせない」→ポートフォリオ（1254–1261行目）へ落とす。最終幕が総復習ではなく、それまでの武器を使った設計演習になっている。

## 欠点

**物語的な圧力が一切ない。** CTO就任という設定はあるが、期限も予算も利害関係者も事故も起きない。全8幕が「やらない夫が問う→やる夫が素朴案を出す→殺される」の家庭教師セッションで、1290行目で やる夫自身が「全部きれいに間違ってた」と言う通り、8回とも同じ型である。1281–1288行目の答え合わせリストが、そのまま構造の単調さの自己申告になってしまっている。同リポジトリの thermodynamics 教材にある「刷ってしまった横断幕」「あと3日」に相当する駆動力が皆無。

**登場人物が2名で、都合の悪い数字を突きつける役がいない。** 数値は全て やらない夫が与え、やる夫が代入する。実測値がやる夫の思い込みを裏切る、という構図が一度も発生しない。CTOという設定にしたのに、運用部門・財務・現場の声が一切登場しないのは舞台の無駄遣いで、8-1の総括原価や8-2の容量市場（1197–1204行目）も対話ではなく講義になっている。

**第3幕後半と第8幕前半が再発見ではなく歴史講義。** 3-2（400–447行目）は電流戦争、3-3（456–480行目）は周波数規格、8-1（1152–1168行目）はインサルと総括原価だが、いずれも やらない夫がほぼ独りで喋り、やる夫は「えげつないお」「大型化と同じだお」と相槌を打つだけ。特に3-3は「50 Hzと60 Hzのどちらが技術的に有利か、やる夫に予想させてから、実際は先に据え付けた者が勝ったと明かす」という再発見の形にできたはずの題材を、最初から結論（478行目）で配ってしまっている。

**3-1の $I^2R$ 例が物理的に破綻している。** 343–353行目で 50 MW を 5 kV・$R=1\,\Omega$ で送ると損失100 MW、つまり送る電力の2倍が線路で消える。やる夫も「送る量の倍を熱で捨ててる」（356行目）と驚いているが、これは送電端で $P=VI$ が成立するという前提と矛盾しており（そんな動作点は存在しない）、教育的誇張としても読者が引っかかる。損失率を数%に収める現実的な数値でも、電圧100倍→損失1万分の1という核心（366–369行目）は完全に示せる。

**7-2の数値が第2幕の離島と接続していない。** 1070–1078行目で $\sum HS=1200$ に対し「100 MWの電源脱落」を置くが、この離島は3台×100 MVA で需要150 MW、つまり各機の出力は50 MWである（99行目・693行目）。100 MW脱落する主体が系統内に存在しない。しかも第2幕の記憶に残る数字は 1.9 Hz/s なのに、ここでは前提の違う 2.5→3.75 Hz/s が出るため、「脱炭素で何倍脆くなったか」の比較が読者の頭の中で一度リセットされる。同じ 50 MW 脱落で 1.9→2.8 Hz/s と示せば、第2幕と直結した。

**やる夫が跳びすぎる箇所がある。** 584–587行目で、無効電力の命名を促されただけで $P$/$Q$/$S$ の三者と $S^2=P^2+Q^2$ まで一息に出す。名前を付けるのと直角三角形の関係を導くのは別の作業で、後者には電流の同相・直交分解という一手が要る。同様に 1102–1118行目の「失った機能と埋め方」の棚卸しは、グリッドフォーミング・インバータやSVC/STATCOMまで やる夫が列挙しており、初出の固有名詞を生徒が知っている状態になっている。

**参考文献セクションがない。** 5500万人・60億ドル（748行目）、RoCoF 平均 −6.25 Hz/s（837行目）、ライドスルー6回→20回（859行目）、FC 120万kW→210万kW→300万kW（976行目・986–987行目）と、検証可能な公式報告書が存在する数字を多用しているのに出典が一つもない。thermodynamics 教材が本文の対応箇所つきで7点挙げているのと比べて、明らかに揃っていない。

## 改善案

1. **第三のキャラクターを入れて、数字を人から出す。** 運用部門の「できる子」型（実測値だけを読む役）を人物紹介（4–10行目）に追加し、178行目のRoCoF、256行目の落ち着き先59.4 Hz、1074–1078行目の慣性喪失後のRoCoFを、やらない夫の出題ではなく計測結果として提示させる。特に第7幕は「先月の再エネ比率上昇後、実際にRoCoFがこう変わった」という現場データにすれば、伏線回収が説教から観測になる。

2. **物語的な期限を1本通す。** プロローグ（13–41行目）に「3か月後に取締役会で2050年に向けた設備投資計画を通す」を置き、8-3（1216–1268行目）をその取締役会当日にする。さらに中盤（第5幕あたり）に猛暑ピーク当日の実運用を1シーン挟み、予備力を削るか料金を上げるかの判断を やる夫にさせれば、第2幕の「保険料」（310行目）が抽象論から実務判断に変わる。分量増は数十行で足りる。

3. **7-2の数値を第2幕と揃える。** 1070–1078行目を書き換え、第2幕と同じ「50 MW脱落」に固定した上で、3台とも同期機のとき 1.9 Hz/s（第2幕の値そのもの）、1台をインバータ電源に置換すると $\sum HS=800\to400$ で 3.75 Hz/s、2台置換で 7.5 Hz/s と段階的に計算させる。最後の値が 841行目の南オーストラリア −6.25 Hz/s を超えることを やる夫に気づかせれば、第5幕の実例と第7幕の予測が一本の直線で結ばれる。

4. **3-1の数値例を作り直す。** 343–353行目を、たとえば「5 kVで送ると損失が送電量の20%、線路の電圧降下も20%で受電端が成立しない」という、実在しうる動作点に置き換える。その上で 500 kV では損失が0.02%になることを計算させれば、破綻した例に頼らずに「電圧の2乗に反比例」（372行目）が示せる。

5. **3-3を再発見型に組み替える。** 456行目の前に、やらない夫が「周波数を高くする利点・低くする利点」だけを与え、やる夫に最適値を推定させる（変圧器の鉄量、フリッカ限界、回転数と極数の制約）。やる夫が「40〜60 Hzのどこかが最適」と結論したところで、467–470行目の史実（AEGは40 Hzのチラつきで50 Hzへ、米国は60 Hz、ナイアガラは水車の都合で25 Hz）を出し、技術的最適が一意でないところに経路依存が入り込んだのだと自分で言わせる。478–480行目の結論を配る順序が逆になる。

6. **参考文献を追加する。** 末尾（1330行目付近）に、U.S.-Canada Power System Outage Task Force 最終報告（2004）、UCTE Final Report on the Disturbance of 4 November 2006、AEMO "Black System South Australia 28 September 2016" 最終報告、Kundur "Power System Stability and Control"、電力広域的運営推進機関のFC増強計画、を本文の対応幕つきで挙げる。748行目・837行目・859行目・986行目の数値に脚注を付ける。

7. **8-2のミッシングマネーを一度計算させる。** 1197–1204行目は概念説明で終わっているので、離島グリッドで数字を入れる。年間10時間しか動かないピーク電源が、スポット価格だけでは固定費を回収できないことを やる夫に電卓で確かめさせ、その不足額（＝ミッシングマネー）が容量市場の対価に等しいと自分で気づかせる。市場設計が「物理の翻訳」だという 1210行目の主張が、初めて実感になる。
