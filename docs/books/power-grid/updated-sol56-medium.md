# 改稿記録

## 工夫した点・主な変更

- プロローグに「3か月後の取締役会」という期限を置き、第8幕の採決へ回収した。中盤には猛暑日の需要上振れとN-1不足を加え、知識だけでなく運用判断と費用の圧力が働く物語にした。
- 中央給電指令所の「できる子」を追加し、RoCoFや需要予測を実測・運用データとして提示させた。やらない夫が数字をすべて与える講義型を緩和した。
- 低圧送電例を、受電端50 MW、線路抵抗0.1 Ω、送電端6 kVという成立可能な動作点へ修正した。500 kV化で損失が1万分の1になる核心は維持した。
- 周波数規格は、高低それぞれの利害からやる夫が40〜60 Hzを推定した後、史実と経路依存性を示す順序へ変更した。
- 無効電力は、命名と $S^2=P^2+Q^2$ の導出を分離し、同相・直交電流の分解を一段挟んだ。
- 第7幕は第2幕と同じ50 MW脱落に統一し、事故後の慣性を $800\to400$ MJ、RoCoFを $1.9\to3.75$ Hz/sとして直接比較した。対策技術も、やる夫が必要機能を先に考え、できる子が固有名詞を与える構成にした。
- ミッシングマネーを40 MWのピーク電源で計算し、容量市場が埋める対象を金額とkW単価で可視化した。
- 三大停電、系統安定度、東西FC増強について、本文の対応箇所が分かる参考文献節を追加した。

## 残した判断

- 既存の離島グリッド、全8幕、3本の伏線、三大停電の比較、要請駆動のポートフォリオ設計は教材の強みとして維持した。
- 3台中2台をインバータへ置換した場合の「7.5 Hz/s」は、同じ50 MWの発電機脱落後にどの電源が残るかを固定すると元の3台構成では一意に作れないため採用しなかった。比較条件を明示できる $1.9\to3.75$ Hz/sまでに留めた。
- 容量市場の数値例は仕組みを掴むための単純化であり、希少時価格・相対契約・制度ごとの細部が収益を変える旨を本文に残した。
