# 寸評：やる夫が第二の脳を作るようです ── 外部化と検索の再発見

約276KB／全8幕＋幕間2。同僚の退職に伴う引き継ぎ資料という実務課題を軸に、索引・参照・出所・時点・形式化・検索から「外に置けないもの」までを、たった3行のカードを7回書き直す形で通した教材。

## 良い点

**「このカードは見つかるか」という反復判定装置が、教材全体の背骨として最後まで機能している。** 535–543行目で「①半年後のやる夫、②来月入る新人、③機械」の三人を明示的に設置し、1-7で全滅（580行目）、7-8で全員合格（4934行目）に至る。しかも判定基準自体が幕ごとに上がっていく：③は5-10で「引けるか」から「機械が正しく答えられるか」へ格上げされ（3651行目）、①は6-6で「引ければ合格」から「いつの話かを間違えずに引ければ合格」へ変わる（4193行目）。読者は7回の同一フォーマットで自分の理解の前後差を測れる。

**トイ例が最初から最後まで同じ3行である。** 401–402行目で書いた値引きカードが、2-7で索引語8つ、3-8で番号47と線2本と議事録番号、6-6で版と有効期間、7-5で6層表へと育ち、8-1で最初の3行を読み返して「間違ってたのか」→「正しいのに使えない」（5219–5225行目）に着地する。円環がきれいで、しかも終点で最初の1枚を捨てずに「転んだ場所の記録」として残す（5503行目）という処理まで付いている。

**物語的な圧力が装飾でなく論証を駆動している。** 橋本さんが来月退職（20–23行目）、課長が「お前がいなくても回るか」と有給5日の抜き打ち試験を課す（4242–4251行目）、木曜に真下さんが一部解約で3時間止まり有給中のやる夫の携帯に電話（4260–4263行目）。この電話が「やる夫は360通りを持っていないのに30秒で答えた」（4491–4493行目）という第7幕の中心問題を生んでおり、期限と事故が理論の要求そのものになっている。

**「両側で失敗させる」型の反復。** 粒度は細かすぎ（1447–1454行目）と粗すぎ（1459–1465行目）の両方で潰し、陳腐化は全部残す（3813–3819行目）と最新だけ残す（3825–3829行目）の両方で潰してから、共通の欠け＝期間を自分で言わせる（3841–3844行目）。素朴案を1回殺す型より一段強く、「答えは中間にある」ではなく「両方の失敗が同じものの欠如を指す」という論証になっている。

**史実を出す順序が正しい。** 2-3では、やる夫が「章を7つに等分してa〜gで呼ぶ」を自力で言い切ってから（819–822行目）、実際にそれが使われたと明かす（825–829行目）。3-2の枝番21/1（1355–1357行目）、5-2の「周りの語を軸にする」（2979–2984行目）も同じ順序。10回の夢のうち少なくとも前半は、歴史が答え合わせとして働いている。

**計算が全部、案の生死に直結している。** 巻物を1本1分で3年以上（713–715行目）、1,500万枚で125年（1642–1644行目）、3行のカードから前提9個→34項目で3,000個超（3186–3202行目）、リンク切れ1,026／3,000＝34%（3975–3976行目）、日報1万件で83時間（4715–4717行目）。どれも「網も形式も正しいが費用で潰れる」（3218行目）という同一の結論へ収束する。

**参考文献28点が本文の対応箇所つきで付いている（5545–5599行目）。** Furnas の0.20（4-1の中心数値）、NevIR、reference rot の「10本に7本」まで、本文の具体数がすべて脚注に紐づく。[^16] と [^24] では「モデル世代で状況が変わりうる」「言語決定論は取らない」と留保まで書いてある。

## 欠点

**やる夫の「商売を思いつく」ギャグが15回以上、全部同じ型で回る。** 要約商売（369–371行目）、カードデッキ（444–446行目）、情報整理コンサル（956行目）、正本管理士（1100行目）、思考ルート集（1574–1576行目）、捨てる情報コンサル（2039–2041行目）、選択マトリクス（2138行目）、印1個100円（3285行目）、業界標準オントロジー（3541行目）、主張5点セット（3948行目）、資格試験（4413–4416行目）、例外報告ピラミッド（4749–4751行目）、外部化検定（4959行目）。すべて「思いつく → 自分で条件に気づいて撤回する」の同一パターンで、5回目あたりから笑いではなく段落の区切り記号として読める。

**夢の枠が後半で形骸化している。** 1-2の王、2-2の巻物館、2-3の修道院は場所と人物に手触りがあるが、5-4のCyc部屋（3128–3137行目）と7-4の会議室（4513–4520行目）は「変な部屋だお → やらない夫が説明する」だけで、夢である必然性がない。特に7-4はホワイトボードに四角が4つ描いてあるという以外の描写がなく、同じ内容を現実の場面で話しても何も失われない。

**やらない夫の台詞の型が固定されすぎている。** 「なるほど、そう来たか」「おっと、気が早いぞ」「まあ落ち着け」「判定してもらおう。反例をやる」「そこだ」「名前を付けとくぞ」がほぼ全節に同じ配置で出る。3幕を過ぎると、やる夫が案を出した次の行に何が来るかが読む前に分かる。反復判定装置の効果と引き換えに、会話の予測可能性が高くなりすぎている。

**定量の水準が幕内で不揃い。** 4-4の余弦は数式（2440行目）と検算（2451–2469行目）まであって出色だが、その直前の4-2は「回数が多くて、かつ全体では珍しい語」（2331行目）で止まり、式も数値例もない。4-5のPageRankも「今日は仕組みの水準までにしておく」（2569行目）で数値なし。4-4だけが計算の島になっており、TF-IDFという最も手計算しやすい部分が言葉だけで通過している。

**5-2の到達点と脚注[^15]の間にギャップがある。** やる夫が再発見したのは周辺語の生カウント（2981–2982行目）であり、そこから「語を数百次元の座標へ落とす方法が作られた」（2988行目）は一行の飛躍。何百万次元の共起表をなぜ数百次元に落とせるのか、落とすと何が起きるのかが省かれているため、5-3以降で「座標」と呼ばれるものの正体が曖昧なまま第6幕まで持ち越される。

**第7幕の最重要結論が、反例を1つも潰さずに立っている。** 「引きに行く判断は、引く前に必要だ。だから外に置けない」（4832–4836行目）が全論証で、これは一段の言い換えに近い。実務では、定型チェックリスト、決裁フローの必須項目、機械側から条件成立時に警告を出すプッシュ型が現に使われており、これらは「引きに行くと決める前」に働く。5-9で「質問が来ないと何も起きない」（3629–3630行目）と言うが、質問を待たない設計を検討せずに一般化しているため、本書で一番強い主張が一番証拠の薄い主張になっている。

**判定③の結論が第2幕と第4幕でほぼ同じ。** 1171–1177行目（機械はやる夫が思いつかなかった語では引けない）と2821–2826行目（やる夫の語彙の外では全滅）は、道具が増えたにもかかわらず同じ文で終わる。7回の判定のうち、この2回は情報量が重複しており、全体276KBの分量に対して圧縮の余地がある。

## 改善案

1. **7-7の結論に、反例を1つ正面から通す。** 4828行目の「なぜ置けない。理由を言え」の直後に、やる夫の反撃を1つ挟む。「見積を出す前に必ず見るチェックリストを置けば、気づかなくても止まるお」と言わせ、やらない夫が「そのチェックリストを見ると決めるのは誰だ」と返し、さらにやる夫が「システムが見積画面で強制表示するお」と食い下がる。ここで「強制表示できるのは、条件が事前に書けている例外だけだ。7-3の360通りの外は表示されない」と落とせば、④例外が半分しか書けない（4802–4805行目）という既出の結論が、そのまま「気づく部分は外に置けない」の根拠になる。現状の一段の言い換えが、本書の他の箇所と同じ「反例で殺す」型に揃う。

2. **4-2にTF-IDFの手計算を1回入れる。** 2331行目の「回数が多くて、かつ全体では珍しい語」の直後に、34項目のうち「お客様」が34項目全部に出て「3月」が2項目にしか出ない、という設定で、$\log(34/34)=0$ と $\log(34/2)\approx 2.83$ をやる夫に計算させる。「お客様」の重みが回数によらずゼロになることを自分の手で確認させれば、2314–2322行目で言葉だけで言った「どこにでも出てくる語は区別に使えない」が数字になり、4-4の余弦計算と定量の水準が揃う。

3. **商売ネタを半減し、残す分に別の機能を与える。** 現状15回以上のうち、幕ごとに1回（計8回程度）へ削る。残すものは「自分で撤回する」型を捨てて、実際に会社の圧力になる形へ変える。例えば3285行目の「印1個100円」は、8-3の2件目（4429行目、課長が「そんな時間はない」と言う場面）で「では印付けを評価項目に入れてください」という実務の交渉として再登場させる。5-5で学んだ「書く人が得しないと書かれない」（3264行目）が、ギャグでなくやる夫の行動として回収される。

4. **5-2に、共起カウントから低次元座標への一段を足す。** 2984行目と2988行目の間に10〜20行。やる夫に「会社の文書に出てくる語が5万種類あったら、1語の座標は5万次元だお。しかもほとんどゼロだお」と数えさせ、「『価格』と『料金』は別の軸だけど、周りの語がほぼ同じだから、まとめて1本の軸にできるお」と言わせる。次元削減の必要と可能性をやる夫の口から出しておけば、以降の「座標」が何を指すかが確定する。

5. **後半の夢を2つ、現実の場面に戻す。** 5-4のCyc部屋（3128行目〜）は、やらない夫が情報システム部として過去に社内マスタの整備を試みて頓挫した実話に置き換えると、「2,000人年」の外部事例と社内の実感が二層になる。7-4（4513行目〜）は、退職前の橋本さんとの最後の会話に置き換えるのが最も効く。「橋本さんはなぜ一部解約が課長案件だと知っていたのか」を本人に聞かせれば、4548行目の「去年、勝手に金額を変えて怒られた」というやる夫の勘の由来が、橋本さん側にも対になって存在することが見え、5469–5472行目（橋本さんは転んだ場所を書かなかった）の回収が格段に重くなる。

6. **判定③の重複を整理する。** 2-7（1171–1177行目）の③は結論が4-8とほぼ同じなので、ここは「機械」ではなく「文書サーバの全文検索という具体的な機械」に限定し、ファイル名・索引語という当時の道具だけで判定を閉じる。そのうえで「意味で引く機械はまだ手持ちにない」と明示すれば、第4幕・第5幕での③の格上げが階段として読める。

7. **やらない夫の定型句を3割間引く。** 特に「判定してもらおう。反例をやる」は全節に出るため、半分は「じゃあ真下さんに渡してみろ」「橋本さんに見せろ」のような、既に登場している人物へ委ねる形に置き換える。504行目や1433行目のように第三者に判定させる型は既に本文中にあり、それを増やすだけで、教師が反例を出す構図の単調さが薄まる。
