## 主な変更

- 5-4の夢の部屋を、情報システム部で凍結された社内業務マスタ統合案件へ置き換えた。社内の失敗とCycの大規模事例を連続させ、形式化費用を現実の仕事として感じられるようにした。

- 反復していた商売・資格ネタを複数削除した。5-5の印付けは、課長に作業時間と評価を求める実務上の交渉へ変えた。
