## 問いと結論

`catalog.yml` が宣言する問いは、「頭に入らない知識を外へ置くとき、どんな形なら必要な場面で取り出せるのか、人間向けの形と機械向けの形は同じなのか」である。

終幕は、外部化を「忘れても事故にならない置き方」と定義し（L5445–5448）、人は理由と曖昧さ、機械は明示的な条件を必要とするため形がずれると答えている（L3410–3425）。さらに、既知の引き金はチェックリストや強制表示へ移せるが、未知の引き金は完全に列挙できないと限界も明示する（L4882–4923）。問いには直接答えている。
