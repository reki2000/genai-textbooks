# やる夫が第二の脳を作るようです ── 外部化と検索の再発見 の骨格

3000件のブックマークを「第二の脳」と呼ぶやる夫が、一枚のカードを人・検索機械・業務担当へ何度も渡して、保存・発見・解釈・更新・実行の違いを学ぶ。全文保存か要約かの二択を越え、内容に応じて順序、分類、索引、リンク、ベクトル、形式知、手続き、人間の判断を配置する。

## 第1幕　全文を写した墓場
- 1-1　3000件保存しても必要な一件を見つけられず、記録量と利用可能性を分ける。
- 1-2　文字が記憶を弱めるという反論を、外部化が内部記憶を置換する場合と、思考・協働を拡張する場合へ分ける。
- 1-3　全文保存は取り込みが安いほど発見・読解費用を後払いにし、10分で一件探す規模へ破綻する。
- 1-4　要約は検索を助けるが、条件・例外・根拠を落とす。圧縮率と再利用目的の交換を明示する。
- 1-5　一枚の条件つきカードを設置し、以後の各方式で見つかるか・正しく使えるかを反復テストする。
- 1-6　「頭には地図と参考文献だけあればよい」という仮説を立て、第7幕で判定する。
- 1-7　本人・他人・機械という三人の判定者にカードを渡し、同じ記録でも利用者ごとに必要な手掛かりが違うと予告する。

## 第2幕　順序を捨ててアクセスを得る
- 2-1〜2-3　物語・巻物の直列順序は文脈を運ぶが一点アクセスに弱い。名前、分類、章節という合意座標を足して飛び先を作る。
- 2-4　目次は構造順、索引は語から複数位置への逆引きであり、別の発明として使い分ける。
- 2-5　十進分類を世界の唯一の分け方でなく、所蔵・発見目的に合わせた棚として読む。
- 2-6　同じ項目を複数棚に実体複製すると更新がずれるため、正本一つと複数参照を分ける。
- 2-7　一枚のカード(2)。座標と索引語で発見は改善するが、関係や理由はまだ弱い。

## 第3幕　カードとカードをつなぐ
- 3-1　分類された項目は引けても、なぜ結論したかという関係が消える問題を出す。
- 3-2〜3-4　一枚一概念、永続番号、適切な粒度、双方向参照でカード索引と辿った道筋を作る。
- 3-5　世界全体を参照網にする構想は強力だが、リンク作成・維持・読解の費用が増える。
- 3-6　誰でも編集可能にする代わり、出典・履歴・訂正手続きを信頼の根拠にする。
- 3-7　リンク数の多さでなく、必要な問いから根拠へ辿れ、反例や出所を検査できるかで網の価値を測る。
- 3-8　一枚のカード(3)。番号、出所、関連カードを加えるが、語彙が合わない利用者にはまだ見つからない。

## 幕間1　レシピと路線図
- レシピは手順順序を保存し、路線図は実距離を捨てて接続を強調する。外部表現は情報を全部残す器でなく、用途に必要な不変量を選ぶ模型だと判別表にする。

## 第4幕　探せないものは無いのと同じ
- 4-1〜4-2　同義語で一致せず、多義語でノイズが出る。語を増やすだけでは再現率と適合率が衝突する。
- 4-3〜4-4　文書を語のベクトルへ置き、長さでなく余弦方向で近さを測る。表面一致を越える一方、座標化の前提を持つ。
- 4-5　検索順位は内容だけでなくリンク・権威・利用履歴等で変わり、「見つかる」は誰の評価関数かという問題になる。
- 4-6　そもそも問いや検索語を作れない状態では検索装置を使えず、内部知識の限界が残る。
- 4-7　名前、座標、逆引き、出所、関係という五機能は媒体が変わっても残ると総括する。
- 4-8　一枚のカード(4)。既知語なら見つかるが、未知概念からは引けない語彙の壁を残す。

## 第5幕　機械には何を渡すのか
- 5-1　条件と例外を含む文章を類似だけで拾うと、似ている逆結論を返す。
- 5-2〜5-3　分布表現・埋込みで語を使わず意味の近さを測れるが、否定、数値条件、適用範囲に弱い。
- 5-4〜5-5　全部を論理式・知識グラフへ形式化すれば厳密だが、作成費用と書く動機がなく構想が維持できない。
- 5-6〜5-8　一枚を散文・表・規則・グラフで書き比べ、形式化が曖昧な顧客同一性を露出させる。閉じた領域・安定語彙・高い反復価値なら費用に見合う。
- 5-9　検索で候補と根拠を絞ってから生成へ渡し、検索と生成に別の役割を持たせる。
- 5-10　一枚のカード(5)。機械判定者を語検索・ベクトル検索・規則系・生成系へ替え、得意な誤りが異なると確認する。

## 第6幕　古びる知識をどうするか
- 6-1〜6-2　保存カードは静かに陳腐化し、消せば過去の判断理由が消え、残せば現行情報と混ざる二重の失敗を示す。
- 6-3　裸の命題をやめ、主張に有効時点、出所、適用範囲、状態を付ける。
- 6-4　リンク切れ・参照頻度・規制上の保存義務を測り、保存・移行・廃棄を判断する。
- 6-5　分類体系そのものが消えると、古い語だけでなく当時の世界の切り方が失われる。対応表と履歴を残す。
- 6-6　一枚のカード(6)。時点と版を入れ、現在用と歴史的証拠を混同しない。

## 第7幕　仕事の知識は書けるのか
- 7-1　退職者の全知識を網羅する指示を、無限の例外と暗黙の判断で壊す。
- 7-2〜7-4　体系書は概念の索引、手順書は標準経路だが、例外判断・身体化した知・責任は文章だけでは移せない。
- 7-5　業務知識を目的・原則、概念・データ、標準手順、判断規則、例外事例、連絡・権限の六層に分ける。
- 7-6　現場で処理できない例外だけ上位者へ上がる設計にし、文書量でなく責任境界とエスカレーションを明示する。
- 7-7　地図と参考文献仮説を判定し、検索語、品質判定、例外処理、技能、責任は頭・人・手続きにも残す必要があると結論する。
- 7-8　一枚のカード(7)。三人の判定者が、出所・条件・時点・責任者を使って発見し実行できる状態へ届く。

## 幕間2　どの形で置くか、抜き打ち
- 題材ごとに物語、手順、表、索引、グラフ、原文保存を選ぶ演習。第1幕の全文保存も、法的証拠・引用検証など目的が合えば正しいと条件つきで復権させる。

## 第8幕　1枚のカードに戻る
- 8-1　最初の内容だけのカードと、出所・時点・条件・リンク・責任を持つ最後のカードを机上で比較する。
- 8-2　何を自分、他人、道具、手続きへ置くか、正本、検索入口、更新責任、廃棄条件を外部化設計にまとめる。
- 8-3　三案件を持ち込ませ、情報の性質と利用目的から置き方を選ぶ演習で道具を転移する。
- 8-4　3000件を全消去せず、墓を原文アーカイブとして残し、今使う一枚への入口を作る。「第二の脳」は量でなく、見つけ、疑い、更新し、動ける仕組みになる。

## 依存
- 一枚のカードは1-5で設置し、1-7、2-7、3-8、4-8、5-10、6-6、7-8、8-1で同じ対象を更新する。カードの条件・例外・出所を変えるなら全判定を見る。
- 1-6の「地図と参考文献」仮説は4-6の問い生成、5幕の機械限界、7-7の業務判断で反証・限定される。
- 第2幕の正本と参照は、第3幕のリンク、第6幕の版・時点、第8幕の更新責任の基礎。コピーを増やす設計に戻さない。
- 幕間1の「何を捨て何を保つか」が、第5幕の形式選択と幕間2の抜き打ちの判定原則。
- 3000件の墓は1-1と8-4の額縁。最後に原文保存を全面否定せず、役割を作業用知識からアーカイブへ変える。
- 本教材の外部化先「自分・他人・道具・手続き」は learning-and-memory 第7幕と対応するが、本作は媒体・検索・更新の側を詳述する。
