# `energy-policy` 改訂記録（sol56-medium）

## 対応した指摘と改訂方針

- やる夫の初期知識を下げた。震災後の火力比率、自給率、シェール革命、放射性廃棄物処分を即答させず、誤答または不確かな推測から資料を読んで言い直す流れへ変更した。
- 「曇りが3日続く冬」を計算問題にした。平均需要50GW×72時間＝3.6TWhを求め、ホーンズデール蓄電池194MWhとの単純比較で約18,600基分とした。充放電損失・出力・予備力を無視した下限であることも明記した。
- 既存教材を横断検索し、できる子を「寡黙に観測値と制約を出す役」、できる夫を「善意と実行が速く、判断の締切を現実化する役」として追加した。できる子は需要・系統運用・イベリア停電・連系工事の事実を担当し、できる夫は予算査定と閣議説明の期限を担当する。
- 第4幕の同型反復を崩すため、架空の比較演習「4-3a　予算は両方を買わせてくれない」を追加した。1兆円の枠に対して、水力・揚水側と太陽光の系統増強側が各7,000億円という設定を置き、やる夫に後者を選ばせた。4-5では、後回しにした調整力が25GWの夕方ランプとして戻るよう接続した。
- 地熱・バイオマスを一括二発言で終わらせず、地熱のkW・慣性・探査リスクと、バイオマスの調整力・燃料由来・供給量制約を別々に査定した。
- 5-5の過剰主張を修正した。制約から導けるのは「単一電源ではなくミックスが必要」という解の形までであり、太陽光23〜29％や原子力2割は、技術コスト、導入速度、国民負担、立地、既存設備、政策判断を含む幅だと明記した。「一意」「一本道」「最適解」という表現も同じ理由で改めた。
- 2025年4月のイベリア半島停電を「低慣性が原因」と単純化しないよう、2026年3月のENTSO-E最終報告に合わせて修正した。振動、電圧・無効電力制御、出力低下、発電機脱落などの複合要因を示し、慣性は高再エネ系統で別途確保すべき機能の一つとして説明した。
- 核融合では、ITERの2034年・2039年という実験工程から商用化年を逆算しないよう修正した。重水素と三重水素の燃料説明も補正し、2040年度の確定供給力には数えられないという政策判断へ絞った。
- 末尾に幕対応つきの参考資料を追加した。第7次エネルギー基本計画、エネルギー白書2025、IEA WEO 2024、ARENAのホーンズデール資料、CAISOのダックカーブ資料、ENTSO-E最終報告、2026年度再エネ賦課金、ITER Baseline 2024を採用した。
- ト書き・舞台指示は追加していない。改稿でやる夫の冗談を削った箇所について、残存するやらない夫の反応が宙に浮いていないことを差分で確認した。
