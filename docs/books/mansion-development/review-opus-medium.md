# 寸評：やる夫がマンションを建てて50年経ったそうです ── 都心200戸・50年の必然を逆算する

約88KB／全8幕（第0〜7幕）。都心200戸の分譲企画を「売値からの逆算」で1枚の事業収支表に絞り込み、その表がトラブルで削られる過程で開発法・資金計画・法規制約・住戸ミックス・期分け販売を再発見し、50年後の理事会で答え合わせをする教材。

## 良い点

**事業収支表1枚が全幕の背骨。** 1-3で表を提示し「1行いじると必ずどこかにしわ寄せが出る」（253行目）と宣言したとおり、土壌汚染で32→31億（307行目）、金利上昇で29億（536行目）、地盤と天空率で26億（750, 759行目）、入札不調で23億（964行目）、販売不振で21億（1167行目）と一方向に削られ続ける。読者が常に残高を追える。

**3つの宿題が全部、離れた場所で回収される。** 第0幕の宿題(1)(2)(3)（61–68行目）が、(3)は1-2（223–226行目）、(2)は4-2で半分（849–853行目）→5-3で残り半分（1060–1065行目）、(1)は6-3の一時金（1334–1335行目）で回収。(2)を二段階に割って幕をまたがせた設計が効いている。

**5-4の絞り込みがクライマックスとして成立。** 販売が満たすべき5条件を番号で立て（1081–1085行目）、候補A・B・Cを条件違反で潰し（1089–1107行目）、残った1つが現実の分譲の姿と一致する（1115–1122行目）。「勘だと思っていた販売計画が必然から一意に出る」という驚きが論証の形で共有される。

**予備費の正体を伏せ、最後に本人に言わせる。** 1-4で「なぜ利益率を20%取ったと思う。答えは最後にお前が自分で言え」と保留し（320–330行目）、11億が食われた後にやる夫が自力で「20%の厚みは保険だった」と言語化する（1177–1183行目）。教材で最も設計が効いた仕掛け。

**業界の利害構造とモラルの問いを避けない。** 系列管理会社のストック収益と第三者管理方式の利益相反（1281–1296行目）を出したうえで、「80年後を今考えるモラルは成り立つのか」（1465行目）に対し初代への積立押し付けという対案も潰し（1481–1486行目）、「後世の選択肢を殺さないこと」（1498行目）へ着地する。出口は制度の領域だと限界も明示していて（1522–1525行目）、説教にならずに済んでいる。

## 欠点

**最終的な数字の帳尻が合っていない。** 戸数は199戸（769行目）、建築費は76億（962行目）、売上は158億（1166行目）に着地したのに、5-4の条件1はなお「160億を回収」（1081行目）、4-2のミックス表は200戸のまま（821–827行目）、6-1は「土地40、建築70、諸経費10、利益32」と計画値を並べ直す（1205行目）。着地21億を支える表がどこにもない。

**参考文献が1件もない。** 末尾（1592–1601行目）はまとめの引用ブロックで終わる。坪440万の相場、レンタブル比80%、利益率15〜20%、自己資金2〜3割、手付金5〜10%が全てやらない夫の言い値で、区分所有法の5分の4（1341行目）や近年の法改正（1453行目）も条文名がない。

**やる夫が発見しすぎる。** 建中金利の削減策を問われて次の発言で青田売りに到達し（451–454行目）、期分けを一発で当て（1016–1018行目）、価格の階段の理由も1往復で正解する（1047–1051行目）。数値を踏んで本当に失敗するのは第1幕の積み上げ（112–144行目）だけで、以降の再発見はほぼ無抵抗に通る。

**トラブルが全部ナレーションで降ってくる。** 土壌汚染（283行目）、利上げ（524行目）、支持層5m深（745行目）、入札不調（944行目）、市況冷え込み（1142行目）は全てやらない夫の宣告で発生し、やる夫の判断の帰結が一つもない。6回とも同じリズムで、後半ほど衝撃が薄い。

**登場人物が実質2人。** ゼネコン・銀行・売主・反対住民は誰もセリフを持たず、やらない夫の語りで処理される。4-4の近隣調整（926–937行目）も4-5の入札不調（942–974行目）も「手は三つある」式の列挙で終わり、交渉が場面にならない。

**会長という落ちの伏線が弱い。** 根拠は人物紹介の「東京タワーも六本木ヒルズも現場にいた」（8行目）だけで、叩き上げの親方でも成立する。むしろ自社物件の理事会で会長の同席が1382行目まで話題に出ないほうが不自然。

## 改善案

1. **着地版の事業収支表を6-1冒頭に置く。** 1205行目の計画値列挙を計画／着地の2列表に差し替える（土地39・建築76・諸経費12・売上158・利益21・199戸）。あわせて3-6の199戸確定後に、4-2の配分のどのタイプを1戸削ったかを1行書く。

2. **参考文献を1598行目の後に付ける。** 不動産鑑定評価基準（開発法）、区分所有法62条、宅建業法の手付金保全措置、国交省「修繕積立金に関するガイドライン」（均等積立方式）、標準管理規約、土壌汚染対策法、マンション建替円滑化法の敷地売却制度、建築費指数。各項目に対応する幕を添える。

3. **トラブルの1つをやる夫の判断の帰結にする。** 4-5の入札不調（944行目）を、3-6で199戸に戻すために採った間取り分割（769行目）が施工を複雑にして見積もりを押し上げた、という因果に組み替える。6回並ぶ打撃の中に質の違う1回が入り、単調さも解消する。

4. **ゼネコン所長できる子立てて4-3〜4-5に出す。** 80億の見積書を持参し、VE提案に「そこを削ると10年で雨漏りする」と押し返し、スライド条項に応じる役。現状やらない夫が代弁している相手の論理（950–952行目）を本人に喋らせるだけで第4幕が場面になる。第2幕の銀行担当も同様。

5. **IRRを実際に計算させる。** 496–499行目は名前と定性説明だけ。自己資金32億で2年なら年約41%、5年なら年約15%と数字を出させ、5-5で販売が延びた時にもう一度計算させれば、条件3（1083行目）の重みが増す。

6. **期分けの発見に失敗を1つ挟む。** 1016行目の直前に、やる夫が「人気の部屋を後から値上げして売り直す」と言い、「公表した値札を後から上げたら客はどう思う」と潰される往復を入れる。そこから予定価格＝幅で問う形に進めば、青田売り（1033行目）との接続も自然になる。

7. **第0幕に会長の伏線を1本置く。** 司会に「本日は顧問の方が後ほどご到着です」と言わせ、やる夫が気に留めない形にする。人物紹介（8行目）にも、親方が作業着で役員会に出入りしていた等の齟齬を一句足せば、1382行目の明かしが回収として働く。
