# 寸評：やる夫で学ぶ統計学 I ── 62人の「買いたい」から、データの読み方を作り直す

約122KB／全9幕＋終幕（II部・III部へ続く三部作のI部）。おもちゃ会社の発売判断を舞台に、記述統計から標本抽出・確率・分布・推定・検定・回帰・実験計画までを「四枚カード」という一つの検査手順で串刺しにした教材。

## 良い点

**「四枚カード」という記憶装置の発明が全体を支えている。** 250行目でやらない夫が「何を決めたいか／データはどう生まれたか／結論に要る前提は何か／何を出力したか」を提示し、以降 549行目（62%）、727行目（ベイズ）、882行目（三数字の仕分け）、1341行目（信頼区間）、1414行目（検定）、1646行目（重回帰）、1823行目（最終統合）と、全幕で同じ四欄へ戻る。統計学の教材は用語が数十個に膨れ上がる分野だが、この教材は「用語一覧」でなく「毎回同じ四つの穴を探す作業」へ翻訳しており、初学者が持ち帰れる形になっている。248行目の「長い注意事項を丸暗記する設計が悪い」という自己言及も効いている。

**62%という一つの数字が第1幕から終幕まで貫通する。** 319行目のファンクラブ調査62%が、826行目で「620人」へ水増しされ、1054行目で全国無作為の62%として再登場し、1301行目で区間 0.524–0.716 を与えられ、1815行目の社長会議で「有意だが必ず売れるとは言えない」へ着地し、1886行目でケーキの62%として笑いに変わる。同じ数字が「意味を変えながら」9幕分の道具に晒され続ける構成は強い。

**やる夫の誤りが全部「実務で本当に起きる誤り」に対応している。** 平均の平均（33行目）、調和平均の必要な速度（34行目）、n を増やせば偏りが消える（321行目）、感度と的中率の逆転（676行目）、最頻値で予算を組む（748行目）、p値を仮説の確率と読む（1360行目）、変数を全部入れれば交絡が消える（1593行目）、有意になるまで覗く（1421行目）、有意な0.5ポイントで発売（1476行目）。どれも机上の練習問題ではなく、実際の報告書で見る事故ばかりで、教材の実用性を上げている。

**幕の締めに「想起テスト」の節を置いている。** 1-4（231行目〜）、2-4（531行目〜）、3-4（815行目〜）は、既習の数字から商品名や文脈を剝がして再判定させる節で、262行目で「数日後に数字を隠して取り出すと強くなる」と明示的に間隔想起の原理まで述べ、脚注[^4]に教育研究のガイドを付けている。教材が自分の学習設計を自覚しているのは珍しい。

**比喩が抽象語の代わりでなく検算の道具になっている。** 「警備員と裁判官」（144行目、外れ値の発見と削除）、「同じ火災報知器でも厨房と水族館」（720行目、事前確率）、「固定した杭と投げ直す網」（1314行目、信頼区間の頻度論的解釈）、「配管のバルブ」（1633行目、調整変数）、「三脚の脚」（1789行目、フィッシャー三原則）。特に1314行目の網／杭は、信頼区間で最も誤解される点を一行で切っており、公式より先に思い出せる形になっている。

**参考文献が節と対応づけて8点付いている。** 1962–1969行目に NIST/SEMATECH、CDC の確率標本ガイダンス、NCBI の一般化と欠測、AERO の想起練習ガイド、統計検定2級の出題範囲。1969行目では「出題範囲を I部では『データを見る→生成を確かめる→…』の順へ組み替えた」と、カリキュラム設計の意図まで明示している。

## 欠点

**やる夫の思考が「うーん、◯◯……いや、××だお……自信ないお……」という一つの型で18回反復される。** 105行目、153行目、266行目、331行目、349行目、409行目、619行目、715行目、778行目、905行目、949行目、1030行目、1146行目、1236行目、1251行目、1300行目、1370行目、1413行目など。同様に「……ということかお？」が16回（494行目、650行目、668行目、971行目、1128行目、1204行目、1228行目、1303行目、1426行目、1449行目、1503行目、1586行目、1808行目ほか）。どちらも初出では効果的だが、ほぼ全節で同じ位置に同じ形で出るため、後半では「型が来た＝正解が2行後に来る」と読者に予告してしまい、思考のスリルが消えている。

**やる夫が一往復で正解に到達し続け、「苦労の過程」がない。** 典型は 1064–1071行目：やらない夫が「$\hat p$ の平均と分散はどうなる」と問うただけで、やる夫が $E(\hat p)=p$ と $\operatorname{Var}(\hat p)=p(1-p)/n$ を導出まで含めて即答する。1238行目のバイアス・バリアンス分解、1150行目の $t$ 統計量、1529行目の最小二乗の SSE も同様に、やらない夫の一言の後に完成形が出る。全9幕を通して、やる夫が2往復以上詰まる箇所が一つもない。素朴案は毎回死ぬが、死んだあとの復旧が速すぎて、読者が一緒に考える時間が確保されていない。

**「金儲け妄想」ギャグが節の冒頭に機械的に配置され、しかも文が途中で切れている箇所が複数ある。** 468行目「テーマパーク入場料。」、612行目「「90%反応保証」の有料音声を配信し。」、678行目「検査一台500円。」、1217行目「強気の数字で予算を取って。」、1437行目「外れた95%は非公開。」、1745行目「刺繍入り白衣で記者会見。」。これらは体言止めや連用中止のまま放置されており、分量削減の途中で語尾が削られた痕跡に見える。ギャグの型自体も「◯◯を売って×××円」がほぼ全節にあり、金額（500,000円、1,000,000円、100,000円…）だけが入れ替わる。

**ガオぽんが登場人物として機能していない。** 12行目で「子供の声に反応して鳴き、首を振る恐竜型ロボット」と紹介されるが、実際に場面へ現れるのは 1899行目、1918行目、および1943行目の言及のみ。608行目や676行目では「鳴いた回数」「警報が出たガオぽん」というデータの器として名前が使われるだけで、物体としての存在感がない。舞台にロボットを置いた以上、実測して数字が出る場面（現物が予想を裏切る場面）を作れたはずで、熱力学教材の「氷の秤」に相当する物理的な計測器が欠けている。

**物語的な圧力がなく、失敗の代償が一度も現実化しない。** できる夫は 1356行目で「在庫発注APIにも接続済みです」と危険な自動化を持ち込むが、1887行目で「今度は送信ボタンの一歩手前で止めました」と回収され、実害はゼロ。期限も、予算の制約も、誤った判断で失われた金額も、9幕を通じて一度も発生しない。すべての誤りがやらない夫の口頭指摘だけで無傷のうちに訂正されるため、「なぜ厳密さが要るのか」の動機が最後まで学術的な水準に留まっている。

**できる子・できる夫の登場が少なく、役が生きていない。** できる子は 233行目、273行目、1734行目、1901行目、1950行目の5回のみ。1734–1738行目の「Aは午前、Bは午後。Aは新品電池、Bは再利用電池。担当者も別。……機種差という結論は、情報不足。」は本教材で最も鋭い一撃で、9-2の交絡の議論を丸ごと駆動しているのに、この機能が他の幕でまったく使われていない。16行目の人物紹介で「危ない結論から皆を守ろうとする」と定義した以上、第5幕〜第8幕にも同型の三行を置けたはずである。

**表記の乱れと数値の不整合が残っている。** 689行目「警報は合計約59台、そのうち本当の故障は9台だから $9/58.5\approx0.154$」は、直前で「約50台」と丸めた後に分母だけ 58.5 という未丸めの値を使っており、読者が追えない。また 785行目・847行目の「software不具合」「software故障」、869行目の「どの揺れやbiasを」は、日本語の本文中に英単語が生のまま混入している。

## 改善案

1. **第5幕5-1で、やる夫を一度失敗させる往復を挿入する。** 1062行目の問いに対し、やる夫がまず「$\hat p$ は $p$ そのものだから分散0」と答え、やらない夫が「同じ100人調査を3回やった結果が 62、57、66 だったらどうだ」と実測値を突きつけ、そこで初めて 1066行目の導出へ進む形にする。現状は導出が滑らかすぎて、標本分布という概念が「新しく発見されたもの」に見えない。10〜15行の増分で済む。

2. **「うーん、◯◯……いや、××」の型を、幕ごとに3種類に振り分ける。** 現在18回同型なので、たとえば第1〜3幕は現行型、第4〜6幕は「やる夫がまず紙に書いて計算し、数値が合わないことに自分で気づく型」、第7〜9幕は「やる夫が正しい答えを言うがやらない夫が『それはどの条件下で言える』と一段追う型」へ切り替える。同型反復の検出（`scripts/yaruo_beat_repetition.py`）でも高スコアが出るはずの箇所である。

3. **ガオぽんに実測をさせる場面を第4幕に作る。** 4-1（889行目付近）のポアソンの導入時に、やる夫が実際にガオぽんを1時間動かして鳴いた回数を数え、「平均2件」の予想に対して 0件の時間帯と5件の時間帯が出る、という実測記録を置く。930–932行目の $P(N=0)=e^{-2}\approx0.135$ が、計算値でなく「実際に0件だった時間の割合」と照合できる形になり、935行目の「どの前提が壊れたらポアソンを疑う」が観測から出てくる。

4. **失敗の代償を一度だけ現実化させる。** 1356行目の自動発注APIを、第7幕の時点では止めきれずに「小ロット1,000台の発注が実際に通ってしまった」ことにし、第9幕（1815行目付近の社長会議）で「その1,000台の在庫をどうするか」を判断材料に加える。9-3が「まだ渡っていない橋の列挙」で終わっている現状に対し、「すでに渡ってしまった橋の後始末」という実害が加わり、統計的厳密さの動機が実務側へ移る。

5. **できる子の「情報不足」型の介入を第5幕・第7幕に各1回追加する。** たとえば 1296行目（$n=100$ での正規近似）の直後に、できる子が「小標本。$\hat p$ が0.05なら期待成功数5。近似の根拠、記録なし」と三行で刺す。1318行目でやらない夫が同じ内容を説明しているので、その説明を彼女の指摘への応答へ置き換えれば分量は増えない。

6. **表記と数値を整える。** 689行目を「警報は 9 + 49.5 = 58.5 台（期待値）」で統一するか、逆に「約59台のうち約9台で約15%」と全部丸めるかを選ぶ。785行目・847行目の「software」を「ソフトウェア」に、869行目の「bias」を「偏り」に直す。468行目、612行目、678行目、1217行目、1437行目、1745行目の中断した文は、語尾を補って完結させる。

7. **第4幕以降にも「調査票を読む③」に相当する想起節を置く。** 1-4／2-4／3-4と3回続いた想起節が第4幕以降で消え、構造が非対称になっている。第6幕と第7幕の間（1347行目付近）に、既出の「62%」「±4.9ポイント」「p=0.03」「800円」を数字だけ並べて再判定させる節を1本追加すれば、262行目でやらない夫自身が宣言した「時間を空けて別順序で取り出す」設計が、教材の後半でも守られる。
