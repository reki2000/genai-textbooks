# `schrodinger-v2` ブロックメモ

## 制約と到達点

- 8幕＋終幕、約9万〜11万字。量子力学の解釈論を断言で決着させず、予測と操作に必要な最小構造を再発見する。
- 同じ二状態トイを、振幅、演算子、時間発展、トンネル、測定、デコヒーレンス、制御で反復する。
- 数式はやる夫が途中式を埋め、やらない夫は次の操作だけを渡す。

## 人物設定

- やる夫：科学館の映像演出家。電子を小球として追跡する映像を作った。やらない夫とは学生時代の電子工作仲間。
- やらない夫：Q-17の制御回路を作った独立設計者。一回だけ成功したパルスを採用した。やる夫とは十年ぶりの共同制作。
- できる子：低温計測担当。温度、ノイズ、反復回数だけを短く提示し、観測事実と解釈を分ける。
- できる夫：科学館の広報担当。巨大な猫シルエットを映像へ足したがるが、物理的に説明できる場面がない。

## マクガフィンとトイ

- 二重量子井戸素子Q-17と「午前6時、右80%以上」の検収票。
- 七本のスペクトル線S1〜S7。線の位置と幅を固定し、幕ごとに意味を解く。
- 左右二状態の磁石ボード。ベクトル、2×2行列、密度行列を同じ盤面で重ねる。
- 位相ダイヤルと障壁パルス発生器。抽象量を実際の操作ノブへ結ぶ。
- 落ちる位置札。電子の途中経路を古典物語で固定したい誘惑を可視化する。

## 伏線と回収

- 七本線の最細ペアは第5幕の対称・反対称状態の分裂。
- 冷却温度表示が周期的に一桁跳ねる。第7幕で環境ノイズの原因へ回収。
- 位相ダイヤルに0と2πが別位置で印刷されている。第2幕で同じ全体位相、相対位相は別と回収。
- Q-17操作画面の「100回で判定」をやる夫が演出字幕で隠す。第6幕と終幕で戻す。
- 猫シルエットの輪郭に測定ケーブルが映り込む。第7幕で、実在する環境結合へ焦点を戻す笑いとして回収。

## 繰り返すギャグ

- 位置札を電子模型へ貼るたび、左右の間へ落ちる。
- やる夫が波動関数を天気予報と呼び、降水確率と一回の雨を混同して叱られる。
- できる夫が猫シルエットを投影しようとするたび、やる夫自身が「その絵で予測値は変わらない」と止めるようになる。
- やらない夫の「まず規格化しろ」に、やる夫が部屋の片づけを始める。

## 緩急と息抜き

- 第1幕は停電・故障疑惑を速く、第2幕は暗室の二経路実演で静かにする。
- 第3・4幕は数式の登り坂。磁石ボードと具体数値を頻繁に挟む。
- 第5幕はトンネル振動の発見で最初の大きな快感、第6幕は測定で一度挫折させる。
- 第7幕の猫シルエット騒動から環境ノイズの現実へ戻し、第8幕を操作設計のクライマックスにする。
- 終幕は百回の点灯音だけで結果を数え、派手な奇跡を避ける。

## ブロック運用

各節は「予測→操作→読み出し→失敗の死因→式の更新」で閉じる。抽象記法を導入した直後にQ-17の二状態へ戻す。測定問題の哲学的立場は、どの実験結果が異なるかを言えない限り決着扱いにしない。障壁と電子のアニメーションが古典軌道の誤解を生まないよう台詞で制止する。

## 状態台帳の初期値

- 初期状態、$J$、離調、パルス時間、温度、コヒーレンス時間、読み出し誤差、各反復結果を固定する。
- 量子井戸の具体数値は教育用の仮想素子と明記し、実在研究成果の再現を装わない。
- ボルン則、ゼノ効果、デコヒーレンスは適用条件を添え、俗流の「意識が現実を作る」へ接続しない。
- 外部出典は確認済みの原典・標準教科書だけを置き、未確認URLを仮置きしない。
