## 定義・式・極限

- $|\psi\rangle=\alpha|L\rangle+\beta|R\rangle$、$P_L=|\alpha|^2$、$P_R=|\beta|^2$、和1。
- 相対位相トイ：$P_A=(1+\cos\phi)/2$。$0$と$2\pi$は同じ、$\pi$で0。
- $\hat p=-i\hbar\partial_x$、平面波固有値$\hbar k$。単位kg m/s。
- 時間発展：$i\hbar\partial_t|\psi\rangle=H|\psi\rangle$、$U=e^{-iHt/\hbar}$、$U^\dagger U=I$。
- $t\to0$で$U\to I$、障壁厚さ増大で$J\to0$、$|\Delta|\to\infty$で最大移動率0。
- 共鳴：$P_R=\sin^2(Jt/\hbar)$、$t_\pi=\pi\hbar/(2J)$。
- 離調：$P_{R,\max}=4J^2/(\Delta^2+4J^2)$。
- ゼノ：$[1-(\Omega t/N)^2]^N\to1$。
- 交換子：$[x,p]f=i\hbar f$、$\Delta x\Delta p\ge\hbar/2$。
- 密度行列のオフ対角を、相対位相と干渉可能性の指標として読む。
