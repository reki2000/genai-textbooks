# やる夫が位相幾何学を応用するようです ―― センサーネットワークの被覆を証明する の骨格

舞台は市の防災システム。**山間部の監視センサー312台**が全台オンラインで通信グラフも連結なのに、点検ドローン7号が沢筋で約4分間どのセンサーからも観測値を受け取れなかった、という矛盾から始まる。**増水予測の更新まで残り6時間12分**というタイマーが 1-1 で置かれ、最終節 8-2 で「残り1時間43分」として回収される。到達点は de Silva–Ghrist の定理（強信号・弱信号2つのRips複体と境界部分複体の対から、包含が誘導するトップ次元相対ホモロジー写像の非零性で被覆を保証する十分条件）で、**座標をいっさい復元せずに**そこへ至る。

全編の目標である変換の鎖は 1-2 で先に宣言される：通信記録 → 有限個の三角形 → 行列 → 穴の生成元 → 追加配置。最終節 8-2 でこの鎖が「局所的な通信関係 → 単体複体 → 境界行列 → 相対ホモロジー → 被覆保証」として再掲される。

## 第1幕　つながっているのに見えていない
- 1-1　$\beta_0(G)=1$ で完全被覆と誤認。**8個の磁石を円環に並べる**教具で、連結なのに中央が空くことを体感し、三角形タイル＝面の情報が要ると気づく。最小次数 $\delta(G)$ を上げても、頂点連結度を上げても、円環を太くすれば穴は作れる（通信の頑丈さと空間被覆は別の品質属性）。**「グラフを捨てるのか」という抵抗に対し、やらない夫が「捨てない、含む＝グラフは新しい構造の一階」**と答えるのが、この教材の設計思想。
- 1-2　**単一の数へ潰す指標を4つ順に殺す**。(a) 面積の足し算 $n\pi r_c^2>A$ ＝重なりを多重計上（包除原理は正確だが座標が要る／GPSは10分で38m揺れる）。(b) 格子判定＝細かさの根拠にも座標が要る。(c) モンテカルロ＝$(1-q)^m$ の見逃し確率しか返さない。(d) セル密度＝セルが大きければ隅に固まり、小さければ0/1になり意味を失う。加えて**平均は最小値の下界ではない**（効くのは $\bar r$ でなく $\min_i r_i$）。確率的被覆定理 $n\pi r_c^2/A\gtrsim\log n$ も、仮定「一様ランダム配置」が成り立たない（設置方針は「林道と尾根沿い、駐車位置から徒歩30分以内」）＝**仮定が成り立つ場所では定理が要らず、定理が要る場所では仮定が成り立たない**。結論：「全称命題を平均量に置き換えるたび同じ形の反例が作れる」。

## 第2幕　地図を捨てる
- 2-1　最小二乗法で座標復元する案。通信装置は距離を返さず、取れるのは**ID・強信号近隣一覧・弱信号近隣一覧・境界近傍フラグの3種の観測データのみ**（できる子が「IDは識別子、観測データは3種類」と訂正する小ネタつき）。距離制約には回転・平行移動・鏡映・非剛性の不定性。決定的な指摘は**「座標精度の評価と位相的特徴の安定性は別の量」**（1cmの差で連結性や3円共通部分が不連続に変わる）。代わりの手段＝**答えのほうを揺すって粘りを見る**＝第6幕のパーシステンスの予告。座標推定は「保証の根拠」でなく「探索のヒューリスティック」へ降格。
- 2-2　入力の形式化。$B_i$（半径 $r_c$ の閉円盤）、$r_s<r_w$、$N_s/N_w$、$G_s\subseteq G_w$、境界フラグ $f_i$ と $X_f$、隣接行列 $A^{(s)}\le A^{(w)}$。**境界フラグは方向を教えない**（北か南か知らず、一定距離以内に境界があるとだけ知る）ことが、第7幕で相対ホモロジーを使う理由になると明言。

## 第3幕　円盤を三角形へ変える
- 3-1　Čech複体と**nerve定理**（交差がすべて可縮なら $\check C\simeq\bigcup B_i$）。ただし**ペア交差から3重交差は決まらない**：$B_1\cap B_2$、$B_2\cap B_3$、$B_3\cap B_1$ が空でなくても $B_1\cap B_2\cap B_3=\varnothing$。アスキー図で、円盤を広げて3重交差が生じる瞬間に $[1,2,3]$ が入り $H_1$ が消えることを確認し、**「円盤を広げる操作と複体に面を1枚足す操作が同じタイミングで起きる」**。そのうえで**「通信は三角形、現実は穴」＝この教材でいちばん怖い絵**とやる夫が名指しし、第6幕の「存在しない穴」はこの裏返しだと予告する。Hellyの定理で3個組へ還元できても、入力（座標）がないので作れない。
- 3-2　Vietoris–Rips複体＝旗複体（クリークを埋める）なので通信グラフから直接作れる。だがRipsは埋めすぎも作りすぎもする。対策は $R_s\subseteq R_w$ の2スケール。**やる夫が $\rho_d$ を自力で導く**：1辺 $\varepsilon$ の正三角形が最悪で外心までが $\varepsilon/\sqrt3$、一般に $\rho_d=\varepsilon\sqrt{d/2(d+1)}$、$d\to\infty$ でも $\varepsilon/\sqrt2$ を超えない＝**座標がないから次元も確定しない、だから次元によらない定数が要る**。挟み撃ち $R_\varepsilon\subseteq\check C_{\varepsilon'}\subseteq R_{\varepsilon'}$ は、途中のČechを構成せず存在と包含だけを使う（「情報が不足しているところを推測で埋めず、定理で迂回する」）。

## 第4幕　穴を線形代数へ落とす
- 4-1　$\mathbb F_2$ 係数の鎖群。正方形の4辺で $\partial_1z=0$、三角形の境界として書ける閉路は穴でない → $H_1=\ker\partial_1/\operatorname{im}\partial_2$。$\partial_{k-1}\partial_k=0$ から $B_1\subseteq Z_1$。$H_0$ と $\beta_0$＝連結成分数。Euler標数 $\chi=4-4=0=\beta_0-\beta_1$ と $\chi=4-5+2=1$ の2例で検算し、**$\chi$ は交互和しか与えないので次元ごとの計算が要る**。
- 4-2　境界行列を実際に掃き出す。正方形：$\operatorname{rank}\partial_1=3$、$\beta_1=1-0=1$。対角線と三角形2枚を足すと閉路空間はむしろ2次元に**増える**のに $\operatorname{rank}\partial_2=2$ で $\beta_1=0$＝**商空間が必要な理由**。実データで $\beta_0(R_s)=1$、$\beta_1(R_s)=3$、代表閉路の1つが $\{87,91,104,118,121,109\}$ でドローンの報告位置と一致。疎行列、クリーク列挙の爆発、**$H_2$ に $\partial_3$（四面体）が要る理由**（偽の2次クラスを消すため＝2-2 の「地面から四面体が生えるのは変だ」への回答）。

## 第5幕　行列がセンサーを動かす
- 5-1　**本編最大の実演。模型では1台、実データでは2台**。模型（4頂点＋中央 $v_5$）ではスポーク4本・三角形4枚で $\beta_1=4-4=0$、外周閉路 $z$ が $\partial_2(t_1+\cdots+t_4)$ になる。ところが実データの代表閉路は**6頂点**で、投入したM5の強信号近傍は4台のみ（121と109は弱信号だけ）。三角形3枚しかできず $\beta_1=4-3=1$ で**穴が残る**。やる夫は「模型の絵をそのまま実データへ持っていった」と自省。残った閉路 $z'$ にはM5自身が含まれ、**2台目M6の条件は「穴の近く」でなく「$z'$ の全頂点（M5を含む）と結べること」**。M6投入後は頂点8・辺15・三角形8で $\beta_1=8-8=0$、$\chi=8-15+8=1$（円盤）で独立検算。さらに**Betti数の増減でなく写像 $j_*([z])=0$ でクラスを追う**（別の場所に新しい穴が生まれても数は変わらないため）。運用ログに $\ker j_*$ と $\operatorname{im}j_*$ を残す。
- 5-2　代表閉路は一意でない（$z'=z+\partial_2c$）ので、辺数・重み最小化は**存在判定と分けた後段の最適化**。できる子が「第2生成元は3辺」と報告し、旗複体なら3辺あれば三角形が入るはずだと**やる夫が矛盾を見抜き、境界部分複体を除外した中間データという入力のミスが発覚**する（「静かに怖いミス」）。出力すべき監査項目5点。できる夫が運用制約を読み上げる：**移動センサーは3台（M5/M6/M7）、電池6時間20分/4時間45分/2時間10分、第1候補まで片道38分・第3候補は1時間52分、M7は往路で尽きる、固定した機体は動かせない**。ここから「消せる穴を全部消すのでなく、**消さないと保証が通らない穴だけ**消す」。$\min_p(\operatorname{rank}H_1(K_p)+\lambda\operatorname{cost}(p))$ の $\operatorname{cost}$ を書けるのは運用側だけ。表示設計まで踏み込み、代表閉路を確定した境界線として見せない。

## 第6幕　存在しない穴
- 6-1　計算はRips複体について厳密だが、Ripsが現実と同じ位相とは限らない。**大きいスケール単独も信用できない**（弱通信は届いても $r_c$ が足りず現実には穴が残りうる）。解は $\iota_*:H_k(R_s)\to H_k(R_w)$ の**階数**を見ること：$\beta_1(R_w)$ の非零性では「新しく生まれた偽穴」と「生き残った穴」を区別できない。相対版でも同じ議論（$H_2(R_s,F_s)\neq0$ が幻の場合、$H_2(R_w,F_w)\neq0$ でもそれが $[\alpha]$ の像とは限らない）。4頂点＋対角線の最小例で $\iota_*([z])=0$。
- 6-2　フィルトレーションとバーコード、寿命 $\operatorname{pers}(z)=d(z)-b(z)$（$[12,14)$ のノイズ対 $[11,23)$ の本物）。ただし**長寿命＝現実の穴とは限らず、短寿命を全部捨ててもいけない**（小さいが危険な穴）。運用を2段階に分離：**長寿命クラス＝点検の優先順位づけ／相対ホモロジーの非零写像＝被覆の証明**。時間変化はzigzagの領域だが「定理の条件を曖昧にしないため」今回は1時点の2スケールに絞ると明言。

## 第7幕　境界をゼロとみなす
- 7-1　区域の外周まで穴と数えてしまう問題。$C_k(K,F)=C_k(K)/C_k(F)$。4外周頂点＋中央の模型で $\partial^{\mathrm{rel}}t_i=s_i+s_{i+1}$、$\alpha=t_1+\cdots+t_4$ の相対境界が0＝**区域を横切って張られた面＝基本類**。$K/F$ の被約ホモロジーという言い換え。**「境界を無視する」は情報を捨てることではなく、どの鎖を0とみなすかを $F$ として明示すること**で、$f_i$ の誤判定は相対サイクルの偽造にも判定失敗にもなる＝**境界フラグの校正は前処理でなく定理の仮定**。
- 7-2　相対境界行列（正方形と同じ形）から $H_2(K,F)\cong\mathbb F_2$。$t_4$ が欠けると3列独立で $\ker=0$、$H_2(K,F)=0$。さらに**どの未相殺辺が裂け目か**を $\partial^{\mathrm{rel}}c=a_1s_1+(a_1+a_2)s_2+(a_2+a_3)s_3+a_3s_4$ の連立から示す。実データでは $H_2(R_s,F_s)\cong H_2(R_w,F_w)\cong\mathbb F_2$、$[\iota_*]=(1)$。**「$H_1$ は内部の穴候補を探す道具、相対 $H_2$ は領域全体の被覆を保証する道具」**と役割を分離。

## 第8幕　地図なしの被覆証明
- 8-1　**半径条件の意味づけがこの節の要**。$r_c\ge r_s/\sqrt2$ は 3-2 で自分が出した $\rho_d$ の上限そのもの（**「天下りじゃなかった」**）＝1つの複体の中身を検知円で覆う余裕。$r_w\ge r_s\sqrt{10}$ は挟み撃ち $R_{r_s}\subseteq\check C_{\varepsilon'}\subseteq R_{r_w}$ の**2段分**（Ripsの幻を許容する余裕＋Čechを弱Ripsへ入れる余裕）で、前者は検知と通信の比、後者は通信同士の比＝**別の部品の仕様**。判定は $\iota_*:H_2(R_s,F_s)\to H_2(R_w,F_w)\neq0 \Rightarrow D\setminus N_{r_y}(\partial D)\subseteq U$。計算機がやる4手順。**できる子が「M5のみでは $[\iota_*]=(0)$、M6投入で $(1)$」と報告**し、5-1 の $\beta_1$ とは別判定でありながら同じくM6まで必要だったと確認。背理法の筋（未被覆点があれば基本類が実現できず非零性と矛盾）。
- 8-2　**成功しても万能ではない**。定理は十分条件であり、$\iota_*=0$ は「未被覆の証明」ではなく「被覆を証明できなかった」の意味（疎すぎる配置、境界フラグの不安定、半径条件違反、細いくびれ）。等半径円盤・理想的な距離閾値・故障や時間変化という仮定も列挙。第1幕で殺した4手法との対比で締め、$\beta_1:1\to0$ と $[\iota_*]:(0)\to(1)$ という2つの数値変化が投入・固定・点検継続という3つの現場判断に対応したことを確認。落ちは報告書ファイル名「完全被覆_最終版_確定_本当に確定_v7.docx」をできる子が削除しようとする場面。

## 依存
- **「グラフを捨てるのでなく含む」**（1-1）が全編の構造：$C_0/C_1$（第4幕）はグラフそのもので、$\beta_0$ は 1-1 の連結性の再定義。ここを弱めると第4幕で「一階を取り壊していない」ことが伝わらない。
- **3-1 の「通信は三角形、現実は穴」の絵**が 6-1 の偽の穴、8-1 の $r_w\ge r_s\sqrt{10}$ の1段目、5-1 末尾の「$\beta_1=0$ だけで配置完了と断言するのは危ない」の共通の根拠。この3円の反例を削ると第6幕と第8幕が同時に支えを失う。
- **$\rho_d=\varepsilon\sqrt{d/2(d+1)}$ と上限 $\varepsilon/\sqrt2$**（3-2）は 8-1 で $r_c\ge r_s/\sqrt2$ として明示的に回収される。やらない夫が 3-2 で「第8幕で出す定数の意味はもう読める」と予告しているので、対で扱う。
- **「答えを揺すって粘りを見る」**（2-1 末）→ 3-2 の2スケール → 6-1 の $\operatorname{rank}\iota_*$ → 6-2 のバーコード、と同じ発想が4段階で具体化される。
- **数を見るのでなく写像を見る**という転換が3回反復される：5-1 の $j_*([z])=0$（投入で消えたクラスの追跡）、6-1 の $\operatorname{rank}\iota_*$（幻の除去）、8-1 の $[\iota_*]=(1)$（被覆保証）。この反復が本編の主題。
- **模型（4頂点＋中央、$\beta_1=0$）と実データ（6頂点の代表閉路、M5だけでは $\beta_1=1$）の対比**が 5-1 の山場。代表閉路の頂点数を6から変えると、スポーク4本・三角形3枚・$\beta_1=4-3=1$、およびM6投入後の 8-15-8 と $\chi=1$ の計算がすべて連動する。
- **第7幕の4三角形模型の相対境界行列**は 4-1／4-2 の正方形の境界行列と**同じ行列**であることが本文で明言される。片方の行列を変えるならもう片方も直す。
- **代表閉路 $\{87,91,104,118,121,109\}$** は 4-2（抽出）、5-1（M5の近傍が4台、M6が5台）、8-1（できる子の変化した単体の報告）で一貫して使われる。ノード番号を変えるなら3箇所。
- **できる夫の運用制約**（3台、電池6:20/4:45/2:10、片道38分/1:52、固定したら動かせない）は 5-2 でのみ提示され、そこで「保証が通らない穴だけ消す」という方針転換の根拠になる。数字を変えると第3候補の除外理由が崩れる。
- **できる子の入力ミス（境界部分複体を除外した中間データ）**は 5-2 の「3辺の閉路」から発覚する。旗複体なら3辺で三角形が入るという 3-2 の定義に依存した仕掛けなので、Rips＝旗複体の説明を弱めると矛盾が見えなくなる。
- タイマー（6時間12分 → 1時間43分）は 1-1 と 8-2 の対。
