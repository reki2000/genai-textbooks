# 改稿記録

`review-opus-medium.md` の改善案7点に沿って改稿した。

## 工夫した点・主な変更

- **TeXの破損4か所を修復した（改善案1）。** `ight)` → `\right)`、`eq0` → `\neq0`（3か所）。いずれも数式ブロック内で改行が `\r`・`\ne` を食っていた痕跡だったので、ファイル全体の `\right` と `\neq` を再走査し、他に同型の欠落がないことを確認した。

- **半径条件をやる夫に導かせた（改善案2）。** 3-2 で「$\varepsilon'/\varepsilon$ は次元と単体の外接半径から決まる」で済ませていた箇所を、やる夫の計算に置き換えた。最悪配置が正三角形であることを「1辺を短くすればその頂点に寄るから」という理由つきで自分で選ばせ、外接円半径 $\varepsilon/\sqrt3$ を出させる。そこへ一般次元の $\rho_d=\varepsilon\sqrt{d/(2(d+1))}$ を置き、$d=2$ で一致することと $d\to\infty$ でも $\varepsilon/\sqrt2$ を超えないことを確認させた。やる夫の反応を「座標がないから次元も確定しない。だから次元によらない定数が要る」にして、この教材の制約（座標なし）と定数の形を直結させている。

- **8-1 の $r_c\ge r_s/\sqrt2$ を、3-2 の計算の再利用として読ませた。** 「これは3-2の外接半径そのものだ。天下りじゃなかった」と言わせ、5幕をまたいだ回収にした。$\sqrt{10}$ の側は導出を求めず、レビューの指示どおり「なぜ2段の余裕が要るか」だけを言語化させた。1段目が「Rips複体の幻（3重に重なっていない場所にも三角形を作る）を許容するための余裕」、2段目が「そのČech複体を弱信号Ripsへ入れる余裕」。締めに「$\sqrt2$ は1つの複体の中身を覆う余裕、$\sqrt{10}$ は2つの複体の間を通す余裕。役割が違うから片方だけ大きくしても成り立たない」を置き、さらに現場語（センサー感度と無線出力の比／受信感度の幅）へ翻訳させて、実運用で機材を選ぶときの判断に落とした。

- **第5幕で実データを手計算させ、1台では埋まらない展開に変えた（改善案3）。** 代表閉路6台 $\{87,91,104,118,121,109\}$ に対し、M5の強信号近傍を4台に制限した。頂点7・辺10・三角形3（$(118,87)$ は外周で隣り合わないためスポーク間に辺がない）から $\beta_1=4-3=1$ を出させ、残った閉路 $z'=e_{118,121}+e_{121,109}+e_{109,87}+e_{87,M5}+e_{M5,118}$ を明示させた。5-1 でやらない夫が出していた警告「新ノードが閉路上の一部としか通信できず、三角形の扇が閉じない」を、その場で本人に引用させて回収している。

- **2台目の投入条件を、位置ではなく代数から決めさせた。** M6の条件を「穴の近く」ではなく「残った閉路 $z'$ の頂点すべてと結べること、$z'$ にはM5自身が入っている」とし、「1台目を置いた瞬間、1台目が次の閉路の一部になる」という帰結を言わせた。M6投入後は頂点8・辺15・三角形8で $\beta_1=8-8=0$、独立性は「閉じた曲面がないので $\ker\partial_2=0$」で示し、オイラー標数 $8-15+8=1$（円盤）による独立検算も付けた。円環なら0になるはずだ、という対比で検算の意味を持たせている。

- **実データと模型の不整合を解消した（改善案3の副次）。** 改稿前は代表閉路が6台なのに8-1では接続ノードが4台で、閉路が閉じる理屈が読者に検証できなかった。今回、4台接続では閉じないことを計算で示し、8-1 側も「M5と87、91、104、118」「M6と118、121、109、87、M5」「三角形8枚」に書き換え、「M5のみの状態では $[\iota_*]=(0)$ のままだった」を明記した。運用命令と できる夫の完了報告も2台に更新している。

- **第1幕1-2のセル密度パートを圧縮した（改善案4）。** 「セルに振り分けるには座標が要る」で1度落としたあと、譲歩して台数が分かるとした場合の議論を、やらない夫との3往復から、やる夫の1発言にまとめた。大きいセルでは隅の偏りが見えず、小さいセルでは0か1になって密度が意味を失う、を並置して1-1の最小次数と同じ罠だと結ぶ形は保っている。平均半径とランダム配置定理はレビューの指示どおり残した。

- **できる夫を運用コストの圧力源にした（改善案6）。** やる夫が一人で「電池、移動時間、通信負荷」と言っていた箇所を、できる夫が具体的な数値を読み上げる場面に変えた。移動センサーは3台（M5・M6・M7）、電池残量6時間20分／4時間45分／2時間10分、第1候補まで片道38分、第3候補は尾根越えで1時間52分。「M7は往路だけで電池が尽きる」「M6でも第3候補には二度行けない」で、$\lambda\,\operatorname{cost}(p)$ の中身が候補の可否を直接決めることを見せた。さらに「固定した機体は動かせない」を持ち込み、やる夫に「1台目の投入は2台目以降の選択肢を減らす決断」「消せる穴を全部消すのではなく、消さないと保証が通らない穴だけ消す」と結ばせた。5-2 でM5とM6を使い、第2候補（弱信号側で消える）を見送るという後半の判断が、この制約の帰結として読める。

- **第6幕の分岐点に図を2枚入れた（改善案7）。** 3枚の円盤がペアでは重なるが3重交差しない配置を、中央の▽を空けたASCII図で描いた。円盤を広げて3重交差が生じた図を並べ、▲の出現と2単体 $[1,2,3]$ の追加が同じタイミングで起きることを対比させた。図の直後にやらない夫が「3枚はペアで重なっている。つまり3台は互いに通信できる。通信グラフだけを見た人間は何を入れる」と問い、やる夫に「通信は三角形、現実は穴」と言わせている。第6幕「存在しない穴」の伏線が、この1枚の絵で先に立つ。

- **やる夫の先取り台詞を2か所やらない夫へ移した（改善案5）。** 1-1 の「グラフを1次元の骨格として含む、もっと大きな構造へ持ち上げる」は、やる夫を「グラフを捨てることになる。連結性の計算が無駄になる」で止め、やらない夫が「捨てない。含む」と答え、階層構造を説明する形にした。やる夫の返しは「一階建てを取り壊すんじゃなくて上に階を足す」という言い換えに落としている。2-1 の「座標精度の評価と位相的特徴の安定性は別問題」も、やらない夫が原理を述べ、やる夫が「じゃあ後者は何で測るんだ」と問い、閾値を揺らして特徴の粘りを見る方法を教わってから「答えのほうを揺すって粘りを見るのか」と言い換える順序に変えた。

## 残した判断

- 座標がないという制約が理論選択を駆動する構造、第1幕の9通りの素朴指標の連鎖、できる子の計算ミスを教育装置にする場面、相対ホモロジーを4三角形模型で手計算する箇所、8-2 で十分条件でしかないことを自分で潰す結末は、レビューで評価された骨格なのでそのまま維持した。

- 参考文献4点（de Silva–Ghrist 2本、Hatcher、Edelsbrunner–Harer）は対応箇所つきで既に整っているため変更していない。今回追加した $\rho_d$ の一般式は de Silva–Ghrist の議論の範囲内で、新しい出典を要する主張は加えていない。

- レビューが指摘した「後半でやる夫の独話が定型化する」については、5-2 と 8-1 に できる子・できる夫・やらない夫の応答を挟む形で往復を増やしたが、節末の総括発言そのものは残した。この教材は計算結果を運用命令へ翻訳する手順を毎節示す構成で、その翻訳がやる夫の仕事だからである。

- 「物語的な圧力が中盤で消える」も欠点欄にあるが改善案には含まれていなかった。ただし できる夫に電池残量と移動時間を持たせたこと（改善案6）で、中盤に時間と資源の制約が1つ入っている。
