# 寸評：やる夫が位相幾何学を応用するようです ―― センサーネットワークの被覆を証明する

約80KB／全8幕。山間部の防災センサー312台の「監視穴」を、座標を一切使わずに単体複体と相対ホモロジーで判定する教材。de Silva–Ghrist の被覆定理へ一直線に向かう。

## 良い点

**「座標がない」という制約が、理論選択のすべてを駆動している。** できる子が入力を3種類（ID、強近傍一覧、弱近傍一覧、境界フラグ）に限定し（459–473行目）、以後この制約が全幕を貫く。Čech複体は理想的だが3重交差を判定できないので使えない（752–788行目）、最小二乗で座標を復元しても誤差は臨界的交差に集中して穴だけ誤る（544–557行目）。道具が「かっこいいから」ではなく「他に入力がないから」選ばれている。

**第1幕の反例の連鎖が本気で潰しにいっている。** 連結性（85–87行目）、最小次数（119–122行目）、頂点連結度（125–131行目）、総面積（170–195行目）、格子（280–289行目）、モンテカルロ（292–302行目）、セル密度（335–354行目）、平均半径（364–370行目）、ランダム配置の定理（378–405行目）。9通りの素朴な指標が全部やる夫の側から出て、全部落ちる。特に405行目の「仮定が成り立つ場所では定理が要らなくて、定理が要る場所では仮定が成り立たない」は、確率的保証の限界を一行で射抜いている。

**できる子の計算ミスが最良の教育装置になっている。** 第2生成元の代表が3辺だと報告され（1550–1553行目）、やる夫が「Rips複体なら3辺あれば三角形も入るから1次穴にならない」と矛盾を自力で見つける（1554–1556行目）。原因は境界部分複体を除外した中間データ（1558–1560行目）。数値を疑う姿勢と、複体の定義が結果を変えるという主題が同時に立つ。

**相対ホモロジーの導入が「境界を無視する」の代数化として厳密。** 4三角形模型で $\partial^{\mathrm{rel}}\alpha=0$ を手計算し（2032–2040行目）、$t_4$ を1枚落とすと階数3・核0で $H_2(K,F)=0$ になることを行列で示す（2145–2175行目）。さらに2222–2252行目で「どのスポークが相殺できないか」を係数レベルまで追い、裂け目の所在を代数から読む。抽象概念が計算可能な手触りまで降りている。

**十分条件でしかないことを最後に自分で潰している。** 2441–2475行目で「写像が0なら穴がある」と言いかけ、逆が成り立たないこと（配置が疎、境界フラグ不安定、区域のくびれ）を列挙して「0は被覆を証明できなかったという意味」に着地する。定理を売り込んで終わらない誠実さがある。

**参考文献が対応箇所つきで4点。** de Silva–Ghrist の2本にDOI付き、Hatcher、Edelsbrunner–Harer（2577–2583行目）。本文の何幕に対応するかまで書かれている。

## 欠点

**TeXが4か所壊れている。** 1620行目が `ight)`（`\right)` の欠損）、1743行目・1769行目・2069行目が `eq0`（`\neq0` の欠損）。いずれも数式ブロック内で、レンダリング時に生の文字列が出る。しかも1743・1769行目は第6幕の核心（偽の相対サイクルが非零であること）の式で、読者が最も注意して読む箇所。

**中核定理の半径条件が完全に天下り。** 2308–2311行目の $r_c\ge r_s/\sqrt2$、$r_w\ge r_s\sqrt{10}$ が根拠なしに提示され、「実際には次元に応じてより良い定数があるけど、ここでは構造を優先する」（2315行目）で流される。3-2でも $\varepsilon'/\varepsilon$ は「次元と単体の外接半径から決まる」（934行目）の一行で済ませている。8幕かけて「なぜこの道具か」を再発見してきた教材が、定理の適用可能性を決める唯一の数値だけを再発見の外へ置いている。ここが空白だと、読者は実運用でこの定理を使えない。

**実データを一度もやる夫が計算していない。** 手計算はすべて4頂点の正方形模型（1180–1247行目、1364–1394行目、2109–2175行目）で行われ、312台の実データは $\beta_1(R_s)=3$（1264行目）、代表閉路6台（1280行目）、$[\iota_*]=(1)$（2215行目）と、できる子が結果だけ報告する。模型と実データの橋がない。特に2398行目で移動センサーが接続した既設ノードは87、91、104、118の4台なのに、1280行目の代表閉路は6台（121、109を含む）で、閉路が閉じる理屈が読者側に検証できない。

**「1台では埋まらないかもしれない」と警告した困難が回避されている。** 1601–1602行目でやらない夫が「穴が大きければ新ノードが閉路上の一部としか通信できず、三角形の扇が閉じない」と明示し、1606行目でやる夫も「対象クラスが残るなら2台目を入れる」と言うのに、実データではM5の1台であっさり $[\iota_*]:(0)\to(1)$ になる（2386–2396行目）。宣言した困難が起きないので、警告が消化されずに残る。

**やる夫が初学者ではない。** 人物紹介で「位相幾何学は初学者」（6行目）とあるのに、141–152行目で自ら「グラフを1次元の骨格として含む、もっと大きな構造へ持ち上げる」と言い当て、540行目で「保証の根拠と探索のヒューリスティックを分離する」、556–557行目で「座標精度の評価と位相的特徴の安定性は別問題」と述べる。これらは本来やらない夫が与えるべき整理で、生徒が先に言ってしまうと発見の落差が消える。

**後半でやる夫の独話が定型化する。** 1465行目、1633行目、2085行目、2222行目、2257行目など、節末で「**やる夫**：」が連続し、対話ではなく一人でまとめを語る形が繰り返される。特に第5幕以降は「やる夫が要点を再説明する」段落が各節に付き、リズムが単調になる。

**物語的な圧力が第1幕以降ほぼ消える。** 期限は106行目（残り6時間12分）と2542行目（残り1時間43分）の2点しかなく、中盤7幕分は時間が止まっている。24行目の「市長表彰、次期部長候補」という動機も回収は2562行目のファイル名オチのみ。できる夫は1327–1336行目、1431行目、2406行目の3回しか登場せず、現場を焦らせる役として機能していない。

## 改善案

1. **TeXを修復する。** 1620行目を `\right)`、1743行目・1769行目・2069行目を `\neq 0` に直す。数式ブロック内で `\n` 相当が欠落した痕跡なので、他の `\neq`・`\right` も一括確認する。

2. **半径条件をやる夫に導かせる。** 3-2の934行目の直後に、正三角形の3頂点が互いに $\varepsilon$ 以内なら、外接円半径は $\varepsilon/\sqrt3$、つまり凸包の任意の点は $\varepsilon/\sqrt3$ 以内に頂点があるという計算をやる夫にさせる。その上で8-1の2304行目の前に「$r_c \ge r_s/\sqrt2$ は、Rips単体の幾何学的実現が検知円に入るための余裕」として、自分の計算した外接半径と見比べさせる。$\sqrt{10}$ の側は導出まで求めず「なぜ強・弱の比にこれだけ余裕が要るか（Čechを間に挟むための2段の余裕）」を言語化させるだけでよい。

3. **第5幕で実データを1回だけ手計算させる。** 1364行目の模型計算の後に、実データの代表閉路6台（87, 91, 104, 118, 121, 109）を頂点とし、M5が4台としか強信号で結べない場合を作る。三角形の扇が閉じず $\beta_1$ が1のまま残ることをやる夫に計算させ、2台目M6の投入で初めて閉じる展開にする。これで1601–1602行目の警告が回収され、2398行目の4台接続の不整合も解消する。

4. **第1幕1-2の密度パートを圧縮する。** 306–434行目でセル密度、平均半径、ランダム配置定理と3周しており、いずれも「1個の数へ潰すと配置が落ちる」という同じ結論に至る。374行目でやらない夫が既にそれを総括しているので、セル密度（306–354行目）を半分に削り、平均半径（356–376行目）は残す。第1幕全体が本編到達までの助走として長い。

5. **やる夫の先取り台詞をやらない夫へ移す。** 141–152行目の「1次元の骨格へ持ち上げる」は、やる夫を「面の情報が要るのは分かったけど、グラフを捨てるのかお」で止め、やらない夫が「捨てない。含む」と返す形にする。540行目・556–557行目も同様に、結論をやらない夫が与え、やる夫は「つまり証明の入力に推定値を混ぜるなということかお」と言い換える側に回す。

6. **できる夫に運用コストの圧力を持たせる。** 1630–1631行目の「電池、移動時間、通信負荷」はやる夫が一人で言っているだけなので、これをできる夫の台詞にし、5-2の候補配置最適化（1612–1624行目）で「M5の電池は残り何時間、往復に何分」という具体的な数値制約を持ち込ませる。1947行目の寿命閾値を「災害リスクから決める」という話にも実体が伴う。

7. **第6幕に図を1枚入れる。** 758–780行目の「3円がペアでは重なるが3重交差しない」配置は本教材の分岐点だが、テキスト記述のみ。同じくRipsとČechの挟み撃ち（925–931行目）も抽象的なままなので、いずれかにASCII図か簡易な図解を入れると、以後の全議論の理解コストが下がる。
