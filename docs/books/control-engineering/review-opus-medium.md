# 寸評：やる夫が中国拳法で戦うロボットを作るようです ── 倒れない棒から、起き上がる拳士へ

約75KB／全6幕。套路の再生（開ループ）が外乱で死ぬところから始まり、倒立振子1本を軸にPID・極配置・オブザーバ・可制御性を組み立て、歩行・跳躍・受け・蹴り・起き上がりまで拡張する。

## 良い点

**ホウキの実演が導入として完璧。** 66–90行目。やる夫が自分の手で立て、目を閉じて倒し、87–90行目で「見て、直すのループが切れた。何も見ずに手を止めた＝開ループに戻った」と自分で言語化する。教師の定義より先に読者の身体感覚が来ており、以降の全論点がこの一場面に接地する。

**「$L=1\,$m、$\omega^2=9.8$ の棒を使い回す」と宣言し、実際に使い回している。** 215–216行目で明示され、第2幕の倍化時間 0.22秒（197行目）、4-7のむだ時間0.1秒で1.37倍（762行目）、5-3のキャプチャーポイント30cm（1007–1010行目）と、幕をまたいで同じ数字が効く。抽象度が上がっても読者が同じ物体を見続けられる。

**必ず数を入れて判定する。** 差分によるノイズ増幅を $\pm1000°/\mathrm{s}$ と計算させ（371–376行目）、極配置で $k_p=19.6,\ k_d=6.26$ を逆算させ（578行目）、$\lambda=-100$ 案をゲイン $k_p\approx10000$ で棄却する（562行目）。214行目の「なんとなく不安定では設計できん」が、教材の作法として守られている。

**失敗が全部やる夫の案から出る。** P制御→振動が止まらない（259–261行目）、差分→痙攣（378行目）、PD→定常偏差（402行目）、高ゲインで固める→発振と関節破損（972–974行目）、静歩行→全力疾走できない（822行目）。反例を教師が持ち込むのではなく、やる夫が出した案の帰結として現れる。

**可制御性を「同じ振り子2本」で導入する切れ味。** 604–644行目。台車1個の入力が2本に同じに効くから差モードに手が届かない、をやる夫が和と差に分解して $u$ が引き算で消えることまで自分で示す（638–640行目）。抽象的なランク条件が、先に具体的な詰みとして理解される。

**套路が第1幕で否定され、5-4で復活する。** 1042–1056行目。角運動量の辻褄合わせを考えたやる夫が「これ……套路の再生だお！ 第1幕のやつだお！」と気づき、フィードフォワード＋フィードバックの二階建てに到達する。冒頭で殺した案が、正しい居場所を与えられて戻ってくる構成は強い。

**参考文献7点のうち4点が原著。** McGeer 1990、Raibert、Pratt 2006、Åström–Furuta 2000（1238–1244行目）。

## 欠点

**第5幕の密度が第4幕に対して明らかに薄い。** 5-1〜5-4は各節が「素朴案→反例→正解」の1往復で終わり、第4幕にあった式の展開がほぼない。特にZMPは839–842行目で言葉の定義だけ、LIPMは831行目で名前だけ。第4幕が極配置とオブザーバを式で組み立てたのに、歩行の中心概念が定性的な説明で通過してしまう。

**やる夫が強すぎる箇所が2つある。** 903–910行目のレイバート3分割は、「独立に決めたい量は何と何と何だ」という問いに一往復で正解しており、教材中で最も非自明な問題分解が最も抵抗なく出る。1039–1042行目の角運動量の相殺と套路への接続も同様。第4幕では毎回失敗してから直したやる夫が、第5幕では当て続ける。

**師匠の背景が伏線として置かれながら回収されない。** 115–118行目でウラカン、メキシコ、アステカの戦神という設定が提示され、「なぜ最強だったか分かるか」と問いまで立つが、答えは「測って、応じたからだ」という抽象論のみ。1220–1224行目の回想も同じ内容の反復で、ウラカンの具体的な試合も敗北も一切描かれない。設定が装飾に留まっている。

**「戦うロボットを作る」と宣言しながら、最後まで一度も戦わない。** 14–16行目の目標に対し、第6幕は道具の答え合わせ（1143–1169行目）と未解決問題の提示で終わり、1216行目「いつかジェット・リーみたいに舞う日が来るお」と将来形のまま閉じる。第1幕で肩を押されて倒れた（47–51行目）ことに対する、実演としての決着がない。

**スペイン語の挿入が同型反復。** 19・66・93・727・1118・1224行目の6回すべてが「感嘆詞＋（訳）」の形。キャラクターの色付けとしては最初の2回で足り、以降は句読点のように機能している。

**判定装置を渡しながら不合格例で使っていない。** 619行目で可制御性行列 $\mathcal{C}$ の一般形を与え、合格例（1本の振り子）では計算させる（624–629行目）のに、不合格例の2本振り子では和・差の分解で済ませ、$\mathcal{C}$ のランクが落ちることを確認していない（632–643行目）。可観測性側（691–693行目）はさらに簡略で、行列を作らず言葉だけ。

**積分ワインドアップの扱いが不均衡。** 450–459行目。他の失敗はすべて数値か式で確かめるのに、ここだけ「覚えておけば十分だ」（459行目）で打ち切られる。

## 改善案

1. **5-1のZMPに式と数を入れる。** 842行目のあと、LIPMの関係 $\ddot{x} = \omega_p^2\,(x - x_{\mathrm{ZMP}})$ を書かせ、足裏長さ25cm・重心高さ0.9m（1007行目で既出の $\omega_p\approx3.3$）を代入して、ZMPが支持面内に収まる重心加速度の上限をやる夫に計算させる。5-3のキャプチャーポイントと同じ $\omega_p$ を使うため、第2幕から続く数の使い回しが第5幕にも及ぶ。

2. **ウラカンに1試合だけ具体を与える。** 118行目に、ウラカンが一度だけ倒れかけた（あるいは倒れて起き上がった）試合の描写を数行足し、その原因を4-7のむだ時間か5-5の起き上がりに対応させる。1220行目の回想でやる夫がその原因を言い当てる形にすれば、師匠の設定が伏線として機能し、第6幕に情緒的な決着が生まれる。

3. **レイバートの3分割の前にやる夫を一度失敗させる。** 903行目の問いの前に、やる夫が「全関節の角度を全部同時に制御するお」と答え、変数が多すぎて設計できないことを確認する往復を挟む。898行目で本人が「制御する変数が多すぎて頭がこんがらがる」と言っているので、その自覚を一度失敗として実演させてから3分割へ進めばよい。

4. **可制御性行列を不合格例でも使う。** 643行目のあと、2本振り子を $(\theta_1,\dot\theta_1,\theta_2,\dot\theta_2)$ の4次系として $\mathcal{C}$ を作らせ、ランクが2に落ちることを確認させる。可観測性側も同様に $\mathcal{O}$ を1回計算させれば、619行目と677行目で渡した2つの装置が、合格・不合格の両方で使われた状態になる。

5. **最後に一戦だけ置く。** 1224行目の後に短い場面を足す。やる夫のロボットがリングに立ち、第1幕と同じように肩を押され、今度はキャプチャーポイントで足を継いで立つ。第1幕（47–51行目）への直接の応答になり、冒頭の宣言が閉じる。

6. **ワインドアップを数値化するか、注記に落とす。** 454行目の「どんどん膨れ上がる」を、押さえつけ3秒・$\theta=5°$ 一定として積分値と解放時トルクを計算させ、他の失敗と同じ扱いに揃える。分量を増やしたくなければ、逆に一行の注記へ縮めて、道具箱の主要項目から外す。
