# 改訂記録（sol56-medium）

対象：`docs/books/control-engineering/README.md`

## 改訂方針

`review-opus-medium.md` の長所として挙げられた、倒立振子1本の数値を幕をまたいで使う構成、やる夫の失敗から理論へ進む流れ、套路をフィードフォワードとして復活させる回収は維持した。そのうえで、薄かった第5幕へ式・数値・失敗過程を加え、冒頭の「戦うロボット」という約束をリング上の実演で閉じた。

## 具体的な変更

1. ZMPを定量化した。
   - LIPMの式 $\ddot{x}=\omega_p^2(x-x_{\mathrm{ZMP}})$ を追加した。
   - 足裏長25cm、重心高さ0.9m、重心が足裏中心にある条件を置き、ZMPを支持面内に保てる水平加速度の上限を約 $1.36\,\text{m}/\text{s}^2$ と計算した。
   - 5-3のキャプチャーポイントと同じ $\omega_p=\sqrt{g/z}$ を5-1でも使い、第2幕からの数値の連続性を強めた。

2. ウラカンの背景を具体的な伏線にした。
   - 準決勝で画像処理装置の0.12秒の遅れにより踵が浮き、約30cmの回復歩で持ち直した試合を第1幕へ追加した。
   - 第6幕で、遅れの間に傾きが $e^{3.13\times0.12}\approx1.46$ 倍になることと、30cmの一歩がキャプチャーポイントだったことをやる夫に説明させた。
   - 「無敗」を単なる強さではなく、傾いてから間に合う手へ切り替えられた能力として回収した。

3. レイバートの3分割へ至る前に失敗を追加した。
   - やる夫が全関節を巨大な状態ベクトルへ入れ、全関節角を同時にPID制御しようとする案を出す。
   - 高さ・速度・姿勢の要求が同じ入力で衝突すること、空中と接地中を区別できないことから棄却する。
   - その後、関節ではなく運動の成果を分けるという段階を踏んで、高さ・前進速度・胴体姿勢へ到達させた。

4. 回転蹴りの発見にも抵抗を追加した。
   - 最初に軸足を高ゲインで固める案を出し、摩擦限界と空中では外トルクを得られない反例で棄却した。
   - 蹴りの反動が出てから直すのでは遅いと確認し、事前計算した全身の角運動量相殺、套路、フィードフォワードへ進むようにした。

5. 可制御性・可観測性の不合格例でも行列を使った。
   - 同一振り子2本の4次系で可制御性行列を明示し、$\operatorname{rank}\mathcal C=2<4$ を計算した。
   - 和だけを測るセンサーの可観測性行列も明示し、$\operatorname{rank}\mathcal O=2<4$ を計算した。
   - 和・差モードによる直観と、一般のランク判定を同じ例で接続した。

6. 積分ワインドアップを数値化した。
   - $5°$ の傾きで3秒拘束、$k_i=20\,\text{s}^{-3}$ と置き、積分値 $0.262\,\text{rad}\cdot\text{s}$、解放時の積分項による角加速度指令 $-5.24\,\text{rad}/\text{s}^2$ を計算した。
   - 積分値の上限に加え、飽和中の積分停止とバック計算に相当する対策も短く示した。

7. 最後に実戦を置いた。
   - 整備済みウラカンとの一ポイントマッチを追加した。
   - 第1幕と同じ肩当てに対し、重心水平速度 $0.99\,\text{m/s}$ から30cm先へ足を継いで立ち直ることで、冒頭の失敗へ直接応答した。
   - フィードフォワードの旋風脚と站樁フィードバックを同時に使って有効打を取り、「戦うロボット」を将来形でなく実演で完結させた。

8. できる子・できる夫の声を既存教材に合わせた。
   - リポジトリ内の複数教材を横断して、できる子は短い事実・計測報告で判定を止める役、できる夫は理解と実行が速く、完成前に企画や手続きを進める役として一貫していることを確認した。
   - できる子には安全確認、速度、接地点、最大傾斜、有効打だけを簡潔に報告させた。
   - できる夫には対戦表、配信、スポンサー、次回枠まで先に押さえさせ、最終実演を起動する役を与えた。

9. 演出上の反復を整理した。
   - スペイン語の感嘆は冒頭の2回だけに絞り、後半の同型反復を日本語へ置き換えた。
   - ホウキの動作を示す独立したト書きを削除し、やらない夫の発言として観察可能な内容を説明した。
   - 括弧書きの「メモ」は、やる夫が実際にメモすると発言する形へ変更した。

## 維持したもの

- 倒立振子、PID、極配置、オブザーバ、むだ時間、受動歩行、キャプチャーポイント、エネルギー整形の既存の式・数値・論理展開。
- 第1幕で否定した套路を、第5幕でフィードフォワードとして復活させる二階建て構成。
