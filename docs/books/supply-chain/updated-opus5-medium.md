# 改稿記録

`review-opus-medium.md` の改善案5点に沿って改稿した。

## 工夫した点・主な変更

- **安全在庫を実際に計算させ、教材の背骨にした（改善案1）。** できる子の数値に納期の標準偏差 0.8週を足し、やる夫に $SS=z\sqrt{L\sigma_D^2+\mu_D^2\sigma_L^2}$ を組ませた。計算の途中で最も効かせたのは内訳で、需要側 16,372 に対し納期側 58,370、つまり **納期のばらつきが3倍以上効いている**。ずっと「需要が読めない」と言っていた本人が、数字に「ファン屋がいつ来るか読めない」と言い返される形にした。1-2 の数円のネジで止まった経験と同じ場所に戻る。

- **サービス水準を上げる費用を、逓増として見せた。** 90/95/99/99.9% の4行の表を出させたうえで、行間の差額（202万→372万→416万円）を読ませ、「買う安心が薄くなっていくのに値段は上がる」「欠品0は $z=\infty$ で在庫が無限に要る」と言語化させた。既出の「欠品0は無理」がここで初めて数値の裏付けを得る。最後に $\sigma_L$ を 0.8 → 0.3 週に改善した場合を再計算させ、$SS$ が 451 → 259台、在庫金額が 902 → 518万円、差額 384万円を「打ち合わせで買える384万円」と言わせた。安全在庫の議論を、在庫を積む話から供給者の納期を締める話へ折り返している。

- **「欠品0を目指す」の正体を1行で言い直させた。** 「目標じゃなくて、金額を見ないための言葉だった」「451台と決めたいま初めて、年に何回か欠品することを選んだ」。教材冒頭の20台の欠品からの回収になっており、やらない夫の返しも「安全在庫は切らさないための在庫じゃない。どこまで切らすかを決めた結果の在庫だ」に変えた。

- **ブルウィップの命名をやる夫に取らせた（改善案2）。** やらない夫の「ブルウィップ効果という」を削り、やる夫に「ムチ現象」と名付けさせたうえで、やらない夫が「名前を付けたなら、その名前で説明できるかを試せ」と要求する。やる夫は $1.2^4$ で各段の掛け算として説明し、「振れが伝わるんじゃなくて各段で掛け算される」と言う。第4幕でできる子が文献側から「ブルウィップ効果、牛追いムチのことだ」と後接続し、脚注 [^2] をそこへ移した。あわせて同じ場面の「リスクプーリングという」も教師の口から外し、できる子の文献照合に統合した。教師による外部命名が2回減っている。

- **資金の線を1本通した（改善案3）。** 第2幕末（TCOで赤字が確定した直後）に、決算書を持って融資を受けに行く場面を新設した。できる子が同席して「その在庫は、いつ、いくらで現金になるのか」「『売れたら』は日付ではない」「在庫は資産の欄に載るが、拘束された現金でもある」「3,100万円持っているのに支払いができない会社」と説明する。運転資金枠 4,000万円・年利2.4%・月次で在庫金額と在庫回転日数を報告、という条件を置き、やらない夫が「ここから先お前が積むものは全部この枠から出る。財布は1つだ」と締める。既存のできる子（分析担当）を銀行員に仕立てず、同席者として説明役に置くことで人物設定を壊していない。

- **その財布を以後3か所で参照させた。** 4-1 の 3,200万円を「枠4,000万円の8割、翌月のファン代が払えない」に、5-2 の船上在庫を「倉庫と海の上と税関で置き場所は違うが削られる財布は同じ1つ、41日分の金利まで乗っている」に、7-1 の半年在庫1億円を「枠の2.5倍。調達には増資か追加融資で2か月、それはいま止まっている生産と同じ長さ」に接続した。「半年分持てば安心は、払える人だけが言える台詞だった」で締めている。孤立していた資金の言及が一本の線になる。

- **「反対側の崖」型を1回だけ破った（改善案4）。** 8-2 で、やる夫が「20か国へ工場を作る」と叫ぶ前に自分で止まり、案A（20拠点：設備40億円、維持費年6億円、売上見込み80億円に対し維持費だけで利益が消える）と案B（1拠点のまま災害損失を費用計上：3週間停止の概算4.8億円を20年に1回として年2,400万円）を先に見積もらせた。やらない夫の「今日は崖へ走らないのか」に対し「9回走った。10回目は先に見積もる」と返す。さらに、数字だけなら案Bが正解に見えることを認めさせたうえで、「20年に1回」を自分で決めて自分で安心しているのは 2-1 で隠れ費用を0と置いたのと同じ手口だと自己診断させ、金額に出ない損（次の製品の棚が取れない）を挙げて、問い自体を「止まったら困る工程だけ二重化する」へ変えさせた。成長を総括で述べるのではなく、意思決定の順序で示している。

- **5本の糸を第1幕に仕込み、色を確定した（改善案5）。** やらない夫の「最新という名前の表を3つ見た」昔話に落ちを付け、「止まった原因はものではなく情報だった」から5本の糸（白＝もの、青＝情報、黄＝金、赤＝責任、黒＝時間）を提示し、「落ちるたびに何色の糸が切れたか言え」と課した。以後、第2幕末（黄と青）、第5幕末（赤）、第6幕末（黒）でやる夫に申告させた。第6幕では「切れたんじゃなくて糸の長さを間違えていた」と、時間の糸だけ切れ方が違うことを言わせている。これにより 10-2 の「青い糸か」「赤い糸だな」「黄色い糸」「黒い糸も切れたか」「白いものの糸は存在する」が、その場の思いつきではなく9幕分の伏線回収になる。

## 残した判断

- 失敗が規模を変えて再発する螺旋構造、「言うのに10秒、やるのに数週間」の日数提示、やらない夫が同じ穴に落ちた過去を持つ造形、できる子が定量で逃げ道を塞ぐ役割、10-2 が「北米だけ1週間延期」で失敗を認めたまま着地する結末は、レビューで評価された骨格なので変更していない。

- できる夫の造形の単調さと、中盤以降の締切圧力の後退は欠点として挙げられているが、改善案には含まれていなかったため今回は手を入れていない。8-2 でやる夫が先に見積もりを始める改稿により、できる夫が煽る前に議論が決着する場面が1つ増えており、煽り役の出番の重みは相対的に下がっている。

- 追加した数値（$\sigma_L=0.8$週、原価2万円、枠4,000万円、年利2.4%、案A/案Bの金額）は、既存本文の数値と整合する範囲で置いた架空の値で、外部の実データは持ち込んでいない。参考文献7点と各脚注の対応箇所は、[^2] の位置移動を除いて変更していない。
