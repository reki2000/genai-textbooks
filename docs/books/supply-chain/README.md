# やる夫が全世界一斉発売するそうです ―― 地域限定製品から世界規模のサプライチェーンを構築

---
## 登場人物

**やる夫**：卓上食品乾燥機ドライポンを開発した小さな会社の社長。調子に乗りやすく、成功を確信すると都合の悪い事実を見なくなる。

**やらない夫**：やる夫の旧友。製造業と物流の経験を持つ。冷静に見えるが、自分の過去の失敗も引きずっている。

**できる子**：データ分析と生産技術を担当する技術者。感情を表に出すことは少ないが、数字をごまかす態度には厳しい。

**できる夫**：海外営業担当。優秀で行動が速いが、供給能力を確認する前に話を大きくする癖がある。

**やらない夫**：
世界同時発売は失敗だな。

**やる夫**：
そうだお。
完全同時にはできなかったお。
悔しいお。
ここまで準備したのに、最後に書類と権限で遅れたお。

**やらない夫**：
悔しいだけか。

**やる夫**：
……前なら原因が分からず、全世界を何週間も止めてたお。
今は問題地域を切り分け、他を動かし、1週間で戻せるお。
失敗だけど、壊れ方が違うお。

**やらない夫**：
それで十分だと言うつもりはない。
ただ、成長は失敗しなくなることだけじゃない。
失敗を広げず、早く戻せることでもあるだろ。

**やる夫**：
地域販売から世界発売まで、やる夫は同じことを何度もやったお。

注文後に全部作れば在庫はいらないと思った。
でも調達時間が顧客納期より長かったお。

部品は覚えていればよいと思った。
でも数円のネジが工場を止めたお。

最安部品を買えば利益が増えると思った。
でも輸送、不良、返品、余剰在庫まで含めると高くついたお。

2社から買えば安全だと思った。
でも上流材料や地域が共通なら同時に止まったお。

注文数が需要だと思った。
でも各段階の恐怖と上乗せが変動を増幅したお。

平均需要だけ作ればよいと思った。
でも需要変動、納期変動、工程能力で欠品したお。

倉庫を増やせば速くなると思った。
でも在庫が分断され、全国で余っているのに地域で欠品したお。

箱を丈夫にすればよいと思った。
でも輸送と保管の費用が増えたお。

国内版を翻訳すれば輸出できると思った。
でも電圧、規制、認証が製品仕様そのものだったお。

港へ渡せば仕事は終わると思った。
でも責任と書類がなければ貨物は動かなかったお。

検査を増やせば品質が上がると思った。
でも量産品質は工程の再現性から作るものだったお。

効率を最大化すれば強くなると思った。
でも余力を0にすると、小さな異常で全体が止まったお。

各国予測を足せば世界需要になると思った。
でも数字には利害が混ざり、共通の意思決定が必要だったお。

出荷すれば終わりだと思った。
でも修理、返品、回収まで責任は続いたお。

システムを入れれば全部見えると思った。
でも定義の違うデータを集めれば、精密な誤解ができるだけだったお。

**やらない夫**：
では、サプライチェーンとは何だ。

**やる夫**：
トラックの経路でも、工場と倉庫の一覧でもないお。

顧客が必要とする製品を、
必要な品質で、
必要な時に、
受け入れられる価格で届けるために、

市場は変わる。
部品は変わる。
規制は変わる。
災害は起きる。
人は自分を守るために数字を変える。
システムの中の定義も古くなる。

だから異常を見つける。
何が分からないかを認める。
記録を集める。
小さく試す。
失敗を修正する。
仕組みを更新する。

世界供給網は、巨大な完成品じゃないお。
学習し続ける仕組みなんだお。

**できる夫**：

**やる夫**：
火星語なんてないお。
電圧も大気も重力も輸送期間も分からないお。
まず市場条件と、顧客が待てる時間と、修理方法を調べるお。

**やらない夫**：
少しは学んだようだな。

**やる夫**：
でも100万台は捨てがたいお……！！

**やらない夫**：
そこは変わらないのか。

**やる夫**：
全部変わったら、やる夫じゃなくなるお！！
