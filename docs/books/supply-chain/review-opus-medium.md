# 寸評：やる夫が全世界一斉発売するそうです ―― 地域限定製品から世界規模のサプライチェーンを構築

約84KB／全10幕20節。卓上食品乾燥機の20台受注から20か国同時発売までを一直線に伸ばし、デカップリングポイント、TCO、ブルウィップ、リスクプーリング、認証、レジリエンス、S&OP、リバースロジスティクスを順に再発見する教材。

## 良い点

**失敗が螺旋で戻ってくる。** 1-1の「注文後に作れば在庫は要らない」（44–45行目）が、3-2で「在庫0になったら発注」として規模を変えて再発する（1094–1100行目）。やる夫が「前にも似た話をやった気がするお」と言い、やらない夫が「少し規模が大きくなって、同じ穴へ落ちたな」（1102–1103行目）と確認する。同じ誤りが大きくなって戻る構造は骨格として正しい。

**「言うのに10秒、やるのに数週間」が全編で数値化されている。** BOM整備3週間（559–560行目）、TCO算出2週間（734行目）、物流見積の比較可能化3週間（1283行目）、治具化7週間（1927–1928行目）、電源分離6か月（1555–1557行目）。思いつきと実装の非対称が、感想ではなく日数で提示されている。

**やらない夫が説教役に堕ちていない。** 工場長に3日口を利いてもらえなかった話（91行目）、最新という名前の表を3つ見た話（525–534行目）、競合と同じ工場の入口（803–811行目）、6-1での「注文の大きさに浮かれていた」（1757–1768行目）。教師役が同じ穴に落ちた過去を持つため、助言が上からにならない。

**できる子が「都合の悪い数字」の供給源として固定されている。** 全件調査4,800時間（905行目）、半年在庫は1億円（2001–2005行目）、そして「夢の費用を算出した」（2010–2011行目）。やる夫が精神論で逃げるたびに定量で塞ぐ役があり、教師の反論を数値へ代行させている。

**10-2の「5本の糸」が総合演習になっている。** ものは全部あるのに、情報（2750–2753行目）、責任（2769–2772行目）、金（2777–2778行目）、時間（2785–2786行目）が切れて商品にならない。解決も「全部守る」ではなく「北米だけ1週間延期」（2800–2804行目）で、失敗を認めたまま着地する。参考文献7点も命名箇所へ脚注で紐づいている（2935–2941行目）。

## 欠点

**定量的な再発見がほぼ存在しない。** 式は $ROP=\mu_L+SS$（1169–1171行目）とTLCの費目列挙（2363–2372行目）だけで、後者は式ではなく項目名の羅列。致命的なのは、できる子が「標準偏差61台、納期平均4.4週・最長6.2週」（1156–1158行目）と分布を渡しているのに、やる夫が $SS$ を一度も計算しないこと。「$SS$ は魔法の定数じゃない」（1174行目）と言った直後に、魔法の定数のまま終わる。「欠品0は無理」（1123行目）は本来、サービス水準を上げたときの在庫費の跳ね上がりを自分で計算して初めて腹に落ちる結論のはず。

**20節すべてが同一の型。** 「極端案を叫ぶ→失敗→反対の極端へ走る→中庸に着地」。1083行目「最大400台に合わせて毎週400台作る」、1253行目「なら中央倉庫1か所に戻す」、2332行目「20か国へ工場を作る」。作中でも「また反対側の崖だったお」（2339行目）と自認しているが、自認は解決ではなく、読者は3節目で次の展開を予測できる。

**命名が常に外から降ってくる。** やらない夫の「〜と呼ぶ／〜という」が359、564、912、1036、1198、1315、1437、1568、1681、1808、2164、2291、2595行目と13回。やる夫は仕組みを自分の言葉で言語化するところまでは行く（1032–1033行目「ムチみたいだお」は良い）のに、名前だけは必ず教師が与える。

**会社の資金が説明されない。** 口座に家賃2か月分しか残っていない会社（247行目）が、6-1で数千万円を失っても（1746–1748行目）翌幕から10万台を出荷している。融資も出資も一度も登場しない。金は本作が「同期させる」と宣言した5要素の1つ（2886行目）であり、そこだけ空白なのは主題との齟齬になる。

**できる夫が同じ機能を7回果たすだけ。** 1450、1691、2096、2177、2607、2732、2907行目、いずれも「!!」で過大な数字を持ち込み煽る。唯一の例外が2218–2220行目の「予測比例で配分される制度だから各地域が確保に走る」という制度分析で、この面が展開されないまま火星ネタへ戻る。

**中盤以降、期限の圧力が回顧形式に置き換わる。** 第1幕の「7日後」「広告5,000枚」（33、204行目）は現在進行形で効いているが、6-2以降は「7週間だお」「3か月かけて」（1928、2664行目）と事後報告になり、読者が締切と一緒に焦る箇所が最終節までない。

## 改善案

1. **1161–1176行目で安全在庫を実際に計算させる。** できる子が出した $\sigma_D=61$ と納期のばらつきを使い、やる夫に $SS=z\sqrt{L\sigma_D^2+\mu_D^2\sigma_L^2}$ を組ませる。次にサービス水準90%／95%／99%の3点で在庫金額（1台原価2万円は1246行目で既出）を出させ、99%が資金的に不可能であることを自分の計算で確認させる。20行で済み、1123行目の結論が実感から数値へ格上げされる。
2. **ブルウィップの命名をやる夫に取らせる。** 1036行目のやらない夫の「ブルウィップ効果という」を削り、以後2〜3節はやる夫の「ムチ」で通す。4-1あたりでできる子が「その現象は文献ではブルウィップ効果と呼ばれる」と後から接続する。順序が入れ替わるだけで再発見の主体が移り、13回の外部命名のうち少なくとも1回が内側から生える。
3. **資金の線を1本通す。** 第2幕末（713行目の赤字の直後）に銀行担当か出資者のできる子を1回だけ登場させ、「在庫は資産ではなく拘束された現金だ」と突きつける短いやり取りを置く。以降、4-1の3,200万円（1246行目）、6-1の数千万円、7-1の1億円（2003行目）が同じ財布から出ていると読者に見え、5-2の「船上の商品も資金を占有してる」（1674行目）の孤立も解消する。
4. **「反対側の崖」型を1回だけ破る。** 第7幕か第8幕の1節を、やる夫が極端案を叫ぶ前に自分から2案の費用比較を始める形で書き、やらない夫に「今日は崖へ走らないのか」と言わせる。成長を最終節の総括（2829–2874行目）で述べるのではなく、構造で示せる唯一の手段。
5. **5本の糸を序盤に仕込む。** 2756行目の「青い糸か」は初出がここでは唐突。525–534行目のやらない夫の昔話の直後に「もの、情報、金、責任、時間のどれが切れても止まる」と一言置き、各幕末でどの糸が切れたかをやる夫に言わせる。最終節の色分けが伏線回収になり、2886行目の定義も唐突さを失う。
