# 改稿記録

`review-opus-medium.md` の7つの改善案をすべて反映した。全10幕＋終幕、白紙の島という舞台、各幕の事件は維持したまま、後半で痩せていた「やる夫が案を出して潰される」往復を戻し、幕をまたぐ縦糸を2本（浜の紛争、コミカドくん）通した。

## 主な変更

- **第1幕の土地紛争を、最後まで通る縦糸にした。** 1-1 で「事前に決める」と言わせて終わらせず、やる夫に取得順序（先使用／表示を信じた費用／公共利用＋費用は島が負担）を条文として書かせ、その基準で浜を漁師に、第3区画を移住者に確定させた。やる夫は自分の書いた基準に自分で負け、失言の代金を島の予算から払う。第7幕はこの2人の続きの事件に差し替えた（通路の通行を100万円で買ったか、見舞金でもらったか）。1-1 で作った台帳に残っていた漁師自身の申出書が勝敗を決め、やらない夫が「その記録がなかったら」と問うことで立証責任の意味が事後の反実仮想として立つ。7-2 の執行では、判決の相手が漁師なので差押えの対象が船（生業）になり、比例と差押禁止の話が具体的な痛みを伴う。10-3 では新しい土地法が 1-1 の基準を変えるため、漁師と移住者の既得の割当をどうするかが経過措置の実例になり、やる夫が附則の「みなす」規定を自分で書く。
- **法律デバッガをコミカドくんと命名し、幕ごとに成長させた。** 2-2 で5項目とともに命名し、やらない夫の「コミカドくんとは何だ」「出どころを聞いているんだが」に対して、やる夫は「なんとなく有能な感じがするから」「やる夫が考えたに決まってる」とごまかす（元ネタには触れない）。以後、第3幕末に「衝突しているのはどの価値とどの価値か」、第4幕末に「誰が判断し、誰が止められるか」、第7幕末に「事実が不明なとき、そのリスクを誰が負うか」、第10幕末に「制度を変えるとき、誰の期待を守り、誰にいつまで猶予を与えるか」を追加。終幕のAI契約4万件は、この9項目を1番から順に当てはめる形へ書き換え、各項目の適用時に唐揚げ、公園、権力集中、証明できない100万円、ひっくり返しかけた台帳という過去の失敗を名指しで参照させた。旧版は無関係な8項目が終幕で唐突に現れていた。
- **5-2 と 6-1 に失敗の往復を足した。** 5-2 では、やる夫にまず「点検を怠った1人に全額負わせる」案を出させ、できる子が数字で潰す（記録は工場内、整備会社は3か月前に破産、鑑定費180万円・期間2年、被害者は先払い）。被害者の「2年どこに住む」で、「誰も払わなくていい」が中立でなく被害者への配分だと自分で気づく。そこから危険責任（記録を持つ者同士に争わせる）と保険（責任確定前に支払を届ける速い経路）を、名詞列挙でなく必要から導いた。6-1 では、やる夫に1件9日の確認を職員3人で412件回す所要期間を計算させ、3年半という数字を自分で出させた。
- **条文の実物を3か所で見せた。** 3-1 に刑法37条1項を引用し、やる夫の「守った利益の方が大きい」との差（「超えなかった場合」／「現在の」危難／「やむを得ずにした」）を本人に指摘させた。同じ 3-1 の罪刑法定に憲法31条・39条を置き、1-2 でやる夫が思いつきで言った遡及処罰の話が先に憲法へ書かれていたことを確認させた。5-1 の公序良俗は民法90条を1行だけ示し、「なぜ中身が空欄なのか」を、できる夫が禁止の隣を通る契約を作り続けるという本書の設定から答えさせた。既存の参考文献 [^3] [^4] [^5] が本文から使われるようになった。
- **やる夫に数を計算させた。** 3-1 で、発覚確率10%・罰金100万円（期待値10万円）と発覚確率80%・罰金10万円（期待値8万円）を比べさせ、さらに「額の書き換えはタダ、検挙率の引き上げは予算」という費用差まで自分で言わせた。6-1 の3年半も同じ趣旨。数値がすべてできる子から降ってくる状態を解消した。
- **島に期限と利害を置いた。** 冒頭で任期1年・1年後の信任投票・昨年の転出3人（理由は約束が守られなかったこと）を提示。6-1 では隣のカネ島が先に取引規則を公布し、移住申込みが月十数件から2件へ落ちる。10-3 では「1年待って完璧にする」案に対し、できる子が信任投票まで1か月・施行日は次の管理人が変更できると告げ、やる夫は条文ごとに施行日を分ける判断へ追い込まれる。終幕で信任162対38、反対理由の最多は「決定が遅い」とし、勝ってもなお制度の速度が代償として残る形にした。
- **末尾の重複表を差し替えた。** 9-1 の3×3の座標表は残し、末尾の六法一覧表は削除。代わりに 9-2 の8事件が座標のどの列にまたがるかと、主に扱う分野を示す表へ置き換えた。9-2 の結論「新しい分野は座標をまたぐ」が締めで可視化される。
