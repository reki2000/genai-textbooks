# 寸評：やる夫で学ぶ法律学 ― 争いを終わらせる仕組みを再発明する

約58KB／全10幕＋終幕。無法の人工島で「法律がなくても善人同士なら争わない」と信じるやる夫が、目の前で起きる紛争を潰していくうちに、所有権・成文法・法の支配・人権・訴訟・執行・立法実務を順に再発明していく教材。

## 良い点

**「白紙の島」という舞台が、制度の必要性を毎回ゼロから問い直させる。** 制度がないところに事件を投げ込むので、やる夫は既存法を引用できず自分で規則を作るしかない。第1条を「管理人がその場の気分で公平に決める」と書いて即座に否定される（132–137行目）くだりは、法律の役割が「正しい結論」ではなく「事前の予測可能性」だと悟る（147–149行目）導入として鮮やか。

**当事者が反論する役として実在している。** 漁師と移住者が、やる夫の折衷案を実務的な理由で潰していく（64–76行目）。半分に分ける・曜日で交代という素朴解が、船の引き上げと家の建築という物理的事情で死ぬ。教師が説教で否定するのではなく、当事者の生活が否定する構造になっている。

**できる夫が「制度は利用方法も生む」を体現している。** 騒音規制に「緊急時を除く」を追加した瞬間に「新商品の発売日は緊急事態です」と入り込み（323–326行目）、有限責任を説明した直後に「その利用法、もう事業計画に入っています」と言う（782–783行目）。抜け道の発見が講義でなく登場人物の行動として起きるため、条文設計の難しさが体感になる。

**自分が少数派になった瞬間に権利を発見させる一撃。** 180対20で公園を作ると宣言したやる夫に、「次の投票で199人がお前の財産を分配する案に賛成したら？」と返す（538–543行目）。「自分が少数派になった瞬間、権利を発見したな」（546行目）は本書で最も鋭い一行で、人権が多数決の外側にある理由をこれ以上短く説明する方法はない。

**法令用語と立法実務を、入門書がまず扱わない深さまで踏み込んでいる。** 「みなす／推定する」の効果差（396–400行目）、「及び／並びに」が括弧の代わりに構文木を表すこと（416–420行目）、改め文と溶け込み方式（1137–1154行目）、附則の経過措置と「なお従前の例による／なおその効力を有する」の違い（1229–1236行目）。特に改正法をパッチに、施行日競合をマージ競合に喩える（1153行目、1182行目）のは、読者層に対して非常に効く比喩。

**参考文献が一次資料中心で、各項目に内容説明が付いている。** 参議院法制局・内閣法制局・e-Gov・裁判所の16点（1391–1421行目）。ネット記事や概説書ではなく制度の運用主体の公式解説を引いている点は信頼できる。

## 欠点

**第4幕以降、やる夫の「再発見」が相槌に痩せる。** 構成要件・違法性・責任の三分説は、やらない夫が一気に述べて終わる（496–498行目）。民法の限界原理（701–702行目）、危険責任・製造物責任・使用者責任（744行目）、会社法の規制群（789行目）も同様に名詞の列挙で、やる夫の役割は「〜なんだお」とまとめ直すだけ。第1幕〜第3幕でやる夫が案を出しては潰されていた密度が、後半では失われている。

**5-2と6-1が事件の提示だけで終わっている。** 5-2（717–748行目）は工場の事故を出し、やる夫が3回発言して結論に着地する。6-1（754–794行目）も同様。他の節が10〜20往復あるのに対し、この2節はやる夫が誤った案を出して潰される往復が1回もなく、節としての機能が概念紹介に留まっている。

**第1幕の土地紛争が決着しないまま放置される。** 漁師と移住者の争いは、台帳を作る（127–129行目）と基準を事前に決める（141–142行目）で幕を閉じ、結局どちらが浜を得たのか本文に書かれない。以後の幕にも再登場しない。教材全体の起点となる事件なので、第7幕（訴訟）や第10幕（経過措置）で「あの浜はどうなったか」を回収できたはず。

**「法律デバッガ」が名前だけ引き継がれ、中身が繋がっていない。** 2-2で5項目のリストとして導入される（361–367行目）が、その後一度も更新・使用されず、終幕で全く別の8項目として再登場する（1321–1330行目）。同じ道具の名前を使うなら、幕ごとに項目が増えていく形にしなければ「道具を組み上げた」感が出ない。

**具体的な条文・判例がほぼ一つも出てこない。** 明示されるのは日本国憲法98条・81条（621行目）だけ。正当防衛・緊急避難は「守った利益の方が大きい場合がある」（486行目）と概念のまま流れ、刑法36条・37条にも触れない。参考文献にe-Govの刑法・民法（1397–1399行目）を挙げているのに、本文で条文が引かれない。抽象度が高い章ほど、条文1本を実物として見せる価値が大きい。

**物語的な圧力が存在しない。** やる夫は「臨時管理人」（7行目）だが、任期も予算も上司も島民の不満の蓄積もない。制度設計に失敗しても何も失わないため、10幕を通じて緊張が単調。終幕のAI契約4万件（1309–1311行目）でようやく事態の規模が上がるが、そこでも誰も損害を被っていない。

**まとめの表が9-1と重複している。** 1016–1020行目の表と1375–1382行目の表が同じ六法の対応関係を扱っており、後者は分量を増やしただけ。9-1で既に「半分正しく、半分違う」（1026行目）と脱神話化した後なので、末尾の表は繰り返しに感じられる。

## 改善案

1. **第1幕の土地紛争を最後まで通す縦糸にする。** 129行目で「最初の帰属を決める基準は別途必要」とした後、その基準を第1幕の末尾でやる夫に条文として書かせ（先使用・登記・費用・公共利用の優先順位）、実際に漁師と移住者のどちらが勝つかを決めさせる。そのうえで第7幕（797行目以降）に、その決着に不服の当事者が提訴する形で同じ2人を再登場させ、立証責任と執行の話を彼らの事件で扱う。終幕近く（1191行目以降の経過措置）でも「旧管理人時代の割当をどう扱うか」として拾えば、10幕を貫く1本の事件ができる。

2. **法律デバッガ「コミカドくん」を幕ごとに成長させる。名の絵はやる夫が好きな法廷ドラマ、リーガルハイの主人公からとった名前だが、触れない。やらない夫に命名をつっこまれて、「なんとなく有能な感じがするから」、とごまかす。** 361–367行目の5項目を、以後の幕の末尾で1〜2項目ずつ追加していく形にする（第3幕で「衝突する価値は何と何か」、第4幕で「誰が判断し誰が止められるか」、第7幕で「不明のリスクを誰が負うか」、第10幕で「経過措置で誰の期待を守るか」）。終幕1321行目でやる夫が使うのは、その積み上がったリストそのものにする。現状の断絶はこの教材で最も惜しい設計上の穴。

3. **5-2と6-1に失敗の往復を足す。** 5-2では、やる夫にまず「点検を怠った者を探して全額負わせる」案を出させ、被害者が誰も特定できないまま数年経つ現実（証拠が工場側にしかない、整備会社が倒産した等）をできる子に数字で提示させて潰す。そのうえで危険責任や保険へ進めば、744行目の名詞列挙が「なぜそれが要るか」に変わる。6-1も、やる夫が全取引を民法原則で確認しようとして所要日数を試算し、船が出ないことを自分で確認する往復を1つ入れる。

4. **条文の実物を最低3か所で見せる。** 484–486行目の緊急避難のくだりで刑法37条の条文を引用し、「現在の危難」「やむを得ずにした行為」「生じた害が避けようとした害の程度を超えなかった場合」という要件が、やる夫の言った「守った利益の方が大きい」とどう違うかを比べさせる。同様に3-1の罪刑法定（508行目）で憲法31条・39条、5-1の公序良俗（701行目）で民法90条を1行ずつ実物で示す。抽象語の連なりが一気に具体化する。

5. **やる夫に一度は数を計算させる。** 現状、数値はできる子が提示するもの（192行目の87件、1099–1100行目の12万条・矛盾37件）ばかりで、やる夫が自分で計算して驚く場面がない。例えば3-1（511行目「罰を重くすれば犯罪がゼロになるのか」）で、発覚確率10%・罰金100万円と発覚確率80%・罰金10万円の期待コストをやる夫に比べさせ、刑の重さより検挙率が効くことを自分で出させる。10-2の参照切れ（1160–1165行目）も、影響する条文数を実際に数えさせるとよい。

6. **島に期限と利害を1つ置く。** 冒頭（28–31行目）に、やる夫の管理人としての任期（例：1年後に島民の信任投票がある）と、失敗すれば島から人が出ていくという具体的な損失を設定する。第6幕の交易（756–758行目）で「他島が先に制度を整えたら商人はそちらへ行く」という競合圧力を入れれば、第10幕の「準備期間を長くすればよいとも限らない」（1261–1263行目）が実際の判断として効いてくる。

7. **末尾の表を統合する。** 1016–1020行目の3×3の表を残し、1375–1382行目の表は削って、代わりに六法に入らない分野（9-2の8事件、1053–1060行目）が座標のどこをまたぐかを示す図に差し替える。同じ内容の表を2回置くより、「座標をまたぐ」という9-2の結論（1085–1086行目）を可視化するほうが締めとして強い。
