# 改稿記録

## 工夫した点

- 完成済みの「遵守の六角形」を冒頭で教える構成を改め、やる夫が各幕の失敗から認知・理解・合理性・実行可能性・社会規範・正当性と信頼を一つずつ命名し、第7幕で初めて六角形として閉じる流れにした。
- 期待利得式へ実数を代入し、過料額と発見確率を変えた場合をやる夫自身に計算させた。計算結果から監視案が出て、その限界を検討する因果にした。
- 「違反ゼロ」の速報を実際に記者へ送らせ、撤回と信用低下を後の説明会まで残した。第1幕の「6か月後に焼却量8%減」という議会への約束も、最終幕の6.3%公表で回収した。
- 長い総括発言は問い返しを挟んで分割し、結論を一息で列挙する箇所を減らした。

## 主な変更

- できる夫を第3幕の顔認証監視案から登場させ、第7幕の再提案を反復ギャグと学習の確認にした。
- 市民A・B・Cを佐藤さん・林さん・グエンさんとして人物化し、第6幕の要望と第8幕の危機協力へ再登場させた。
- 第7幕の4件目で、やる夫が合理性の問題と誤診した後、6週間の行動記録によって社会規範の仮説へ修正する場面を加えた。
- 第8幕の「良いルールの8条件」の再掲を、規範の可視化と例外利用者のプライバシーが衝突する具体問題へ置き換えた。

## 残した判断

- 冒頭の47袋、情報到達ファネル、第4幕の1週間実践、危機時の処理能力データ、6か月後の成果値は、物語の回収と理解を支えるため維持した。
- 罰則を否定するのではなく、危険度・反復性・証拠・手続的公正に応じて使う立場、および既存の参考文献構成は維持した。
- 数式は厳密な予測モデルではなく思考補助である旨を残し、期待利得の計算値にも「単純化した発見確率」と明記した。
