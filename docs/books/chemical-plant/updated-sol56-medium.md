# chemical-plant 改稿記録

## 工夫した点・主な変更

- 冒頭に「3年後のサンプル供給」という対外公約と100億円の投資会議を置き、第5幕の時間・需要リスクが物語上の判断へつながるようにした。
- 分析・運転担当の「できる子」を追加した。第1幕では槽内温度、第8幕では温度・水分・粒径・連続運転時間を報告させ、「やらない夫がそう言うから」ではなく実測値で楽観が崩れる構成にした。
- 蒸留の60%→70%という与件を、濃度比と対数を使って99.9%まで計算した。理想段数と段効率を分け、30段・還流比2と18段・還流比5の概念比較で、建設費と運転費のトレードオフを数値化した。
- 第5幕でA（商用一括）・B（パイロットから段階投資）・C（見送り）を提示し、やる夫にB案を選ばせた。終幕で、その投資が失敗の実測値を買ったものだったと回収した。
- 終幕の反応器論争は、建設費七項目を100%に足し上げ、反応器が説明例では4.5%にすぎないとやる夫自身に計算させた。
- 工場図鑑は九業種をやる夫が暗唱する形をやめ、やらない夫がカードを提示し、やる夫が供給網上の位置を誤答・修正する短い推論場面へ改めた。
- 同一幕の自己参照、共沸の自己参照、滞留時間の重複表記、第2幕の廃棄物を第3幕とした誤参照を修正した。
- 参考文献節と個別注を追加し、歴史・設備費・見積り精度の数値が概数である範囲を明記した。

## 残した判断

- 枝番を含む節番号は既存の相互参照と読者の位置情報を一斉に壊すため、今回は維持した。全編のリンク・索引を同時に更新できる段階での一括改番が安全と判断した。
- 幕間展示や熱回収節は重複感があるが、削除すると後段の回収と参照も広く再設計する必要があるため、今回の改稿では物語の圧力・定量性・登場人物の役割という優先度の高い欠点を先に直した。
- 建設費割合、蒸留段数、パイロット実測値は教材上の説明例であり、特定の実在プラントの設計値ではないことを本文で明示した。
