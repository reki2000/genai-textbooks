# やる夫が携帯電話会社のCTOになるそうです ── 無線通信をゼロから建てる の骨格

やる夫は新設携帯会社のCTO、やらない夫は無線の古参技術者、できる子は電波測定班主任（実測値を抑揚なく置く役）。**第1幕で3つの壁**が立てられ、終幕で「どの世代も新しい壁を壊したのでなく、同じ3つの壁をより賢く踊って回避してきただけ」と総括される。

- **壁1（物理）**：波長がアンテナに乗らない／距離で減衰／フェージング・マルチパス・ドップラー
- **壁2（情報）**：シャノン $C=B\log_2(1+\mathrm{SNR})$ の天井
- **壁3（規制・共有）**：使える電波は**20MHzだけ**

同時に**経営数値**が固定される：免許料**420億円**（支払済）、サービス開始まで**18か月**、設備投資枠**1,200億円**、先行3社。これが 6-1 の局数計算と 7-3／7-5 の調達判断で効く。

**やる夫が計算を外す回数は3回**で、終幕で本人が数え上げる：ARQで1パケット8分（4-1）、伝搬指数 $n=2$ で半径31km→実測2.7km（3-1）、MIMO 2×2で2倍→郊外1.06倍（4-5）。いずれも「式は正しく、前提が現場と違った」。

## 第1幕　「でかいアンテナで叫べばいい」が死ぬ日
- 声3kHz→波長100km→**アンテナ長25km**で壁1。距離2倍に出力4倍で壁1。20MHzしかないで壁3。ここで420億円・18か月・1,200億円が提示され、「技術の前に金と締切がある」。

## 第2幕　電波に情報を載せる ── 変調とシャノンの壁
- 2-1　逆算：アンテナ8cm→波長32cm→**900MHz**。搬送波と変調。**周波数分割が壁3にも効く**とやる夫が自分で気づく。いじれるのは $A/f/\phi$ の3つ。
- 2-2　AMは雑音が情報の入っている場所を直撃 → FM（リミッタで振幅を捨てる）＋捕捉効果。代償は帯域（AM数kHz対FM 200kHz）＝**雑音耐性を帯域で買う**。AMラジオが雷でガリガリ言う実感で確認。1Gはこれ。
- 2-3　アナログは中継のたびに雑音が積算 → **再生中継**のためのデジタル化。ナイキスト定理から8kHz×8bit＝**64kbps**（G.711）、CDの44.1kHz/16bit、エイリアシング（車輪の逆回転）と保護フィルタ。
- 2-4　**この教材の理論的な山場**。BPSK→QPSK→多値化で、点を64倍にすると隣との距離が1/8になり誤判定。適応変調のはしご（QPSK/16QAM/64QAM/256QAM/1024QAM＝電波表示のアンテナ本数の正体）。そのうえで**やらない夫は式を与えず、やる夫が点を数えてシャノン容量を自力で導出**する：間隔 $\sigma$ で $n\approx1+A/\sigma$ 点 → $\log_2(1+A/\sigma)$ ビット → ナイキストで毎秒 $2B$ シンボル → 電力に直して $A/\sigma=\sqrt{\mathrm{SNR}}$ → $C\approx B\log_2(1+\mathrm{SNR})$。**「なぜ log なのかはお前がいま自分で見た＝点を増やす努力は対数でしか報われない」**。20MHz・SNR 30dBで**約199Mbps**が上限。

## 第3幕　チャネルが牙をむく
- 3-1　**予測を先に紙に書かせてから測る型の初出**。やる夫が $n=2$ で半径31kmと書き、できる子が3kmで圏外と報告。100m→1kmで35dB落ちから $10n=35$ で**伝搬指数 $n=3.5$** を逆算し、引き直して2.7km。**距離で11倍、面積で約130倍の誤り**＝1,200億円が溶ける。以後「やる夫が設計値を出したらできる子が測る」順番が確立。
- 3-2　マルチパスと干渉。900MHzの半波長16cm＝**半歩動くと30dB落ちる**。アナログTVのゴースト、トンネルのラジオ。第二の顔＝遅延1μsが次シンボルに被る**ISI**で、高速化するほど悪化（0.1μsなら10シンボル分の尾）。**やらない夫が「マルチパスは今は最大の敵だが後で友になる」と明示的に保留**（4-5 で回収）。
- 3-3　ドップラー。時速100km・2GHzで185Hz、新幹線300km/h・3.5GHzで970Hz、対向列車ですれ違うと反転。

## 第4幕　チャネルを叩く道具箱
- 4-1　**やる夫が自分で仕様を書いて自分で殺す**：1000ビット／RTT20ms／ARQに対し、BER $10^{-2}$ だと成功率 $0.99^{1000}\approx4.3\times10^{-5}$、平均23,000回、**1パケット8分**。→ FEC。3回反復（符号化率1/3）→ ハミング(7,4)で0.57＝**冗長の配り方の構造**。畳み込み＋ビタビ（2G）、45年の壁を破ったターボ符号（1993、シャノン限界1dB手前、復号器同士の確率の対話）、LDPC、ポーラ符号。5Gはデータ＝LDPC／制御＝ポーラの使い分け（短くて落とせない対長くて高スループット）。CD（CIRC）、QRコード、ボイジャーへの一般化。**第2幕のシャノンの壁を「越える」のでなく「壁ギリギリまで無駄なく詰める」戦いだったと回収**。
- 4-2　バースト誤りに**インターリーブ**（散らして飛び飛びの誤りに化けさせる）と**ダイバーシチ**（時間／周波数／空間＝谷が重ならない別軸）。CDの傷、Wi-Fiルーターのアンテナ本数。散らす＝遅延との綱引き。
- 4-3　スペクトラム拡散（GPS、対妨害）と**RAKE受信機**＝分離した反射波を遅延を揃えて足す。**「敵だったエコーが戦力になった、友になりかけている」**（完全な反転は 4-5 と予告）。
- 4-4　**OFDMの直交条件をやる夫が積分で導く**。ISIは「シンボルが短いから」→シンボルを長く→遅くなる→**並列化**（20MHzを1000本、各20kHz）。$I=\int_0^T\cos(2\pi f_1t)\cos(2\pi f_2t)dt$ を積和で展開し、**$|f_1-f_2|=k/T$ なら $I=0$**＝隙間ゼロで重ねられる。FFTで安く実装。**その直後にやらない夫が「その積分に反射波を入れてみろ」と問い、積分区間の頭に前シンボルの尻尾が入ると整数周期が崩れて $I\neq0$ になる**ことを示し、**巡回プレフィックス（CP）＝やる夫の計算の前提を守る柵**へ。代償はLTEで約7%＝「$C$ を7%捨ててISIをゼロで買う」。LTE 15kHz固定／5Gニューメロロジー15/30/60/120kHz、Wi-Fi、地デジ、ADSL。
- 4-5　**3-2 の保留を回収**。MIMOは受信2本の式が「A×a+B×b」「A×c+B×d」の**連立方程式**で、経路が違うほど解ける＝**マルチパスが豊かなほど分離しやすい**。ここで2度目の予測外し：できる子の実測が地下街1.92／市街1.71／**郊外1.06**。見通しがよいと経路が似て**連立方程式が退化**する＝MIMOの利得を決めるのはアンテナ本数でなく経路の差異。「郊外に2×2は金の無駄」＝6-1 の投資配分に直結。ビームフォーミングとmassive MIMO（64T64R）は 7-5 のmmWave救済と 8-2 のフェーズドアレイで再登場。

## 第5幕　大勢で分け合う ── 多元接続
- 5-1　FDMA。できる子の実測**音声稼働率38%**により、100本配って62本が常時遊ぶ＋ガードバンド。1G AMPSは1通話30kHz占有＝20MHzで600人。TDMA（GSM 200kHz÷8スロット、577μs、電池が持つ副産物）も固定割当という同じ病気。
- 5-2　CDMA。**直交を比喩でなく内積で示す**：$c_A=(+1,+1,+1,+1)$、$c_B=(+1,-1,+1,-1)$、混合 $(2,0,2,0)$ から掛けて足すだけで両方復元、$c_A\cdot c_B=0$。次にできる子が「到着時刻差は最大1.4チップ」と置き、**やる夫が2段階で計算する**：等電力で1チップずれ→$+0.5$（判定は正解）、**振幅3倍のB→$-0.5$ で符号が反転**＝**近遠問題**（ずれた残りかすに電力差が掛け算される）。解は高速電力制御（IS-95で毎秒800回、W-CDMAで1500回）とソフトハンドオフ。1.2288／3.84Mチップ/秒、周波数再利用1。
- 5-3　OFDMA＝時間×周波数の升目（LTEは12サブキャリア180kHz×0.5ms）を1msごとに動的配分。**マルチユーザーダイバーシチ**（誰かの谷は誰かの山）。4方式の総括表。締めは「20MHzは**日本全体で**20MHz、東京だけで1000万人」で第6幕へ。

## 第6幕　国土を覆う ── セル方式という発明
- 1本鉄塔＝全国同時100通話 → **セル分割と周波数再利用**、7色クラスタ（1/7の取り分×数万セル）、色数を減らすと容量↑干渉↑のトレードオフ、セルスプリッティング、マクロ／マイクロ／スモールセルの寸法。1947年ベル研の概念、1979年NTTで実現。
- **経営の山場**：できる子が半径2.7km（3-1 の実測）、マクロ1局2.5億円、マイクロ0.4億円を出し、やる夫が六角形面積 $2.6r^2\approx19$ km² → 8,000km²÷19＝**421局×2.5億＝1,053億円**、残**147億円**÷0.4＝**367局**。選択は**「面を薄く広く取るか、点を厚く取るか」**。ここで **4-5 のMIMO実測を使い、郊外のマクロは1×1、MIMOは地下街と繁華街の367局だけ**と決める＝物理と財務が同じ紙の上で決まる。ハンドオフとピンポン・ハンドオーバ。最後に**「同じ周波数を離れた場所で再利用するトリックを、第8幕で空でもう一度使う」と保留**。

## 第7幕　世代と政治 ── 規格は誰の思惑で決まったか
- 7-1　**やる夫を1980年の通信当局に立たせる**。AMPS採用対自国仕様の2択表を与えると、やる夫は自国仕様を選ぶ。答え合わせ：NMT、TACS、NTT大容量方式＝**全員が同じ理由で同じ選択をし、各国個別には正しかったのに合計すると世界が分断された**。「あの盤面ならもう一度自国仕様を選ぶ、それが怖い」。
- 7-2　GSM＝欧州の政治プロジェクト（単一市場の象徴、ノキアとエリクソンを育てた産業政策）、SIMカードの発明。
- 7-3　**1999年、3Gの陣営選択**。CDMA2000／W-CDMA／独自方式の3択表（移行費用3,400億／1,100億／2,000億、特許の重し、GSM資産の流用可否）。やる夫は最初「動いている方」に傾くが、自社がGSM資産を持つことに気づき、**技術の新しさでなく移行経路と特許の重しで W-CDMA を選ぶ**。答え合わせでFOMA 2001年。さらに**「技術の賭けに勝って普及の戦争に負けた」**クアルコム、巨大な国内市場を持つ国の動機からTD-SCDMA（中国）を自力で推論。
- 7-4　4Gの大収斂。クアルコムがUMBを2008年に中止。**LTE対WiMAXで、やる夫は7-3と同じ物差し（移行経路とエコシステム）を自分から適用**して即座にLTEを選ぶ＝「同じ間違いを二度しなかった」。
- 7-5　5Gの三すくみ（eMBB／URLLC／mMTC）を**同時最適化できない**と看破し、ニューメロロジーとネットワークスライシングで捌く。Sub-6とmmWave、mmWaveの脆さを**4-5 のmassive MIMO＋ビームフォーミングと第6幕のスモールセルで救う**＝道具箱の総動員。政治は地政学へ。**5,000局の調達3択表**（A社中国系800万円・最高性能・排除されれば全数撤去／B社北欧系1,150万円・納期18か月／C社国内系1,300万円・32T32R）。やる夫は総額400／575／650億円を出し、A社の最悪ケース975億円が資金繰りを切る＝**確率が分からない賭けは期待値で選べないので「最悪ケースで会社が死ぬか」で決める**とし、**B社4,000局＋C社1,000局＝590億円の分割発注**。「一番安くて一番速い選択肢を、値段以外の理由で捨てた」。

## 第8幕　空へ ── 衛星とStarlink
- 8-1　GEO 35,786km→片道119ms、実用往復500〜600ms、しかも1本のビームを地球1/3の全員で分け合う。ただし気象衛星・BS/CS・Inmarsatなど「止まって見える」用途では現役。
- 8-2　LEO 550km→往復25〜50ms＝**地上の光ファイバー並み**。だが秒速7.6kmで滞空数分 → **数千機のコンステレーション**と**空でのハンドオフ**。イリジウム（66機、1990年代、破綻）＝**アイデアが正しくても部品が安く小さくなる時代が来ないと成立しない**。ドップラーは数百kHz規模だが軌道既知なので予測補正。アンテナは**フェーズドアレイ**で電子追尾＝4-5 のビームフォーミングの使い回し。
- 8-3　**第6幕の保留を回収**。1機から複数のスポットビームを降ろして地上を区画し、離れたビーム同士で周波数を再利用＝**地上のセルと同じ原理**。各ビームが「空飛ぶセル」。Starlinkの端末（Dishy）、Ku帯／Ka帯、高い周波数で広帯域を取るのは地上mmWaveと同じ戦略。衛星間レーザーリンク。

## 終幕
- 3つの壁と全技術の対応表を再掲。規格の物語（1G分裂→2G GSMとCDMA→3G陣営分裂→4G収斂→5G地政学）から「**技術的最良が勝つ**は幻想」。外した3回を数え、「教科書の式は天井を教えるが、天井までの距離を教えるのは測定値だけ」でできる子の数字を最後の拠り所に置く。6Gは「どの軸で殴るか」を未解決として残す。

## 依存
- **3つの壁**（第1幕）は終幕で全技術を貼り付ける枠として再掲される。壁の番号（壁1物理／壁2情報／壁3共有）は各幕の台詞中で頻繁に参照されるので、番号や定義を変えると多数の台詞が連動する。
- **「マルチパスは今は敵だが後で友になる」**（3-2 でやらない夫が明示）→ 4-3 のRAKEで「半分」→ **4-5 のMIMOで完全反転**。3段構えなので、途中のRAKEを削ると反転の実感が薄れる。
- **「同じ周波数を空間で再利用する」の保留**（第6幕末でやらない夫が「第8幕、空でもう一度使う」と宣言）→ **8-3 で回収**。この対が第8幕の存在理由。
- **シャノン容量 $C=B\log_2(1+\mathrm{SNR})$**（2-4 でやる夫が自力導出）は 4-1（符号は壁に肉薄する戦い）、4-4（CPで7%捨てる）、4-5（MIMOは空間という新しい軸で迂回）で3回参照される。導出の筋（点の間隔→$\log$→ナイキスト→電力）を変えると、これらの台詞の根拠が崩れる。
- **できる子の実測が予測を否定する型**は4回：3-1（3km／$n=3.5$）、4-5（郊外1.06）、5-1（音声稼働率38%）、5-2（到着時刻差1.4チップ）。うち 3-1 と 4-5 は**そのまま 6-1 の投資判断の入力になる**（半径2.7km→421局、郊外1.06→MIMOは繁華街だけ）。数値を変えると 6-1 の 1,053億円／147億円／367局が全部連動する。
- **経営数値の連鎖**：1,200億円（第1幕）→ 6-1 で1,053＋147に分解 → 7-3 の移行費用差2,300億円を「設備投資枠まるごと2つぶん」と表現 → 7-5 の調達総額590億円。420億円と18か月は第1幕・7-5 で参照される。
- **7-3 で確立した物差し（移行経路とエコシステム）**を 7-4 でやる夫が自分から再適用するのが第7幕の設計。7-3 の3択表を弱めると 7-4 の「二度目は間違えなかった」が成立しない。
- **7-5 の調達判断は 7-3 と意図的に異なる決め方**（7-3は全額確定なので引き算、7-5は確率不明なので最悪ケース基準）。この対比が明示的に台詞になっているので、片方の表の性質を変えるならもう片方の台詞も直す。
- **4-4 の積分 $I=0$** は、その直後の「反射波を入れると崩れる」→CP、という二段構えとセット。前半だけ残すとCPの必然性が消える。
- 5-2 のCDMA数値例（長さ4の符号、$(2,0,2,0)$、1チップずれで$+0.5$、3倍で$-0.5$）は連続した4つの計算で構成される。符号や倍率を変えると符号反転が起きなくなる。
- 4-1 のARQ計算（1000ビット／BER $10^{-2}$／RTT 20ms → 23,000回 → 8分）は終幕の「外した3回」の1つとして数え上げられる。
