# やる夫が圏外の半島に電話を戻すそうです ── 無線通信をゼロから建てる の骨格

地震で既存3社の局と本土への光回線が止まった汐見半島へ、新設キャリア「星環通信」のCTOやる夫が可搬局3台（1.7 GHz帯20 MHzのみ）を担いで入る。発災30時間〜68時間。目標は尾根の裏の集落・上ノ谷（集会所に58人、要救助14人、下る道は土砂で切断）に電波を届けること。「名前を売りに来た」やる夫が、最後は他社の網に管を貸す側に回る。公民館のホワイトボードの経路図（最初は「細い線が一本と人の耳が三つ」）が場面ごとに描き足される。

人物：やる夫（星環通信CTO、工学の素養はあるが無線は素人）／やらない夫（移動基地局を何度も回した古参の無線技術者、「乗ってやろう」で素朴案を数えさせる）／できる子（電波測定班主任、現場の数字だけを抑揚なく置く。「やる夫が設計値を出したら、できる子が測る」）／できる夫（大手「東陽テレコム」の災害復旧責任者、第6幕末から船上基地局で登場）。

## 第1幕　圏外の半島
- 1-1　汐見山300 m山頂から最大出力で半島全体、さらにスマホから対岸40 kmの鉄塔へ。自由空間 $1/r^2$ で20倍の距離は出力400倍、スマホ0.2 W→80 W。周波数は国が割り当てた共有資源、隣の帯域を汚す。低い周波数は新設には割り当てがなかった。叫ぶ前に外と一本つなぐ。
- 1-2　静止衛星の1.2 m皿で県の本部へ。課長が毎回0.6秒ためてから喋り、声が重なる→「怒っている人の間」と誤解（8-1 で回収、「あとで数える」）。下り4・上り1 Mbps。上ノ谷から安否が一件も来ていない。
- 1-3　消防団の三段の言い継ぎで「イシハラ夫婦／要救助14人」が「イシダ夫婦／要救助4人」に化けた。「近い名前は別の人」。経路図を初めて描く。72時間の目安、発電機充電待ち100人、燃料は明朝補給、明日夕方から雨の前線。「上ノ谷に電波を届けるまでは帰らない」。

## 第2幕　声を電波に載せる
- 2-1　消防団無線機の17 cmアンテナ：声3 kHzなら1/4波長25 km、逆算で約440 MHz＝搬送波と変調。周波数分割で住み分け。$A\cos(2\pi ft+\phi)$ の3か所、振幅変調AM。
- 2-2　体育館のAMラジオが発電機の点火で鳴る（雑音が振幅を直撃）、無線機のFMは澄む（リミッタ、捕捉効果）。代償は帯域（AM数kHz、FM 200 kHz）。1G（AMPS・NTT大容量・TACS）はFM。「全部FMで決まり」→言い継ぎはFMでも化けた。
- 2-3　アナログ中継は雑音がたまる、人の言い継ぎは言い直すが候補が多いと外れる→候補を2つにすれば再生中継。標本化で1秒3,000回案→1周期1点で波が止まる、標本化定理で8,000回・8ビット＝64 kbps（PCM、G.711、CD 44.1 kHz）。できる子が5 kHzを8 kHzで取り込むと偽の3 kHz＝エイリアシング、前置フィルタで消える。衛星上り1 Mbpsで15本→音声符号化12 kbpsで約80本（騒音下で聞き取りにくい、0.08秒遅れる）。やる夫の「昼めし符号表」（16品に4ビット、塩0100・味噌0110）で塩が味噌で届き、炊き出し班の押し間違いと決めつける（3-3・4-2 で回収）。
- 2-4　BPSK→QPSK→QAM、点を増やせば無限案→同じ円内で256点は4点の8分の1間隔、雑音で隣と誤る。適応変調（QPSK〜1024QAM）。点を数えて $\log_2(1+A/\sigma)$、標本化定理で $2B$ 個/秒、電力比に直して $C\approx B\log_2(1+\mathrm{SNR})$ を自力で導出（シャノン1948）。20 MHz・30 dBで約200 Mbps。1-1 の大出力案はSNR 1→10→100で1→3.46→6.66 Mbps＝二通目の請求書。細いのは空の方。

## 第3幕　尾根と瓦礫
- 3-1　山頂局で「$n=2$ なら半径31 km、残り2台は受付に飾る」。できる子の実測で3 kmで圏外、100 m→1 kmで35 dB＝伝搬指数 $n=3.5$、引き直して2.7 km、面積で約130倍外した。以後「設計値を出したら測る」順番。上ノ谷の手前で表示1本でも発信不可→表示は下りだけ。リンクバジェット：下り $43+15-3-147-3=-95$ dBm（10 dB余る）、上り $23-3+15-3-147=-115$ dBm（4 dB足りない）、差は出力20 dB−局の耳6 dB。局を大声にしても上りは変わらない。尾根の回折損失は周波数の平方根の対数、700 MHzなら約3.9 dB得＝ちょうど足りない分、だが700 MHzは大手のもの。尾根に中継局の案を描く。
- 3-2　トンネル入口で2 cmごとに−70〜−88 dBm、12 cmで18 dB変動＝マルチパスとフェージング（半波長8.8 cm）。入口3 m左の壁ぎわだけ表示2本なのに音声が最も澄む（4-6 で回収）。遅延1 μsのシンボル間干渉、速くするほど自分の残響で読めない行き詰まり。
- 3-3　啓開車（時速40 km）でドップラー63 Hz、QPSKの点が回転木馬のように回る、既知信号で追いかけて戻る。新幹線3.5 GHzで約970 Hz。塩ラーメンもこれで化けたか？→「なぜ味噌だったか」はまだ説明していない。

## 第4幕　壊れたビットを救う
- 4-1　トンネルの写真を1000ビットパケットでARQ。誤り率 $10^{-2}$ で無傷確率 $4.3\times10^{-5}$、往復0.6秒（課長の間）で1パケット3.8時間。悪い回線ほど再送は効かない→FEC、3回繰り返しは符号化率1/3。
- 4-2　上ノ谷の安否を4ビット（0010要救助）で送る案→3番目反転で0000無事、ヘリのリストから黙って消える。塩0100と味噌0110も同じ3番目＝16個全部を使ったからどの1ビットでも別の料理になる（炊き出し班の疑いが晴れる）。圧縮は余りを削り、余りが消えると誤りがもっともらしい別の意味になる。パリティは異常は分かるが住所がない。ハミング(7,4)で0010→0101010、6番反転を検査結果110＝6で特定。符号化率4/7。2ビット誤りは誤って直す、できる子の試験で8ビット目（全体偶奇）を足して「直せない」と言わせ再送へ。安否と符号表を8ビットに作り直す。
- 4-3　畳み込み符号とビタビ（GSM）、シャノンは存在のみ証明、ターボ符号（1993、天井まで約1 dB、3G・4G）、LDPC、ポーラ符号（2008、5Gの制御）。荷物ごとに符号化率を変える：安否は強く一回で、写真はほどほど＋再送、報道映像は薄く。
- 4-4　啓開車のバースト誤り（縞の谷で20ビット）→インターリーブ（待ち時間が代償、声は浅く写真は深く、CD）。ダイバーシチでアンテナ2本の失敗 $0.1\times0.1=0.01$、条件は二本が互いに関係なく失敗すること（終幕で回収）。
- 4-5　3-2 の行き詰まりに戻り、シンボルを長く→遅くなる→1000本のサブキャリアに分ける。$\int\cos(2\pi f_1t)\cos(2\pi f_2t)dt=0$ から間隔 $1/T$ の整数倍＝直交、FFT、OFDM。反射が積分区間の頭に食い込むと直交が壊れる→巡回プレフィックス（CPは計算の前提を守る柵）。トンネルの遅延最大2.2 μs、LTEのCP約4.7 μs（容量7%を払う）。LTE 15 kHz、5Gは可変。
- 4-6　同じ周波数・時間に二つの流れ→道4本で連立方程式、$\mathbf{y}=\mathbf{Hx}+\mathbf{n}$、空間多重MIMO。「2本ならきっちり2倍」→できる子の実測：トンネル1.92、体育館1.71、漁港海岸1.06（見通しで $\mathbf{H}$ が縮退）。道がどれだけ違うかが容量を決める。3-2 の澄んだ一点の正体＝マルチパスが資源。ビームフォーミング。2本はトンネルと体育館へ。救助隊がトンネルの車から二人救出、写真が本部の判断に間に合う。

## 第5幕　800台が一斉に鳴る
- 5-1　発災40時間、県・国・3社の取り決めで体育館の局に他社加入者を臨時収容。800台が一斉に位置登録。緊急地震速報が全台に同時に届く（終幕の伏線）。5本なのに発信中のまま、「指で6本目を描く」。接続48%、呼び出しまで中央値19秒・遅い5%で41秒以上。10人（1が9人と41秒）の平均5秒で尾を隠す、平均でなく中央値と尻尾。ランダムアクセスの入口10個に800台が衝突・やり直しで再衝突、ずらすと衝突は減り時間が延びる。発信規制、災害時優先電話。5本は入口の照明で、番号札は別。
- 5-2　FDMA：通話中の発話割合は平均38%、黙っている間も1本を握る。AMPSは30 kHz占有で20 MHzに約666人。TDMA：GSMは200 kHz×8枠・577 μs、電池が持つが黙っている人の枠は遊ぶ。
- 5-3　CDMA：長さ4の直交符号 $c_A$・$c_B$ で混ざった $(2,0,2,0)$ から両データを取り出す（内積0＝4-5 と同じ直交）、スペクトラム拡散、GPS。上りで到達時刻が1チップずれると残りかすが出て判定0.5、Bが3倍の振幅で届くと判定が反転＝近遠問題。IS-95は電力制御毎秒800回、RAKE受信でマルチパスを足して力に。
- 5-4　OFDMAの升を話している人に。3人×3周波数の表で全部Aに渡すと12、山の人に渡すと24＝マルチユーザーダイバーシチ、スケジューラ、4Gは12サブキャリア単位。「発信中」は升の順番待ちだった。
- 5-5　局の脇の報道中継車が上りの升を独占、合計最大化では安否が飢える。$\log$ の和で $(1,1,10)$ と $(2,2,8)$ を比べ比例公平。QoS：安否つながるまで27秒→3.7秒、中継車の映像は12%遅く（謝りに行く）。毎秒9件と10秒後に90件は同じ平均でも待ちが違う（余震後の一斉送信）。体育館は捌けても衛星上り1 Mbpsを800人で一人1.3 kbps、細いのは空。

## 第6幕　三台で半島を覆う
- 6-1　3台を山頂に集めて最大出力案→同じ20 MHzを分けても100本、届くのは2.7 km。離して出力を絞れば同じ周波数を使い回せる＝セルと周波数再利用、7色と3色で取り分とSIRの綱引き。境目で他局の電波は15 dB弱い＝3-1 で落胆させた $n=3.5$ が味方。尾根の中継局は道の亀裂と雨で消防団に止められ断念、3台目はトンネル口、汐見山の1台は漁港へ。見通しの漁港は1本。セル分割、1947年ベル研・1979年NTT。
- 6-2　救急車の往復で「少しでも強い局へ即乗り換え」→1分17回ピンポン・途切れ1.8秒。3 dB・0.5秒で3回・0.12秒、10 dB・5秒で2.4秒途切れ。ハンドオーバの手順、ソフトハンドオフ。
- 6-3　本土の家族からの着信が鳴らない人がいる（発信はできる）。番号から場所は分からない→位置登録とページング、台帳は東陽の網の奥。東陽の台帳は倒れた鉄塔の区画のまま＝登録の手紙が上り1 Mbpsで報道映像に押され時間切れ。RANとコア網。SIMの鍵による認証（鍵は飛ばない）も0.6秒の往復。着信4.2秒中2.9秒が空の一本。網の奥の手紙を映像より優先、登録を少しずつずらして再実行（一斉は5-1 の再演）で1時間で半減。「東陽の台帳を星環の都合で書き換えている」、沖に船の灯り。
- 6-4　燃料あと6時間、補給は10時間後。全部を均等に弱める案を 5-5 で捨てた配り方と気づき、縮退運転：報道映像停止、声を低レート、安否・救護所・登録呼び出しを守る、夜の漁港局停止、充電は止めない→11時間もつ。復帰も少しずつ（バーストと一斉登録）。可用性99%と99.9%は87.6時間と8.76時間、だが止まる時刻が悪ければ意味がない、何を止まったと数えるか。できる夫から無線「うちの加入者の台帳を夜の間に書き換えていたのはそちらか」。

## 第7幕　他社の船、他国の箱
- 7-1　できる夫：昨夜数百件の着信が鳴らなかった、相互接続試験を済ませていない局に自社の客は預けられない。「同じ規格なら合格」→東陽の端末で音声符号化の組み合わせに共通がない機種、1.7 GHz帯の一部に非対応の機種。能力交換（交わりを見つける場）と相互運用試験。能登地震のドコモ・KDDI共同の船上基地局。東陽の船の700 MHzで上ノ谷から初めて外へ電話がかかる（集会所の多くは東陽加入者）、3-1 の4 dBをあっさり越える。「上ノ谷の人にとって網の名前は何でもいい」。
- 7-2　海外救援チームのトランク一つのGSM基地局（900 MHz）→国内の割り当てと重なり電源を入れられない。1980年の盤面（AMPSに合わせるか自国仕様か）でやる夫も自国仕様を選ぶ＝NMT・TACS・NTT方式、全員が正しく選んで世界がばらばら。欧州はGSMで統一（TDMA、規格統一が産業政策、ノキア・エリクソン、SIMの発明）、日本はPDC（1993）。40年前の判断がトランクのスイッチを止めている。チームは発電機整備と通訳を手伝う。
- 7-3　1999年、欧州GSM事業者の技術責任者として CDMA2000／W-CDMA／独自方式の表。技術の先行よりGSM資産の流用と移行費用（3,400億 vs 1,100億）、クアルコム特許の重しでW-CDMA。3GPP、2001年ドコモ世界初の商用3G、auはIS-95系資産からCDMA2000＝同じ物差しで資産が違えば答えが違う。中国TD-SCDMA。4GはOFDMAへ、UMB中止（2008）、WiMAXはLTEに押される。仲間の数と移行の道を握った方が勝つ。できる夫「規格が一つになっても約束は各社で別」。
- 7-4　本設：東陽は700 MHzで谷を先に。星環は300局を5Gで予算40億。5Gの三すくみ（大容量・低遅延・多数接続）、サブキャリア間隔とネットワークスライシング、6 GHz以下とミリ波。調達表 A社（800万・最良・政府が排除検討中で全撤去リスク・6か月）／B社（1,150万・0.95・18か月）／C社（1,300万・0.8・3か月）。A社24億が最悪で58.5億、確率不明の賭けは期待値でなく最悪時の生存で選ぶ→A除外、半島60局をC社で3か月、残り240局をB社で計35.4億、B社遅延ならC比率を上げる。できる夫「上ノ谷のような谷に星環はいつ局を建てる」→60局に上ノ谷は入っていない、4 dBは本設でもついて回る。

## 第8幕　空の一本
- 8-1　課長の0.6秒を数える：静止軌道35,786 km、片道119 ms×4区間≈0.48秒＋符号化・待ち＝0.6秒。怒っていたのではなく声が宇宙にいた（謝る理由が一つ減る）。自由空間損失 $20\log_{10}(4\pi d/\lambda)$ で12 GHz約205 dB、上ノ谷の147 dBより約60 dB大きい、1.2 m皿が要る。動かさなくていいから真っ先に使えた。
- 8-2　低軌道衛星の平たいアンテナが届く。550 kmで往復数十 ms。衛星からスマホへ直接案→3 kmの上ノ谷で4 dB足りない上りが距離183倍で45 dB余分、今は短いメッセージ中心。数分で地平線へ→数千機の群れ（イリジウム66機の破綻、部品が安くなるまで20年）、衛星間ハンドオーバを軌道予測で先渡しして途切れ1.4秒→0.08秒。ドップラー数百kHzも予測補正。平たいアンテナはフェーズドアレイ（4-6 のビームフォーミング）。下り120・上り15 Mbps、一人19 kbpsで12 kbpsの声が載る。
- 8-3　一機で広く照らせば静止衛星と同じ→スポットビームで空にもセルを切る（6-1 と同じ原理）、Ku帯・Ka帯、衛星間レーザー。外への道が二本＝ダイバーシチで可用性99.99%と胸を張る。高い周波数は雨に弱い（Ka帯で10 dB超）、二本とも公民館の同じ屋上。降り始める。

## 終幕　雨の夜、上ノ谷へ
- 発災68時間、上ノ谷に避難指示（集会所は斜面の下、高台の寺へ）。一人ずつ電話する案に対し同時に三つ：皿は雨で切れ平たいアンテナも15→3 Mbps、体育館の接続要求が 5-1 の3倍、東陽の船の外への静止衛星回線も雨で切れる。二本は同じ屋根で同じ雨をかぶる＝「関係なく失敗する」条件を自分で言って忘れていた。層ごとに直す：適応変調を下げて3 Mbpsを維持、載せる荷物を先に決め（映像・写真停止、声低レート、安否・救護所・消防・登録呼び出し優先）、入口のやり直し間隔を広げ消防と救護所を先に。上ノ谷へは局を大声にする案を自分で退け（上りの4 dB）、船の局の外への道に星環の平たいアンテナを「中身を見ない管」として貸す（東陽の客は東陽の網のまま、暗号のまま）。7-1 に懲りて両端で試験信号を往復（80 ms、取りこぼしなし）。58人への一斉連絡は 5-1 の緊急速報が一人ずつ升を配らず区画の全員に一度だけ降らせたと気づき、緊急速報メール（一斉同報）を船の局と体育館の局から。全員の電話が同時に鳴り寺へ、安否は8ビットで58人到着、化けゼロ・1ビット誤り3件とも訂正。5本の奥はもう5本の外にある、6本目は描かない。上ノ谷の画面は東陽テレコム、星環の名前は一文字もないが「それでいい」。できる夫「管がなければ届かなかった、報告書にそう書く」。700 MHzが欲しい→「国に言ってくれ」。できる子の数字は取り続ける。炊き出し班から味噌ラーメン、8ビットだから化けではなく味噌しか残っていなかった。ホワイトボードの最終形（三局・空の二本・東陽の船と星環の管・「周波数の調整中」のGSMの箱）。

## 依存
- 課長の0.6秒：1-2（怒っている人の間、「あとで数える」）→ 4-1（ARQの往復0.6秒）→ 6-3（認証・登録の往復）→ 8-1 静止軌道で回収。静止軌道の数値を変えたら 4-1 の3.8時間も直す。
- 昼めし符号表：2-3（塩0100が味噌0110で届き炊き出し班を疑う）→ 3-3（ドップラーで化けたかも、なぜ味噌かは未説明）→ 4-2（16個全部使ったから必ず別の料理＝圧縮と冗長、8ビットに作り直す）→ 終幕（8ビットだから化けではない）。
- 上ノ谷の4 dB：3-1 のリンクバジェットで上りだけ足りないと確定 → 7-1 東陽の700 MHzが越える → 7-4 本設でもついて回る → 8-2 衛星直収は45 dB → 終幕で局を大声にする案を自分で退ける。リンクバジェットの数値（43/15/3/147/3、23 dBm、−111 dBm）を変えたら全所を直す。
- 伝搬指数3.5：3-1 で31 km→2.7 km、局130倍の落胆 → 6-1 で再利用の味方に（境目で15 dB）。
- トンネルの澄んだ一点：3-2 で「縞の山にたまたま」と保留 → 4-6 MIMO の道の豊かさで回収（1.92/1.71/1.06）。マルチパスが敵（3-2）→ CP で無害化（4-5）→ 資源（4-6）→ RAKE（5-3）。
- ダイバーシチの条件「互いに関係なく失敗」：4-4 で自分で言う → 8-3 で二本の空回線を99.99%と胸を張る → 終幕で同じ屋根・同じ雨で両方落ちる。
- 緊急速報：5-1 で800台に同時に届く描写 → 終幕で一斉同報と気づいて避難指示に使う。5-1 のこの一文を削ると終幕が成り立たない。
- 5本表示：5-1「6本目を描き足す」→ 5-4「升の順番待ち」→ 終幕「6本目は描かない」。
- 平均と尻尾（5-1）、平均9件のバースト（5-5）、可用性の年間平均と止まる時刻（6-4）は同じ論点の三段。
- 優先制御：5-5 QoS → 6-3 網の奥の手紙の優先 → 6-4 縮退運転 → 終幕で三つを同時に適用。
- 登録の一斉やり直し：5-1 の衝突 → 6-3 ずらして再実行 → 6-4 復帰を少しずつ → 終幕の入口制御。
- 東陽の台帳の書き換え（6-3）→ 6-4 末できる夫の詰問 → 7-1 相互運用試験の欠如 → 終幕で「中身を見ない管」と両端試験。やる夫が 7-1 で自分の急ぎを認めることが終幕の協力の前提。
- 周波数の割り当て：1-1（新設に低い周波数なし）→ 3-1（700 MHzは大手）→ 7-1 → 7-2 GSMの箱の900 MHz → 7-4 → 終幕「国に言ってくれ」。
- シャノンの天井：2-4 で導出 → 4-3 符号はその手前まで → 4-6 MIMO は別の軸から回り込む。
- 直交：4-5 の積分 → 5-3 CDMA の内積 → 5-3 の近遠問題で時刻ずれにより崩れる。
- 経路図：1-3 → 2-4 → 3-1 → 5-5 → 8-2 → 終幕の最終形。「細いのは空」は 2-4・5-5・6-3 で繰り返し、第8幕で空を太くする。
- 「上ノ谷に電波を届けるまでは帰らない」（1-3）と「名前を売りに来た」は 7-1「やる夫の局じゃない」→ 終幕「網の名前は東陽、それでいい」で閉じる。
