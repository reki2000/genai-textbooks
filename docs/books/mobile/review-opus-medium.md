# 寸評：やる夫が携帯電話会社のCTOになるそうです ── 無線通信をゼロから建てる

約73KB／全8幕＋終幕。第1幕で立てた「物理・情報・規制」の3つの壁だけを軸に、変調からシャノン限界、OFDM／MIMO、多元接続、セル方式、規格戦争、Starlinkまでを一本で貫く教材。

## 良い点

**3つの壁という骨格が最後まで緩まない。** 第1幕の壁1・2・3（61–63行目）が、第4幕の道具箱まとめ（713–719行目）、第5幕の整理（846–849行目）、終幕（1340–1354行目）で三度そのまま参照される。「新しい壁を壊したわけじゃない、同じ3つの壁をより賢く踊ってきただけ」（1353–1354行目）という結論は、この軸があって初めて立つ。

**「マルチパスは敵、後で友になる」の伏線回収が白眉。** 3-2でISIの元凶として憎ませ（357–365行目）、368–369行目で明示的に保留を宣言し、4-5で受信2式・未知数2個の連立をやる夫自身に立てさせて反転する（663–669行目）。MIMOの本質を比喩でなく式で掴ませている。第6幕の周波数再利用（944–948行目）を8-3のスポットビームで回収する構造（1301–1306行目）も同じ質。

**7-3の意思決定シーンがCTO設定を最大限に活かす。** 1999年の三択を表で出し（1017–1021行目）、やる夫が「動いてる方」に傾いてから足元の資産を数えて覆す（1024–1037行目）。「技術の新しさじゃなく移行経路と特許の重しで決めた」（1048行目）という基準が、7-4のWiMAX戦（1104–1109行目）で再利用され、学習の定着を行動で示す二段構えになっている。

**実装値と身近な実例が毎回そろう。** AMPS 30kHz（746行目）、GSM 200kHz／8スロット／577μs（755–756行目）、IS-95の毎秒800回の電力制御（808行目）、LTEのリソースブロック180kHz×0.5ms（841行目）。車輪の逆回転＝エイリアシング（207–209行目）、CDの傷とインターリーブ（535–537行目）、電波表示のアンテナ本数＝適応変調（255行目）と、抽象論に落ちない。

## 欠点

**やる夫が「作って測る」場面が一度もない。** CTOで会社を持つのに全幕が机上の対話。数値はすべて与式への代入（274行目、381行目、1216行目）で、想定外の実測値が理屈を殴り返す瞬間がない。やる夫の外から数字を突きつける第三の役が不在。

**物語的圧力が皆無。** 期限も予算も競合も出ない。20MHzの免許を持つ設定（55行目）なのに免許料も加入者目標も開始日も語られない。7-5でオークションが兆円規模と述べられる（1177行目）が、会社の財務には一切跳ね返らない。

**「では反例」の同型反復が全幕を貫く。** 113行目、235行目、421行目、738行目、789行目、963行目。やらない夫が反例を出し、やる夫が「ぐぬぬ」で気づく型が、切り出しの言葉まで同型で繰り返される。中盤以降は次の展開が読めてしまう。

**主役級の概念2つが天下り。** シャノンの式（263–268行目）は「最も重要な一本の式がある」と提示されるだけで、なぜ $\log_2(1+\mathrm{SNR})$ なのかの直観すらない。教材が最重視する壁2の正体が唯一再発見を経ていない。OFDMの直交条件（612–614行目）も結論だけで、やる夫が確かめていない。

**CDMAの核心が比喩のまま。** 5-2は「違う言語で喋る」（774–775行目）から「直交する符号」（779行目）へ飛び、直交性を一度も計算しない。近遠問題と電力制御（793–810行目）が良いだけに前段の空洞が目立つ。

**第7幕が再発見型から歴史講義へ落ちる。** 7-1・7-2・7-5はやらない夫の説明が主で、やる夫は「政治の意思だお」（987行目）「産業政策だお」（999行目）と相槌役に退く。

**設計メモが本文に漏れている。** 408行目の見出しが「第4幕　チャネルを叩く道具箱（最厚）」。「最厚」は執筆時の分量配分メモ。参考文献も23点中21点がWikipedia（1402–1446行目）で、一次資料はシャノン1948とArıkan 2008のみ。

## 改善案

1. **試験基地局を設け、実測が理屈を殴る場面を作る。** 3-2（315行目付近）の直前に、第2幕で設計した900MHz局を市街で測る場面を挟む。設計上届くはずの距離で圏外になり、309–311行目の計算を「先に予測させて実測で外す」形に組み替える。同じ測定係を第4幕以降も再登場させ、MIMO 2×2の実効利得が理論2倍に届かないことなどを数値で突きつける。

2. **会社に期限と金額を与える。** 55行目の直後に「免許料◯◯億円、開始まで18か月、既存3社」を提示。第6幕のセル設計（910–925行目）で局数を予算内に収めさせ、1017行目の表に「移行費用」列を追加する。現状の表は特許と互換性だけで金額欄がなく、決断の重みが出ていない。

3. **シャノンの式を半分だけ導かせる。** 263行目の前に、2-4の多値化を引き継いで「雑音 $\sigma$ のとき振幅レンジ $A$ に何点置けるか」を数えさせ、点数 $\approx A/\sigma$ → ビット数 $\approx\log_2(1+A/\sigma)$ → 毎秒 $B$ 回、の順で式に到達させる。15行程度で「なぜ log か」がやる夫の手で出る。

4. **CDMAで直交を手計算させる。** 779行目の直後に $(+1,+1,+1,+1)$ と $(+1,-1,+1,-1)$ の2符号を配り、合成波に各符号を掛けて足せば片方だけ復元されることを計算させる。同じ計算に電力差3倍を入れれば、近遠問題（797行目）が自分の計算の崩壊として体感できる。

5. **OFDMの直交とCPをやる夫に確かめさせる。** 612行目の説明を問いに変え、$\int_0^T \cos(2\pi f_1t)\cos(2\pi f_2t)dt$ が間隔 $1/T$ でゼロになることを確認させる。CP（622–625行目）も「CPなしだと反射が頭に食い込み直交が壊れる」失敗を先に見せてから導入する。

6. **第7幕の1G・5Gも決断形式に揃える。** 7-1（958行目付近）を「米AMPSに合わせるか自国仕様か」の二択にし、選ばせてから「全員が同じ理由で自国仕様を選び繋がらなくなった」と答え合わせする。7-5（1172行目付近）も基地局ベンダ選定を価格・性能・政治リスクの表で決めさせる。

7. **反例の投入者を分散させる。** 421行目・738行目・789行目のうち2つを、やる夫が先に設計図を出し、やらない夫は計算だけさせて自壊を待つ形に変える。反例の出所がやらない夫に固定されている限り、やる夫は受け身のまま。

8. **408行目の「（最厚）」を削り、参考文献を一次資料化する。** 1402行目のナイキストは Shannon 1949、1414行目は Berrou et al. ICC 1993、1416行目は Gallager 1962 に差し替える。
