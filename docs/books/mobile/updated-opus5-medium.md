# 改稿記録

## 工夫した点・主な変更

- **測定役として「できる子」を新設した。** 電波測定班の主任。感情を挟まず、測った数字だけを短く置く役に固定した。やる夫の外から数字を突きつける第三の声がないという指摘への回答で、3-1・4-5・5-1・5-2・6・終幕の6か所に登場する。説明はしない。数字を置いて黙るだけで、解釈はやる夫にさせた。

- **3-1を「予測してから外す」構造に組み替えた。** 従来は $1/r^{3.5}$ をやらない夫が先に告げていた。改稿では、やる夫が自由空間モデルで半径31kmと先に紙に書き、できる子が実測（100m で $-60.3$dBm、1km で $-95$dBm、3kmで圏外）を置く。やる夫は10倍ごとの減衰35dBから伝搬指数 $n=3.5$ を自分で割り出し、引き直して2.7kmを得る。距離で11倍、面積で130倍という外し方が、そのまま後段の予算破綻につながる。

- **会社に金額と期限を与えた。** 第1幕に免許料420億円（支払い済み）・開始まで18か月・先行3社・設備投資枠1,200億円を置いた。この4つの数字は第6幕（421局×2.5億円＝1,053億円、残147億円でマイクロ367局）、7-3の移行費用列（3,400億円 対 1,100億円）、7-5のベンダ調達（総額比較と最悪ケース975億円）で三度使い回され、決断の重みを持たせている。

- **シャノンの式を、やる夫が点を数えて導く形にした。** 振幅レンジ $A$ と雑音 $\sigma$ から点数 $1+A/\sigma$ → 1シンボルあたり $\log_2(1+A/\sigma)$ ビット → ナイキストで毎秒 $2B$ シンボル → 電力比に直して $A/\sigma=\sqrt{\mathrm{SNR}}$ → $C \approx B\log_2(1+\mathrm{SNR})$、という順に踏ませた。教材が最重視する壁2だけが天下りだった穴を塞いだ。あくまで点を数えた概算であり、シャノンの証明は別物だと本文で明示している。

- **CDMAの直交を、比喩から手計算に落とした。** $c_A=(+1,+1,+1,+1)$、$c_B=(+1,-1,+1,-1)$ を配り、合成波 $(2,0,2,0)$ に各符号を掛けて足すと両方復元されることを計算させた。「直交＝内積ゼロ」をやる夫の口から言わせている。近遠問題は、同じ計算に到着時刻の1チップずれを入れて崩す形にした。等電力なら $+0.5$ で判定は生き残り、電力3倍で $-0.5$ に反転して誤る。ずれは同じで電力比だけが違う二例を並べたので、「電力を揃えれば直る」という解法がやる夫の計算から出てくる。

- **OFDMの直交を積分で確かめさせ、CPは失敗を先に見せた。** $\int_0^T\cos(2\pi f_1t)\cos(2\pi f_2t)dt$ を積和公式で開かせ、間隔 $1/T$ の整数倍で消えることを出させた。そのうえで「反射で積分区間の頭に前シンボルが混じると、区間が整数周期でなくなり $I=0$ が壊れる」という失敗を先に置き、CPを「やる夫の計算の前提を守る柵」として導入した。CPが情報を運ばない代償（約7%）も追記した。

- **MIMOの実効利得に現場の数字を突きつけた。** やる夫が「2×2なら2倍」と宣言した直後に、できる子が地下街1.92／市街1.71／見通しの良い郊外1.06を置く。やる夫は自分が立てた連立方程式に戻り、経路が似ると式が退化することを見つける。この数字は第6幕の予算配分で「MIMOは繁華街の367局だけに入れる」という設備判断に直結させた。

- **「では反例」の同型反復を6か所から2か所に減らした。** ARQ（4-1）とFDMA（5-1）は、やる夫が数値入りの仕様を先に出し、やらない夫は計算だけさせて自壊を待つ形に反転させた。ARQは1000ビット／往復20ms／誤り率 $10^{-2}$ から平均23,000回・1パケット8分を、FDMAは音声活性率38%の実測から6割の帯域が遊ぶことを、いずれもやる夫自身に出させている。多値化（2-4）は反例ではなく点間距離が $1/8$ になる計算に置き換えた。

- **第7幕の1Gと5Gも決断形式に揃えた。** 7-1は1980年の自国当局として「AMPSに合わせるか自国仕様か」の二択にし、やる夫に自国仕様を選ばせてから「全員が同じ理由で選び、合計すると世界が分断された」と答え合わせする。7-5は5,000局のベンダ選定表（価格・実効容量・政治リスク）を出し、最安・最高性能のA社を最悪ケース975億円で捨てさせ、B社主・C社従の分割発注に着地させた。7-3・7-4の「移行経路とエコシステム」の物差しが確率不明の局面では効かないことも、やる夫自身に言わせている。

- **設計メモの漏れと参考文献を直した。** 第4幕見出しの「（最厚）」を削除。脚注は3点を一次資料に差し替えた ── [^1] を Shannon, *Communication in the Presence of Noise*, Proc. IRE 1949、[^7] を Berrou, Glavieux, Thitimajshima, ICC '93、[^8] を Gallager, IRE Trans. IT 1962。

- **終幕に「外した回数」を数えさせる往復を足した。** 31km／2倍／完璧、の三つの外しを本人に列挙させ、「式は正しく、前提が現場と違っただけ」「天井を教えるのは式、そこまでの距離を教えるのは測定値」という形で、新設したできる子の役割を結論に組み込んだ。

## 残した判断

- 3つの壁（物理・情報・規制）の骨格、「マルチパスは敵、後で友になる」の伏線、第6幕の周波数再利用を8-3のスポットビームで回収する構造は、レビューで最も高く評価された長所なので一切いじっていない。追加した実測・予算の要素は、すべてこの3本の軸に接続する位置に置いた。
- 追加した数値（免許料、局あたり建設費、測定値、ベンダ価格）は、この架空の会社の設定値であり、実在の事業者の実績値ではない。伝搬指数3.5、LTEのCP約7%、六角形セルの面積公式など、既存本文と物理から導ける部分は既存の記述と整合させた。
- レビュー指摘のうち「参考文献23点中21点がWikipedia」は、一次資料が明確に特定できる3点のみ差し替え、規格の概観にあたる残りはWikipedia引用のまま残した。未確認の一次資料を推測で足さないためである。
- `dialogue-shape` の warning（実効往復不足・長大発言）は改稿前から出ているものが大半で、今回追加した導出部分（2-4、4-4、5-2）は不可分な計算の連なりとして長さを許容した。error は0件。
