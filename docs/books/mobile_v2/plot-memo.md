# `mobile_v2` ブロックメモ

## 制約と到達点

- 新規長編。高校数学の対数、ベクトル内積、簡単な積分は会話内で足場を作る。
- 8幕＋終幕、約9万〜11万字。規格史だけのツアーは全体15%以内。
- 読了後は「アンテナ表示」「速度」「世代名」だけで判断せず、端末から相手までの層と有限資源を切り分けられる。

## 人物設定

- やる夫：新設キャリア「スターリンクス通信」の実証責任者。出力、アンテナ本数、最高速度を広告文句へ直結させがち。
- やらない夫：音楽祭側が通信設計の監査を委ねた独立系フィールドエンジニア。やる夫の上司ではなく、開通の華やかさに対し、会場運営と相互接続の利害を背負う。無線とコア網の両方を見る。
- できる子：会場測定班主任。予測を書かせてから実測値を出す。
- きらきー：音楽祭の舞台監督。第1・5・6・終幕で、技術指標を観客の体験へ翻訳する。

## マクガフィンとトイ

- 金色端末G-01：12秒の星図オープン合図を送る試験機。壊れた魔法の端末ではなく、各層の状態が見える診断画面を持つ。
- 12秒音声：同じ原音をPCM、圧縮音声、パケット損失、低ビットレートで聞き比べる。
- 12ビット列 `101101001011`：変調、誤り、符号化、資源割当を通り続ける。
- 12升の資源盤：時間×周波数を磁石で分配。幕末ごとに利用者とQoSを増やす。
- 五地点カード：会場中央、地下、丘裏、移動バス、連絡船。全方式を同じ場所で検算する。

## 伏線と回収

- G-01は最初から5本表示だが「scheduler wait」が小さく点滅。第5幕で読めるようになる。
- 会場地図の六角形ステッカーを装飾と思わせ、第6幕でセル設計へ使う。
- 連絡船の12秒だけ少し遅れる試験録音を第1幕に置き、第8幕の衛星経路で回収する。
- 地下通路の反射で偶然音が良い地点を第3幕で怪異扱いし、MIMOの空間ランクへ回収する。
- 舞台監督が「最高音質より12秒全部」と言い続け、第4幕のサービス別符号化と終幕の縮退判断を支える。

## 繰り返すギャグ

- やる夫がアンテナ表示を指で一本書き足して6本にしようとする。
- 「出力を10倍」が出るたび、電池、干渉、免許、熱の別担当から請求書が来る。
- できる子の実測前に、やる夫の予測値が会場の大型LED予測盤へ固定表示される。やる夫は自分の体で数字を隠そうとするが、別画面に即座にミラーされる。後半は自分から予測値と外れた理由を公開する。
- 音声試験の決まり文句が「もしもし、焼きそばは塩」。符号誤りで毎回別メニューになり、終幕だけ正しく届く。

## 緩急と息抜き

- 第1幕は群衆の一斉アクセスを高速に描き、診断画面の一行で静止する。
- 第2幕は音を実際に聞き比べる遊び、第3幕は会場を歩く測定ツアーで身体感を出す。
- 第4幕はビット盤のパズル、第5幕は資源盤の競りゲームで会話を短くする。
- 第6幕は地図へ基地局を置く経営クライマックス。単価と局数をやる夫が計算する。
- 第7幕は歴代端末を舞台床の時代線へ実際に並べる博物館休憩から、調達判断の緊張へ上げる。
- 第8幕は屋外で空を見上げる静かな導入から、動く衛星の追跡へ速度を上げる。
- 終幕は12秒をリアルタイムで追う動的クライマックス、最後は星図を無言で眺める。

## ブロック運用

各節はG-01の追跡票のどこで失敗したかから始める。式はやらない夫が完成形を渡さず、点の数、距離、成功確率、内積、局数をやる夫に計算させる。理論値の後には必ずできる子の測定、合格地点と不合格地点を置く。速度改善が遅延・電池・公平性・費用を悪化させる副作用を次節の始動事件にする。

## 状態台帳の初期値

- G-01、12秒、12ビット、五地点、会場5万人、帯域20 MHzを固定する。
- 実規格の周波数、符号、タイミングは一次規格・公的資料を優先し、世代や地域差を省略するときは明記する。
- Starlink固有名との混同を避けるため、架空会社名は本文で別名へ変更してよいがcatalogと統一する。
- 通信不能を人命危機の安易な演出にせず、音楽祭の演出・連絡・観客体験を主な賭け金にする。
