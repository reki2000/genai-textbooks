# 寸評：やる夫で学ぶ流体力学 ── 水と空気の法則を再発見する

約158KB／全9幕27節。水と風の科学館の再開館準備を舞台に、連続体近似から検査体積、ベルヌーイ、ナビエ–ストークス、境界層、乱流、圧縮性、CFD検証までを通す大部の教材。

## 良い点

**全27節が「やる夫の誤った断言」を節タイトルに据えている。** 「定常なら加速度はゼロ」（256行目）、「管の中は一様速度」（2205行目）、「上面の空気は急いで再会する」（3521行目）、「格子を細かくすれば正解になる」（3791行目）。誤り→反証→再構成の型が最後まで崩れず、目次が「初学者が実際にやる誤解の一覧」として機能している。

**9-4のラバールノズルが本書で最良の再発見。** $dA/A=(\mathrm{Ma}^2-1)dU/U$ に $\mathrm{Ma}=2$ を入れて $dA>0$ を得た後、やる夫は式を一度拒否する（3689–3692行目「そんなわけないお。ホースの先を潰したら勢いよく出るお」）。やらない夫は「ホースの中の水は、密度が変わるか」とだけ返し、やる夫が自分の直感の出どころ（$AU$一定は密度が動かない場合の式）を特定する（3697–3701行目）。抵抗の正体まで言語化されている。

**9-2の剥離も同じ手つき。** 逆圧力勾配に対し最初「全体が同じだけ遅くなるだけ」（3399行目）と答え、壁上と外側の対比を渡されて「層のどこが先に力尽きるか」（3418行目）へ至る。剥離を運動量の階層差として掴ませている。

**できる子の測定値が誤りを数値で確定させる。** ノズル細径化で流量0.26倍（1090–1092行目）、エルボ設計荷重110 Nに対し実荷重1.34 kN（1637–1639行目）、非粘性解析の抗力係数0.003に対し実測0.041（3318–3321行目）。反論ではなく実測が直前の主張を潰す。

**7-2でNSを組み立てた後、既習の全式を回収する。** 2610–2615行目で静水圧・オイラー・ベルヌーイ・ポアズイユが「条件を変えた同じ方程式の枝」として並べ直され、第2幕から第6幕が一度に伏線回収される。

**参考文献12点が本文の対応節つきで付く（4056–4078行目）。** Reynolds 1883、Prandtl 1904 の原論文を含む。

## 欠点

**物語的圧力がほぼ働いていない。** 冒頭の「30日後に再開館」（22行目）以降、期限は最終節の「残り30分です」（3913行目）まで一度も現れない。間の約3000行が期限と無関係に進むため、設計判断が「正しいから採る」だけで決まり、時間や費用と衝突する場面がない。

**できる夫が圧力源として機能していない。** 登場は20、665、1752、1945、2911、3912、4006行目のほぼ7回で、いずれも大風呂敷を広げる同一機能。2911–2914行目の「実物大は高いので10分の1模型」は費用が相似則を強制する絶好の場面だが、誤りの提示で終わり拘束にならない。

**各節後半の追加ブロックが講義へ退化している。** 本編後に空行2つで区切られる補足では、やる夫が誤らず正しい知識を交互に述べるだけになる。3818–3823行目の数値誤差5分類、2684–2689行目の境界条件列挙は、やる夫の口調をした箇条書きにすぎない。この形式が分量のかなりを占める。

**失敗が負債として持ち越されない。** 水槽壁の4.2 mm変形（408行目）、エルボのボルト脱落（1572–1573行目）、噴水速度が理想の37%（1501行目）はどれも当該節内で解決して終わり、後の幕で代償に縛られる展開がない。

**1501行目の「理想計算では出口速度18.8 m/s」の根拠が合わない。** $\sqrt{2\times9.8\times18.0}=18.8$、つまりポンプ水頭18.0 mを全部速度水頭にした値だが、静水頭差7.0 mは損失を無視しても必ず消費される。理想値は $\sqrt{2g(18.0-7.0)}=14.7$ 相当のはずで、損失の効きを過大に見せている。

**2405行目のTeXが壊れている。** `\int_V ho\frac{D\mathbf{u}}{Dt}\,dV` と `\rho` のバックスラッシュが落ちており、コーシー運動方程式を導く最重要の変形で「ho」と表示される。

**できる子が一度も判断しない。** 人物紹介（10行目）通り測定値だけを読む役だが、40回以上同一書式が続き後半では儀式化する。

## 改善案

1. **期限を中盤へ通し、一度だけ「正しい対策が間に合わない」判断を作る。** 各幕冒頭にできる夫の一行（「残り22日です！」）を置き、6-3の詰まり区間（2291–2293行目）を配管全交換か部分改修かの選択にする。全交換が工期で落ち、部分改修とポンプ作動点の再設定で妥協する着地なら、$R^4$則の学習が実務判断へ直結する。

2. **8-1の縮尺模型を予算制約として拘束する。** 2911–2914行目を「実物大の予算は承認されない」という決定に変え、やる夫がReとFrを同時に合わせられない現実（3008–3010行目）へ追い込まれる形にする。無次元数の取捨選択が講義でなくやる夫の決断になる。

3. **9-5の補足を順序反転する。** 3833–3837行目の格子収束データ（0.842→0.879→0.887、実験0.91、粗い入口乱れなら1600万セルでも0.81）を先に突きつけ、やる夫が「格子のせいだ」と誤ったまま細分化して外し続ける往復を挟んでから、3818–3823行目の誤差分類を自分で作らせる。同内容を再発見の型へ戻せる。

4. **1501行目の数値を直す。** 「理想計算」の定義を明記し、$\sqrt{2g(h_p-\Delta z)}$ に基づく値へ改める。あわせて1499–1500行目の内訳（18.0＝7.0＋5.4＋3.1＋2.5）が閉じることを、やる夫に一行で確認させる。

5. **2405行目の `ho` を `\rho` へ修正する。**

6. **できる子に一度だけ測定の限界を言わせる。** 5-2のロードセル（1805–1807行目）か9-3の後流測定（3629–3630行目）で判定を保留させれば、終盤でやる夫が検証計画そのものを設計する場面（4024–4029行目）が伏線回収として効く。
