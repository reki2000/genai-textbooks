# `fluid-mechanics` 改稿記録（sol56-medium）

## 改稿方針

`review-opus-medium.md` の指摘を基準に、既存の事実、数式、全9幕27節の構成を保ちながら、設計判断へ期限・予算・測定不確かさが作用するように `README.md` を改稿した。

人物の声は、既存教材の `statistics` と `supply-chain` を中心に横断確認した。できる夫は、理解と実行が速い一方で、期限・承認・発注を先に確定して周囲へ判断を迫る人物として調整した。できる子は、短い数値や問いで危険な結論を止め、結論を急がず測定限界も示す人物として調整した。追加場面はすべて話者の発言だけで構成し、ト書きは使っていない。

## 具体的な変更

### 1. 30日の期限を全幕へ通した

第2幕以降の幕頭に、残り27日、24日、21日、18日、14日、10日、6日、2日という期限を配置した。単なるカウントダウンにはせず、水槽補修、部品発注、ポンプ変更、固定具再製作、安全審査、模型試験、実物試験の締切と結び付けた。

水槽壁の4.2 mm変形は補強で二日を消費し、エルボ固定具の失敗は再製作費を消費する設定にした。失敗を当該節だけで閉じず、後の予算と工程を狭める負債として残した。

### 2. 6-3を工期制約下の設計判断へ変えた

詰まり配管の全交換には施工11日と耐圧試験2日が必要で、他装置の連動試験を含めると再開館へ間に合わない条件を追加した。やる夫は全交換を断念し、詰まり区間だけを三日で交換する案を選ぶ。

部分改修後は、系統曲線とポンプ曲線の新しい交点に合わせてバルブ開度とポンプ回転数を再設定する。残る損失は消費電力として監視し、休館日の全交換へ引き継ぐ。これにより、半径4乗則を暗記事項ではなく、限られた工期をどの区間へ配分するかの判断根拠にした。

### 3. 8-1の縮尺模型を予算制約として拘束した

実物大設備の予算却下を確定事項にし、使用できるものを10分の1模型と同じ水に限定した。その条件では、フルード相似を選ぶと速度比は $\sqrt{0.1}\approx0.316$、レイノルズ数比は $0.0316$ となる。一方、Reを合わせる速度比10ではFr比が約31.6となり、両者を同時に合わせられないことを数値で示した。

人工河川では自由表面の水位と波による越流を優先するためFr相似を選び、Reの不一致は壁面抵抗の別計算、既存データ、CFD、局所測定で補う判断にした。模型試験が何を合格させ、何を合格させないかも明示した。

### 4. 9-5をデータ先行の再発見へ組み替えた

誤差分類の講義より先に、100万、400万、1600万セルで揚力係数が0.842、0.879、0.887へ収束するデータを提示した。やる夫はいったん1600万セルを正解とし、実験値0.91を見ても6400万セルへ進もうとする。

収束先が0.91へ向かっていないことと、同じ1600万セルでも入口乱れ条件により0.81へ動くことから、やる夫自身が「方程式を正しく解いたか」と「方程式と入力が現実を表すか」を分離する。そこからverification、validation、数値誤差、モデル誤差、入力不確かさを再構成し、盲目的な細分化を止めて計算資源を感度確認へ振り向ける判断へつないだ。

### 5. 数値とTeXを修正した

4-3の理想出口速度は、ポンプ水頭18.0 mから静水頭差7.0 mを差し引き、$\sqrt{2g(18.0-7.0)}=14.7\ \mathrm{m/s}$ とした。実系では $18.0=7.0+5.4+3.1+2.5$ mが閉じ、残る速度水頭2.5 mから実測7.0 m/sと整合することを会話内で確認した。

7-1のコーシー運動方程式導出にあった `ho` を `\rho` へ修正した。

### 6. できる子に測定限界の判断を持たせた

5-2のロードセル測定で、予測との差5%だけでは測定不確かさの範囲内にあり、式の一致を断定できないと判断させた。一方、圧力推力を落とした22%差は測定幅を越えるため、欠落項を疑えるとした。最終節の検証計画へつながるよう、測定値を判子ではなく不確かさ込みの証拠として扱った。

### 7. 終幕で妥協案を回収した

最終起動時にも、噴水流量は部分改修後に残る損失を含めて決めたこと、圧力と消費電力を監視すること、残した配管を休館日の全交換へ引き継いだことを確認した。再開館成功によって途中の妥協が消えたように見えない結末にした。
