# `rhetoric_v2` 整合性台帳

## 固定条件

- 状態：8幕＋終幕まで完稿。
- 対象：公共的な判断、交渉、説明、訂正、謝罪を扱う長編。
- 知識予算：読者とやる夫は専門的な修辞学・交渉学を未習。日常的な割合、平均、表の比較はできる。
- 舞台：老朽化した架空の虹見橋をめぐる七日間の公開意思決定。やる夫は橋詰めの店、やらない夫は対岸の送迎という異なる利害を持つ、決定権のない二人の市民当事者。橋梁の安全判断はできる子の専門点検を前提とし、話術で代替しない。
- 仮想数値：橋長120 m、点検日6月3日、平日利用1,000人、朝2時間620人、観測12時間、車椅子利用調査20人、補修4億円、架替え7億円、仮橋0.6億円、補修案の追加工事幅1.2〜2.8億円。すべて教材用の仮想データ。
- 日程：第1幕が会議初日、第2〜3幕が2日目、第4幕が3日目、第5幕が4日目、第6幕が5日目、第7幕が6日目、第8幕と終幕が7日目。終幕末だけ一か月後。

## 定義済み用語

- 修辞状況（rhetorical situation）：発話者、聴衆、判定者、場、制約、時機、求める行動の組。
- 省略三段論法（enthymeme）：結論と明示理由の間を聴衆が暗黙の前提で補う推論。
- 争点（stasis）：事実、定義、原因、価値、政策という食い違いの型。
- ロゴス（logos）・エートス（ethos）・パトス（pathos）：筋道と証拠、話者への信頼、感情を通じた価値の具体化。配点せず相互に検査する。
- 利益相反の開示（conflict-of-interest disclosure）：発言者を排除する判定でなく、利害、独立検証、権限範囲を見せる情報。
- 序論（exordium）・叙述（narratio）・立証（confirmatio）・反駁（refutatio）・結び（peroratio）：聴衆の問いが変わる配列。固定欄ではない。
- 反復（repetition）・対句（antithesis）・修辞疑問（rhetorical question）：注意と比較を組織する操作。異論や条件を隠さないか検算する。
- 平均値（mean）：合計を件数で割った値。容量やアクセス判断では分布、ピーク、通行不能を併記する。
- 現在価値（present value）：異なる時点の費用を割引率の仮定で同じ時点へ換算した値。
- 藁人形論法（straw man）ほか：誤謬名を退場札にせず、元の主張、根拠、関連、立証責任、回答可能量へ戻す。
- 鋼人化（steel manning）：相手が署名できる最強の形へ主張を言い直すこと。
- 対話の型（dialogue type）：追及、探索、交渉、熟議で質問の役割を分けること。
- 誠実な非回答（responsible non-answer）：既知、未知、確認手順、期限、暫定措置を渡す回答。
- 立場（position）と利害関心（interest）：表面の要求と、その要求で守りたい必要・懸念。
- BATNA（best alternative to a negotiated agreement）：交渉不成立時に実行できる最良の現実的代替案。
- 留保点（reservation point）：合意を受け入れられる境界。
- 条件付き合意（conditional agreement）：測定、見直し、撤回、異議の条件を伴う合意。

## 反復物と回収

- 空席カード7枚：第1幕で通学生・送迎利用者の不在、第7幕で「代弁した答え」でなく未回答の質問へ転換、終幕で祭り騒音の新しい空席へ自発使用。
- 虹見橋の木片：第4幕で1932、1968、1997の補修年を発見。「百年前のまま」を壊し、第7幕の保存条件、終幕の「変えながら継ぐ」展示文へ回収。
- 六版グラフ：第5幕で軸、期間、注釈による印象差を盲検。派手さより元データへ戻れるかを検算。
- Rカード裏の白紙：第1幕で無駄扱いし質問を一つ置く。終幕で90秒を27秒余らせ、実際の質問時間として回収。
- 「歴史が泣いている」：第1幕の便利な感情句、第3・4幕の過剰使用、第8幕で謝罪の主役にしないため自制、終幕で「代わりに泣かせない」へ反転。
- 見出し文字数：第1〜6幕で短縮による欠落を反復。第8幕で訂正の共有可能版を二層にし、終幕では見出し不能を受け入れる。
- 90秒タイマー：第1幕は時間後に結び三つ、第2幕は二つ、第3〜6幕で一つへ減少、第8幕で12秒、終幕で27秒を質問へ残す。
- やる夫とやらない夫の鏡像失敗：保存側の弱い反対者選び、送迎側の動機断定、双方の分母拡張をそれぞれ本人が修正。

## 幕末コーナー・幕間

- 共通名「虹見橋を読む」：第1幕は修辞状況、第2幕は争点、第3幕は三訴求、第4幕は配列と媒体、第5幕は数字、第6幕は強い反論、第7幕は履行条項、第8幕は修復へ累積適用。
- 幕間「橋のない朝」：別のパン店行列へ、修辞状況・争点・選択肢分解を転移し、誤答を経るクイズを実施。
- 幕間「サンドイッチの順番」：橋の五段を流用せず、注文、店内説明、厨房で入口と順番を再設計。
- 幕間「答えられない二分間」：修辞状況、争点、三訴求、配列、数字、反論を累積し、測定遅延を行動可能な非回答へする。

## 感情曲線

- 第1幕：拡散への慢心→対岸の具体的損失への恐怖→失敗を保持する覚悟。
- 第2幕：事実一本化への慢心→議論交差への苛立ち→異なる質問を同じ比較へ置く達成感。
- 第3幕：三訴求の配合遊び→他人の経験を借りる危うさ→証拠・信頼・感情の相互検査。
- 第4幕：全文朗読と名比喩への陶酔→木片の物語崩壊→変えながら継ぐ記憶への安堵。
- 第5幕：強い割合への高揚→互いの分母の狭さへの恥→好感低下を受け入れる覚悟。
- 第6幕：弱い敵へ勝つ快感→互いの藁人形化を認める緊張→強い反論と同じ検査へ進む達成感。
- 第7幕：一予算の奪い合い→決裂時の生活への警戒→異なる理由の条件付き合意。
- 第8幕：支持回復を急ぐ焦り→評価権を手放す怖さ→許しを要求せず修復を続ける静けさ。
- 終幕：全成果を言い切る誘惑→27秒の空白→次の空席から始める余韻。
