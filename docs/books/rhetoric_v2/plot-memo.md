# `rhetoric_v2` ブロックメモ

## 制約と到達点

- 新規長編。論破術の悪用指南ではなく、公共的な判断、交渉、説明、謝罪を扱う。
- 8幕＋終幕、約8万〜10万字。技法史は各事件に必要な範囲だけ。
- 読了後は、場の目的、聴衆、争点、証拠、配列、反論、関係、実行条件を確認して発言を設計・監査できる。

## 人物設定

- やる夫：虹見橋のたもとでサンドイッチ店を営む保存会員。橋への愛着と客足を同じ言葉で守ろうとする。
- やらない夫：対岸の診療所と福祉施設を結ぶ送迎運転手。元地方紙の整理記者で、迂回時間と安全の両方に利害を持つ。
- できる子：橋梁点検を担当した技術者。複数幕で測定値と不確実幅だけを提示する。
- きめぇ丸：地域ラジオの記者。第1・5・8幕で、引用と訂正の伝播を担う。

## マクガフィンとトイ

- 90秒カードR-0〜R-6。主張、根拠、暗黙前提、感情、行動要求、省略の六色欄を持つ。
- 空席カード7枚：通学者、車椅子利用者、商店、納税者、作業員、将来世代、欠席反対者。
- 虹見橋の木片：保存対象と思わせ、終幕では橋全体と記憶保存を分ける交渉材料になる。
- 同じ点検グラフの六版：軸、分母、期間、注釈を変え、印象と情報量を盲検する。

## 伏線と回収

- 最初の配信に「点検は大げさ」の一言。第6幕の藁人形、第8幕の謝罪対象として戻る。
- 会議室の空席をやる夫が配信機材置場に使い、やらない夫も送迎中の利用者を「自分が代弁できる」と決めつける。第7幕で双方の代弁の限界を認め、不在者の席として取り戻す。
- 橋の木片に補修年が三つ刻まれている。第4幕で「百年前のまま」という物語が誤りと判明する。
- 記者が毎回「見出しにすると何文字」と聞き、第8幕で訂正文の共有可能性へ回収する。
- Rカード裏の白紙をやる夫が無駄扱いし、終幕で質問時間として使う。

## 繰り返すギャグ

- やる夫が何にでも「歴史が泣いている」と付け、予算表や仮設トイレにまで歴史を泣かせる。
- 90秒タイマーが鳴っても結びが三つ続く。後半ほど短くなり、終幕は時間を余らせる。
- やらない夫が強い比喩を出すたび、やる夫が商品名として登録しようとする。
- 切り抜き再生数を票数へ換算しようとして、毎回別の分母に負ける。

## 緩急と息抜き

- 第1幕は配信炎上の高速導入、削除前の沈黙で急停止。
- 第2幕は付箋で争点を床へ分ける作業、第3幕は三音声の聞き比べ。
- 第4幕は橋上の現地説明で景色と比喩を扱い、第5幕は数字パズルで速度を上げる。
- 第6幕は模擬反論の応酬から鋼人化の静かな言い直しへ。
- 第7幕は交渉を知的クライマックス、第8幕は謝罪でギャグを抑える。
- 終幕は90秒の発言後に長い質問時間を置き、言わない勇気を情緒的到達にする。

## ブロック運用

各節はRカードの一欄が具体的に欠け、やる夫かやらない夫の現実の利害を傷つける事件から始める。やる夫の案は保存と商売には効き、やらない夫の案は安全と移動には効くが、どちらも単独では不在者を落とす構造にする。やらない夫は送迎側の異議と自分の素朴案を持つ当事者であり、自説も反例で修正する。技法名は作用と代償を言語化した後に付ける。幕末は同じ90秒を別聴衆へ渡し、支持率だけでなく理解、質問、合意、履行、関係を測る。

## 状態台帳の初期値

- R版、空席7、点検数値、会議日程を固定する。
- 誤謬・誘導技法は使用条件、害、検出・防御をセットにし、無差別な操作手順にしない。
- 橋梁の安全判断を教材の言葉だけで代替できるよう描かず、専門点検を前提にする。
- 数字例は仮想データと明記し、実在自治体・橋の事故へ結びつけない。
