# 寸評：やる夫で学ぶ軌道力学 ── 月へ行って、帰ってくる

約60KB／全7幕。「まっすぐ月へ飛ぶ」という素朴案が四方から潰される第1幕を起点に、軌道・ロケット方程式・vis-viva・ホーマン遷移・パッチドコニックを組み上げ、最後にアポロのLOR方式を必然として再導出する教材。

## 良い点

**第1幕が伏線の投下装置として非常によく設計されている。** 大砲23,000G（30行目）、ホバリング課金（62–66行目）、月の位置ずれ（86–88行目）、帰りの燃料の連鎖（104–107行目）の4つを冒頭で並べ、それぞれを4-1（379–381行目）、4-1の内訳（393–399行目）、4-4（666–669行目）、第5幕（884–886行目）で明示的に回収する。どの回収も「あっ、これ第1幕の◯◯だお」という形でやる夫自身に言わせており、読者が伏線を見失わない。

**ランデブー・パラドックスが直観破壊として最良の位置に置かれている。** 「前の仲間に追いつくには加速」という誰もが持つ直観を、周期の話だけで反転させる（260–267行目）。そして「なぜ直観が壊れたか、言葉にしろ」（272行目）→「位置と推力で考えるのをやめろ、保存量で考えろ」（282–283行目）と、失敗の原因を方法論の転換にまで昇華させている。第4幕以降の道具立てが「なぜ必要か」の動機がここで完全に立っている。

**vis-viva を二つの極端で検算させている。** 円軌道（$a=r$）で第2幕の式に一致（466–470行目）、$a\to\infty$ で脱出速度11.2km/s が出て第1幕の「秒速11km」の正体が判明（476–486行目）。新しい式を導いたら極限で既知の式に落ちるか確かめる、という物理の作法が、やる夫の手続きとして自然に埋め込まれている。

**LOR の再導出が「候補を条件でふるいにかける」形になっている。** 設計要請(1)〜(4)を番号で書き出させ（837–841行目）、候補A/B/C を同じ基準で落としていく（849–866行目）。しかも直接上昇とEORが藁人形ではなく、フォン・ブラウンが推した本命だったこと、ホーボルトが一人でねじ込んだ史実（874–879行目）が添えられ、やる夫が「藁人形じゃなかったお」と言う（882行目）。教材の再発見が歴史の再演であることが明示される稀な例。

**摂動を「バグから仕様へ」転じさせる締め方。** J2歳差を厄介者として提示した直後に、同じ歳差を1年周期に合わせると太陽同期軌道になる（980–986行目）。この反転が第7幕末尾の低エネルギー遷移（1133–1135行目「厄介者だった鋭敏さが、また味方に化ける」）と韻を踏み、二度使われる構造になっている。

**末尾に開いた問いがある。** やる夫自身が「三体問題をまともに使ったらもっと安い道があるのでは」と問い（1121–1125行目）、低エネルギー遷移と「ひてん」（1136–1137行目）が提示される。「今日通ったのは高速道路、宇宙にはまだ峠道がある」（1139–1140行目）という閉じ方は、教材の外へ扉を開けている。

## 欠点

**第7幕の「答え合わせ」が自己充足していて、検証になっていない。** 1072–1077行目で6項目すべてに ✓ が付き「全部合ってるお！！」（1079行目）となるが、③降下2.0、④上昇1.9、⑤TEI 0.9 は第5幕（788–789行目）でやる夫が計算せずに書き並べた値である。導出したのは①TLIと②LOIだけ。自分で置いた数字を自分で照合して全問正解するのは循環であり、教材のクライマックスとして最も弱い。③④⑤にも出典脚注がない（脚注10はサターンVのみ）。

**やる夫が失敗を「体験」せず、計算の中で先回りして回避する。** 遠心分離や配管のような実際に手を動かした失敗はなく、失敗はすべて机上の見積もりで却下される。第4幕以降は特に、やらない夫の「本当にそうか」「では計算しろ」への即応が続き（357行目→366行目、520行目→524行目、540行目→545行目）、やる夫が数往復詰まる場面がほぼない。「苦労の過程とセット」という点では第1幕・第3幕に偏っている。

**物語的な圧力が一切ない。** 舞台も期限も利害もなく、全編が二人の対話のみ（登場人物欄は6–8行目の2名だけ）。「月に行く」という動機は1行（14行目）で宣言されるだけで、予算・締切・競争相手・失敗した場合の損失が最後まで出てこない。第5幕の「請求書」という比喩は良いが、支払う相手も残高もないため比喩に留まっている。

**$\varepsilon = -GM/2a$ を天下り式に渡している。** 450行目で「代数計算の末に」出るとし「計算は任せる」で済ませているが、この式は vis-viva の心臓部であり、これを与えてしまうと 454–456行目の vis-viva 導出はただの代入作業になる。近地点・遠地点でエネルギーと角運動量を連立するくだりこそ、やる夫にやらせる価値がある。

**J2 の歳差公式が完全に天下り。** 939行目の式はやらない夫が突然書き下すだけで、$J_2$ の数値も定義も本文にない（$1.08\times10^{-3}$ という値がどこにも出ない）。しかも半通径ではなく $a$ を使った近似形で、円軌道以外では正しくない。他の式がすべてやる夫の手で立てられているのに、ここだけ導出も検算もない。

**影響圏半径66,000kmが与えられるだけ。** 706行目で数値が示されるが、なぜその大きさかの見積もり（地球と月の質量比に依存すること）がない。パッチドコニックの発想自体はやる夫が出している（699–702行目）だけに、境界の位置を自分で概算させないのは惜しい。

**旅の時間の食い違いが処理されていない。** 642–643行目で「5日と決まってる」と結論した直後に括弧書きで「実際のアポロは約3日」と添えられるが、月の重力に引き込まれる分でなぜ5日が3日になるのかの説明がない。第1幕（86行目）で3日を前提に位相計算しているため、読者は二つの数字の間で宙づりになる。

## 改善案

1. **第7幕の答え合わせを、③④⑤の事前計算に変える。** 第5幕の 788–789行目で③④を「約2.0」「約1.9」と書き置くのをやめ、月面の重力（$1.62\,\mathrm{m/s^2}$）と月の円軌道速度1.63km/s（727行目で既出）から、やる夫に上昇Δvを見積もらせる。理想値1.63に重力損失を上乗せして1.9前後になる、という粗い推定でよい。⑤TEIも月の脱出速度2.31km/s と近月点速度から算出できる。そのうえで第7幕の表に脚注を付ける。自分の見積もりが実測と合う体験は、値を書き写して✓を付ける現状より格段に強い。

2. **舞台と期限を1つ導入する。** 第1幕冒頭（13–16行目）に、やる夫が誰に何を提出しようとしているのか（例：有人月計画の設計案を期限までに出す）を10行程度で置き、第5幕の「請求書」を実際の予算・機体規模の制約に紐づける。第6幕の予備Δv（1054行目）が「余裕を積む＝重量を食う＝予算に響く」という緊張を持てば、6-2の着地が説教から判断に変わる。今は勉強中だが月探査ベンチャー企業として起業したい、投資家に出さなければならないなど。

3. **$\varepsilon = -GM/2a$ をやる夫に導かせる。** 450行目を、やらない夫が「近地点と遠地点で $\varepsilon$ と角運動量 $rv$ が両方保存する。連立して $v$ を消せ」と道具だけ渡す形に変え、やる夫に $r_p v_p = r_a v_a$ から $\varepsilon$ を $a$ だけの式に落とさせる。15行程度で済み、vis-viva が「与えられた式への代入」から「自分で組んだ式」に格上げされる。

4. **J2 の扱いを整える。** 939行目の前に、扁平率1/298（928行目）から余分な引力が本来の重力の $10^{-3}$ 程度であることをやる夫に概算させ、「1周あたり $10^{-3}$ ラジアン程度ずれるなら、92分周期で1日15周だから数度／日」という桁の見積もりを先に出させる。そのうえで正確な式を提示すれば、天下り感が消えて桁の妥当性も体感できる。

5. **影響圏半径を自分で見積もらせる。** 706行目の直前に「月の重力が地球の重力に勝ち始めるのはどこか」を問い、$GM_{\text{月}}/d^2 = GM_{\text{地}}/D^2$ という素朴な釣り合い点（約38,000km）をやる夫に出させ、実際の影響圏66,000kmとのずれを提示する。「単純な釣り合いより広い」理由（潮汐的な扱い）は一言で足りる。

6. **旅の時間5日 vs 3日を解消する。** 643行目の括弧を本文に昇格させ、「遷移楕円の遠地点が月の軌道半径ちょうどではなく、月の影響圏に入った時点で終わるため、楕円の半周を回りきる前に到着する」旨をやらない夫に2〜3行で説明させる。第1幕86行目の位相計算も、後で5日に更新される旨を4-4で一言拾う。

7. **失敗の往復を第4幕に1つ足す。** 4-3のホーマン遷移（516–557行目）で、やる夫が「外向きに一発」を提案して外れる（533–538行目）くだりは良い出だしだが、すぐ正解へ跳ぶ。ここに「では外向き一発で本当に外へ行けるか、vis-viva で近地点速度を計算しろ」という数値的な失敗を1往復挟み、進行方向の噴射でなければ長半径が効率的に伸びないことを自分で確認させる。
