# 寸評：やる夫の世界平和 ── 国連事務総長になって設計する

約63KB／全6幕。国連事務総長に就任したやる夫が素朴な平和案を出しては潰され、Fearon の「合理的戦争原因」三体を軸に、集団安全保障・拒否権・抑止・PKO を再発明していく教材。

## 良い点

**「三体の敵」という地図が全幕を貫く背骨になっている。** 第2幕で情報の非対称性・コミットメント問題・分割不可能性を確立し（321–328行目）、「道具を見たら常に『これはどの敵を殺す武器だ?』と問え」（334行目）という読み方まで明示する。以後、査察（502–509行目）、拒否権（738–739行目）、棚上げ（864–868行目）が全部この3軸に回収され、最終幕の対応表（995–1014行目）と付録の早見表（1104–1109行目）で閉じる。設計思想がぶれない。

**拒否権の再発明が本書の白眉。** 「多数決こそ正義」（621–623行目）→「多数決で負けた大国は脱退する」（629–635行目）→「大国が留まる条件は何か」（641–652行目）と、やる夫自身が特権付与という不愉快な結論へ追い込まれる。その上で「拒否権を廃止すべき」（706–707行目）を出させ、廃止すると連盟に戻ると自分で気づかせ（713–719行目）、「バグじゃなくて仕様」「値札」（730–732行目）へ着地させる。理想論を一度も外から否定せず、自分の案の帰結だけで詰ませている。

**PKO三原則の導出と反転が鮮やか。** やる夫に中立・同意・非武力を自力で列挙させ（886–892行目）、ルワンダに当てはめて「三原則が全部、虐殺を止めない方向に働いてる」（909–916行目）と自分の設計が裏返る瞬間を作る。そこから平和強制の条件を再導出させる（930–935行目）。「正しい原則が場面によって害になる」という一段深い理解に、余計な説明なしで到達している。

**伏線が実際に牙を剥く。** 第4幕で買った拒否権という「値札」が、第5幕で R2P の発動鍵として跳ね返る（948–962行目）。作者自身が「第4幕の値札が、ここで牙を剥く」（965行目）と回収を宣言しており、章をまたいだ因果が装飾ではなく論証になっている。

**時事例の扱いを冒頭で宣言している。** 「2026年7月10日時点のスナップショット」「理論の骨格は歴史例に置き、イラン・ウクライナ・台湾は補助例」（10–12行目）と役割分担を明示。実際に軍拡スパイラルは英独建艦競争で構造を確定させてから南シナ海に適用しており（416–437行目）、賞味期限のある例に理論を依存させない設計になっている。参考文献も22点、本文に脚注番号つきで対応する。

## 欠点

**第1幕で掲げた積極的平和が最後まで回収されない。** 66–73行目でガルトゥングを引き「やる夫が目指すべきは積極的平和」と目標を設定するのに、以降の6幕は全て消極的平和（撃ち合いを止める）の設計である。構造的暴力、貧困、格差、開発といった話題は一度も現れず、1048–1049行目で「積極的平和はもっと遠い」と述べて終わる。教材が自分で立てた目標を、達成できないと認めるのではなく、扱わないまま閉じている。

**やる夫が賢すぎる箇所が多い。** 194–208行目では、シグナリングの問題（弱い国ほどハッタリをかける／強い国は区別してもらえない／だから軍事演習で証明する）を、やらない夫の「なぜズレる」の一言だけでほぼ完全に説明しきり、そのまま自分で「情報の非対称性」と命名する。296–300行目の分割不可能性も、「分けられないもの」の例としてエルサレムを即答。第4幕の拒否権が3往復かけて追い詰められるのと比べ、抵抗がなさすぎる。

**数値が第3幕の利得表で止まる。** 第2幕の「X=GDPの5%、戦争コスト10%」（126–151行目）は交渉可能領域を数で見せる良い導入だが、以後この計算は一度も使われない。第3幕の利得表（364–367行目）も、繰り返しゲームの割引因子や「未来がどれだけ重ければ協調が支配的になるか」（487–488行目で「未来が十分に重い」と言うだけ）を数値化しない。$T>R>P>S$ を書いた以上（398行目）、しっぺ返しの成立条件を1回計算させれば、抽象的な「未来の影」が量になった。

**国連が機能した事例が一つもない。** 満州、エチオピア、ウクライナ、シリア、ルワンダ、スレブレニツァと、挙がるのは全て失敗である。1022–1031行目の Long Peace だけが成功として置かれるが、それは核抑止との合わせ技で、国連固有の寄与が切り分けられていない。PKO が停戦後に「見事に機能する」（896行目）と一言あるのに、具体例（ナミビア、リベリア、東ティモール等）が挙がらないため、読後感が「国連は無力」に偏る。第5幕の三原則導出も、成功例を1つ置いてから反例をぶつけたほうが落差が効く。

**物語的な圧力が存在しない。** 「事務総長に就任」は看板だけで、期限も予算も部下も、判断を迫る危機もない。最終幕の「お前の任期は、まだ始まったばかりだ」（1096行目）が効くのは、任期中に何か決断させた場合である。実際には全編がやらない夫の設問とやる夫の応答で、第3の登場人物も、外部からの締切も一切ない。会話が講義形式に張り付いている原因もここにある。

**MAD の物理的裏付けが省かれている。** 783–789行目でやる夫は「先制攻撃で潰されても生き残った核で報復できる」と第二撃能力に自力で到達するが、なぜそれが可能なのか（潜水艦発射弾道ミサイル、地下サイロ、移動式発射機）が一切出てこない。「生き残る核をどう作るか」は抑止の中核の工学的条件で、ここを飛ばすと MAD が概念操作だけに見える。

**未使用の参考文献が残っている。** [^23]（ロシア・ウクライナ戦争の死傷者、1138行目）は本文のどこからも参照されていない。第6幕で「4年を超えて続き」（1035行目）と述べる箇所に、死傷者の実数を入れる予定だった痕跡と思われる。

## 改善案

1. **積極的平和を最終幕で正面から扱う。** 1047–1051行目のやる夫の述懐を10〜20行に拡張し、第1幕で掲げた目標に答えを返す。具体的には、やらない夫に「消極的平和の道具（拒否権・抑止・PKO）は、積極的平和の敵をどれも殺していない」と言わせ、経済相互依存、開発援助、人権レジームが「未来の影を重くする＝コミットメント問題を緩める」道具として三体の地図の上に乗ることをやる夫に発見させる。地図が拡張されるので、既存構造を壊さずに接続できる。

2. **成功例を第5幕の冒頭に1つ置く。** 895–896行目「停戦後の土地では見事に機能する」の直後に、ナミビア（UNTAG、1989–90年の独立監視）を10行ほど入れ、やる夫に「同意・中立・非武力の三原則が全部満たされている」と確認させる。その上でルワンダへ移れば、同じ三原則が真逆に働く落差が計測可能になり、「PKO は無力」ではなく「適用条件がある」という正しい理解になる。

3. **しっぺ返しの成立条件を計算させる。** 486–496行目のあいだに、割引因子 $\delta$ を導入して「裏切りの利得 $5 + \delta\cdot 1/(1-\delta)$ と協調の $3/(1-\delta)$ を比べろ」とやる夫に解かせ、$\delta > 1/2$ という数を自分で出させる。10行で済み、「未来が十分に重い」という定性語に境界値が入る。第2幕の 5%/10% と並ぶ、二つ目の数値の錨になる。

4. **情報の非対称性の発見に一度失敗を挟む。** 191行目「正直に手札を見せ合えばいいだろう」に対し、やる夫にまず「じゃあ軍事力を国連に申告させる制度を作るお」と答えさせ、やらない夫が「弱い国は水増しし、強い国は本当のことを言っても信じてもらえない。申告制度は何を解決した?」と潰す往復を入れる。その失敗を経てから、コストのかかるシグナル（軍事演習、ミサイル発射）に到達させれば、第4幕と同じ密度になる。

5. **第二撃能力の中身をやる夫に設計させる。** 789行目の直後に、やらない夫が「では、先制攻撃で全部壊されない核をどう置く」と問い、やる夫に「海に沈める」「動かす」「地下に埋める」を自力で挙げさせる。SLBM と移動式発射機の実在に触れれば、MAD が概念から装置に降りる。

6. **利害を持つ第三の人物を入れる。** 例えば安保理常任理事国の大使、あるいは予算を握る事務局の財務担当を できる子として置き、第4幕（616行目以降）と第5幕（948行目以降）に登場させて、やる夫の案に「その決議はうちの本国が呑まない」「その部隊の派遣費用は誰が出す」と現実的な制約をぶつけさせる。教師役の設問ではなく利害の衝突として反論が来るので、講義調が緩み、事務総長という設定が初めて機能する。

7. **未使用脚注を回収するか削る。** 1035行目の「4年を超えて続き」に死傷者の概数と [^23] を付けるか、1138行目を削除する。
