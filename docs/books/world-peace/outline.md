# やる夫の世界平和 ── 国連事務総長になって設計する の骨格

冒頭に **時事例の扱い** の注記（2026年7月10日時点のスナップショット。理論はA国・B国のトイ例と確定した歴史例に置き、イラン・ウクライナ・台湾海峡は補助例）。巻末に「三体の敵と国連の道具」早見表。

## 第1幕　平和とは「何がない状態」か
- 「戦争がない＝平和」を、台湾海峡の砲弾なき緊張と冷戦44年で潰し、消極的平和／積極的平和（ガルトゥング）を区別。次に「悪い国を皆で懲らしめる」＝集団安全保障を言わせ、それが1920年に実装されて壊れた（国際連盟）とだけ告げて第4幕へ保留。「平和は状態でなく設計問題」。

## 第2幕　なぜ戦争は起きるのか ── 三体の敵
- 「悪い指導者のせい」を、資源地帯Xの価値5%対戦争コスト10%の計算で潰す（勝っても−5%）。交渉可能領域が必ず存在する＝合理的なら戦争は避けられる、というフェアロンの設定へ。
- 敵1 **情報の非対称性**：軍事力の申告制度案を「弱い国は水増しし、強い国の申告も信じられない」で潰し、費用のかかるシグナル（軍事演習）へ。その副作用が戦争の火種。補助例＝イランの査察制限と2026年2月末の攻撃。
- 敵2 **コミットメント問題**：合意しても守らせる上位者がいない。5年後にB国が強くなるなら今のうちに叩く＝予防戦争。補助例＝ウクライナ停戦とNATO加盟要求。
- 敵3 **分割不可能性**：エルサレム、台湾。緩め方は**第5幕への保留**。
- 「これから作る国連のあらゆる仕組みは、全部この三体のどれかを狙い撃つ道具だ。道具を見たら『これはどの敵を殺す武器だ』と問え」という地図を渡す。

## 第3幕　協力はなぜ崩れるか ── 軍拡のゲーム
- 利得表（+3,+3 / −2,+5 / +5,−2 / +1,+1）で囚人のジレンマを自力で計算させ、$T>R>P>S$（$5>3>1>-2$）。安全保障のジレンマ。実例＝英独建艦競争とドレッドノート、補助例＝南シナ海。
- 「条約を結ばせればいい」を、署名しても裏切りが得なままだと気づかせ、やる夫自身が「これは第2幕のコミットメント問題だ」と病名を当てる。
- 繰り返しゲームとしっぺ返し。「未来の影」を詩で終わらせず、$\frac{3}{1-\delta}\ge 5+\frac{\delta}{1-\delta}$ から $\delta\ge 1/2$ を導く。$\delta$ は誠実さでなく「あと何年その椅子に座るつもりか」。「利得表は変えられないが $\delta$ なら動かせる。動かせるほうを動かす」（**第6幕で回収される最重要の伏線**、やらない夫が「第6幕でもう一度この $\delta$ に戻る」と明言）。
- 最後に検証の必要（裏切りを検出できなければしっぺ返しは働かない）→ 査察。ここで第2幕のイランと接続。「信ぜよ、されど検証せよ」。

## 第4幕　大国をどう扱うか ── 拒否権の再発明
- 第1幕で保留した集団安全保障を設計させ、動く条件3つ（認定／発動／痛み）を列挙させてから、国際連盟でその3つが順に破れたと見せる：満州事変の認定→日本の脱退／全会一致→侵略国自身が拒否できる／エチオピア侵攻の制裁→石油禁輸の除外と米国の未加盟。根本原因は「大国の扱い」。
- やる夫が「多数決にすればいい」と言った直後、**できる子**が5大国の「多数決で拘束されるなら署名しない」という回答と、軍事支出6割・分担金4割という数字を出す。多数決で負けた大国は脱退する→大国を絶対に脱退させない条件を考えて、やる夫が自力で**拒否権を再発明**する。
- 拒否権の代償をトイ例（大国Cが同盟国Aを守る）で計算し、補助例＝ウクライナで安保理が麻痺し舞台が総会（2026年2月24日、賛成107・反対12・棄権51、法的拘束力なし）へ移ること、シリアでの繰り返しの拒否権行使。
- 「拒否権を廃止すべき」→廃止すると第4幕の最初に戻る（大国が脱退し、外で誰の制約も受けずに戦争する）と自分で気づき、「拒否権はバグでなく仕様」「大国戦争を絶対に防ぐという最優先目標を買うための値札」へ到達。

## 第5幕　抑止と平和維持 ── 殺し合いを止める
- 5-1　「圧倒的優位で安全」を、完成前に叩かれるリスク（＝第2幕の予防戦争、補助例イラン）で潰す。目指すべきは優位でなく確実な報復能力。第二撃能力の実装を、やる夫が「場所が分からない／動く／壊れない」の3条件から潜水艦・移動式発射機・地下サイロを自力で導く。「相手にも同じものを持たせたほうが安定する」＝MAD。キューバ危機で検算。抑止の前提（相手が合理的／指揮系統が確実／非国家主体でない）が崩れると抑止も崩れる → NPT・IAEAは「抑止が効く前提を守る仕組み」。
- 5-2　**第2幕の保留（分割不可能性の緩め方）を回収**。台湾がなぜ決着せずに済んでいるかから、「分けられないなら時間で割る／先送りする」＝戦略的曖昧さ・棚上げへ。三体の敵すべてに対処法が出揃う。
- 5-3　PKOの三原則（同意・中立・自衛以外の不行使）をやる夫に列挙させ、ナミビア UNTAG で全部満たされる成功例を見る。ここで「PKOがやっているのは敵1（情報の非対称性）つぶし＝中立の目撃者」「三原則はPKOが証拠として機能するための条件」と気づく。次にルワンダで同じ三原則が全部虐殺を止めない方向に働くことを判定させ、平和維持と**平和強制**の境界を自力で引く。スレブレニツァ。R2Pに飛びつくが、発動の鍵が安保理＝拒否権に握られていると気づく。さらに**できる子**が第二の門（5,000名・展開60〜90日に対し虐殺は100日、部隊提供国と費用償還の遅れ）を数字で示し、「拒否権を全部消しても次の壁が待っている」と分かる。「万能の仕組みは無い」。

## 第6幕　答え合わせ ── 平和は完成したか
- 三体の敵と国連の道具の対応づけ。最大の検算＝1945年以降、大国同士の全面戦争が一度も起きていない「長い平和」。だが2026年時点でウクライナは4年超、イランとの戦争、台湾海峡。「国連はすべての戦争をなくす機構ではなく、大国戦争だけは防ぐ機構として設計された」。
- 第1幕の目標（積極的平和）へ戻り、6幕で作った道具が積極的平和の敵を**ゼロ**しか殺していないと自認する。そこから 3幕の $\delta$ を思い出し、$\delta$ を上げる装置＝経済相互依存・開発援助と貧困削減・人権レジームと国内制度（個人の椅子と国家の $\delta$ を切り離す）を挙げる。「積極的平和は別の目標でなく、三体の地図の同じマス（コミットメント問題）を、罰でなく未来の重みという別の武器で攻めること」。$\delta$ を上げる道具は効くのが遅いので両方要る。
- 全行程の振り返り（9つのつまずき）。最後に、80年前の設計図（敵は大国の核ミサイル）では扱えない新しい敵（非国家テロ、サイバー、AI兵器、気候変動）を未解決の問いとして置く。

## 依存
- 「三体の敵」は第2幕で確立し、第3幕・第4幕・第5幕の各道具がどの敵を狙うかで意味づけられ、第6幕と巻末早見表で総括される。敵の数や名称を変えると全編と付録が連動する。
- $\delta\ge 1/2$ の計算（第3幕）は本編最大の伏線。やらない夫が「第6幕でもう一度戻る」と明言し、第6幕で積極的平和の定義そのものに使われる。利得表の数値（3/5/1/−2）を変えると $\delta$ の閾値も変わり、第6幕の議論の土台も動く。
- 第1幕で保留した集団安全保障→第4幕で国際連盟として回収。第2幕で保留した分割不可能性の緩め方→5-2 で回収。
- 第4幕で得た「拒否権は値札」は、5-3 でR2Pの発動を阻む形で牙を剥き、第6幕で「同じ一本の拒否権」として総括される。本文が「これが伏線の回収だ」と明示している。
- 第2幕のイラン（情報の非対称性／予防戦争）は、第3幕末（査察がなければしっぺ返しが働かない）と 5-1（優位を築こうとして叩かれる）で計3回参照される。
- できる子は第4幕（5大国の署名拒否と分担金4割）と 5-3（5,000名・60〜90日・償還1年半遅れ）の2箇所だけに登場し、いずれも理念を数字で止める役。片方を削るともう片方の効き目が落ちる。
- 5-3 のナミビア（成功）とルワンダ／スレブレニツァ（失敗）は同じ三原則で判定する対照実験。三原則を変えるなら両方の判定も直す。
- 時事例（イラン2026年2月末、ウクライナ総会決議2026年2月24日の賛否数、台湾海峡、南シナ海）は冒頭注記で「情勢が変われば読み替える」と断られている。更新するときは冒頭注記の日付と巻末早見表の補助例欄も揃える。
