# 改稿記録

`review-opus-medium.md` の改善案7点に沿って改稿した。

## 工夫した点・主な変更

- **積極的平和を最終幕で正面から回収した（改善案1）。** やらない夫が「第1幕で立てた目標は何だった」と戻し、6幕で作った道具（集団安全保障、拒否権、抑止、査察、PKO、平和強制、R2P）が積極的平和の敵をいくつ殺したかを問う。やる夫の答えは**ゼロ**で、「全部、撃ち合いが始まってから働く道具だ」と自己診断させた。そこから第3幕の $\delta$ を思い出させ、「表は変えられないが $\delta$ なら動かせると自分で言ったのに、$\delta$ を上げる装置を一つも作っていない」と気づかせている。

- **積極的平和を「別の目標」ではなく「同じマスを別の武器で攻めること」として地図に乗せた。** 経済相互依存（明日も取引が続く見込みが今日壊す損を大きくする）、開発援助（失うものがない人間に $\delta$ は期待できない）、人権レジームと国内制度（指導者個人の椅子と国家の $\delta$ を切り離す装置）の3つを、すべて $\delta$ を上げる装置として整理させた。締めは、三体の敵のうち情報の非対称性は査察で、分割不可能性は棚上げで対処できたが、**コミットメント問題だけが消極的平和の道具では解けていない**、積極的平和はその同じマスを罰ではなく未来の重みで攻める道だ、という位置づけ。既存の三体の地図を壊さずに拡張できる形にした。やらない夫が「$\delta$ を上げる道具は効くのが遅い、一方で殴り合いは今日始まる」と釘を刺し、やる夫が「消極的平和の道具は $\delta$ が育つまでの時間を稼ぐためのものだ」と両者を接続する。

- **PKOの成功例をルワンダの前に置いた（改善案2）。** ナミビア（UNTAG、1989–90）を入れ、撤退監視・武装解除・差別法廃止の確認・制憲議会選挙の監視という具体を出したうえで、やる夫に三原則が全部満たされていることを確認させた。単なる成功例の紹介で終わらせず、「ここでPKOがやっているのは第2幕の一つ目の敵つぶしだ、当事者同士では確認できないことを第三者が双方に見えるようにしている」と、情報の非対称性へ接続させた。やらない夫の「中立と非武力は飾りではない。どちらかに肩入れした瞬間その目撃証言は誰にも信じられなくなる。撃った瞬間、目撃者は当事者になる。**三原則はPKOが証拠として機能するための条件だ**」で、直後のルワンダの反転が「原則の失敗」ではなく「適用条件の逸脱」として読めるようにした。

- **しっぺ返しの成立条件を計算させた（改善案3）。** 「未来の影」を詩だと切り、割引因子 $\delta$ を導入させた。既存の利得表（$T=5, R=3, P=1, S=-2$）を使い、協調 $3/(1-\delta)$ と裏切り $5+\delta/(1-\delta)$ を比べさせて $\delta \ge 1/2$ を自分で出させている。数を言葉に戻す作業も踏ませ、「$\delta$ は誠実さでも道徳心でもない、**あと何年その椅子に座るつもりか**だ」「任期が残り半年の指導者と20年やるつもりの指導者では、同じ条約でも $\delta$ が違う」に着地させた。この $1/2$ が第6幕の積極的平和の議論の土台になるので、やらない夫に「第6幕でもう一度この $\delta$ に戻る」と予告させている。

- **情報の非対称性の発見に、一度失敗を挟んだ（改善案4）。** 「正直に手札を見せ合えばいい」に対し、やる夫にまず**軍事力の申告制度**を提案させ、(1) 弱い国は水増しする、(2) 強い国が正直に申告しても信じてもらえない、(3) 結果として申告書が紙の上で同じになる、という3段で潰した。「むしろ全員が水増しするから、全員が実際より強く見えて、かえって最悪の想定が膨らむ」まで言わせている。やらない夫の総括を「**タダで言えることは、何も証明しない**」に置き、そこから費用のかかるシグナルへ到達させた。さらに「証明のために本物の軍事行動をとらないといけない、信じてもらうための手段がそのまま戦争の火種だ」という副作用まで自分で言わせ、第3幕の安全保障のジレンマへの助走にした。

- **第二撃能力をやる夫に設計させた（改善案5）。** 「先制攻撃で全部壊されない核をどこへ置く」という問いを立て、やる夫に条件を「場所が分からない／動く／壊れない」の三つに分解させてから、海に沈める・陸を動かす・地下に埋めるを自力で挙げさせた。やらない夫が潜水艦発射弾道ミサイル・移動式発射機・地下サイロとして実在を確認し、「核保有国が同じものを三つ揃えるのは見栄ではない、**同時に全部を潰す方法がない組み合わせ**を作っている」と締める。やる夫の受けは「『必ずやり返せる』は気持ちの問題ではなかった。海の深さと、道路の長さと、コンクリートの厚さだ」。さらに「相手にも同じものを持たせたほうが安定する、相手の報復能力を潰せてしまうと相手は使う前に使えと考える」という逆説まで到達させ、MADの導入を概念操作から装置へ降ろした。

- **利害を持つ第三の人物として できる子 を追加した（改善案6）。** 事務局の加盟国調整担当とし、理想も反対意見も述べず、各国の本国の回答と予算・兵力の数字だけを伝える役に固定した。第4幕では、やる夫の多数決案に対し「5か国から同一の回答、多数決で拘束されるなら署名しない」を持ち込み、その5か国が世界の軍事支出の約6割、国連通常予算の分担金の約4割を占めることを数字で示す。やる夫が「決議は通るけど、誰も動かせない」と自分で結論するので、拒否権の再発明が教師の設問ではなく交渉の帰結として起きる。

- **R2Pの後に「二番目の門」を置いた（改善案6）。** できる子が、仮に拒否権が使われなくても、ルワンダ規模の虐殺を止めるには5,000名と装甲車両と航空輸送が要り、展開まで60〜90日（虐殺は100日で終わった）、費用の償還は平均1年半遅れ、という数字を出す。やる夫の到達点は「拒否権が悪者だと思っていた。でも拒否権を全部消しても次の壁が待っている。『止めるべきだ』と全員が合意しても、『うちの兵士が行く』と言う国は別に必要だ」。やらない夫が「拒否権は最初の門で、部隊提供と費用負担は二番目の門だ。理念は門を通らない。通るのは、通す理由を持った国だけだ」で受ける。既存の「第4幕の値札が牙を剥く」の直前に置いたので、伏線回収の重みを削がず、その先へ一段進めた。

- **未使用脚注 [^23] を回収した（改善案7）。** 第6幕の「ウクライナへの全面侵攻は4年を超えて続き」の直後に、「双方の死傷者は、推計に幅はあるものの数十万人規模に達している」を挿入して [^23] を付けた。推計値そのものを断定せず、幅があることを明示する書き方にしたのは、冒頭の「2026年7月10日時点のスナップショット」という宣言と整合させるため。

- **最終幕の振り返りリストに3行を追加した。** 「ナミビアの成功条件とルワンダの無力」「拒否権さえなければ介入できる → 部隊を出す国が要る」「積極的平和は別の目標 → $\delta$ を上げる道具」。今回の改稿で増えた3つの躓きが、既存の「素朴な案が死んだ跡地」の一覧に並ぶようにした。

## 残した判断

- 三体の敵を全幕の背骨にする構成、拒否権の再発明（理想論を外から否定せず自分の案の帰結だけで詰ませる）、PKO三原則の導出と反転、第4幕の値札が第5幕で牙を剥く伏線、時事例の扱いを冒頭で宣言する設計、参考文献22点は、レビューで評価された骨格なのでそのまま維持した。

- レビューの欠点欄にある「物語的な圧力が存在しない」については、できる子の追加（改善案6）で、加盟国の拒否・分担金・部隊提供という外部からの制約が第4幕と第5幕に入った。ただし任期や期限といった時間の圧力は、この教材が歴史例を横断する構成であることと合わないため導入していない。

- 追加した数字（分担金の約4割、軍事支出の約6割、5,000名、60〜90日、償還の1年半遅れ）は、議論の骨格を成立させるための概数として作中の事務局データという形で置いた。実在の特定年度の統計として提示していないのは、冒頭の「情勢が変われば読み替えること」という宣言の範囲に収めるためである。既存の脚注つきの数値（死者数、決議の賛否、条約名）には手を触れていない。
