# 寸評：やる夫が元素を発見するようです ―― 石と炎しか知らない世界から周期表へ

約86KB／全10幕＋終幕。錬金術工房で「色ごとに棚を分ける」ところから始まり、混合と化合、気体、質量保存、フロギストン、原子と分子、電気分解、周期律、希ガス、原子番号を経て、「金は作れません」という看板に着地する。

## 良い点

**「物質系譜帳」が教材の進行そのものになる。** できる子が第1幕（138–144行目）で5欄の帳面を作り、以後、判定欄（241–244行目）、密閉天秤箱（615–618行目）、酸素移動欄（817–821行目）、物質層と元素層への2分割（956–966行目）、暫定原子模型（1127–1129行目）、化学式の表記約束（1234–1243行目）、元素カード（1612–1615行目）、分光器の記録（1961–1964行目）と成長する。読者は自分が何を獲得したかを帳面の欄として数えられる。

**「物質札」が時代の語彙で書かれている。** 胆礬（96–99行目）、生石灰（199–203行目）、苛性アルカリ液（358–362行目）、礬油（381–385行目）、強水（398–402行目）、金属灰（650–655行目）。いずれも当時の呼称・英名・ラテン名・作り方・用途・注意を揃えており、礬油の希釈手順（385行目「必ず水のほうへ礬油を細く注ぐ」）まで書く。近代的な元素名を知らない状態を、語彙の面から本気で再現している。

**フロギストン説の扱いが公正。** 4-1でまず成功を体験させる。燃焼・製錬・呼吸を一つの原理で統一し（660–679行目）、やる夫に「これはかなり強い説だお」と言わせてから、金属の質量増加という反例（682–693行目）、負の質量という修正（699–700行目）、そして709行目の循環論法の指摘へ進む。713–717行目「すぐ捨てるには惜しいお」「新しい説は成功例も説明し、さらに質量増加を自然に説明する必要がある」。棄却された理論を単なる誤りとして片付けていない。

**7-2の循環論法を明示する。** 「化学式を決めるために原子量が必要。原子量を決めるために化学式が必要」（1301–1303行目）。$\mathrm{HO}$ と $\mathrm{H_2O}$ が質量比だけでは区別できないことを実際に確かめさせ（1276–1280行目）、7-3では仮定を2つ並べてどちらを捨てるか選ばせる（1359–1360行目）。原子論を置いただけでは式が決まらない、という19世紀中葉の実際の停滞が再現される。

**第10幕の希ガス発見が白眉。** 1900行目の「何とも反応しない元素があったら、どうやって見つける」という問いが、それまで9幕で使ってきた手段（反応）を一挙に無効化する。密度の0.5%差（1911–1918行目）→誤差か中身かの判別（1925–1929行目）→比熱比1.67による単原子の決定（1993–1996行目）→輝線（1961–1968行目）→液体空気の分留（2066–2078行目）。そして2100–2103行目でやる夫が第1幕と対比する――「あのときは黄色い粉という、混ぜれば混ざり薄めれば薄まる特徴を見ていた。輝線は、混ぜても薄めても位置が動かない。量ではなく、位置が指紋になっている」。教材の最初の失敗が、最後の成功の対義語として回収される。

**錬金術の決着に逃げがない。** 2379–2392行目。鉛は82、金は79、陽子を3個減らす操作が炉にも坩堝にも王水にもない。しかも核反応でなら実現するが採算が合わないと補い、「間違いだったというより、使える道具の外側にあった」と着地する。さらに看板のオチ（2408–2428行目）で、第2幕の物質札（強水は銀を溶かし金を溶かさない）が金の真贋鑑定の値段表に転用される。

**参考文献10点がすべて原典＋標準的化学史で、対応箇所つき。** Davy 1808、Mendeleev 1869＋Scerri 2007、Moseley 1913、Lavoisier 1789、Dalton 1808、Avogadro 1811、Cannizzaro 1858、Partington／Ihde、Berzelius 1813、Rayleigh–Ramsay 1895ほか。

## 欠点

**第6幕に計算がない。** 倍数比例が主題なのに、1057行目「炭の軽い気体を1とすれば、炭酸ガスでは2」、1066行目の1対2、1074行目の2対3は、いずれも比を宣言するだけで実測質量からの計算過程がない。995–996行目の「水素1に対して酸素8」も、できる子が結果だけ述べる。第6幕は「なぜ飛び飛びの比になるのか」を問う幕（1038行目）だが、その飛び飛びの比自体が読者の手で確かめられない。

**第9幕で周期表を組む場面がない。** 1618行目でやる夫が「このカードを原子量順に並べたら、家族が何度も現れるかもしれないお」と期待を立てるのに、並べた結果の表が本文に一度も現れない。9-1では化合物の型を列挙し（1635–1726行目）、1748–1750行目で「重い元素では崩れる」と述べるが、崩れ方が文章による説明で、表の破綻として見えない。表題が「周期表へ」である教材の中心が、記述で処理されている。

**第8幕にイオンと電子の式が唐突に入る。** 1454行目「現代的な表現なら」と断ってから $\mathrm{Na^+ + e^- \rightarrow Na}$（1457行目）が出るが、電子もイオンも、この時点で教材は一切導入していない（電子配置は10-3の2228行目が初出）。物質札を当時の語彙で書き通してきた一貫性が、ここだけ破れる。

**できる夫の役割が3回とも違う。** 1161–1166行目で記号のラテン語化という有用な提案、1735–1738行目でオクターブ則という誤り、1816–1818行目でエカアルミニウムの予測という正解。人物紹介（20–23行目）の「名前を付けるのも速い」に対して、有用・誤り・正解を1回ずつ担うため、登場するたび読者が「今回はどちらの役か」を判断できない。

**やる夫の撤回が速すぎる。** 第1幕の色分類、4元素説、第2幕の混合物万能、第3幕の気体一元論、5-1の水＝根源物質、6-1の割合自由、8-2の色による分類。いずれも1〜2往復で撤回される。負の質量まで食い下がる4-1のフロギストンだけが例外で、そこが最も読み応えのある節になっているのは偶然ではない。

**前史が長い。** 全2470行のうち、周期表を扱う第9幕以降は850行。第2幕（混合と化合）と第3幕（気体の同定と質量保存）は、それぞれ論点が実質1つずつで、往復数に対して進む距離が短い。

## 改善案

1. **第6幕に実測からの計算を入れる。** 1054行目付近で、できる子に測定値を読ませる――同じ炭12gから、炭酸ガス44g と炭の軽い気体28g。やる夫に結びついた酸素を32g と16g と引き算させ、比が2対1だと自分で出させる。銅の2種の灰、硫黄の2種の気体も同様にすれば、1079–1083行目の比較表が、宣言ではなく計算の集計になる。

2. **第9幕で元素カードを実際に並べる。** 1627行目の直後に、軽い元素を原子量順に並べ、原子価と水素化物の型を列に持つ表を本文へ出す。そのうえで、1748行目の「重い元素では崩れる」を、同じ表を延長したときに列が合わなくなる形で見せる。9-2の空欄（1786行目）も、その表の空きマスとして提示すれば、「空欄を残す勇気」が視覚的に成立する。

3. **第8幕のイオン・電子表記を10-3へ移す。** 1454–1470行目を、当時の観察の記述（溶融した塩へ電流を通すと一方の極に金属が現れ、他方に黄緑色の気体が出る）に置き換える。イオンと電子による説明は、電子を導入した2220行目付近でまとめて置き、「8-1で見た電気分解は、こう書き直せる」と回収する形にする。時代設定の一貫性が保たれ、10-3が厚くなる。

4. **できる夫の役割を「早すぎる一般化」に統一する。** 1735–1738行目のオクターブ則を軸に据え、1161–1166行目では「記号は全部1文字で足りる」と性急に提案させて塩素で破綻させる（現状はできる夫が二文字案まで正しく出している）。1816–1818行目のエカアルミニウム予測は、やる夫の発言に移す。予測の主体が生徒側に戻り、9-2の「空欄へ入る元素の性質を発見前に予測する」（1793行目）という決意と一致する。

5. **5-1でやる夫に1回粘らせる。** 856–859行目で水の電気分解を見た後、すぐ納得させず「電極から出た気体は、もともと水に溶けていた空気ではないか」と食い下がらせる。あらかじめ煮沸脱気した水でも同じ体積比で出ることを確認させてから、862行目の電極の可能性の検討へ進む。フロギストン以外にも抵抗の場面が生まれる。

6. **第2幕と第3幕を圧縮して第9幕へ配分する。** 2-1（254–311行目）の混合物の判定は例が4つあるが2つで足り、3-1（451–534行目）の気体の同定も3種類のうち2種類を丁寧に扱えば型は伝わる。削った分を、改善案2の元素カードの並べ替えに充てる。
