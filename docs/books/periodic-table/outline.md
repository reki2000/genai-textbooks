# やる夫が元素を発見するようです ―― 石と炎しか知らない世界から周期表へ の骨格

舞台は相続した錬金術工房。やる夫の当初目的は**鉛を金に変えて大儲け**で、これが終幕で「なぜ40年やっても誰も成功しなかったか」として回収される（先代は理由を知らずに死んだ）。できる子は**物質系譜帳**と**物質札**（胆礬・生石灰・苛性アルカリ液・礬油・強水・金属灰…と、和名／英語名／ラテン語名／作り方／用途を並べた札）を作り続ける記録係で、この二つの教具が全編を通じて成長する。できる夫は「速すぎる一般化」役として 7-1（1文字記号）と 9-1（オクターブ則）に登場する。

## 第1幕　白い粉の中の世界
- 1-1　白い粉（塩・砂糖・石灰・石膏・重曹・顔料）が水と酸でばらばらに振る舞う。胆礬の加熱→白化→加水→再青化、銅板の赤／黒／青／白の遍歴から**色は物質の本名ではない**。物質系譜帳が5欄で発足。「記録欄が多すぎる、少数の根源物質で説明できないか」が 1-2 への導線。
- 1-2　4元素説。鉄から土を取り出せず、石灰石の分解も「石から空気が出た」で何でも説明できてしまう。**説明できることと予測できることは違う／反証できない説は暫定保留**という判定欄が系譜帳に追加され、これが第4幕のフロギストン批判の物差しになる。

## 第2幕　混ぜることと化けること
- 2-1　塩水・砂水・鉄粉と硫黄粉から混合物の三特徴（成分比が連続／性質が残る／物理的に分離可能）。「濾過・蒸留・結晶化を尽くせば化学は終わり」と宣言した直後に加熱を促される。
- 2-2　鉄＋硫黄の加熱で磁石も溶媒も効かなくなる＝化合。余分な鉄／硫黄が残ることから**決まった割合**の芽（第6幕の定比例）。胆礬→青い沈殿→黒い粉→胆礬の往復と、食塩水＋銀の強水液の白い沈殿（日光で黒ずむ）で組み替えを確認。系譜帳を線で結び、**銅に対応する何かが系譜を通じて保存される**という第5幕の元素概念の前触れ。

## 第3幕　空気の中の複数の物質
- 3-1　気体を発生源でなく**判定手順**で仮に呼ぶ：可燃空気／助燃空気／固定空気（＋水蒸気）の4行表。「気体は物質名でなく状態の名前」「空気は混合物」。この**仮の札**が 4-2（助燃空気→酸素／固定空気→炭酸ガス）と 5-1（可燃空気→水素）で一つずつ卒業していく。
- 3-2　木の燃焼で「物質が消えた」を、炭が固定空気になって逃げることで否定。石灰石100 g→生石灰約56 g＋約44 g。金属は逆に**重くなる**という反例をここで置き、密閉天秤箱を系譜帳の基準装置に据える。質量保存は「永久の証明」でなく「消えたと考えるより見落とした生成物を探すほうが成功する仮説」と限定する。

## 第4幕　燃える物質は何を失うのか
- 4-1　フロギストン説の**成功**を先に立てる（燃焼・製錬・呼吸を一つの原理で統一）。金属灰の質量増加という複数の反例に対し、やる夫が**負の質量**を持ち出し、やらない夫に「質量増加を説明するために負の質量を置き、負の質量の根拠に質量増加を使っている」と循環を突かれる。1-2 の反証可能性の基準がここで効く。「新しい説はフロギストン説の成功例も説明しなければならない」。
- 4-2　密閉容器で固体の増加＝気体の減少、空気の**約5分の1**で反応が止まる。助燃空気を**酸素**と命名（酸のもとになる気体）、固定空気を**炭酸ガス**と再命名。金属灰は固体で残り、炭・硫黄の生成物は気体で逃げるという状態の差が「増える／減る」の見かけを作る。製錬＝炭が酸素を奪う、呼吸も同型。酸化＝酸素との結合／還元＝酸素の除去（後世に電子移動へ一般化されると注記、10-3 で実際に回収）。

## 第5幕　水まで化合物だった
- 5-1　可燃空気＋酸素で水が生じ、電流で水が二つの気体へ分かれる。**「溶けていた空気が追い出されただけ」という対抗仮説を3段階で潰す**（残りかすの気体が出ない／コップに入り切らない体積が出続ける／脱気水でも同じ体積比）、さらに電極金属を替えても同じ＝分解と合成の両立。可燃空気を**水素**と命名。元素は「今の化学的方法でそれ以上分けられない純物質」という**操作的定義**であり、更新されうると明言（第8幕でその通りになる）。
- 5-2　酸素とオゾン、黒鉛とダイヤモンドから**単体≠元素**。単体＝1種類の元素からなる瓶に取れる物質、元素＝変化を通じて受け継がれる種類。系譜帳が**2層（物質層／元素層）**に分かれる。

## 第6幕　化合物は好きな割合で作れない
- 6-1　水の水素:酸素＝1:8 が出どころによらず一定、余剰は未反応で残る＝**定比例**。「元素に決まった結合能力があるから」は言い換えにすぎないと自分で却下。
- 6-2　**倍数比例**を3組の実数値で示す。炭12.0 g→28.0/44.0（酸素16.0/32.0＝1:2）、銅25.4 g→28.6/31.8（3.2/6.4＝1:2）、硫黄16.0 g→32.0/40.0（16.0/24.0＝2:3）。比較表つき。「1.37倍の酸素を含む純化合物はない」から**原子**仮説へ。フロギストンとの差を「都合が悪いたびに性質を足すのでなく、新しい質量比を予測できる」と明示。系譜帳には**観測事実でなくモデルとして区別して**記録する。

## 第7幕　原子を置いても式が決まらない
- 7-1　記号法。できる夫の「ラテン名の頭文字1文字で足りる、26文字で数十元素をさばける」が、**塩素の C が炭素と衝突**して崩れる。二文字目を小文字で添える規則、金属はラテン名から（Cu/Fe/Ag/Hg/Pb/Sn/Zn）。表記の約束5項目の表。最後に「記号は決まったが**式の中の原子数がまだ決まっていない**」と気づく。
- 7-2　$\mathrm{HO}$ か $\mathrm{H_2O}$ か。質量比1:8 は両方と両立し、「最も単純な式」の単純さを測る基準自体がない＝**化学式と原子量の循環**（酸素8の表と16の表が併存）。突破口として気体の**体積比**（2:1→2、1:1→2、1:3→2）。
- 7-3　同体積同数を仮定すると酸素原子が足りない矛盾から、**単体気体が2原子分子**だと置いて解消。原子＝元素の種類を担う単位／分子＝独立に動く粒。原子量が揃えば「全元素を同じ物差しで並べられる」＝周期表の前提。

## 第8幕　電気が元素一覧を壊す
- 8-1　水溶液では分解できないのは水が先に反応するから。**熔融塩**電解で $\mathrm{2NaCl \rightarrow 2Na + Cl_2}$、$\mathrm{MgCl_2 \rightarrow Mg + Cl_2}$。**「電気が何をどう運んでいるかは分からない、事実だけ書いて仕組みは空欄にする」**と明言（10-3 で埋める）。元素概念は失敗ではなく、一覧が**使用可能な分解法に依存して暫定的**だった。デービー1807年。
- 8-2　見た目でなく**反応の型**で家族を判定する。アルカリ金属の塩化物3式、ハロゲンの水素化物3式と置換反応から $\mathrm{Cl_2>Br_2>I_2}$、アルカリ土類の炭酸塩3式。**元素カード**（表＝原子量、裏＝酸化物・水素化物・塩化物・原子価・置換反応）が作られ、第9幕の教具になる。

## 第9幕　元素カードの繰り返し
- 9-1　カードを原子量順に並べ、Li〜F と Na〜Cl を2段に折り返した表で原子価1,2,3,4,3,2,1 の反復と $\mathrm{CH_4/SiH_4}$、$\mathrm{NH_3/PH_3}$、$\mathrm{H_2O/H_2S}$、$\mathrm{HF/HCl}$ の型の一致を見る。できる夫の**オクターブ則**（8個ごと・音階）を、3段目（K〜Cu）で潰す：水素化物が全部横棒、原子価が複数、**Fe/Co/Ni が1マスに押し込まれ順序すら決まらない**、銅がハロゲンの下に来る。「周期性は本物だが、周期の長さを常に8とした仮定が強すぎた」。
- 9-2　原子量は化学式から推定した相対値であり、未発見元素もありうる → **空欄**。Al 27／？／In 115 の列で、原子量70前後・密度5〜6・$\mathrm{E_2O_3}$・$\mathrm{ECl_3}$ と**外れたら表が吹き飛ぶ形で**予測（エカアルミニウム）。ガリウム（70、5.9）とゲルマニウム（$\mathrm{GeO_2}$、$\mathrm{GeCl_4}$）で答え合わせ。メンデレーエフ1869年。「今度こそ完成」に対し「どの元素とも反応しない気体をどこに置く？」で第10幕へ。

## 第10幕　原子量を越えて
- 10-1　**希ガス発見の方法論が本編の白眉**。これまでの発見手段は全部「反応」だったので、反応しない元素は原理的に見つからない。第一の手掛かり＝**密度**（空気由来窒素1.2572 g／化合物由来1.2508 g、差0.5%。ばらつきでなく系統差＝誤差でなく中身が違う）。マグネシウムで窒素を除いて残る空気の約1%＝**アルゴン**。第二の手掛かり＝**分光の輝線**（セシウム・ルビジウムの先例）。原子量を出すため反応の体積比が使えないので、**比熱比1.67＝単原子**で解決（第7幕の問題の別解）。原子量40はどの族にも入らないので**列そのものを新設**し、族には仲間が要ると考えて太陽由来のヘリウムを地上で確認。4と40の間に**再び空欄**を宣言し、反応でなく**沸点差＝液体空気の分留**でネオン・クリプトン・キセノンを同定（分留表）。**「第1幕では色で失敗したのに、最後は光で元素を見分けた」**＝量でなく位置が指紋、という自己言及で第1幕と結ぶ。のちにラドンが加わり、キセノンのフッ化物で「反応しない」→「反応しにくい」へ修正。
- 10-2　テルルとヨウ素、アルゴンとカリウムの逆転。モーズリーのX線から**原子番号 $Z$**（核電荷＝陽子数）へ。
- 10-3　同位体（Cl 35/37、原子量35.45は存在比平均）。元素の定義を $\boxed{\text{原子番号が同じ原子の種類}}$ へ更新。周期性の主因＝外側の電子配置。**8-1 で空欄にした熔融塩電解の仕組みを、$\mathrm{Na^+ + e^- \rightarrow Na}$／$\mathrm{2Cl^- \rightarrow Cl_2 + 2e^-}$ として明示的に埋める**。アルカリ金属・ハロゲン・希ガスの性質を電子配置で説明。

## 終幕　1枚の表に圧縮された反応
- 物質系譜帳を最初から読み返し、各幕の到達点を反応式で並べ直す（$\mathrm{Fe+S}$／$\mathrm{CaCO_3+HCl}$／$\mathrm{Zn+HCl}$／$\mathrm{2H_2+O_2}$／$\mathrm{2Cu+O_2}$／$\mathrm{CuO+H_2}$／$\mathrm{2H_2O\rightleftharpoons}$／$\mathrm{H_2+Cl_2}$／$\mathrm{N_2+3H_2}$／$\mathrm{2NaCl}$／$\mathrm{Cl_2+2KBr}$）。周期表＝何千何万の反応結果を原子番号と電子配置で1枚に圧縮したもの。
- **鉛→金の決算**：化学反応で組み替わるのは外側の電子だけで核は手つかず、鉛82・金79で陽子3個の差、炉にも坩堝にも王水にも陽子を減らす操作はない。核反応でなら可能だが費用が桁違い＝**錬金術は間違いというより使える道具の外側にあった**。落ちは看板の裏返し「**金は作れません**」（10幕を6文字に圧縮）＋「ただし、お手持ちの金が本物かどうかは調べます」で、**第2幕の物質札（金は強水に溶けない）がそのまま値段表になる**。

## 依存
- **「色は物質の本名ではない」**（1-1）は 8-2 の「銀白色の金属を同じ家族にできない」で再演され、10-1 の「色で失敗したのに光で見分けた」で明示的に回収される。第1幕の色の失敗を弱めると終幕直前のこの対比が効かなくなる。
- **反証可能性の基準**（1-2 で系譜帳に判定欄として導入）が 4-1 の負の質量批判と 6-2 の「原子仮説はフロギストンと違う」の両方の根拠。3箇所セット。
- **仮の札（可燃空気／助燃空気／固定空気）**は 3-1 で導入し、4-2 で酸素・炭酸ガス、5-1 で水素として卒業する。名前を与える順序が「性質が分かってから命名する」という本編の作法そのものなので、順序を入れ替えない。
- **金属を焼くと重くなる**は 3-2 で反例として置かれ、4-1 でフロギストンを殺し、4-2 で酸素説の勝因になる。3段構え。
- **8-1 の「仕組みは空欄にする」**は 10-3 で電子の受け渡しとして明示的に埋められる。やらない夫が「第8幕で空欄にすると言ったな」と名指しするので、8-1 の空欄宣言を削ると 10-3 の締めが宙に浮く。
- **空欄を宣言して予測する**という手口は 9-2（エカアルミニウム→ガリウム）と 10-1（ヘリウムとアルゴンの間→ネオン）で2回使われ、10-1 側が「第9幕でやったことをもう一度やる」と自己参照している。
- **原子量が決まらない問題**（7-2 の循環）は 7-3 で反応体積比により解決されるが、10-1 の希ガスでは反応が使えないため**比熱比**という別解が必要になる。7-3 の解法が万能でないことを 10-1 が示す構造。
- **できる夫の速すぎる一般化**は 7-1（1文字記号）と 9-1（オクターブ則）の2回で、いずれも「元素は今後も増える」という同じ理由で破れる。9-1 の「音階が和音になってしまいました」は 7-1 の敗北と対になる落ち。
- 数値の連動：6-2 の3組（12.0/28.0/44.0、25.4/28.6/31.8、16.0/32.0/40.0）は引き算した酸素量の比が 1:2、1:2、2:3 になるよう組まれている。3-2 の 100 g→約56 g＋約44 g、10-1 の 1.2572/1.2508 g（差0.5%）と比熱比1.67、9-2 の Al 27／In 115 → 予測70前後・密度5〜6 と実測 Ga 70・5.9 も、いずれも本文中で計算されるのでどれか一つを変えると台詞の数字も直す。
- 9-1 の3段の表と 10-1 の分留表は、本文の議論がそのまま表の欄を参照している（水素化物の行が全部横棒、Fe/Co/Ni が1マス、銅が7列目）。表を編集すると直後のやる夫の指摘も直す。
- 物質札（胆礬・生石灰・苛性アルカリ液・礬油・強水・金属灰）は第1〜4幕に分散して置かれ、**終幕で「値段表になる」として一括回収**される。特に強水の「金を溶かさない＝分金」は終幕の商売の落ちに直結。
