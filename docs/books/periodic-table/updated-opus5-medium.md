`review-opus-medium.md` の6つの改善案に沿ってリライトした。物質系譜帳・物質札・希ガス発見・看板のオチという既存の強みには手を入れず、指摘された「宣言で済ませている箇所」を読者が手を動かせる形に置き換えた。

## 主な変更

- **6-2に実測からの計算を入れた。** できる子が密閉天秤箱の記録を読み、やる夫が引き算で結びついた酸素を出す形にした。炭12.0 gから炭酸ガス44.0 g／炭の軽い気体28.0 g（酸素32.0 gと16.0 g、1対2）、銅25.4 gから赤い灰28.6 g／黒い灰31.8 g（3.2 gと6.4 g、1対2）、硫黄16.0 gから32.0 g／40.0 g（16.0 gと24.0 g、2対3）。比較表も「宣言の一覧」から「固定した元素の質量・生成物質量・差し引いた酸素・比」の集計表に組み替え、直後の「1.37倍や2.48倍ではない」という違和感が計算の結果として効くようにした。
- **9-1に元素カードの表を出した。** Li〜FとNa〜Clを折り返して2段に並べ、原子量・原子価・水素化物・酸化物を行に取った。周期性を文章ではなく「縦に目を落とすと見える」形にした。破綻も同じ表の3段目（K, Ca, Ti, Cr, Mn, Fe/Co/Ni, Cu）として見せ、水素化物の行が全部横棒になること、鉄・コバルト・ニッケルが1マスに押し込まれること、銅がフッ素・塩素の列に来てしまうことを表の上の事故として示した。
- **9-2の空欄を表の空きマスにした。** Al（27, 2.7）とIn（115, 7.3）に挟まれた「？」の行を出し、やる夫が上下の中間から原子量70前後・密度5〜6を自分で見積もる流れにした。予測の主体を生徒側へ戻し、「発見前に予測する」という決意と実際の行動を一致させた。ガリウムの回収も、原子量70・密度5.9という数値の照合にした。
- **8-1のイオン・電子表記を10-3へ移した。** 8-1は当時の観察（熔けた食塩に電流を通すと片方の極に銀白色の金属、他方に黄緑色の気体）に置き換え、やる夫が「分解できた事実と仕組みの説明は別物だから、仕組みは空欄にしておく」と明示する。10-3で電子を導入した直後に「第8幕の空欄を今なら埋められる」として$\mathrm{Na^+ + e^- \rightarrow Na}$以下を回収した。物質札を当時の語彙で通す一貫性が保たれ、薄かった10-3が厚くなる。
- **できる夫の役割を「早すぎる一般化」に統一した。** 7-1ではラテン名の頭文字案に「1文字ずつで全部さばけます！！」を足し、塩素のCで破綻させる。二文字表記の考案はやる夫に移した。9-1のオクターブ則はそのまま軸として残し、破綻後に一言だけ落とす反応を追加した。9-2のエカアルミニウム予測はやる夫の発言へ移し、できる夫は「数字まで書いたら外れたとき表ごと吹き飛ぶ」と怯む側に回した。人物紹介の説明文も、この役に合わせて書き直した。
- **5-1でやる夫に1回粘らせた。** 水の電気分解の直後に「水に溶けていた空気が追い出されただけではないか」と食い下がらせ、(1) 燃えも燃やしもしない残りかすの気体が出ない、(2) 溶存量に限りがあるのに気体が出続ける、(3) 煮沸脱気した水でも同じ体積比、の3段で自分で棄却させた。フロギストン以外にも抵抗の場面ができた。
- **2-1の混合物の例を4つから3つに減らした。** 水と酒精の蒸留を落とした（分離手段としての蒸留は直後のやる夫の発言に残っている）。

## 残した判断

- **3-1の気体3種は圧縮しなかった。** 可燃空気・助燃空気・固定空気の3札は第4幕のフロギストン、第5幕の水の合成と分解でそれぞれ独立に使われる。2種に減らすと後段の伏線が切れるため、改善案6のうち3-1側は採らなかった。
- できる夫の役を統一したことで、7-1の二文字表記という有用な提案は失われるが、これはやる夫が「1文字前提が崩れた理由」を自分で言語化してから出す形にしたので、教材としての情報は減っていない。
- 終幕の看板2行が `dialogue-period` の error になっていたため、看板の下にやる夫の短い一言を足して解消した（看板そのものの文言は変えていない）。lint は error 0件。
