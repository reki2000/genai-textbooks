# 寸評：やる夫の新党が霞が関を解体するようです ― 合理的な政府をゼロから作ったら、動かせなかった

約54KB／全8幕。党員1人の新党が「全省庁廃止」から出発し、統合・集権・分権・独立委員会をひととおり試して壊し、最後に「止めずに変える10原則」へ到達する行政組織論の教材。

## 良い点

**やる郎という生活者役が、抽象論を一撃で床に落とす。** 結党演説の直後に「母の年金が来月入るかだけ先に教えてください」（122行目）、7省案の直後に「どちらに申請すればいいですか」（275行目）、大都市独立案の直後に「私は、どこの市民として数えられるのでしょうか」（1100行目）。いずれも理屈で反論せず、自分の生活の具体を一つ置くだけで案が崩れる。教師役の説教にならずに反証が入る構造で、本書最大の発明。

**4-2 の「250倍」が、数字から概念を生んでいる。** 1,700市町村×3人の人件費（976–980行目）から、人口50万区と2,000人の町で住民1人あたり250倍（989–991行目）を計算させた後、やる夫自身が「金が無いから置けないんじゃない、置いてもその3人は経験を積めない」（1000–1002行目）へ跳ぶ。費用の話が能力形成の話へ転換する瞬間で、本書で最も密度の高い10行。

**5-2 で役割を反転させ、やる夫に審査させたのが効いている。** やらない夫が「23区を廃止して900万人の東京市ひとつ」案を出し、やる夫が赤ペンを入れる（1167–1173行目）。上へ寄せるべき業務を認めた上で不合格を出し（1176–1193行目）、直後に「やる夫の最初の案は、その真逆を同じ雑さでやってた」（1199–1201行目）と自分へ返る。他人の案を裁いて初めて自分の案の型が見えるという、教材として珍しい経路。

**6-2 でやる夫自身を独立統計委員長に任命する実演。** 幹事長の発表日ずらし依頼を断らせた直後、「来年度の予算は誰が決める」「後任は誰が任命する」（1329–1336行目）で独立が金と人事から成ることを示し、次に統計を勝手に壊させて「お前は選挙で選ばれていない」（1353行目）と逆側から挟む。6-1 で自分が発した「統合した大臣を誰が止める」（1267行目）がそのまま自分に返る（1360行目）構成は見事。

**「責任の赤いボール」が抽象概念を物理化している。** 862–889行目で大臣3人の間を転がり、6-2 で大臣と委員長の間を往復する形で再投入される（1391–1394行目）。同じ小道具を離れた幕で再使用し、独立性の設計が責任の消去ではないこと（1397行目）を絵で示している。

**着地が自分の身に降りかかる。** 旧党名ポスター1万枚に訂正シールを貼る作業を「最初の行政移行実験」と呼び（1829行目）、党員2人・期限は明朝・財源なしという条件を突きつける（1808–1826行目）。抽象論の教材が最後に実行能力の話へ落ちる終わり方は良い。

## 欠点

**会話が一問一答の梯子で、幕によって極端に単調。** 3-1 の 707–741行目は「病院を運営するのか／しないお」「検疫所を動かすのか／指示するお」「学校を休校するのか／指示するお」「空港便を／指示するお」「物資を／指示するお」「予算は／頼むお」と、同じ型が6連続する。755–777行目でも「職員も置くか／置くお」「地方組織も／置くお」「予算も／持たせるお」「法律の所管も／持たせるお」が4連続。1-2 の 174–207行目、2-3 の 566–600行目も同型。結論（783行目「巨大な新省庁だお」）は正しいが、読者は3往復目で着地が見えてしまう。

**失敗に代償がない。** 1-3 で「行政停止時計。年金支給予定日まで18日」（394–395行目）という優れた圧力装置を導入しておきながら、以後一度も参照されない。第7幕の支持率1.5%（1448行目）も次の幕へ何も引き継がない。やる夫は8幕にわたり案を壊され続けるが、失うものが最後のポスター代しかなく、物語的な負債が積み上がらない。

**数値が 4-2 にしかない。** 250倍の計算（989–991行目）が唯一の定量的思考で、他は「10,000件」（330行目、しかも実数でなく表示上限）と支持率だけ。省庁の職員数、予算規模、再編にかかった年数など、行政改革を論じる教材が扱うべき数字が本文に一つも出てこない。

**2001年の中央省庁再編という実例を、参考文献に置きながら本文で一度も使っていない。** [^3][^7]（1853行目、1861行目）に厚生省と労働省の統合、行政改革会議最終報告が挙がっているのに、2-3 の「厚生と労働は近いのか」（564–660行目）は完全に架空の議論として進む。日本が実際に統合し、その後20年で何が起きたかは、やる夫の仮説を検証する最良の材料だったはず。

**7-1 の移行コストが列挙で終わる。** できる子が権限者変更から国会常任委員会再編まで12項目（1466–1476行目）、さらに5項目（1482行目）を読み上げ、やる夫の反応は「多いお」（1479行目）の一言。4-2 で数字から概念を掘り当てた手法が、ここでは使われていない。項目を数えるだけで、重さが体感されない。

**8-3 の10原則が導出されずに読み上げられる。** 1673–1701行目で10項目が一息に並ぶが、どの原則がどの幕の失敗の対価なのかが本文で紐づかない。第7原則「失敗した場合に戻せる設計」に至っては、対応する失敗が本編に存在しない。8幕分の授業料の回収としては弱い。

**やる郎の母の年金が回収されない。** 1-3 で「停止する」（348行目）と宣告された後、8-4 の入党（1734–1750行目）まで母の件がどうなったかに触れられない。せっかく第1幕で最も鋭い問いを立てた人物なので、終盤で「母の認定はどうなりましたか」を一度返させるべき。

## 改善案

1. **行政停止時計を全幕の背骨にする。** 394–395行目で導入した「年金支給予定日まで18日」を、各幕の冒頭でできる子に一行読み上げさせる（第2幕15日、第3幕11日……）。第7幕（1405行目付近）で残り2日になったところで、やる夫が最終案の完全移行を諦め、給付系だけ現行組織に残す部分移行を選ぶ、という形にすれば、8-1 の「中間が見つからない」（1571行目）が観念でなく時間制約からの発見になる。

2. **移行コストを1件だけ実際に見積もらせる。** 1479行目の「多いお」を、やらない夫の「数えろ」に置き換える。例えば「難病助成の申請先変更」を1件取り、対象者数×再申請の手続時間×自治体数で総人時を出させ、4-2 と同じく数字から「移行費用は制度の受益者が払っている」という発見へ繋げる。手法は既に本書の中にある。

3. **8-3 の10原則に出所を書き込む。** 1673行目以降の各原則の直後に、やる夫の一行で対応する失敗を添える（第1原則→3-2 の赤いボール、第2原則→3-1 の司令塔が実施省庁化、第3原則→4-1 の全国共通窓口、第8原則→3-2 の恒久化、第9原則→6-2 の委員長体験）。現状の第7原則には対応する失敗が無いので、第2幕あたりに「人事シャッフルを1年で元に戻せなかった」場面を作るか、原則を削る。

4. **3-1 の梯子を別形式へ組み替える。** 707–741行目の6連続の一問一答を、できる子の「感染症対策室が単独で発出できる命令：0件」という一行の集計に置き換え、やる夫が「じゃあ権限を渡すお」から先だけ会話にする。同じ結論に半分の行数で着き、直後の 755–783行目の反転が立つ。

5. **2001年の省庁再編を本文へ入れる。** 2-3 の 634行目「厚生と労働は近いのか」の直前に、できる子が「2001年に統合済み。統合前は別省」という事実を置く。やる夫が「じゃあ既に解決してるお」と言い、やる郎の5回の窓口たらい回し（566–600行目）がその統合後に起きている事実に潰される、という往復にすれば、架空の設計論が現実の検証へ変わる。

6. **やる郎の母の件を終盤で回収する。** 8-4 の入党の場面（1734–1750行目）の前に、やる郎の一行として「母の介護認定は、結局2か月遅れて出ました」を置く。入党の動機（1748行目「止めずに変えると言った政党は少ない」）が、抽象的な共感でなく実体験の裏づけを得る。

7. **できる夫に発表以外の芸を1つ足す。** 現状は 1433–1448行目、1666–1670行目、1758–1760行目、1785–1793行目のすべてが「勝手に先走って数字を誇張する」同一パターン。第6幕あたりで一度、独立委員会案を「政治から自由になる」と誤って賛美させ、6-2 の両側からの挟み撃ちの前振りにすると、キャラクターが論点の運搬にも使える。
