# 改訂メモ（sol56-medium）

`review-opus-medium.md` の具体的な改善案に沿って、本文を次のように改訂した。

- 第1幕で始まる「行政停止時計」を第2幕15日、第3幕11日、第4幕8日、第5幕6日、第6幕4日、第7幕2日、第8幕1日、終幕0日まで通した。残り2日で一括移行を断念し、年金・介護・難病助成などを現行組織へ残す部分移行を選ばせ、時間制約から「止めずに変える」経路を発見させた。
- 第2幕の人事シャッフルを1年間仮想実行し、組織図を戻しても退職者・継続案件・チーム経験は復元できないと示した。これを第7原則「戻せる設計」の作中根拠にした。
- 厚生省と労働省が2001年に厚生労働省へ統合された事実を第2幕へ入れた。統合後もやる郎が五つの担当へ説明する状況を対置し、組織統合とサービス統合を区別した。
- 第3幕の反復的な一問一答を、できる子の「感染症対策室が単独で発出できる命令は0件」という集計へ圧縮した。その後は、権限だけでなく実施職員・地方組織・予算・法律所管まで持たせると新省庁になる、という反転に集中させた。
- 第7幕では難病助成の再申請を例に、仮定を明示して $50 \times 0.75 \times 1{,}700 = 63{,}750$ 人時（約7,969人日）を計算した。省庁再編の移行費用を、本人・家族・自治体窓口が負担する時間として可視化した。
- 第8幕の10原則すべてに、どの幕の失敗から得たかを会話で付記した。長い読み上げにならないよう、やらない夫の確認と費用面の反問を挟んだ。
- やる郎の母について、支給日当日に年金が入ったことと、以前の介護認定が2か月遅れたことを回収し、入党理由を生活上の経験へ結びつけた。
- できる夫には、独立委員会案を「政治から完全に自由」と早合点して発表しようとする役割を追加した。既存教材に見られる、理解と行動は速いが前提を飛ばして話を大きくする人物像へ合わせた。
- できる子は、時刻・件数・試算条件・制度上の事実を短く提示する話し方に統一した。既存の話者外にあった二つの文は、やる夫の発言として明示し、ト書きは追加していない。
