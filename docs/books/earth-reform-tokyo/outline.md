# やる夫は東京を広くしたい ── 世界地図と固体地球物理学を再発見する の骨格

実家を出る無職のやる夫が、駅前の不動産屋で18m²・9万2000円の部屋に負け、「東京が狭いのが悪い、陸3海7の地球を陸7海3にすればいい」と言い出す。不動産屋の窓口に積んである**地球改造申込書**（(1)欲しい地形 (2)材料をどこから持ってくるか (3)余った岩石と水をどこへやるか (4)100万年後も維持できるか (5)1億年後も維持できるか）の欄で毎回詰まり、そのたびに陸高海深曲線、アイソスタシー、部分融解、大陸移動説、和達―ベニオフ帯、海洋底拡大と磁気縞、プレートとオイラー極、スラブプル、大陸衝突、隆起と侵食、堆積空間、海岸線のフラクタル次元へ手を伸ばす。火曜14時40分から金曜の内見までの四日間。

人物：やる夫（無職、部屋探し中。掛け算が世界と合うとすぐ「新規事業だお」と舞い上がる）／やらない夫（不動産屋。地盤と災害リスクの説明を続けるうちに地質に詳しくなった。問いで返し、仮定を疑わせる）／できる子（同じ店の事務員。地図・断面図・観測データ担当。丁寧体で数字と「見積もりに幅がある」を置く）。地球改造申込書も登場人物として扱う。

## 第1幕　東京が狭すぎる
- 1-1　18m²・築35年・徒歩12分・9万2000円、欲しいのは24m²・新しい・駅近・7万円＝全員が欲しい条件、土地の量が変わらなければ値段で調整される。東京湾を埋める→房総半島を伸ばす→日本を大きくする→海が71%なのがおかしい、陸7海3にするには2.08億km²＝日本550枚。「それを、どこの何で作る？」でできる子が申込書を出す。1番は「平らな陸地」、2番から動かない。
- 1-2　最終氷期最盛期に海面120〜130m低下で露出した大陸棚は2000万km²の桁＝陸29%→33%の4ポイント、「単純に9倍で1080m」は勾配一定の仮定。全球の高度分布は海面のすぐ上と水深4000m台の二つのこぶ＝陸高海深曲線（hypsographic curve）、1080mはこぶの谷間を掘っただけ。海水13.4億km³（掛け算が一致）、4000m下げるには9割を捨てる→宇宙へ捨てると雨も川も止まり、平らな土地を作る工事が全部止まる（第7幕まで覚えておく）。水を全部抜いても床は二種類の高さのまま＝なぜ床が二種類あり、高い床をどこで手に入れるか（2番の欄）。

## 第2幕　大陸はなぜ海に沈まない
- 2-1　海底をジャッキで4000m上げる→隙間がない。地殻の代表値（海洋7km・2.9、大陸35km・2.8、マントル3.3、海水1.03）。密度3%差と厚さ5倍のどちらが効くか→氷山のアルキメデスで、基準面35kmで重さを等しくする柱の計算：水なしで $H=4.45$ km（現実の約4.5kmと一致、「不動産屋の机で地球が解けた、新規事業だお」）→水を入れると6.48km で2km外す→厚さ30km・密度2.85でいじって合わせても何も分かっていない、筋書き（厚さと密度のつり合い）は桁で合う、地殻の下を全部3.3で塗ったのがずれの原因（海の下は冷たく重い、5-1で回収）＝アイソスタシー、高い大陸ほど深い根。大陸地殻を足すと地表は係数0.15で上がる（1km上げるのに6.6km、6-1・6-2で再利用）。2.08億km²に30km敷くと62億km³＝現在の大陸地殻総量約70億km³をもう一個作る注文。
- 2-2　軽い岩の在庫を探す案→SiO₂はかんらん岩45%・玄武岩50%・安山岩60%・花崗岩70%、一回の工程で5ポイントしか動かない。海水を凍らせると氷の塩分は薄くなる＝部分融解と分別結晶作用を繰り返す工場のライン。水が融点を数百度下げる→水を深部へ運ぶ沈み込み帯で島弧・大陸弧のマグマ＝現在の主な大陸地殻の生産。今のやり方を40億年前に貼り付けない（初期地球のモデルは競合、含水量と酸化状態が現代の島弧に似るという研究もあるが未決着）。生産は年数km³で62億km³に20億年、100万年後の欄は「まだ0.05%」。大陸には40億年近い岩があるのに海底だけ妙に若い（4-2で回収）。

## 第3幕　大陸が動くなんて誰も信じなかった
- 3-1　水曜10時15分、南米とアフリカの形が合う→似ていない組み合わせもたくさんある、形は気づきで証拠でない、海を渡れないものの一致が要る。ウェゲナー（1912年提示、1915年『大陸と海洋の起源』）の化石・地層と山脈・低緯度の氷河痕跡。嘲笑された理由は2番の欄＝駆動機構：力の桁が足りない、固定した海底を大陸が押し分けると押す側（同じ岩）が先に潰れる＝房総半島を東に押す案と同じ病気。決定打は面積の7割（海）から。
- 3-2　和達清夫（1927年）の深さ数百kmの地震、学習用の震源断面表（50km→30km…600km→300km）で斜めに並び、区間ごとの傾き14°→22°→27°→33°と奥ほど急。熱い岩は流れるのに地震＝そこだけ冷たい＝地表の冷たい板が斜めに刺さっている。年8cm台で500万年、$\sqrt{\kappa t}$ で両側13kmしか温まらず100kmの板の中央70kmは冷たいまま＝和達―ベニオフ帯、スラブ。表面が消える場所があるなら生まれる場所がある。

## 第4幕　海底が生まれて消えている
- 4-1　戦後の音響測深、マリー・サープが大西洋中央の高まりに連続した裂け目状の谷を見いだし、震源も並ぶ。床が増える一方なら地球膨張説→2億年より古い海洋底がほとんどないので2億年前の半径0.63倍・重力2.5倍、恐竜が走れない。海嶺で作り海溝で捨てる＝ヘス（1962年）の海洋底拡大説、大陸は動く床に載って運ばれ押す側が潰れる問題が消える。だがつじつまが合うだけでは膨張説と同じ、まだ測っていないことを言い当てないと勝てない（ヘス自身「地球の詩」）。
- 4-2　海嶺に平行で左右対称の磁気縞＝熱残留磁化と地磁気逆転。予言：縞の幅を逆転年代で割ればどの縞も同じ速さ→16/0.78・52/2.58・72/3.6で20.5・20.2・20.0 km/百万年（片側年2cm）＝ヴァイン＝マシューズ＝モーリー仮説（1963年、モーリーの投稿は不掲載）。年2cmで南米沿岸2900kmまで1.45億年、南大西洋の開き始め約1.3億年と1割のずれは速さ一定の決めつけで、桁が合うことが大事。2-2の疑問の回答＝海底は消耗品で2億年で張り替わる、大陸が古いのは軽くて沈み込めないから。「東京の下の床も張り替えられる」。
- 4-3　南米大陸と東の大西洋の海底は一緒に動く＝動く単位の境目は変形する場所（地震と火山の細い帯）で、囲まれた内側は硬い板＝プレートテクトニクス、大陸も海底も板の上の模様。球面上で距離を変えない動きは回転だけ（オイラーの定理、オイラー極）、$v=\omega R\sin\theta$ で0.7°/百万年なら90°で年7.8cm・30°で3.9cm、磁気縞の拡大速度が $\sin\theta$ に乗るかで検査＝マッケンジーとパーカー（1967年、北太平洋）、モーガンも独立に。ウェゲナーから55年、正しさが認められたのでなく主役が大陸からプレートへ入れ替わり問いの立て方が変わった。

## 第5幕　プレートは誰に押されているのか
- 5-1　マントル対流＝鍋の味噌汁なら速さは似るはず→太平洋年8cm台、大陸を含む板は年1〜3cmで5倍以上違う。速い板は縁の多くが海溝＝押されているのでなく沈んだ縁に引きずられる。冷えて縮む：$3\times10^{-5}\times600=1.8\%$、1m³あたり60kgは軽いが、厚さ100km・深さ600kmの板で海溝1mあたり約3.5×10¹³ N＝スラブプル（リッジプッシュより大きい寄与とされる）。検算に海底は $\sqrt{t}$ で深くなる $d=2500+350\sqrt{t}$、2500万年で4250m＝1-2の低いこぶの正体、2-1で2km外したのも冷えて重い上部を3.3で塗ったため。ただしマントル対流が無関係なのでなく、沈み込みが流れを駆動する循環で細部は議論中。「プレートを東京へ集めるお」。

## 第6幕　土地を増やしたら山になった
- 6-1　木曜11時、大陸を日本へ押しつけて面積を足す→紙を両側から押すと縮んで盛り上がる。インド–ユーラシア衝突（4000万〜5000万年前から）、年5cm×5000万年で2500km近づいたのにヒマラヤ・チベットの幅は1500km、一部は東方へ押し出され内陸深くまで変形。35kmが半分に縮み70kmなら2-1の係数で5.3km＝チベット高原4500〜5000m・地殻70〜80kmと一致（2-1の道具が生きていた）。面積は200万km²減って高さ5kmを買った、5000mで約540〜560hPa、玄関で高山病。衝突が何度も起きたのになぜ関東平野のような平らな場所があるのか。
- 6-2　アパラチア（古い造山帯、最高峰2000mそこそこ）。$dh/dt=U-kh$、$U$=年1mmで定常5km・時定数500万年＝高さは止まって見えても岩は流れている、地形は物体でなく流れの模様。$U=0$ でアパラチアを計算すると $e^{-60}\approx10^{-26}$ で26桁外れる→削ると柱が軽くなって浮き上がる（2-1）、正味0.15Δしか下がらず1m下げるのに6.6m削る、時定数3300万年で60cm、まだ4桁不足。疑うのは $U=0$ の決めつけ（新生代の再隆起の議論、未決着）と $E=kh$（削る力は高低差で決まる）。腕相撲の絵では足りない。削れば削るほど下から浮き上がる。

## 第7幕　削った山で東京ができる
- 7-1　削った岩は砕いても質量は減らない（1幕の水と同じ保存則）→山の出口で扇状地、洪水で氾濫原、河口で三角州、海底斜面を沖へ＝山地は土砂の生産地、川は輸送路、平野と海底は堆積地の一本の線。ブラマプトラの網状流路、ガンジス・ブラマプトラの三角州とバングラデシュの若い堆積物。年約10億t＝0.38km³、ベンガル海底扇状地約1250万km³は箱で近似したヒマラヤ300万km³の4倍＝見えている山は削り残し（6-2の6.6とは一致とは言えないが向きは合う）。1250万÷0.38で3300万年は衝突年代と頭の数字まで近い（速さ一定と空隙の雑さはどちらも短くする向き）＝独立な検算。
- 7-2　砂を机に撒いても厚い平野にならない＝受け皿＝堆積空間（accommodation space）、地面が沈むか水面が上がる。東京低地の地下には最終氷期の低海面期に刻まれた古東京川の谷が埋もれている（1-2の120〜130m）、東京都区部で5万本超のボーリング資料＝縦の線から横のつながりを推理する。下位の砂礫と三角州、縄文海進期の内湾の泥、その上の高海面期以後の堆積物。海面上昇は年12mm、谷の埋積は年6mm＝1万年の「ついさっき」。同じ標高・駅距離でも成り立ちで揺れやすさと水の集まり方が違う＝土地は履歴まで含めて物件情報。東京湾を長方形に埋めて碁盤の目に→4番の欄。

## 第8幕　海岸線を定規で引いてはいけない
- 8-1　海岸線の長さを測って長方形に直す設計→イギリスの海岸は物差し100kmで約2800km・50kmで約3400km、短くするほど伸びて止まらない＝長さは測り方つきでしか数字にならない。$2^x=1.214$ から $x=0.28$、フラクタル次元1.28（一般に1.25程度）。位置も潮・波・川・沿岸流・隆起沈降・海面で動く＝ $dV/dt=Q_{\mathrm{in}}-Q_{\mathrm{out}}$、ダムで供給を止めると海岸が痩せる＝海岸線は固定線でなく物質の流れが出会う前線。三角州・リアス海岸・フィヨルド・砂州・海成段丘は成立条件の組み合わせの違い。定規で引いた線は引いた瞬間から間違い。
- 8-2　地球2号（初期大陸配置だけ違う）を10億年待つと日本列島はできるか→固有名詞は偶然、地形の種類（海嶺・海溝・火山列・衝突山脈・谷・河川網・扇状地・三角州・氷河地形・海岸）は物理法則からかなり必然、ただし「プレートが動くなら」という条件つき。金星はプレート構造が確認されず、火星のオリンポス山は20km超＝板が動かないと一箇所に積み上がる、地球では火山が列に散る＝板が動くかで地形の文法が変わる。海7陸3は必然でない（水・大陸地殻量・床の高さ・プレート史の組み合わせ）、だが二つのこぶ＝大陸と海への二分は必然に近い。「地形の文法は物理法則が決め、その文法で書かれる文章は地球史が決める」。

## 第9幕　地図は完成図ではない
- 9-1　金曜11時05分、申込書を返却され全欄を書き直す：2番は62億km³を10億〜100億年（できる子「数字を一つに固めて書かないで」、幅のまま書けるなら審査は通る）、3番は海水の行き先が書けず、削った岩は捨てられず下流で平野になる＝1番で欲しいものは3番の捨て場＝欄を分けたこと自体が間違い。4番は年5cmで100万年に50kmずれ長方形の角は丸くなる、5番は1億年で5000km、海洋底は半分入れ替わる。一番難しいのは広げることでなく形を固定すること＝地表に「完成」がない。世界地図は完成品でなく、ある瞬間のスナップショット。
- 9-2　駅徒歩16分・築28年・24m²・7万9000円（m²単価5111円→3292円で6割）。川が近い低地と分かると、地形分類図・旧河道・地質図・ボーリング資料・ハザードマップを求める。24m²の履歴は46億年近い、成り立ちの無い土地はなく知らずに住むか知って住むかの違い＝それでも借りる。やらない夫「それが聞けるなら、資料は全部出す」、内見13時。床を厚くして東京湾を埋める案は捨てていない→できる子「材料はどこから」、やらない夫「申込書、2番だ」、「埋まったら持ってこい。そのときは、俺も一緒に考える」。

## 依存
- 地球改造申込書の5欄：1-1で導入 → 1-2で3番（水の行き先） → 2-1・2-2で2番（材料と生産速度）、4番「まだ0.05%」 → 3-1 ウェゲナーも2番（機構）で詰まる → 6-2の末で3番（削った岩） → 7-2の末で4番 → 9-1で全欄を書き直し欄の分割自体を否定 → 9-2の最後に2番で刺される。
- 陸高海深曲線の二つのこぶ（1-2）：2-1 アイソスタシーで高低差 → 5-1 $\sqrt{t}$ 沈降で低いこぶが4250m → 8-2 二分は必然に近い。
- 2-1の柱の計算と係数0.15（6.6倍）：2-1 で4.45/6.48kmのずれ → 5-1 冷えて重い海洋側で説明 → 6-1 チベットの5.3km → 6-2 削っても6.6分の1しか下がらない → 7-1 見えている山は削り残し。数値（密度・厚さ）を変えたら全所を直す。
- 2-2「海底だけ妙に若い」→ 4-1 2億年より古い海洋底がない → 4-2 海底は消耗品と回答 → 9-1 1億年で半分入れ替わる。
- $\sqrt{\kappa t}$：3-2 スラブが冷たいまま届く → 5-1 海底の $\sqrt{t}$ 沈降。
- 押す側が先に潰れる（3-1、房総半島案と同じ病気）→ 4-1 床ごと動けば消える → 6-1 大陸衝突で実際に押したら山になった。
- 1-2の水を捨てると平らな土地を作る工事が止まる → 7-1 削った岩は下流で平野になる → 9-1「1番で欲しいものは3番の捨て場」。
- 最終氷期の海面120〜130m低下：1-2 露出面積 → 7-2 古東京川の谷と埋積速度。
- 「予言で勝つ」：4-1 つじつまが合うだけでは膨張説と同じ → 4-2 磁気縞の20.5/20.2/20.0 → 4-3 $\sin\theta$ の検査 → 7-1 扇状地体積と衝突年代の独立な検算。
- 数値を合わせていじることの戒め（2-1）と、ずれを仮定の側で疑う（4-2の1割、6-2の26桁→4桁、7-1の4倍と6.6）は同じ態度の反復。
- 家探し：1-1 18m²・9万2000円 → 7-2 土地は履歴まで含めて物件情報 → 9-2 24m²・7万9000円で地形資料を求めて借りる。
