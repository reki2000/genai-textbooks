# やる夫が最後の園バスを走らせるようです ── 30年後の町と少子高齢化

---
## 登場人物

**やる夫** ── 朝凪町で園児12人の私立保育園を営む園主。今年から交通協同組合の路線委員長。

**やらない夫** ── 朝凪町の訪問看護師。町の共同交通を20年運行してきた。

**たんぽぽ号** ── 保育園と協同組合が共同所有する黄色いバス。座席7、停留所12、年間運行費900万円。

**朝凪町の年齢帯** ── 同じ時期に生まれた集団であるコホート（cohort）を5歳刻みで並べ、磁石で先へ動かす掲示板。

### 1-1　900万円を三人で割る ── 一人当たり費用

〜〜 月曜7時25分　たんぽぽ号の車内 〜〜

**やる夫**：
三人だお。
七席あるのに三人しか乗ってないお。
残り四席は空気を運んでるお！

**やらない夫**：
朝からよく数えるな。

**やる夫**：
数えたついでに割ったお。
年間運行費900万円、園児3人。

$$900万円 \div 3人 = 300万円/人$$

**やる夫**：
一人300万円だお！！
やる夫の園、園児一人の年間保育料が42万円だお。
バス代がその7倍だお！

**やらない夫**：
それで？

**やる夫**：
廃止だお。
900万円を園の献立に回せば、毎日ステーキだお。
朝凪町でいちばん豪華な保育園として全国から園児が集まって、大儲けだお！！

**やらない夫**：
バスを消したのに園児が集まるのか。

**やる夫**：
……。

**やらない夫**：
今日の三人、どうやって来た。

**やる夫**：
バスだお。

**やらない夫**：
明日は。

**やる夫**：
歩き……は無理だお。
一人目は峠側で、園まで8 kmだお。

**やらない夫**：
残りは。

**やる夫**：
二人目の家には車が1台ある。
でも保護者が通勤で使ってるお。
三人目は海側で、雪の日は徒歩の道が閉じるお。

**やらない夫**：
廃止した翌日、その三人はどうなる。

**やる夫**：
一人目はタクシー。
二人目は保護者が送る。
三人目は雪の日だけ休む。
……ほら、全部片付いたお。

**やらない夫**：
片付いた分の値段を書け。

**やる夫**：
タクシー補助が年120万円。
送りは往復70分、年240日で……280時間。
三人目は欠席日数と、保護者が休む日数が天候次第で──

**やる夫**：
280時間は0円じゃないお。

**やらない夫**：
ほう。

**やる夫**：
現金は出てないお。
でも保護者の仕事の時間か、休む時間か、下の子と過ごす時間から出てるお。
やる夫は900万円を消したんじゃなくて、家庭と別の助成と欠席へ**引っ越させた**だけだお。

**やらない夫**：
それを費用転嫁（cost shifting）という。
協同組合の帳簿からは消えたが、町からは消えていない。

**やる夫**：
帳簿の外に置けば節約になるお。
やる夫は会計の天才だお。

**やらない夫**：
その天才の帳簿では、園児が来られなくても支出はゼロだ。

**やる夫**：
……ぐぬぬ。

**やらない夫**：
もう一つ聞く。
一人当たり300万円の、その「一人」は誰だ。

**やる夫**：
朝乗る園児3人だお。

**やらない夫**：
朝と帰りで6回乗る。

**やる夫**：
なら6で割るお。
900割る6で150万円だお。
半分になったお！
やる夫は費用を半分にする魔法を──

**やらない夫**：
今、園児は何人になった。

**やる夫**：
3人だお。

**やらない夫**：
6で割ったな。

**やる夫**：
……あっ。
やる夫は同じ子を、朝の子と帰りの子で二人に数えたお。
人は往復しても一人だお。

**やらない夫**：
分母を変えれば数字は動く。
だが動いたのは数字だけだ。

**やる夫**：
じゃあ一人当たり費用は使えないのかお。

**やらない夫**：
使えないなら、俺は20年間なにを見て走らせてきたことになる。

**やる夫**：
……使えるお。
同じ種類のサービス同士を比べる入口にはなるお。
ただし割る前に、分母が実人数なのか乗車回数なのか、分子に代替手段の費用が入っているかを書くお。
書かずに割った300万円は、ただの大きい数字だお。

**やらない夫**：
一つ書き足せ。
その300万円で、誰が何をできている。

**やる夫**：
峠側の子が園に来られてる。
車が1台の家で、保護者が仕事を続けられてる。
雪の日に休まずに済んでる。
……値段の隣に、買えているものを書かないと、高いか安いか決められないお。

考え直したお。

誰と誰の多数決だ。

**やる夫**：
5人と3人だお。

**やらない夫**：
その5人は、朝は何をしている。

**やる夫**：
……朝は乗ってないお。

**やらない夫**：

**やる夫**：

**やる夫**：
昼便で走ってるお。

**やらない夫**：

25分遅れる。

**やる夫**：

**やらない夫**：
四つ挙げろ。

**やる夫**：
一つ、昼便を中止して園へ戻る。
二つ、迎えをタクシー補助にする。
三つ、昼便の経路の途中に園を組み込む。

**やらない夫**：
値段と時間を付けろ。

**やる夫**：
中止は5人の予約が全部変更だお。
タクシーは片道8,000円、チャイルドシート付きは到着まで40分だお。
経路を変えると、海側の一人が15分、他の二人が8分遅れるお。
予備の車は、走らない日も固定費（fixed cost）がかかるお。

**やらない夫**：
今日の条件なら三つ目だ。
だが毎回それでいいか。

**やる夫**：
週3回こういうことが起きたら、昼便はいつも遅れるお。
例外の処理をいつも使ったら、それはもう例外じゃないお。
遅れることを前提にした路線を、時刻表では定時のふりをしてるお。

**やらない夫**：
だったら何を測る。

**やる夫**：
急な変更の回数。
影響が出た人数。
その人が我慢できる遅れの幅。
代替手段が着くまでの時間だお。
回数が一定を超えたら、予備の車を契約する条件にするお。

**やらない夫**：
そのために運行表へ何を入れる。

**やる夫**：
……空き時間だお。
毎日きっちり詰めたら、突発を受ける場所がないお。

**やらない夫**：
空席は無駄だと言っていたのは誰だ。

**やる夫**：
やる夫だお。
朝に四席空いてるのは無駄だと言ったお。
でも満席だったら、発熱した子と付き添いを途中から乗せられないお。

**やらない夫**：
一つ問題がある。

**やる夫**：

## 第2幕　出生率が上がっても赤ちゃんは減る

---
### 2-1　1.45から1.60へ ── 率と人数

〜〜 同日18時　協同組合の会議室 〜〜

**やらない夫**：
朝凪町の数字を置く。
20歳から44歳の女性人口を5歳刻みにした。
右の列は、その年齢の人が1年に産む子どもの平均件数だ。

| 年齢 | 人数 | 一人あたり年間件数 |
|---|---:|---:|
| 20〜24 | 25人 | 0.03 |
| 25〜29 | 28人 | 0.08 |
| 30〜34 | 32人 | 0.10 |
| 35〜39 | 30人 | 0.06 |
| 40〜44 | 27人 | 0.02 |

**やる夫**：
簡単だお。
この率を10%上げれば、来年の赤ちゃんも10%増えるお。
たんぽぽ号は満席だお。

**やらない夫**：
まず今年を計算しろ。

**やる夫**：
掛けて足すだけだお。
$25 \times 0.03 = 0.75$。
$28 \times 0.08 = 2.24$。
$32 \times 0.10 = 3.20$。
$30 \times 0.06 = 1.80$。
$27 \times 0.02 = 0.54$。

**やる夫**：
合計$0.75+2.24+3.20+1.80+0.54=8.53$人だお。
0.53人ってどこにいるんだお。

**やらない夫**：
平均だ。
実際に生まれるのは整数だが、年ごとにばらつく期待値として8.53と置く。

**やる夫**：
率のほうも合計してみるお。
$0.03+0.08+0.10+0.06+0.02=0.29$。

**やらない夫**：
5歳刻みだから幅5を掛けろ。

$$TFR = 5 \times 0.29 = 1.45$$

**やらない夫**：
これが合計特殊出生率（total fertility rate, TFR）だ。
各年齢の率は年齢別出生率（age-specific fertility rate）という。

**やる夫**：
1.45は聞いたことがあるお。
ニュースで言ってるやつだお。

**やらない夫**：
では次の年だ。
すべての年齢別出生率が10%上がった。
ただし人数はこう変わった。

| 年齢 | 人数 |
|---|---:|
| 20〜24 | 20人 |
| 25〜29 | 23人 |
| 30〜34 | 26人 |
| 35〜39 | 25人 |
| 40〜44 | 23人 |

**やる夫**：
率が10%上がったんだから、まずTFRだお。
新しい率は0.033、0.088、0.110、0.066、0.022。
合計0.319。

$$TFR = 5 \times 0.319 = 1.595$$

**やる夫**：
1.60だお！
1.45から1.60へ上がったお！
朝凪町は少子化を克服したお！！
やる夫の任期中の大成果として組合の壁に飾るお！

**やらない夫**：
出生数も出せ。

**やる夫**：
はいはい、どうせ増えて──
$20 \times 0.033 = 0.66$。
$23 \times 0.088 = 2.024$。
$26 \times 0.110 = 2.86$。
$25 \times 0.066 = 1.65$。
$23 \times 0.022 = 0.506$。

**やる夫**：
合計……$0.66+2.024+2.86+1.65+0.506=7.70$人。

**やる夫**：
減ってるお。
8.53人から7.70人だお。
率は上げたのに赤ちゃんが減ったお！
計算を間違えたお、もう一回──

**やらない夫**：
三回やっても同じだ。
何が起きた。

**やる夫**：
……あっ。
率は「一人あたり」だお。
その率を掛ける相手の人数が減ってるお。
$25$人が$20$人、$32$人が$26$人。
掛け算の片方だけ上げても、もう片方が下がれば積は減るお。

**やらない夫**：
式にしろ。

**やる夫**：
年齢層$a$の女性人口を$W_a$、年齢別出生率を$f_a$とすると、期待される出生数$B$はこうだお。

$$B=\sum_a W_a f_a$$

**やる夫**：
TFRは$f_a$だけを合成した数字だお。
$W_a$は入ってないお。
出生数は$f_a$と$W_a$の両方で決まるお。

**やらない夫**：
親になる年齢の人数は、いつ決まった。

**やる夫**：
20年前から30年前だお。
今年どんな政策を打っても、今年30歳の人数はもう変えられないお。
……率を上げる努力を全部やっても、掛ける相手が減っていれば出生数は減りうるお。

**やらない夫**：
もう一つ。
TFR1.60は、朝凪町の女性が一人あたり1.60人産むという予測か。

**やる夫**：
そう読んでたお。

**やらない夫**：
その年の年齢別率が、これから一生変わらず続くと仮定したらどうなるか、という仮想の合計だ。
実在の誰か一人の人生の予測じゃない。

**やる夫**：
……じゃあ「TFRを上げればバスが満席」は二重に間違いだお。
率と人数を混ぜたのが一つ。
人口の指標を、やる夫の乗車率の目標にしたのがもう一つだお。

**やらない夫**：
壁に飾るか。

**やる夫**：
飾らないお。

### 2-2　二年の先送り ── テンポ効果とコホート

**やる夫**：
分かったお。
率と人数は別だお。
なら今年のTFRが下がったら、その世代が最終的に持つ子どもの数も必ず減るお。

**やらない夫**：
10人で試せ。
10人が一人ずつ子どもを希望していて、当初は全員が今年出産する予定だった。
事情が重なって、5人が2年後へ時期を移した。

**やる夫**：
今年5人、2年後5人。
合計10人。
変わってないお。

**やらない夫**：
今年の数字だけを見た人には何が見える。

**やる夫**：
10人の予定が5人。
半減だお。
新聞に「出生数が半分に」と載るお。

**やらない夫**：
2年後は。

**やる夫**：
普段の予定に先送り分5人が乗るから、急に増えるお。
谷と山が、時期の移動だけで作れるお。

**やらない夫**：
出産の時期が前後することで期間の指標が上下する。
テンポ効果（tempo effect）という。

**やる夫**：
じゃあ谷は気にしなくていいお。
全部先送りで、いずれ帰ってくるお。
少子化は錯覚だったお！
やる夫は少子化問題を解決した男として──

**やらない夫**：
その5人は2年後、何歳だ。

**やる夫**：
2歳上だお。
……2年の間に、年齢も、健康も、仕事も、相手との関係も、希望そのものも変わるお。
先送りした人が全員そのとおり実現できるとは限らないお。

**やらない夫**：
つまり期間の指標だけで何が分けられない。

**やる夫**：
**先送りと、断念が分けられないお。**
どっちも今年の数字は同じように下がるお。

**やらない夫**：
分けるにはどう見る。

**やる夫**：
同じ年に生まれた人を、ずっと追いかけるお。
その人たちが最終的に何人子どもを持ったかを、あとで数えるお。

**やらない夫**：
それが出生コホートの見方だ。
出産年齢をおおむね過ぎた世代について、完結出生児数として確認する。

**やる夫**：
なら最初からそっちを使えばいいお。

**やらない夫**：
今年の朝凪町の子育て世帯が何に困っているか、その数字はいつ分かる。

**やる夫**：
……30年後だお。
コホートは人生の結果に近いけど、分かるのが遅すぎるお。
期間の指標は早いけど、時期の移動に揺れるお。
どっちかを捨てるんじゃなくて、揺れる指標だと知って使うお。

**やらない夫**：
組合で「原因は何だ」と聞かれる。

**やる夫**：
晩婚化だお。

**やらない夫**：
即答だな。

**やる夫**：
だって新聞に……。

**やらない夫**：
結婚しない人、結婚という制度を選ばない人、不妊治療を受けている人、子どもを希望していない人、希望していて条件が足りない人。
この五人を一列の順位表に並べられるか。

### 5-1　25%減らない請求書 ── 固定費と埋没費用

〜〜 翌週月曜9時00分　協同組合の作業日 〜〜

**やる夫**：

25%減だお。

**やらない夫**：
水道でやれ。
今の年間費用は5,000万円。
内訳は、管路80 km、浄水設備、監視、最低限の人員などに4,000万円。
使った量に応じて動く電力や薬品などに1,000万円。

**やる夫**：
今は$5,000万円 \div 1,000人 = 5万円$だお。
30年後は750人だから、費用も25%減らして3,750万円。
$3,750万円 \div 750人 = 5万円$。
ほら同じだお。
やる夫の均衡理論は完璧だお。

**やらない夫**：
人が250人減ると、管路80 kmは何kmになる。

**やる夫**：
……80 kmだお。

**やらない夫**：
浄水設備は。

**やる夫**：
同じだお。
監視も、最低限の人員も同じだお。
減るのは……使った量に応じる1,000万円のところだけだお。

**やらない夫**：
やり直せ。

**やる夫**：
量に応じる分が25%減って750万円。
4,000万円のほうは残るお。

$$\frac{4,000万円+750万円}{750人}\approx6.33万円/人$$

**やる夫**：
6.33万円……。
5万円から26.7%増えたお。
人口が25%減ったのに、一人あたりは26.7%増えるお。
逆に動いたお！

**やらない夫**：
何を混ぜていた。

**やる夫**：
費用を一種類だと思ってたお。
使う量に合わせて動く費用と、使う人が減っても短期には残る費用があるお。

……人が減っても管の長さは減らないお。
**分母だけが減って、分子の大部分が残るお。**

**やらない夫**：
これは水道だけの話か。

**やる夫**：

たんぽぽ号も、園児が3人から2人になっても、運転手を三分の二人にはできないお。

**やらない夫**：

**やる夫**：

地中の管は、他の用途に使えないお。

**やらない夫**：

**やる夫**：
じゃあ「もう80 km分払ったんだから、元を取るまで全部使い続けるお」は──

**やらない夫**：
逆向きだ。

**やる夫**：
……過去に払った額は、これからの判断の材料じゃないお。

払った分がもったいないから続ける、は理由にならないお。

**やらない夫**：
では固定費は永久に動かせないか。

**やる夫**：
そこは違うお。
今日は切れないお。
