# `ultimate-detergent-v2` ブロックメモ

## 制約と到達点

- 新規の標準〜長編教材。高校化学の用語を知らなくても追えるが、濃度、割合、簡単な物質収支はやる夫が手計算する。
- 目標分量は8幕＋終幕で約6万〜8万字。成分カタログではなく、未知の洗浄事故に対して仮説、試験、判定を作れる状態を到達点にする。
- 実験値は教材用の仮想データと明記し、危険な混合を読者へ促さない。塩素系と酸性製品の混合禁止を冒頭に置く。

## 人物設定

- やる夫：町の百周年祭で衣装の洗浄設計を引き受けた化学サークル員。泡立つものをすぐ強いと思い、成功すると屋台化と商品化まで夢見る。
- やらない夫：町の共同洗濯所を営む設備技術者。納期を優先する祭り側に対し、設備・安全・排水の利害を背負う。洗剤処方と品質保証の経験がある。
- できる子：祭り衣装班の採寸・記録担当。複数幕で試験片の数値だけを短く報告する。
- シロクマ君：百周年祭の着ぐるみ。話さないが、泡雪崩、縮み、臭い戻り、最終舞台をつなぐ反復物。

## マクガフィン、トイ、視覚的な小道具

- マクガフィン：翌日17時の開会式で使うシロクマ着ぐるみ。洗浄に失敗すれば使えないが、乱暴に危機を煽らず「町の思い出が詰まった再利用品」とする。
- 反復トイ：「D-01〜D-07」の七枚。油、泥、カレー、模造血、口紅、汗臭、皮脂を、綿・ポリエステル・ウールへ配置する。各幕で同じIDを再判定する。
- 試作ラインX：配合ログを消失した配管から、泡だけ派手な試作液が出てくる。最終的に「処方だけでは使い方と適用範囲が欠ける」証拠になる。
- 事件票：対象、汚れ、素材、水質、温度、時間、機械力、直後、翌日、失格条件の列を持ち、幕ごとに列が増える。
- 大時計：開会式まで18時間。各幕の冒頭で時刻だけを示し、説明的なカウントダウンにしない。

## 伏線と回収

- シロクマの左耳だけが最初から硬い。第3幕で再付着、第6幕で過去のすすぎ不足と判明し、最終幕で左右同じ摩擦へ戻る。
- 七枚のうちD-06だけ、乾燥直後は無臭。第4幕で湿らせると臭いが戻り、評価時点の伏線を回収する。
- 試作ラインXの吐出口に透明な結晶。第2幕では見逃し、第6幕の5℃保存で溶解度と投入量の問題として回収する。
- ポンプを押す人によって一回量が違う小ギャグを第1・3・6幕で反復し、第6幕で操作条件の本題にする。
- 衣装担当が「棚は二本分」と早期に口にする。第7幕で事業制約として回収するが、化学的失格条件は譲らない。

## 繰り返すギャグ

- やる夫が泡の高さへ勝手に「拍手メーター」と目盛りを付ける。毎回別の理由で泡が洗浄力を表さない。
- シロクマの頭だけが扉や乾燥棚から出ており、やらない夫が無言で向きを直す。
- 「10倍入れるお」がCMC、酵素、防腐剤、香料で出かけ、そのたびやる夫自身が途中で止める。後半ほど止めるのが速くなる。
- やらない夫の頭頂部を光沢計の標準板にしようとして却下される。終幕では標準板を正しく持参する。

## 緩急と息抜き

- 第1幕は泡雪崩の高速コメディから、七枚を並べる無音に近い低速へ落とす。
- 第2幕はビーカー実験と計算を短い往復で進め、硬水の白い沈殿を雪景色のように見せる。
- 第3幕後半に夜食休憩を置き、油の付いた焼きそば容器をそのまま新しい試験例へする。
- 第4幕は衣装損傷で緊張を上げ、漂白剤混合の安全場面ではギャグを止める。臭い戻りの判定で静かな驚きを作る。
- 第5幕は人体の不快を扱うため、前半のボケを抑え、手洗い休憩で関係性を近づける。
- 第6幕は保存棚の「六つの死体」を探偵劇のテンポで診断する。
- 第7幕の候補潰しを知的クライマックス、第8幕の手袋・騒音・縮退条件を運用上の統合試験、終幕の雨を動的クライマックスにする。

## 幕ブロック別の再発見サイクル

各幕は `outline.md` の事件を起点にし、節ごとに課題→素朴案→同じ七枚の反例→やる夫の原因言語化→修正→合否両例の検算を回す。教師は成分名を先に言わず、命名はやる夫が作用へ到達した後に限る。幕末の「七枚カルテ」は要約でなく、過去の道具を累積使用する抜き打ち案件にする。

## 状態台帳の初期値

- 定義前の語をやる夫に言わせない。第1幕の知識予算は日常の「油と水は混ざらない」「熱いと落ちそう」まで。
- 七枚ID、素材、初期汚れ量、合格指標は本文冒頭の表で一度だけ固定する。
- 出典候補は旧版の参考文献を入口にし、界面化学、酵素、漂白、皮膚バリア、保存試験の一次・公的資料へ本文脚注を付ける。
