# `ultimate-detergent-v2` ブロックメモ

## 到達点

- 未知の洗浄事故に対して、条件を書き、失格条件を先に決め、次の試験を選べる。
- 成分表示を、界面活性剤・助剤・酵素・漂白・保湿・保存・伝達の仕事に読み替え、各成分が何を担当しているかを仕組みで説明できる。

## 人物

- やる夫：化学サークル員。屋台村の廃油と灰で石鹸を煮るのが趣味で、自作の石鹸液で一本化の夢を見る。泡や濃さで押し切る案を出し、試して崩れ、自分で言い直す。
- やらない夫：共同洗濯所の設備技術者。業務用洗剤の配合と品質管理の経験者。去年衣装班に分けた業務用洗剤を、寒い倉庫に置くなと伝えなかった負い目を6-2で口にする。
- できる子：衣装班の採寸・記録担当。測定値を短く報告し、祭りの側の条件（棚、日程、倉庫）を持ち込む。
- シロクマ君：百周年祭の着ぐるみ。泡の雪崩、左耳、雨の終幕をつなぐ。

## 小道具

- 七枚の試験布：油布、泥布、カレー布、血糊布、口紅布、汗布、皮脂の見本。番号ではなく汚れの名前で呼ぶ。
- 記録票：条件を先に書く紙。幕を追うごとに列が増える（翌日、置く場所、保存後、容器から出た量）。
- 去年の洗剤瓶：ポンプの一回量の差、底の透明な粒、左耳の原因をつなぐ。
- 三本の完成品：日常洗い液、しみ抜き液、手洗い液。

## 使わないもの

- 試験片・処方・案・人物の記号名、拍手メーター、「10倍」の反復、大時計の残り時間、頭頂部の冗談、場面転換カード。

## 緩急

- 第1幕は泡の雪崩の騒ぎから、七枚を並べる静かな場面へ落とす。
- 第2幕は計算と反応式を短い往復で積み、2-4で歴史と分子設計の山を作る。
- 第3幕は蛍光増白剤で測定そのものを疑い、夜食の容器を抜き打ちに使う。
- 第4幕は衣装の損傷で緊張を上げ、塩素系の場面では冗談を止める。
- 第5幕は人の手荒れを扱うため冗談を抑え、幕間で関係を近づける。
- 第6幕は保存見本の診断から、去年の瓶と左耳の謎を解く。
- 第7幕は六条件の導出を知的な山にし、引継ぎと盲検で運用へ渡す。
- 終幕は雨の中の実地処理と、泡のない拍手で閉じる。
