- v1（`ultimate-detergent`）と旧v2を統合した改訂版。骨格は旧v2、化学の中身はv1から移植。構成は `outline.md`。

- 記号的な名前と反復ギミック（拍手メーター、「10倍」の口癖、大時計、頭頂部）は使わない。

## 主要な数値

- 硬度：井戸水 Ca²⁺ 0.8 mmol/L。10 Lで8 mmol → 石鹸16 mmol（分子量300で4.8 g）が沈む。ゼオライト2.0 mmol/g で最低4 g。3-5の試験浴は1 Lで0.8 mmolに対し0.3 g（0.6 mmol）で0.2 mmol不足。
- CMC：表面張力 60/49/39/37/36 mN/m（0.25〜4.00 mmol/L）、100 mLで1.00→2.00 mmol/L は0.100 mmol。
- 酵素：リパーゼ単独の油除去30%、アミラーゼ単独の質量減20%、併用の油除去80%（到達面積 $a$ のモデル）。
- 曝露：いつも 1×3×1×30=90、今回 0.5×5×2×60=300。
- ポンプ：できる子3.2 g、やる夫4.7 g、厚手の手袋2.4 g（0.8〜5.3 g）。改良後2.8〜3.5 g。
- 洗い直し：半量35＋35×40%＝49（標準70）。

## 伏線と回収

- 去年の洗剤瓶：1-2でポンプ差・底の透明な粒を記録して保留 → 2-3で白い沈殿と区別 → 6-2で洗濯所の業務用の同じ配合と判明、寒さによる結晶と偏り → 6-4で今夜の液の保管条件へ。
- 左耳の硬さ：1-2 → 3-1で電気伝導度 → 6-2で濃い液の直接投入と短いすすぎと特定 → 終幕で工程の修正だけで戻す。
- 汗布の乾いた直後の無臭：1-3 → 4-5で臭い戻り → 7-5の一枚目。
- やる夫の石鹸液：1-1の泡 → 2-1〜2-4の化学の題材 → 5-1の手荒れ → 終幕でけん化価から作り直す。
- グリセリン：2-4でけん化の副生成物 → 5-2で湿潤剤として回収。
- アニオンとカチオンの会合：2-5 → 5-3の二段階洗髪と柔軟剤 → 7-1の一本案の棄却。
- 棚二本：1-1 → 2-5 → 6-4 → 7-1で置き場所の読み違いとして回収。
