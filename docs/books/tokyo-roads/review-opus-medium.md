# 寸評：やる夫は東京の道を物語で覚えるようです

約327KB／第0〜23幕＋幕間5＋演習7。深夜のタクシー一晩で、東京の道を「リスト」から「中心・放射・環状＋物語」へ組み替える教材。実車22本＋演習7本という反復訓練が骨格。

## 良い点

**冒頭で投げた3つの宿題が、全部本編の山場として回収される。** 第0幕の宿題(1)(2)(3)（135–143行目）が、(1)＝日本橋原点（189–217行目）、(2)＝環一〜六は名前が先（1283–1295行目）、(3)＝川は公有地（1568–1575行目）として、それぞれ独立した幕のクライマックスになる。しかも(2)は「呼ばれ方は、その道が生まれた順番の化石」（1292–1293行目）という一段上の言い換えに到達しており、答え合わせで終わっていない。

**「用地買収を避ける」という一つの原理を、3回、別の姿で再利用している。** 首都高が川の上を這う（1570–1575行目）→ C2が地面の環六の真下に潜る（1999–2019行目）→ 地下鉄が幹線道路の下を掘る（4629–4648行目）。3回目でやる夫自身が「上か下か、方向が逆なだけで、『公のものの空いてる隙間を使う』はそっくり同じだお」（4639–4641行目）と一般化する。理論の転移を、読者ではなく主人公にやらせている。

**冒頭の問いを終幕でそのまま再演し、成長を測定可能にしている。** 第0幕の「赤坂見附から新宿駅西口、ナビは圏外、どっちに曲がる」（38–46行目）に対し、23-1（6169–6183行目）で同じ問いが再提示される。答えが「外堀通り＝環二 → 新宿通り＝20号の背骨 → 新宿は西の結び目」と、教材中の3つの道具の合成として組み立てられており、何が変わったかが一行も説明なしで示せている。

**幕間(2)と演習6で、東京固有性を意図的に剥がしている。** パリのエトワールとペリフェリック（1399–1414行目）、架空の城下町のバイパス（1442–1463行目）、そして演習6の「初めての地方都市」（6698–6749行目）。「東京の暗記じゃなく、中心を持つ街が道を組む原理」（1426–1430行目）という主張を、実際に別の街で使わせて検証している。転移を口約束で終わらせていない。

**第11幕だけ、他幕と異なる厳しさで自説を潰している。** 「通り名は名前を読めば分かる」という前幕までのルールに対し、清洲橋通りが「入谷起点、まず南、浜町から東」（3342–3355行目）と橋名から向きを出せない反例を出し、「名前だけで向きも起終点も決めつけない」（3389–3391行目）へ後退させる。目白通りの「目白は終点じゃない」（3240–3248行目）も同様。教材が自分の作ったルールを自分で削っている数少ない箇所。

**参考文献17点が、本文の対応幕つきで付いている（6848–6880行目）。** 首都高の公有地8割（[^8]）、環七57km（[^5]）、16号330km（[^12]）、保土ヶ谷バイパス交通量（[^15]）と、本文の具体的数値に脚注が対応している。柳瀬『国道16号線』（[^13]）のような書籍も含む。

## 欠点

**やる夫がほぼ全問正解する。** 東海道の番号を「当てずっぽうで、15号？」と言って即正解（256–262行目）、山手トンネルの「山手」から環六を即座に導出（2015–2019行目）、C2の存在を予想して的中（1990–1994行目）。全編で本当に間違えるのは、放射の乗り換えで外側へ逃げようとする（776–791行目）、中野駅と中野坂上を取り違える（3211–3215行目）、C1と圏央道を反射で言いかける（3149–3153行目）の3箇所程度で、いずれも同じ発言の中で自己訂正される。教材の目的である「苦労の過程とセットで学ぶ」が、構造として存在していない。

**節の型が完全に固定され、80回近く反復される。** どの節も「素朴案 → やらない夫の判定質問 → やる夫が一往復で気づく → 調子に乗る → まとめ → 残った疑問」で閉じる。特に「調子に乗る」は時給8000円（278行目）、本を出してベストセラー（355行目）、写真集（521行目）、写真集第二巻（1029行目）、パリで稼ぐ（1437行目）、関東地方の王（2538行目）、川ソムリエ（3874行目）、透視能力者（4399行目）と同型が10回以上続き、5回目以降は笑いとして機能していない。

**分量に対して、再発見される理論が少ない。** 放射と環状の必然性、用地買収回避、誘発需要、ボトルネック。実質これで打ち止めで、残りは地名・番号・由来の対応関係を対話で語らせたものである。実際、索引（6817–6836行目）で全教材が20行に要約できてしまう。第17幕（道の幅）、第20幕（一方通行・右折）、第22幕（湾岸）は、それぞれ第15幕の「まっすぐ＝新しい土地」の再確認か、一節で足りる内容を4節に引き延ばしている。

**物語的な圧力が一切ない。** やる夫には期限も、失敗したときの損失もない。むしろ127行目で、やらない夫が「メーターは止めておく」と言って時間的な制約を明示的に消してしまう。同リポジトリの熱力学教材の「祭りまで3日」に相当する装置がなく、22本の実車はすべて架空の客の想定問答で、外れても何も起きない。第0幕の「面接に落ち続けている」という設定は、この夜の間、一度も効いてこない。

**やらない夫の造形が3つの定型句で尽きている。** 「判定してやる」「そこにたどり着いたか」「締めろ」。25年この街を流している運転手という設定（36行目）にもかかわらず、自身の失敗談も、この仕事で見た具体的な夜の記憶も、一度も語らない。5502行目や6572行目で情の見える返しはあるが、経験の中身は空白のままで、教師役が最初から完成品として置かれている。

**終盤の出典が抜けている。** 誘発需要（5131行目）とボトルネック（5212行目）は交通工学の確立した概念だが脚注がない。特に「アメリカの宅配便が右折だけで回る、なんて話もある」（5690行目）は、実態（右折の完全排除ではなく削減の最適化）と食い違う俗説寄りの書き方で、無出典のまま置かれている。第14幕以降（郊外・地形・渋滞・時間天気・湾岸）は約2700行あって脚注が[^17]の1点のみ。

**細部の食い違いが残っている。** 大宮が4199行目では「北西の指の先」、4227行目では「北」。第一・第二京浜のねじれの説明（1006行目）が「造られた順や海からの近さで数えた」と二つの基準を併記したまま確定しておらず、「ねじれてる、と知っておくのが対策だ」（1009行目）で逃げている。

## 改善案

1. **やる夫を長く詰まらせる場所を3箇所作る。** 最優先は5-2（1553–1575行目）。現状は「川には家がない」→「公のものだ」が1560–1566行目の一往復で跳んでいる。ここに誤案を1つ挟む：「私有地の上空だけ買えばいい、地面は使わないんだから安いはず」→ やらない夫が「空中の権利でも、結局は地権者一人ずつと交渉することになる。何百件だ」で潰す。同様に4-3（1245–1252行目）で、やる夫に「七と八だけ偉い」以外にもう2案（環状は7本目で完成した、七と八が一番長い）を出させて全部外させる。18-1（5078行目）は「一年後もすいている」と一度断言させてから外す。

2. **中盤に一度だけ、本物の客を乗せる。** 幕間(3)（2193行目付近）で、やらない夫が実際に客を拾い、やる夫が助手席から答えを言う場面を20〜30行入れる。やる夫が方向を外し、やらない夫が黙って正しい方へハンドルを切り、降車後に「今のは実車ごっこじゃない。あの人は会議に遅れた」と告げる。実害が出る場面が1つあるだけで、以降22本の実車の緊張度が変わる。

3. **分量を2割削る。** 第17幕（4863–5056行目）を第15幕の地形の一節へ吸収し、第20幕（5526–5765行目）を演習へ降格、第22幕（5965–6157行目）を第15幕「まっすぐ＝新しい土地」の実車として1節に圧縮する。合計で60KB前後減り、密度の高い第1〜12幕の比重が上がる。

4. **やらない夫に失敗談を2回だけ与える。** 1回目は第5幕の日本橋（1671–1677行目付近）で「開通した年に、この上を走るのが誇らしかった」という、当時の価値観に自分も乗っていた告白。2回目は最終幕の別れ際（6363–6369行目）で、若い頃に客を逆方向へ運んだ夜の話。教師が完成品でなくなり、「道は完成しない」（第21幕）の主題が人物側でも鳴る。

5. **「調子に乗る」ギャグを半減し、種類を変える。** 現状の10回超（278、355、521、1029、1223、1437、2538、3874、4399行目ほか）を4〜5回に減らし、残す分は「金額の跳ね上がり」に統一する（時給8000円→1万円→タワマン、が第0幕の63行目に既にある）。回収として、23-1（6206–6212行目）の「時給1万円じゃなくていい」がはじめて効く。

6. **終盤の出典を補う。** 誘発需要（5131行目）にDowns–Thomson則やDuranton & Turner (2011) の「基本法則」、ボトルネック（5212行目）に道路交通センサスまたは交通容量の一般文献、5690行目の宅配便の話はUPS ORIONの実際の運用（右折削減であって排除ではない）に修正した上で出典を付けるか、削除する。

7. **細部の食い違いを直す。** 4227行目の「大宮は北」を「北西」に統一。1006–1015行目の京浜のねじれは、「第一・第二は京浜間の国道として整備された順（海沿いが先）」と一つの基準に確定させ、やる夫に「じゃあ第三京浜が466号なのも、生まれが最後だからだお」（2789行目で既出）まで一息でつなげる。
