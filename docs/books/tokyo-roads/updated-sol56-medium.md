# リライト記録

`review-opus-medium.md` のレビュー・皆瀬案を基に、教材の強い骨格を残しつつ、主人公の失敗と物語上の圧力を増やした。

## 追加修正：ト書きの会話化

- 表情、乗降、分岐への進入、車外の道路状況を示していた会話外の括弧書き10か所を削除した。
- 場面情報は省略せず、やる夫・やらない夫・客が標識や周囲の状況を観察して口にする形へ置き換えた。
- 特に幕間(3)の誤進入は、やらない夫の進路確認と、やる夫が標識を読んで誤りに気づく発話に分け、失敗の因果が会話だけで追えるようにした。

- 環状道路の呼称、川上空の利用、誘発需要では、やる夫が複数の誤案や疑念を出してから結論へ進むようにした。
- 幕間(3)に本物の客を追加し、C2の向きを取り違えて客の時間を失わせる失敗を描いた。以後は「知っている道を言う」のでなく、目的地・方向・内外を確認する成長へつないだ。
- やらない夫に、日本橋高架への過去の見方と、若いころに目的地を取り違えた失敗談を与えた。教師役も誤りから学んだ人物として描いた。
- 第17・20・22幕は反復を圧縮し、幅・一方通行・右折・湾岸を独立した暗記事項ではなく、既出の地形・ボトルネック・方向を使う実車へ組み替えた。
- 第一・第二京浜は「京浜間の幹線として整備された順」に基準を一本化し、大宮の方角は「北西」に統一した。
- 誘発需要、交通ボトルネック、UPSの経路最適化に出典を追加した。UPSは曲がり方の完全排除という俗説を避け、「費用の高い左折を減らす」と修正した。
- 繰り返されていた出世・称号型のギャグを減らし、終盤の時給一万円の撤回が残るようにした。

残した判断として、第1〜16幕の中心・放射・環状・公有地という再発見の連鎖、終幕の赤坂見附での再試験、地方都市への転移演習は本稿の長所なので維持した。後半も時刻・天候・変化する道路という実務上重要な観点は削らず、圧縮対象を理論の重複が大きい三幕に絞った。
