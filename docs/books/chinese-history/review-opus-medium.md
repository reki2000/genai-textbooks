# 寸評：やる夫で学ぶ中国史 ― 王朝は前王朝の何を捨て、何を受け継いだのか

約171KB／序幕＋全10幕。都市を日本の都市札へ固定し、民族名に「人・言語・政治・名前」の4本の線を引く2つの道具で、殷周から現代までを「前王朝の何を継いだか」で通す教材。

## 良い点

**冒頭で配った道具が最後まで運用される。** 都市の固定札（38–49行目）は、董卓が洛陽＝京都から献帝を長安＝奈良へ移す（751行目）、南京＝大阪が首都から副都へ下がり北平＝東京が首都へ上がる（1781–1783行目）まで一貫する。4本の線（150–153行目）も終幕の最終系譜表（2583–2599行目）で15項目へ引き直され、序幕に預けた道具がそのまま最終試験になる円環構造ができている。

**「反応席」の発明が善悪史観を構造的に禁じている。** 6席の表（185–192行目）以後、政策評価が必ず「誰が得て誰が失うか」に分解される。紹興の和議を「屈辱／戦争停止／生存／地位喪失」の4視点へ割る箇所（1336行目）は、岳飛・秦檜の英雄・売国奴図式を否定するより効いている。

**「成立編」節が創業者の死という型を反復して比較可能にしている。** 武王の死→三監の乱（318行目）、始皇帝の死→胡亥・趙高（463行目）、柴栄の急死→陳橋の変（1249行目）、モンケの死→クビライとアリクブケ（1500行目）、洪武帝の死→靖難の役（1694行目）。同じ欄で並ぶため、「周、漢、晋、明初と同じく、創業功臣へ地方軍を預ける問題がまた現れる」（1993行目）が実感として届く。

**終幕の詩の反転が主題を一句で決めている。** 劉希夷「年年歳歳花相似たり」（2638行目）を出しておいて「花は自然に同じ形で咲き直すのではない」「誰かが前の株から枝を切り取って接ぎ木した」（2649–2650行目）と裏返し、唐の骨格が隋の枝、隋の枝が鮮卑系軍事貴族の土（2653行目）へ遡る。

**作品札の扱いと参考文献が堅い。** 封神演義（303–310行目）、キングダム（448–487行目）、天幕のジャードゥーガル（1504–1505行目）等を「人物名の入口にはなるが、この部分は物語」と切り分けつつ切り捨てない。文献は学術書20点（2671–2690行目）に加え、再構音が Baxter–Sagart へ紐づき `*` や末尾 `H` の意味まで注記される（2701–2702行目）。

## 欠点

**やる夫が「再発見」していない。** ほぼ全節が「素朴な誤解 → やらない夫の否定と正解 → やる夫の要約」の3手で閉じる。6-3では「全部モンゴル式にすればいいお！」（1537行目）の2行後（1543行目）にやる夫が完答する。0-2（63→90行目）、7-1（1666→1672行目）、9-7（2428→2434行目）も同型。やる夫が案を実行して失敗し、その結果に殴られる場面が全編に一つもなく、反証はすべて教師の口から出る。

**物語的な圧力が皆無で、最後に取ってつけられる。** 10-1の「永久に滅びない国家の設計図」「歴代皇帝に売れば宰相だお」（2487–2488行目）は序幕から第9幕まで一度も言及されない。学習に目的も期限も利害もない。つまみ論（2491–2524行目）自体は本教材で最良の場面だが、伏線がないため突然始まる別のゲームに見える。

**「政策反応札」が対話でなく箇条書きの朗読になっている。** 494–498行目、576–579行目、771–774行目、959–964行目、1259–1263行目、1707–1713行目、1984–1988行目、2322–2328行目と8回以上、やる夫が4〜6項目を読み上げる。6席の枠組みが表を埋める作業へ退化し、しかも常に一発正解なので読者に予想の余地がない。

**できる夫の世界同時刻盤が9回とも同形式の列挙で終わる。** 392–394行目、653–654行目、979–982行目、1186–1190行目、1447–1450行目、1628–1631行目、1903–1907行目、2240–2243行目、2467–2470行目。すべて「！」付きで地域名を並べ、やる夫が一般論で受ける。比較史担当（16行目）が反証でなく地名の同時上映に留まる。銀の連鎖（1910–1911行目）だけが唯一、比較が因果になっている。

**数量がほとんど出てこない。** 澶淵の盟は「銀と絹を送る」（1224行目）だけで額も歳入比もない。「全面戦争の費用と比べれば安い外交保険」（1225行目）は両者の金額を並べて初めて成立する主張である。両税法（1178行目）、一条鞭法（1726行目）、清の低税（2086–2094行目）も数字を一切伴わず、負担の大きさが常に定性語のままになる。

**0-3の音韻の精密さが以後回収されない。** 再構音の説明（101–124行目）は丁寧だが、以降は固有名詞への機械的な注記になり分析に使われない。「名前の線」（153行目）や他称の音写しかない場合（117行目）と接続すれば道具になったが、終幕の表でも音韻には一言も触れず、読者の負担だけが残る。

## 改善案

1. **設計図を序幕へ前倒しし、各幕末で1行ずつ改訂させる。** 2487行目の設計図を0-5の直後（203行目付近）へ移して目的として置き、各幕の引きの直前（403行目、1197行目、1639行目など）に「設計図第n版」をやる夫が一行追記する欄を作る。10-1のつまみ論で、その追記履歴が互いに矛盾していると突きつければ、9幕分の伏線が一挙に回収される。

2. **反応席の箇条書きを、やる夫の予想とできる子の訂正へ分割する。** 少なくとも3回（494行目、1259行目、1707行目）で、やる夫が6席のうち3席を先に予想し、できる子が史料上の痕跡（秦の隠田記録、宋の落第者数、明の軍戸逃亡率など）で1つを外す。やる夫が読み違える経験が、教材で唯一の「本人の失敗」になる。

3. **金額と人数を最低5箇所へ入れる。** 1224行目に歳幣の銀・絹の額と宋の年間歳入比、遠征1回の推定戦費を並置。1178行目に租庸調との課税基準の差、1726行目に銀納化の規模、2090–2094行目に地方官一人あたり担当人口の概数を置けば、負担の議論が定性語から抜ける。

4. **世界同時刻盤に反証機能を持たせる。** 3回（984行目、1633行目、2245行目）で、できる夫の列挙をやる夫が誤って対応づけ（例「五胡十六国＝ゲルマン民族大移動と同じ」）、できる夫が移住規模や先住政権の残存度を数字つきで訂正する応酬を1往復入れる。

5. **音韻を終幕で回収する。** 2583行目の表の直前に、できる子が「匈奴・羯・柔然は中国側の音写しか手掛かりがない」の一点で0-3（110行目、117行目）へ戻り、「名前の線が最も細いのは、名前が他称の音写しかない集団だ」と接続する。5〜10行で序幕の音韻節が道具に変わる。

6. **できる子の連続講義を対話へ割る。** 693–714行目の5連続発言を、やる夫が各集団へ4本の線を先に引き、できる子が「羯だけは1本目も2本目も引けない」と返す形へ組み替える。22行の一人講義が、道具の初回運用へ変わる。
