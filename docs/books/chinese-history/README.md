# やる夫で学ぶ中国史 ― 王朝は前王朝の何を捨て、何を受け継いだのか

---
## 登場人物

**やる夫**：
中国（ちゅうごく、Zhōngguó、China）史を王朝名と年号の列として覚えてきた初学者。巨大国家なら皇帝が命令すれば動くと思い込み、中央集権、徳治、軍事力、民族同化など、毎回ひとつの万能策に飛びつく。

**やらない夫**：
制度史とユーラシア史を教える研究者。答えを先に示さず、誰が税を払い、誰が命令を翻訳し、誰が馬と穀物を運ぶのかを問い続ける。

**できる子**：
古文書、地図、言語、民族名の整理を担当する。似た名称を安易に直系の祖先・子孫として結ばず、分かっていることと不明なことを分ける。

**できる夫**：
世界同時刻盤を動かす比較史担当。中国で起きた変化を、日本、ヨーロッパ、中東、インド、アフリカ、東南アジアの同時代と接続する。

## 序幕　同じ地図を、別の国だと思って読む

### 0-1　都市の札は動かさない

**やる夫**：
中国史の都市名が無理だお！
長安（ちょうあん、Cháng'ān）、洛陽（らくよう、Luòyáng）、建康（けんこう、Jiànkāng）、金陵（きんりょう、Jīnlíng）、応天府（おうてんふ、Yìngtiānfǔ）、大都（だいと、Dàdū）、燕京（えんけい、Yānjīng）、汴京（べんけい、Biànjīng）、臨安（りんあん、Lín'ān）……王朝が変わるたびに都市までテレポートしてるように見えるお！

**やらない夫**：
都市が動いたんじゃない。名前と役割が変わったんだ。[^18]
今回は日本の都市を固定した札にする。時代によって札を付け替えるのは禁止だ。

**やる夫**：
洛陽がある時代は京都で、別の時代には大阪、みたいにはしないんだお？

**やらない夫**：
しない。対応は最後まで固定する。

| 中国の都市圏 | 時代による主な名称 | 固定する日本都市の札 | 記憶する地理的役割 |
|---|---|---|---|
| 洛陽 | 洛邑（らくゆう、Luòyì）・雒陽（らくよう、Luòyáng）・洛陽・東都（とうと、Dōngdū） | 京都 | 古い正統性を背負う内陸の旧都 |
| 長安・西安（せいあん、Xī'ān） | 鎬京（こうけい、Hàojīng）・長安・大興（だいこう、Dàxīng）・西京（せいけい、Xījīng）・西安 | 奈良 | 計画的に造られた大陸帝国の西寄りの都 |
| 北京（ぺきん、Běijīng、Peking） | 薊（けい、Jì）・幽州（ゆうしゅう、Yōuzhōu）・燕京・中都（ちゅうと、Zhōngdū）・大都・北平（ほくへい、Běipíng）・北京 | 東京 | 北方国境に近い軍事・政治首都 |
| 南京（なんきん、Nánjīng、Nanking） | 建業（けんぎょう、Jiànyè）・建康・金陵・江寧（こうねい、Jiāngníng）・応天府・南京 | 大阪 | 長江（ちょうこう、Cháng Jiāng、Yangtze River）下流の経済力を背負う南方の大都市・首都候補 |
| 開封（かいほう、Kāifēng） | 汴州（べんしゅう、Biànzhōu）・東京（とうけい、Dōngjīng）・汴京・開封 | 名古屋 | 大運河（だいうんが、Dà Yùnhé、Grand Canal）と黄河（こうが、Huáng Hé、Yellow River）交通に支えられた平原の実務首都 |
| 杭州（こうしゅう、Hángzhōu） | 杭州・臨安 | 神戸 | 江南（こうなん、Jiāngnán）の富と水運を背負う洗練された南方都市 |
| 広州（こうしゅう、Guǎngzhōu、Canton） | 番禺（ばんぐう、Pānyú）・広州 | 長崎 | 南海（なんかい、Nánhǎi）交易と外国人が集まる南の窓口 |
| 泉州（せんしゅう、Quánzhōu） | 泉州・刺桐（しとう、Cìtóng、Zayton） | 堺 | 民間海商が集まる国際貿易港 |
| 上海（しゃんはい、Shànghǎi） | 上海 | 横浜 | 近代の外国貿易から急膨張した新興港湾都市 |
| 成都（せいと、Chéngdū） | 成都・益州（えきしゅう、Yìzhōu） | 福岡 | 中央から遠いが豊かな盆地を持つ西方の自立的中心 |

**やる夫**：
じゃあ唐（とう、Táng、中古音 dang）の長安は奈良、後漢（ごかん、Dōng Hàn、Eastern Han）の洛陽は京都、元（げん、Yuán）の大都も清（しん、Qīng）の北京も東京、六朝（りくちょう、Liù Cháo）の建康も明（みん、Míng）初の南京も大阪だお。
同じ札の都市が、首都になったり旧都になったり占領都市になったりするのを見るわけかお。

**やらない夫**：
そうだ。京都が平安京の新都、古都、朝廷所在地、観光都市と意味を変えても京都であり続けるように、洛陽も位置を動かさず、歴史的な意味だけを変える。
比喩は都市の同一性をつかむ補助であって、規模や文化が同じという意味ではない。

### 0-2　中国語は一つ、では統治の苦労が消える

**やる夫**：
でも中国なら、みんな中国語で皇帝の命令を聞いたんじゃないかお？
日本の藩より広いだけで、基本は同じ国だお。

**やらない夫**：
その想像をいったんヨーロッパへ置き換えろ。
ローマからパリ、マドリード、ウィーン、ワルシャワ、イスタンブールまでを一人の皇帝が治め、村ではフランス語、イタリア語、スペイン語、ドイツ語、ポーランド語、ギリシア語、トルコ語が話されているとする。
そのうえ北には騎馬移動をする連合国家、西にはオアシス都市、南西には山岳社会がある。
皇帝の命令は、誰が何語で読ませる？

**やる夫**：
えっ……役人が現地語を全部覚えるのかお？

**やらない夫**：
覚える者もいる。通訳も使う。地域の有力者を役人にする。文書だけ共通化する。複数の行政制度を並べる。
漢字による文語は、中世ヨーロッパのラテン語に少し似ている。発音も日常語も違う人が、同じ古典文体を読み書きできる。
ただし漢字は各地の発音で読めるため、ラテン語よりさらに特殊だ。

**やる夫**：
広東（かんとん、Guǎngdōng）の商人と福建（ふっけん、Fújiàn）の船員と山西（さんせい、Shānxī）の役人が、口では通じにくくても、紙に書くと制度上はつながることがあるのかお。

**やらない夫**：
そうだ。ただし読み書きできる者は限られるし、同じ文字でも語法や行政慣行は違う。
明清期には官僚用の共通口語として官話が発達するが、村の全員が話したわけではない。
元ではモンゴル語、漢語、チベット語、ペルシア語系の実務言語が交差し、清では満洲語、漢語、モンゴル語、チベット語などが国家運営に使われる。
これは単一言語国家を大きくしたものではなく、ハプスブルク帝国やオスマン帝国のような多言語統治に近い感覚だ。

**やる夫**：
皇帝の詔書を出した瞬間、全国の農民が内容を理解するわけじゃない。
中央文書から地方官、その下の書記、村の有力者、口頭説明へと何段も翻訳されるんだお。
途中で意味も利害も変わりそうだお……。

**やらない夫**：
その変形こそ、これから見る統治だ。

### 0-3　小コラム　王朝名はなぜ似て聞こえるのか

**やる夫**：
秦（しん、Qín、上古音 *[dz]i[n]）は「しん」、晋（しん、Jìn、中古音 tsinH）も「しん」、金（きん、Jīn、中古音 kim）も「きん」、清も「しん」に近いお。
漢（かん、Hàn、中古音 xanH）と韓（かん、Hán、中古音 han）、隋（ずい、Suí、中古音 zye）と周（しゅう、Zhōu、上古音 *tiw）まで混ざってきたお！
昔の中国人も「次のシンはどのシン？」って困ったのかお？

**できる子**：
そこで読み札の約束。
中国語圏の固有名詞は初出時に、**日本語の読み、現代標準中国語のピンイン、英語の慣用表記がピンインと異なる場合は英語名**を添える。
王朝・国号は、その時代に近い再構音を研究者が示せる場合だけ「上古音」「中古音」も置く。
元・明・清のような近世には地域・身分・宮廷言語の差があり、単一の「当時音」を安全に置けない場合は無理に添えない。
再構音は録音の再生ではなく、韻書・韻文・音写・漢字の系列から組み立てた仮説なので、先頭の `*` は「復元形」を表す。[^29][^30]

**やる夫**：
テムジンやヌルハチみたいに、もともと漢語の名じゃない人物はどうするんだお？

**できる子**：
漢字音へ無理に戻さず、モンゴル語・満洲語などの原名が通用している場合はそのラテン文字表記を置く。
中国史料の音写しか手掛かりがない民族名は、ピンインと英語圏の慣用名を併記して、原音そのものとは断定しない。

**やらない夫**：
現代北京語で並べると、秦は **Qín**、晋は **Jìn**、金は **Jīn**、清は **Qīng** だ。
日本語の音読みでは接近しても、北京語では子音、声調、語末の `-n / -ng` が違う。
音の変化を比べる基準として中古音まで戻ると、差がさらに見える。
たとえば秦は同時代に近い上古音 `*[dz]i[n]`、晋・金・清の各文字は中古音で `tsinH`・`kim`・`tshjeng` と再構される。
後者三つは各王朝創業時の録音再現ではなく、同じ歴史段階へそろえて比較するための基準形だ。

**やる夫**：
似ているのは王朝が同じ音を襲名したからじゃないお。
一音節の国号を、日本語・現代北京語・古い中国語という別々の音の地図へ載せた結果、ある区別は残り、ある区別は合流したんだお。

**やらない夫**：
その通りだ。
以後は「しん」とだけ覚えず、**字・日本語読み・ピンイン・時代**を一組の札にしろ。

### 0-4　民族名を直線で結ばない

**やる夫**：
民族も覚えにくいお。
匈奴（きょうど、Xiōngnú、Xiongnu）が消えたら鮮卑（せんぴ、Xiānbēi、Xianbei）、鮮卑が消えたら突厥（とっけつ、Tūjué、Göktürks）、突厥が消えたら契丹（きったん、Qìdān、Khitan）、女真（じょしん、Nǚzhēn、Jurchen）、モンゴル（Měnggǔ、Mongols）、満洲（まんしゅう、Mǎnzhōu、Manchu）……名前が違うだけで、ずっと同じ北方民族じゃないのかお？

**できる子**：
不正確。
人は移動し、婚姻し、別の連合に入り、言語を変え、古い政治名を捨てる。
一方で、騎馬軍事、首長への贈与、草原の移動路などは別集団へ継承される。
血統、言語、政治組織、生活様式は別々に追う必要がある。

**やらない夫**：
民族名を見るたびに4本の線を引く。

1. **人の連続**：子孫や移住集団が確認できるか。
2. **言語の連続**：同じ語族、近縁語、別言語、不明のどれか。
3. **政治の連続**：前の国家の制度、称号、部族を再編したか。
4. **名前の連続**：本人の自称か、中国側など他者が付けた総称か。

**できる子**：
4本の線がどれくらいバラバラに動くか、三つだけ先に見せる。

| 名称 | 4本の線はどう食い違うか |
|---|---|
| 匈奴 | 政治の記憶と草原の編成技術は後世へ渡ったが、人・言語の線は追い切れない。突厥やモンゴル、欧州のフンの直系祖先とはいえない |
| 契丹 | 言語はモンゴル語族に近い可能性が高いが、政治の線は遼（りょう、Liáo）・西遼（せいりょう、Xī Liáo、Western Liao）で切れ、金や元の家門へ分散した。モンゴル人の旧名ではない |
| 女真 | 4本がほぼ揃って続く珍しい例。金の女真から後金（こうきん、Hòu Jīn、Later Jin）・清の満洲へ、名称変更と再編を伴いながら比較的明瞭に連続する |

**やる夫**：
血筋が続いても名前が変わるし、名前が似ていても同じ人々とは限らない。
さらに、消えた集団が全滅したとは限らず、別の戸籍や言語へ溶け込むんだお。

**やらない夫**：
その理解で始めよう。
残りの名前は、幕を進めながらその場で4本の線を引いていく。
全部の札が出そろったら、終幕でまとめて並べ直す。

### 0-5　「国民の反応」は一つではない

**やる夫**：
政策を詳しくするなら、国民が喜んだか怒ったかを書けばいいお。
減税なら歓迎、増税なら反対。簡単だお！

**やらない夫**：
その「国民」を分解しろ。
前近代の中国には世論調査も全国紙もなく、同じ政策でも立場によって反応が逆になる。
今後は政策を出すたび、少なくとも次の6つの席から見る。

| 反応席 | 主に気にすること |
|---|---|
| 自作農・小作農 | 土地、税、労役、兵役、飢饉時の救済 |
| 地方豪族・宗族 | 土地所有、裁判、地域支配、官職への入口 |
| 官僚・知識人 | 任用、昇進、法の一貫性、皇帝への発言権 |
| 兵士・軍事集団 | 給与、土地、戦利品、家族保障、指揮官との結びつき |
| 商人・職人 | 通貨、関税、道路、治安、専売、移動の自由 |
| 周辺諸集団 | 交易、朝貢、首長の地位、移住、自治、軍役 |

**やる夫**：
たとえば土地を国が細かく登録すれば、中央官僚は税収が増えて喜ぶ。
でも豪族は隠していた土地を取られ、農民は脱税を防がれる一方、土地権利を公認されることもあるお。
同じ政策に賛成と反対が同時に存在するんだお。

**やらない夫**：
さらに反応は、歓迎、服従、逃亡、戸籍の偽装、賄賂、訴訟、宗教運動、地方反乱など異なる形で現れる。
大反乱が起きなかったから支持されたとも限らない。
史料に声を残しやすい官僚と、声を残しにくい農民・女性・被征服民を同じ重さで読めないことも覚えておけ。

## 第1幕　神に選ばれた王から、条件付きの王へ――殷・周

---
### 1-1　夏・殷成立編――伝承と甲骨を分ける

**やる夫**：
最初から成立人物を並べるお！
夏（か、Xià、上古音 *[ɢ]ˤraʔ）の禹（う、Yǔ）、桀（けつ、Jié）、殷（いん、Yīn、上古音 *ʔər）の湯王（とうおう、Tāng Wáng）だお！
禹が洪水を治めて夏を作り、悪い桀を湯王が倒したんだお！

**やらない夫**：
ここでは後代の伝承と、同時代に近い考古資料を分けろ。
夏王朝については後世の史書に禹、啓（けい、Qǐ）、桀などの系譜があるが、王名と事件を同時代文字資料で確認できない。
二里頭文化（にりとうぶんか、Èrlǐtóu wénhuà）を夏と結ぶ議論はあるが、遺跡自身が「ここは夏王朝だ」と名乗る文字資料は見つかっていない。

**できる子**：
まず勢力別に置く。

- **夏の伝承系譜**：禹 → 子の啓 → …… → 桀。禹から啓への継承は、賢者を選ぶ政治から父子継承へ移った物語として語られる。
- **殷の創業勢力**：湯。夏最後の桀と敵対し、桀を倒して殷を開いたとされる。
- **交代線**：桀の敗北・死によって夏が終わり、湯の系統へ天命が移った、という形に後世の史書は整えた。ただしこの死亡・交代過程を同時代文字資料では確認できない。

**やる夫**：
史実として確実に会話を再現するのは無理なんだお。

**やらない夫**：
そうだ。
殷になると甲骨文字によって王名、祭祀、戦争、収穫、天候などが確認できる。
ただし甲骨が豊富なのは主に後期の安陽（あんよう、Ānyáng）時代だ。

**できる子**：
確認しやすい殷側も、王統と軍事協力者を分ける。

- **殷王統**：盤庚（ばんこう、Pán Gēng） → …… → 武丁（ぶてい、Wǔ Dīng） → …… → 帝辛（ていしん、Dì Xīn）。盤庚は都を後の安陽地域へ移したと伝わり、武丁期には甲骨資料が多い。帝辛は最後の王で、後世には紂王として暴君化された。
- **武丁政権の軍事・祭祀勢力**：婦好（ふこう、Fù Hǎo）。武丁の配偶者の一人で、祭祀と軍事を担った。婦好が武丁より先に死ぬと、王は繰り返し甲骨で彼女の死後世界を問い、彼女自身の軍事指揮は継承されなかった。
- **王朝交代線**：帝辛と周の武王が敵対し、牧野で殷軍が敗れる。帝辛の死は殷王統の終わりを決定づけるが、旧殷勢力そのものは直ちに消えず、次の周成立編で再反乱する。

**やる夫**：
殷の政策反応はどう書くんだお？
世論調査がないお。

**やらない夫**：
分かる範囲を限定する。
王都の工房へ青銅器、骨、玉、穀物、人員が集まったことから、王が生産と貢納を集中できたことは分かる。
軍事遠征で王族と従属勢力は戦利品を得る一方、敵対集団は捕虜・貢納・移住の負担を受けた。
祖先祭祀は王族の結束を作るが、王都から遠い勢力は婚姻、贈与、威圧がなければ従い続けない。

**やる夫**：
「殷の民衆は湯王を歓迎した」みたいな後世の徳治物語を、そのまま当時の国民反応とは書けない。
早い時代ほど、分からないことを分からないまま残す必要があるんだお。

**やらない夫**：
その姿勢を保ったまま、殷末から周成立へ進もう。

### 1-2　殷の王は何を支配していたのか

**やる夫**：
最初の王朝なら、皇帝が中国全土を県に分けて統治したんだお？

**やらない夫**：
いきなり後世の帝国を投影するな。
殷の王が確実に握ったのは、王都、王族、祭祀、軍事遠征、青銅器生産、周辺勢力との従属・同盟関係だ。
現代国家のように領域内の全住民を均等に戸籍化したわけではない。

**やる夫**：
安陽は固定札だとどこだお？

**やらない夫**：
主要対応表の外だが、補助札なら吉野ヶ里に伊勢神宮と軍需工場を重ねた感じだ。
祖先へ問う宗教中心、武器と祭器を作る工房、戦争捕虜、貢納物が王都に集まる。

**やる夫**：
じゃあ王は法律より占いで決めるのかお。
雨が降るか、戦争するか、王妃が出産するかを甲骨に刻む……国家会議が全部神託だお！

**やらない夫**：
神託は気まぐれな迷信というより、王だけが祖先へ正式にアクセスできるという権力装置だ。
王族の祖先と政治秩序が重なっている。

**やる夫**：
その王家を倒した周は、殷の神を否定したんだお？

**やらない夫**：
全面否定すると、殷を倒した自分も単なる反逆者になる。
そこで周は、天は一つの家を永久に選ぶのではなく、徳を失えば命令を取り上げるという天命を語った。
革命を正当化すると同時に、自分も徳を失えば倒されうるという危険な原理を導入した。

**やる夫**：
政権交代を正当化するために作った理屈が、次の反乱軍にも使われるお！

**やらない夫**：
中国王朝史を最後まで貫く仕掛けだ。

### 1-3　周成立編――征服直後の死が内戦を招く

**やる夫**：
『封神演義（ほうしんえんぎ、Fēngshén Yǎnyì、Investiture of the Gods）』なら、悪い紂王と妲己（だっき、Dájǐ）を太公望（たいこうぼう、Tàigōng Wàng）たちが倒して、正しい周が始まるお！[^21]
王朝成立は善悪決戦だお！

**やらない夫**：
作品札を出せ。
藤崎竜版は明代小説をさらに再構成した仙人戦だ。
太公望のモデルとなる呂尚（りょしょう、Lǚ Shàng）、殷最後の王とされる帝辛、周の文王（ぶんおう、Wén Wáng）・武王（ぶおう、Wǔ Wáng）という名前を覚える入口にはなるが、宝貝や封神計画を史実へ持ち込むな。
妲己を王朝滅亡の原因とする話も、後世の「悪女が君主を狂わせた」という定型を強く含む。

**できる子**：
成立人物札を陣営と後継線で並べる。

- **殷王朝と旧殷勢力**：帝辛 → 敗死後、王子の武庚。帝辛の死で王朝は終わるが、武庚は旧殷圏の中心として周へ敵対する。
- **周の父子継承線**：姫昌（文王） → 子の姫発（武王） → 子の成王。姫昌は周を拡張したが、殷征服前に死んだため、征服は姫発へ引き継がれた。
- **周の協力者**：呂尚（太公望・姜尚〈きょうしょう、Jiāng Shàng〉）は軍事・政治を支え、周公旦（しゅうこうたん、Zhōu Gōng Dàn）は武王の弟として王家を支えた。
- **死亡から内戦への線**：武王が勝利後まもなく死ぬ → 幼い成王が即位 → 周公旦が摂政 → 武庚と管叔・蔡叔らが摂政に敵対して三監の乱。周公旦の勝利で東方支配が再編される。

**やる夫**：
武王が勝って即終了じゃないのかお？

**やらない夫**：
武王は勝利後まもなく死ぬ。
幼い成王を周公旦が補佐すると、殷の旧王族武庚（ぶこう、Wǔ Gēng）と、周側の管叔（かんしゅく、Guǎn Shū）・蔡叔（さいしゅく、Cài Shū）らが結びついて反乱する。
いわゆる三監の乱だ。
「殷を倒した連合軍」は勝利した瞬間から、戦利品、東方支配、摂政権をめぐって割れる。

**やる夫**：
周公旦が反乱を鎮圧し、洛陽＝京都付近に東方統治の拠点を作る。
京都札がいきなり「西の本拠から遠い旧殷圏を監視する副都」として出るんだお。

**やらない夫**：
そこで周は、王族と功臣を各地へ封じるだけでなく、誰が誰の祖先を祭り、誰が本家で、どの儀礼を使えるかを階層化する。
軍事同盟を親族秩序と礼の秩序へ変換した。

**やる夫**：
政策反応札だお。

**やる夫**：
周の王族・功臣は土地と地位を得るから歓迎。
殷の旧支配層は宋（そう、Sòng、state of Song）などに祭祀を残す道を与えられる者もいるけど、反乱した者や支配を失う者もいる。
在地の住民から見れば、王朝が変わっても日々の耕作は続き、貢納先と軍役の主人が変わる。
周王室から遠い封国では、数世代後に「周王の代理」より「この地方の君主」という意識が強くなるお。

**やらない夫**：
成立直後の妥協が、数百年後の分裂要因になる。
これが最初の王朝引継書だ。

### 1-4　親族へ土地を渡せば全国が家族になるのか

**やる夫**：
周は広い土地をどう治めるんだお？
通信も遅いなら、兄弟や親戚を地方へ送ればいいお。
家族なら裏切らないお！

**やらない夫**：
それが封建的な分封だ。だが日本の江戸時代の藩や中世ヨーロッパと完全に同じではない。
王族、功臣、在地勢力へ土地と儀礼上の地位を与え、軍事・貢納・祭祀の網を作る。
創業期には有効だ。

**やる夫**：
ほら成功だお！

**やらない夫**：
200年後の親戚を想像しろ。
洛陽＝京都の王室から見れば遠縁だが、地方では何世代も土地を治め、独自の軍、婚姻、祭祀、家臣を持つ。
誰への忠誠が強い？

**やる夫**：
顔も知らない京都の本家より、地元で給料をくれる君主だお……。

**やらない夫**：
春秋期になると、周王は正統性の中心ではあっても命令を強制できない。
楚（そ、Chǔ、上古音 *s-r̥aʔ）、秦、斉（せい、Qí、上古音 *[dz]ˤəj）、晋などはそれぞれ違う地域社会を統合する。
楚は長江中流の文化と中原（ちゅうげん、Zhōngyuán）の制度を組み合わせ、秦は西方の軍事国家として育ち、南方には百越（ひゃくえつ、Bǎiyuè）と総称される多様な集団がいる。

**やる夫**：
華夏対異民族という一本線じゃなく、何が華夏か自体が拡大してるんだお。
楚だって最初は南方の異質な国扱いされても、戦国（せんごく、Zhànguó、Warring States）政治の主役になっていく。

**やらない夫**：
民族境界は城壁ではない。服装、礼、言語、婚姻、政治参加によって動く。
周の仕組みは広域秩序を作ったが、成功した地方定着が中央の空洞化を生んだ。

### 1-5　世界同時刻盤――国家はどこでも同じ形になるのか

**できる夫**：
世界同時刻盤、起動します！
周が分封秩序を作るころ、日本列島は縄文後期から弥生への長い変化の途中です！
西アジアではアッシリアや後のペルシアにつながる広域帝国が、都市と異民族を軍事・道路・地方総督で束ねます！
インドではヴェーダ祭祀から諸国形成へ進み、地中海ではポリスが育ちます！

**やる夫**：
周だけが未熟な封建制から完成した中央集権へ進むわけじゃないんだお。[^15]
通信、税、軍事、宗教の条件に応じて、各地が違う組み合わせを試してる。

**やらない夫**：
そうだ。次は戦争の規模が、家族的な秩序を壊す。

## 第2幕　人間を数え、土地を測り、国家が直接命令する――戦国・秦・漢

---
### 2-1　強い国は、良い国なのか

**やる夫**：
諸侯が勝手に戦うから混乱するんだお。
一番強い国が全部征服し、法を一つにすれば平和になるお！

**やらない夫**：
戦国の各国も同じことを考えた。
鉄製農具、灌漑、人口増加、歩兵の大軍によって、戦争は貴族の戦車戦から農民を大量動員する総力戦へ変わる。
国家は家柄より、戸籍に載る人口と収穫量を欲しがる。

**やる夫**：
秦なら商鞅（しょうおう、Shāng Yāng）の改革だお。
民を戸籍に登録し、軍功で爵位を与え、連帯責任で逃亡を防ぎ、土地を耕させる。
古い貴族より国家に役立つ兵士を上げるお。

**やらない夫**：
それまでの周的な世襲秩序を否定し、君主が官僚を任命して県を治める。
成功したか？

**やる夫**：
大成功だお！
秦が六国を滅ぼしたお！

**やらない夫**：
では統一後も戦時動員を続ける。
宮殿、陵墓、道路、長城、遠征へ人を送り、厳しい法を全国へ急速に適用する。
地方の旧貴族、農民、兵士はその国家を自分の国家と思うか？

**やる夫**：
勝つために最適化した装置が、平和に切り替わらないお。
征服の成功が過剰動員を正当化し、二世代目で反乱が連鎖する……。

**やらない夫**：
秦は中央集権に失敗したのではない。[^1]
中央集権を作ることには成功し、その運用負荷と正統性の調整に失敗した。

### 2-2　秦統一編――改革者が死んでも制度が残る

**やる夫**：
『キングダム』では嬴政（えいせい、Yíng Zhèng）と信（しん、Xìn）が中華統一へ進むお！[^22]
つまり始皇帝が天才だったから秦が勝ったんだお！

**やらない夫**：
嬴政が生まれる100年以上前から始めろ。
秦の勝利は一人の英雄ではなく、何代もの君主が改革を撤回しなかった結果だ。

**できる子**：
秦側を王統、その政権を支えた者、敵対国に分ける。

- **改革を継いだ秦王統**：孝公（こうこう、Xiào Gōng） → 恵文王（けいぶんおう、Huìwén Wáng） → …… → 昭襄王（しょうじょうおう、Zhāoxiāng Wáng） → …… → 嬴政（えいせい、Yíng Zhèng、後の始皇帝〈しこうてい、Qín Shǐhuáng〉）。
- **孝公政権**：商鞅（しょうおう、Shāng Yāng）が戸籍、軍功爵、県制を進めた。孝公の死 → 保護者を失った商鞅が恵文王政権に処刑されるが、制度は廃止されず王統へ継承された。
- **昭襄王政権**：范雎（はんしょ、Fàn Jū）が外交、白起（はくき、Bái Qǐ）が軍事を担う。白起は長平（ちょうへい、Chángpíng）で趙（ちょう、Zhào）へ大打撃を与えた後、王命で自死させられ、秦は最有力将軍を失った。
- **嬴政政権**：初期は呂不韋（りょふい、Lǚ Bùwéi）、統一行政は李斯（りし、Lǐ Sī）、戦争は王翦（おうせん、Wáng Jiǎn）・王賁（おうほん、Wáng Bēn）・蒙恬（もうてん、Méng Tián）が担った。呂不韋の失脚・死後、嬴政の親政が強まる。
- **敵対した六国**：韓・趙・魏（ぎ、Wèi、上古音 *N-qʰuj-s）・楚・燕（えん、Yān）・斉。相互に競争して統一戦線を維持できず、秦に各個撃破された。
- **創業者死亡の衝撃**：始皇帝が前210年に巡幸先で死ぬ → 胡亥（こがい、Húhài）・趙高（ちょうこう、Zhào Gāo）・李斯が後継を操作 → 二世皇帝の下で粛清と過剰動員が加速し、反乱への対応力を失う。

**やる夫**：
商鞅は旧貴族の特権を削り、戦場で功績を上げた者に爵位を与える。
農民を5家・10家の単位で監視し、土地と人口を国家へ直結させる。
旧貴族は当然反発するお。

**やらない夫**：
孝公が死ぬと商鞅本人は政争に敗れて処刑される。
だが次の王は改革を廃止しなかった。
改革者を嫌っても、改革で増えた税と兵力は手放せない。
制度が個人から独立した瞬間だ。

**やる夫**：
そのあと秦は巴蜀（はしょく、Bā-Shǔ）を取り込み、四川盆地（しせんぼんち、Sìchuān Péndì）＝成都・福岡札の穀物を得る。
関中の農業、四川の生産、軍功制、道路がつながり、戦争を続けられるお。

**やらない夫**：
嬴政が親政を始めた後、秦は韓、趙、魏、楚、燕、斉を順に滅ぼす。
楚攻略では若い李信の少数兵案が失敗し、老将王翦が大軍を要求したという伝承が有名だ。
ここで重要なのは勇気の差ではなく、広い楚を占領し補給線を守る兵力の見積もりだ。

**やる夫**：
『キングダム』は人物の顔と六国の緊張を覚えるのに強い。
でも作品の信と史料上の李信の人物像は同じではないし、合戦の会話や一騎打ちは物語なんだお。

**やらない夫**：
統一後の政策と反応を並べろ。

**やる夫**：

- 郡県制：旧六国の王族・貴族は支配基盤を失って反発。中央から派遣される官僚には昇進機会。
- 文字・度量衡・貨幣・車軌などの標準化：役人と広域商人には便利。地域慣行を失う人には負担。
- 道路・運河・長城・宮殿・陵墓：軍事と物流には有効だが、農民と兵士には労役が重い。
- 武器と城郭の管理、旧貴族の移住：反乱防止には効くが、征服された地域には監視国家と映る。
- 思想統制：官僚文書を一本化しやすいが、旧国の学者や諸子百家には敵対的に映る。

**やらない夫**：
統一の利益は長期に現れ、負担は直ちに現れる。
秦は「統一して平和にする国家」から「統一後も戦時速度で動員する国家」へ変わりきれなかった。

### 2-3　漢は秦を否定したのか

**やる夫**：
漢は悪い秦を倒した善い儒教国家だお。
秦の制度は全部捨てたんだお？

**やらない夫**：
郡県、戸籍、税、官僚、皇帝号、統一法、道路網を捨てたら、漢は広域国家を運営できない。
漢は秦の機械を残し、運転方法と説明を変えた。

**やる夫**：
最初は功臣や皇族に王国も与えて、分権を少し戻したお。
でも諸侯王が強くなれば削る。
秦の反省で緩め、周の反省でまた締める……両方の失敗の間を揺れるんだお。

**やらない夫**：
武帝期には儒学を官僚の共通教養に取り込み、皇帝を徳と天命の中心として説明する。
ただし行政実務は法、刑罰、文書、監察、財政で動く。
儒家と法家を単純な善悪に分けると、漢の実像を失う。

**やる夫**：
家族では父への孝、国家では皇帝への忠。
祖先祭祀、家の序列、官僚倫理を一本につなぐから、宗教と政治と家族道徳が分離してないお。

**やらない夫**：
その仕組みは官僚の共通規範を作る一方、家父長権、女性の位置、家格、儀礼の正しさを政治問題にする。
国家は家族を利用し、家族も官職と名誉を通じて国家を利用する。

### 2-4　秦末・漢成立編――反秦連合が二陣営へ割れる

**やる夫**：
秦が倒れたら劉邦（りゅうほう、Liú Bāng）がすぐ漢を建てたんだお？
『項羽（こうう、Xiàng Yǔ）と劉邦』は2人の性格勝負だお！[^23]

**やらない夫**：
最初に立ったのは劉邦でも項羽でもない。
紀元前209年、徴発された兵士を率いる陳勝（ちんしょう、Chén Shèng）・呉広（ごこう、Wú Guǎng）が反乱する。
期限に遅れれば厳罰を受けるという恐怖と、旧六国復興の期待が各地で結びつく。

**できる子**：
反秦連合は最初から一枚岩ではない。

- **最初の反乱勢力**：陳勝（ちんしょう、Chén Shèng）・呉広（ごこう、Wú Guǎng）。蜂起が各地へ波及した後、両者が早くに死んでも反乱は止まらず、「秦へ反抗できる」という合図だけが別勢力へ継承された。
- **楚復興・項氏勢力**：項梁（こうりょう、Xiàng Liáng） → 甥の項羽（こうう、Xiàng Yǔ）。項梁の戦死後、項羽が軍事指導権を継ぎ、西楚（せいそ、Xī Chǔ）の覇王となる。項羽は劉邦陣営と敵対し、垓下（がいか、Gāixià）敗北後の自死で楚漢戦争（そかんせんそう、Chǔ-Hàn Zhànzhēng）が決着する。
- **漢王・劉邦勢力**：劉邦（りゅうほう、Liú Bāng）を、張良（ちょうりょう、Zhāng Liáng）が戦略・外交、蕭何（しょうか、Xiāo Hé）が関中（かんちゅう、Guānzhōng）の行政・兵站、韓信（かんしん、Hán Xìn）が別働軍、陳平（ちんぺい、Chén Píng）が交渉・離間で支えた。
- **後継関係のねじれ**：劉邦の皇帝即位後、韓信ら異姓王は創業の協力者から中央集権の潜在的敵へ変わる。韓信の処刑は、反秦連合の分権的な功臣体制から劉氏中心の皇帝国家へ移ったことを示す。

**やる夫**：
劉邦は咸陽（かんよう、Xiányáng）へ入り、秦王子嬰（しえい、Zǐyīng）を降伏させる。
そこで秦の帳簿や地図を蕭何が確保する。
項羽が旧秦への復讐と戦功の配分を優先するのに対し、蕭何は「次の国家を動かすデータ」を取るんだお。

**やらない夫**：
項羽は秦を滅ぼした後、天下を18の王国へ分ける。
戦国諸国を復活させつつ、自分に近い将軍へ土地を配ったため、旧王家、功臣、在地勢力の期待が衝突する。
劉邦は辺境の漢中（かんちゅう、Hànzhōng）へ追いやられるが、韓信を用いて関中へ戻り、楚漢戦争が始まる。

**やる夫**：
項羽は正面戦で何度も強い。
劉邦は彭城（ほうじょう、Péngchéng）で大敗しても、蕭何が関中から兵と食糧を送り、韓信が北方の諸国を落とし、張良と陳平が同盟を組み替える。
最後は垓下で項羽が包囲され、紀元前202年に劉邦が皇帝になる。
個人の武勇より、後方を失わない連合が勝ったんだお。

**やらない夫**：
横山光輝『項羽と劉邦』は役割分担をつかむ入口になる。
ただし項羽を高潔な武人、劉邦を人を使う庶民的指導者として対比する構図は、史料の選択と物語化を含む。

**やる夫**：
漢初の政策反応札だお。

- 秦の苛酷と見られた法・労役を緩める：農民と兵士には歓迎されやすい。
- 郡県と封国を併用する：功臣・皇族は王になれて満足するが、中央には将来の独立勢力になる。
- 税率と宮廷支出を抑える：小農の再建に有利だが、辺境軍事には資金不足。
- 秦の官僚・文書を継承する：実務官僚には国家継続、旧六国復興派には秦の再来にも見える。

**やらない夫**：
その後、文帝（ぶんてい、Wén Dì）・景帝（けいてい、Jǐng Dì）期には倹約と減税が評価される一方、諸侯王の領地を削る政策が呉楚七国の乱（ごそしちこくのらん、Wú-Chǔ Qīguó zhī Luàn）を招く。
武帝は塩鉄専売、貨幣統制、均輸・平準、遠征、屯田を進める。
中央官僚と軍は資源を得るが、商人は国家競争を嫌い、農民は兵役と税負担を感じ、辺境入植者は土地を得る代わりに危険を負う。
善政か悪政かではなく、誰の安全と財源を優先したかで評価が割れる。

### 2-5　匈奴は国境の外の盗賊なのか

**やる夫**：
北の匈奴は、農耕地を略奪するだけの集団だお。
長城を高くして追い払えば終わりだお！

**やらない夫**：
匈奴を一つの草原帝国として見ろ。[^16]
牧畜では家畜を季節ごとに移動させる。首長は部下へ戦利品、絹、穀物、婚姻関係を配り、連合を維持する。
固定農地から税を取る漢とは財政の仕組みが違う。

**やる夫**：
漢が交易を閉じれば、匈奴の首長は配る品を失って弱くなる……と思ったら、国境を襲って品を取る圧力が増すお。
贈り物を出せば平和になるけど、漢の朝廷では屈辱だと批判される。

**やらない夫**：
軍事、互市、和親、称号、贈与はすべて外交手段だ。
ローマ帝国がゲルマン諸集団へ軍務と補助金を与えた関係にも少し似る。
国境は文明と野蛮の線ではなく、人、馬、穀物、絹、情報が出入りする市場だ。

**やる夫**：
匈奴の一部が漢へ降り、漢の爵位をもらい、国境内に住むこともある。
漢人が匈奴側へ逃げることもある。
民族の線より、どの君主に属し、どの軍団と戸籍に入るかが動いてるお。

**やらない夫**：
東北には烏桓（うがん、Wūhuán、Wuhuan）や鮮卑、西には羌（きょう、Qiāng、Qiang、上古音 *C.qʰaŋ）と総称される多様な集団、南には百越の諸社会がある。
漢は彼らを一律に県民化できず、首長への称号、交易、移住、軍役、郡県化を組み合わせる。

**できる子**：
系譜札。
匈奴の一部は分裂後に漢領へ入り、後の五胡十六国（ごこじゅうろっこく、Wǔ Hú Shíliù Guó、Sixteen Kingdoms）でも匈奴系を称する政権が現れる。
しかし匈奴から突厥、契丹、モンゴルへ一直線の民族系譜を引くことはできない。
継承されたのは人の一部、草原の政治技術、称号、軍事編成であり、同じ民族の名称変更ではない。

### 2-6　繁栄した漢は、なぜ戸籍から人を失うのか

**やる夫**：
漢は秦より穏やかに統治し、儒教も入れた。
これで永久政権だお！

**やらない夫**：
土地を失った農民が大地主の保護下へ入ると、国家の戸籍からどう見える？

**やる夫**：
税を払う小農が減るお。
でも豪族の荘園では働いてる。人口が消えたんじゃなく、国家が直接つかめなくなったお。

**やらない夫**：
地方豪族は治安、貸付、灌漑、裁判、教育を担う。
中央から見れば脱税の原因だが、村人から見れば実際に頼れる政府でもある。
宮廷では外戚、宦官、官僚が幼帝へのアクセスを争う。
辺境軍事と災害救済で財政が傷み、黄巾の乱（こうきんのらん、Huángjīn zhī Luàn）などが起こる。

**やる夫**：
制度が腐敗した、で終えると何も分からないお。
小農を直接把握する制度が、土地集積と人口移動で現実からずれた。
皇帝中心の制度が、皇帝が幼い時の代理権争いを激化させた。
成功した設計が環境変化で弱点に変わったんだお。

### 2-7　世界同時刻盤――漢はローマと隣国だったのか

**できる夫**：
漢の時代、日本は弥生から古墳社会へ進みます！
西ではローマ帝国、間にはパルティアやクシャーナ朝、インド洋には南アジアと東アフリカを結ぶ商船、東南アジアには扶南などの港市国家が育ちます！

**やる夫**：
漢とローマが直接会議するわけじゃないけど、絹、ガラス、香料、馬、宗教、感染症が中継地を通る。
ソグド人が本格的に活躍する前から、ユーラシアは鎖のようにつながってるお。

**やらない夫**：
そして漢の崩壊後、その鎖から来た人々と中国北部の住民が、新しい国を作る。

## 第3幕　五胡は中国を壊したのか、作り替えたのか――三国・晋・十六国・南北朝・隋

### 3-1　漢を復活させれば済むのか

**やる夫**：
三国（さんごく、Sānguó、Three Kingdoms）を統一した晋が漢の制度を復活させれば、乱世は終わるお！

**やらない夫**：
司馬氏は有力皇族へ軍事力を持たせ、簒奪を防ごうとした。
皇族なら王朝を守るという周と同じ期待だ。

**やる夫**：
でも八王の乱で皇族同士が戦うお！
反乱を防ぐための皇族軍が、内戦の主役になるお！

**やらない夫**：
その戦争へ、漢以来国境内に移住していた匈奴、羯（けつ、Jié）、鮮卑、氐（てい、Dī）、羌などの軍事集団も巻き込まれる。
ただし五胡という語は、後世が複雑な集団を5分類にまとめた呼び方だ。
全員が同時に一枚岩で漢人へ侵入したわけではない。

**やる夫**：
ここで名前を漏らさず整理するお。
匈奴、鮮卑、羯、氐、羌だお。

**できる子**：
系譜札を更新する。

**できる子**：
匈奴。
漢代の草原帝国の後、一部集団が華北へ移住し、漢・前趙などの政権に関与した。
ただし政権の住民は匈奴だけではない。

**できる子**：
鮮卑。
東北からモンゴル高原東部に広がった複数集団の総称。慕容、拓跋、宇文などが別々の政権を作る。
後の契丹との歴史的連関が論じられるが、鮮卑全体が契丹やモンゴルへそのまま変わったわけではない。

**できる子**：
羯。
後趙の支配層に関わるが、起源と言語は確定しない。
中央アジア系の可能性を含む複数説があり、後世に同じ名の大集団として続かない。

**できる子**：
氐。
関中・甘粛・四川周辺の農耕と牧畜を組み合わせた諸集団に使われた名称。前秦や成漢を建てた人々を含む。

**できる子**：
羌。
西北・チベット高原東縁の多様な集団に長期間使われた広い名称。後秦などに関わる。
現代の羌族と古代史料の羌を一対一で結べない。

**やる夫**：
五胡という5チームが外から一斉に攻めた図じゃないんだお。
何世代も漢領内に住み、漢語を使い、軍役を負い、漢風の国号を名乗る者もいる。
一方で独自の部族組織や言語も残す。

**やらない夫**：
ヨーロッパなら、西ローマ帝国内のゴート人部隊、ローマ化した将軍、地方住民、移住集団が、ローマ皇帝の称号やキリスト教を利用して複数王国を作る状況に近い。
外から文明を壊す一方向の話ではない。

### 3-2　三国・晋成立編――地方軍から三王朝、さらに簒奪へ

**やる夫**：
ここは『三国志』の知識があるお！
桃園（とうえん、Táoyuán）の誓い、曹操（そうそう、Cáo Cāo）、劉備（りゅうび、Liú Bèi）、孫権（そんけん、Sūn Quán）、諸葛亮（しょかつりょう、Zhūgě Liàng）、赤壁（せきへき、Chìbì）だお！

**やらない夫**：
まず作品を2層に分ける。
陳寿（ちんじゅ、Chén Shòu）の正史『三国志（さんごくし、Sānguózhì、Records of the Three Kingdoms）』は3世紀の歴史書。[^24]
後世の小説『三国志演義』は忠義、策略、因果応報を強くした物語で、横山光輝版は主にその世界を漫画化している。
人物名を覚えるには強いが、蜀漢（しょくかん、Shǔ Hàn、Shu Han）中心の善悪評価をそのまま制度史にしない。

**できる子**：
後漢崩壊から晋統一までを、勢力ごとの後継線で置く。

- **反乱と後漢宮廷**：張角（ちょうかく、Zhāng Jiǎo）の太平道（たいへいどう、Tàipíng Dào）が黄巾の乱を起こす → 鎮圧のため地方軍が成長。董卓（とうたく、Dǒng Zhuó）が献帝（けんてい、Xiàn Dì）を掌握 → 董卓の死後も軍閥抗争は収まらない。
- **曹氏・魏**：曹操（そうそう、Cáo Cāo） → 子の曹丕（そうひ、Cáo Pī）。曹操は献帝を保護下に置き、官渡（かんと、Guāndù）で袁紹（えんしょう、Yuán Shào）を破る。曹操の死後、曹丕が献帝から禅譲を受け魏を建てた。
- **劉氏・蜀漢**：劉備（りゅうび、Liú Bèi） → 子の劉禅（りゅうぜん、Liú Shàn）。劉備を諸葛亮（しょかつりょう、Zhūgě Liàng）が支え、劉備の死後は幼い劉禅を補佐した。関羽（かんう、Guān Yǔ）の敗死は荊州同盟を壊し、劉備の対呉戦争へ連鎖した。
- **孫氏・呉（ご、Wú）**：孫策（そんさく、Sūn Cè） → 弟の孫権（そんけん、Sūn Quán）。孫策の急死後、孫権が江東（こうとう、Jiāngdōng）を継ぎ、周瑜（しゅうゆ、Zhōu Yú）・魯粛（ろしゅく、Lǔ Sù）が軍事と劉備との同盟を担った。
- **司馬氏・晋**：司馬懿（しばい、Sīmǎ Yì） → 子の司馬師（しばし、Sīmǎ Shī） → 弟の司馬昭（しばしょう、Sīmǎ Zhāo） → 子の司馬炎（しばえん、Sīmǎ Yán）。司馬昭の死後、司馬炎が魏から禅譲を受け晋を建て、280年に呉を滅ぼした。
- **敵対線**：曹氏・劉氏・孫氏が三国として競争し、その魏内部で司馬氏が曹氏の実権を奪う。晋は魏の敵国を倒しただけでなく、魏の中から王統を置き換えて成立した。

**やる夫**：
黄巾の乱を鎮圧するため、地方官と豪族が私兵を増やす。
中央を救うための地方武装が、中央崩壊後の軍閥になるお。
董卓が洛陽＝京都へ入り、献帝を長安＝奈良へ移すと、都の権威と軍事力が完全に分かれる。

**やらない夫**：
曹操は献帝を許昌（きょしょう、Xǔchāng）へ迎え、「皇帝の命令」という正統性を使って諸侯を討つ。
同時に屯田で流民と兵士へ土地・種を与え、収穫の一部を国家が取る。
荒地が回復し兵站は安定するが、屯田民は一般戸籍より強い国家管理を受ける。

**やる夫**：
官渡で袁紹に勝ち華北を統合した曹操が南下する。
劉備と孫権が臨時同盟を結び、208年の赤壁で止める。
映画『レッドクリフ』は同盟交渉と水上戦の緊張を見せるけど、周瑜・諸葛亮・女性人物の役割や時間順序は映画用に再構成されているお。[^25]

**やらない夫**：
赤壁はその場で三国を成立させた戦いではない。
曹操が華北、孫権が江東、劉備が後に益州を確保する可能性を残した戦いだ。
220年に曹丕が漢から帝位を受け魏を建て、221年に劉備が漢の継承を主張し、229年に孫権が皇帝を称して三国が揃う。

**やる夫**：
政策反応札だお。

- 魏の屯田と戸籍再編：流民には生存手段、国家には穀物、豪族には労働力を奪われる不満。
- 九品官人法：地方の人物評価を制度化するが、名門が評価を独占すると家格制度へ傾く。
- 蜀漢の軍事国家化：益州豪族と旧劉備集団の協力が必要。北伐の負担を農民が支える。
- 呉の江南開発と水軍：山越と総称された在地集団を征討・移住・兵士化し、豪族には新田開発の機会と緊張を生む。

**やらない夫**：
魏を奪った司馬氏は、自分と同じ簒奪者を防ぐため皇族へ兵力を与える。
晋統一を歓迎した民衆も、税制と身分秩序が安定する前に八王の乱へ巻き込まれる。
三国の英雄物語は終わっても、地方軍と名門家格という問題はそのまま晋へ渡る。

### 3-3　南京＝大阪へ逃げた朝廷は、中国なのか

**やる夫**：
晋の皇族と名門が南へ逃げ、建康＝大阪に東晋を作る。
北を失ったなら、もう地方政権だお？

**やらない夫**：
彼ら自身は正統な晋の継承者だと考える。
大阪に京都の朝廷と東北の名門が大挙して移り、地元の豪族と土地を分け合う場面を想像しろ。

**やる夫**：
北から来た名門は家柄を誇るけど、米と船と労働力を持つのは江南の在地社会だお。
両者が婚姻し、対立し、長江下流を開発する。
中国の経済重心が南へ動く入口になるお。

**やらない夫**：
言葉も違う。
北方から来た官僚の発音と、呉地域の住民の日常語は同じではない。
文書と古典を共有しても、村での会話、歌、親族慣行は別だ。

**やる夫**：
大阪に亡命した政府が、ラテン語文書で官僚制を動かしつつ、地元ではイタリア語やフランス語ほど違う言葉が話される感じかお。

**やらない夫**：
完全な対応ではないが、日本人が多言語性を想像するにはそのくらい離してよい。
「方言」という日本語から受ける、少し訛っただけという印象を捨てろ。

### 3-4　北魏は漢化して成功したのか

**やる夫**：
北では拓跋鮮卑の北魏（ほくぎ、Běi Wèi、Northern Wei）が統一する。
異民族王朝が中国文化を学び、漢人になったから成功したんだお！

**やらない夫**：
それでは変化を一方向にしすぎる。
北魏は鮮卑の軍事組織、移住民の配置、華北の戸籍・官僚制、仏教の権威を組み合わせた。[^2]
洛陽＝京都へ遷都し、漢風の姓、服装、官制を推進したのは事実だが、国家と社会の全員が同じ速度で変わったわけではない。

**やる夫**：
北の軍事拠点に残された鮮卑系兵士から見れば、京都の宮廷だけが上品な漢風になり、自分たちは辺境で貧しくなる。
六鎮の乱につながる不満だお。

**やらない夫**：
漢化政策は統合策であると同時に、旧軍事共同体の地位を下げる再分配だった。
その後、東魏（とうぎ、Dōng Wèi、Eastern Wei）・西魏（せいぎ、Xī Wèi、Western Wei）、北斉（ほくせい、Běi Qí、Northern Qi）・北周（ほくしゅう、Běi Zhōu、Northern Zhou）へ分かれ、北周系の軍事貴族から隋唐の支配層が出る。

**できる子**：
鮮卑は消滅したのではない。
多くが漢語話者の戸籍や貴族家へ入り、別の政治名の下で存続した。
宇文氏などの名は北周へ、拓跋系の制度は隋唐の軍事・土地制度へ影響する。
民族名が消えることと、人や制度が消えることは別。

### 3-5　十六国・北魏成立編――一斉侵入ではなく、競合する連合国家

**やる夫**：
五胡十六国は国名が多すぎるお。
「異民族が順番に侵入した」でまとめたいお！

**やらない夫**：
成立人物を追えば、一斉侵入ではないと分かる。

**できる子**：
十六国を一列にせず、競争した政権ごとに置く。

- **匈奴系・漢／前趙**：劉淵（りゅうえん、Liú Yuān）が晋領内の軍事集団を基礎に漢王を称した。劉淵の死後は子らの継承争いを経て政権が前趙（ぜんちょう、Qián Zhào）へ続くが、石勒（せきろく、Shí Lè）の後趙と敵対して滅ぶ。
- **羯系・後趙**：石勒（せきろく、Shí Lè）が捕虜・流民・軍事集団から台頭し後趙（こうちょう、Hòu Zhào）を建てた。石勒の死後、石虎（せきこ、Shí Hǔ）が権力を奪い、その死後の継承内戦で後趙が急速に崩れた。
- **氐系・前秦**：苻堅（ふけん、Fú Jiān）を王猛（おうもう、Wáng Měng）が法・財政・軍事で支え、華北を一時統一した。王猛の死はただちに崩壊を招かなかったが、南征を慎む有力な補佐役を失い、淝水（ひすい、Féishuǐ）敗戦後は慕容氏（ぼようし、Mùróng shì）など従属勢力が離反した。
- **鮮卑系・北魏**：拓跋珪（たくばつけい、Tuòbá Guī） → 拓跋王統 → 馮太后（ふうたいごう、Féng Tàihòu）の摂政 → 孝文帝（こうぶんてい、Xiàowén Dì）。均田・三長制から洛陽遷都へ改革が継承された。
- **南朝の対抗線**：東晋では劉裕（りゅうゆう、Liú Yù）が軍功で台頭し、420年に帝位を奪って宋（そう、Sòng、中古音 sowngH）を建てた。北の諸政権と敵対しつつ、南でも皇帝家が交代する。

**やる夫**：
劉淵は漢の皇族との婚姻や臣従の記憶を使い、「漢」を名乗る。
石勒も漢人官僚を使う。
前秦の苻堅は氐だけの王ではなく、王猛を宰相にして多民族の華北国家を作る。
民族国家というより、軍事連合が中国皇帝の制度を取り込むんだお。

**やらない夫**：
苻堅は華北統一後、383年に東晋を倒そうとして淝水で敗れる。
敗北そのものより、従属していた鮮卑・羌などの指導者が「前秦はもう配分と保護を保証できない」と判断し、離脱したことが崩壊を速めた。
連合帝国は軍事的威信が財政でもある。

**やる夫**：
北魏は439年に華北を統一する。
国家が耕地を把握して農民へ配分する均田制、村を5家・25家・125家の階層でまとめる三長制を進める。

**やらない夫**：
反応を分けろ。

**やる夫**：
戦乱で土地を失った農民には、登録されれば耕地と保護を得る可能性がある。
国家は戸籍と税を回復できる。
大土地所有者や寺院は隠していた戸口を失うので抵抗する。
村の有力者は三長に任命されれば国家権力の末端になれるが、徴税責任も負う。
鮮卑系軍人は宮廷の洛陽移転と漢風官制を、昇進機会と見る者も、旧来の地位を奪う政策と見る者もいるお。

**やらない夫**：
南朝でも、劉裕のような軍人が名門貴族を抑えながら王朝を交代させる。
宋、斉、梁、陳と皇帝家は変わるが、建康＝大阪の官僚・貴族・寺院・商業社会は続く。
北の王朝名が変わるたびに人が入れ替わるわけでも、南の王朝が同じ国家のままでもない。

### 3-6　仏教は外国宗教だから受け入れられないのか

戦乱、飢饉、短命な王朝の世界で、祖先と国家だけで死後や苦難を説明できるか？

**やる夫**：
仏教は王朝が滅びても続く宇宙観、来世、因果、救済、僧院共同体を与える。
皇帝にとっても巨大仏像や寺院を作れば、言語や出自の違う臣民を仏法で包めるお。

**やらない夫**：
一方で僧院は土地と労働力を集め、課税や兵役から外れることがある。
国家は保護と弾圧を繰り返す。

今度こそ成功例を学び、無理をしなければいいお。

**やらない夫**：

南北統一という新環境に必要なインフラだお。

**やらない夫**：
同時に宮殿、運河、東方遠征を進めたら？

**やる夫**：

秦と同じだお！

**やらない夫**：

### 3-8　隋再統一編――北の軍事国家が南の戸籍と水運を継ぐ

**やる夫**：
隋の成立は、北朝が強くなって南朝を倒した、で終わりじゃないのかお？

**やらない夫**：
北周の外戚だった楊堅（ようけん、Yáng Jiān）が、幼い皇帝の摂政から実権を握り、581年に帝位を奪って隋を建てる。
妻の独孤伽羅（どっこから、Dúgū Qiéluó）は皇后として後継・宮廷政治へ強い影響を持った。
楊堅は文帝、子の楊広（ようこう、Yáng Guǎng）は煬帝となる。

**できる子**：
再統一を、隋王家・協力者・敵対王朝で分ける。

- **北周から隋への王統線**：北周（ほくしゅう、Běi Zhōu）の外戚だった楊堅（ようけん、Yáng Jiān、文帝〈ぶんてい、Wén Dì〉） → 子の楊広（ようこう、Yáng Guǎng、煬帝〈ようだい、Yáng Dì〉）。楊堅は幼帝の摂政から帝位を奪い、北周の制度と軍事基盤を継承した。
- **楊堅政権**：皇后の独孤伽羅（どっこから、Dúgū Qiéluó）が後継政治へ影響し、高熲（こうけい、Gāo Jiǒng）が行政と戦略、賀若弼（がじゃくひつ、Hèruò Bì）・韓擒虎（かんきんこ、Hán Qínhǔ）が南征を担った。
- **南朝陳の敵対勢力**：陳（ちん、Chén、中古音 drin）の後主・陳叔宝（ちんしゅくほう、Chén Shūbǎo）。589年に隋軍へ降伏し、南北の皇帝対立が終わった。
- **死亡と継承の衝撃**：独孤伽羅の死後、宮廷の均衡が変わり、楊広が即位した。煬帝が618年に反乱軍側の将兵に殺されると、隋の名を掲げる求心力が失われ、李淵（りえん、Lǐ Yuān）ら競争者が各地の軍と官僚を奪い合った。

**やる夫**：
文帝は南朝陳を倒しても、南方官僚を全員追放せず、旧陳の戸籍と人材を取り込む。
北の律令と軍事、南の穀物と水運を接続するお。

**やらない夫**：
開皇律は刑罰体系を整理し、中央では三省六部につながる官制を整え、州県を簡素化する。
戸籍の再調査、均田、租税、義倉も進める。

**やる夫**：
政策反応札。

- 統一と法の整理：長年の国境が消え、商人・旅行者・官僚には便利。
- 戸籍再調査：登録から漏れていた民や豪族には負担、土地を認められる小農には保護。
- 義倉：平時の穀物拠出は負担だが、飢饉時には救済になる。
- 南北官僚の統合：旧北朝人には地位競争、旧南朝人には征服された不安と中央進出の機会。

**やらない夫**：
煬帝は長安＝奈良だけでなく洛陽＝京都を大規模な東都とし、大運河を整備する。
都の食料、北方軍、江南経済を結ぶ合理的な政策だ。
だが建設時の労役、高句麗遠征、巡幸、宮殿建設が同時に重なり、合理的な事業の合計が耐えられない負担になる。

**やる夫**：
一つずつなら必要でも、全部を同じ世代にやれば民衆には「統一の利益」より徴発が先に来る。
地方反乱軍には旧貴族、官僚、農民、軍人が混ざり、次の唐の創業者もその一人になるんだお。

### 4-1　唐は純粋な漢人王朝へ戻ったのか

**やる夫**：
隋を倒した唐は、外国風になった北朝を終わらせて漢の中国へ戻したんだお？

**やらない夫**：
唐の皇室と支配層は、北周・隋へ続く西北の軍事貴族社会から出た。[^4]
漢語と儒教古典を使う一方、鮮卑系を含む北方諸集団との婚姻、騎馬軍事、草原的な称号感覚にも親しい。
「漢人か胡人か」を現代の国籍のように二択にすると理解できない。

**やる夫**：
唐太宗が中国皇帝であると同時に、草原側から天可汗と呼ばれるのも、二重の正統性なんだお。
ヨーロッパで一人の君主がローマ皇帝とドイツ王とイタリア王を兼ねる感じだお。

**やらない夫**：
その比喩でよい。
唐は隋の制度を否定する物語を作るが、奈良＝長安、京都＝洛陽、大運河、律令、官僚制、科挙、土地・兵役制度を継承する。
新しいのは、それらを北方・中央アジアとの大規模な外交と軍事へ接続したことだ。

**やる夫**：
奈良の都に、朝鮮人、日本人、ソグド人、ペルシア人、インド僧、テュルク系兵士が住み、街では複数言語が飛び交う。
日本史の奈良に、コンスタンティノープルとバグダードの国際性を足した感じだお。

### 4-2　唐成立編――統一戦争の後にも続いた王家の内戦

**やる夫**：
隋が倒れたら唐高祖李淵が即位し、名君太宗が完成させたんだお。

**やらない夫**：
隋末には李密、竇建徳、王世充、梁師都など多数の勢力がいる。
李淵は617年に太原（たいげん、Tàiyuán）で挙兵し、長安＝奈良を取り、618年に唐を建てたにすぎない。
全国支配はその後の戦争で作られる。

**できる子**：
唐王家、統一戦争の敵、政権を支えた集団に分ける。

- **隋末の競争勢力**：李密（りみつ、Lǐ Mì）、竇建徳（とうけんとく、Dòu Jiàndé）、王世充（おうせいじゅう、Wáng Shìchōng）、梁師都（りょうしと、Liáng Shīdū）らが別々の軍・都市・税源を持ち、李氏勢力と敵対した。
- **唐の父子線**：李淵（りえん、Lǐ Yuān、高祖〈こうそ、Gāozǔ〉） → 子の李世民（りせいみん、Lǐ Shìmín、太宗〈たいそう、Tàizōng〉） → …… → 高宗（こうそう、Gāozōng）。李世民は統一戦争の主力だが、玄武門（げんぶもん、Xuánwǔmén）で兄の李建成（りけんせい、Lǐ Jiànchéng）と弟の李元吉（りげんきつ、Lǐ Yuánjí）を殺し、父に譲位を迫って後継となった。
- **太宗政権**：房玄齢（ぼうげんれい、Fáng Xuánlíng）・杜如晦（とじょかい、Dù Rúhuì）が政策、魏徴（ぎちょう、Wèi Zhēng）が諫言、長孫無忌（ちょうそんむき、Zhǎngsūn Wújì）が外戚・重臣として支えた。
- **女帝の周**：高宗の皇后だった武則天（ぶそくてん、Wǔ Zétiān）が、高宗の死後に子の皇帝たちを介して権力を握り、690年に周を建てて李氏王統を一時中断した。
- **武則天後の李氏復帰**：李隆基（りりゅうき、Lǐ Lóngjī、玄宗〈げんそう、Xuánzōng〉）が政争を勝ち抜き、唐王統を安定させた。後半には安禄山（あんろくざん、Ān Lùshān）が唐の辺境軍から反乱勢力へ転じ、反乱中に殺されても配下の軍事政権はすぐには消えなかった。

**やる夫**：
李世民は虎牢（ころう、Hǔláo）の戦いで王世充と竇建徳を破り、東方の主要勢力を崩す。
でも統一後、兄の皇太子李建成との後継争いがあり、玄武門で兄弟を殺して父から帝位を譲らせる。
名君伝説の前に、創業家の内戦があるお。

**やらない夫**：
太宗はその正統性の弱さを、官僚の諫言を聞く君主、律令を守る君主、国外勢力を包摂する天可汗という複数の姿で補う。

**やる夫**：
初期政策の反応札だお。

- 均田・租庸調：登録小農には土地利用の根拠、国家には税と労役。人口移動や土地集中が進むと帳簿と現実がずれる。
- 府兵制：農民兵に土地と地位を与える一方、遠征が長期化すると農業と両立しない。
- 唐律：官僚には統一基準、家族秩序を法に組み込まれる女性・奴婢・被支配者には非対称な秩序。
- 科挙：地方の学者に中央進出の道を開くが、教育資源を持つ家が有利。
- 国際交易と宗教保護：商人、ソグド人、仏僧には機会。排外感情や財政危機時には攻撃対象にもなる。

**やらない夫**：
武則天は旧来の関隴貴族や李氏皇族を抑え、科挙出身者や新しい官僚を登用する。
旧名門には簒奪者、新興官僚には上昇機会、仏教勢力には保護者と映る。
女性皇帝だったことだけでなく、人事市場を組み替えたから強い抵抗と支持を同時に生んだ。

**やる夫**：
玄宗初期は財政・官僚制を整えるけど、辺境戦争が常態化すると節度使へ兵と財源を集中する。
安禄山はソグド系・突厥系の背景を持つ軍人で、唐の多民族軍事システムから出世した。
反乱は「外国人が唐を裏切った」より、帝国が作った巨大辺境軍が中央政治へ反転した事件なんだお。

### 4-3　突厥は匈奴の復活なのか

**やる夫**：
匈奴の次に突厥が草原を支配したなら、匈奴が名前を変えたんだお？

**できる子**：
直結できない。
匈奴帝国崩壊後の草原では、鮮卑、柔然（じゅうぜん、Róurán、Rouran）など複数の連合が興亡した。
6世紀に突厥が柔然を倒し、テュルク語系の可汗国を作った。[^17]
同じ草原政治の技術を利用しても、政治共同体と言語系統は別に確認する必要がある。

**やる夫**：
柔然はどこへ行ったんだお？

**できる子**：
一部は突厥へ編入され、一部は移動したと考えられる。
ヨーロッパのアヴァールとの関係は有力説の一つだが確定ではない。
「国名が消えた＝全員死亡」ではない。

**やらない夫**：
唐は東突厥を軍事的に破り、草原の集団を内地へ移し、首長へ唐の官位を与え、都の軍へ編入する。
しかし唐が直接、草原の全家畜と全遊牧民を県のように管理したわけではない。

**やる夫**：
草原の首長から見ると、唐皇帝は外国の敵だけでなく、爵位と絹を配る上位首長にもなる。
唐の官位を持ったまま自分の部族を率つ者もいるお。

**やらない夫**：
唐の辺境統治は、フランスの県制より、ハプスブルク皇帝がハンガリー貴族やクロアチア軍事境界を別契約で束ねる仕組みに近い。
地域ごとに同じ法律をそのまま適用しない。

### 4-4　ソグド人は商人であり、軍人であり、中国人でもある

**やる夫**：
シルクロードは中国人とローマ人が一本道で絹を売買する道だお？

**やらない夫**：
長距離交易は多数の中継者で動く。
ソグド人はサマルカンドなどを中心とするイラン系言語の都市民で、交易植民地を中央アジアから中国北部まで作った。[^5]

**やる夫**：
ペルシア語系を話し、ゾロアスター教、仏教、マニ教などを持ち込み、漢姓を名乗り、唐の軍人や官僚にもなる。
「外国商人」という職業だけでは括れないお。

**やらない夫**：
安禄山の「安」はソグド系出自を示す姓と関係するが、本人は多民族的な辺境軍事社会で育った。
反乱を「外国人が唐を裏切った」とだけ説明すると、唐軍側にも多数の非漢人兵士がいたこと、反乱側にも漢人官僚や兵士がいたことを失う。

**できる子**：
系譜札。
ソグド国家が消えた後、ソグド系住民は中国、中央アジア、イスラム圏へ同化し、ソグド人という独立した民族名は薄れる。
しかし商業網、音楽、銀器、宗教語彙、家系は各地へ残る。

**やる夫**：
民族が残る方法は、同じ旗を1000年掲げることだけじゃないんだお。
別の言語と戸籍へ入りながら、文化や家族の断片が残る。

### 4-5　吐蕃・回鶻・南詔は唐の地方勢力なのか

**やる夫**：
唐の地図が広いなら、周辺国は全部朝貢する属国だお？

**やらない夫**：
朝貢文書の上下表現と、現実の軍事力を分けろ。
吐蕃（とばん、Tǔbō、Tibetan Empire）はチベット高原を統一した強国で、唐と婚姻も戦争も行い、一時は奈良＝長安を占領する。
唐から見た「蕃」でも、独自の王権、軍、文字、外交を持つ帝国だ。

**やる夫**：
回鶻（かいこつ、Huíhú、Uyghur Khaganate）は突厥を倒したテュルク語系の可汗国で、安史の乱（あんしのらん、Ān-Shǐ zhī Luàn）では唐を助ける。
援軍の代価として絹と交易特権を得る。
唐が一方的に支配してるんじゃなく、弱った唐が草原帝国を雇ってるお。

**できる子**：
回鶻可汗国が崩壊すると、集団の一部は甘州、天山北部、タリム盆地へ移る。
そこでオアシス住民と混合し、仏教・マニ教・後にはイスラムを受容する。
現代ウイグル人形成への重要な一要素だが、8世紀回鶻の全員がそのまま現代まで移動したわけではない。

**やらない夫**：
南西の南詔（なんしょう、Nánzhào、Nanzhao）も、唐の一県ではない。
雲南の複数集団を束ね、唐と吐蕃の間で同盟を変え、東南アジアとも接続する。
後の大理国や現代の白族・彝族などとの歴史的関係はあるが、一民族国家として単純化できない。

**やる夫**：
中国周辺は空白地帯じゃなく、別の国家と交易圏が並ぶ。
唐の「天下」は外交文書上の世界観で、実際の主権地図とは違うお。

---
### 4-6　強い辺境軍を置けば安全なのか

**やる夫**：
吐蕃、突厥、契丹がいるなら、国境ごとに強い将軍を置けばいいお。
現地判断で兵を動かせる節度使だお！

**やらない夫**：
初期の府兵制は、国家が土地と農民兵を把握する前提だった。
土地所有と人口移動が変わり、長期遠征が増えると、兵農一致は維持できない。
そこで職業兵と辺境司令官へ依存する。

**やる夫**：
節度使は現地の兵、財源、部下の人事を握る。
外敵には強いけど、中央が弱ると自分が王になれるお。

**やらない夫**：
安史の乱後、唐は反乱を鎮圧するため、さらに別の節度使へ権限を与える。
問題を解くため問題の原因を増やす。

**やる夫**：
中央は軍人を信用できず、宦官に禁軍を預ける。
皇帝に家族を持たない宦官なら世襲しないと思ったら、宮廷へのアクセスを独占するお。

**やらない夫**：
土地と人口を直接把握できなくなると、租庸調から両税法へ移り、現実の資産と居住地を基準に夏秋2回徴税する。
これは制度の崩壊ではなく、旧前提を捨てた適応だ。
ただし地方軍、塩税、宦官、官僚の利害を一つへ戻せず、唐は緩やかに解体する。

---
### 4-7　世界同時刻盤――奈良の都は世界の端だったのか

**できる夫**：
唐の前半、日本は飛鳥・奈良時代から平安初期へ進み、律令、仏教、都城、漢字文化を受容します！
朝鮮半島には新羅、北東には渤海があります！
中東ではサーサーン朝がイスラム勢力に倒れ、ウマイヤ朝、アッバース朝へ！
インドでは諸王朝、東南アジアではシュリーヴィジャヤ、アフリカ東岸ではインド洋交易が発展します！
ヨーロッパではビザンツ帝国、フランク王国、後のカロリング帝国です！

**やる夫**：
奈良時代の日本から見ると唐が世界の中心に見える。
でも唐自身も、馬は草原、宝石と宗教は中央アジア・インド、香料は東南アジア、銀器様式はイラン世界から取り込む巨大な接続点なんだお。

**やらない夫**：
次の時代、中国は一つの帝国ではなく、複数の皇帝国家が対等に並ぶ。

## 第5幕　中国は一国ではなく、国際社会だった――五代・宋・遼・西夏・金

---
### 5-1　宋が統一したのに、なぜ遼へ歳幣を払うのか

**やる夫**：
唐滅亡後の五代十国（ごだいじっこく、Wǔdài Shíguó、Five Dynasties and Ten Kingdoms）を宋がまとめた。
中国統一の完成だお！
あとは北の少数民族を服属させるだけだお。

**やらない夫**：
その言い方は宋の立場だけを採用している。
北には契丹の遼があり、皇帝を称し、独自の年号、官僚、文字、軍、外交秩序を持つ。
宋より先に成立した強国だ。

**やる夫**：
契丹は鮮卑の子孫なんだお？

**できる子**：
鮮卑系諸集団との歴史的・文化的連関は強く、契丹語はモンゴル語族に近い、または傍系と考えられる。
しかし北魏の拓跋鮮卑がそのまま契丹へ改名したわけではない。
長い間に複数集団が再編され、新しい契丹共同体と遼国家ができた。

**やらない夫**：
宋は軍事的に遼を倒せず、澶淵の盟（せんえんのめい、Chányuān zhī Méng）で銀と絹を送る代わりに国境安定を得る。
宋の史書では屈辱に見えるが、全面戦争の費用と比べれば安い外交保険でもある。

**やる夫**：
ローマ皇帝だけが正統と思っていた国が、北の別皇帝と兄弟関係を結び、毎年支払いをする感じだお。
「朝貢＝服属」という一方向の図では読めないお。

---
### 5-2　五代・宋成立編――王家でなく軍団が王朝を渡り歩く

**やる夫**：
唐が滅びて、すぐ宋が統一したんだお？

**やらない夫**：
907年に朱温（しゅおん、Zhū Wēn）が唐を終わらせ後梁（こうりょう、Hòu Liáng、Later Liang）を建てる。
その後、華北の中心王朝だけでも後梁、後唐（こうとう、Hòu Táng、Later Tang）、後晋（こうしん、Hòu Jìn、Later Jin）、後漢（こうかん、Hòu Hàn、Later Han）、後周（こうしゅう、Hòu Zhōu、Later Zhou）と交代する。
南には呉、南唐、呉越、荊南、楚、前蜀、後蜀、南漢、閩、北漢などが並ぶ。
「五代十国」は数を丸暗記するより、軍人政権が税源都市と軍団を奪い合う市場として見ろ。[^6]

**できる子**：
五代は、前王朝の血統より軍団と後援者の移動で並べる。

- **後梁**：朱温（しゅおん、Zhū Wēn）が黄巣（こうそう、Huáng Cháo）軍から唐へ降り、節度使となって唐を終わらせた。後梁（こうりょう、Hòu Liáng）は沙陀勢力と敵対した。
- **沙陀系・後唐**：李存勗（りそんきょく、Lǐ Cúnxù）が沙陀（さだ、Shātuó）系軍事集団を率い、後梁を倒して後唐（こうとう、Hòu Táng）を建てた。本人が兵士の反乱で死ぬと、軍団内の別系統へ皇位が移った。
- **契丹を後援者とした後晋**：石敬瑭（せきけいとう、Shí Jìngtáng）が契丹の軍事援助で後晋（こうしん、Hòu Jìn）を建て、燕雲十六州（えんうんじゅうろくしゅう、Yānyún Shíliù Zhōu）を遼へ譲った。後晋が遼と敵対へ転じると滅ぼされた。
- **後周から宋への継承線**：郭威（かくい、Guō Wēi） → 養子の柴栄（さいえい、Chái Róng） → 幼い実子。柴栄の急死で有力な成人君主を失ったため、将軍趙匡胤（ちょうきょういん、Zhào Kuāngyìn、宋太祖〈そうたいそ、Sòng Tàizǔ〉）が陳橋（ちんきょう、Chénqiáo）の変で推戴され、後周の軍・官僚・領土を宋へ移した。
- **宋の兄弟継承**：趙匡胤 → 弟の趙光義（ちょうこうぎ、Zhào Guāngyì、宋太宗〈そうたいそう、Sòng Tàizōng〉）。南方諸国と北漢（ほくかん、Běi Hàn）を併合したが、燕雲十六州を持つ遼とは敵対関係が残った。

**やる夫**：
宋太祖も軍人の推戴で皇帝になった。
だから次の軍人推戴を恐れ、禁軍の指揮を分割し、将軍を頻繁に交代させ、文官を地方へ送るんだお。
有名な「杯酒釈兵権」は細部が伝説化されていても、武将の独立基盤を解体した方向は確かだお。

**やらない夫**：
政策反応札。

- 軍の中央直轄化：皇帝には安全、地方住民には節度使の私戦が減る。前線将軍には不信と指揮制約。
- 文官知州と監察：地方豪族の独占を抑えるが、中央文書と試験に強い士大夫が優位になる。
- 科挙拡大：旧門閥の世襲を弱め、地方家族が教育投資へ向かう。落第者は膨大に生まれる。
- 商業税・専売・貨幣：都市と市場から財源を取れるが、塩などの専売価格は生活者と密商人の不満を生む。

**やる夫**：
宋は統一国家を作ったけど、石敬瑭が契丹へ渡した燕雲十六州を回復できない。
北京＝東京周辺の防衛線を失ったまま、遼と並立するんだお。

---
### 5-3　遼は二つの国を一人の皇帝が治めたのか

**やる夫**：
契丹人も漢人と同じ県、同じ法律、同じ税にすれば統一できるお。

**やらない夫**：
契丹の遊牧・軍事社会と、燕雲地域の農耕都市社会を同じ仕組みで管理するとどうなる？

**やる夫**：
家畜と季節移動を土地台帳へ固定できない。
反対に農民へ部族単位の軍役や移動を求めても生産が壊れるお。

**やらない夫**：
遼は北面官と南面官に象徴される複合統治を行う。
契丹的な部族・宮廷・軍事制度と、中国式の州県・租税・官僚制を並べる。
ハプスブルク君主がオーストリア、ハンガリー、ボヘミアで別の法と身分議会を持つようなものだ。

**やる夫**：
同じ皇帝が、契丹人には可汗的君主、漢人都市には中国皇帝として振る舞う。
一つの国民へ同化させず、違うまま税と軍を取るんだお。

**できる子**：
契丹は独自の大字・小字を作った。
国家が中国式文書だけに依存せず、自分たちの言語と正統性を保存しようとした証拠。
遼滅亡後、一部は西へ移り西遼を建て、一部は金やモンゴルへ編入された。
契丹という名は薄れるが、耶律楚材のように元初期まで契丹系家門は残る。

---
### 5-4　遼・西夏・金成立編――三つの北方王朝、三つの創業原理

**やる夫**：
遼、西夏（せいか、Xī Xià、Western Xia）、金は宋の周辺民族が作った脇役国家だお？

**やらない夫**：
それぞれ成立の論理が違う皇帝国家だ。

**できる子**：
北方三王朝と宋を、四つの勢力として並べる。

- **契丹・遼**：耶律阿保機（やりつあぼき、Yēlǜ Ābǎojī） → 皇后の述律平（じゅつりつへい、Shùlǜ Píng）が継承を主導 → 子の耶律徳光（やりつとくこう、Yēlǜ Déguāng）。阿保機の死後、述律平が反対者を抑えて王統を維持し、徳光が後晋を援助して燕雲十六州を得た。
- **党項・西夏**：李元昊（りげんこう、Lǐ Yuánhào）が党項（とうこう、Dǎngxiàng、Tangut）諸集団と河西（かせい、Héxī）地域を再編し、宋・遼の双方と競争しながら1038年に皇帝を称した。元昊の死後は幼帝と外戚の政治が続き、宋との戦争と講和を反復した。
- **女真・金**：完顔阿骨打（わんやんあくだ、Wányán Āgǔdǎ）が女真諸部をまとめて遼へ反乱 → 弟の太宗が継承。阿骨打の死で征服は止まらず、完顔宗望（わんやんそうぼう、Wányán Zōngwàng）・宗翰（そうかん、Zōnghàn）が遼と北宋を攻略した。
- **北宋から南宋**：開封陥落と皇帝一族の連行後、趙構（ちょうこう、Zhào Gòu、宋高宗〈そうこうそう、Sòng Gāozōng〉）が南宋を建てた。岳飛（がくひ、Yuè Fēi）・韓世忠（かんせいちゅう、Hán Shìzhōng）は抗戦、宰相秦檜（しんかい、Qín Huì）は講和を主導して対立した。岳飛の処刑は抗戦派の軍事的・象徴的中心を失わせ、紹興の和議へ向かう政権選択を固定した。
- **敵対と同盟の反転**：宋＋金が遼を挟撃 → 遼滅亡後は金が宋を攻撃 → 南宋は金との戦争・講和を選ぶ。昨日の同盟者が、共通の敵の死後に最大の敵となった。

**やる夫**：
遼は契丹の移動的な社会と、燕雲の農耕都市を同じ法律で潰さず、北面官と南面官を置く。
契丹貴族には旧組織を維持できる安心、漢人官僚には州県行政の継続、皇帝には二つの財政基盤だお。

**やらない夫**：
ただし二重制度は平等を意味しない。
宮廷内の契丹皇族、后族、漢人官僚の競争が続き、誰が皇帝へ近いかで権力が変わる。

**やる夫**：
西夏の李元昊は、宋とも吐蕃系諸勢力とも異なる党項国家を示すため、独自文字、服装規定、官制、軍事編成を整える。
党項の有力者には共同体の格上げ、漢人官僚には新国家での職、宋の辺境民には戦争と交易停止が来る。

**やらない夫**：
金の女真は遼への貢納と支配に反発し、阿骨打の下で連合する。
宋は金と同盟して遼を挟撃するが、遼滅亡後に金軍が北宋の弱さを見抜き、1127年に開封＝名古屋を占領する。

**やる夫**：
靖康の変で皇帝一族が連れ去られ、趙構が杭州＝神戸方面へ逃れて南宋を作る。
岳飛は北伐支持の象徴、秦檜は講和の悪役として有名だけど、政府には軍事継続で財政と政権が崩れる恐怖もあったお。

**やらない夫**：
紹興の和議は、失地回復を望む人々には屈辱、江南の農民・商人には戦争停止、南宋皇帝には生存、前線軍人には地位喪失と映る。
英雄と売国奴の二択では、誰が戦費を払い、誰が和平で利益を得るかが消える。

---
### 5-5　宋は軍人を弱くして正解だったのか

**やる夫**：
唐は節度使が強すぎて滅びた。
なら宋は将軍を徹底的に中央へ従わせ、文官が軍を管理すればいいお！

**やらない夫**：
宋太祖の課題は、外敵より先に、皇帝を交代させ続けた軍事クーデターを止めることだった。
将軍の指揮権、兵士との私的結合、地方財源を分離する。
国内政変の防止には成功した。

**やる夫**：
でも戦場では、将軍が兵士を長期に育てても別任地へ動かされ、文官の承認を待つ。
北方の騎馬国家に対し、意思決定が硬くなるお。

**やらない夫**：
一方で宋を「弱い国」とだけ呼ぶな。
名古屋＝開封は巨大な消費都市となり、夜市、印刷、商業、運河輸送、貨幣、紙幣、石炭、鉄生産が発達する。
税収は農地だけでなく商業から得られる。

**やる夫**：
唐までの国家は、土地と農民を固定して兵と税を取ろうとした。
宋は人と商品が動くことを前提に、流通から税を取る方向へ適応したお。

**やらない夫**：
科挙は貴族家門だけでなく、多数の読書人へ官僚への道を広げる。
ただし合格者は少なく、地域の学校、土地、宗族の資力が必要だ。
能力主義が家族投資を消すのではなく、家族が試験競争へ再編される。

---
### 5-6　党項の西夏は、宋と吐蕃の中間なのか

**やる夫**：
北西には西夏……党項は羌の子孫で、つまりチベット人なんだお？

**できる子**：
一文で固定できない。
党項は古い史料で羌系と結びつけられ、西夏語はチベット・ビルマ語派に属する。
しかし党項、西夏臣民、古代羌、現代チベット人・羌族は同じ集合ではない。

**やらない夫**：
西夏は宋、遼、吐蕃系諸勢力、中央アジアの間に位置し、農耕、牧畜、オアシス交易を組み合わせる。
独自文字を作り、仏教経典と法令を翻訳し、中国皇帝型と草原君主型の制度を併用する。

**やる夫**：
文字を作るのは文化趣味じゃないお。
漢文だけで行政すると漢人官僚に依存する。
独自文字なら党項語で命令を残し、国家共同体を作れる。
でも翻訳官僚と教育制度が必要になるお。

**やらない夫**：
多言語国家では、翻訳は補助業務ではなく国家中枢だ。
一語の誤訳が、称号の上下、税、領土、宗教権威を変える。

---
### 5-7　女真は契丹を倒し、後に満洲になる

**やる夫**：
遼を倒した女真も、次の北方民族が交代しただけだお？

**やらない夫**：
女真は東北の森林、河川、農耕、狩猟、牧畜を組み合わせたツングース系諸集団だ。
契丹の支配下にあった者も多いが、言語も社会編成も契丹と同じではない。

**できる子**：
ここは後世への比較的明瞭な線を引ける。
金を建てた女真諸集団と、17世紀にヌルハチ（Nurhaci）が再編した女真、1635年以後の満洲には、言語・氏族・政治伝統の連続がある。
ただし400年間まったく同じ構成ではなく、モンゴル人、漢人なども八旗へ編入され、新しい満洲共同体が作られる。

**やる夫**：
女真は遼を倒して金を建て、さらに宋と組んで遼を挟撃する。
そのあと宋の東京＝開封を占領する。
宋は敵の敵を利用したら、もっと近くに強敵を呼び込んだお！

**やらない夫**：
北宋滅亡後、宋は神戸＝杭州へ移り南宋となる。
北の金、南の宋、西北の西夏が並ぶ。
どれが唯一の中国かではなく、複数国家が中国式皇帝号、独自民族制度、国際条約を競う時代だ。

**やる夫**：
金も女真人だけで北中国を治められない。
猛安・謀克など女真軍事組織と、漢地の州県官僚制を並べる。
遼と同じく複合統治だけど、人口の大多数は農耕民だから、支配層が都市生活と官僚政治へ取り込まれていくお。

---
### 5-8　朱子学は難しい哲学なのか、生活のOSなのか

**やる夫**：
宋代の儒学は理と気の哲学だお。
試験に出る難しい思想で、普通の家庭には関係ないお？

**やらない夫**：
家礼、祖先祭祀、婚姻、喪、家族内序列、学習、地域の義倉まで含めて考えろ。
朱子学は宇宙の秩序、自己修養、家族秩序、国家官僚を一本へつなぐ。

**やる夫**：
科挙で個人が出世するほど、家族は田畑を集め、学校を作り、族譜を書き、優秀な男子へ教育投資する。
個人主義になるどころか宗族が強くなることもあるお。

**やらない夫**：
女性の財産権や再婚慣行は時代・地域で一様ではないが、後世には貞節や父系宗族を強調する規範が強まる。
思想は書物の中だけでなく、相続と婚姻の設計になる。

---
### 5-9　世界同時刻盤――宋は産業革命寸前だったのか

**できる夫**：
宋・遼・金の時代、日本は平安後期から鎌倉時代です！
ヨーロッパでは中世都市、十字軍、王権形成！
中東ではアッバース朝後の諸勢力とセルジューク朝、インドではチョーラ朝などがインド洋交易を動かし、東南アジアではアンコールや海港国家が発展します！
西アフリカではガーナ王国からマリにつながる金交易圏が成長します！

**やる夫**：
宋の鉄、石炭、印刷、紙幣、都市化はすごい。
でも技術が多いだけで自動的に近代工業化するわけじゃない。
賃金、資源価格、市場、政治、海外拡張など別条件も必要だお。

**やらない夫**：
その宋・金・西夏を、草原で再編されたモンゴルが順に飲み込む。

## 第6幕　中国がユーラシア帝国の一地域になる――モンゴル帝国・元

---
### 6-1　モンゴルは昔から一つの民族だったのか

**やる夫**：
チンギス・ハンがモンゴル人を率いて世界征服した。
匈奴以来のモンゴル民族がついに統一されたんだお！

**やらない夫**：
逆だ。
チンギス・ハン以前の草原には、モンゴル語系、テュルク語系などの諸集団があり、部族名と忠誠関係が競合した。
征服と再編を通じて、千戸制の軍事単位へ人々を組み替え、チンギス家への忠誠を中心に「モンゴル」という政治共同体が強化された。

**やる夫**：
民族が国家を作っただけじゃなく、国家と軍制が民族を作ったんだお。

**できる子**：
系譜札。
モンゴル語族は契丹語と近縁関係を持つ可能性が高いが、契丹国家がそのままモンゴル帝国になったのではない。
匈奴との直接系譜も確定できない。
ただし草原の可汗号、左右翼、婚姻同盟、部族再編など、政治技術の長期継承はある。

---
### 6-2　モンゴル帝国・元成立編――四つの家への分配が内戦を生む

**やる夫**：
チンギス・ハンが中国を征服して元を建てたんだお？

**やらない夫**：
チンギス・ハンの生前に元という中国王朝はない。
まずテムジンが草原の諸集団を戦争、婚姻、同盟、降伏者の再編によってまとめ、1206年にチンギス・ハンとして推戴される。
氏族ごとの軍を10進編成へ組み替え、旧来の血縁を越えて功績と忠誠で人を配置した。

**できる子**：
チンギス家を家系ごとに分けると、帝国の後継争いが見える。

- **創業者と四子の分配**：テムジン（Temüjin、チンギス・ハン〈Genghis Khan〉） → ジョチ（Jochi）・チャガタイ（Chagatai）・オゴタイ（Ögedei）・トルイ（Tolui）。チンギス・ハンの死後、領民・土地・軍は四家へ分配され、共同の皇帝を選ぶ仕組みが拡張と分裂の両方を生んだ。
- **オゴタイ家**：オゴタイ → 皇后ドレゲネ（Töregene）が死後に摂政 → 子のグユク（Güyük）。オゴタイの死で遠征が中断し、ドレゲネが後継選出と官僚人事を握った。グユクの早い死後、皇位はオゴタイ家から外れる。
- **トルイ家**：トルイの子モンケ（Möngke）が第4代皇帝 → 弟のクビライ（Qubilai）とアリクブケ（Ariq Böke）が後継を争う。モンケが南宋遠征中に死んだことが内戦を直接始動させ、クビライの勝利は帝国の一体性を弱めた。
- **元と南宋の敵対線**：クビライが1271年に元を称し、将軍バヤン（Bayan）が南宋を攻略。南宋側では文天祥（ぶんてんしょう、Wén Tiānxiáng）・陸秀夫（りくしゅうふ、Lù Xiùfū）が抵抗し、陸秀夫と幼帝の死で亡命朝廷が消滅した。

**やる夫**：
『天幕のジャードゥーガル』は、捕虜となったイラン出身のファーティマとオゴタイ妃ドレゲネを中心に、征服地の知識と女性の宮廷政治を描く。[^26]
中国史の教科書だと「太宗オゴタイ」と1行で終わる時代を、ペルシア語圏、捕虜、医療知識、後宮、皇位継承から見る入口なんだお。

**やらない夫**：
作品は創作を含むが、モンゴル帝国が中国人とモンゴル人だけの二者関係でなかったことは重要だ。
ウイグル系書記、ムスリム商人、漢人官僚、契丹人、女真人、チベット僧、ルーシや中央アジアの使節が同じ帝国で働く。

**やる夫**：
金は1234年にモンゴル・南宋の挟撃で滅ぶ。
その後モンケの死でクビライとアリクブケが争い、クビライが中国の農地税・都市・漢人軍を使って勝つ。
でも草原側からは、中国式の都と財政へ寄りすぎた皇帝に見えるお。

**やらない夫**：
クビライは北京＝東京の大都を首都とし、1271年に元を名乗り、1276年に杭州＝神戸の南宋朝廷を降伏させ、1279年に残存勢力を滅ぼす。[^7]

**やる夫**：
政策反応札だお。

- 行省：広域軍政を地方政府へ定着させ、後代の省制度へ影響。地方官には権限、中央には監督問題。
- 駅伝・通行証：使節と商人には高速移動、沿道民には馬・食糧負担。
- 紙幣：遠距離取引には便利だが、過剰発行時には物価と信頼が崩れる。
- 多言語文書・多宗教保護：征服地人材を使える一方、官職と免税をめぐる競争が起きる。
- 征服順序による住民分類：モンゴル支配層には安全保障、旧南宋人には昇進差別と重税の感覚。
- 税の請負：短期に歳入を得るが、請負人が徴収を増やせば農民・都市民が圧迫される。

**やらない夫**：
元は中国制度を採用したからモンゴル性を失ったのでも、中国制度を拒否したから失敗したのでもない。
草原の家産分配と中国の一元的官僚財政を同時に満たせず、皇族・軍人・官僚・商人の要求が衝突し続けた。

---
### 6-3　征服した国の制度を全部壊せば自由なのか

**やる夫**：
世界最強の騎馬軍なら、農耕国家の面倒な官僚制を捨て、全部モンゴル式にすればいいお！

**やらない夫**：
馬上から都市を征服できても、馬上から灌漑水路の税額、塩の流通、戸籍、倉庫を管理できるか？

**やる夫**：
できないお。
中央アジアでは現地の徴税官、イランではペルシア系官僚、中国では漢人・契丹・女真系官僚を使うしかない。

**やらない夫**：
モンゴル帝国は統一制度を押しつけるより、征服地ごとの技術者、宗教者、書記を移動させる。
宿駅で情報を運び、チンギス家の諸王へ領民と収入権を分配する。
これは近代的な単一国家ではなく、巨大な家産的連合帝国だ。

**やる夫**：
元を中国王朝だけとして見ると、大都＝東京から南中国を治める話になる。
でもモンゴル側からは、東京はカラコルムや中央アジア、イラン、ロシアへ連なる複数中心の一つだお。

---
### 6-4　元の住民分類は人種カーストなのか

**やる夫**：
元はモンゴル人、色目人、漢人、南人の4階級で差別したんだお。
完全な人種カーストだお？

**やらない夫**：
格差は確かにあったが、固定した近代的人種分類として扱うと誤る。
征服順序、地域、官職登用、法的待遇を反映する行政カテゴリーだ。
北中国の旧金領住民には漢人だけでなく契丹・女真なども含まれ、色目人も中央・西アジアの多様な人々をまとめた名称だった。

**やる夫**：
本人の言語や血筋だけで自動判定される一枚岩じゃない。
家族の移住、官職、軍籍、婚姻で位置が変わることもある。
でも南宋旧領の南人が不利になるなど、征服の順序が制度に残ったお。

**やらない夫**：
元朝廷ではモンゴル語文書、漢文、ウイグル文字系の書記、ペルシア語系の財務実務、チベット仏教の宗教語彙が交差する。
勅令は一つの言語で全国へ降りるのではなく、複数版が作られ、翻訳される。

**やる夫**：
EUより翻訳制度が未整備で、ハプスブルク帝国より移動速度が速く、王家の分配権が強い世界だお。
通訳が権力を持つのも当然だお。

---
### 6-5　宗教に寛容なら近代的なのか

**やる夫**：
モンゴルは仏教、イスラム教、キリスト教、道教を保護した。
信教の自由を実現した先進国家だお！

**やらない夫**：
近代的個人の権利とは違う。
宗教団体は祈祷、暦、医療、文字、国際連絡、徴税協力を提供する。
皇帝は有用な宗教者へ免税や保護を与え、宗派間の論争を裁く。

**やる夫**：
チベット仏教の高僧とモンゴル皇帝の関係も、単なる信者と僧じゃない。
宗教権威が皇帝へ宇宙的正統性を与え、皇帝が寺院と教団を軍事的に保護するお。

**やらない夫**：
一方で免税特権や宗教裁判権は、一般住民や他宗派との摩擦を生む。
寛容とは全員を同じ条件にすることではなく、異なる共同体へ別々の特権を与える統治でもある。

---
### 6-6　海と陸がつながったのに、なぜ元は安定しないのか

**やる夫**：
モンゴル帝国でユーラシアがつながり、商人と技術者が移動し、泉州＝堺にはイスラム商人も集まる。
交易が増えれば全員得をして安定するお！

**やらない夫**：
交易網は富だけでなく、疫病、価格変動、徴税請負、宮廷への奢侈品需要も運ぶ。
元は紙幣を広域流通させるが、軍事費と財政赤字を埋めるため発行への信頼を損なう。

**やる夫**：
黄河治水、災害、労役、塩税、紙幣不信が重なり、各地の反乱が宗教結社や地域軍事集団へつながる。
皇位継承もチンギス家の複数候補が争うから、宮廷派閥が安定しないお。

**やらない夫**：
元の問題を「異民族は中国を治められなかった」で片づけるな。
中国統治には約1世紀成功した。
崩れたのは、多地域帝国の分配、財政、継承、環境危機を同時に調整できなくなったためだ。

**できる子**：
元が中国から退いた後もモンゴル人は消えない。
北元（ほくげん、Běi Yuán、Northern Yuan）として草原で政権を続け、オイラト（Wǎlà、Oirats）など別のモンゴル系連合と競争する。
明、清はその政治世界と数世紀にわたり向き合う。

---
### 6-7　世界同時刻盤――マルコ・ポーロだけが世界を見たのか

**できる夫**：
元の時代、日本は鎌倉後期、モンゴル襲来を経験します！
ヨーロッパでは十字軍後期から都市・王権が成長し、中東ではモンゴル系イル・ハン国とマムルーク朝、インドではデリー・スルタン朝！
東南アジアではパガン、スコータイ、ジャワの諸国、アフリカではマリ帝国とインド洋沿岸都市が繁栄します！

**やる夫**：
ヨーロッパ人だけが東へ冒険したんじゃない。
中国人、モンゴル人、ペルシア人、アルメニア人、アラブ人、ソグド系の末裔、中央アジア商人が双方向に移動するお。

**やらない夫**：
次の明は、この国際帝国を否定して農村的な漢人国家を作ろうとする。
だが世界との接続は止められない。

## 第7幕　漢人王朝へ戻せば安定するのか――明

---
### 7-1　元を否定して、元の国を引き継ぐ

**やる夫**：
朱元璋（しゅげんしょう、Zhū Yuánzhāng）が元を北へ追い、明を建てたお！
これでモンゴル帝国の制度を捨て、漢と唐の正しい中国へ戻るお！

**やらない夫**：
新王朝はそう宣伝する。
だが元の駅伝、行政区画、軍事的な南北統合、雲南支配、北京の都市基盤を使わずに済むか？

**やる夫**：
使うしかないお。
元の「行中書省」は形を変えながら後世の省につながり、元が広域帝国へ組み込んだ地域も明の領域構想に入る。
王朝を否定しても、前王朝が作った統治空間まで捨てるわけじゃないお。

**やらない夫**：
朱元璋は貧農と反乱軍から皇帝になった経験から、官僚、富商、大地主、軍人の自立を疑う。
大阪＝南京を首都に、皇帝が細部まで把握する国家を作ろうとする。

**やる夫**：
丞相を廃止し、六部を皇帝直属にする。
権力者が皇帝を操れないように、皇帝が全部決裁するお！

**やらない夫**：
創業者本人の処理能力を制度の標準にしたら、後継皇帝が同じ速度で働けない時にどうなる？

**やる夫**：
文書が皇帝へ集中し、補佐役が非公式に必要になる。
内閣大学士や宦官が、法定の丞相ではないのに情報の入口を握るお。
権力機関を消しても、権力機能までは消えないお。

---
### 7-2　明成立編――元末の三勢力と、創業家内部の再征服

**やる夫**：
明太祖朱元璋は貧しい農民から皇帝になった大逆転人物だお！
元を追い出して漢人国家を復活させたお！

**やらない夫**：
貧困、飢饉、疫病で家族を失い、寺へ入り、紅巾軍（こうきんぐん、Hóngjīnjūn）系の郭子興（かくしこう、Guō Zǐxīng）へ参加したことは重要だ。
だが元軍対漢人反乱軍という単純な二陣営ではない。
反乱勢力同士、元の地方軍、塩商・水運勢力、地主武装が競争する。

**できる子**：
元末の競争勢力と、明王家内部の後継戦を分ける。

- **郭子興から朱元璋へ**：郭子興（かくしこう、Guō Zǐxīng）の紅巾系軍へ朱元璋（しゅげんしょう、Zhū Yuánzhāng、洪武帝〈こうぶてい、Hóngwǔ Dì〉）が参加。郭子興の死後、朱元璋が軍団の一部と婚姻関係を継ぎ、南京を基盤に自立した。
- **朱元璋政権**：劉基（りゅうき、Liú Jī）・李善長（りぜんちょう、Lǐ Shàncháng）が戦略と行政、徐達（じょたつ、Xú Dá）・常遇春（じょうぐうしゅん、Cháng Yùchūn）が軍事を担い、元軍および競争勢力と戦った。
- **長江の敵対勢力**：陳友諒（ちんゆうりょう、Chén Yǒuliàng）が長江中流、張士誠（ちょうしせい、Zhāng Shìchéng）が江南の富裕地域を支配した。陳友諒が鄱陽湖（はようこ、Póyáng Hú）の戦いで死ぬと陣営は求心力を失い、朱元璋が最大の水上競争者を除いた。
- **洪武帝後の王統争い**：朱元璋 → 皇太孫の建文帝（けんぶんてい、Jiànwén Dì）。洪武帝の死で創業者の威圧が消えると、建文帝の削藩に対し叔父の朱棣（しゅてい、Zhū Dì、永楽帝〈えいらくてい、Yǒnglè Dì〉）が反乱した。
- **燕王勢力**：朱棣を僧侶・参謀の姚広孝（ようこうこう、Yáo Guǎngxiào）が支え、靖難の役（せいなんのえき、Jìngnàn zhī Yì）で建文帝側と敵対。南京陥落時に建文帝が死亡したか逃亡したかは確定せず、その不明確さが永楽帝の正統性問題として残った。

**やる夫**：
朱元璋は南京＝大阪を取り、1363年の鄱陽湖の戦いで陳友諒を破り、張士誠を倒し、1368年に皇帝を称する。
徐達が大都＝東京を占領すると元の朝廷は北へ退く。
元人が全員消えたのではなく、北元が続き、元官僚や軍人の一部は明へ仕えるお。

**やらない夫**：
洪武帝の政策は、自分が見た飢饉・地主・腐敗官僚・軍閥への不信から作られる。
農民を村と戸籍へ固定し、官僚と軍人を皇帝が直接監督する。

**やる夫**：
政策反応札だお。

- 里甲制・黄冊・魚鱗図冊：国家には人口土地データ。自作農には土地権利確認、豪族には隠田摘発、村役には徴税責任。
- 軍戸・衛所制：兵士家族には世襲の土地と身分保障のはずが、世代が進むと逃亡できない負担になる。
- 常平・備荒と農業奨励：戦乱後の回復には有効。商人への不信と職業固定は市場成長と衝突。
- 丞相廃止と皇帝直轄：皇帝には権力、官僚には最終調整役の欠如と過重な文書。
- 厳しい官僚処罰：汚職抑止を期待される一方、官僚は責任回避と恐怖政治を感じる。

**やらない夫**：
洪武帝の孫建文帝は、強大な皇族諸王を削ろうとする。
北京＝東京で北方軍を握る燕王朱棣は反乱し、1402年に南京＝大阪を落として永楽帝となる。
周の分封、漢の諸侯王、晋の八王と同じ問題が明でも再発した。

**やる夫**：
永楽帝は首都を北京へ移し、北方防衛と自軍の基盤を国家中心にする。
南京の官僚・経済人には政治中心喪失、北京の軍人・建設業者には機会、江南農民には運河輸送と税の負担だお。
鄭和（ていわ、Zhèng Hé）航海は朝貢外交と皇帝権威を広げるけど、費用を負う官僚からは持続性を疑われる。

**やらない夫**：
後期には張居正（ちょうきょせい、Zhāng Jūzhèng）が一条鞭法（いちじょうべんぽう、Yītiáobiānfǎ）を全国化し、複雑な税と労役を銀納へまとめる。
役人には徴収が簡単、銀を得やすい商業地域には便利、銀を市場で買わねばならない農民には価格変動が直撃する。
政策の合理化が、世界銀市場への依存を深めた。

---
### 7-3　全国民を帳簿へ固定できるのか

**やる夫**：
人が勝手に移動するから税と兵が足りなくなるんだお。
農民は農民、軍人は軍人、職人は職人の戸籍を世襲させ、土地台帳と黄冊へ全部書けばいいお！

**やらない夫**：
洪武帝の構想だ。
里甲制で地域住民を組織し、軍戸から世襲兵を出し、魚鱗図冊で土地を把握する。
戦乱後の人口と農地を再建する初期には効果がある。

**やる夫**：
でも100年たてば、軍戸の土地が減り、兵士が逃げ、商業都市が拡大し、農民が出稼ぎし、家族が分かれる。
帳簿は創業時の写真のまま、現実だけが動画で動くお。

**やらない夫**：
国家は世襲軍戸だけで国境を守れず募兵へ依存する。
税も現物・労役の複雑な体系から、銀納を中心とする一条鞭法へ収斂する。
固定身分国家を掲げながら、実務では貨幣と市場へ適応する。

**やる夫**：
制度を守ったから明が続いたんじゃなく、制度をこっそり変えたから続いたお。
でも理念では古い帳簿を正しいとし続けるから、現実とのずれが汚職や不正として処理される。

**やらない夫**：
地方では宗族、郷紳、商人、胥吏が、税の取りまとめ、治安、慈善、教育を担う。
中央集権を強調する明も、現場では非公式な地域エリートへ依存する。

---
### 7-4　南京＝大阪から北京＝東京へ首都を移す

**やる夫**：
南京＝大阪は江南の富に近く、大運河と長江を使える。
首都はずっと大阪でいいお。

**やらない夫**：
靖難の役で帝位を奪った永楽帝の本拠は北平＝東京だ。
北には北元のモンゴル勢力がいる。
政治と軍事の重心をどこへ置く？

**やる夫**：
東京へ移すお。
北京と改称し、紫禁城（しきんじょう、Zǐjìnchéng、Forbidden City）を造り、北方軍事へ近づく。
でも米と税収の中心は江南だから、大阪・杭州・蘇州（そしゅう、Sūzhōu）方面から大運河で東京へ運ばないと首都が食べられないお。

**やらない夫**：
北京＝東京は、江戸のように巨大な政治消費都市となる。
自前の経済だけでなく、全国から運ばれる穀物、税、官僚、職人で維持される。
首都移転は地図上の飾りではなく、北方防衛を国家財政の中心へ置く選択だ。

**やる夫**：
南京＝大阪は副都として官庁名と文化的格を残す。
都市札を動かさないと、大阪が首都から副都へ下がり、東京が辺境軍事拠点から首都へ上がる変化が見えるお。

### 7-5　北元とオイラトは元の残党なのか

**やる夫**：
元が滅びた後のモンゴルは、敗残兵が砂漠で小競り合いを続けただけだお？

**できる子**：
元朝の中国支配が終わったのであり、モンゴル政治が終わったのではない。
チンギス家の北元は草原で皇帝号を維持し、東部モンゴル諸集団と西部のオイラト諸集団が競争した。

**やらない夫**：
明は長城を一本築いて完全に遮断したわけではない。
時代ごとに要塞線を整備し、互市を開閉し、モンゴル首長へ称号を与え、遠征し、朝貢貿易を行う。

**やる夫**：
交易を閉じれば平和になると思ったら、馬や穀物を得られない側の襲撃圧力が増す。
開けば首長が富み、軍事力を増す可能性もある。
漢と匈奴以来の難問だお。

**やらない夫**：
15世紀にはオイラトのエセン（Esen Taishi）が明軍を破り、土木の変（どぼくのへん、Tǔmù zhī Biàn、Tumu Crisis）で皇帝を捕虜にする。
「異民族が弱い王朝末期に侵入した」のではなく、明中期の最盛期にも草原国家は国家存亡級の相手だった。

**できる子**：
オイラトは後にジュンガル（Zhǔngá'ěr、Dzungars）などへ再編される。
清が18世紀に戦う相手へつながるため、明代で消えた名称ではない。

---
### 7-6　女真は金の記憶を持っていたのか

**やる夫**：
東北の女真は、金が滅びてから400年もたってるお。
もう金の女真とは別物じゃないかお？

**できる子**：
同一ではないが、連続は比較的強い。
女真語と後の満洲語はツングース系の近縁な歴史段階で、氏族伝承、狩猟・農耕・貢納関係、金王朝の記憶が残った。
一方、明代の女真は建州（けんしゅう、Jiànzhōu）、海西（かいせい、Hǎixī）、野人（やじん、Yěrén）など中国側の分類で分けられ、互いに統一されていなかった。

**やらない夫**：
明は女真首長へ官職を与え、朝貢貿易を管理し、相互牽制させる。
辺境の首長を中央官僚の末端として扱う文書と、実際には独自の軍事・婚姻連合を率つ現実が重なる。

**やる夫**：
ロンドン政府がスコットランド高地の氏族長へ爵位を与え、外国君主ではなく臣下だと記録する感じだお。
でも氏族長側は、その称号を国内で威信と交易権に使うお。

**やらない夫**：
その仕組みを利用して勢力を広げるのがヌルハチだ。

---
### 7-7　海禁は鎖国なのか

**やる夫**：
明は海禁で外国との交流を止めたんだお。
鄭和の大航海をやめ、鎖国したから西洋に遅れたお！

**やらない夫**：
国家使節、朝貢貿易、軍事航海、民間交易、密貿易を分けろ。
鄭和艦隊は皇帝の威信と外交秩序を示す大事業で、民間商人の自由交易と同じではない。

**やる夫**：
海禁は沿岸住民の出航や私貿易を制限するけど、実際には福建・広東・浙江の商人、琉球、日本、東南アジアの交易を止められない。
倭寇も日本人だけでなく、中国人海商や混成集団を含むお。

**やらない夫**：
16世紀に海禁を緩め、銀を介した交易が拡大する。[^8]
日本銀と、スペイン領アメリカからマニラ経由で来る銀が、中国の絹、陶磁器、茶と交換される。

**やる夫**：
農村国家を目指した明が、世界規模の銀経済へ組み込まれる。
税まで銀で納めるようになると、銀の流入が止まった時に農民の納税条件が急変するお。
世界経済が国内財政を揺らすんだお。

---
### 7-8　苗・瑶は昔から同じ山地民族なのか

**やる夫**：
南西の苗族や瑶族は、漢代から同じ民族が山に残ってたんだお？

**できる子**：
史料上の苗（びょう、Miáo、Miao）、瑶（よう、Yáo、Yao）、獠（りょう、Liáo）などは、王朝が戸籍外・半自治の山地集団へ付けた広い分類でもある。
時代と地域で指す範囲が変わり、現代の民族分類とそのまま一致しない。

**やらない夫**：
明は土司制度で在地首長へ世襲官職を与え、現地社会を間接統治する。
中国式県制へ直ちに変えず、首長を帝国官僚の一種として組み込む。

**やる夫**：
ハプスブルク帝国が山岳地域の領主へ自治と軍役を認めるようなものだお。
中央には臣下、地元では王に近い。

**やらない夫**：
後に改土帰流で中央任命官へ置き換えると、税と法の統一は進むが、在地秩序を壊して反乱を生む。
直接統治が常に進歩とは限らない。

---
### 7-9　明は誰に滅ぼされたのか

**やる夫**：
明は満洲族に侵略されて滅びたお。

**やらない夫**：
順序を追え。
北方防衛費、官僚対立、宮廷財政、気候寒冷化と災害、疫病、銀流通の変動、農民反乱が重なる。
李自成（りじせい、Lǐ Zìchéng）軍が北京＝東京を占領し、崇禎帝（すうていてい、Chóngzhēn Dì）が死んだ時点で明中央政権は倒れている。

**やる夫**：
山海関（さんかいかん、Shānhǎiguān）の明将・呉三桂（ごさんけい、Wú Sānguì）が、李自成に対抗するため清軍を関内へ招く。
外敵が一方的に壁を破ったというより、内戦の一派が別の国家を利用したお。

**やらない夫**：
清は明の官僚、将軍、地方紳士を大量に取り込み、南明と反乱勢力を長く征服する。[^9]
王朝交代は1日では終わらない。

### 7-10　世界同時刻盤――銀が地球を一周する

**できる夫**：
明代、日本は室町・戦国・安土桃山・江戸初期です！
ヨーロッパではルネサンス、宗教改革、大西洋航海、スペイン・ポルトガル帝国！
中東ではオスマン、サファヴィー、ムガルという火器帝国、アフリカではソンガイ、エチオピア、コンゴ王国、東アフリカ海岸の交易都市！
東南アジアではマラッカ、アユタヤ、後のバタヴィアなどが海上交易を競います！

**やる夫**：
石見銀山やメキシコ・ポトシの銀が、マニラや日本商人を通じて中国へ入る。
明の税制は中国国内だけで完結せず、南米鉱山と日本の戦国大名にまでつながってるお。

**やらない夫**：
次の清は、女真から満洲へ自分たちを再編し、中国王朝であると同時に内陸アジア帝国となる。

## 第8幕　一人の皇帝が複数の世界で別の顔を持つ――後金・清

---
### 8-1　女真が満洲になった日

**やる夫**：
ヌルハチは女真族を統一し、清を作ったお。
金の女真がそのまま復活したんだお？

**やらない夫**：
ヌルハチは既存の女真集団を集めただけではない。
八旗へ人々を再編し、敵対氏族を解体し、投降したモンゴル人や漢人も別旗・所属として組み込む。
国家建設が新しい共同体を作る。

**できる子**：
1616年の国号は後金。
1635年にホンタイジ（Hong Taiji）が女真という名称を満洲へ改め、1636年に国号を清とする。
女真から満洲へは言語・氏族・政治の連続があるが、名称変更は単なる看板替えではなく、多様な旗人を新しい支配民族へ統合する政策。[^10]

**やる夫**：
八旗は軍隊だけじゃなく、戸籍、給与、婚姻、居住、身分を束ねる生活組織だお。
満洲人とは血統だけでなく、旗に所属して皇帝へ軍事奉仕する身分でもある。

**やらない夫**：
そのため清が長く平和になると、旗人の軍事能力低下と生活保障が財政問題になる。
戦争に適した制度が、平和には重い固定費へ変わる。

---
### 8-2　後金・清成立編――明の死後、四勢力が北京を奪い合う

**やる夫**：
女真のヌルハチが満洲人を率いて万里の長城を越え、明を倒したんだお！

**やらない夫**：
清軍が北京へ入った1644年、明の北京を先に占領していたのは李自成の反乱軍だ。
明は内乱、財政危機、北東の後金、飢饉、地方軍の自立が重なって崩れる。

**できる子**：
1644年を一本の侵略線にせず、四勢力で置く。

- **後金・清王統**：ヌルハチ（Nurhaci） → 子のホンタイジ（Hong Taiji） → 幼い順治帝（じゅんちてい、Shùnzhì Dì）。ヌルハチの死後、ホンタイジが八旗内の合議を経て継承し、国号と共同体名を改めた。ホンタイジの急死後は幼帝を、叔父ドルゴン（Dorgon）が摂政として支えた。
- **明王朝**：崇禎帝（すうていてい、Chóngzhēn Dì）と山海関（さんかいかん、Shānhǎiguān）の将軍呉三桂（ごさんけい、Wú Sānguì）。李自成の北京占領と崇禎帝の自死で中央命令系統が切れ、呉三桂は清と組む選択をした。
- **反乱軍・大順**：李自成（りじせい、Lǐ Zìchéng）が大順（だいじゅん、Dà Shùn）を建て、明を倒した。呉三桂＋ドルゴン軍と敵対して敗れ、李自成の死後は大順の求心力が急速に低下した。
- **南明・海上抵抗**：南京などの明皇族政権と、鄭成功（ていせいこう、Zhèng Chénggōng、Koxinga）の海上勢力。鄭成功は台湾（たいわん、Táiwān）へ拠点を移したが、本人の死後も鄭氏政権は子・孫へ続き、清への抵抗は即時には終わらなかった。
- **征服後の内部分岐**：ドルゴンの死で摂政政治が終わり、順治帝が親政。呉三桂らは清の協力者から地方藩王となり、後に康熙帝（こうきてい、Kāngxī Dì）の削藩へ敵対して三藩の乱を起こす。呉三桂の死後も反乱は続いたが、後継勢力は結束を失った。

**やる夫**：
ヌルハチは女真の小集団をそのまま束ねるだけでなく、家族と兵士を八旗へ再編する。
降伏したモンゴル人・漢人も別旗へ組み込み、民族名より軍事・戸籍組織が国家を作るんだお。

**やらない夫**：
ホンタイジは後金を清へ改称し、満洲という新しい共同体名を整え、中国式官庁と皇帝儀礼を導入する。
同時にモンゴル諸部へ婚姻と称号を使い、朝鮮を服属させる。
北京征服前から多地域帝国を作っている。

**やる夫**：
1644年、李自成軍が北京へ入り、崇禎帝が死ぬ。
山海関の呉三桂は李自成へ降るか清と組むかを迫られ、ドルゴン軍を招く。
清は李自成を破って北京へ入り、「明の仇を討ち秩序を回復する」と宣伝するお。

**やらない夫**：
しかし南京＝大阪などには南明政権が立ち、各地で長い抵抗が続く。
清成立を1644年の1日で終わらせず、地方征服、投降官僚の採用、税の再開、海上勢力の鎮圧まで含めろ。

**やる夫**：
政策反応札だお。

- 明の県制・科挙・土地税を維持：漢人官僚と地方紳士には秩序回復と仕官の道。
- 八旗駐防：満洲・蒙古旗人には給与と身分、都市住民には土地接収と隔離への不満。
- 辮髪令：服従の可視化として清には重要だが、身体・家族慣行への介入として強い抵抗を招く。
- 投降者の登用：現実的な統治策だが、明への忠節を重視する人には裏切りと映る。
- 税の軽減と荒地開墾：戦乱地域には歓迎される一方、軍の駐屯と地方官の徴収が続けば効果は地域差が大きい。

**やらない夫**：
呉三桂ら投降将軍へ広い藩を与えたのは征服期には合理的だった。
だが康熙帝が削藩すると三藩の乱が起こる。
周、漢、晋、明初と同じく、創業功臣へ地方軍を預ける問題がまた現れる。

---
### 8-3　清は中国化したから成功したのか

**やる夫**：
少数の満洲人が多数の漢人を治めるには、漢語と儒教へ完全同化するしかないお。

**やらない夫**：
漢地では科挙、州県、儒教皇帝、明の税制を使う。
だがモンゴルにはハーン、チベット仏教圏には教法の保護者、満洲人には八旗の君主として振る舞う。
一つの顔へ同化したのではなく、複数の王冠をかぶる。

**やる夫**：
オーストリア皇帝がハンガリー王、ボヘミア王などを兼ねるハプスブルク帝国に近いお。
北京＝東京の紫禁城だけ見れば中国皇帝だけど、熱河（ねっか、Rèhé、Jehol）、モンゴル草原、チベット寺院では別の儀礼と言語を使う。

**やらない夫**：
清朝文書には満洲語と漢語の併記が多く、モンゴル語、チベット語、後にはチャガタイ系テュルク語も使われる。[^11]
翻訳は帝国の飾りではない。
同じ地名や称号が言語ごとに別の政治的意味を持つため、皇帝は複数世界の語彙を管理する。

**やる夫**：
漢語だけ読んで清を理解すると、満洲皇帝が漢人官僚へ見せた顔だけを見ることになるお。

---
### 8-4　モンゴルは清の外国か臣民か

**やる夫**：
清が中国を支配した後、モンゴルは北の外国だお？

**やらない夫**：
モンゴル諸集団も一つではない。
内モンゴルの諸侯は早くから満洲皇室と婚姻・盟約を結び、盟旗制度で清帝国へ入る。
外モンゴルのハルハ（中国語 Kā'ěrkā、Khalkha）も後に清の保護を受ける。
西にはオイラト系のジュンガルが強大な独立帝国を作る。

**できる子**：
系譜札。
明代のオイラト諸集団から、ホシュート、ドルベト、ジュンガルなどの連合が生まれる。
全モンゴルが清へ同時に服属したのではない。
ジュンガルは17～18世紀に中央ユーラシア最後の大遊牧帝国の一つとなる。

**やる夫**：
清とジュンガルの戦いは、中国王朝対北方蛮族じゃなく、満洲・モンゴル・漢地を持つ複合帝国と、オイラト系草原帝国の内陸アジア覇権争いだお。

**やらない夫**：
清の勝利で新疆（しんきょう、Xīnjiāng）が帝国へ組み込まれる。[^12]
この拡張は後の近代中国の領域形成に大きく影響する。

---
### 8-5　ウイグル人は回鶻のまま1000年生きたのか

**やる夫**：
新疆のウイグル人は唐代の回鶻の直系で、ずっと同じ民族なんだお？

**できる子**：
重要な連続はあるが、単純ではない。
回鶻可汗国崩壊後、テュルク語系集団が甘州やタリム盆地へ移り、現地のイラン系・トカラ系などのオアシス住民と混合した。
その後イスラム化し、複数の都市・宗教共同体として生活した。[^13]

**やる夫**：
清代の人々は、全員が自分を現代的意味のウイグル民族と呼んでいたわけじゃない。
カシュガル（Kashgar、中国語 Kāshí）人、トルファン（Turpan、中国語 Tǔlǔfān）人、ムスリムなど、都市・宗教・地域の名が重要だったお。

**やらない夫**：
近代国家が人口を分類し、民族名を標準化することで、古い名称に新しい範囲が与えられる。
民族は捏造でも永遠の血統でもなく、歴史的素材を国家と知識人が再編する共同体だ。

---
### 8-6　チベットは清の県だったのか、外国だったのか

**やる夫**：
現代の国境感覚なら、チベットは清の領土か独立国か、どちらかだお。

**やらない夫**：
前近代の関係を二択へ押し込むな。
ダライ・ラマ政権、モンゴル諸勢力、チベット貴族・寺院、清皇帝が、宗教保護、軍事介入、冊封、駐蔵大臣などを通じて関係した。
時期によって清の関与の強さも異なる。

**やる夫**：
県知事を派遣して全村から直接税を取る関係ではない。
でも単なる対等外交だけでもない。
皇帝が仏教の保護者として介入し、現地政府は独自行政を行うお。

**やらない夫**：
オスマン帝国内の自治宗教共同体や、ハプスブルク領内の歴史王国よりさらに複雑だと思え。
近代の主権概念が入ると、この曖昧な多層関係を一本の国境線へ変える争いが起こる。

---
### 8-7　低い税は善政なのか

**やる夫**：
康熙・雍正・乾隆期は領土も人口も増え、土地税を低く抑えた。
善政だから問題なしだお！

**やらない夫**：
人口と経済が増えても、税額と官僚数を大きく増やさなければどうなる？

**やる夫**：
一人の地方官が担当する人口が増え、書記や郷紳へ実務を外注する。
正式税は低くても、手数料や非公式負担が増えるお。

**やらない夫**：
トウモロコシ、サツマイモなど新大陸作物は山地人口を支える。
長期平和と市場拡大で人口が増える。
繁栄の成果だ。

**やる夫**：
でも一人あたり耕地が減り、山林が開発され、科挙競争が激化し、貧しい移住者が辺境へ流れる。
成功が土地不足と行政過負荷を作るお。

**やらない夫**：
宗族や商人組織、寺廟が福祉と秩序を補う。
国家が小さいから社会が自由なのではなく、家族と地域共同体の拘束が強くなる面もある。

---
### 8-8　キリスト教宣教師は宗教家か技術者か

**やる夫**：
イエズス会士は西洋科学を教え、中国人をキリスト教へ改宗させたお。
近代化の使者だお！

**やらない夫**：
宮廷では天文学、暦、地図、火器、数学の専門家として価値を持つ。
だが宗教上は、祖先祭祀と孔子祭祀を社会儀礼として認めるか、異教の礼拝として禁じるかが問題になる。

**やる夫**：
中国側では家族と国家秩序の基本儀礼。
ローマ教皇庁側では唯一神信仰との境界問題。
同じ行為を宗教と見るか社会慣習と見るかで衝突するお。

**やらない夫**：
宗教観の違いは教義だけでなく、家族、死者、国家儀礼をどこまで宗教に含めるかの違いだ。
中国社会では儒教・仏教・道教・民間信仰を排他的会員資格として選ばない人が多い。
キリスト教やイスラム教の共同体原理とはそこが異なる。

---
### 8-9　ヨーロッパとの戦争は、文明の優劣だけで決まったのか

**やる夫**：
産業革命したイギリスが、停滞した清をアヘン戦争で倒した。
科学文明対旧文明だお。

**やらない夫**：
軍事技術の差は重要だが、それだけではない。
イギリスには世界規模の海軍、インド植民地の財政とアヘン生産、民間商社、保険、信用、工業生産がある。
清は広大な内陸帝国の国境、反乱、河川、人口を同時に管理する。

**やる夫**：
清の広州＝長崎一港管理は、外国貿易を統制するには合理的だった。
でも相手が東インド会社と海軍を持つ帝国になると、商人管理の制度では対応できないお。

**やらない夫**：
南京条約（なんきんじょうやく、Nánjīng Tiáoyuē、Treaty of Nanking）で上海＝横浜などが開港し、条約港、治外法権、関税制約が生まれる。
国内では太平天国、捻軍、回民反乱など巨大反乱が続く。

**やる夫**：
清は地方の漢人有力者に団練・湘軍・淮軍を作らせて反乱を鎮圧する。
唐末と同じで、中央軍を救う地方軍が強くなるお。

**やらない夫**：
洋務運動は西洋技術だけを表面的に輸入した失敗、と切り捨てるな。
造船所、兵器工場、翻訳学校、外交組織、電信、鉱山を作る。
ただし中央集権的な国家予算と統一軍制へまとめきれず、地方官僚ネットワークへ分散する。

---
### 8-10　清末崩壊編――宮廷・反乱・地方軍・革命の四勢力

**やる夫**：
清末は『蒼穹の昴』の西太后（せいたいごう、Xī Tàihòu）と、『ラストエンペラー』の溥儀（ふぎ、Pǔyí）につなげれば人物が見えるお！
西太后が改革を邪魔し、幼い溥儀で王朝が終わったんだお？

**やらない夫**：
一人の悪役で100年を説明するな。
清末は、世界貿易、軍事技術、人口圧力、地方財政、巨大反乱、官僚改革が連鎖する。

**できる子**：
清末は、宮廷、反乱、地方軍、改革・革命の四勢力で置く。

- **清皇帝と宮廷**：道光帝（どうこうてい、Dàoguāng Dì） → …… → 咸豊帝（かんぽうてい、Xiánfēng Dì） → 同治帝（どうちてい、Tóngzhì Dì） → 光緒帝（こうしょてい、Guāngxù Dì） → 溥儀（ふぎ、Pǔyí）。咸豊帝の死後、皇太后慈禧（じき、Cíxǐ、西太后〈せいたいごう〉）が幼帝の母として権力を握った。光緒帝と慈禧が1908年に相次いで死に、幼い溥儀が即位したことで、危機時の王朝に成人君主が不在となった。
- **対外危機の官僚**：林則徐（りんそくじょ、Lín Zéxú）が道光帝の命でアヘンを取り締まり、イギリスと敵対。敗戦後は、条約を受け入れる宮廷内の別路線に押されて失脚した。
- **太平天国**：洪秀全（こうしゅうぜん、Hóng Xiùquán）が独自のキリスト教理解から太平天国（たいへいてんごく、Tàipíng Tiānguó）を建て、清と敵対。洪秀全が南京陥落直前に死ぬと、後継指揮系統は包囲を破れず政権が崩壊した。
- **清側の地方軍・洋務勢力**：曾国藩（そうこくはん、Zēng Guófān）の湘軍（しょうぐん、Xiāngjūn） → 李鴻章（りこうしょう、Lǐ Hóngzhāng）の淮軍（わいぐん、Huáijūn）。太平天国を倒して清を救ったが、兵と財源を地方大官へ集めた。
- **立憲改革派**：康有為（こうゆうい、Kāng Yǒuwéi）・梁啓超（りょうけいちょう、Liáng Qǐchāo）が光緒帝を支え、戊戌変法（ぼじゅつへんぽう、Wùxū Biànfǎ）を進める。慈禧側の政変に敗れ、光緒帝は幽閉、康・梁は亡命した。
- **新軍と革命派**：袁世凱（えんせいがい、Yuán Shìkǎi）が北洋新軍、孫文（そんぶん、Sūn Wén、Sun Yat-sen）が革命運動を組織し、清朝と敵対しつつ退位交渉では取引した。清は袁へ軍事権を委ねたため、王朝を救う将軍が王朝終焉を仲介する立場になった。

**やる夫**：
林則徐の取締りを、清の閉鎖性対イギリスの自由貿易だけで説明すると、アヘンという商品と主権問題が消える。
取締りを求める官僚と家族、利益を得る密貿易者、輸出市場を守りたいイギリス商人、戦費を負う沿岸住民で反応が違うお。

**やらない夫**：
アヘン戦争後の条約は港の開放、関税、領事裁判権などを変え、清の従来外交を崩す。
だが最大の国内危機は太平天国などの巨大反乱だ。
中央の八旗・緑営だけでは鎮圧できず、曾国藩や李鴻章が地域の紳士、郷里、給与関係で軍を作る。

**やる夫**：
反乱を鎮圧するため地方軍を強くし、軍需工場、造船、外国語学校を作る洋務運動が始まる。
国家再建に成功する一方、軍と財源が地方大官へ分散する。
清を救った仕組みが、中央の一体性を弱めるお。

**やらない夫**：
『蒼穹の昴』は、架空の若者と宦官を通して西太后、光緒帝、科挙、改革派の宮廷を見せる。[^27]
作品を見ると西太后を単なる怪物ではなく、満洲皇室、官僚、列強、軍、財政の均衡を取る政治家として想像できる。
ただし人物の内面と陰謀は小説的構成だ。

**やる夫**：
日清戦争敗北で、洋式艦船を買うだけでは制度全体の差を埋められないと分かる。
康有為・梁啓超らは教育、官制、産業まで変えようとし、光緒帝が戊戌変法を進める。
急改革を歓迎する若い知識人と、職を失う官僚、満洲皇族、実施能力を疑う地方官が衝突し、西太后側が政変で止めるお。

**やらない夫**：
義和団事件後、清朝自身が新政として新式学校、新軍、科挙廃止、立憲準備を進める。
改革が遅すぎたというより、改革によって旧制度に依存した人を動揺させ、新軍と地方議会という王朝外の政治力を育てた。

**やる夫**：
1908年に溥儀が即位し、1911年に武昌（ぶしょう、Wǔchāng）の新軍が蜂起する。
各省が独立し、袁世凱が清朝と革命派の間で交渉し、1912年に皇帝退位となる。
映画『ラストエンペラー』は、皇帝の権威が紫禁城の壁内だけ残り、外では共和国、軍閥、日本帝国、人民共和国へ世界が変わる感覚を見せるんだお。[^28]

**やらない夫**：
ただし溥儀を歴史に翻弄された被害者だけにせず、満洲国皇帝として日本の支配へ協力した責任も検討する必要がある。
伝記作品は、個人の視点が見せるものと隠すものを同時に読む教材だ。

---
### 8-11　清朝は満洲人の王朝だから革命されたのか

**やる夫**：
清末の革命は漢人が満洲人を追い出した民族革命だお？

**やらない夫**：
それは革命派の有力な言葉の一つだが、全体ではない。
立憲君主制、地方自治、共和制、漢人ナショナリズム、五族共和、社会革命など複数案が競争した。

**やる夫**：
清を満洲人の外国王朝として否定しつつ、清が支配したモンゴル、チベット、新疆を新しい中国の領土として継承しようとする。[^19]
帝国を壊しながら帝国の地図を引き継ぐ矛盾だお。

**やらない夫**：
まさに近代中国の中心問題だ。
臣民を皇帝へ属する多様な集団として束ねる帝国から、同じ国民が同じ主権を持つと称する国民国家へ移る。
言語、民族、国境を以前より明確に分類する必要が生じる。

---
### 8-12　世界同時刻盤――清は世界最大の帝国だったのか

**できる夫**：
清前半、日本は江戸時代、後半は明治維新へ！
ヨーロッパでは絶対王政、科学革命、産業革命、国民国家化！
インドではムガル帝国からイギリス支配、中東ではオスマンとカージャール、東南アジアでは海域国家が欧州植民地支配へ組み込まれます！
アフリカでは大西洋奴隷貿易、内陸諸国、19世紀後半の植民地分割が進みます！

**やる夫**：
18世紀の清は領土、人口、商業、生産で巨大だった。
19世紀の敗北を知っているから、最初から停滞国家だったように見るのは逆算だお。

**やらない夫**：
しかし長期平和に適応した低税・少数官僚・多層間接統治は、工業化した海洋帝国と大量動員型の近代国家に対して弱点を表す。

---
## 第9幕　皇帝を倒せば、王朝循環は終わるのか――中華民国・中華人民共和国

---
### 9-1　共和国を宣言すれば国民は生まれるのか

**やる夫**：
1912年、皇帝を倒して中華民国（ちゅうかみんこく、Zhōnghuá Mínguó、Republic of China）という共和国になったお！
これで王朝交代の歴史は終わり、全国民が中国人になるお！

**やらない夫**：
清の臣民は、満洲旗人、漢語諸地域の住民、モンゴル諸集団、チベット人、テュルク系ムスリム、回民、苗・瑶など、異なる政治関係で皇帝へ属していた。
皇帝を外したあと、何が全員を一つにする？

**やる夫**：
憲法、議会、国籍、学校、軍隊、標準語、国旗、歴史教育だお。
でも制度を宣言しても、地方軍は独自財源を持ち、村人は国会より宗族や郷紳に頼る。

**やらない夫**：
清末の新軍と地方財政を引き継いだ軍事指導者が競争し、北京＝東京の政府が全国を実効支配できない。
共和国という新しい正統性と、徴税・軍事・交通の実力が一致しない。

**やる夫**：
周王、後漢皇帝、唐末皇帝と同じで、正統な中央政府の看板があっても地方へ命令を強制できない状態だお。
制度名は近代でも、課題は続いてるお。

---
### 9-2　民国・人民共和国成立編――王統に代わる軍・政党・思想の継承線

**やる夫**：
清が退位して中華民国、国共内戦で中華人民共和国（ちゅうかじんみんきょうわこく、Zhōnghuá Rénmín Gònghéguó、People's Republic of China）。
王朝名が変わるのと同じだお？

**やらない夫**：
皇帝の家を替えるだけでなく、主権の持ち主を皇帝から国民へ置き換える試みだ。
しかし国民が先に一つになっていたわけではない。
軍、地方省、政党、学校、新聞、商会、農村、民族地域を新しい国家へ結び直す必要がある。

**できる子**：
近代は王統でなく、軍・政党・知識運動の継承線で並べる。

- **革命派から中華民国へ**：孫文 → 臨時大総統職を袁世凱へ譲渡。孫文の勢力は理念と組織を持つが軍が弱く、袁は北洋新軍と清朝官僚機構を持つため、両者の取引で皇帝退位が実現した。
- **北洋政府**：袁世凱が議会勢力と国民党に敵対し、帝政復活にも失敗。袁の死で部下をまとめる個人的中心が消え、北洋軍閥は複数派へ分裂した。
- **新文化運動**：陳独秀（ちんどくしゅう、Chén Dúxiù）・胡適（こてき、Hú Shì）・李大釗（りたいしょう、Lǐ Dàzhāo）が白話文、科学、社会主義など異なる路線を広げた。後に陳・李は中国共産党の創設へ関わり、胡適とは政治路線が分かれた。
- **国民党**：孫文 → 死後、蔣介石（しょうかいせき、Jiǎng Jièshí、Chiang Kai-shek）らが主導権を争う。蔣は国民革命軍で北伐を進め、1927年に共産党と敵対して南京国民政府を主導した。
- **中国共産党**：陳独秀らの党創設 → 毛沢東（もうたくとう、Máo Zédōng）が農村革命と軍事路線を形成 → 周恩来（しゅうおんらい、Zhōu Ēnlái）が党組織・外交・政府運営を担う。国民党と協力・敵対を反復し、1949年に中華人民共和国を成立させた。
- **改革開放への継承**：毛沢東の死後、後継争いと路線転換を経て鄧小平（とうしょうへい、Dèng Xiǎopíng）が改革開放を主導した。王朝の父子相続ではないが、指導者の死が政策連合を組み替える転機になった。

**やる夫**：
孫文は皇帝退位を得るため大統領職を袁世凱へ譲る。
清の官僚と新軍を壊さず共和国へ移す妥協だけど、袁は議会と政党を抑え、自ら皇帝になろうとして失敗する。
中央集権を急げば共和国の手続きが壊れ、手続きを優先すれば地方軍を統制できないお。

**やらない夫**：
袁の死後は各地の軍事政権が並立する。
1919年の五四運動（ごしうんどう、Wǔsì Yùndòng、May Fourth Movement）では学生、商人、労働者が外交と文化改革を結びつけ、文語から白話への転換、女性解放、家族批判、科学・民主主義などを論じる。[^20]
都市青年には解放でも、農村家族には生活保障を代替する制度がない。

**やる夫**：
国民党はソ連の組織技術を取り入れ、共産党と一時協力して北伐する。
1927年に分裂し、南京＝大阪の国民政府は関税、通貨、法、道路、教育を整えようとする。
都市商工業者は統一市場を歓迎する一方、農民には地方軍・地主・税の負担が残るお。

**やらない夫**：
日本の侵略は国民党政府と共産党を一時的に抗日へ向かわせ、大規模な人口移動と戦時動員を生む。
戦後の内戦では、国民党の都市・正規軍・国際承認に対し、共産党は農村組織、土地政策、規律、地方動員を強みにする。
1949年に中華人民共和国が成立し、中華民国政府は台湾へ移る。

**やる夫**：
人民共和国初期の政策反応札だお。

- 土地改革：貧農には土地と政治参加、地主層には財産と地位の喪失、村社会には長い対立。
- 婚姻法：女性と若者には離婚・婚姻選択の法的根拠、家長と宗族には秩序破壊。
- 第1次五カ年計画：都市労働者と技術者には工業化機会、農村には穀物供出と投資偏重。
- 大躍進：急速発展への動員が現場の誇張と資源配分の失敗を生み、深刻な飢饉へつながる。
- 文化大革命：既存官僚・教育制度への攻撃が若者の参加を促す一方、行政、教育、家族、文化財へ大きな混乱を与える。
- 改革開放：農家と企業に生産意欲と所得機会を与え、同時に地域・階層格差、出稼ぎ、社会保障の再編を生む。

**やらない夫**：
王朝史の問いは残っている。
中央が地方をどう統制するか、統一言語をどう広めるか、異なる地域を同じ制度で治めるか、市場の活力と国家管理をどう両立するか。
ただし正統性は天命ではなく、革命、民族、発展、選挙、法、生活向上など近代の言葉で争われる。

### 9-3　方言を標準語にすれば一つの国になるのか

**やる夫**：
地域ごとに言葉が通じないなら、北京語を全国へ教えればいいお。
同じ中国語なんだからすぐ普及するお！

**やらない夫**：
近代以前の官話は官僚の共通語で、全国民の母語ではない。
呉語、粤語、閩語、客家語、湘語、贛語などの中国語系諸言語は、互いに会話が通じない組み合わせが多い。
さらにモンゴル語、チベット語、ウイグル語、朝鮮語、チワン語など別語族の言語がある。

**やる夫**：
フランスが学校と徴兵でフランス語を広め、イタリアがトスカーナ系標準語を全国化したのに近いお。
標準語は自然に昔から全員が話していた言葉じゃなく、国家が学校・放送・軍隊で作る共通インフラだお。

**やらない夫**：
標準化は全国移動と教育を可能にする一方、地方語を遅れた言葉と扱い、地域文化を弱めることもある。
言語統一は便利さだけでなく権力の配分だ。

**やる夫**：
昔の漢文＝ラテン語的な文書統一から、近代は話し言葉まで統一しようとする。
国家が人間の口の中へ深く入るんだお。

### 9-4　家族を解体すれば個人は自由になるのか

**やる夫**：
新文化運動では儒教の家父長制が中国を弱くしたと批判する。
古い家族を壊し、個人、恋愛、科学を解放すればいいお！

**やらない夫**：
家族は抑圧の場であると同時に、年金、教育、就職、信用、介護、災害救済を担っている。
国家福祉が弱いまま家族だけ解体すれば、個人は何に支えられる？

**やる夫**：
自由になるけど孤立もする。
女性の婚姻自由、足纏の廃止、教育拡大は重要だお。
でも都市知識人の家族像を農村へそのまま当てると、生産と扶養の単位を失わせるお。

**やらない夫**：
国民党も共産党も、宗族や地方有力者を弱め、国家が個人を直接把握しようとする。
秦以来の課題が、戸籍、学校、党組織、近代警察、土地調査という新技術で再登場する。

### 9-5　抗日戦争は中国を統一したのか

**やる夫**：
日本の侵略に対し、中国人が一致団結したから近代国民が完成したお？

**やらない夫**：
共通の外敵は国民意識を強める。
しかし国民政府、共産党、地方軍、占領下の協力政権、地域社会は異なる戦略を取る。
戦争は統一と分裂を同時に進める。

**やる夫**：
南京＝大阪が陥落し、政府は重慶（じゅうけい、Chóngqìng）へ移る。
沿海工業や学校が内陸へ移転し、西南地域と中央政府の結びつきが強まる。
一方で徴兵、徴税、物価上昇が農村を疲弊させるお。

**やらない夫**：
戦後の国共内戦では、どちらが近代国家をより強く組織できるかが問われる。
理念だけでなく、土地、兵站、農民動員、官僚規律、通貨への信頼が勝敗を左右する。

### 9-6　人民共和国は歴代帝国を全否定したのか

**やる夫**：
1949年の人民共和国は、皇帝、地主、宗族、儒教、外国支配を否定した。
中国史をゼロからやり直したんだお！

**やらない夫**：
思想と所有制度は大きく変えた。
土地改革、集団化、党組織、計画経済によって、国家が村と個人へ直接入る力は歴代王朝よりはるかに強くなる。

**やる夫**：
でも広大な領域を中央から統治し、標準文字と標準語を広め、戸籍で人口移動を管理し、辺境地域を行政単位へ組み込む課題は歴代帝国から続くお。
答えは違っても問題設定が似てる。

**やらない夫**：
民族区域自治と56民族の分類は、清の複数身分・複数統治をそのまま残したものではない。
近代民族学と社会主義国家が、流動的だった地域名・言語共同体・歴史名を全国的な分類へ整理したものだ。

**やる夫**：
分類すれば権利や自治、教育政策を設計できる。
同時に、連続的で重なっていた自己認識を固定する力もあるお。
「昔から56民族が同じ形でいた」わけじゃないんだお。

### 9-7　大躍進と文化大革命は、中央集権の失敗なのか

**やる夫**：
中央が全国を直接動かせるなら、地方豪族や軍閥の問題は解決だお。
正しい目標を全国一斉に実行できるお！

**やらない夫**：
中央目標が誤っていた時、地方が異論を言えず、成果を誇張して報告したら？

**やる夫**：
誤情報が上へ集まり、さらに高い目標が下り、全国規模で損害が拡大する。
地方分権なら地域差が生じるけど、中央集権は中央の誤りを全国化するお。

**やらない夫**：
文化大革命では、官僚制の固定化を大衆運動で破ろうとし、党・学校・家族・文化権威を攻撃する。
しかし既存制度を壊せば権力が消えるのではなく、軍、派閥、個人的権威へ移る。

**やる夫**：
明の丞相廃止と同じだお。
役職を消しても調整機能は必要で、非公式権力が生まれる。
王朝が変わっても、権力の空白は空白のまま残らないお。

### 9-8　市場を戻せば国家は弱くなるのか

**やる夫**：
改革開放で市場と外国資本を入れたら、計画国家を否定して自由放任へ戻ったんだお？

**やらない夫**：
国家は市場を放置したのではなく、特区、土地制度、国有企業、金融、戸籍、インフラ投資を通じて成長を設計した。
明が固定戸籍を掲げながら銀経済へ適応したように、理念と運用を調整する。

**やる夫**：
上海＝横浜、広州＝長崎、深圳（しんせん、Shēnzhèn）など沿海都市が世界市場へつながり、内陸から大規模な人口移動が起こる。
でも戸籍によって教育・福祉へのアクセスが違い、移動する労働者と都市住民の権利が同じではないお。

**やらない夫**：
沿海の成長、内陸格差、地方政府の競争、中央の統制を同時に見る。
市場対国家という二択ではなく、国家が市場を作り、市場が国家の財政と社会を変える循環だ。

### 9-9　世界同時刻盤――中国史は世界史の外にあるのか

**できる夫**：
中華民国から人民共和国の時代、日本は帝国化、敗戦、高度成長へ！
ヨーロッパは2度の世界大戦、植民地帝国の解体、EU形成！
中東・インド・東南アジア・アフリカでは植民地支配から独立国家が生まれ、冷戦と開発政策が進みます！

**やる夫**：
中国だけが伝統から近代へ遅れて移ったんじゃない。
オスマン、ロシア、ハプスブルク、ムガルの旧帝国圏も、多民族帝国の領域を国民国家へ変える難題を抱えたお。

**やらない夫**：
違いは、中国では王朝国家の官僚制と領域的連続が強く、帝国崩壊後も統一国家を再建する目標が主要勢力に共有されたことだ。

## 第10幕　王朝が滅びても、誰が中国を運んだのか

### 10-1　永久国家の設計図に、誰がいないのか

**やる夫**：
完成したお！
周の分権、秦の中央集権、漢の儒教、唐の国際性、宋の文治、元と清の複合統治、近代国家の直接統治を全部載せた、永久に滅びない国家の設計図だお！
これを歴代皇帝に売れば、やる夫は時空を超えて宰相だお！

**やらない夫**：
その設計図、つまみが全部「最大」になっているぞ。
三つだけ同時に動かしてみろ。
地方へ裁量を与え、軍人を強くし、住民を同じ制度へ統一する。

**やる夫**：
地方は現地事情へ対応できて、強い軍で国境を守り、制度は全国一律。
完璧だお！

**やらない夫**：
では唐の節度使に、草原の騎馬軍団と農耕地の戸籍を同じ規則で管理させる。
辺境で異変が起きたが、長安の許可なしには動けない。
動く権限を与えれば、徴税も兵士の任命もその将軍へ集まる。

**やる夫**：
……つまみがぶつかったお。
中央の命令を待たせれば国境対応が遅れ、現地裁量を渡せば節度使が自前の軍と財源を持つ。
しかも農耕地と草原へ同じ制度を押しつけたら、どちらかの暮らしを壊すお。

**やらない夫**：
なら、地方裁量を切れ。
軍人も弱くし、税を軽くして反乱を防げ。

**やる夫**：
それなら宋みたいに国内の軍事政変は抑えやすいお。
でも国境の判断は遅れ、軽い税では治水、軍、防災、官僚を全部は維持できない。
中央が間違えば、地方が止められず全国へ一斉に広がるお。

**やらない夫**：
つまみの唯一の正解は？

**やる夫**：
ないお。
制度には解決した問題の形が刻まれていて、環境が変われば長所が短所になる。
だから永久に正しい位置ではなく、誰の負担で動き、どの前提が崩れたかを測って調整し続けるしかないお。

**やらない夫**：
惜しい。まだ主語がない。

**やる夫**：
主語？
皇帝と官僚が調整するんじゃないのかお？

**やらない夫**：
北魏が華北を治め、隋唐の骨格を用意したのは誰だ。
遼・金・元・清が、農耕地だけでなく草原、森林、オアシス、高原を結んだのは誰だ。
明が北方へ備えた軍制も、清が築いた広域支配も、「中原の王朝」だけ眺めて説明できるか？

**やる夫**：
……できないお。
やる夫の設計図には、制度の名前は全部あるのに、それを別の土地へ運び、翻訳し、組み替えた人々がいない。
王朝を箱、周辺民族を箱の外から来る敵として描いたせいで、箱が壊れた後に誰が材料を拾ったのかが消えていたお。

**やらない夫**：
だから最後の試験は、新しい制度を一つ選ぶことじゃない。
序幕で預けた「人・言語・政治・名前」の4本の線を、全部の札へ引き直すことだ。

**やる夫**：
一覧は暗記の付録じゃないんだお。
王朝表だけでは見えない継承者を戻して、やる夫の設計図に欠けていた主語を検査する表なんだお。
よし。今度こそ、名前が似ている順には並べないお。

### 10-2　最終系譜札で、四つの線を引き直す

**やる夫**：
王朝順に、匈奴から鮮卑、突厥、契丹、女真、モンゴル、満洲へ一本の矢印を引いたお！
北方民族の進化ツリー、完成だお！

**やらない夫**：
序幕から何も学んでいない。
では女真から満洲への線と、匈奴からモンゴルへの線を、同じ太さで引いてよい理由を説明して。

**やる夫**：
どっちも古い名前が消えて、後の強い集団が現れたから……。
あっ、それは王朝表で隣り合っているだけだお。
女真から満洲には言語・氏族・政治組織・名称変更の連続がかなり見えるけど、匈奴からモンゴルには同じ4本がそろわないお。

**やらない夫**：
もう一問だ。
ソグド人という国家名も民族名も中国史の表から消えた。
なら、彼らが運んだ交易、宗教、芸術、人の系譜もそこで消滅したのか？

**やる夫**：
しないお。
名前の線が切れても、人が定住して別の家系や戸籍へ入り、技術や文化が別の社会へ渡ることはある。
逆に同じ名前が残っても、参加する人や意味が入れ替わることがある。

**できる子**：
合格。
だから矢印一本の系譜図は捨てる。
「後へ残った線」と「直結させてはいけない点」を同じ行へ置けば、継承と断絶を同時に読める。

| 古い集団・国家 | 後の時代へ残った主な線 | 直結させてはいけない点 |
|---|---|---|
| 匈奴 | 華北へ移住した人々、草原帝国の編成技術、単于などの政治記憶 | 突厥・モンゴル・欧州フンの単純な直系と断定しない |
| 鮮卑 | 拓跋北魏、慕容諸国、宇文北周、隋唐の北西軍事貴族、契丹との遠い連関 | 鮮卑全体を一民族・一言語とみなさない |
| 羯 | 後趙などの支配集団、華北社会への吸収 | 出自・言語が不明で、後世民族へ線を引けない |
| 氐・羌 | 前秦・後秦など、西北・四川・高原東縁の諸集団、党項・チベット系諸社会との地域的連関 | 現代羌族・チベット人へ一対一対応させない |
| 柔然 | 草原連合の制度、一部集団の突厥その他への編入 | アヴァールとの同一性を確定事項にしない |
| 突厥 | テュルク語と可汗国伝統、中央アジアの多数のテュルク系国家 | 現代トルコ人だけの祖先、または全テュルク系民族の単一祖先としない |
| 回鶻 | 甘州・天山・タリム盆地への移住、文字、仏教・マニ教文化、現代ウイグル形成への寄与 | 可汗国の住民と現代ウイグル人を無変化で同一視しない |
| 吐蕃 | チベット語文書、王権、仏教受容、高原の政治的記憶 | 吐蕃帝国の全臣民と現代チベット民族を同一視しない |
| 契丹 | 遼、西遼、金・元へ入った契丹系家門、モンゴル語族に近い言語 | モンゴル人の旧名としない |
| 党項 | 西夏、独自文字、チベット・ビルマ語派の言語、北西地域文化 | 古代羌・現代民族へ単純直結しない |
| 女真 | 金、明代女真、後金、満洲への言語・氏族・政治的連続 | 満洲共同体に編入された漢人・モンゴル人を無視しない |
| モンゴル | 元、北元、東部モンゴル、オイラト、現代モンゴル諸集団 | 匈奴・鮮卑・契丹の単なる改名としない |
| ソグド人 | 中国・中央アジアへの定住、交易、宗教、芸術、家系の同化 | 国家名・民族名の消失を全滅とみなさない |
| 百越 | 華南・東南アジア北部の多様な言語・文化集団への人口的・文化的連関 | 一つの越民族だったとしない |
| 苗・瑶 | 南方山地の共同体、言語・祭祀・移住史、現代民族形成の素材 | 歴代史料の分類と現代公式民族を同一範囲としない |

**やらない夫**：
表から、4本の線が比較的重なる例と、名前が消えても別の線が残る例を一つずつ拾え。

**やる夫**：
この表で同じ名前を探しても、一直線の家系図にはならないお。
でも線が切れた場所ばかりでもない。
女真から満洲のように複数の線が重なる例、回鶻から現代ウイグル形成のように寄与はあるが同一ではない例、匈奴や羯のように分からない部分を残す例が、同じ基準で区別できるお。

**やらない夫**：
では、この表を王朝一覧の後へ置く理由は？

**やる夫**：
王朝一覧は、国家がいつ交代したかを見せる。
この表は、その境目を越えて**誰が人・言語・政治・名前を運び、どの線が切れたか**を見せる。
最後に置くのは周辺をおまけで足すためじゃない。王朝だけで読んだ結論が、本当に中国史全体で成り立つかを一番厳しく検算するためだお。

---
### 10-3　同じ花を咲かせたのは誰か

**やる夫**：
中国史は、漢民族の国に外から別民族が交代で侵入する話じゃない。[^14]
黄河、長江、草原、東北森林、チベット高原、オアシス、南海の社会が、人と制度を交換しながら何度も「中国」を作り直す話だお。

**やらない夫**：
そして漢人という共同体自体も、その交換の外側にある純粋な固定集団ではない。
古代の華夏（かか、Huáxià）、漢帝国の臣民、中世の文化・政治分類、近代民族としての漢族（かんぞく、Hànzú、Han Chinese）は、重なりながら意味を変えてきた。

**やる夫**：
王朝名だけ覚えると、滅亡のたびに世界がリセットされて見える。
制度、人、言語、都市の札を追えば、国家は倒れても材料は次へ渡る。
前王朝の失敗を否定しながら、前王朝の成功を盗んで、新しい環境に合わせ、また別の歪みを作る。
それが中国史なんだお。

**できる子**：
最後に一つ、札ではなく詩を置く。
初唐の劉希夷『代悲白頭翁』の一句。

> 年年歳歳　花相似たり
> 歳歳年年　人同じからず

**やる夫**：
毎年同じ花が咲くけど、それを見る人は毎年入れ替わる……。
これ、王朝の話にそのまま使えるお。長安の春は何度も来て、そのたびに見ている王朝が違うんだお。

**やらない夫**：
半分は合っている。だが中国史では、その一句をもう一度ひっくり返す必要がある。

**できる子**：
花は自然に同じ形で咲き直すのではない。
郡県も、戸籍も、科挙も、複合統治も、誰かが前の株から枝を切り取って、別の土に接ぎ木したから同じ形に見える。

**やらない夫**：
劉希夷が長安でこの詩を書いたとき、彼を養っていた唐の骨格――均田、府兵、律令――は隋から接いだ枝で、その隋の枝は北朝の、鮮卑系軍事貴族の土に根を張っていた。
花を咲かせていたのは自然の循環ではなく、名前を変えながら株を運び続けた人々だ。

**やる夫**：
じゃあ順番が逆だお。
人が同じでないからこそ、花を似せるために毎回誰かが接ぎ木した。
似ているのは放っておいた結果じゃなくて、作り直した結果なんだお。

**やらない夫**：
そう読めたなら、この教材の札は全部使えている。
次に王朝表を見るときは、滅亡の年号ではなく、そこで誰がどの枝を持って逃げたかを探せ。
