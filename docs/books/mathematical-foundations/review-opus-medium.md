# 寸評：やる夫で学ぶ数学基礎論 ── 数学は何でできているか

約260KB／全6幕＋幕間4本＋付録。骨折入院6週間を舞台に、「1+1=2 はなぜ正しいか」から不完全性定理・独立性・P対NPまでを、対角線論法という単一の型の反復として一本に通した長編。

## 良い点

**対角線論法に通し番号を振り、教材全体の背骨にしている。** 1047行目で「今のが1回目だ」と宣言し、冪集合で2回目（1174行目）、ラッセルで3回目（1314行目）、停止性問題で4回目（3094行目）、ゲーデル文で5回目（3626行目）と、やる夫自身に数えさせる。しかも「はみ出し者の搭乗資格を確認する」という副次ルール（1034–1042行目）が2回目以降も毎回律儀に適用され（1191–1194行目、3098–3101行目）、型の再利用が標語でなく実作業になっている。最終幕の総括（4505–4520行目）で「同じ一つの型が、楽園も廃墟も両方作った」に着地するのは見事。

**喩えの「ズレの検分」が制度として機能している。** プロローグ49–53行目で「喩えで分かった気になったら、そのズレを毎回セットで確認する」と契約を結び、実際に椅子取りゲーム（828–830行目）、床屋（1360–1383行目）、街とご近所（2011–2023行目）、zipファイル（2608–2612行目）、合わせ鏡（3701–3705行目）、保証人の連鎖（4044–4048行目）で6回以上履行される。特に床屋の検分で「欠けているのは追い詰められ具合だ」（1376–1378行目）に到達させるのは、喩えの限界を教材の内容そのものへ変換した好例。

**やる夫が実際にバグを作り、そのバグが後で武器になる。** +1マシンの停止忘れで無限ループを踏む（2780–2798行目）。やらない夫が「後で主役級になる。捨てずに取っておけ」（2814行目）と言い、実際に停止性問題の天邪鬼マシン $D$ の部品として再利用される（3035行目）。「失敗作が定理の証明の部品になる」という構造は、この教材の再発見設計の白眉。

**保留リスト方式で問いを預け、全部返している。** 保留1（338行目）→ 第二不完全性定理で回収（3812行目）、保留2・3（1069行目、2518行目）→ 独立性で回収（4143–4157行目）、保留4（2519行目）→ 第一不完全性定理で回収（3425行目）。2516–2520行目で在庫を数え上げる場面があり、読者も残債を把握できる。

**誤解の焼却が具体的かつ網羅的。** 「NP＝Not Polynomial」（4311–4318行目）、「量子コンピュータでNP完全瞬殺」（4399–4414行目）、「ゲーデル文は真偽不明」（3652–3659行目）、「人間の知性は機械を超えている」（3706–3726行目）、「バナッハ＝タルスキーは矛盾」（1713–1735行目）。しかも4528–4542行目で11個を一覧にして「全敗だお」と締める。動画で単語だけ覚えた冒頭のやる夫（22–25行目）への回答として完結している。

**ケーニヒスベルクの円環。** 第1幕でオイラーの橋の街として登場（346行目）した都市が、第5幕でゲーデルの公表とヒルベルトの「我々は知るであろう」演説の舞台として再登場する（3863–3884行目）。伏線ではなく史実の一致だが、配置が完全に効いている。

**参考文献33点が本文の脚注として貼られている。** BB(5)=47,176,870とCoq検証（3143–3146行目、[^30]）、グッドスタイン数列の $3 \cdot 2^{402653211} - 2$（4224行目、[^20]）など、具体値に個別の出典が付いている。

## 欠点

**やる夫が要所で強すぎる。** クラトフスキの順序対 $(a,b) = \{\{a\},\{a,b\}\}$ を、「袋は入れ子にできる」というヒント1つで一発正解する（1863–1873行目）。やらない夫自身が「よく再発明した」（1876行目）と言うが、これは数学史上でも非自明な工夫で、この教材の他の箇所（水滴、平行線、内包原理）で必ず1回は転ばせてきた設計と釣り合っていない。同様に、ゲーデル数の素数冪方式（2560–2568行目）も「連結は復元不能」の1往復だけで着地する。

**最大の定理で、やる夫の仕事が最小になっている。** 第二不完全性定理（5-3）の核心 $T \vdash (\mathrm{Con}(T) \to G)$ は、3798行目でやらない夫から丸ごと支給される。やる夫がやるのは、そこからの三段論法（3803–3805行目）だけ。3786–3790行目で「推論そのものをゲーデル数化して T の棋譜として再現できる!?」と気づく場面はあるが、そこから先の作業が一切ない。第一定理では5-1（停止性経由）と5-2（ゲーデル文）の2ルートを歩かせたのに、第二定理だけ受け身。

**看護師とできる夫が、人物紹介で与えられた役割を果たしていない。** 10行目で看護師は「素朴な質問が急所に刺さるタイプ」、12行目でできる夫は「素人の直観で専門家の急所を突く」と設定される。ところが看護師の「何かの役に立つんですか」（1472行目）はやる夫が答えられず、やらない夫が助け舟を出して終わる（1479–1502行目）。できる夫の「無限公理は無から作れてない」（2228–2232行目）はやる夫が即答して終わる（2236–2244行目）。どちらも本筋の論証を1ミリも動かしていない。急所を突く役なら、その質問がきっかけで次の概念が要請される構造が要る。

**物語的な圧力がほぼゼロ。** 「入院あと6週間」（34行目）という時計はあるが、期限が切迫して何かが困る場面が一度もない。第5幕終盤でやらない夫が手術で中断する（3923行目）のが唯一の中断だが、翌々日に何事もなく再開される。同リポジトリの熱力学教材が「刷ってしまった横断幕」で第9幕を実務判断の幕に変えたような、理論の外側からの圧力がない。骨折・松葉杖は喩えの供給源としては優秀（53行目、193行目、4640–4641行目）だが、ドラマの駆動装置にはなっていない。

**3-3の構成ラッシュが箇条書きで流される。** 1881–1888行目で関数・整数・有理数・実数の集合による構成が4行の箇条書きで通過する。実際にやる夫が抵抗するのはデデキント切断の循環疑い（1890–1908行目）だけ。整数を自然数のペアで作るときに同値関係（$(a,b) \sim (c,d) \iff a+d=b+c$）が必要になることは、「$3-1$ と $4-2$ が同じ整数」という具体例で必ず躓く箇所であり、ここを飛ばしたぶん「全数学が空集合から組み上がる」（2029–2033行目）の実感が薄い。

**6-3のP対NPだけ再発見の型を外れている。** PとNPの定義がやらない夫から天下りで与えられ（4281–4308行目）、やる夫の仕事は $29!/2$ の計算（4272–4276行目）と誤解の訂正（4311行目）に限られる。他の幕では必ず「素朴案→反例→定義」の順で進むのに、ここだけ「定義→例」。教材の最終盤で型が崩れるのは惜しい。

**やる夫の「記号で目が滑る」設定が中盤以降で消える。** 44–45行目の自己申告と49行目の「例えで頼む」条項は、2393行目（$\forall$ って何だお）まではよく効いているが、第5幕では $\mathrm{Con}(T) := \neg\mathrm{Prov}(\ulcorner 0=1 \urcorner)$ を自分から書き下す（3765行目）。成長として読める一方、成長の描写が一度もないため、キャラクターの一貫性としては切れている。

## 改善案

1. **クラトフスキの順序対で一度失敗させる。** 1863行目の前に、やる夫の素朴案 $(a,b) = \{a, \{b\}\}$（後ろだけ袋に入れて印を付ける）を出させる。これは $a$ 自身が袋だった場合、たとえば $a = \{1\}, b = \{1\}$ のときに $(a,b)$ と $(b,a)$ が同じ集合に潰れる。この反例をやらない夫が出し、「印は片方だけに付けるのでなく、両方に共通のものを1つ入れて非対称を作る」という要請を先に発見させてから $\{\{a\},\{a,b\}\}$ へ進ませる。10〜15行で済み、この教材唯一の「一発正解の大工夫」が解消する。

2. **第二不完全性定理で、形式化の手作業を1つやらせる。** 3790行目の気づきの後に、導出可能性条件を1本だけ具体例で確認させる。たとえば「$T$ が $0=1$ を証明したなら、その棋譜のゲーデル数 $m$ は具体的な数だから、$T$ は『$m$ は $0=1$ の証明である』という数の主張も証明できる」を、4-3のzip開封の作業（2612行目の「2でちょうど7回割れる」）に接続して、やる夫に確かめさせる。これで $T \vdash \mathrm{Con}(T) \to G$ が支給品でなくなる。

3. **看護師とできる夫に、本筋を動かす質問を1回ずつ与える。** 看護師の1472行目「役に立つんですか」を、やらない夫の助け舟ではなく、やる夫が答えられずに持ち帰る形で終わらせ、その未解決が第4幕の「計算可能数」（1499–1502行目）へやる夫自身の動機として繋がるようにする。できる夫には2256行目の再登場（退院後）を実際に書き、第6幕で「ZFCが矛盾したら銀行は止まるのか」（4069–4070行目）を彼に言わせる。素人の実務的な問いとして、やる夫の口から出るより自然で、キャラクターの設定通りになる。

4. **期限を1本入れる。** 34行目の「6週間」を、たとえば「退院日に、同室の患者やリハビリ仲間に『数学とは何か』を説明する約束をした」程度の宣言に変え、第2幕の幕間（1440–1509行目、看護師への説明）を予行演習、エピローグ直前を本番として置く。全面改稿は不要で、プロローグに3行、幕間に2行、6-4の総括（4466行目以降）を「本番のスピーチ」として枠付けするだけで、4553–4556行目の最終回答が「試験の答案」から「約束の履行」に変わる。

5. **整数の構成を1つだけ実演させる。** 1882行目の箇条書きを分解し、「整数はペア $(a,b)$ で『$a-b$ のつもり』」を与えたうえで、やる夫に $(3,1)$ と $(4,2)$ を比較させる。どちらも 2 のつもりなのに集合としては別物、という食い違いに躓かせ、「同じ整数とみなす」という約束（同値関係）が別途要ると発見させる。20行程度で、第1幕の外延性クイズ（468–487行目）と呼応する。

6. **6-3をNPの定義から再発見型に戻す。** 4295行目のナンプレの非対称性（解くのは大変／検算は一瞬）を先に置き、やる夫に「この非対称を測る言葉が要る」と言わせてから、彼自身に「答えを見せられたら速いクラス」を定義させる。そのうえでやらない夫が名前（NP）を与え、直後に4311行目の「Not Polynomialだお！」の誤解を踏ませる。順序を入れ替えるだけで、他の幕と同じ型に揃う。

7. **やる夫の「目が滑る」体質の卒業を1度だけ描く。** 第5幕のどこか、たとえば3765行目で $\mathrm{Con}(T)$ を自分で書き下した直後に、やらない夫の一言（「プロローグで記号から逃げていた男が、自分から式を書くようになったな」）と、やる夫の自己認識を2〜3行入れる。6週間の成長を明示すると、44–45行目の設定が回収される。
