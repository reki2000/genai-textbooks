# やる夫で学ぶこころの支援 ― 相談先を選び、関係を育て、変えていく

---
## 登場人物

**やる夫** ── 会社員。できる夫とは小学校以来の幼馴染で、父親の一号店時代からの常連客。

**やらない夫** ── 地域医療と精神保健福祉の連携に関わる精神科医。

**できる子** ── 公認心理師・臨床心理士。地域の相談支援を補助するAI「ココロ」を開発している。

**できる夫** ── やる夫の幼馴染。地域で七店舗の焼肉チェーンを経営し、八店舗目の開店を控える創業社長。

**ココロ** ── 相談の準備と、本人・支援者・専門家の情報整理を補助する支援AI。

!> このコンテンツは生成AIによって作成された一般的な学習用情報であり、実際のこころの支援・診断・治療に代わるものではありません。こころの不調について相談する際は、医師や公的な相談窓口などに相談してください。

### 1-3　科名の前に切り分ける

**できる夫**：
スマホで検索結果を開きました！！
精神科、心療内科、カウンセリング！！
検索するほど候補が増えます！！
焼肉屋ならメニューを見れば何が出るか分かりますが、心療内科のメニューはどこですか！！

**できる子**：
始める前に確認する。
今日は相談先を調べるための一般的な整理で、診断を確定する診察ではない。
記録は保存しない。
やる夫とやらない夫が同席してよい？

**できる夫**：
同意します！！
ただし、私が止めた話題はそこで止めてください！！

**やる夫**：
ここはやる夫に任せるお。
動悸と胃痛は体だから心療内科、寝不足と確認は心だから精神科、仕事の悩みはカウンセリングだお。

**できる夫**：
体、心、仕事で3軒ですか！！
通院だけで定休日が終わります！！

**できる子**：
語の一致で振り分けた。

**やる夫**：
検索とはそういうものだお。

**やらない夫**：
心療内科は本来、心理社会的な要因が発症や経過に関わる身体疾患、つまり心身症（psychosomatic disorder）を主な対象にする。
ただし実際には、心療内科の看板で一部の精神疾患を診る施設もある。
精神科はこころの病気を専門に診るが、得意分野や提供する治療は施設ごとに違う。[^1]

**できる子**：
「何を主に診るか」と「そこで何ができるか」を分ける。

| 相談先 | 主に担うこと | できることの例 | それだけではできないこと |
|---|---|---|---|
| 精神科 | 気分、思考、行動、睡眠などを含む精神面の医学的評価と治療 | 医師による診断、検査の検討、薬の処方、診察。施設によって心理療法や入院治療 | すべての身体疾患を一施設で除外すること。心理面接や福祉・職場調整が必ず受けられるとは限らない |
| 心療内科 | 心理社会的要因が関わる身体疾患の医学的評価と治療 | 医師による診断、身体面を含む検査の検討、薬の処方、診察 | 看板だけで、精神疾患全般や心理療法を扱うとは判断できない |
| カウンセリング・心理相談 | 困りごと、感情、考え方、行動、関係を面接で整理し、変化を一緒に試す | 訓練を受けた心理職による心理的評価、心理療法、意思決定や生活上の相談 | 医療機関で医師が担当する場合を除き、医学的診断、薬の処方、身体疾患の検査はできない |

**やる夫**：
精神科と心療内科は医療だから、医師が診断や処方を担える。
カウンセリングは話を聴くだけとは限らず、心理的な評価や治療をする場合もあるけど、その名前だけでは担当者の資格も方法も分からないお。

**やらない夫**：
それに、精神科の診察と心理職の面接を同じ施設で受けられる所もあれば、別々につなぐ所もある。
科名は入口の手掛かりであって、担当者、検査、心理療法、連携先まで保証する商品名じゃない。

**できる夫**：
看板だけではメニューが分からないじゃないですか！！

**やらない夫**：
だから電話や公開情報で、何を診て何を提供しているか確かめる。
だが、その前に順番がある。

**やる夫**：
人気順だお？

**やらない夫**：
緊急性だ。
できる夫、今この場で強い胸の痛みや呼吸の苦しさ、意識が遠のく感じはあるか。

**できる夫**：
今はありません！！

**やらない夫**：
自分を傷つけたい、消えてしまいたいという考えは。

**できる夫**：
ありません。
今のところ、その考えはありません。

**やらない夫**：
急に安全を保てない状態や、命に関わる身体症状があるなら、予約先の比較より緊急対応が先になる。
今の返答だけで今後の安全を保証できるわけではないが、少なくとも現在の行き先を考える材料にはなる。

**やる夫**：
最初の分岐は病名じゃなくて、待って選べる状態かどうかなのかお。

**できる子**：
次に、ココロの一時切り分けを本人と作る。
点数は確定値に見えるから、まず「未確認／少しある／目立つ／優先して確認」で置く。

| ベクトル | 仮の優先度 | 現在の手掛かり |
|---|---|---|
| 身体・生理 | 優先して確認 | 動悸、胃痛、食欲、睡眠 |
| 感情・思考 | 目立つ | 焦り、仕事から離れたときの不安 |
| 行動・生活機能（functioning） | 目立つ | 深夜の確認、判断の集中 |
| 関係・安全 | 未確認 | 店長との関係、孤立、安全上の懸念 |
| 環境・制度 | 目立つ | 八号店の期限、社長への決裁集中 |
| 意味・価値 | 未確認 | 仕事が本人にとって何を意味するか |

**できる夫**：
意味・価値は「会社を守る」で確定です！！

**できる子**：
会社の何を守るのかは未確認。

**できる夫**：
売上、雇用、店長、取引先、常連客、父から借りた最初の店舗名、それから──。

**やる夫**：
一つじゃないお。

**できる夫**：
……会社を守ると言えば一項目だと思っていました！！
でも、売上を守ることと、私が全部決めることと、従業員の生活を守ることは、同じではないかもしれません！！

**やらない夫**：
病名を決める前でも、それだけは分けられる。

**やる夫**：
じゃあ、6項目を見て精神科か心療内科か選ぶお。

**やらない夫**：
まだ一軒に畳む気か。

**やる夫**：
だって相談先を選ぶための表だお。

**できる子**：
表が示すのは、誰と何を確かめる必要があるか。
一人が全部を担当するとは限らない。

**できる夫**：
では最初に何をしますか！！
15分はもう超えています！！

**やる夫**：
身体症状を「ストレス」と決めず、まず医学的に確認するお。
同時に、どの場面で何が起きるか、生活と仕事の経過を整理する。
それを持って、実際に何を診られる施設か問い合わせるお。

体の症状はこころの不調でも現れる一方、体の病気が関係する場合もあるから、最初から片方に決めないんだお。[^2]

**できる夫**：
病名は出ないんですか！！

**やる夫**：
今日は出さないお。

**やる夫**：
店長が間違えたら。

**できる夫**：
許容範囲の失敗は、権限を返す理由にしません！！
重大安全基準だけは即時連絡し、通常の改善は翌週の会議で扱います！！

個人の症状が下がれば成功じゃないのと同じだお。

**できる夫**：

**やる夫**：

**できる夫**：
来すぎです！！

|---|---|
| しないこと | 診断の確定、専門家ランキング、治療の自動決定 |
| すること | 情報源の表示、本人の同意、仮説と反例、役割と共有範囲、見直し時期の記録 |
| 警告すること | 緊急性の可能性、急な悪化、支援の空白、測定されていない領域 |

ココロは私を切り分けて箱へ入れる機械ではありません！！
私と支援者が、違う見方を混ぜずに置き、次に何を確かめるか話す共同仮説ノートです！！

**やらない夫**：
専門家同士の役割と連絡先を本人が理解し、誰へ何を相談するか分かることも、継続支援の一部だ。[^13]

**やる夫**：
戻る条件があるなら、終了は「二度と困るな」という追放じゃないお。

**できる子**：
支援者側から終了や異動が必要な場合も、理由、引き継ぎ、空白期間、緊急時の窓口を確認する。

**やる夫**：
支援を増やすことが目的じゃないお。
必要な機能がつながり、できる夫が自分で経路を変えられることが目的だお。

**できる夫**：
関係を持つ力だけでなく、関係を安全に変える力も回復の一部です！！

**やる夫**：
心理面接の間隔を空けた週に不安が増えたら、元へ戻すのは敗北かお？

**できる夫**：
いいえ！！
予定した戻り方を使い、何が変わったか確認します！！

**できる子**：
段階的に減らすことも、必要時に増やすことも、同じ見直し。

**やる夫**：
支援の量を一方向の成績にしないお。

**できる夫**：
減らす支援は、利用回数だけで決めればよいですか？

**やる夫**：
その支援が担当した仕事を、自分や別の関係で扱えるかを見るお。

**やらない夫**：
役割が空白になるなら、回数だけ減らすな。

**できる夫**：
人を外す前に、機能がどこへ移るかを確認します！！

**やる夫**：
逆に役割が重なり、同じ記録を何度も作るなら統合できるお？

**できる子**：
本人の負担と情報共有の必要性を確認して、窓口や記録を整理できる。

**できる夫**：
支援網そのものにも、維持ループがないか点検します！！

**やる夫**：
助けを増やし続ける不安確認にしないお。

**できる夫**：
不安が3以下なら心理面接終了、4以上なら再開という自動ルールはどうですか！！

**やらない夫**：
不安3でも、食べられず仕事が集中していたら。

**やる夫**：
一つの点数で関係を開閉できないお。
症状、機能、本人の希望、残った課題、再開経路を一緒に見るお。

**できる夫**：
終了判定もココロへ任せず、支援者と私で理由を確認します！！
