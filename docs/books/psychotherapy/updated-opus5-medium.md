# 改稿記録

`review-opus-medium.md` の6つの改善案に沿ってリライトした。指摘の中心は「数式と数字が一度も計算されない」「登場人物が使い捨て」「事業側に緊張がない」の3点だったので、既存の強み（5-2の基準の矛盾、Gさんでの数値と語りの並置、7-1の安全側の失敗、9-3のAさん再発）には手を入れず、その周りを計算と因果でつなぎ直した。

## 主な変更

- **3-1の98%を陽性的中率まで計算させた。** 感度・特異度98%として、有病率10%で約84.5%、有病率1%で約33%になるところをやる夫自身に計算させた。そのうえで「やる夫が作ろうとしているのは、専門家にかかれない人向け＝有病率の低い集団向けのサービスで、検証データは再診患者中心＝有病率が一番高い集団」という自分の設計への刺さり方まで書いた。3-2では、同じ「62%」表示が集団によって倍以上違う意味になること、そして相談フォームから来た匿名利用者についてはその集団が分からない＝書けない数字だったことを追加し、「数値が精密なほど、意味まで精密に見える」を計算の帰結にした。
- **目的関数 $J$ に実際に重みを入れて回した。** $w_1=1$、他ゼロで最適化した結果を「電車・バスの利用を中止／人数3名以上の場面を回避／外出を伴う活動をすべて回避、4週後の不安尺度 −71%」としてココロに出力させた。やる夫の「避けるほど生活範囲が狭くなる」という口頭の指摘を、自分の書いた式が返してきた計画として突きつける形に変えた。あわせて「ゼロを掛けた項は最適化から見えなくなる」「不安を下げる方法は耐えることと状況を消すことの2つあるが、$J$ にはその区別が無いので安いほうが選ばれた」という診断を入れた。
- **Fさんを第9幕に再登場させた。** 第4幕でやらない夫が挙げた3つの仮説（内容が不快／言い方が不快／先回りされたことが不快）に、教材自身が答える形にした。Fさんの回答は「分析は合っていた。合っていたから続けられなかった」で、やる夫が最も自信を持っていた内容の正しさが離脱原因そのものだったと反転する。半年後に人の相談室で同じことを3か月かけて言われ、そこでは自分から言えた、という対比を置き、「同じ結論までの時間を短くしたぶん、本人が自分の言葉にする時間を削っていた」に着地させた。Aさん（成功例が壊れて戻る）と対になる。
- **できる夫に一度粘らせた。** 8-2の親密表現の提案を即撤回させず、「離脱者の追跡ができていないのは自分たちが認めたことだ」「治療同盟が効くと言ったのはやる夫自身だ」と、教材の中の実際の発言を根拠に反論させた。やる夫が一度詰まり、「治療同盟は目標に紐づく／親密表現は継続率に紐づく」「治療同盟なら目標達成で関係の役割が終わるが、継続率なら終わらないほど良い」という差で棄却する。ここで出た「離脱者追跡の仕組みで解くべき」が、そのまま9-3のFさん再登場の装置になる。
- **期限を1つ置き、達成不能にした。** 冒頭のできる夫の導入に「10か月後の資金調達、条件は継続利用者3000人」を追加。第7幕で「あと4か月、現在410人」として破綻させ、やる夫が自傷念慮の検出閾値を緩めれば数字が届くことに気づいたうえで棄却する場面を置いた。9-2では資金調達不成立・規模4分の1・専門機関との提携という代償を明示し、「置き換えという意味では失敗」に事業上の重さを持たせた。そのうえで「3000人は専門家を置き換えたときの人数で、専門家と組んだときの人数ではない」と、第3幕の有病率の話（同じ数字でも当てる集団が変わると意味が変わる）へ明示的に接続した。
- **動機づけ面接を本文で機能させた。** 人物紹介の療法名列挙を、本文で実際に使う認知行動療法・行動活性化・動機づけ面接・治療同盟に絞った（ACT、対人関係療法、家族療法、精神力動的な見方は削除）。そのうえで6-2に、Iさんの「できなかった私が悪いということですか」を抵抗ではなく両価性として読み直し、課題を出す前に本人から変化の理由を引き出す往復を追加した。「準備性は遵守度の分母ではなく、介入の対象」というできる子の一行で締めている。
