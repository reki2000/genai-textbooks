# 寸評：やる夫で学ぶ心理治療 ― 心を治すAIを再発明する

約51KB／全9幕。心理療法を実装可能な手続きと見なしたエンジニアが、環境・診断・関係・目的関数・エビデンス・害・依存の各論点で設計を作り直し、「心を治すAI」から「共同仮説ノート」へ縮小していく。

## 良い点

**やる夫が「知らない」のではなく「知っているのに実装で落とす」設定になっている。** 7行目と34行目で知識量が明示され、失敗はすべて知識を部品に翻訳する過程で起きる。596–605行目が象徴的で、「お前はそれを知識として知っていたな」→「知っていたお」→「では、なぜ実装で消えた」→「『正しい介入を届ける通信品質』だと思っていたからだお」。無知→学習という一般的な型を捨てて、翻訳の失敗を主題にしており、題材と構造が噛み合っている。

**5-2で基準の矛盾が本人に突きつけられる。** 767–776行目。Bさんでは「症状が減っても駄目」、Gさんでは「症状が残っていると駄目」。やる夫が「やる夫の基準、途中で動いてるお」と気づいた直後、やらない夫が「動かしたのか。それとも、最初から基準が無かったのか」と刺し、「無かったお」に至る。教材中で最も鋭い一撃で、ここから回復の定義そのものが問い直される。

**Gさんの場面で、数値と語りを並置する。** 749行目の「不安尺度は開始時から20%改善しています。目標値には達していません」に対し、782行目の「先月まで、駅の階段の前で引き返していました。今は、乗って、降りて、友人に会って、帰ってきます」。785行目の「同じ人の同じ4週間を測って、片方は未達、片方は取り戻したと言っているお」で、尺度の限界が説明ではなく対比として示される。

**7-1の安全側の失敗が具体的。** 禁止条件842件（987行目）→「何を話しても、それしか言わないですね」（993行目）→「安全ですが、役に立ちません！！」（996行目）。しかも1002行目の「何もしないことには危険がないか」で対称性が回復され、安全設計が「停止すること」ではないという第7幕の主題に着地する。

**第8幕がAIの利点を認めたうえで反転させる。** 1073行目「AIなら、嫌われないので話せます」を1082行目で「人間の劣化版じゃないお」と積極的に肯定してから、1091行目「同時に、対人接触が減少」で反転する。結論の1169行目「AIにしか話せないことを否定しない。でも、AIにしか話せない状態を固定もしないお」は、両側を切り捨てない到達点になっている。

**9-3でAさんが再発して戻ってくる。** 第1幕の最初の成功例が、症状が戻った状態で再登場し（1301–1320行目）、「前とは違います」と言う。成功例が壊れることで、1331行目の $\text{病気}\to\text{正常}$ という当初の変換が1339行目の5段階へ書き換わる。最初の成功を最終幕で解体する構成。

**できる子の一行が毎回場面を反転させる。** 「試験利用者1人」（156行目）、「多様性が、モデルを壊す」（189行目）、「文章の表面だけ直す」（219行目）、「精度が下がる」（666行目）、「同時に、対人接触が減少」（1091行目）。短さが機能として一貫している。

**参考文献5点がすべて公的機関または査読論文で、本文の対応箇所つき。** APA、NICE NG197、Flückiger et al. 2018、WHO 2021・2025（1402–1410行目）。末尾に医療上の注記もある（1415行目）。

## 欠点

**数式が一度も計算されない。** 42行目のフロー、613行目の「治療効果＝介入内容×伝達品質」、680行目の目的関数 $J$、1331・1339行目の矢印。すべて提示されて否定されるか、比喩として置かれるだけで、値を入れて結果に驚く場面が皆無。$J$ は重み $w_1..w_5$ を持つのに、具体的な重みで最適解を出す場面がない。「最適化問題にしてしまう癖」を批判する教材だが、その批判自体が計算で裏づけられていない。

**「98%」がほとんど使われずに消える。** 376–388行目で一致率98%が提示され、条件（単一施設、再診中心、主要診断のみ）が開示されて「急に弱く聞こえます」で終わる。以後この数字は二度と出てこない。診断精度の落とし穴を扱う節なのに、有病率依存や陽性的中率には踏み込まず、3-2の「62%とは何の62%か」（475–478行目）とも数値的につながらない。

**利用者11人のうち10人が使い捨て。** A〜Kが登場するが、Bさん（258行目）、Hさん（719行目）、Iさん（868行目）はいずれも1回の長い発言で状況を開示して退場する。Aさんだけが再登場するため、他の10人が論点の運搬役に見える。

**離脱者のその後が追われない。** Fさんは554行目で離脱、Jさんは966行目で利用停止と書かれるだけ。584行目でやらない夫が「正しかったという判定も、お前の側の仮説にすぎない」と指摘するのに、教材自身も離脱者を仮説のまま放置している。

**できる夫が同型を6回繰り返す。** 25・153・379・844・996・1290行目、すべて「！！」で期待を煽り、直後に撤回するか反論される。1148行目の「私です！！ でも今、非常にまずい提案だったと理解しました！！」は笑えるが、事業側の主張が一度も粘らないため、利益相反が緊張として立ち上がらない。

**34行目の専門用語列挙が本文と対応していない。** ACT、動機づけ面接、対人関係療法、家族療法、精神力動的な見方が並ぶが、本文で実際に機能するのは認知行動療法、行動活性化、治療同盟の3つだけ。

**物語的な期限がない。** できる夫が事業側の圧力役だが、締切も資金枯渇も起きない。1055行目「事業範囲が増え続けています！！」が唯一の圧力で、これも次の発言で流される。

## 改善案

1. **3-1の98%を計算させる。** 386行目のあと、有病率を10%と仮に置き、感度98%・特異度98%のときの陽性的中率をできる子に計算させる（約85%）。さらに有病率1%なら約33%まで落ちることを示す。484行目の「数値が精密なほど、意味まで精密に見えるお」が、実際の数字で裏づけられ、3-2の62%表示の危うさへ直結する。

2. **目的関数に一度だけ数を入れる。** 680行目のあと、Gさん（不安を完全になくしたい）について $w_1=1$、他をゼロと置いて最適化した結果をココロに出力させる――「外出を伴う活動をすべて回避」。698行目の「避けるほど生活範囲が狭くなる」が、やる夫の口頭の指摘ではなく、自分が書いた式の帰結として返ってくる。

3. **Fさんを第9幕に再登場させる。** 554行目で離脱した人物を1320行目付近に置き、AIをやめた後どうなったかを本人に語らせる。584行目の指摘に教材自身が答える形になり、Aさんの再登場と対になって、成功例だけが戻ってくる構造が是正される。

4. **できる夫に一度だけ粘らせる。** 1148行目で即座に撤回させず、「継続率が上がれば、支援に届かなかった人も救えます」と反論させ、やる夫が一度詰まる往復を置く。事業側の主張にも根拠があることを認めたうえで棄却すれば、6回続く同型が崩れ、8-2の依存の議論に重みが出る。

5. **34行目の列挙を本文で使う3つに絞る。** 使われない療法名を削るか、逆に1つ（動機づけ面接）を第6幕のIさん（868行目）の場面で実際に使い、「準備度が低い人に課題を出す前にすべきこと」として機能させる。

6. **期限を1つ置く。** 25行目のできる夫の導入に、次の資金調達までのマイルストーン（利用者数と期日）を足し、第7幕の1055行目でそれが達成不能になる形にする。1230行目の「置き換えという意味では失敗だお」に事業上の代償が伴い、9-2の「置き換える対象を間違えていた」（1236行目）が判断として重くなる。
