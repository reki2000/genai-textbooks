# 寸評：やる夫で学ぶ現代宇宙論 ── 宇宙の履歴を再発明する

約98KB／序幕＋全9幕＋終幕。旧天文台の検収室で、名前を消された5台分の観測データを1つの模型で同時に説明せよという課題を通じ、FLRW・フリードマン方程式・熱史・CMB・インフレーション・$\Lambda$CDM を再構成する教材。

## 良い点

**序幕の「5台の端末」が全編の構成表になっている。** 57–63行目でデータだけを名前なしで提示し、以後1号機が第4幕（1034行目）、2号機が5-2（1340行目）、3号機が第5–6幕（1430行目、1528行目）、5号機が第9幕（2169行目）で回収される。「設計するな、観測から復元しろ」（106–108行目）という主題と章立てが一致している。

**やる夫の誤答が全編で同じ型を持つ。** 全観測点を通る多項式1本（72行目）、全銀河のN体計算（118行目）、地球が爆発の中心（220行目）、点粒子の $T^{\mu\nu}$（451行目）、光年＝距離（1098行目）、ハッブル半径が因果の壁（1184行目）、バリオンだけで銀河（2041行目）、重力を直せば暗黒物質不要（2085行目）。人物紹介6行目の「すぐに最短ルートを発見したと思い込む」が構造原理として機能している。

**「観測量」と「模型依存量」の分離が背骨として貫かれている。** 赤方偏移は観測量だが速度は定義依存（1086–1091行目）、CMBは宇宙定数を撮影したのではない（1661–1663行目）、超新星は負圧成分を支持するが $\Lambda$ とは限らない（2210–2212行目）、$H_0$ 緊張は装置同士の直接比較ではない（2305–2308行目）。同じ切り分けを5回以上、別の題材で反復している。

**未解決を未解決のまま検収表に残す。** リチウム問題（1418–1424行目）、$S_8$（2346–2355行目）、DESI の $w_0w_a$ 兆候を「興味深い兆候であって確定発見ではない」（2368–2372行目）。終幕の表（2436–2447行目）が「不明」を4行含んだまま合格印を押す形は、締めとして誠実。参考文献も DESI DR2・JWST 距離梯子・KiDS-Legacy と新しく、係争中の話題で両論を引いている（2572–2577行目）。

**できる夫のパラメータ増殖ギャグが理論選択の規範と直結している。** 42パラメータ模型（1925行目）、クインテッセンス列挙（2272–2273行目）、振動型暗黒エネルギー（2374–2375行目）。いずれもやらない夫の1行（1928行目「予言を1つに絞ってから来い」、2378行目「データ点の数より多い節を持つ関数を置くな」）で切られ、笑いと方法論が同じ動作で処理される。

## 欠点

**数値がほとんど出ず、「検収」が言葉だけで終わっている。** 実数が入るのは $n/p\simeq1:7$ と $Y_p\simeq1/4$（1398–1400行目）程度で、$\Omega_m$、$\Omega_\Lambda$、$H_0$、宇宙年齢、$T_0=2.725$ K、$z_*\simeq1100$ が本文に一度も現れない。序幕で7つのダイヤル（93行目）を出し、9-2で6パラメータを列挙（2231–2236行目）しながら、その値を一度も読まない。検収表（2436–2447行目）も「高精度で説明」「概ね整合」という語の表で、数値の突き合わせが1件もない。再発見教材としては最大の欠落。

**フリードマン方程式が天下りで出る。** 536–545行目で、やる夫は $G\rho$ の次元を確認しただけで係数 $8\pi G/3$ を含む完成形を書き下し、加速度方程式（551–554行目）も「空間成分を使うと」の一言。最も中心的な式が唯一まともな導出を持たない。FLRW計量も同様で、やる夫自身が「いきなり公式が出てきたお」（357行目）と言うがそのまま流れる。

**物語的な圧力が皆無。** 検収に落ちたら何が起きるか、期限は誰の都合かが一行もない。序幕101行目の合格条件以外に賭け金がなく、終幕2452–2454行目の合否宣告でやる夫が失うものがない。旧天文台という舞台も端末を置く以外の役割を果たさず、以後ほぼ言及されない。

**節末の形が同型で単調。** 210、314、435、610、930、1277、1519、1743、2156、2519行目——ほぼ全節が、やる夫の「〜なんだお」という抽象度を1段上げた総括で閉じ、やらない夫の短い承認が続く。30節近く続くと、失敗→修正→教訓の運動が教訓の朗読に平板化する。

**後半の補遺でやる夫が専門家になっている。** 空行2つで始まる追加部分（1482行目以降、1704行目以降、2121行目以降）では誤答が出ず、$A_se^{-2\tau}$ の縮退（1500–1502行目）、テンソル比 $r$（1952–1957行目）、重力スリップ（2131–2132行目）を初学者設定の生徒が導出なしに口にする。再発見ではなく交互解説になっている。

**できる子の役が薄い。** 登場は75、160、1157、1656、2320、2473行目の6箇所程度で、内容は「模型依存に注意せよ」。やらない夫と機能が重なる。数値と限界に厳しい観測家という設定（10行目）が、数値を一度も読まないため活きていない。

**失敗が測定でなく口頭で潰される。** ほぼ全ての誤答がやらない夫の反問1〜2往復で撤回される（地球中心説は230–245行目の思考実験だけで解決）。5号機の超新星ですら遠方が「予想より暗い」（2181行目）と語られるだけで、どの模型がどれだけ外れるかは示されない。

## 改善案

1. **9-2に「ダイヤルを実際に合わせる」節を作る。** 2236行目の列挙直後に $\Omega_bh^2\simeq0.0224$、$\Omega_ch^2\simeq0.120$、$n_s\simeq0.965$ を置き、やる夫に $h\simeq0.67$、$\Omega_m\simeq0.31$、$\Omega_b/\Omega_m\simeq1/6$ を計算させる。「バリオンは全物質の6分の1」が自分の手から出れば、2252行目の「通常物質は少数派」が実感になる。読み上げをできる子に担わせれば、この人物の設定も同時に活きる。

2. **フリードマン方程式をニュートン的に導出させる。** 536行目の前に、半径 $R=a\chi$ の一様球の縁の試験質量のエネルギー保存から $H^2=\frac{8\pi G}{3}\rho-\frac{kc^2}{a^2}$ を出させる往復を10〜15行入れる。その上でやらない夫が「この導出には圧力が入らない」と指摘して加速度方程式（551行目）へ進めば、490–492行目で予告した「圧力も重力源」が導出の中で回収される。

3. **検収に期限と利害を与える。** 序幕101行目の直後に、通らなければ次期観測計画の申請が出せず、人員予算が削られて誰かがここにいられなくなる、等の条件を1〜2行置く。第9幕の $H_0$ 警告灯（2286行目）で期限を突きつけられたやる夫が、それでも2327行目のように「未決着」と書く形にすれば、未決着と書くことが敗北でなく判断であると分かる。

4. **超新星の失敗を数値で確定させる。** 2181行目を、やる夫が $\Omega_m=1$ の減速宇宙で $z\simeq0.5$ の $D_L$ を計算し、観測との差が0.2等程度になることを自分で出す形に変える。続く「暗い理由は加速膨張以外にも」（2185行目）が、その0.2等を系統誤差で食えるかという具体的な検査になる。

5. **補遺ブロックの先頭に誤答を置く。** 1482、1704、2121行目の追加部分は現状いきなり正しい質問から始まる。それぞれ「再結合と脱結合は同じだから片方の言葉でいいお」「BAOは非線形進化で消えるから使えないお」「銀河数を数えれば $\delta$ が直接測れるお」という断定から入らせ、既存の内容をその反証として並べ替える。分量を増やさずに本編の型へ揃う。

6. **できる子に「装置では超えられない」を宣告させる。** 1560行目の宇宙分散を、やる夫が「望遠鏡を良くすれば低 $\ell$ も精密に測れるお」と主張し、できる子が「空は1枚。標本は増えない。」と切る形にする。教師の説明ではなく観測家の宣告として限界を受け取る場面が1つあれば、この人物の存在理由が確定する。
