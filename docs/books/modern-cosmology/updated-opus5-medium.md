# 改稿記録

## 工夫した点・主な変更

- **フリードマン方程式を、やる夫がニュートン力学で係数まで導く形にした。** 共動半径 $\chi$ の一様球の縁に置いた銀河のエネルギー保存 $\frac12 m\dot R^2-GMm/R=E$ から出発し、$R=a\chi$ を代入して $\frac12 ma^2\chi^2$ で割るだけで $8\pi G/3$ が落ちてくる。$k$ の符号が「宇宙の脱出速度」であることも、$E$ の符号としてやる夫の口から出るようにした。そのうえで「この導出に入っていないものは何か」と問い、圧力 $p$ が一度も現れないことに気づかせ、加速度方程式の $\rho+3p/c^2$ を「ニュートンでは届かない場所」として提示した。2-1で予告した「圧力も重力源」が、2つの式の差分として回収される。

- **検収に賭け金を与えた。** 序幕で、検収表は次期観測計画の申請書に添付され、通らなければ来年度の人員枠が削られて4人のうち1人がここにいられなくなる、と置いた。同時にやらない夫に「分かっていないものを分かったと書いた検収表はその場で失格」と言わせ、**埋めるか落ちるかの二択ではなく、空欄を残して通す判断がありうる** ことを先に仕込んだ。終幕でこれを回収し、やらない夫が「5行消せば今日押せる」と誘惑する場面を作ってから、やる夫に空欄のまま出させている。

- **終幕の検収表に数値列を足した。** 「高精度で説明」「概ね整合」という語だけの表を、$\Omega_m=0.313$／$T_0=2.7255$K／$z_*\simeq1090$／$z_{\rm eq}\simeq3400$／リチウムは予測が観測の約3倍／$H_0$ は差 $5\sigma$／$z=0.5$ で0.4等／$\ell=2$ の宇宙分散63%、という具体値の表に置き換えた。数値はすべて本編でやる夫が自分で計算したか、できる子が読み上げたものに限り、表で初出の数字を作らないようにした。

- **9-2に「ダイヤルを実際に合わせる」節を作った。** できる子が $\Omega_bh^2=0.0224$、$\Omega_ch^2=0.120$、$h=0.674$、$\tau=0.054$、$n_s=0.965$ を読み上げ、やる夫が $h^2$ で割って $\Omega_m=0.313$、$\Omega_b=0.049$、$\Omega_\Lambda=0.687$、バリオン比 $0.158\simeq1/6$ を出す。さらに $\Omega_rh^2=4.15\times10^{-5}$ から $1+z_{\rm eq}\simeq3400$ を計算させ、$z_*\simeq1090$ より前だと確認させた。**記号のままでは $z_{\rm eq}$ と $z_*$ の順序すら決まらない** という一文で、数値を入れる動機そのものを本文に書いた。

- **超新星の失敗を数値で確定させた。** $\Omega_m=1$ の平坦宇宙で $D_L=\frac{2c}{H_0}(1+z)\left(1-1/\sqrt{1+z}\right)$ を解析的に、$\Omega_m=0.3,\Omega_\Lambda=0.7$ を $1/E(z)$ の刻み値からシンプソン積分で出させ、$z=0.5$ で $0.551\,c/H_0$ 対 $0.662\,c/H_0$、等級差 $\Delta m=5\log_{10}1.202\simeq0.40$ 等を計算させた。続けて「0.4等は系統誤差として大きすぎない値だ」とやる夫自身に言わせ、独立な系統誤差を持つCMB・BAOとの交差が必要になる論理へつないだ。

- **できる子に「装置では超えられない」を宣告させた。** 宇宙分散を、やる夫が「感度を上げて10年観測すれば低 $\ell$ も精密に測れる」と主張する場面に作り替え、できる子が $\Delta C_\ell/C_\ell=\sqrt{2/(2\ell+1)}$ から $\ell=2$ で63%、$\ell=1000$ で4.5% を出し、「空は1枚。別の標本を取るには別の宇宙が要る」と切る形にした。限界が装置ではなく観測者の位置で決まることを、教師の説明ではなく観測家の宣告として受け取らせている。できる子の登場は6箇所から10箇所へ増え、すべて数値か限界の宣告に用途を限定した（解説はさせない）。

- **補遺ブロック3箇所の先頭に誤答を置いた。** いずれも「正しい質問」から始まっていたものを断定から入る形に変えた。
  - 再結合／脱結合：「同じ瞬間だから片方の言葉に統一していい」→ 電離度と散乱率が別の量だと気づかせ、再電離 → $\tau$ → $A_se^{-2\tau}$ の縮退 → その $\tau$ を測る場所が低 $\ell$ 偏光、すなわち直前に宇宙分散63%と言われた場所、という連鎖に着地させた。**用語を分けることは測るべき量を1つ増やすこと** という教訓に変えている。
  - BAO：「非線形進化で消えるから使用不可」→ 変位10Mpc級に対し殻の半径150Mpc級という桁の比較を自分でさせ、「消える」ではなく「ぼける」だと訂正させ、そこから再構成を自力で発想させた。直後に「観測データを理論通りに直している」という自己批判を置いた。
  - 構造成長：「銀河を数えれば $\delta$ が直接測れる」→ 数えられるのは光る側だけで $b\delta$ の縮退が出ることに気づかせ、赤方偏移空間歪みと重力レンズを「縮退の掛かり方が違う代理量」としてやる夫に選ばせた。重力スリップは、8-3で口頭議論した「粒子か重力か」を測る形にしたもの、という位置づけに変えた。

- **$H_0$ 緊張に数値を入れ、緊張の性質を切り分けさせた。** できる子が $67.4\pm0.5$／$73.0\pm1.0$／$69.8\pm1.9$ を読み、やる夫が $5.6/\sqrt{0.5^2+1.0^2}=5\sigma$ を計算する。さらに $h=0.730$ を採ると $\Omega_m$ が $0.313\to0.267$ に動いて検収表の他の行が全部動くことを自分で確認させ、そのうえで「$5\sigma$ は装置対装置ではなく、模型を通した外挿対直接測定の差だ」と言わせた。9-2で数値を入れておいたことが、ここで効くようにしてある。

## 残した判断

- 序幕の5台の端末と各幕の対応、「観測量と模型依存量の分離」の反復、未解決を未解決のまま残す終幕の姿勢は、レビューで最も評価された骨格なのでそのまま維持した。追加した数値も、この分離を壊さないよう「測定値」「模型を通した推定値」を毎回書き分けている。
- 数値は Planck 2018 の 6パラメータ、SH0ES と TRGB の代表値、$T_0=2.7255$K、$r_s\simeq147$Mpc、第1ピーク $\ell\simeq220$ など、既存の参考文献の範囲で確立している値に限った。DESI の $w_0w_a$ や $S_8$ のように係争中の項目には、確定的な数値を新たに置かず「解析によって $2\sigma$ 前後」という書き方に留めた。
- 節末が「〜なんだお」の総括で閉じる同型性は、指摘は受けたが全面改修すると検収表という枠組み自体が崩れるため、今回手を入れた11節については総括を「次に何を測るか」「何が確定したか」の形へ寄せるに留め、他節は維持した。
- レビュー指摘のうち「旧天文台という舞台が活きていない」は、期限と人員枠という賭け金を序幕・終幕に通したことで部分的に回収したと判断し、舞台描写そのものは増やしていない（ト書きを置かない形式のため）。
- lint は error 0件。追加した導出部分（2-2、9-1、9-2）で長大発言の warning が出ているが、いずれも途中で切ると計算が追えなくなる不可分な導出として残した。
