# `modern-cosmology-v2` ブロックメモ

## 制約と到達点

- 8幕＋終幕、約11万〜13万字。宇宙の年代記を一方的に語らず、異なる観測メッセンジャーの照合として進める。
- 現在も変動する観測値や緊張は、参照時点、模型依存、系統誤差を明記し、確定発見の演出にしない。
- 一つの数値を出したら、別の残響がどう独立検算するかまで描く。

## 人物設定

- やる夫：プラネタリウムの生解説・音響演出家。宇宙史を一本の楽曲として語りたがり、音高と物理的年代を混ぜる。
- やらない夫：観測データの可聴化プログラマ。やる夫の学生時代のバンド仲間で、七残響の誤った再生順を共同制作した旧友。
- できる子：観測解析者。二人と対等な立場で、誤差、縮退、系統誤差、模型依存を短文で読み上げる。
- できる夫：番組プロデューサー。「宇宙の真相、完全判明」の字幕を用意し、警告灯が増えるたび小さくする。

## マクガフィンとトイ

- 七つの残響A赤方偏移、B軽元素、C CMB、D BAO・銀河、E超新星、Fレンズ、G標準サイレン。
- 八拍目Hの休符。リチウム、暗黒物質、暗黒エネルギー、初期機構、緊張、特異点を六つの警告灯で示す。
- 宇宙会計レール。放射・物質・曲率・暗黒エネルギーの比率光をスケール因子に沿って動かす。
- 光円錐型の床面。距離でなく放射時刻を歩いて比較する。
- 七種の時計音。赤方偏移、温度、反応凍結、音響尺度、成長率、光度距離、波形距離を区別する。

## 伏線と回収

- Bの重水素リズムとCのピーク比が同じバリオン密度を指す。第5幕で独立照合。
- Cの規則的ピーク列は第8幕の初期位相とインフレーションへの伏線。
- Dの150 Mpc間隔は第5幕の音の地平線が化石化したものとして第6幕で回収。
- Gだけ人の耳に聞こえるチャープを元波形から直接時間伸長している。第8幕で光と別の距離尺度へ。
- Hは最初から無音。終幕で未解決は隠す物でなく次の測定要求だと回収。

## 繰り返すギャグ

- やる夫が低い音ほど古いと並べ、やらない夫が可聴化ソフトの音高設定を一つ動かして全順序を崩す。
- できる夫の「完全判明」字幕へ注釈が増え、最後は字幕より警告灯が目立つ。
- 宇宙会計光を動かすたび合計100%なのに正体不明部分が増え、やる夫が照明卓の故障を疑う。
- 距離の種類が増えるたび、やる夫が「宇宙論距離メドレー」を始め、単位と観測操作へ戻される。

## 緩急と息抜き

- 第1幕は生放送の締切と不協和音を高速で、第2幕は光円錐の床を歩く静かな場面にする。
- 第3・4幕は会計と核反応の計算、第5幕はCMBの音響ピークを可聴化して息を抜く。
- 第6幕は銀河地図の反復模様、第7幕は数値積分と誤差トラックで緊張を上げる。
- 第8幕は初期宇宙と現在の警告灯を頂点にし、終幕は八拍目の意図的な沈黙で閉じる。

## ブロック運用

各節は「観測の光・波形→直接測る量→模型を通した量→別残響との照合→残る縮退」で閉じる。観測者が光円錐内にいること、空が一つであること、代理量にバイアスがあることを繰り返す。可聴化は演出上の符号化であり、宇宙空間を伝わった実際の音と誤認させない。

## 状態台帳の初期値

- 七残響の仮想数値、可聴化規則、参照宇宙モデル、誤差、相関、放送時刻、字幕文言を固定する。
- $H_0$、$S_8$、暗黒エネルギー動力学など時点依存の主張は執筆時点の確認済み一次資料へ寄せる。
- $\Lambda$CDM内の推定値と模型非依存の直接観測を同じ言葉で扱わない。
- 観測可能な宇宙と宇宙全体、熱いビッグバンと特異点、インフレーション枠組みと具体模型を区別する。
