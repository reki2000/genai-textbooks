# `tokyo-roads_v2` ブロックメモ

## 制約と到達点

- 新規長編。現行道路情報は変わるため、固有名詞の網羅より地図更新と現場標識を重視する。
- 8幕＋終幕、約8万〜10万字。道路史は現在の形を説明する範囲に限定する。
- 読了後は、目的地方向、放射、適切な環状半径、川・地形・駅、移動手段、規制、時間を重ねて代替路を考えられる。

## 人物設定

- やる夫：個人ポッドキャストの配信者。背の高い放送車を自分で運転し、検索順位と派手な到着音を勝利と考える。
- やらない夫：自転車メッセンジャー。別番組の配信枠を競い、細道と脚力なら車へ必ず勝てると思う。
- できる子：中継局の回線技師。複数幕で接続時刻、通信状態、現場規制の確認先だけを伝える。

## マクガフィンとトイ

- 東京七時報S1〜S7。七地点から決められた時刻に10秒の街の音を生中継し、遅着すると無音が流れる。
- 七透明シート：中心放射、環状、川橋、地形、首都高、鉄道、時間規制。
- 赤い「最短距離」ボタン。押すたび、車か自転車の別の制約を落とす反復装置。
- 日本橋道路元標のレプリカ。距離の原点から、七つの音が合流する額縁へ意味が変わる。
- 一台の音声端末。競争相手へ渡したくない道具から、移動手段を切り替えて中継を保つバトンへ変わる。

## 伏線と回収

- 放送車屋根の小傷。第1幕の高さ制限未遂、第8幕の通らず端末を渡す判断へ。
- 古い紙地図に将来線が点線で残る。第5幕で用地・工事、第8幕で版管理へ。
- 雨雲レーダーをやる夫が番組映えの情報、やらない夫が向かい風情報として奪い合い、第4・7幕の経路コストへ戻す。
- シートを重ねると日本橋だけ見えなくなる。第5幕の首都高、第8幕の工事、終幕の音の合流へ。
- 音声端末の受渡テストを二人が拒む。第6幕の駅前、第8幕の閉鎖リンクで段階回収する。

## 繰り返すギャグ

- やる夫が最短距離ボタンを連打すると放送車が細街路へ、やらない夫が押すと自転車が階段へ案内される。
- 道に一つの正式名を決めようとし、住民、標識、国道、旧街道から別名が同時に中継へ入る。
- 二人が環状道路を完全な円として描き、片方は海へ、片方は自転車通行不能区間へはみ出す。
- 川を邪魔扱いするたび、渡れる橋の通行条件が生放送の効果音として読み上げられる。

## 緩急と息抜き

- 第1幕は高さ制限と規制の二連続停止、第2幕は日本橋で最初の街音を拾う静けさ。
- 第3幕は透明シート競争、第4幕は雨の橋上で車と自転車の順位が入れ替わる。
- 第5幕は首都高分岐とGPS断の速度感、第6幕は駅前の端末受渡しで呼吸を作る。
- 第7幕は待ち行列と時報の知的クライマックス、第8幕は閉鎖下のライブ統合試験。
- 終幕は日本橋の朝と七音の再生で閉じる。

## ブロック運用

各節は次の時報への経路が車か自転車の一つの制約で不可能になる事件から始める。やる夫の案は距離、速度、放送品質の一軸で、やらない夫の案は細道、料金、乗降の一軸で優れるようにし、車高、川、向き、坂、通行区分、変動、更新で交互に壊す。二人は同職域の上下関係でなく、スポンサーを競う友人同士であり、終盤に単独勝利から音声リレーへ評価軸を変える。道路名は作用と方向の理解後に命名し、幕末で名前を隠しても経路骨格を再現できるか試す。

## 状態台帳の初期値

- 七時報の場所・接続時刻、車高、自転車の通行条件、道路版、仮想渋滞値を固定する。
- 現実の通行では最新ナビ、標識、規制、安全な運転手順を優先し、教材だけで走行判断させない。
- 道路の開通・工事・名称は執筆時点の公的道路情報を確認し、基準日を記す。
- 実走の危険や規制違反を演出せず、停車して確認し、通らない・端末を渡す判断を成功として描く。
