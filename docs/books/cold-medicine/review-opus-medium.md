# 寸評：やる夫が作る総合感冒薬 ── 一錠にこめられた風邪との闘い

約59KB／全11幕。「かぜの特効薬は存在しない」から出発し、症状ごとに機構を分けて成分を選び、製造と規制の壁を越えて、市販の総合感冒薬の成分表と一致するところへ着地する。

## 良い点

**4本の伏線を番号つきで宣言し、全部回収している。** 112–119行目で伏線A（生薬→単離→改良の型）・B（鏡像が効果を分ける、二回来る）・C（眠気の借金）・D（墓場）を明示し、A は612行目でやる夫自身が5例を列挙して回収、B は450行目と652行目の二回、C は700行目と728行目、D は933–942行目の墓標カウントで閉じる。宣言の時点で「二回来る」「借金を誰かが返す」と回数まで予告してあるため、読者が回収を待つ姿勢で読める。

**空欄の「処方欄」が進捗メーターとして全編を貫く。** 67–74行目で6行の空表として提示され、282・373・469・562・689・730行目で1行ずつ埋まり、912–920行目で「越えた墓場」列を追加した完成表として検算される。抽象的な議論が続く教材で、読者が現在地を見失わない。

**墓場が「具体的な死に方」で並ぶ。** 無顆粒球症、メトヘモグロビン血症、鎮痛薬腎症、QT延長、出血性脳卒中、依存。しかも214行目でやる夫が自分で系列化する（キニーネ→ピラゾロン→アセトアニリド→フェナセチン→生き残り）。「効きそうな案が具体的にどう死ぬか」を積み上げる構成が、教材全体の型として一貫している。

**「活性代謝物こそ主役」が2回出て、2回目でやる夫が自分で接続する。** 3-2のアセトアミノフェン（203–211行目）と、4-2の後継抗ヒスタミン（351–352行目）。355行目「3-2のアセトアミノフェンと同じ筋書きだお！」で、読者が学んだパターンの転移が起きる。

**第9幕の製造編が独自性の高い部分。** 「効く成分を6つ選ぶ」と「一錠に固めて安く量産する」を明確に分離し、含量均一性、造粒、アスピリンと水の三すくみ（770行目）、成分同士の反応、苦味と防湿の兼用コーティング、固さと崩壊の両立を順に出す。821–823行目の「一錠の体積という予算の中で6成分が席を奪い合う」は、配合薬の制約を一言で掴んでいる。

**第10幕で試作品が実際に失敗する。** 868–874行目、カフェインと血管収縮薬という刺激系を二重に入れて動悸と不眠。教材中で唯一、やる夫が組んだものが動いて壊れる場面で、871行目の自己診断（「記号上で相殺したつもりが、覚醒側を過量にした」）が効く。

## 欠点

**参考文献26点がすべて Wikipedia。** 997–1022行目。医療分野の教材で、しかも本文はライ症候群による小児禁忌（245行目）、PPAと出血性脳卒中（641行目）、2023年の経口フェニレフリン無効判定（681行目）といった臨床上の断定を含む。これらは公的機関の資料や原著が存在する主張で、二次情報だけで支えるには重い。冒頭の免責（10行目）があっても補えない。

**製造の要所でやる夫が強すぎる。** 787行目の二層錠、794–795行目の「コーティングが防湿も兼ねる」はいずれもヒントなしの即答。前者は「錠剤を二層にして上下で分ければいい」と製剤設計の答えそのものを言っており、薬局に来た学生（6行目）の発想としては跳びすぎている。第9幕は本教材で最も専門的な幕なのに、最も抵抗が少ない。

**「判定しろ」と言われてもやる夫は判定していない。** 172行目「その顔は違うお。何が起きたんだお」、340行目「墓場のにおいがするお。何が起きたんだお」、670行目「その顔は違うお。まさか、効かないのかお」。やる夫の役割は毎回「何かある」と察するところまでで、失敗の中身は例外なくやらない夫が供給する。同じ言い回しが3回反復されることで、型として固定してしまっている。

**数を動かす場面がほぼない。** 748–750行目の含量均一性が唯一の量の議論だが、「数mg」対「数百mg」と述べたところで止まり、比率も幾何希釈の段数も計算されない。753行目の「ひとつまみの塩を米俵に」という比喩で代替されている。

**第10幕の「一意化」が主張ほど強くない。** 902行目「要請から配合がほぼ一意に決まった」と言うが、849–857行目でやったのは5軸に5カテゴリを割り当てただけで、各軸内で候補を競合させて1つに絞る過程がない。解熱鎮痛だけでもアセトアミノフェン／アスピリン／イブプロフェンが並ぶはずで、条件(5)(6)による絞り込みが省かれている。

**6-3の矛盾をやる夫が解いていない。** 545行目でやる夫が「止めると出すが同居してるお。矛盾だお」と鋭く指摘するが、548–557行目でやらない夫が建前・議論の存在・設計思想まで全部説明して終わる。教材中で最も面白い問いが、提示者から取り上げられている。

## 改善案

1. **主要な断定4点に一次資料を付ける。** 245行目のライ症候群、518行目の1962年法改正、641行目のPPA（Kernan et al., *NEJM* 2000 の Hemorrhagic Stroke Project）、681行目の経口フェニレフリン（2023年のFDA諮問委員会）。全26点を差し替えなくとも、本文が「〜と結論した」「〜が分かった」と断定する箇所だけでも一次資料に当て直す。

2. **6-3をやる夫に解かせる。** 545行目の矛盾指摘の直後、552行目の質問の前に、やる夫の解決案を1つ挟む――「乾いた咳用の箱と痰用の箱に分けて売ればいいお」。これを555–556行目の「買う人は自分の咳がどちらか選べない／同じ人でも初日と三日目で変わる」で潰す。現状やらない夫が語っている設計思想が、やる夫の失敗から出てくる形になる。

3. **含量均一性に数を入れる。** 748行目のあと、抗ヒスタミン2mg 対 錠剤全体400mg の比を1:200 とやる夫に計算させ、1回の混合で希釈できる比を1:3程度とすれば $3^n \ge 200$ から $n \ge 5$ 段必要、と手を動かさせる。第9幕唯一の量的議論が実感に変わり、758行目の「手間がかかる」が数字で裏づけられる。

4. **二層錠の前に失敗を1つ挟む。** 786行目の「同じ部屋に入れなきゃいい」の後、やる夫にまず「別々の錠剤にして2錠飲めばいいお」と言わせ、やらない夫が「片方だけ飲む人が出る」「一箱一錠の利便性が配合薬の存在理由だ」で潰す。そのうえで787行目の層の発想へ進ませれば、跳躍が段階を踏む。

5. **第10幕を候補の競合にする。** 849行目の表を埋める前に、解熱鎮痛軸だけでも「アスピリン／アセトアミノフェン」を並べ、条件(5)小児のライ症候群と(6)湿式造粒が封じられる点でアセトアミノフェンが選ばれる、という絞り込みを1往復やる。902行目の「ほぼ一意」が、標語ではなく手続きの結論になる。

6. **最後に「飲んだ後」を数行足す。** 989行目の締めの後、翌日のやる夫が仕事に行けたかを短く描く。6行目の「明日は仕事」と伏線Cの借金返済が、理屈だけでなく生活の側でも閉じる。
