# `cold-medicine` 改訂記録（sol56-medium）

## 改訂方針

`review-opus-medium.md` の6つの改善案を本文へ反映し、既存の事実・数式・伏線回収・処方欄の構造は維持した。改訂では、やる夫が答えを受け取る場面を減らし、証拠や制約から自分で失敗原因と設計案を組み立てる過程を増やした。

## 具体的な変更

1. 重要な医療・規制上の断定4点について、Wikipedia脚注を公的資料または原著へ差し替えた。
   - 小児のウイルス感染時のアスピリンとライ症候群：米国公衆衛生総監勧告（CDC収載）
   - 1962年Kefauver–Harris改正と有効性証明：FDAの法制史
   - PPAと出血性脳卒中：Kernan et al., *NEJM* 2000（PubMed）
   - 2023年の経口フェニレフリン判定：FDA諮問委員会結果の公式説明

2. 6-3の鎮咳薬と去痰薬の矛盾では、やる夫が先に「乾いた咳用と痰用で箱を分ける」案を出すようにした。その案を、購入時に咳の型を選びにくいことと、同じ患者でも日ごとに症状が変わることから退け、全部入りの利便性と薬理的な緊張をやる夫自身に整理させた。

3. 含量均一性へ数値計算を追加した。抗ヒスタミン2mgと錠剤全体400mgを $1:200$ とし、一段で三倍まで広げる条件から $3^n \ge 200$、したがって最低5段の幾何希釈が必要だと計算させた。

4. 二層錠へ直行していた箇所に「二錠へ分ける」失敗案を追加した。片方だけ服用される危険と配合薬の利便性要件で退けた後、一錠内に仕切りを作る発想から二層錠へ到達させた。コーティングも、甘味料で苦味を隠す失敗を経て、できる夫の膜案とやる夫の防湿への転用を組み合わせた。

5. 第10幕に解熱鎮痛薬の候補比較を追加した。アスピリン、イブプロフェン、アセトアミノフェンを並べ、効き目だけでなく対象者、安全性、湿式造粒との適合で選択する手続きを示した。「個々の成分がほぼ一意」という強すぎる主張は、「候補は一意ではないが必要な成分の型は大きく絞られる」へ修正した。

6. 翌朝の短い終幕を追加した。やる夫は出勤できたものの完治ではなく、引き継ぎ後に休むと判断する。冒頭の「明日は仕事」と眠気の借金を、薬は無限に働く許可証ではなく回復までを少し楽にする道具だという生活上の結論へ接続した。

7. 「その顔は違う」「墓場のにおいがする」に依存していた3場面を、検査票、心電図、投与経路ごとの効果差からやる夫が判定する形へ変更した。失敗の名称や原因をやらない夫が一方的に供給する反復を崩した。
