# 改稿記録

## 工夫した点・主な変更

- **2-2を「計算を最後まで通してから返される」形に変えた。** レビューが第一に挙げた改善案。やる夫が新基本給305,000円 × 料率15.0% = 45,750円 を自分で計算し、**明細に入れて提出する**。一週間後、年金事務所の通知の写しに赤字で「控除額相違」と付いて戻ってくる。通知額は44,000円で1,750円ずれている。「計算は合っている。掛けた相手が違う」と言われて初めて、明細の中で **唯一動いていない列** に気づく。やる夫自身に「言われて聞くのと、返されるのは全然違う」と言わせ、この教材で再発見の手触りが最も薄かった箇所を埋めた。

- **2-1をやる夫自身の残業申請にした。** 締切後に届いた6月12日の2時間を、他人の申請から **やる夫の申請** に変えた。「2時間くらいなら6月へねじ込むお。自分の分だから誰にも迷惑かからないお」と言わせた直後に、やらない夫が「それを一行で説明できるか」と返す。やる夫は「担当者が自分の残業代を、締切を過ぎてから自分で入れた」と読み上げて自壊する。節末も、5,750円が1か月遅れることへの本人としての不満を先に言わせ、それを給与担当としてどう受けるかへ折り返す形にした。**自分が納得できない説明は、他人にも通らない**という一言で、当事者性と実務の両側に立たせている。

- **1-3で賞与率表の設計意図を推論させた。** 見出しを読んで従うだけだった箇所の前に、「賞与額そのものを入口にする表を作ったら何が困るか」を置いた。やる夫は、年2回払いの会社と年1回払いの会社で同じ年収でも1回の賞与額が違うこと、賞与額を入口にすると年1回の人だけ高い率が張り付き、年間税額から乖離したまま1年間取られすぎになることを自力で出す。そこから「賞与の回数に左右されず、支給直前に確定した実額がある材料＝前月の給与」に到達し、**表は賞与の大きさではなくその人の税率帯を測っている**という理解に着地する。

- **4-2で退職日1日差を円で出した。** 研修用の標準報酬月額300,000円・本人負担合計料率15.0%を与え、1か月分45,000円、Aさん（8月30日退職）は7月分のみ、Bさん（8月31日退職）は7月分と8月分で90,000円 → **差45,000円** を計算させた。そのうえで「その45,000円を見て何を思った、正直に言え」と問い、やる夫に「全員の退職日を月末前日に書き換えたくなった、年20人辞めるなら90万円」と本音を言わせた。反論は説教ではなく、Bさんの側から出させている ── 厚生年金の加入月数が1か月減り、どこにも加入していない月ができ、国民年金・国民健康保険の手続きが要る。**45,000円は会社から見た節約だが、本人から見たら保障の穴**。締めは「金額を出す前は当たり前で終わっていた。誘惑の大きさを知ってから断る方が、本当の判断だ」。

- **第5幕の監査に期限と帰結を与えた。** できる子が **3営業日後の17時** という期限と、差戻し時の帰結（翌月の給与計算の基礎データが凍結され、**全社員327名の振込が予定日にできない**、源泉所得税の納付期限にも間に合わず延滞税が出る）を読み上げる。やる夫が「空欄の多い月から潰す」と走り出したところで、やらない夫が「1,200行のうち何行誤っていたら差戻しだ」と問い、やる夫が「**1行だお**」と自答する。速く埋めることと通ることが逆を向いている、という形で5-1の条件先出しに動機を与えた。

- **5-3の「保留」を、期限との取引として書き直した。** 回答待ちの1行を、3営業日目の朝・期限まで7時間という状況に置いた。やる夫は「第1幕の計算はできる、率を掛けて入れれば台帳が完成し327人の振込も間に合う」と誘惑に触れてから、「1,199行の根拠がある行と1行の根拠がない行が同じ顔で並ぶ」「5-1で自分が作った4状態のうち **引渡し** を **確定** に書き換えることになる」と自分で止める。できる子が「根拠のない確定と根拠のある保留では、後者だけが分離できる」と補い、**保留は逃げではなく仕分け**、分からないまま埋めたら1,200行全部が信用できなくなる、という結論を本人に言わせた。

- **できる夫を2-3に投入し、控除の権限の話に圧力を持たせた。** 早口で「結論から言うね!!」と入り、80,000円・部の予算が尽きた・本人も謝った・明日が締切・部長に処理済みと報告したい、を一息で並べる。やる夫はいったん「入れるお」と傾く（かつ「規程がザルな総務が悪い、やる夫は言われた通り引くだけ」と責任を他人へ転嫁する）。節の最後で、やる夫が **急がせた側に順序を返す** ── 「謝罪は事実の確認で、給与から引かれることへの同意とは別だお」。できる夫も「早さの問題じゃなく順序の問題か!」と受けて人事へ回す。教師との一対一では出せなかった緊張を、第三者の圧力で作った。

- **ボケの型を5か所置き換えた。** 「〇〇で天下／覇権／表彰／講演依頼／戴冠」の同型が15回続いていた問題に対し、近接する5つを別種の失敗へ変えた。
  - 2-3：他人（総務）に責任を転嫁する型。
  - 3-1：確かめる前に朝礼で部内へ宣言してしまった型（「言ってから確かめる順序か」で受ける）。
  - 4-1：確定前の金額を退職者本人へメールしてしまった型。内訳を分ける話に実害が伴う。
  - 4-3：過去の失敗（2-2で返された件）を「通知が遅かったから」と言い訳する型。やらない夫に「返された理由を通知の遅さにするな。掛ける相手を間違えただけだ。今回も同じ形をやろうとしている」と繋がせ、幕をまたぐ再発防止の線を1本引いた。
  - 4-2・5-2：「王」「戴冠式」を削り、素の断定に戻した。

## 残した判断

- 27,300円を最後まで一円で閉じる第1幕の型、終幕が第1幕の仮定計算（17,357円）をそのまま実演する円環、5-1の4状態（確定・差戻し・保留・引渡し）、5-2の同額3候補の棄却は、レビューで評価された骨格なので変えていない。今回追加した期限・金額・当事者性は、すべてこの骨格に接続する位置に置いた。
- やらない夫の「〜してよいか」型は、2-1・2-2・2-3・4-2・5-1・5-3 で (a) 数字だけ示して説明させる、(b) 提出させて返す、(c) 本人の本音を先に言わせる、(d) 第三者に要求させる、へ置き換えた。残る箇所は制度の可否そのものを問う場面であり、この形が最も短く正確なため維持した。
- 追加した数値（料率15.0%、標準報酬月額300,000円、修理見積80,000円、327名、3営業日）は、いずれも研修値・設定値であることが本文から分かる書き方にした。既存の令和8年分の率表・住民税・保険の制度説明には手を入れておらず、参考文献24点もそのまま対応が保たれている。
- 4-4（海外赴任）は、レビューが「片方を本人からの苦情メール全文に置き換えるとよい」と提案していたが、今回はできる夫を2-3に集中投入し、第4幕は4-2の金額計算と4-3の言い訳型で密度を上げる方針を採った。人物の登場箇所を散らしすぎると、できる夫の「急がせる」役が薄まると判断したためである。
- lint は error 0件。5-3 の長大発言 warning は、期限と保留の取引を一息で言い切る場面のため残した。
