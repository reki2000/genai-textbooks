# 寸評：やる夫の給与明細

約57KB／全5幕。「昇給したのに手取りが27,300円減った」という自分の明細の謎から始め、住民税・賞与源泉・標準報酬・退職・海外赴任・年間台帳監査へ広がる給与実務の教材。

## 良い点

**冒頭の謎が具体的な差額で、最後まで一円で閉じる。** 27,300円（29行目）を、遡及差額15,000円の消失＋住民税12,800円の出現＋所得税500円減へ分解する（155行目）。数字が合うまで犯人を決めない進め方が第1幕で確立され、以降の型になっている。

**終幕が第1幕の仮定計算をそのまま実演する。** 225行目で「5月に遡及差額がなければ4.084%で17,357円」と予行しておき、翌年の同条件で同じ17,357円が実際に出る（1031行目）。1年後の同じ6月25日、同じ2通の通知（1010行目）で始まる構図と合わせ、円環がきれいに閉じている。

**やる夫の誤りが毎回「制度の入口の取り違え」になっている。** 賞与額を率表の入口にしかける（183行目で見出し「前月の社会保険料等控除後の給与等の金額」を自分で読んで直す）、税の甲乙を社会保険へコピーする（698行目）、社会保険の1,000円未満切捨てを税側へ持ち込む（464行目）。実務で実際に起きる誤りで、的が正確。

**「未完成」を4状態へ割る5-1が全体の総括になっている。** 確定・差戻し・保留・引渡し（824–826行目）は、各幕でやる夫が止まった場所を後から分類し直したもの。5-2の同額3候補の棄却（888–932行目）も、「振込額の一致は何も証明しない」という監査の核心を演習として示していて秀逸。

**参考文献24点が全て本文の対応箇所つき。** 1078–1101行目。国税庁・日本年金機構・厚労省・都主税局の一次資料に閲覧日つきで当たり、率も令和8年分で揃っている（1081行目）。

## 欠点

**やる夫がほぼ何も再発見していない。** 大半の節が「ボケ→やらない夫の一問→完成した正答」の1往復で終わる。393行目（賃金全額払いと控除の根拠）、472行目（現物給与の経済的利益）、699行目（複数事業所の合算・按分）、764行目（所得源泉地）は、直前まで無知だった人物が専門用語つきの正確な結論を即座に出しており、実質は知識の口移し。苦労の過程がここで失われている。

**やらない夫の問いが誘導尋問の一形式に固定されている。** 「〜してよいか」に対しやる夫が「駄目だお／しないお」と返す型が、329, 349, 398, 459, 469, 543, 579, 597, 645, 677, 695, 727, 770, 850, 918, 979, 997行目とほぼ全編で反復する。3幕目には答えが内容でなく形式から予測でき、読者が考える前に結論が見える。

**第2幕以降、やる夫の利害が消える。** 2-3の破損端末、4-1の退職者、4-2のA・Bさん、4-4のUさんはいずれも他人の事例で、やる夫は損得も叱責も受けない。5-1で監査通知が来る（801行目）が締切日も不合格時の帰結も書かれず、5-3の「回答が戻った」（939行目）も待った日数がない。物語的な圧力が第1幕以外に存在しない。

**ボケの構文が単一。** 「〇〇で天下／覇権／昇進／表彰／講演依頼」型が30, 98, 166, 252, 316, 385, 447, 503, 564, 623, 682, 746, 806, 874, 898行目と15回続く。同じリズムで15回来ると、ページをめくる合図としてしか読まれなくなる。

**計算がやる夫の武器になっていない。** 数式は67, 187–213, 225, 283–297, 718–720, 868–872, 962–964行目のみで、第2幕後半から第4幕前半はほぼ言葉の分類。4-2の退職日1日差（631–640行目）は「7月分まで／8月分まで」で終わり、最終給与でいくら違うかという読者が最も知りたい金額が出ない。

**登場人物が2名で造形が薄い。** 6–8行目の紹介以上の情報が最後まで増えない。やらない夫は「管理部の実務家」という機能のみで、自身の過去の失敗も動機もない。会社側の圧力役（早く払え、損失を回収しろ）を担う第三の人物がいれば、2-3の控除の権限の話は格段に緊張する。

## 改善案

1. **各節に一度、計算を最後まで通してから壊れる場面を作る。** 2-2（320行目付近）で、やる夫にまず「新基本給×料率」で保険料を計算させ、その額を明細に入れて提出させる。翌週に通知額と合わないと返ってきてから標準報酬月額へ向かわせる。「言われて気づく」を「出してから返される」に変えるだけで再発見の手触りが出る。

2. **第2幕以降にやる夫の当事者性を残す。** 2-1の締切後残業（249行目「6月12日の2時間」）をやる夫自身の申請にする。自分の5,750円が翌月へ回る側に立てば、303行目の「会社のごまかしだ」を、やる夫が自分の内心として言える。

3. **監査に期限と帰結を与える。** 801行目の監査通知に提出期限（例：3営業日）と、差戻し時に誰が困るか（全社員の振込がずれる、納付期限に間に合わない）を書く。5-3の回答待ち（939行目）を、期限を睨みながら他の行を埋める形にすれば、「保留」という状態の重みが体感になる。

4. **やらない夫の問いを3種類以上に散らす。** 「〜してよいか」型を半減させ、(a) 数字だけ示して説明させる（表47–51行目の形）、(b) やる夫の答えの反例を出す、(c) 何も言わず別の書類を置く、を混ぜる。特に連続して同型な4-3（677行目）と4-4（750行目）は、片方を「本人からの苦情メール全文」に置き換えるとよい。

5. **4-2で保険料の金額差を円で出す。** 640行目の後に標準報酬月額と料率の研修値を与え、A・Bさんの最終手取り差を計算させる。「1日違うと2か月分引かれて約2万円減る」という具体額があれば、645行目の「退職日を書き換えればよいな」が本当に誘惑になる。

6. **賞与率表がなぜ前月給与を入口にするかを推論させる。** 183行目でやる夫は見出しを読んで従うだけ。その前に「賞与額そのものを入口にすると何が困るか」（年1回の大きな賞与に高い率が張り付き年税額から乖離する）を考えさせれば、制度の丸暗記でなく設計意図の再発見になる。

7. **ボケの型を5回ほど別種へ置き換える。** 過去の失敗の言い訳、他人のせいにする、根拠のない自信で先に社内へ宣言する等。特に近接する564行目「人生最終明細」と623行目「定時退社の王」は、片方を「先に退職者へ金額をメールしてしまった」に変えれば、4-1の内訳を分ける話に実害が伴う。
