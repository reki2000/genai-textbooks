# やる夫の給与明細 の骨格

## 第1幕　昇給したのに手取りが減った
- 1-1　6月給与227,700円が5月255,000円より27,300円少ない謎。4〜6月の3か月表を並べ、5月だけにあった「昇給遡及差額15,000円（4月分）」を発見。5月に見えた30,000円のうち遡及は1か月分だけ、という区別を通す。総支給305,000円を内訳で検算。
- 1-2　残る12,300円の犯人＝6月初登場の住民税12,800円。「新人卒業税」という創作を退け、「入社前年に大きな課税所得がなかったこのケースでは」まで主張を狭める訓練。自治体通知をそのまま反映するだけで会社が12等分し直さない、という控除欄の権限の話が 2-3・5-2 へつながる。6月減少を「当月の給与・前月だけの支給・前年の所得という三つの時間の衝突」と一文でまとめる。
- 1-3　賞与源泉26,035円は最終税額でなく仮徴収。賞与額を入口にすると年1回払いの会社だけ高率が張り付く、と自力で気づき、前月給与を入口にする設計意図へ到達。5月の控除後261,000円→6.126%、$425{,}000\times0.06126=26{,}035$ 円、振込398,965円まで再現。遡及がなければ4.084%で8,678円差、という比較が 5-4 でそのまま再演される。

## 第2幕　給与が変わる月は何がずれる
- 2-1　締切後に届いた残業申請の申請者が、やる夫自身。自分の裁量で当月へねじ込もうとして「他人の申請なら断る処理だ」と自覚する。発生日6/12・承認日・支払月7月の三分割。概算10,000円を先に入れて差額精算する案も履歴の観点で退ける。21:30〜23:30の2時間を時間帯で割り、1.25倍一律の5,000円でなく深夜割増込みの5,750円を出す。最後に「翌月払いは会社のごまかしに見える」と申請者側の感情を正直に述べ、給与担当としてどう返すかを両側から考える。
- 2-2　新基本給305,000円×15.0%＝45,750円を自分で計算して提出し、一週間後に「控除額相違」で差し戻される。4〜6月表で社会保険料等44,000円だけが動いていなかった＝明細の中で唯一動かない列を見ていなかった、と気づく。掛ける相手は標準報酬月額。随時改定の条件、現金の遡及支給月と標準報酬の改定月が別線であること、据え置きと遅れの区別へ。「言われて聞くのと、返されるのは全然違う」。
- 2-3　できる夫が端末破損80,000円を給与から4回で引けと迫る。やる夫は一度「総務の規程がザルなのが悪い、責任は総務」と責任転嫁して引き受けかけ、「根拠が無いと言いながら根拠が無いまま実行する側に回っている」と突かれる。賃金全額払いの原則と控除の根拠、過払賃金の相殺の制限、チャット一行は同意でない、謝罪は合意でない。最後に「なぜ会社が税を引けるのか」を問い返され、源泉徴収は会社が預かって納める役だと逆転して理解する。できる夫が「早さでなく順序の問題か」と受け取って退場。

## 第3幕　賞与を払っても税金は終わらない
- 3-1　賞与500,500円を税と保険で同じ額にする「ワン賞与・ワン金額」構想。しかも朝礼で先に宣言済み、という順序の失敗つき。社会保険は標準賞与額（1,000円未満切捨て→500,000円）、税は賞与額から社会保険料等を引いた額、と丸める場所が制度ごとに違う。現物給与は税と社会保険で評価根拠が別、現物を評価すると現金手取りはむしろ下がる。「現金支給額・現物評価額・課税/保険対象額・振込額」の四分割。
- 3-2　毎月正しく引けば年末調整の差額は0円か、という仮説を、支払時点では年間の所得と控除を知らないという理由で自力で否定。年調年税額と既徴収額の比較。証明書が来週届く見込みでも推測で控除は入れない。還付を「会社が返してくれた」と受け取らない。「差が出るのは計算ミスでなく資料の待ち行列」。

## 第4幕　会社を出ても計算は終わらない
- 4-1　最終給与280,000＋未払残業20,000＋退職手当2,000,000を合計2,300,000円として月額表へ入れる案。しかも確定前に本人へメール済み、という失敗の反復。給与経路と退職所得経路の分離、「退職所得の受給に関する申告書」未提出時に提出済みのふりをしない、退職後承認の残業は消さない、振込を一件にまとめても支払種別と内訳は分ける。
- 4-2　8月30日退職のAと8月31日退職のBで最終保険料が変わる。資格喪失日＝退職日の翌日、保険料は喪失日の属する月の前月まで。標準報酬300,000円・料率15.0%で差は45,000円。ここでやる夫は「全員の退職日を月末前日に書き換えたくなった」と誘惑を正直に言い、Bの8月が年金加入月数から消え無保険月ができると自分で見つけて撤回する（「誘惑の大きさを知ってから断る方が本当の判断」）。住民税の未徴収分90,000円も、退職月が6〜12月か1〜4月かで普通徴収／一括徴収の経路が分かれる。
- 4-3　兼業。A社200,000円・B社150,000円。ここでやる夫は 2-2 の差戻しを「通知が遅かったせい」と言い訳し、「掛ける相手を間違えただけだ、今回も税の区分を保険へ持ち込んでいる」と同型の誤りを指摘される。税は甲欄・乙欄で主従を分け、社会保険は合算・按分・通知。$52{,}500\times4/7=30{,}000$、$\times3/7=22{,}500$ は異常検知用の試算にとどめる。A社明細にB社給与を印字しない。
- 4-4　海外赴任Uさん。183日ルールで即断する「世界居住者判定アプリ」を却下。居住者判定は住所・居所・職業・赴任予定期間。日本法人が日本口座へ払っても源泉地は勤務地で決まる。振込0円でも処理0件ではない（シャドーペイロール）。現地給与の二重計上を支給IDで防ぎ、換算レートは目的ごとに基準日を先に決める。

## 第5幕　年間給与台帳を締めろ
- 5-1　できる子が3営業日後17時の監査期限を通告し、落ちれば全社員327名の振込が遅れ延滞税も出ると示す。空欄の多い月から手を動かそうとするが、「1,200行のうち何行誤れば差戻しか」→「1行」で、速く埋めることと通ることが逆を向くと気づく。確定に必要な6条件（事実／規程・公的資料／必要書類／適用時点／計算経路／精算先）を、この一年で止まった場所から抽出。未完成を4状態（確定・差戻し・保留・引渡し）へ割る。自分で計算して自分で丸を付けた行は検算されていない、資料の版と対象年まで書く。
- 5-2　差引支給額が同じ246,830円になる候補甲・乙・丙を、金額を見ずに落とす。雇用保険だけが総支給×0.6%で逆算でき、他の三つは根拠が別々。乙は誤りが二つ相殺、丙は住民税を会社が作り直して差額を別名の行に隠している。年間の振込総額一致は検算にならない。
- 5-3　残り1行、Uさんの12月賞与500,000円が専門家回答待ち。期限7時間前に「率を掛けて埋めれば台帳は完成する」と誘惑され、埋めれば 5-1 で自分が作った「引渡し」を「確定」に書き換えることになると気づいて保留のまま提出する。「保留は逃げでなく仕分け」。回答は完成額でなく前提の束（国内勤務72日／国外51日、日本出張12日は国内へ）。$500{,}000\times72/123=292{,}683$、$\times51/123=207{,}317$ で合計が戻る。全部国内案・全部国外案をどちらも棄却。
- 5-4　終幕。翌年6月25日。遡及差額のない5月（控除後256,000円）なので賞与源泉は4.084%区分の17,357円で、去年の26,035円をコピーしない。8,678円少なくても「得した」「去年は取り過ぎ」と言わない。住民税を「新人卒業税」と呼ばなくなった。最初の一枚は「会社が計算できる範囲へ収まっていた運のよい一枚」だったと総括し、「どこまで払い、どこで止め、誰へ渡すか」で締める。

## 依存
- 1-1 の3か月表（4月/5月/6月の各欄）は本編の背骨。5月の遡及差額15,000円は 1-3 の6.126%区分の根拠であり、5-4 で「今年は遡及がないから4.084%」という対比の前提になる。数値を変えると 1-1・1-3・5-4 の3か所が連動する。
- 1-3 で計算した「遡及がなければ4.084%、差8,678円」は 5-4 でそのまま実現する仕掛け。片方だけ直すと呼応が崩れる。
- 2-2 の「掛ける相手を間違えた」は 4-3 で明示的に再言及される（やる夫が言い訳し、やらない夫が同型の誤りだと指摘する）。2-2 の失敗の形を変えるなら 4-3 の指摘文も直す。
- 1-2 の「住民税は自治体が完成させる数字で会社が作り直さない」は 5-2 の候補丙を落とす根拠。
- 3-1 の「税と保険で評価根拠が別」は 5-3 の社宅評価で再利用される。
- 5-1 で作る4状態（確定・差戻し・保留・引渡し）は 5-2（差戻しの判定）と 5-3（保留の実行）で使われる。4状態を増減するなら両節。
- やる夫の失敗の型は「先に言ってしまう／先に手を動かす」で反復する：2-1（自分の残業をねじ込む）、3-1（朝礼で宣言済み）、4-1（確定前に本人へメール）、5-1（空欄から埋めようとする）。この反復が 5-3 の「埋めずに保留する」判断を際立たせる。
- 4-2 の45,000円は、やる夫が誘惑を口に出してから自力で撤回するという本編最大の倫理的山場。金額を出す前後で判断が変わる構造なので、計算を省くと山場が消える。
- できる夫（2-3・急がせる側）とできる子（5-1/5-3・乾いた期限と判定）は、それぞれ1回ずつやる夫に順序と分離を教える役。
- 5-4 は 1-1 の冒頭（6月25日、二つの振込通知）と同じ場面を1年後に再演する額縁構造。冒頭を変えるなら終幕も直す。
