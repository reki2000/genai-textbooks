# やる夫が一個の電子を右へ着地させるようです ── 位相ダイヤルからシュレーディンガー方程式へ の骨格

科学館地下の低温計測室で一夜（午前0時〜6時）の話。素子「ふたご井戸」で電子を左から右へ移す操作が初回100回で右37回。午前6時に事前固定した100回で右80回以上なら合格。映像演出家やる夫（矢印アニメの作者）と制御回路の設計者やらない夫（「昨日一回で成功した」）が、原因を半分ずつ抱えていたと突き止めるまでに、確率振幅・演算子・時間依存シュレーディンガー方程式・トンネル・測定・デコヒーレンスを記録から組み立てる。数値はすべて学習用の仮想値（冒頭注記）。

人物：やる夫（映像演出家、元電子工作サークル）／やらない夫（回路設計者、物理学科出身、学生時代の仲間）／できる子（低温計測の技師、寡黙に記録を出す）／できる夫（広報、猫の影の切り絵を持ち込む）。

## 第1幕　午前零時、電子の居場所が消える
- 1-1　右37回。やる夫はセンサーの見逃しを疑うが、左右入替で右38回となり潔白。判定条件（事前固定100回で80回以上）が操作画面下段にあるが、やる夫の字幕の帯で隠れている（8-3 の伏線）。「責任を半分ずつ＝一人18.5%」のギャグは 7-3・8-1 の「半分ずつ」の伏線。
- 1-2　吸収線七本（4.10〜6.20 GHz、最細は5.00と5.50）。「七個の電子」案を、読み出しが毎回一電子分で否定。水素656 nm→1.89 eV、$h=4.136\ \mu$eV/GHz で5.00 GHz→20.68 μeV。線は段の差。冷却表示が0.7秒ごとに跳ねる（7-1 の伏線、「故障と決めつけない」）。使っていない位相ダイヤルの位置まで保存（2-2 で使う）。
- 1-3　二項分布の標準偏差 $\sqrt{100\cdot0.37\cdot0.63}\approx4.83$、80との差は約9σで運では済まない。やる夫はホール映像も一番きれいな試行を選んでいたと自白（やらない夫の「昨日の一回」と同型の選択バイアス）。台本一行目「電子は一本道を走り…」に線を引くが代わりが書けない（9-1 で回収）。できる夫が猫の影の切り絵を置いていく。

## 第2幕　波打つのは確率ではない
- 2-1　水風船（電荷の雲）案。半分の電荷は一度も出ず、分かれているのは100回の回数＝見つかりやすさ。
- 2-2　確率を足す案。位相ダイヤルの校正記録（分ける→片側に角度→混ぜる→出口A/B）でダイヤル0で100%、πで0%。正の数の和では0にならない。打ち消し合う量の3条件（打ち消せる／それ自体は観測されない／0以上の確率を作れる）。
- 2-3　符号±ではπ/2の50%が出ない。$|1+x|^2=2$ を実数で解けず $x=i$。複素平面・$e^{i\varphi}$ を略記として導入、加法定理で積が角度の和。$P_A=(1+\cos\varphi)/2$ が記録3点と一致。確率振幅・ボルン則（1926）。「知らないだけ」（隠れた道）案は $P_A=1/2$ で記録と矛盾。0と2πが同じ結果という引っかかりを残す。
- 2-4　$3|L\rangle+4i|R\rangle$ で2500%→規格化。全体位相は確率に効かず、相対位相が効く（$4i$→出口A 50%、$4$→98%）。確率だけメモして角度を捨てると次が分からない。本番でダイヤルに誰も触っていないのに角度が効くなら、何が回したのか（4-4 で回収）。

## 第3幕　七本の線は操作の指紋
- 3-1　状態にエネルギー値を貼る案。混ざった状態に一つの数は貼れず、値を読み出す手続きが要る。
- 3-2　ド・ブロイ（50 eV電子で0.17 nm、デイヴィソン＝ガーマー）。平面波 $e^{ikx}$、$p=\hbar k$。$mv$ を掛ける案は波の形と無関係で失敗。微分で $ik$ が出ることから $\hat p=-i\hbar\,d/dx$、固有状態・固有値、単位確認。
- 3-3　$\hat p^2/2m+V$ でハミルトニアン。平面波が $\hat H$ の固有状態であることを確認。
- 3-4　二つを混ぜると固有状態でなく、測れば $E_1$ か $E_2$ が $|c_n|^2$ で出る。平均は一回も出ない値（37回も同じ）。七本の線は固有値の差。時刻0から1 ns後はまだ計算できない。

## 第4幕　時間を進める式を作る
- 4-1　記録から式への約束5つ：線形（ダイヤル）／時間一階（初期化は置き場所だけ）／確率保存（毎回一個）／定常状態は角度だけ回る（実数 $\sin^2$ だと点滅する）／自由粒子で $\hbar\omega=\hbar^2k^2/2m$。
- 4-2　候補A 波動方程式は $\omega\propto k$ かつ時間二階で不合格。偏微分を導入。候補B 拡散方程式は $\omega$ 虚数で確率が蒸発（冷めたお茶）。
- 4-3　候補C：$D$ を虚数に。$a=\hbar/2m$ から $i\hbar\partial_t\psi=\hat H\psi$。$\psi^2$ 項は線形性違反。絞り込みは「局所・低階・線形」の範囲内と断る。シュレーディンガー本人は固有値問題から来た別ルート（1926）。
- 4-4　$\hat Hu=Eu$ に $e^{-iEt/\hbar}$ を付けて確認。二準位の重ね合わせは相対位相が $(E_2-E_1)t/\hbar$ で勝手に回る＝量子ビート。2-4 の「何が角度を回したか」の答えは $\hat H$。揺れの速さはエネルギー差＝線の間隔。

## 第5幕　壁より低いのに向こうへ出る
- 5-1　壁の中では $u''=\kappa^2u$ で $e^{-\kappa x}$、すそが右の井戸へ届く。
- 5-2　$\psi\approx\alpha u_L+\beta u_R$ の二準位近似（壁が厚い条件つき）。結合項の候補イ（逆符号）とウ（同符号）を確率保存で判定、イは電子が消える。「出入りの勘定は二乗したあと」。エルミート行列、底の共通定数は全体位相、離調 $\Delta$。$J>0$ に揃える。
- 5-3　$\Delta=0$ で $\alpha=\cos(Jt/\hbar)$、$\beta=i\sin(Jt/\hbar)$（$i$ は式から決まる）。最細二本の差0.50 GHz＝$2J/h$ で $J/h=0.25$ GHz、$t_\pi=1.00$ ns。トンネル効果。やらない夫が、パルスで隣の底も引っ張られ補正を調整していなかったと告白。
- 5-4　離調つき：$E=\pm\sqrt{J^2+\Delta^2/4}$（行列式）、$P_R=\frac{4J^2}{\Delta^2+4J^2}\sin^2(\Omega t/2)$。ずれると最大値が下がり、最大時刻も早まる二重の損。つまみは電圧とパルス長の二つ。できる子が電圧をかけた掃引を1時間で。「37回の半分はやらない夫の回路」。

## 第6幕　測ると操作が終わる
- 6-1　0.5 nsで覗く演出案。測ると状態が置き換わり、最終の右は50%に落ちる。
- 6-2　小分けに覗くと $[\cos^2(\pi/2N)]^N$（N=100で0.976）で左に居座る＝量子ゼノ効果（1990年のイオン実験）。矢印アニメは覗きっぱなしの絵だった。台本から「道のりの半分です」を消す。
- 6-3　同じ状態でも左右で測るか和・差で測るかで結果が違い、先に左右を測って捨てるだけで出口Aが100%→50%。$[x,\hat p]=i\hbar$ を関数に作用させて確認、不確定性関係は結論のみ。操作中にセンサーを強くつなぐと干渉が消える。できる子「位相の揺れの記録に周期がある」。

## 第7幕　誰も見ていないのに測られている
- 7-1　できる夫の猫の影の試写で床のケーブル束が映り、やる夫の信号線が測定ケーブルと並走と判明。矢印ループの周期0.7秒と一致（1-2 の冷却表示も同じ束）。「電極へつながってない」は本当だが隣を走っていた。
- 7-2　二目盛りの針の模型で、電子と針の振幅を分けて足すと $P_A=(1+\cos\theta\cos\varphi)/2$。干渉を残す割合 $\gamma=\cos\theta$、密度行列の形で提示。誰も読まなくても印が付いた時点で干渉が削れる＝デコヒーレンス（意識は要らない）。
- 7-3　$T_2=2.0$ ns、1 nsで $C=e^{-1/2}=0.607$。やらない夫の「結合を強めて0.2 nsで」はほかの段への漏れと二準位近似の破綻でやる夫が止める。信号線の分離・ループ停止・フィルタで $T_2=20$ ns。ループだけ戻すと再び劣化して因果を確認。「残りの半分はやる夫の矢印」。

## 第8幕　右へ移す一発を設計する
- 8-1　最細二本の間隔0.673 GHzから $\Delta=1.8J$。$P_{\rm true}=P_{\max}(1-C\cos\Omega t)/2$ で干渉部分にだけ $C$ を掛け、読み出し誤り4%を入れて $P_{\rm obs}\approx0.366$＝初回の37回を予言。片方だけ直すと0.41と0.78で届かない（本当に半分ずつ）。昨日の一回も一番きれいな映像も「三回に一回の当たり」。
- 8-2　補正で $\Delta=0.8J$、パルス0.928 nsで $P_{\rm obs}\approx0.815$。だが100回で80回以上の確率は約7割で、三回に一回落ちる（率と回数の区別）。位相ダイヤルは0に固定して0と2πを同位置と記録。
- 8-3　残り1時間弱。冷却調整90分（上がっても1.8点）より電圧補正20分（$\Delta=0.5J$、0.970 ns、88.5%）を選ぶ。79回以下は1%未満だが0ではない。判定条件が字幕の帯で隠れていたのをやる夫が認め、字幕を下げて「始める前に決めた100回、選び直さない」を台本へ。

## 終幕　午前六時の百回
- 9-1　右83回。予言88.5%より約1.7σ低く、83回以下は約6%。見落としか揺れかは保留し、選び直さず低めも記録する。台本一行目の代わり「準備し、決めた時間だけ時間発展させ、最後に一度だけ測った。途中の道は測っていません」。猫の影はケーブル束の図の隅へ（今夜一番の発見）。
- 9-2　七本の線は飾らず、最細二本は毎回の $J$・$\Delta$ の物差し、ほかは漏れの目印として使う。次は三つの井戸。矢印を描きたくなるのを抑え、3×3の表の空欄（左右直結の欄は未知のまま）から測る順番を決める。

## 依存
- 「37回」は 1-1 で出し、8-1 で $\Delta=1.8J$・$T_2=2.0$ ns・読み出し誤り4%から予言し直して回収する。いずれかの数値を変えたら 8-1 の計算と 8-2・8-3 の数字を全部やり直す。
- $J/h=0.25$ GHz は 1-2 の最細二本（5.00／5.50 GHz）から 5-3 で決まり、8-1 の0.673 GHz、8-2・8-3 のパルス長まで連鎖する。
- 位相ダイヤルは 1-2 で保存 → 2-2・2-3 で校正記録として使用 → 2-4 の「何が角度を回したか」 → 4-4 で $\hat H$ と回収 → 8-2 で0固定。0と2πの同一視は 2-3 末で引っかかり、2-4 で解く。
- 0.7秒は 1-2（冷却表示）→ 6-3（位相の揺れの周期）→ 7-1（矢印ループ、ケーブル束）で回収。できる夫の猫の影が発見の契機なので、1-3 の切り絵持ち込みと 7-1 の試写、9-1 の扱いは一組。
- 「半分ずつ」：1-1 の18.5%ギャグ → 5-4（回路）→ 7-3（矢印）→ 8-1（片方だけでは届かない）。
- 選択バイアスの反復：1-1 やらない夫の一回 → 1-3 やる夫のきれいな映像 → 8-1 どちらも三回に一回の当たり → 8-3 字幕の帯で隠れた判定条件 → 9-1 選び直さない。1-1 の「字幕の帯を太めに」が 8-3 の伏線。
- 台本一行目：1-3 で線を引く → 2-4 で書きかけ → 6-2 で「道のりの半分」削除 → 8-3 で判定条件の一行追加 → 9-1 で完成。
- 7-2 の $C$（干渉を残す割合）を 8-1 で干渉項にだけ掛ける論理は、4-4（相対位相のビート）と 5-4 の $\cos\Omega t$ の書き換えに依存する。
- 5-2 の二準位近似の適用条件（壁が厚い）は、7-3 でやる夫が高速パルス案を退ける根拠になる。
