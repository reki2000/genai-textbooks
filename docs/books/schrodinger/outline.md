# やる夫で学ぶシュレーディンガー方程式 ── 量子力学を再発明する の骨格

## 第1幕　古典物理が壊れる日
- （見出し直下）紫外破綻とプランクの $E=h\nu$。「エネルギーに最小単位を入れるだけ」で済ませようとする素朴案を、バルマー系列 $1/\lambda=R_H(1/2^2-1/n^2)$ の $1/n^2$ という形で殺す。$n=3$→656 nm を手計算。
- 1-1　ボーア模型を $L=n\hbar$ から自力で導き $E_n=-13.6/n^2$ eV とバルマー系列を再現。ヘリウムで $-108.8$ eV 対実験 $-79.0$ eV の30 eVずれで破綻。やる夫が「間違った模型がなぜ水素だけ当たったのか」と自分から引っかかり、**伏線(3)** として明示的に保留。

## 第2幕　粒子は波である
- （見出し直下）光電効果→波動粒子二重性→ド・ブロイの逆転。50 eV電子のド・ブロイ波長0.17 nmを計算し、原子間隔と同オーダーだから結晶が回折格子になる（デイヴィソン・ガーマー）。
- 2-1　「何が波打っているのか」。電子1個ずつの二重スリットを提示し、やる夫が消去法を主導する。案1（電荷が広がる）は着弾が1点であることで棄却、案2（確率そのものが波打つ）は確率が非負で打ち消し合えないことで棄却。波打つ量が満たすべき3条件（打ち消し合える／それ自体は観測されない／非負の確率を作れる）を書かせ、「確率のもと」へ到達。**伏線(1)**（位相＝複素数か）を保留。

## 第3幕　確率振幅への跳躍
- （見出し直下）ボルン解釈。隠れた変数理論を、$P_{\text{classical}}=|A_1|^2+|A_2|^2$ と $P_{\text{QM}}=|A_1+A_2|^2$ の数値比較（中央で1対2、暗線で1対0）で区別し、ベル／アスペで棄却。到達点4項目（確率振幅／複素数値/規格化条件/測定まで不定）を明示。やる夫が「位置を絞ると運動量は」と問い、**伏線(2)** として保留。

## 第4幕　道具の構築
- 4-1　なぜ実数ではダメか。$\sin(kx-\omega t)$ の $|\psi|^2$ が空間に等間隔の絶対零点を作り、1点で見れば粒子が現れたり消えたりすることを自力で発見。$|e^{i\theta}|^2=1$ でユニタリ性が自然に満たされる。**伏線(1)回収**（干渉の位相と確率保存の両方が複素数を要求）。
- 4-2　演算子。$e^{ikx}$ から $k$ を引き出す操作として $\hat p=-i\hbar\,d/dx$ を自力で見つけ、「数を掛けるだけでは波の中身が見えない」と言語化。$\hat H=-\frac{\hbar^2}{2m}\partial_x^2+V$ を組み、箱の $\psi_n$ で検算して固有値方程式の形を先取りする（6-1 で正式導出）。
- 4-3　固有値問題とボルンの規則。重ね合わせ $\frac{1}{\sqrt2}(\psi_1+\psi_2)$ が固有状態でないことを確かめ、確率 $|c_n|^2$、期待値 $(E_1+E_2)/2$ が1回の測定では出ない値であることを区別する。ここで使った直交性が 4-4 への橋。
- 4-4　ヒルベルト空間とブラケット。$\mathbb{R}^n$ が不足する理由（連続変数で無限次元／複素数値）を自力で挙げる。ブラケットを「内積のシンタックスシュガー」「抽象クラスと具象化」とプログラマ語で言い換える対応表。$\hat p$ のエルミート性を部分積分で証明し、境界項が消える条件 $\Psi\to0$ を明示して「後でもう一度使う」と予告（5-3 で回収）。$i$ が付いている理由＝測定値を実数にする要請。
- 4-5　交換子 $[\hat x,\hat p]=i\hbar$ をテスト関数に作用させて導出し、ロバートソンの不等式から $\Delta x\Delta p\ge\hbar/2$。**伏線(2)回収**。合格例（自由粒子の $[\hat H,\hat p]=0$）と不合格例で検証し、「順序依存の副作用がある関数は同時に確定値を返せない」とプログラマ語で締める。道具5点を整理。

## 第5幕　方程式を書き下す
- （見出し直下）方程式が満たすべき4条件（線形性／時間1階／ド・ブロイ整合／確率保存）をやる夫に列挙させる。
- 5-1　候補A：波動方程式。分散関係が $\omega\propto k$ になり条件3違反、時間2階で条件2も違反。棄却。
- 5-2　候補B：拡散方程式。$\omega$ が純虚数になり $\int|\Psi|^2$ が指数減衰、条件4違反。不可逆過程だから棄却。
- 5-3　候補C：$D=i\alpha$ とすると $\omega$ が実数化し、$\alpha=\hbar/2m$ が決まって $i\hbar\partial_t\Psi=\hat H\Psi$ へ。4条件を全部チェックし、確率保存の証明が 4-4 の $\hat p$ エルミート性と**同じ部分積分・同じ境界条件**であることをやる夫自身が気づく（道具の二度使い）。
- 5-4　変数分離で $T(t)=e^{-iEt/\hbar}$（位相回転）と $\hat H\psi=E\psi$ へ。第4幕の固有値問題がここで合流。一般解の重ね合わせと量子ビート。

## 第6幕　検証と見晴らし
- 6-1　箱の中の粒子。SEから $E_n=n^2\pi^2\hbar^2/2mL^2$ を正式導出し 4-2 の検算と一致。零点エネルギーが不確定性原理と整合すること、$n$ が大きいと対応原理に近づくこと。
- 6-2　調和振動子の代数的解法。$[\hat a,\hat a^\dagger]=1$ を $[\hat x,\hat p]=i\hbar$ から導き、数演算子の関係だけで全固有値 $E_n=\hbar\omega(n+1/2)$ を出す。微分方程式を一切解かない。$\hat a^\dagger$ が場の量子論の生成演算子への直通路だと予告。
- 6-3　水素原子。3量子数 $n,l,m$ と $E_n=-13.6/n^2$。**伏線(3)回収**：ボーアは $l=0$（s軌道、角運動量ゼロ＝円軌道で記述不能）を見逃していたが、水素では $E$ が $l$ に依存しない縮退のためエネルギーだけ一致した＝偶然。ヘリウムでは電子間反発が縮退を破る（1-1 の失敗の理由）。球面調和関数と s/p/d 軌道の形。
- 6-4　$sp^2$ 混成軌道はSEの固有解ではなく、$\{|s\rangle,|p_x\rangle,|p_y\rangle\}$ からのユニタリ変換＝基底の取り直し。$\langle sp^2_1|sp^2_2\rangle=0$ をブラケットで検算。ベンゼン環・グラフェンの起源へ。
- 6-5　全行程の振り返り。「引っかかった場所が全部要所だった」（実数の棄却→複素数の必然、演算子の順序→不確定性、候補の棄却→SEの一意化）。多粒子系・スピン・場の量子論への地図で締める。

## 依存
- 伏線は3本、明示的に `> **伏線(N)**` 記法で立てられている。(1) 2-1末→4-1で回収、(2) 3幕末→4-5で回収、(3) 1-1末→6-3で回収。番号と回収先の宣言が本文に書かれているので、幕を動かすなら宣言文も直す。
- 1-1 のボーア模型（$E_n=-13.6/n^2$、ヘリウムの $-108.8$ 対 $-79.0$）は 6-3 の縮退による偶然という回収の前提。ヘリウムの数値を変えるなら 6-3 の「電子間反発が縮退を破る」説明も見る。
- 4-4 の $\hat p$ エルミート性の部分積分と境界項 $\Psi\to0$ は、5-3 の確率保存証明でそのまま再利用される。「道具は二度使われる」というやらない夫の台詞がこの対応を明示している。片方の証明を書き換えるなら両方。
- 4-2 で箱の $\psi_n$ に $\hat H$ を作用させる検算は、6-1 の正式導出と同じ答えを出す設計。式を変えるなら両方。
- 4-5 の $[\hat x,\hat p]=i\hbar$ は 6-2 の $[\hat a,\hat a^\dagger]=1$ の導出に直接使われる。
- 4-3 の直交性・4-4 のブラケットは 6-4 の混成軌道の検算で回収される。
- 2-1 の消去法（案1・案2）と 5-1〜5-3 の候補棄却は、同じ「素朴案を殺して残るものを取る」構造の反復。6-5 の振り返りが両方を名指しで参照する。
- 零点エネルギーは 6-1（箱）と 6-2（調和振動子）で2回出て、いずれも不確定性原理と結ぶ。
