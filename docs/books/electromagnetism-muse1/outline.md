# やる夫で学ぶ電磁気学 ── 見えない力から光を作る の骨格

全編を貫く枠は「やる夫の無線通信機」で、各幕末にできる子が **性能記録**（到達距離・通信速度・有線か無線か）と **幕末の問い** を読み上げる。性能記録は 3cm/0.2 bit/s → 2m → 5m → 5m → 5m → 5m → 8m・無線/1 bit/s と進む。第5幕でできる子から「配線工事ができない家の玄関チャイムを導線なしで鳴らしたい」という具体的な使い道が出て、終幕で徒歩5秒に距離では負けても暮らしの中では勝つ、と落ちる。各幕末の問いは前出の道具だけで解ける形にし、答えは次の幕の冒頭（第7幕の問いは終幕）で数値つきで回収する。

## 第1幕　触れていないのに動く
- 1-1　こすった下敷きで紙片を動かす通信機第1号。風説をアクリル板で、熱説を熱いマグカップと温度計（21.3→21.4℃、分解能と同じ差）で潰す。「電気」という名前を知っていることと仕組みを説明できることは違う、と釘を刺され、事実だけを並べて電荷を導入。同符号の反発を実験で見つけ、正負は単なる約束だと確認。最後に「帯電していない紙がなぜ引かれたか」が未解決で残る。
- 1-2　電荷は作られるか。布まで調べて全体で0＝電荷保存則。何が移動したかは外からは区別できず、電流の向きと電子の動く向きが逆な歴史的経緯へ。1-1 の宿題を分極で回収し、導体／絶縁体／接地まで。
- 1-3　クーロンの法則。$1.0\times10^{-8}$ C の下敷きと 1 mg の紙片で、必要な有効電荷の偏り約 $1.0\times10^{-10}$ C から $F\approx1.0\times10^{-5}$ N 対 $mg\approx9.8\times10^{-6}$ N と桁を合わせる。100個＋1個の力を100種類の $q$ で計算する手間から、$q$ を括り出す「計算をサボる小細工」として電場を発明し、それが $q$ を含まない＝空間の量だと気づく。電気力線の本数を数えさせ、逆二乗と球面積 $4\pi r^2$ が打ち消し合うことからガウスの法則へ（「逆三乗だったら」の反実仮想つき）。
- 幕末の問い：点電荷から 3.0cm の点の $E$ と試験電荷が受ける力（答えは 2-1）。

## 第2幕　電気を流し、ためる
- 2-1　第1幕の問いを回収（$E\approx1.0\times10^5$ N/C、$F\approx1.0\times10^{-5}$ N で紙片の重さと桁一致）。電荷をためる方式は一度しか動かない。100万倍の電荷を電圧に直すと $10^7$ V、空気の絶縁破壊は $3\,\mathrm{mm}$ で約 $9\times10^3$ V＝桁が3つ足りない。連続動作には循環が要る→電流の定義、$I=neAv_d$、ドリフト速度は遅いのに電球がすぐ点く理由（水の詰まった管）。金属板の間に薄い板を差し込むと静電容量が増える場面から、束縛電荷の分極で誘電体と比誘電率 $C=\varepsilon_r C_0$ を導入。分極が 1-2 の仕掛けと部品の性能向上で再登場する。
- 2-2　電池は電荷を作る工場か、を電荷保存則で否定。$V=W/Q$ で電位を定義し、仕事の式を等しく置いて **電位の勾配としての電場** $E_x=-dV/dx$、$\mathbf E=-\nabla V$ を導く。等電位面は等高線、電場はその垂直方向。$10$ V／$2.0$ cm $=5.0\times10^2$ V/m で検算し、V/m と N/C の一致も確認。豆電球は $V/I$ が5.0→6.25 Ωと変化し（温度）、金属抵抗器では一定＝オームの法則は基本法則でなく条件付きの関係だと自分で言う。$P=VI=I^2R=V^2/R$。
- 2-3　キルヒホッフの電流則を電荷保存から、電圧則を静電場の保存性 $\oint\mathbf E\cdot d\mathbf l=0$ から導く。ここでやらない夫が「静電場では」と含みを残し、時間変化する磁場があれば電圧則は修正が必要だと予告（4-3 で回収）。
- 幕末の問い：9V に 100Ω＋200Ω 直列の電流と電圧降下（答えは 3-1）。

## 第3幕　磁石という別世界
- 3-1　第2幕の問いを回収（30mA、3V＋6V）。N極＝正電荷という素朴案。磁石を切り続けても必ず両極が現れる→磁気単極子なし、$\oint_S\mathbf B\cdot d\mathbf A=0$。閉曲面を縮めて体積で割る操作から発散 $\nabla\cdot\mathbf B=0$ を導入し、積分形と微分形（箱全体でいくら／各点でいくら）の対応を作る。この操作は 5-3 で閉曲線を縮める回転の導入と対をなす。
- 3-2　電流が方位磁針を回す。振動説を電流反転で潰し、磁場が導線を周回することを発見。$B=\mu_0I/2\pi r$、アンペールの法則、コイルと鉄心→電磁石で受信側の針を動かす電信機へ。鉄心がなぜ効くのかを **磁性体** で場面化する。磁気モーメントのそろった領域が外場でそろう＝磁化、強磁性体、$B=\mu_r\mu_0H$、電流を切っても残る磁化が永久磁石。誘電体の分極と対にして「物質は場に応答して場を作り直す」と整理。
- 3-3　磁場中の電荷に働く力。陰極線が両方に垂直に曲がることから外積を導入し $\mathbf F=q\mathbf v\times\mathbf B$。円運動 $r=mv/qB$ から質量分析・加速器へ話が及んだところで「磁場を強くし続ければ無限のエネルギー」と言い出し、$P=q(\mathbf v\times\mathbf B)\cdot\mathbf v=0$ で磁場は仕事をしないと自分で否定する。モーターの回転エネルギーの出所も電源だと確認し、$\mathbf F=q(\mathbf E+\mathbf v\times\mathbf B)$ で役割分担を締める。
- 幕末の問い：10A の直線電流から 2.0cm の $B$（答えは 4-1）。

## 第4幕　磁石から電気を取り出す
- 4-1　第3幕の問いを回収（$B=1.0\times10^{-4}$ T）。磁石を1個→2個→10個と増やしても電流計は0.0 mA。動かしている間だけ ±0.8 mA が流れる。磁束と $\mathcal E=-d\Phi_B/dt$、$\Phi_B=BA\cos\theta$ から発電機へ。ここで永久機関を思いつく。
- 4-2　マイナス符号をプラスにすれば永久機関になる、という主張を組み立ててから、実測（N極接近で針は左）で予想が逆だと知る。レンツの法則を「自然は変化を嫌う」でなく「変化を強める向きだと永久機関になるから」と因果を逆にして言い直す。発電機を回すと重くなる理由、損失0でも余剰がないこと。
- 4-3　モーターと発電機は同じ構造の双方向変換。手回し発電で暗い部屋の豆電球が回した分だけ点く場面で、機械的仕事→光の変換を体感させ、停電時の使い道へつなぐ（生活への波及の前半）。ホワイトボードに3本の矢印（電荷→電場／動く電荷・電流→磁場／変化する磁場→電場）を書き、$\oint_C\mathbf E\cdot d\mathbf l=-d\Phi_B/dt$ から 2-3 の予告を回収してキルヒホッフの電圧則が近似だったと確認。
- 幕末の問い：磁場 0.20T・面積 0.010 m² が 0.10s で消えるときの起電力（答えは 5-1）。

## 第5幕　場は計算上の幻か
- 5-1　第4幕の問いを回収（20mV）。場は計算上の便宜だという立場を、1光秒離れた電荷Aを動かす思考実験で崩す。瞬時伝達なら超光速通信になり相対論と矛盾。「何が伝わるか」を追い、各点の局所状態が有限速度で伝播する＝因果の局所化へ。
- 5-2　エネルギーは電子が宅配便のように運ぶのか。ポインティングベクトル $\mathbf S=\frac{1}{\mu_0}\mathbf E\times\mathbf B$ で、エネルギーは回路周囲の空間を通って抵抗へ流れ込むと知る。導線の役割は表面電荷で場を整えること。ここでできる子が「配線工事ができない家の玄関チャイムを導線なしで鳴らしたい」と打ち明け、無線完成の目的が金儲けと距離競争から暮らしの困りごとへ変わる（7-3 と終幕で回収）。
- 5-3　コンデンサの隙間。同じ閉曲線 $C$ に張る面の選び方でアンペールの法則が $\mu_0I$ と 0 の両方を出す矛盾を、やる夫自身が発見する。隙間で増えているもの＝変化する電場に気づき、変位電流 $I_d=\varepsilon_0 d\Phi_E/dt$ で解消。3-1 と対にして、閉曲線を縮めて面積で割る操作から回転 $\nabla\times$ を導入し、「$\nabla\cdot$ が源の有無、$\nabla\times$ が渦の有無」と整理。矢印が4本になって輪が閉じる。
- 幕末の問い：$C=1.0\,\mu$F の電圧が毎秒 100V 増えるときの充電電流＝変位電流（答えは 6-1）。

## 第6幕　光が方程式から現れる
- 6-1　第5幕の問いを回収（$100\,\mu$A、面の選び方でずれない条件として）。4本のマクスウェル方程式を微分形で並べ、暗記でなくここまでの失敗の履歴として意味づけ直す。真空で源項を落とす。
- 6-2　ファラデーの法則に $\nabla\times$ を作用させ、「渦の渦」はベクトル解析側の恒等式を道具として借りる（導出しないと明言）。真空の $\nabla\cdot\mathbf E=0$ で第1項が落ち、波動方程式へ。$1/\sqrt{\mu_0\varepsilon_0}\approx3.00\times10^8$ m/s が光速と一致し、光は電磁波だと結論。
- 6-3　$\mathbf E\perp\mathbf B\perp$ 進行方向、$E=cB$、同位相。**偏光** を電場の振動方向として導入し、分極（物質内の電荷の偏り）との混同を台詞で切り分ける。偏光板を90度重ねると暗くなる、水面の反射を落とす偏光サングラス、液晶表示へ波及。周波数による電磁波の種類と $c=f\lambda$。「無線通信機は見えない光を作る装置」。
- 幕末の問い：$5.0\times10^{14}$ Hz の光の波長（答えは 7-1）。

## 第7幕　電波を作って、暮らしを動かす
- 7-1　第6幕の問いを回収（600nm）。乾電池をアンテナにつなぐ案。スイッチを入れた瞬間しか反応しない＝定常の場は放射しない、電荷の加速が要る。**放射** を、加速する電荷の波成分が $1/r$ で弱まりエネルギーを運び去って源から切り離れる現象として説明し、交流へつなぐ。手で毎秒1億回反転はできない。
- 7-2　LC回路。$U_E=\frac12CV^2$ と $U_B=\frac12LI^2$ の往復を「電気的な振り子」として掴み、$f_0=1/2\pi\sqrt{LC}$ から $f_0=1.0$ MHz・$C=1.0$ nF に必要な $L\approx25.3\,\mu$H を逆算する（式が部品の値を教える場面）。続けて **交流回路とインピーダンス**。抵抗・コイル・コンデンサの位相のずれから $Z=\sqrt{R^2+(\omega L-1/\omega C)^2}$ を出し、共振では $Z=R$ で最小になること、$\omega L\approx159\,\Omega$ と $1/\omega C\approx159\,\Omega$ がそろう検算で桁合わせする。抵抗による減衰と、アンテナ結合による放射。
- 7-3　搬送波 $s(t)=A\cos(\omega t+\phi)$ の3つの可変量からAM/FM/PM。受信側の共振による選局、重ね合わせで空間を周波数で共有する。生活への波及の山場として、受信側にリレーをつないだ無線チャイムを実際に鳴らす。玄関で押したことが導線なしに部屋のベルを動かし、第1幕の「3cm先の紙」と対比する。モールスで「やる」まで送って符号表を忘れる落ちも残す。
- 幕末の問い：同じ $L$ で $C$ を4倍（4.0nF）にしたら共振周波数はどうなるか（答えは終幕）。

## 終幕　電気と磁気は同じものか
- 第7幕の問いを回収（$\sqrt{LC}$ が2倍→ $f_0=0.50$ MHz）。できる子が「昨夜、玄関で押されてベルが鳴り、荷物を受け取れた」と報告し、無線機が徒歩5秒に距離では敗北しても、配線できない家では暮らしの中で勝つと落ちる。性能記録の全推移（距離267倍、配線0本、受信側でベル作動）。全10段の道筋をテキスト図でまとめ、勾配・誘電体・磁性体・偏光・放射・インピーダンスの新規要素も図に織り込む。最後にやらない夫が「電場と磁場は本当に独立した2種類か」と問い、観測者の運動で分け方が変わることから電磁場テンソルと特殊相対論の入口を示して締める。

## 依存
- できる子の「性能記録」と「幕末の問い」は各幕末に置かれ、問いの答えは次の幕の冒頭（第7幕分は終幕）で回収される。問いと答えの数値（$E\approx1.0\times10^5$ N/C と $1.0\times10^{-5}$ N、30mA と 3V／6V、$1.0\times10^{-4}$ T、20mV、$100\,\mu$A、600nm、0.50MHz）を変えるなら対の箇所も直す。
- 2-3 で「静電場では」と留保した $\oint\mathbf E\cdot d\mathbf l=0$ は 4-3 で明示的に回収される。予告と回収は対。2-2 の $\mathbf E=-\nabla V$（電位を坂の高さとみる話）も 4-3 の回収で前提として再利用される。
- 3-1 の閉曲面を縮めて発散を導く手順と、5-3 の閉曲線を縮めて回転を導く手順は意図的に同型。片方の説明を変えるならもう片方も揃える。「$\nabla\cdot$ が源、$\nabla\times$ が渦」という 5-3 のまとめが両方に依存する。
- 1-3 で電場を「計算をサボる小細工」として導入したことが、5-1・5-2 で「場は実在か」を問い直す前提。1-3 末尾でやらない夫が「後で場を計算上の道具では済ませられなくなる」と予告している。
- 分極は 1-2（紙が引かれる理由）→ 2-1（誘電体で静電容量増）→ 3-2（磁化との対比）と3回、意味を変えて再登場する。6-3 の偏光は別概念で、本文中で分極と切り分けている。
- 矢印の表は 4-3（3本）→5-3（4本）と増える。ここを増減するなら 6-1 の4方程式の並びと終幕の道筋図も連動する。
- やる夫の永久機関／超光速の誤りは 3-3（磁場で無限加速）・4-2（マイナス符号を反転）・5-1（瞬時遠隔作用で超光速通信）の3回。いずれも保存則か相対論で自力で潰す構造。
- 1-1 で残した「中性の紙がなぜ引かれるか」は 1-2 の分極で回収。
- できる子の玄関チャイムは登場人物紹介で仕込み、5-2 で事情を明かし、7-3 で実際に鳴らし、終幕で「荷物を受け取れた」まで回収する。仕込みを削るなら 7-3・終幕の落ちも連動して直す。
