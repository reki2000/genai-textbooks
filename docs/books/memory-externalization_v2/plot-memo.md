# `memory-externalization_v2` ブロックメモ

## 制約と到達点

- 新規長編。ノート術の推薦ではなく、人・道具・組織・検索機械にまたがる外部知識設計を扱う。
- 8幕＋終幕、約8万〜10万字。簡単な検索指標と余弦類似度はやる夫が手計算する。
- 読了後は、保存量を知識量と同一視せず、利用者、場面、表現、検索入口、出典、時点、所有者、技能移転を設計できる。

## 人物設定

- やる夫：移動プラネタリウムを営む科学解説者。今夜の公開観望会を天文台と共同主催し、観客へ約束した時刻と解説を背負う。写真を撮ると理解した気になる。
- やらない夫：天文台が観測装置と文書サーバの保守を委託する共同工房の望遠鏡技術者。やる夫の上司ではなく、公開時刻に対して機器の安全と停止判断を背負う対等な契約者。
- できる子：大学天文部の学生リーダー。第2・4・7・8幕で初参加者としてカードを盲検する。
- できる夫：市の検索システム担当。第5・6・8幕で検索・RAGの実装と限界を担う。

## マクガフィンとトイ

- card_id `OBS-RED-017`、通称「赤い星カード」。K-0〜K-7の版を壁に並べる。
- 23時47分の彗星。天体自体を危険や奇跡にせず、引継ぎの締切と静かな報酬にする。
- 七段ゲート：存在、発見、同定、理解、信頼、実行、更新。カードが通過できないゲートへ赤磁石を置く。
- 三人の判定者：未来の本人、初参加者、検索機械。同じ問いを各幕末に渡す。
- 一万枚の写真フォルダ。削除で爽快感を作らず、原文、重複、現行入口、保存期限へ分類する。

## 伏線と回収

- K-0の紙に古い機器型番の透かし。第6幕で機種適用範囲の手掛かりになる。
- 赤色灯の写真は多数あるが、どれも警告発生前後が欠ける。第3・4幕で時系列ログの必要へ。
- ベテランが残した音声ファイル名 `heavy.wav`。第7幕で知覚技能の教材になるが、単独では条件不足。
- ドームの壁に手書きの矢印。第3幕では地図、第6幕で旧機種の逆方向を示す歴史資料と分かる。
- できる子が毎回カードを逆さに持つ。第8幕で向きに依存しないIDと構造化表示へ回収する。

## 繰り返すギャグ

- やる夫が写真を撮るたびレンズキャップを外し忘れ、真っ黒な「完全な暗黒観測」が増える。
- フォルダ名が `final`、`final2`、`final_really` と増え、第6幕で版管理へ昇格する。
- 検索に困るたびタグを100個足そうとし、タグ検索そのものが難しくなる。
- できる夫のRAGが丁寧な口調で別機種の正反対手順を答え、やる夫が文章の自信に騙されかける。後半は根拠IDを先に見る。

## 緩急と息抜き

- 第1幕は撮影連打と探索失敗のコメディからK-0の短文へ急停止する。
- 第2幕は机上の記憶実験を遊びとして行い、外部化への不安を丁寧に扱う。
- 第3幕は天文台内を歩き、地図・説明書・チェックリストの形を身体で比較する。
- 第4幕はカード棚を組む工作回。幕末に三者の盲検でテンポを上げる。
- 第5幕は検索結果の早い往復と小計算。AIの誤答では笑って終えず、検証責任を残す。
- 第6幕は旧手順で機器が逆に動きかける緊張。安全停止場面ではギャグを止める。
- 第7幕は音を聞き分ける静かな稽古と、初成功の達成感。
- 第8幕は彗星時刻の実地クライマックス。終幕は観望後の静かな会話とレンズキャップの落ち。

## ブロック運用

各節はOBS-RED-017が七段ゲートのどこで止まるかから始める。やる夫の素朴案は保存、要約、タグ、リンク、ベクトル、形式化、全文書化のそれぞれの長所を本当に持たせる。反例で適用限界を出し、全面否定せず役割を限定して復権させる。節末はやる夫が「何をどこへ残し、何を頭・人・訓練へ残すか」を自分の言葉で更新する。

## 状態台帳の初期値

- 彗星時刻、機器型番、card_id、K版、七段ゲート、三判定者を固定する。
- 外部化と学習の関係は単純な善悪にせず、置換、拡張、検索手掛かり、判断能力を分ける。
- 認知科学、情報検索、RAG、チェックリストの事実は原著・公的資料を優先し、製品固有の推測を避ける。
- 操作事故は安全停止できる範囲にし、無資格者が現実の大型望遠鏡を独断操作することを勧めない。
