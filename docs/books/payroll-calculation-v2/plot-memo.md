# `payroll-calculation-v2` ブロックメモ

## 制約と到達点

- 新規長編。日本の給与実務を題材にするが、個別法務・税務助言ではなく判断構造を学ぶ教材。
- 8幕＋終幕、約8万〜10万字。金額は仮想例、制度率・条件は基準年を明記する。
- 読了後は、支給・控除を制度と時点で分け、根拠不足を停止・引渡しし、複数粒度で検算できる。

## 人物設定

- やる夫：共同制作チームの映像編集者。労働者側の照合代表で、前月プロジェクトの複製と自動同期を信じる。
- やらない夫：同じチームへ別会社から参加するライブ音響技師。兼業者側の照合代表で、自分もT10の支給を受ける当事者。
- できる子：外部の給与実務専門家。複数幕で公的資料の基準年、決定主体、確認窓口だけを示す。
- できる夫：作品の上映責任者。第1・7・8幕で午前0時の公開と支払完了を同時に迫る。

## マクガフィンとトイ

- T01〜T12の十二本の編集タイムライン。支給ID、対象期間、根拠、状態がイベントとして時間上に現れる。
- 五本の再生ヘッド：労働発生、申請承認、締め、支払、制度適用。同じ「六月」を別位置で横切る。
- T12の赤い停止線。邪魔な未完成から、安全に止めて再開条件を残す道具へ意味が変わる。
- 同額246,830円の三波形。最終音量が一致しても経路は一致しない反復トイ。
- 午前0時の同期音。全件緑の祝砲と思わせ、根拠が同期した案件だけ鳴らす確認音へ変える。

## 伏線と回収

- T12の環境音に国外空港の出発・到着チャイムが二度入る。第1幕では編集ノイズ、第6・8幕では勤務日配分の手掛かりになる。
- 前月タイムラインに一つだけ手書きの「通知待ち」マーカー。第5幕で停止処理の先例と分かる。
- T01の6月住民税を毎幕やる夫が新しい効果音と呼びかけ、終幕で決定主体を正しく説明する。
- 銀行のカウントダウンと制度適用ヘッドが最初から7分ずれている。故障でなく異なる時点を見ている象徴。
- やらない夫自身のT10も兼業例に該当する。第6幕で他人へ厳しく自分だけ先に出力する誘惑を返す。

## 繰り返すギャグ

- やる夫がスペースキー一発で五本のヘッドを同期させようとし、毎回一つだけ別方向へ進む。
- 制度の時間差へ映像のトランジションを足して滑らかに見せ、やらない夫に「見た目を払うんじゃねぇ」と止められる。
- 「同じ率で公平」を言うたび、税・保険・住民税の三レーンから違う同期音が鳴る。
- 波形の太さで手取りを推測し、賞与と無音の休職月で毎回外す。

## 緩急と息抜き

- 第1幕は前月複製の高速編集から四つの音切れで停止。
- 第2幕は五ヘッドのスクラブ再生、第3・4幕は短い区間計算をテンポよく往復する。
- 第5幕は休職・退職を扱うため笑いを抑え、無音と生活への影響を丁寧にする。
- 第6幕は世界時計と二重露光で複雑さを上げ、第7幕は逆位相の誤差を聞き分ける知的クライマックス。
- 第8幕は午前0時の静かな停止、終幕は翌朝の同期音で閉じる。

## ブロック運用

各節は一本のタイムラインが根拠、時点、権限のどこで同期を失うかから始める。やる夫の案は編集画面と振込だけなら間に合うようにし、やらない夫の案も音量・支給側の一軸では合理的にする。翌月、納付先、本人説明、監査の副作用で交互に壊す。二人は異なる会社と時間素材を背負う対等な照合代表である。計算は途中式と逆算を示し、制度名は何へ率を掛け、誰が決め、いつ適用するかへ到達後に付ける。

## 状態台帳の初期値

- T01〜T12の雇用・勤怠・支給条件と仮想金額、各ヘッド時刻を固定する。
- 現行制度の条件・率・様式は執筆時の公的資料で確認し、将来変更されうると明記する。
- 給与・税・保険の個別判断は専門家・行政窓口への確認が必要と注意する。
- 退職、休職、海外勤務を本人の落ち度として笑わず、ギャグはやる夫の編集癖と二人の時間感覚へ向ける。
