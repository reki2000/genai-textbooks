# やる夫が給料日の五つの時計を同期させるようです ── 十二本のタイムラインと午前零時

---
## 登場人物

**やる夫** ── 共同制作チームの映像編集者。チーム内の支給照合代表。

**やらない夫** ── 別会社から共同制作へ参加するライブ音響技師。兼業者側の支給照合代表。

**できる子** ── 外部の給与実務専門家。

**できる夫** ── 共同制作作品の上映責任者。

**T01〜T12** ── 支給ID、対象期間、根拠、状態を表示する十二本の編集タイムライン。

**五本の再生ヘッド** ── 労働発生、申請・承認、締め、支払、制度適用の時点を別々に指す五本の線。

**制度基準日** ── 2026年8月23日。金額は明記した仮想例で、実案件は支払時点の法令、表、通知、規程、事実を再確認する。

概算10,000円を今夜払って、来月ぴったり合わせれば生活には優しいお。

### 2-2　22時をまたぐ二時間半 ── 割増の区間分解

〜〜 10時13分　T02の波形を拡大 〜〜

**やらない夫**：
承認された記録は、6月12日20時30分から23時30分、途中30分休憩だ。
所定労働は9時から18時、休憩1時間、法定休日ではない。

**やる夫**：
残業は3時間だから、基礎単価2,000円へ25%増しだお。

$$2,000\times1.25\times3=7,500\text{円}$$

**やらない夫**：
休憩30分をどこへ置いた？

**やる夫**：
波形の真ん中、21時30分から22時だお。
実労働は20時30分から21時30分が1時間、22時から23時30分が1.5時間だお。

**やらない夫**：
22時以降は？

**やる夫**：
深夜だお。
法定時間外25%以上と、22時から翌5時の深夜25%以上が重なる区間は、合計50%以上の割増になるお。[^3]

**やる夫**：
20時30分から21時30分は時間外1時間。

$$2,000\times1.25\times1=2,500\text{円}$$

**やる夫**：
22時から23時30分は時間外かつ深夜1.5時間。

$$2,000\times(1+0.25+0.25)\times1.5=4,500\text{円}$$

**やる夫**：
合計7,000円だお。

$$2,500+4,500=7,000\text{円}$$

**やらない夫**：
最初の7,500円との差は？

**やる夫**：
30分休憩を労働へ入れた過大1,250円と、深夜加算を落とした過小750円が同居して、差額だけなら500円過大だお。

$$7,500-7,000=500\text{円}$$

**やる夫**：
総額差500円だけ直しても、休憩と深夜の二つの誤りは残るお。
また逆位相の病気だお！

**やらない夫**：
法定休日なら同じ式か？

**やる夫**：
法定休日35%以上と深夜25%以上が重なる区間なら、少なくとも60%増し。
でも所定休日と法定休日を名前だけで同じにしないお。

**できる子**：
月60時間超の法定時間外、変形労働時間制、固定残業代、端数処理など、実案件では追加条件があります。
この例は通常日の区間分解だけを扱います。

**やる夫**：
T02は金額7,000円、対象日は6月12日、支払は9月25日、根拠は勤怠・休憩・承認・基礎単価だお。

### 3-1　四月昇給、七月改定 ── 標準報酬月額

〜〜 8月22日13時24分　T03の4月から9月 〜〜

**やる夫**：
T03は4月に基本給が280,000円から320,000円へ上がったお。
だから4月支払から社会保険料も320,000円へ率を掛け直すお。

**やらない夫**：
毎月の総支給額へ直接率を掛けるのか？

**やる夫**：
同じ率で公平だお！

**やる夫**：
……税レーン、保険レーン、住民税レーンから別々の同期音が鳴ったお。

**できる子**：
厚生年金保険料などは、実際の月々の報酬を一定幅の等級へ当てはめた標準報酬月額（standard monthly remuneration）を基礎に計算します。[^4]

**やらない夫**：
T03の4月、5月、6月に実際に支払われた報酬を出せ。

**やる夫**：
固定給320,000円に、時間外などの非固定分が4月30,000円、5月20,000円、6月10,000円。
報酬月額は350,000円、340,000円、330,000円だお。

$$\frac{350,000+340,000+330,000}{3}=340,000\text{円}$$

**やる夫**：
平均は340,000円だお。

**やらない夫**：
それだけで改定か？

**やる夫**：
平均が上がったから決定だお。

**できる子**：
条件を三つ確認します。
固定的賃金の変動、変動月以後3か月の支払基礎日数、従前と新しい標準報酬月額の等級差です。
原則として、全条件がそろった時に随時改定（revision upon change）を判定します。[^5]

**やらない夫**：
この仮想例では3か月すべて支払基礎日数20日以上、社内検証用の等級表でも2等級以上の差になるとする。
いつから新しい標準報酬月額を使う？

**やる夫**：
4月から三か月を見るから、4月、5月、6月。
4か月目の7月から改定だお。

**やらない夫**：
4月の現金支給が増えたから、4月の保険料も必ず変わるという最初の案は？

**やる夫**：
壊れたお。
現金の報酬が変わった時点と、標準報酬月額を決定して適用する時点は別ヘッドだお。

**できる子**：
毎年の定時決定は、原則として4月、5月、6月の報酬を基にし、その年9月から翌年8月まで使います。[^4]
ただし随時改定などの対象者は、定時決定と重なる場合の扱いを確認します。

**やる夫**：
同じ4〜6月の数字が、随時改定なら7月、定時決定なら9月という別の出口へ行く可能性があるお。

**やらない夫**：
固定給が上がったのに、残業が減って平均が下がったら？

**やる夫**：
数字の差だけで飛びつかず、固定的賃金の向きと報酬全体の向き、等級差、支払基礎日数を確認するお。
一本の平均値から決定条件を省略しないお。

### 3-2　350,000円へ15%を掛けない ── 算定基礎と決定主体

〜〜 13時39分　T03〜T04を左右に配置 〜〜

**やる夫**：
8月の総支給は350,000円。
説明用に本人負担の合成率を仮の15%とすれば、控除52,500円だお。

$$350,000\times0.15=52,500\text{円}$$

**やらない夫**：
その15%は実在の2026年料率か？

**やる夫**：
違うお。
制度ごとの料率、加入先、年齢、事業、労使負担を混ぜないための研修用合成率だお。
実案件の健康保険、厚生年金、雇用保険をこの15%で計算してはいけないお。

**やらない夫**：
では仮に、通知された標準報酬月額が340,000円で、同じ研修率を使うなら？

**やる夫**：

$$340,000\times0.15=51,000\text{円}$$

**やる夫**：
実支給350,000円へ掛けた52,500円とは1,500円違うお。

**できる子**：
実務では、各制度の対象となる賃金・報酬、料率、通知、端数処理を別々に確認します。
標準報酬を使う制度と、支払賃金を基礎にする制度を一括率へ潰しません。

**やる夫**：
所得税は社会保険料等控除後の給与と扶養条件を税額表へ当てる。
住民税は自治体通知。
社会保険は標準報酬月額と各料率。
雇用保険は対象賃金と年度・事業別の料率を確認するお。

**やらない夫**：
四レーンを誰が決める？

**やる夫**：
給与ソフトが全部──じゃないお。
