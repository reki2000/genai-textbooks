# リライト記録

`review-opus-medium.md` の指摘を軸に、教材の主張が実演と整合するよう本文を改訂した。

- 第6幕では、架空データから現実の罰則政策を結論できないことを本文中で明示した。実在研究の層を加え、ヘルメットの保護効果と罰則付き義務化の効果を別の問いとして扱った。
- 第7幕では彼女を直接登場させ、夜道への不安、複数の論点、合意後の言葉を本人の発話として置いた。やる夫の要約が正しいかを読者も確認できる構造にした。
- 第8幕の再戦は、できる夫の九つの主張、やる夫が選んだ要、20分18秒の応答、コメント欄の反応まで書き起こした。勝敗票と意見変化が反転した理由を、結果報告ではなく議論本体で示した。
- 演習は三題の問題を先にまとめ、読者が四つの問い・一手目・避ける一手を書いてから解答へ進む形式に変更した。公園の責任問題は推測の根拠と確認質問も補った。
- 幕間(2)の六場面は、重複を避けて相対リスクと恋人の二場面へ圧縮した。第5幕以降の誇大妄想ギャグも複数削り、沈黙や自己点検が増えることで三週間の成長が見えるようにした。
- 滑り坂と正当な帰結検討の境界、現状維持側にも説明責任が生じる条件、「8倍」が普遍定数ではないこと、グラフ操作の典拠を補った。

残した判断として、四つの勝利条件、各幕末の「技を数える」仕掛け、二種類の投票数字、38冊の伏線という全体骨格は維持した。架空の市の数字も計算練習としては有効なので削除せず、「その数字から言える範囲」を狭めて残した。
