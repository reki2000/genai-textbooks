# 寸評：やる夫は論破されたようです ── 弁論術と四つの勝利条件

約207KB／全8幕＋幕間2＋演習3＋終幕。深夜討論で812対88の惨敗を喫した営業マンが、制圧・防御・誘導・協働の四つの勝ち方を順に手に入れ、最後に「勝ち方を選ぶ問い」へ到達する教材。

## 良い点

**教える手口そのものが教材の対象になっている。** 1-4でやらない夫が「今日から予告なしにこの四つの技を使う。各幕の終わりに何をやられたか数えろ」と条件を出し（335–336行目）、以後すべての幕が「今のは何だお」という技の点検節で終わる。この構造は装飾ではなく、5-4で誘導と操作の線を引く場面（2127–2134行目）の唯一の根拠として効く。「先に開示してあったから、引っかかったのはやる夫が下手だっただけで、騙されたのとは違う」という結論は、第1幕の一行が三週間かけて回収された結果であり、他の教材にはない仕掛け。

**数字が二本立てで、最後に反転する。** 2-5で祝勝会の前に説明欄を開かせ、勝敗票588対412に対し賛成率が72%→70%しか動かないことを突きつける（741–744行目）。第8幕では471対529で負けたのに賛成率が72%→58%、「どちらとも言えない」が9%→24%へ動く（3425–3428行目）。同じ二つの数字で、勝ちの空虚さと負けの実質を対称に描いており、教材の主張が説教でなく計測結果として出てくる。

**自分で作った枠組みを二度壊す。** 1-4で四つの勝利条件を渡すとき「この四つの箱に世界が綺麗に収まると思うな」と予告し（314–315行目）、幕間(1)で実際に壊す。交渉というジャンルが丸ごと抜けていたこと（914–918行目）、そして「防御」だけが場の名前ではなく個人の狙いで、他の三つと層が違うこと（1002–1004行目）。分類を渡して終わりにせず、分類の欠陥まで教材の中身にしている。

**技が私生活で暴発し、その代償を払う。** 部長への荷物の押し付けは「君の言うとおりだ。だが今期は無理だ」で終わり（876–877行目）、彼女には藁人形と立証責任を使って「……もういい」と歩き去られ（948–949行目）、工場長には質問の形をした追及を三つ並べて口を閉ざされる（1671–1674行目）。習った技が習ったとおりに効いて、そのせいで負ける。苦労が「分からない」ではなく「できてしまう」側から来ている点が良い。

**28個の技を7個まで自分で削らせる。** 幕間(2)-1でラミネートカードの案が「会話は止まってくれない」で潰れ（2588–2592行目）、7-6で「開示に耐えた技は7個」まで絞られる（3155–3159行目）。網羅表を作って渡す教材になりかけたところを、教材自身が否定して四つの問い（3240–3245行目）へ圧縮する。

**参考文献が28点、すべて本文の節番号つき。** アリストテレス、ショーペンハウアー、ウォルトン＆クラッベ、フィッシャー＆ユーリー、サンスティーン、ギーゲレンツァー、ハーバーマス、ミルまで（3906–3960行目）。特に「善処します」の誤訳逸話を出したうえで、その逸話自体が公文書上確認できないと注で潰す構成（1643–1645行目／3938行目）は、曖昧な言葉の危険を語る話が曖昧な出所だったという二重の落ちになっている。

**人物紹介の一行が伏線として全部回収される。** 「押し入れに背表紙のない黒いファイルが38冊」（8行目）は終幕の想定問答集（3792–3827行目）へ、「まだ一度も負けていない」（10行目）は8-2の「僕は、まだ一度も負けていません」（3306行目）へ着地する。

## 欠点

**同じギャグを約30回打っている。** やる夫が誇大妄想を語り、次のやらない夫の一言で潰される型が、82–84、233、296、368–370、465、553–556、638、906、1214–1216、1336–1339、1604–1605、1914–1917、1980–1981、2042–2045、2266–2269、2335–2338、2625–2626、2832–2835、2951–2954、3247、3344–3346、3623、3679、3739行目ほかで反復される。しかも「塾を開いて月謝3万円」「Tシャツを1枚3,000円」「講演依頼が来る」と金額まで同型。第4幕あたりで読者は次の行を予測できるようになり、以後は笑いではなく句読点として機能してしまう。207KBという分量の相当部分がこの型の反復で埋まっている。

**中心の事例が架空の数字で、教材が自分の基準に触れていない。** 第6幕の全論証は「説明用に組んだ架空の市の数字」（2233–2235行目）に立っている。5万人・1万人・8人という数字は相対リスクと基準率を教えるには理想的だが、その架空データからやる夫は説明会で「罰則を付ける根拠は薄いですお」と結論する（2450行目）。数字の誠実な扱いを最も厳しく教える幕が、ヘルメットの効果に関する実在のエビデンスに一度も触れないまま、実在の政策論点について結論を出す形になっている。教材が自分で立てた「開示できるか」の基準に、この設計自体が引っかかる。

**彼女に一行も直接発話がない。** 第7幕の協働は彼女との引っ越し交渉が舞台なのに、彼女の言葉はすべてやる夫の伝聞で出てくる（938行目「駅の近くがいいと思うんだけど、どう思う？」、2820行目、2973–2974行目）。7-1の教えは「相手の言い分を、相手より上手く言え」であり、その実演を読者が採点するには彼女の実際の言葉が要る。第1幕でできる夫の5文を一文ずつ書き起こして数えさせた（125–130行目）のと同じ扱いをすべき場面で、相手が舞台に上がっていない。

**最大の山場の中身が省略されている。** 8-4の再戦は、賛成率が14ポイント動いた根拠が「20分18秒」の一行（3414–3415行目）だけで、やる夫が何をどう話したかは描かれない。900人が考え直した瞬間を作った議論そのものが本文にないため、教材の最終主張が実演ではなく報告になっている。第1幕が対戦の書き起こしを丁寧に解剖したのと対照的に、最も重要な討論だけが要約で処理されている。

**演習が演習になっていない。** 3608–3785行目の3題は、やる夫が(1)(2)(3)(4)を通し、途中で自分で誤答を訂正し、正解まで自分で言う。読者が考える隙間がゼロで、本編の会話と形式も密度も変わらない。「演習」という見出しを掲げている以上、問いだけ置いて解答を末尾へ回すなど、読者が手を動かせる形が必要。

**個々の概念が浅い箇所がある。** 滑り坂は「勝手に極端まで転がす」で導入され（477–484行目）、正当な帰結論証との線引きが一度も出てこない。立証責任は「現状を変えようとしている側が理由を示す」（629–630行目）で完結し、現状維持そのものが正当化を要する場合の扱いがない。2-2の「撒くコストと潰すコストが8倍」（539–541行目）に至っては、やる夫の場当たり的な計測（1つ5秒、反論40秒）だけが根拠で、他の概念には全部付いている参考文献がここにはない。

**幕間(2)の圧縮余地。** 幕間(2)-1で三問を作り（2611–2624行目）、幕間(2)-2で六場面に当てる（2646–2706行目）が、この六場面は幕間(1)-3の五問（1020–1068行目）とほぼ同じ形式の反復であり、しかも第8幕の演習3題とも重なる。同型の「場を判定させるクイズ」が3セット並んでいる。

## 改善案

1. **誇大妄想ギャグを半分に削り、代わりに沈黙を置く。** 第5幕以降（1867行目以降）は特に密度が高い。2042–2045、2335–2338、2951–2954、3344–3346行目あたりは、やる夫が反射的に暴走せず、一度黙って考え込んでから間違える形に書き換える。三週間で人物が変わったことを、暴走の頻度が落ちるという形で示せば、ギャグの削減がそのまま成長曲線の描写になる。

2. **彼女を舞台に上げる。** 7-1の2820行目付近と7-2の2854–2857行目付近に、彼女の直接発話を各5〜8行入れる。特に7-2で論点が11個出てくる場面は、やる夫の要約ではなく彼女自身の言葉で並べさせ、そこから「これが逆なら結論が変わるもの」をやる夫が選り分ける形にする。7-5の「ありがとう」（3108行目）が伝聞でなく実際の台詞として置かれるだけで、第7幕の着地の重みが変わる。

3. **第6幕に実データの層を一枚足す。** 2233行目の「架空の市」という前提は残したうえで、6-4のできる子の指摘（2436–2440行目）の後に、実在の研究（自転車ヘルメットの効果推定、義務化後の利用者数変化に関する研究など）を10〜20行で持ち込み、「架空の数字で練習した読み方を、本物のばらついた数字に当てると何が起きるか」をやる夫に一度やらせる。同時に、6-3のチェリーピッキングと軸切り（2385–2392行目）に他の概念と同水準の脚注を付け、参考文献の網羅度を揃える。

4. **8-4の討論本体を書く。** 3402–3418行目を拡張し、できる夫が撒いた9個のうちやる夫が選んだ1個が何で、なぜ「これが崩れたら残りも崩れる」と言えたのかを実際の台詞で見せる。そのうえで20分18秒の一手（相手の一番強い言い分を自分の口で置く）を、コメント欄の反応と並べて描く。ここは第1幕の書き起こし解剖（120–140行目）と対を成すべき箇所で、教材全体の証明にあたる部分が現状は伝聞になっている。

5. **演習を読者向けに作り直す。** 3608行目以降の3題は、やらない夫が状況を提示したところで一度切り、(1)〜(4)とやってはいけない一手を読者に書かせる形にする。やる夫の解答は末尾にまとめて置き、演習1で撤去派の要が「責任の所在」だと当てる部分（3655–3656行目）のような跳躍には、なぜそう推測できたのかの根拠を解答側に付ける。

6. **幕間(2)-2の六場面を削り、第8幕に統合する。** 2646–2706行目は幕間(1)-3（1020–1068行目）と機能が重複している。六場面のうち二つ（4番の相対リスク、6番の恋人）だけ残して幕間(2)-1に吸収し、残りは第8幕の演習側へ移す。同型のクイズが3セット並ぶ状態が解消され、全体で数十KB圧縮できる。

7. **概念の穴を1〜3行ずつ埋める。** 484行目の後に、滑り坂が正当になる条件（実際に因果の連鎖が観測されている場合）を一問足す。630行目の後に、現状維持側にも立証責任が生じる場面（現状がすでに誰かに損害を与えている場合）を一問足す。541行目の8倍という数字には、検証コストの非対称に関する既知の言及（ブランドリーニの法則など）を脚注で付ける。いずれも数行で済み、「便利な規則を渡して終わり」という印象が消える。
