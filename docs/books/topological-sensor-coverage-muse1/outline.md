# やる夫が位相幾何学を応用するようです ── センサーネットワークの被覆を証明する の骨格

舞台は市の防災システム。**山間部の監視センサー312台**が全台オンラインで通信グラフも連結なのに、点検ドローン7号が下流に集落と避難路のある沢筋で約4分間どのセンサーからも観測値を受け取れなかった、という矛盾から始まる。**増水予測の更新まで残り6時間12分**というタイマーが 1-1 で置かれ、最終節 8-3 で「残り1時間43分」として回収される。到達点は de Silva–Ghrist の定理（強信号・弱信号2つのRips複体と境界部分複体の対から、包含が誘導するトップ次元相対ホモロジー写像の非零性で被覆を保証する十分条件）で、**座標をいっさい復元せずに**そこへ至る。各幕末にできる子が**幕末の問い**を置き、答えは次の幕の冒頭で数値つきで回収される（定着装置）。2-2 に**道具の対応表**（概念↔手元のデータ↔現場の判断）を置く。

全編の目標である変換の鎖は 1-2 で先に宣言される：通信記録 → 有限個の三角形 → 行列 → 穴の生成元 → 追加配置。最終節 8-3 でこの鎖が「局所的な通信関係 → 単体複体 → 境界行列 → 相対ホモロジー → 被覆保証」として再掲される。主題は**数を見るのでなく写像を見る**ことで、5-1 の $j_*([z])=0$、6-1 の $\operatorname{rank}\iota_*$、8-1 の $[\iota_*]=(1)$ と3回反復深化される。

## 第1幕　つながっているのに見えていない
- 1-1　$\beta_0(G)=1$ で完全被覆と誤認。**8個の磁石を円環に並べる**教具で、連結なのに中央が空くことを体感し、三角形タイル＝面の情報が要ると気づく。最小次数・頂点連結度を上げても円環を太くすれば穴は作れる。**「グラフを捨てるのか」に対し「捨てない、含む＝グラフは新しい構造の一階」**。沢筋の下流の集落・避難路が stakes として最初に置かれる。
- 1-2　**単一の数へ潰す指標を順に殺す**。面積の足し算 $n\pi r_c^2>A$＝重なりを多重計上（包除原理は座標が要る／GPSは10分で38m揺れる）。格子・モンテカルロ $(1-q)^m$・セル密度も座標か見逃し確率が残る。**平均は最小値の下界ではない**（効くのは $\bar r$ でなく $\min_i r_i$）。確率的被覆も仮定「一様ランダム配置」が成り立たない（設置方針は「林道と尾根沿い、駐車位置から徒歩30分以内」）。
- 幕末の問い：磁石8個の輪の $\beta_0$ と、中央の穴は $\beta_0$ で数えられるか（答えは 2-1）。

## 第2幕　地図を捨てる
- 2-1　最小二乗法で座標復元する案。通信装置は距離を返さず、取れるのは**強信号近隣一覧・弱信号近隣一覧・境界近傍フラグの3種の観測データのみ**。距離制約には回転・平行移動・鏡映・非剛性の不定性。**「座標精度の評価と位相的特徴の安定性は別の量」**（1cmの差で連結性や3円共通部分が不連続に変わる）。代わりの手段＝**答えのほうを揺すって粘りを見る**＝第6幕のパーシステンスの予告。座標推定は「保証の根拠」でなく「探索の参考」へ降格。
- 2-2　入力の形式化。$B_i$、$r_s<r_w$、$N_s/N_w$、$G_s\subseteq G_w$、境界フラグ $f_i$ と $X_f$。**境界フラグは方向を教えない**ことが第7幕で相対ホモロジーを使う理由になる。ここに**道具の対応表**（連結成分／$H_1$／パーシステンス／相対 $H_2$／写像 $\iota_*$ ↔ データ ↔ 判断）を置く。
- 幕末の問い：3台が互いに強信号でも3円共通点は即断できるか（答えは 3-1）。

## 第3幕　円盤を三角形へ変える
- 3-1　Čech複体と **nerve定理**（交差がすべて可縮なら $\check C\simeq\bigcup B_i$）。ただし**ペア交差から3重交差は決まらない**。円盤を広げて3重交差が生じる瞬間に $[1,2,3]$ が入り $H_1$ が消えることを確認し、**「通信は三角形、現実は穴」＝この教材でいちばん怖い絵**と名指しする。
- 3-2　Vietoris–Rips複体＝旗複体（クリークを埋める）なので通信グラフから直接作れる。だがRipsは埋めすぎも作りすぎもする。対策は $R_s\subseteq R_w$ の2スケール。**やる夫が $\rho_d$ を自力で導く**：正三角形が最悪で $\varepsilon/\sqrt3$、一般に $\rho_d=\varepsilon\sqrt{d/2(d+1)}$、上限 $\varepsilon/\sqrt2$。挟み撃ち $R_\varepsilon\subseteq\check C_{\varepsilon'}\subseteq R_{\varepsilon'}$ は途中のČechを構成せず存在と包含だけを使う。
- 幕末の問い：1辺 $\varepsilon$ の正三角形の外心距離（答えは 4-1）。

## 第4幕　穴を線形代数へ落とす
- 4-1　$\mathbb F_2$ 係数の鎖群。正方形の4辺で $\partial_1z=0$、三角形の境界として書ける閉路は穴でない → $H_1=\ker\partial_1/\operatorname{im}\partial_2$。$\partial_{k-1}\partial_k=0$ から $B_1\subseteq Z_1$。$H_0$ と $\beta_0$＝連結成分数（第1幕の連結性の再定義＝グラフは一階として残る）。Euler標数 $\chi=4-4=0=\beta_0-\beta_1$ で検算し、**$\chi$ は交互和しか与えないので次元ごとの計算が要る**。
- 4-2　境界行列を実際に掃き出す。正方形：$\operatorname{rank}\partial_1=3$、$\beta_1=1$。対角線と三角形2枚を足すと閉路空間は2次元に**増える**のに $\beta_1=0$＝**商空間が必要な理由**。実データで $\beta_0(R_s)=1$、$\beta_1(R_s)=3$、代表閉路の1つが $\{87,91,104,118,121,109\}$ でドローンの報告位置と一致。疎行列、**$H_2$ に $\partial_3$（四面体）が要る理由**。
- 幕末の問い：外周4辺だけの正方形の $\beta_1$（答えは 5-1）。

## 第5幕　行列がセンサーを動かす
- 5-1　**本編最大の実演。二段の失敗と修正**。模型（4頂点＋中央 $v_5$）ではスポーク4本・三角形4枚で $\beta_1=4-4=0$、外周閉路 $z$ が $\partial_2(t_1+\cdots+t_4)$ になる。ところが実データの代表閉路は**6頂点**で、M5の強信号近傍は4台のみ（121と109は弱信号だけ）。三角形3枚しかできず $\beta_1=4-3=1$ で**穴が残る**。残った閉路 $z'$ にはM5自身が含まれ、**2台目M6の条件は「穴の近く」でなく「$z'$ の全頂点（M5を含む）と結べること」**。M6投入後は頂点8・辺15・三角形8で $\beta_1=8-8=0$、$\chi=8-15+8=1$（円盤）で独立検算。さらに **Betti数の増減でなく写像 $j_*([z])=0$ でクラスを追う**。
- 5-2　代表閉路は一意でない（$z'=z+\partial_2c$）ので、辺数・重み最小化は**存在判定と分けた後段の最適化**。できる子が「第2生成元は3辺」と報告し、旗複体なら3辺あれば三角形が入るはずだと**やる夫が矛盾を見抜き、境界部分複体を除外した中間データという入力のミスが発覚**する。できる夫が運用制約を読み上げる：**移動センサーは3台（M5/M6/M7）、電池6時間20分/4時間45分/2時間10分、片道38分/1時間52分、固定した機体は動かせない**。ここから「消せる穴を全部消すのでなく、**消さないと保証が通らない穴だけ**消す」。
- 幕末の問い：M5投入後の $\beta_1$ と、$z'$ にM5が含まれるか（答えは 6-1）。

## 第6幕　存在しない穴、動く穴、終わらない計算
- 6-1　計算はRips複体について厳密だが、Ripsが現実と同じ位相とは限らない。解は $\iota_*:H_k(R_s)\to H_k(R_w)$ の**階数**を見ること：$\beta_1(R_w)$ の非零性では「新しく生まれた偽穴」と「生き残った穴」を区別できない。4頂点＋対角線の最小例で $\iota_*([z])=0$。幻へ機体を送る／本物を捨てる、双方の損失を下流の集落の stakes で示す。
- 6-2　フィルトレーションとバーコード、寿命 $\operatorname{pers}(z)=d(z)-b(z)$（$[12,14)$ のノイズ対 $[11,23)$ の本物）。ただし**長寿命＝現実の穴とは限らず、短寿命を全部捨ててもいけない**。続けて**時間変化する被覆**を小さな具体例で場面化する：104番の間欠動作で $K_{\text{昼}}\supseteq K_{\text{夜}}\subseteq K_{\text{朝}}$ と包含が折り返し、夜だけ穴が開く列を **zigzagパーシステンス**で追う。ただし被覆定理は1時点の2スケールのままで、zigzagは点検判断に使うと自己限定する。
- 6-3　**計算量と実装の現実**。弱信号側の全クリーク列挙で計算が止まる場面から、$\binom{312}{3}=5013320$、$\binom{312}{4}=387278970$、$2^{312}$ を数え、工夫を4つ出す：(1) 必要な次元までで止める、(2) 疎行列、(3) 近傍の交わりからクリーク候補を作る、(4) 時刻差分で再計算を局所化する。制限時間内に返らない計算は現場では存在しない判定と同じ、と締める。
- 幕末の問い：$[12,14)$ と $[11,23)$ のどちらを先に点検するか＋長寿命が証明にならない理由（答えは 7-1）。

## 第7幕　境界をゼロとみなす
- 7-1　区域の外周まで穴と数えてしまう問題。$C_k(K,F)=C_k(K)/C_k(F)$。4外周頂点＋中央の模型で $\partial^{\mathrm{rel}}t_i$ を出し、$\alpha=t_1+\cdots+t_4$ の相対境界が0＝**区域を横切って張られた面＝基本類**。$K/F$ の被約ホモロジーという言い換え。**「境界を無視する」は情報を捨てることではなく、どの鎖を0とみなすかを $F$ として明示すること**で、$f_i$ の誤判定は相対サイクルの偽造にも判定失敗にもなる＝**境界フラグの校正は前処理でなく定理の仮定**。境界帯の避難路・連絡橋が後半の stakes。
- 7-2　相対境界行列（第4幕の正方形と同じ形）から $H_2(K,F)\cong\mathbb F_2$。$t_4$ が欠けると3列独立で $\ker=0$、$H_2(K,F)=0$。**どの未相殺辺が裂け目か**を $\partial^{\mathrm{rel}}c$ の連立から示す。実データでは $H_2(R_s,F_s)\cong H_2(R_w,F_w)\cong\mathbb F_2$、$[\iota_*]=(1)$。**「$H_1$ は内部の穴候補を探す道具、相対 $H_2$ は領域全体の被覆を保証する道具」**と役割を分離。
- 幕末の問い：$t_4$ 欠損模型の $H_2(K,F)$（答えは 8-1）。

## 第8幕　地図なしの被覆証明
- 8-1　**半径条件の意味づけ**。$r_c\ge r_s/\sqrt2$ は 3-2 で自分が出した $\rho_d$ の上限そのもの（**「天下りじゃなかった」**）。$r_w\ge r_s\sqrt{10}$ は挟み撃ちの**2段分**の余裕で、前者は検知と通信の比、後者は通信同士の比＝**別の部品の仕様**。判定は $\iota_*:H_2(R_s,F_s)\to H_2(R_w,F_w)\neq0 \Rightarrow D\setminus N_{r_y}(\partial D)\subseteq U$。**できる子が「M5のみでは $[\iota_*]=(0)$、M6投入で $(1)$」と報告**し、5-1 の $\beta_1$ とは別判定でありながら同じくM6まで必要だったと確認。背理法の筋（未被覆点があれば基本類が実現できず非零性と矛盾）。
- 8-2　**コホモロジーへの橋渡し**。境界行列を転置し、辺に載せた値（時刻のずれ $+2,+2,-5$、輪の和 $-1\neq0$）が頂点の補正では消せない不整合として残る具体例で1次コホモロジーを導入する。パーシステントコホモロジーの簡約が実務で速いことが 6-3 の爆発へのもう1つの答え。続けて**3次元の導入場面**：ドローン滞空層まで対象が広がればトップ次元クラスは $H_3(K,F)$ になり4単体まで要るが、$\rho_d$ の上限は次元によらない。ただし条件は3次元で改めて確かめると留保する。
- 8-3　**成功しても万能ではない**。定理は十分条件であり、$\iota_*=0$ は「未被覆の証明」ではなく「被覆を証明できなかった」の意味（疎すぎる配置、境界フラグの不安定、半径条件違反、細いくびれ）。等半径円盤・理想的な距離閾値・故障や時間変化という仮定も列挙し、zigzagは定理の拡張ではないと再確認する。第1幕で殺した手法との対比で締め、$\beta_1:1\to0$ と $[\iota_*]:(0)\to(1)$ が投入・固定・点検継続という3つの現場判断に対応したことを確認。落ちは報告書ファイル名「完全被覆_最終版_確定_本当に確定_v7.docx」。

## 依存
- **「グラフを捨てるのでなく含む」**（1-1）が全編の構造：$C_0/C_1$（第4幕）はグラフそのもので、$\beta_0$ は 1-1 の連結性の再定義。
- **3-1 の「通信は三角形、現実は穴」の絵**が 6-1 の偽の穴、8-1 の $r_w\ge r_s\sqrt{10}$ の1段目の共通の根拠。
- **$\rho_d=\varepsilon\sqrt{d/2(d+1)}$ と上限 $\varepsilon/\sqrt2$**（3-2）は 8-1 で $r_c\ge r_s/\sqrt2$ として、8-2 で3次元への橋として回収される。
- **「答えを揺すって粘りを見る」**（2-1 末）→ 3-2 の2スケール → 6-1 の $\operatorname{rank}\iota_*$ → 6-2 のバーコードと zigzag、と同じ発想が段階的に具体化される。
- **数を見るのでなく写像を見る**という転換が3回反復される：5-1 の $j_*([z])=0$、6-1 の $\operatorname{rank}\iota_*$、8-1 の $[\iota_*]=(1)$。
- **模型（4頂点＋中央、$\beta_1=0$）と実データ（6頂点の代表閉路、M5だけでは $\beta_1=1$）の対比**が 5-1 の山場。代表閉路の頂点数を6から変えると、スポーク4本・三角形3枚・$\beta_1=4-3=1$、およびM6投入後の 8-15-8 と $\chi=1$ の計算がすべて連動する。
- **第7幕の4三角形模型の相対境界行列**は第4幕の正方形の境界行列と**同じ行列**であることが本文で明言される。
- **代表閉路 $\{87,91,104,118,121,109\}$** は 4-2（抽出）、5-1（M5の近傍が4台、M6が5台）、8-1（変化した単体の報告）で一貫して使われる。
- **できる夫の運用制約**（3台、電池6:20/4:45/2:10、片道38分/1:52、固定したら動かせない）は 5-2 でのみ提示され、「保証が通らない穴だけ消す」という方針転換の根拠になる。
- **幕末の問い**は第1〜7幕の各幕末に置かれ、答えは次の幕の冒頭で回収される。問いと答えの数値（$\beta_0=1$、即断できない、$\varepsilon/\sqrt3$、$\beta_1=1$、$\beta_1=1$ とM5含有、$[11,23)$ 優先、$H_2=0$）を変えるなら対の箇所も直す。
- **6-3 の組合せ数** $\binom{312}{3}=5013320$、$\binom{312}{4}=387278970$ は $n=312$ に依存する。台数を変えるなら再計算する。
- タイマー（6時間12分 → 1時間43分）は 1-1 と 8-3 の対。夜間の再計算予約（8-3）は 6-2 の zigzag の場面への小さな回収。
