# `orbital-mechanics-moon_v2` 状態台帳

## 制約

- 新規長編、8幕＋終幕。高校数学から始める。
- 反射鏡との会合、七回目の測距、安全終端を物語の背骨にする。
- やる夫＝月面光学研究者、やらない夫＝民間タグ船設計者。対等な二者として、観測価値と落下域安全に別々の責任を負う。
- 2幕後の承認待ちは、ユーザーの全編執筆承認により省略。

## 固定した仮想データ

- 地球半径 $R_E=6378\ \mathrm{km}$、地球標準重力パラメータ $\mu_E=398600\ \mathrm{km^3/s^2}$。
- TSUKI-17：近地点高度300 km、遠地点高度40,000 km、$r_p=6678\ \mathrm{km}$、$r_a=46378\ \mathrm{km}$。
- $a=26528\ \mathrm{km}$、$e=0.7483$、$T=43000\ \mathrm{s}=11.9445\ \mathrm{h}$、$v_p=10.215\ \mathrm{km/s}$、$v_a=1.471\ \mathrm{km/s}$。
- 教学用軌道面座標の$T_0$遠地点状態：$\mathbf r=(46378,0,0)\ \mathrm{km}$、$\mathbf v=(0,1.471,0)\ \mathrm{km/s}$。
- 実運用要素の予定値：$i=28.50^\circ$、$\Omega=75.0^\circ$、$\omega=140.0^\circ$、$\nu(T_0)=180^\circ$。第3幕で導入。
- タグ船候補：軌道面差0.25°、TSUKI-17より位相で8.0°後方。残Δv $320\pm8\ \mathrm{m/s}$。
- 七回目の測距窓：$T_0+35\ \mathrm{h}\ 58\ \mathrm{min}\ 40\ \mathrm{s}$。二体3周期との差8分39秒。
- TSUKI-17終端用自己Δvは最大30 m/s。反射鏡有効面積12 cm²。
- 初期位置推定の進行方向3σ幅36 km。第3幕で共分散を具体化。

## 全幕の到達点

- 第1幕：状態ベクトル、エポック、ECI、単位、Δv、予算の不確実性を定義。直進20分で対象が約1,765 km進む反例。10分直線近似の内向き誤差を約33 kmと概算。
- 第2幕：高度400 kmでも$g=8.68\ \mathrm{m/s^2}$。円軌道速度・周期、半長軸、離心率、活力方程式、比角運動量、エネルギーによる円錐曲線分類を導出。
- 幕間：同じ位置・速さでも速度方向が違えば軌道面が違うと転移。第3幕の六軌道要素へ接続。
- 第3幕：六軌道要素、状態との相互表現、共分散と状態遷移を導入。0.25°の面差が遠地点で約202 kmになる反例。追加観測後も近傍条件を満たさない。
- 第4幕：R/T/N噴射、オーベルト効果、面変更式、ホーマン遷移を導出。遠地点面変更6.42 m/s対近地点44.6 m/s。第一修正は面外6.4＋半径3.0で7.07 m/s。
- 第4幕後：面差0.018°、第三遠地点時刻差2分14秒、伝播後進行方向3σ幅18 km。悪い側の残量304.3 m/s以上。
- 第5幕：8°を一周で稼ぐフェージングを導出。$T_f=11.6791$ h、$a_f=26134$ km、遠地点高度39,212 km、近地点で−11.1/+11.4 m/s。Hill/CWで直進接近の横流れを反証。推定更新と保持点を導入。
- 第5幕後：第二札は5噴射合計35.2 m/s。第一札と合計42.27 m/s、悪い側残量269.73 m/s。相対距離1.8 km、相対速度0.04 m/s、3σ位置幅0.42 km。
- 第6幕：月影響圏約66,100 km、patched conics、月中心$\mathbf v_\infty$と地球中心速度の変換、重力アシスト、自由帰還、ラグランジュ点を導出。六回の光行時間から第七測距を再構成。
- 第6幕後：第七測距は$T_0+35$ h 58 min 40 s、往復光行時間2.258731 s、距離約338,575 km、開始幅±0.9 s。
- 第7幕：$J_2$節点歳差を導出。TSUKI-17で約−0.308°/day、36 hで−0.462°。月太陽、抵抗、放射圧を含む感度・モンテカルロ・閉ループ航法へ進む。
- 第7幕後：測距直前3σ幅は半径0.31 km、進行0.84 km、面外0.18 km。通信条件内99.94%。タグ船悪い側残量265.6 m/s以上。
- 第8幕：遠地点逆行候補20/24/30 m/sを入口回廊で比較。24 m/s候補を採用し、実測23.8 m/s、新近地点56 km、120 km入口角−5.28°予測。
- 終幕実績：第七反射往復2.258729 s、予測差−0.002 ms。入口角実測推定−5.31°、落下予測帯は指定海域内。第三札6.2 m/s未使用。

## トイ・伏線

- 黒い三十六時間盤：第1幕は状態矢印、第2幕は楕円時計。各幕末の「三十六時間盤を読む」で累積適用。
- 二つのビー玉：同一点・逆速度から、第3幕の軌道面、第5幕の相対運動へ再利用。
- Δv札3枚：第一札7.07 m/s、第二札はフェージングと段階接近へ分割して35.2 m/s。裏面「使わないも判断」。第三札は第8幕。
- 薄い月軌道：第6幕でpatched conicsと光路へ回収。
- 七回目だけ空白の反射時刻列：第6幕で軌道履歴の独立検査と測距時刻へ回収。終幕で実測を埋める。
- 再突入回廊の二線：第8幕で教材用入口角−6.0°〜−4.5°として回収。滑走路誤認ギャグも回収。
- `320±8 m/s`：第7・8幕で余裕の下側評価へ。

## 感情・関係

- 第1幕：やる夫の直進自信→1,765 km空振り→責任条件を相互承認。
- 第2幕：無重力の慢心→重力88.5%→三周期が測距窓近傍と分かる達成感。
- 第3幕：0.25°を無視する慢心→202 km差→線を帯へ変える警戒。
- 第4幕：全噴射を遠地点へ置く慢心→目的により有利な場所が逆転→小修正を選ぶ節度。
- 第5幕：加速追跡の慢心→位相悪化→時間を使うフェージング、近接の緊張から段階接近へ。
- 第6幕：月を無料加速器・L点を駐車場とみなす慢心→参照系と交換の理解→六回の光を静かに読む共同謎解き。
- 第7幕：閉じる楕円への慢心→$J_2$だけで365 km級→一発必中を捨て閉ループへ。
- 第8幕：最大逆噴射への慢心→浅過ぎ・深過ぎの両反例→24 m/sを選び6.2 m/sを残す。
- 終幕：観測価値と落下域安全のどちらも犠牲にせず、二人の別責任を一つの検算可能な軌道へ統合。
- 二人は互いの表を正解扱いせず、共通座標へ載せることで協働を開始。

## 回収確認

- 定規直進：第1幕失敗→第5幕近傍で再失敗→第6幕光行時間→終幕で短時間近似へ限定。
- 七回目の空白：第6幕で予測条件、第8幕で実測、終幕で科学解析へ。
- 月の薄線：第6幕のpatched conics・光路へ。
- `320±8 m/s`：悪い側残量で全幕評価し、第7幕で質量請求書へ。
- 「使わないも判断」：第8幕で自己Δv6.2 m/s未使用。ただし未使用自体でなく条件達成を成功理由にした。
- 回廊二線：第8幕の候補A/B/Cと不確実帯で回収。
- 次の未解決は小惑星KX-41。開かれた地平として終幕にのみ置いた。
