# やる夫が日銀総裁になるようです ── 金融政策を再発明する の骨格

全編で **りんご島**（人口100人、年産1万個、1個100円、貨幣50万円、1人あたり5,000円）を使い回す。巻末に道具一覧表がある。

## 第1幕　「お金を刷ればインフレ」が壊れる日
- 蛇口理論＝貨幣数量説 $MV=PY$ を、りんご島で $V=2$ と計算させてから、2013年のQQE（マネタリーベース135兆→670兆、約5倍）に対し物価上昇率が年0.5%前後だった事実で潰す。やる夫が自力で「$V$ が5分の1に潰れた」と診断。「$V$ が下がるなら余計に刷ればいい」も、$V$ の低下が $M$ の増加に連動するいたちごっこだと気づいて撤回。「$MV=PY$ は $V\equiv PY/M$ と定義すれば恒等式で、死んだのは『$V$ は安定な定数』という追加の仮定のほう」。
- **保留その1**（$V$ はなぜ・いつ潰れるのか。ヒント＝当時の短期金利はゼロ）と**保留その2**（物価の安定が目標ならなぜ0%でなく2%か。「恐怖から逆算された安全マージン」とだけ予告）を設定。

## 第2幕　金利ゼロの世界で、お金と国債が同じ紙になる
- 緩和の正体＝買いオペ＝資産の交換。りんご島の島民として、金利5%の国債と現金の交換なら行動が変わるが、金利0%の国債との交換では「白い紙を白い紙と交換されただけ」で何も変わらないと発見。**保留その1を回収**（$M$ の増加がそっくり $V$ の低下に吸収されるのは偶然でなく必然）＝流動性の罠。
- 「効き目が弱い」と「効かない」は程度問題ではないか、という疑いに対し、金利5%→0%で現金保有のペナルティが消える＝需要が無限に伸びきる**相転移**だと自力で言語化。ゼロ金利制約の理由（現金という金利0%の逃げ場）、日銀−0.1%・ECB−0.5%の実例と限界。
- **保留その3**（床に着いたら中央銀行は無力なのか）を設定。ヒントは「今日の金利が動かせないなら、動かせるものは『今日』の外にある」。

## 第3幕　今日の物価は明日の政策が決める
- りんご島で「来年から貨幣を毎年2倍」と宣言されたら、貨幣が1円も増える前に今日の価格が動く。逆向きも確認。「物価は静的な需給の一致点でなく**資産価格**」と到達し、第2幕の禅問答の方向（明日以降の金利予想は動かせる）が見えかける。だが因果の鎖を最後まで言えず矢印が絡まるので、第4幕で4つの道具を作ると宣言。保留リストを更新。

## 第4幕　道具の構築 ── ループを1本ずつ固定する
- 4-1　フィッシャー方程式。5,000円＝りんご50個を貸して年10%インフレなら46.8個しか返らない、という計算から $r\approx i-\pi$、さらに $r=i-\pi^e$（予想が実体に入る入口）。1998年の日本を $i=0$、$\pi^e=-1\%$ で診断して $r=+1\%$ を出すが、「比べる相手がいないと高いか低いか判定できない」と詰まる（4-2 への入口）。デフレが深まるほど実質金利が自動的に上がるスパイラルと、フィッシャーの負債デフレ理論。
- 4-2　自然利子率 $r^*$。貨幣のないりんごの現物貸借の島で、我慢の対価と投資の実りが釣り合う点として定義。$r^*=3\%$ の島で名目金利を1%に固定すると、インフレ予想が上がるほど実質金利が下がって加速する＝ヴィクセルの累積過程を数値で追い、「名目金利の固定は手のひらに棒を立てるのと同じ＝不安定平衡」と言語化。1942年のFRBの金利釘付けと1951年アコード。**できる子が政府側から低金利固定を要請する場面**があり、「断る根拠を総裁個人の勘でなく公表できる言葉で示せ」と迫られる（第5幕の候補A棄却の伏線）。$r^*$ は観測できず推計値が1%ポイント単位でブレるという制約を、第5幕の条件(3)として予告。さらに「先進国の $r^*$ は40年下がり続けている」という不吉な事実を予告（最終幕で回収）。
- 4-3　IS関係。りんご島の島民として $r=0\%$ と $r=20\%$ で消費配分が変わることから「実質金利は今日の消費の値段」と掴み、$x=-\sigma(r-r^*)$。差だけが効く＝4-2 の棒が式になっている。最後に「本当は将来にわたる実質金利経路の全体で今日の需要が決まる」と精密化（第5幕のフォワードガイダンス導出に直結）。
- 4-4　フィリップス曲線。やる夫が「価格が伸縮的なら $x$ は恒等的にゼロでISの出番がない」＝古典的二分法の異議を出し、ボルカーの引き締め（金利20%、失業率10.8%）で事実として潰される。ジュース屋1軒の据え置き理由＝メニューコスト。さらに「1軒の気分から島全体の平均価格へ」の飛躍を、100軒中20軒だけが330円に改定して平均306円＝需要10%増が物価2%増に薄まる、という数値で埋める。$\pi=\pi^e+\kappa x$。「価格がサボった分の調整を生産と雇用が肩代わりする」＝金融政策が実体経済に効く理由。ここで4部品が揃いループが閉じる。
- 4-5　テイラー原理。インフレ上振れに名目金利を1対1で対応させると $r=i-\pi^e$ の引き算で相殺されて実質金利が動かない＝予想がどこへ漂流しても追認するだけ、と数値で確認。やる夫が「これは 4-2 のヴィクセルの棒と同じ病気」「1対1ルールは予想と一緒に動く釘付け」と自力で転移。$\phi>1$ の条件を導き、$\phi=1.5$（収束）と $\phi=0.8$（発散）の両方を計算。「手のひらに立てるのでなく糸で天井から吊るす」。

## 第5幕　総裁の行動原理を導出する（クライマックス）
- 条件(1)物価の錨／(2)実体の安定／(3)観測可能性／(4)頑健性／(5)ZLB対応／(6)信頼可能性 を列挙。
- 候補A（純粋裁量）＝(6)で即死。ここで**できる子が選挙前の利下げを要請**し、ルールという盾がなければ断れないこと、時間非整合性を確認。
- 候補B（フリードマンのk%ルール）＝(4)で死ぬ。カナダ銀行ブーイー総裁「貨幣供給量が我々を見捨てた」。
- 候補C（素のテイラー・ルール）＝(1)(2)(4)(6)は合格だが(3)$r^*$と$x$が観測不能、(5)ZLBで不合格。
- (5)の修理：マイナス金利で床の下を掘る案を現金への逃避で潰し、4-3 末尾の「経路全体」を思い出して**フォワードガイダンス**へ到達＝**保留その3を回収**。1999年の日銀ゼロ金利が世界初の実戦投入、クルーグマンの「信じてもらえる形で無責任を約束せよ」。約束を縛る仕掛け（目標との紐付け、条件文、長期国債購入の引き返しにくさ）。
- (3)の修理：推計を幅で扱い、式を機械実行しない。「裁量に逆戻りでは」という自問への答えが**インフレ目標政策＝制約された裁量**（目標は固く、手段は柔らかく）。
- 到達点を箱書きし、りんご島で実装。$r^*=3\%$ の昔は平時の名目金利5%、$r^*=0\%$ の今は2%で、ZLBまでの余地が5%ポイントから2%ポイントへ縮む（保留その2 への橋）。

## 第6幕　答え合わせ ── 日本という実験場
- 症例1 ボルカー（テイラー原理は効くが費用が巨大、錨を流される前に対処せよ）。症例2 日本1990年代末〜2012年（2000年と2006年の解除が「どうせ早めに引き締める」を裏書き＝責任感を証明してしまった）。症例3 QQE（第1幕の嘲笑を撤回し、巨額買いオペは蛇口でなく約束の担保だったと診断を書き直す。デフレは止まったが予想の再固定には届かず、$\pi^e$ は下向きにも粘着的）。2016年のマイナス金利・YCC、2024年3月の解除。症例4 2022年以降の世界インフレ（米9.1%、ユーロ圏10.7%。当初「一時的」と読んで実質金利が下がり火に油、遅れて連続利上げで錨を打ち直した＝流され切る前なら安く打ち直せる）。
- **保留その2を回収**：$i=r^*+\pi^{目標}$ が利下げの弾数で、目標0%は床のすぐ上での綱渡り。2%はZLBという断崖からの安全マージン。副次的理由としてCPIの上方バイアスと名目賃金の下方硬直性（のりしろ）。
- 全行程の振り返り。最後にやる夫が 4-2 で予告された「$r^*$ が下がり続けている」を持ち出し、安全マージンの前提が痩せていく問題（目標を上げれば錨の信頼が壊れる、財政との役割分担と独立性の線引きが問い直しになる）を未解決の宿題として置く。

## 依存
- 保留は3本。その1＝第1幕→第2幕、その2＝第1幕→第6幕、その3＝第2幕→第5幕。本文中で保留リストが第1幕末・第3幕末・第6幕末の3回更新されるので、増減するならこの3箇所も直す。
- りんご島の設定（100人／1万個／100円／貨幣50万円／1人5,000円）は第1幕・第2幕・4-1・4-2・4-3・第5幕末で繰り返し使われる。1つ変えると $V=2$、5,000円＝50個、平時金利5%→2% の各計算が連動する。
- 4-2 のヴィクセルの棒（不安定平衡）は 4-5 で「1対1ルールは同じ病気」として明示的に再利用される。この転移が 4-5 の山場なので、4-2 の言い回しを変えるなら 4-5 も直す。
- 4-3 末尾の「将来にわたる実質金利経路の全体」は、第5幕でフォワードガイダンスを導く唯一の梃子。ここを削ると保留その3 が回収できない。
- 4-2 で予告される「$r^*$ は観測できない」は第5幕の条件(3)、「$r^*$ は下がり続けている」は第6幕末の宿題として2回回収される。
- できる子（政府の財政担当）は 4-2 と第5幕の候補Aの2箇所だけに登場し、いずれも「低金利を求める合理的な圧力」を体現して独立性とルールの必要を引き出す役。片方を削るともう片方が浮く。
- 4-4 のボルカー（$\kappa$ が小さいので雇用が肩代わりする）は第6幕の症例1でそのまま診断対象になる。
- 第1幕の「QQEを嘲笑する」場面は第6幕の症例3で「診断を書き直す」ことで回収される額縁構造。
- 4-1 のデフレによる自動引き締めは、第5幕の条件(5)不合格の理由と、第6幕の保留その2 回収（0%目標が綱渡りである理由）で2回使われる。
