# リライト記録

## 工夫した点・主な変更

- 冒頭で、やる夫が翌月の社内LTへ登録済みという期限を置き、第8幕の卒業試験を本番前日の確認へつなげた。長い学習を続ける外的な理由を、既存の筋を壊さない範囲で追加した。
- 省略されていた `FoldMapPar` を、CPU数に応じた分割・並列集計・部分結果の再結合まで読める実装へ置き換えた。幕内の誤った「第2幕」参照も修正した。
- Writerの3法則とログのモノイド則を、左右の単位元則・結合法則ごとに本文で照合した。「宿題」で主題を飛ばさず、壊れる例と成立する例を対称にした。
- モノイド対象への翻訳では、やる夫に `T ⇒ Id` と矢印を逆向きにさせ、`Option[A] → A` は `None` で実装不能だと型から反証させた。その後に `Id ⇒ T` を再発見させ、一発正解だった跳躍を解消した。
- 壊れていた Validation のコード断片を削除し、エラー蓄積 Applicative と、Monadから導かれる打ち切りの適用が整合しない理由を対話で補った。「Validationは一切Monadになれない」という強すぎる説明を避け、蓄積という振る舞いとの非両立に限定した。
- `sequenceA` は完成形を教師が示す前に、2要素の `[Maybe a]` を `(:)`, `<$>`, `<*>` で組み立てさせ、そこから再帰定義へ一般化した。
- 第8幕では van Laarhoven Lens を即答で提示せず、共通の型から `Identity` と `Const` をやる夫に選ばせた。後半にも一つ、既存概念から新しい道具を再発見する節を戻した。

## 残した判断

- 第8幕の名所群は、教材の目標である「識者の言葉を棚分けできる地図」と「国境線」に直接必要なため、大幅削除や節統合はしなかった。代わりに、観光宣言を弱め、レンズ節の学習リズムを変えた。
- lintの warning は、脚注の補足不足、長い発言、節ごとの往復数を人間に確認させる診断であり、今回の変更だけではなく全編にまたがる。内容上不可分な導出や観光節の短さも含むため、一律な分割・水増しは行わなかった。
