# 寸評：やる夫が高層ビルを建てるそうです ── 240mを再発明する

約65KB／第0幕＋8幕＋終幕。240m・60階のビルを建てるという宣言から出発し、組積造→鉄骨→横力→柔構造→チューブ→制振と技術史を追いながら、支配する物理が重力から風・地震へ、強度から剛性・減衰へ主役交代していく過程を再発見する教材。

## 良い点

**3つの宿題が伏線として完全に機能している。** 第0幕で「不快の正体は傾きか」「周期がぶつかると何が起きるか」「なぜ無限に高くならないか」を提示し（55–62行目）、答えるなと明示的に保留させる。①は第6幕の新幹線の思考実験で加速度へ（718–733行目）、②は第4幕の $T=2\pi\sqrt{m/k}$ と共振で（415–428行目）、③は第7幕のレンタブル比と坪単価で（1010–1021行目）回収される。伏線と回収の距離が長く、しかも全部が別の物理を経由してくる設計は見事。

**やる夫が実際に手を動かして計算する。** $q=\frac12\times1.2\times50^2=1500$ Pa（243行目）→受風面積9600㎡→約19,000kN→腕120mで228万kN·m（251–266行目）と、桁の実感が一段ずつ積み上がる。$\delta=wH^4/(8EI)$ から「120mで10cmなら240mで1.6m」（309–312行目）という具体化も良い。数式が飾りでなく驚きの生成装置になっている。

**経験式と実物の答え合わせが2回ある。** $T\approx0.02H=4.8$秒に対しあべのハルカスの実測5.6秒（399–405行目）、森タワー54階の実測32cm対「制振なしなら61cm」（815–822行目）。前者は「桁が合うかで方針の正誤が分かる」（1059–1060行目）という設計者の勘の話につながり、後者は制振の効果を実測値で確定させている。

**第7幕の「候補を殺す」構成が秀逸。** 9条件を列挙し（899–907行目）、候補A〜Dを条件番号を指しながら順に棄却して候補Eへ収束させる（913–962行目）。各幕で学んだことが「知識」でなく「棄却の道具」として再利用されるため、復習になりつつ設計行為そのものになっている。教材の構成として最も強い箇所。

**着地が力学の外にある。** 「高さを決めるのは、最後は力学じゃなく採算だ」（1029行目）と、第8幕の避難計画（1078–1087行目「逃げ出す街でなく逃げ込める街」）。構造教材が普通は書かない領域まで踏み込み、しかもそれが宿題③と接続しているので付け足しに見えない。

**主役交代という一本の軸が全編を貫く。** 冒頭10行目の引用で宣言し、第3幕で強度→剛性（344–348行目）、第6幕で剛性→減衰（794–795行目）、終幕1124–1125行目で「高さは量の拡大じゃない」と締める。骨が太い。

## 欠点

**第5幕以降、やる夫が転ばない。** 第0幕で「12回転ばせる」と宣言している（37行目）が、実際に転ぶのは第1〜4幕に偏る。第5幕では逆にやらない夫が悪案を出し、やる夫が既習の式で完璧に撃ち返す（556–562行目）。第4幕でも霞が関ビルの必要条件3つを先回りで全部当てて「三つとも合格だ」（522–528行目）。教材の後半が「賢くなったやる夫の総ざらい」になり、苦労の手触りが失われる。

**条件2（倒れない）が立てられたまま一度も検証されない。** 900行目で条件に挙げながら、候補A〜Eの棄却（913–962行目）で条件2が判定に使われる場面がゼロ。しかも材料は揃っている。第2幕で出した自重125万kN（183行目）と第3幕の転倒モーメント228万kN·m（265行目）を比べれば、復元モーメントが桁で勝つことがすぐ分かる。この計算がないため、「なぜ超高層は転倒を心配しないのか」という自然な疑問が放置され、同時に第2幕の125万kNが以降まったく使われない死んだ数字になっている。

**登場人物が2人しかおらず、数値がすべてやらない夫の口から出る。** 実測値も相場もすべて教師が与えるため、やる夫は反論できない。第三者の測定役がいれば、やる夫が先に予測を書き→数値が突きつけられる、という緊張が作れた。現状 404行目のあべのハルカスも 822行目の61cmも、教師の宣告として受け取るしかない。

**物語的な圧力が皆無。** 施主も予算も締切も存在しない。第7幕で条件7（工期）と条件8（払える）を掲げる（905–906行目）が、やる夫のビルに予算額も竣工期限も設定されていないので、条件として一度も作用しない。534行目の「約163億円」は霞が関ビルの数字で、やる夫の判断を縛らない。結果として候補Eの選択が「全部満たすから」で終わり、何かを諦める場面がない。

**ビートが単調。** 「やらない夫が問う→やる夫が計算する→『あっ』『あれ』で気づく」の型が全編で反復する（102, 199, 284, 417, 500, 722, 1005行目）。第4幕以降はコメディ要素もほぼ消え、第0幕の勢い（16–18行目「240m、60階建て、これでいくお」）が持続しない。エンタメとして読める、という要件では弱い。

**出典の格が内容に見合っていない。** 参考文献32点のうち大半がWikipedia（1152–1157行目ほか）。二乗三乗則をガリレオに帰す記述（106行目）の根拠が Wikipedia、カーンの体系化（630行目）も Wikipedia とブログ記事（[^20]）。坪単価「1.5倍から2倍」（677行目）には出典が付いていない。第8幕の対照表（1050行目）も森タワーの固有周期欄が「超高層らしい長周期」という定性語で、答え合わせの表の中で唯一数字がない。

## 改善案

1. **第3幕265行目の直後に、転倒の答え合わせを10行入れる。** やらない夫が「じゃあ倒れるのか。第2幕でお前が出した重さで踏ん張れ」と振り、やる夫に自重125万kN×腕20mの復元モーメントを計算させ、228万kN·mと比べさせる。桁で勝つと分かった上で「では敵は何だ」→たわみと加速度、へ移る。条件2（900行目）が回収され、125万kNが生き返り、以降の「横力が主役」の意味が精密になる。

2. **第0幕に施主・予算・竣工期限を置く。** 社長のおじさんが自社ビルを建てることを聞いたやる夫が、簡単だお、やるおがやってやるお！と暴走し、友人のやらない夫に相談する流れ。 18行目の宣言の直後に、投資家への提案という枠と、具体的な予算額・竣工年を入れる。第7幕（975–1021行目）で条件7・8が実際の数字で判定でき、宿題③の「もう1階足すと儲けより費用が上回る」が抽象論から、やる夫のビル固有の階数計算になる。

3. **測定役できる子を1人追加する。** 風洞実験と時刻歴応答解析の結果だけを読み上げる第三者を置き、404行目のあべのハルカス5.6秒、815–822行目の32cm/61cm、603–610行目の鋼材量206→145kg/m²をその役へ移す。やる夫が先に予測値を紙に書く手順を挟めば、外した回・当たった回の差が体験になる。

4. **第5幕でやる夫を一度大きく転ばせる。** 556行目の「私が悪い案を出す」を削り、代わりにやる夫にチューブ案の副作用を見落とさせる。例えば「外周に柱を密に並べる＝窓が細くなる／アウトリガー階は貸せる床が消える」に気づかず設計し、条件9（レンタブル比）で跳ね返される往復を入れる。第7幕の条件9が第5幕から効き始め、後半の平板さも解消する。

5. **出典を格上げする。** 二乗三乗則（[^1]）をガリレオ『新科学対話』へ、カーンの構造システム分類（[^6][^20]）を Khan 本人の論文または CTBUH の資料へ、坪単価1.5〜2倍（677行目）を建設物価または国交省の統計へ差し替える。国交省・日本建築センター系（[^14]〜[^17]）は既に良質なので、その水準に他を揃える。

6. **第8幕の対照表を数値で埋める（1050行目）。** 森タワーの固有周期は公表値を当たり、得られなければ「非公表（同規模から推定4〜6秒）」と明記する。表の1行だけ定性語だと、他の行の一致まで印象論に見えてしまう。

7. **各幕に笑いを1つ置く。** 第0幕のノリ（16–18行目、43行目「めんどくさいお」）が第4幕以降途切れる。特に第7幕の候補殺し（913–934行目）は棄却理由が正論で連続するので、やる夫が愛着を持った案を自分で殺す未練を1〜2行入れるだけでリズムが戻る。
