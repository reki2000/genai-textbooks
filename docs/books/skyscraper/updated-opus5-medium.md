# 改稿記録

`review-opus-medium.md` の7つの改善案すべてに対応した。3つの宿題と伏線回収、第7幕の「候補を殺す」構成、主役交代という縦軸は一切変更していない。指摘の中心は「後半でやる夫が転ばない」「条件2が死んでいる」「圧力がない」「数値の出所が教師だけ」の4点だったので、そこを補った。

## 主な変更

- **条件2（倒れない）を第3幕で決着させ、125万kNを生き返らせた。** 転倒モーメント228万kN·mを出した直後、やる夫に「倒れるお」と怯えさせ、やらない夫が「踏ん張る側の数字を第2幕で自分で出している」と振る。自重125万kN×腕20m＝**2,500万kN·m**を計算させ、安全率約11倍を確認して「超高層は転倒では壊れない」と畳んだ。そのうえで「倒れないことと使えることは別だ。これから先の敵は変形と揺れだ」と、以降5幕分の敵の定義を先に立てた。第7幕の条件一覧にも「条件2は第3幕で決着済み、どの候補でも自重は変わらないので判定に使わない」と明記し、立てっぱなしの条件をなくした。
- **第0幕に施主・予算・期限を置き、第7幕で実際に効かせた。** 伯父である社長が「予算1,200億円、竣工6年後」を告げて帰る枠を作り、やる夫が延床96,000㎡で割って125万円/㎡を出すところまでを第0幕でやらせた。やらない夫の「その1,200億円と6年が、これから毎回お前の案を殺しに来る」が全編の圧力線になる。第7幕では条件7を「6年」、条件8を「1,200億円」と実数に置き換え、宿題③の回答をやる夫のビル固有の階数計算に変えた——レンタブル比70%なら実効179万円/㎡（坪約590万円）、60階を65階にすると延床は8,000㎡増えるがレンタブル比が67%に落ちて**貸せる床は2,480㎡しか増えない**（増分の7割が消える）。費用は素直に増え収入は7割減で増えるから必ず逆転する、という形にした。「240m・60階は力学が決めた数字ではなく、1,200億円と6年とこの土地の賃料が決めた数字だ」で締めている。
- **測定役できる子を追加し、予測→答え合わせの手順を3回入れた。**
  - あべのハルカス：やる夫に先に「$0.02\times300=6.0$秒」と書かせてから、できる子が5.6秒を出す。**当たった**回。できる子の「当てたのは式であって、あなたではない」で締めた。
  - 鋼材量：やる夫に「高いほうが増えるはずだから200kg/m²くらい」と予想させてから145kg/m²を出す。**外した**回で、「高くすれば材料は増える」という前提自体を疑わせた。
  - 森タワー：やる夫に「548基も入れたなら制振なしは1〜1.5m」と予想させてから61cmを出す。**大きく外した**回で、そこから「減衰は最大変位を劇的に下げる道具ではない、効くのは揺れが続くかどうか」という減衰の本質へ接続した。
  - 当たり1回・外れ2回にすることで、答え合わせが儀式ではなく体験になる。
- **第5幕でやる夫を大きく転ばせた。** やらない夫が悪案を出す構成（「私が悪い案を出す」）を削除し、やる夫自身に「外周の柱を1mおきに極太で並べる」という案を出させた。方向はカーンと同じで一度褒められるが、立面図を描かせると**窓が幅30cmのスリットになる**——条件9で跳ね返される。さらに「外周を固めた分、中の柱を細くする」と言ったことを突かれ、横力ばかり見て第2幕の鉛直荷重125万kNを忘れていたことに気づく。「主役交代は脇役の解雇じゃない」という一線を置いた。カーンの実際の解（柱間隔3m前後＋スパンドレル梁を深くする）を「性能を最大にする案ではなく、売れる床が残る範囲で最大にする案」として提示し、条件9が第5幕から効き始める形にした。
- **出典を格上げした。** 二乗三乗則をガリレオ『新科学対話』(1638) へ、カーンの体系化を Khan 1969 と CTBUH *Fazlur Khan Legacy* / Ali & Moon 2007 へ、層間変形角を建築基準法施行令第82条の2へ、武藤清を本人の著書2点へ差し替えた。坪単価1.5〜2倍には建設物価調査会・国交省建築着工統計を出典として付けた（[^33]）。さらに、出典表記だけだった26件すべてに、本文のどの主張を裏づけるかと要点の数値・年号を一文ずつ添えた。これで参考文献欄が国交省・日本建築センター系（既に良質だった [^14]〜[^17]）の水準に揃った。
- **第8幕の対照表を修正した。** 森タワーの固有周期欄が唯一の定性語だったので、「公表値なし。$0.02H$ と同規模実測から推定4〜6秒」と明記した。そのうえでできる子に「表の3行目は実測ではなく推定。他の行と同じ重みで読んではいけない」と言わせ、やる夫に「合ってるところと、合ってることにしたところを混ぜないお」と受けさせた。答え合わせの表が印象論に見えないようにした。
- **第4幕以降に笑いを戻した。** できる子の突き放し（「当てたのは式であって、あなたではない」／やる夫「言い方があるお」）、第5幕の「オフィスじゃなくて刑務所だお」「やる夫の『完璧だお』、2か所で死んだお」、第7幕で自分の案を殺す未練（「やる夫が自分で思いついた案なんだお。それを、やる夫が自分で殺すのかお」→やらない夫「殺すんじゃない、足りないものを足すんだ」）を入れた。終幕には社長を再登場させ、「条件が9つあったお」「……お前、誰だ」で第0幕の暴走との落差を落ちにした。

## 残した判断

- 第7幕の候補A〜Eの棄却は、条件番号を指しながら潰す構成そのものが教材の骨なので、順序も判定理由も変えていない。追加したのは条件2の扱いの明確化と、候補Dへの未練だけ。
- 残る Wikipedia 出典（建物の高さ・竣工年・所在といった事実確認）は、レビューが名指しした4件をすべて一次資料・法令・専門書へ差し替えたうえで、注釈を付けて残した。個別建物の諸元については、参照の性格上これで実害がない。
- lint は error 0件、warning 2件。終幕の長い振り返り発言と承認語の頻度に関する診断で、いずれも改稿前から存在する。内容を確認したうえで残した。
