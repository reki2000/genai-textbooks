# 寸評：やる夫で学ぶ世界史は誰のものか ── 文化祭で世界の中心を動かす

約92KB／全10幕。「人類5000年を30分で理解する」完全版展示を作ろうとした高校生が、公平な物差し・時代区分・地域別構成を次々に破綻させ、8つの問いを壁に貼る展示へ到達する。

## 良い点

**主題と形式が完全に一致している。** 扱うのは「誰の視点で歴史を語るか」だが、それを抽象論ではなく、教室1つ・30分・パネル1行という物理的制約の問題として提示する。176行目「何かを中心にしないと説明にならないお！」に対する180–184行目「その通りだ。問題は、中心を持つこと自体ではない。中心を持っていないふりをすることだ」で、教材全体の立場が最初期に定まる。編集という作業が、歴史記述の比喩ではなく実物として置かれている。

**第2幕の物差し連続棄却が、5-2で回収される。** 253–274行目、人口比→面積比→GDP比が3往復で潰れ、「数字を使えば客観的になると思ったのに、物差しを選ぶところで価値判断が入ってるお」に至る。そして5-2（888–914行目）、できる子が史料の種類が書かれたカードを表だけ見て分類させ、裏返すと使いにくい側がサハラ以南アフリカと太平洋に揃う。「やる夫は地域で選んでないお。展示に使いやすい史料の種類で選んだだけだお。……でも並べ替えた結果は、最初の案でアフリカが消えたときと同じ並びだお」。第2幕の教訓が、自分では公平だと思った操作の中に再出現する。

**視点の問題を文法操作として扱う。** 3-1（434–451行目）、「朝鮮半島の国家が冊封を受け」と書き直して「主語は変わったのに、受けるって動詞が残ってるお」→「なら動詞から変えろ」。4-1（605–620行目）、できる夫の試作を画面を見ずに音だけ聞かせ、「伝わる。広がる。進出する」「4場面あるのに、東南アジアの人が主語になってる文が1つもないお」。抽象的な「視点」が、主語と動詞という操作可能な対象になる。

**4-2の見出し1行。** 742–767行目、「セポイの反乱」「インド大反乱」「第一次独立戦争」を3回書いて3回消し、「中立な名前を探してたけど、そんな欄は最初から無かったお」。770–772行目でやらない夫が「1行しかないのは展示だけじゃない。教科書の索引も、年表も、試験問題も1行だ」と広げる。

**7-1で演出案を本人が撤回する。** 1174–1192行目、できる夫の「足元に進路が現れる」案に対し、やる夫を実際に歩かせて20mで外させる。「それを足元の矢印1本にしたら、太平洋の航海が、地図を持ってなかった人の当てずっぽうに見えてしまうお。矢印は自分で消すお」。教師に止められるのではなく、実演の結果として自分で撤回する数少ない場面。

**9-2で相対主義への転落を通過して抜ける。** 1568–1626行目。やる夫が航海日誌の語数で動機を断定→できる子が原本不在を指摘→「歴史は全部だれかの言い分だお」と全面降伏→やらない夫の「10分で断定と全面降伏を両方やった」「言える範囲が狭いことと、何も言えないことは違う」。多視点の強調が「何でもあり」へ落ちる危険を、教材が自分で踏んでから登り直す。1623–1626行目の「解釈の強さは、証拠がどこまで支えるかで決まる」が、標語ではなく失敗の結論として出る。

**10-2の自己適用が構成の要。** 1813–1847行目、8つの問いを自分の展示に当て、4つ目で朝鮮半島パネルの連続線が3-1で最初に潰した読み方の再発だと気づく。1850–1851行目「自分で見つけられたなら、道具は効いている。効かない道具は、他人の展示にしか当たらない」。さらに1886–1918行目で、やらない夫が教科書初版の編集者だったと判明し、「教科書を作った人間の権威を使ってどうする」（1918行目）で、素性を隠していたこと自体が主題と整合する。

**参考文献16点が各国の教育課程一次資料。** 日本・韓国・シンガポール・インド・南アフリカ・ガーナ・米国AP・カナダBC州・豪州・NZ・ブラジル・チリ・トルコ、加えてUNESCO、Osterhammel、Conrad。全点URL付き。しかも[^7]に「APは米国全体の統一教育課程ではない」という留保が添えられている。リポジトリ内で最も網羅的な文献リスト。

## 欠点

**できる夫の演出案が19回近く同型で反復する。** 48・195・288・370・478・547・642・779・971・1048・1118・1162・1274・1498・1506・1692・1782・1858・1882行目。「派手な案→制止→縮小して採用」がほぼ全節に置かれるため、後半は登場した時点で結果が読める。1168行目の「やってみろ」（制止しない例外）や、1118–1121行目の1492年の演出（そのまま採用される良案）が、反復の中に埋もれる。

**地域巡りの構造が5回同型。** 第3〜7幕がいずれも「地域名を挙げる→やる夫が日本の教科書的な要約を述べる→カメラを移す→中国・日本・ヨーロッパの役柄が反転する」で進む。各幕内の発見（主語と動詞、海の地図、史料カード、歩く向きの反転、航海の実演）は質が高いが、幕をまたぐ設計は反復になっている。

**できる子の発言が資料の朗読に寄る箇所が多い。** 662–664・868–871・954–956・1029–1032・1096–1098・1262–1264行目など、各国教育課程の紹介が続く。5-2のカード実験（888–911行目）で見せた「実験を設計する人物」としての側面が、他の幕ではほとんど発揮されない。

**第8幕が薄い。** 1290–1426行目。1492年と1945年の同時代比較を扱う幕だが、いずれも「画面を並べる」という発想の提示で終わる。1375行目で12地域の状況が列挙され、1384–1386行目でやる夫が3つの比較軸（戦争の終わりと始まり、帝国の崩壊と独立、戦勝国内部の差）を挙げるが、その軸で12項目を実際に分類する作業がない。比較の結論は1396–1397行目の2行だけ。

**「ヒントだけ」の自己申告と実態のずれが5回ネタにされる。** 214・391・689–692・1657・1922行目。1922行目のできる子の「ヒントだけという自己評価は事実と一致しない」が本来の落としどころだが、そこまでに4回同じ指摘が済んでいるため、一撃にならない。

**数が使われない。** 40行目の「1世紀あたり18秒」以降、第2幕の物差し議論を除いて数で詰める場面がない。1779行目の来場者436人・アンケート281枚も、そこから何も導かれず、1788行目と1791行目で回答の傾向が語られるだけ。

## 改善案

1. **第8幕で比較軸を実際に使う。** 1386行目でやる夫が挙げた3軸を表の列にし、1375行目の12地域を行にして、やる夫に埋めさせる。日本は「戦争が終わった／帝国が崩れた」、インドネシアとベトナムは「別の戦争が始まった／独立を求めた」、米国は「戦争が終わった／内部に矛盾」——と分類が割れることを、表の空白と重複として見せる。1396行目の「日本人の戦後は、他地域の戦争中と重なる」が、一文の主張から表の観察になる。

2. **できる夫の登場を半減し、制止しない回を明示する。** 現状ほぼ全節にある演出案のうち、質の高い3つ（979–981行目の奴隷貿易、1118–1121行目の1492年、1274–1276行目の半透明の幕）と1168行目の太平洋を残し、他は削る。残した回では「今回は誰も止めなかった」と地の文で示せば、1703–1704行目の「これ以上の譲歩は演出担当の尊厳に関わります」が、単なるギャグでなく蓄積の結果になる。

3. **できる子に実験をもう1つ設計させる。** 5-2のカード実験と同種のものを第4幕か第6幕に置く。例えば、地域名を伏せた年表の断片を並べ替えさせ、やる夫が無意識に「ヨーロッパの事件を基準に前後を判断していた」ことを露見させる。資料紹介役に偏った造形が、仕掛ける側として立ち直る。

4. **地域巡りの1つを主題別の節に置き換える。** 第5幕と第6幕の間に、大西洋奴隷貿易を「どの地域の部屋にも置けない現象」として1節扱う。2-1の201–207行目で、できる夫が「4回上映します！」と言って潰される場面が既にあるため、そこの回収になる。地域別構成の限界が、教材の構成そのもので示される。

5. **10-2に数を入れる。** 1779行目のアンケート281枚に自由記述の内訳を添える。「学校で習った世界史にも入口があったとは考えなかった」が何件、「情報が多すぎる」「結論を教えてほしい」が何件。1749–1750行目の「世界中の誰も不満を持たない展示ではない。でも、不満がどこから生まれるかを考えられる展示にはなった」が、印象ではなく数で裏づけられる。

6. **「ヒントだけ」への言及を2回に絞る。** 214行目と1922行目を残し、391・689–692・1657行目を削る。最後にできる子が事実との不一致を指摘する一撃が効く。
