# やる夫で学ぶ世界史は誰のものか ── 文化祭で世界の中心を動かす の骨格

## 第1幕　完全な世界史を30分で
- 1-1　ファミレスの文化祭会議 … やる夫が「人類5000年を30分で理解する」展示を構想するが、欧州中心の太い幹と、他地域を外部勢力との接触時だけ登場させる欠落をやらない夫に突かれる。「その世界史は誰の目か」が全編の問いになる。
- 1-2　教科書には全部書いてある … 教科書の短縮によって欧州近代へ至る一本道が生まれたと気づく。歴史は選択と編集であり、中心を持つことより中心を隠すことが問題だと学ぶが、地域別の均等配分も相互関係を切ると示される。

## 第2幕　公平な展示が壊れる
- 2-1　全地域3分の平等 … 国・人口・面積・GDPなどの機械的配分を順に試して失敗し、物差しを選ぶ時点で価値判断が入ると再発見する。公平を、地域の連続性・相互作用・過去への国境投影・被支配者や移動者の扱いから考え直す。
- 2-2　古代・中世・近代は世界共通か … 欧州由来の時代区分を全地域へ当てる歪みと、地域固有の区分では同時代比較が難しくなる矛盾に直面する。時代の切れ目は後世の編集線だと理解し、線を引く根拠そのものを展示する方針へ進む。

## 第3幕　朝鮮半島から東アジアを見る
- 3-1　中国の周辺か、半島の王国か … 現代の国境や民族を古代国家へ投影する問題を検討し、半島国家を主語にして動詞まで書き換えることで、中国・日本の役柄が反転する。冊封を現代の属国／独立国の二択に押し込めない視点を得る。
- 3-2　解放の日と分断の始まり … 1945年を日本の終戦だけでなく、朝鮮の解放・占領・分断・戦争へ続く過程として見る。同じ地域にも南北・国家・民族・民主化・女性・労働など複数の歴史観があり、国旗一つで代表させられないと学ぶ。

## 第4幕　海から見る東南アジアとインド
- 4-1　ヨーロッパ人が来る前の港 … 「伝わる・広がる・進出する」という外部主体の語りを発見し、現地の選択・再構成・交易を動詞へ戻す。陸と国境ではなく海路を中心にすると、欧州の航海は既存の交易秩序への暴力的な参入として見え直す。
- 4-2　一つのインド、いくつものインド … 現在のインド共和国と南アジアの長い連続性、多言語・多宗教・多地域性の緊張を扱う。1857年の事件名を三度書き直して、短い名称自体が主語と目的を選ぶ解釈だと悟り、1947年の独立と分離・移動・暴力を同じ画面へ置く。

## 第5幕　中東とアフリカを脇役から戻す
- 5-1　中東は誰から見た東か … 「中東」「イスラム世界」「アラブ世界」など範囲の異なる名称を検討し、十字軍・オスマン帝国が欧州、トルコ、アラブ、イランなどの入口で別の位置を占めると示す。石油と紛争だけを地域史の結論にしない。
- 5-2　文字がないと歴史がないのか … 文字史料を優先する分類がアフリカと太平洋を再び消す実験に失敗する。口承・考古・言語・芸術・建築などを文字史料と同様に批判的に照合し、アフリカ内部の地域差も一つの箱へ潰さない方針を得る。
- 5-3　どの地域の部屋にも入らない歴史 … 大西洋奴隷貿易を四地域のどれか一箱へ入れる課題が破綻する。捕獲・船舶と金融・強制労働・消費・抵抗・文化形成の関係を、地域別展示を横断する一本の線として設計する。

## 第6幕　アメリカ大陸の発見を裏返す
- 6-1　北米の自由と奪われた土地 … 独立・憲法・西部開拓という成功物語を、奴隷制、先住民の土地侵奪、排除された人々による理念の拡張と結び直す。同じ通路を逆向きに歩くと領土拡張と土地喪失が反転する展示を作る。
- 6-2　独立したのは誰か … 中南米の政治的独立後にも残った身分・土地・人種・労働の構造を検討し、ハイチ革命や各国・先住民の異なる経験を戻す。1492年以前から動く社会へ欧州船が侵入する映像に変え、「発見」から始まる歴史を裏返す。

## 第7幕　太平洋は空白ではない
- 7-1　島ではなく海を渡る世界 … 海を空白、島を孤立点と見る陸地中心史観を改め、航海知と島々の関係を主軸にする。単純な航路矢印では身体化された知識を矮小化すると体験し、植民地化・戦争・核実験・独立後までをつなぐ。
- 7-2　建国と侵入を同じ文章に書けるか … 豪州・ニュージーランドの建国史を、先住民側からの侵入・植民地化・抵抗・権利回復と同じ過程として記す。国家の民主制度や移民史を否定せず、それらが誰の土地と排除を前提にしたか関係づける。

## 第8幕　同じ年に別の世界が動く
- 8-1　1492年を誰の始まりにするか … 有名事件がない地域を静止背景にする年表の偏りを認め、1492年を前後100年の窓へ広げる。複数社会がすでに動く中で結合が強まり、暴力と混合が同時に進む様子を、史料と再構成を区別した複数音声で示す。
- 8-2　1945年は戦後の始まりか … 12地域を「戦争の終始」「帝国崩壊・独立」「戦勝側内部の差」で比較し、空欄や重なりも結果として残す。日本を入口にしつつ、他地域を日本史の結果へ縮めない双方向の矢印を設計する。

## 第9幕　冷戦の脇役は誰だったか
- 9-1　代理戦争という便利な言葉 … 世界を米ソ二色に塗る試みが非同盟や各国の離反・国内対立で破綻する。アフリカ、中南米、中東、南・東南・東アジアで2〜3か国ずつ比較し、脱植民地化や国家建設という共通項と、同盟・離反・革命・内戦という経路差を重ねて捉える。
- 9-2　自国中心史観は捨てるべきか … 国名を消した完全中立案を退け、自国を「入口」にすることと世界の「目的地」にすることを区別する。公開英訳の10月13日・16日項を読んでコロンブスの動機を断定するが、伝承形態と反証から撤回し、複数視点は史料への耐性で評価できると再発見する。

## 第10幕　世界の中心が動く教室
- 10-1　一本道をやめる … 展示を「世界史は誰のものか――同じ過去、違う入口」へ改題し、日本から地域・同時代・複数の主語へカメラを動かす体験型構成にする。主語、公平の物差し、転換点、国境投影、現地の選択、史料、消えた人、証拠を問う8項目が完成する。
- 10-2　教科書の余白 … 文化祭の反響後、避難経路とポルトガル語の誤記を確認して展示を三周したやらない夫に促され、完成展示にも現代の枠を過去へ伸ばす偏りが再発したと発見する。やらない夫が旧版教科書の編集協力者だったと判明し、権威でなく自力で問いを得させた意図が明かされる。

## 依存
- 1-1 の「誰の目か」が全編の中心問題で、10-1 の展示名とカメラ移動、10-2 の自己点検へ回収される。
- 1-2 の地域別均等案は2-1で数値的な公平の失敗として掘り下げられ、5-3の地域横断展示と10-1の同時代窓へつながる。
- 2-1 の「物差しを選ぶ時点の価値判断」は5-2の史料分類で再演され、10-1の第2の問いとして明示される。
- 2-2 の時代区分と同時性の矛盾は8-1・8-2の同時代比較で実装される。
- 3-1 の現在の国境・民族を過去へ投影する失敗は4-1、4-2、6-2でも反復され、10-2の完成展示で再発して自己点検の決定打になる。
- 3-2 の1945年の複数見出しは8-2で12地域比較へ拡張され、10-1の分割映像へ実装される。
- 4-1 の「主語だけでなく動詞を変える」発見は6-2の征服・抵抗・生存の書き直しと、10-1の第1・第5の問いの前提になる。
- 5-2 の史料批判は8-1の音声展示における史料と再構成の区別、9-2の解釈を証拠で評価する議論へ発展する。
- 5-3 の地域を横切る関係史は8幕の同時代窓、9-1の現地要因と超大国介入を重ねる設計の模型になる。
- 6-1・7-2の「進歩／建国」と「喪失／侵入」を同時に書く設計が10-1の体験型展示へ組み込まれる。
- 8-1の史料と再構成の区別は9-2のコロンブス航海日誌の失敗を準備し、証拠を問う第8項目として10-1で回収される。
- 9-2で得た「自国は入口であって目的地ではない」という整理が、10-1の最終設計と10-2の継続改訂を支える。
