# 改稿記録

`review-opus-medium.md` の指摘と皆瀬案をもとに、本文を次の方針で改稿した。

- CMC測定に表面張力の傾きと追加量の物質収支、ビルダー設計に硬度20 mmolと交換容量からの必要量、酵素併用に到達面積モデルを加えた。数値は教材内の仮想データであることも明記した。
- 製品形態の比較では、やる夫に「粉末は低温投入も合格」と先に予想させ、実測で外す流れへ変更した。顔面砂漠事件では、油を足す失敗の後に「濃度を下げた結果、二度洗いと摩擦が増える」二度目の失敗を置き、皮膚バリアの評価軸へ段階的に到達させた。
- 長い自己完結発言へやらない夫の反問を追加し、王者選び、製品形態、人体用洗浄の推論を複数往復へ分割した。
- 第2幕のルブラン法・ソルベー法は圧縮し、ソルベー法の副生物である塩化カルシウムを硬水問題へ接続した。
- 第3幕から購買担当と「二本以内」「印刷済みラベル二百枚」という圧力を常駐させた。最終審査では六本化による容器・在庫・棚面積の負担も明示し、安全上の失格条件との比較から六本を選ぶ形にした。
- 欠落していたカチオン説明の話者ラベルを補い、比喩的な箱入り数式は文章へ戻した。
- 界面活性剤、自己集合、洗剤処方に関する参考文献を追加し、仮想データと一般的事実の境界を注記した。

残した判断として、冒頭の六枚のクレーム票と終幕での回収、幕ごとに「増やせば比例する」を異なる機構で崩す構成、安全上の混合禁忌、六本を設計体系として再定義する結論は、レビューでも強みと評価されていたため維持した。反復する過去参照は一部残したが、重要概念の回収として働く箇所に限る方向で、追加場面では具体的な実験・反問を優先した。
