# やる夫が給料日の五つの時計を同期させるようです ── 十二本のタイムラインと午前零時 の新アウトライン

## 再設計の方針

旧版の一人の年間明細と、一件ずつ順番に処理する演出を捨てる。給与システム更新で、共同制作チーム12人のデータが映像編集ソフト風の十二本のタイムラインT01〜T12へ誤変換された支払前夜に置き換える。映像編集者やる夫とライブ音響技師やらない夫は、雇用や社歴の上下関係を持たない二人の照合代表であり、自分たちも支給を受ける当事者である。労働発生、申請・承認、締め、支払、制度適用という五本の再生ヘッドを別々に動かし、音が鳴らない区間、二重に見える区間、位相が打ち消し合う誤差をライブで探す。全部を緑にすることではなく、十一件を根拠どおり進め、一件を根拠不足のまま止めることを勝利条件にする。

## 第1幕　前月プロジェクトは今月を払わない

- やる夫が前月の編集プロジェクトを複製し、昇給、遡及、住民税開始、扶養変更の四イベントを古い位置へ貼り付ける。
- マスターの振込総額は近いのに、T01〜T04の手取りが逆方向へずれ、やらない夫のモニター音が四箇所で途切れる。
- 総支給、課税対象、保険対象、控除、差引支給を一本の波形へ合成する案を、同じ振幅で内訳の違う反例で壊す。
- T01の4〜6月を拡大し、当月給与、前月限定の遡及、前年所得由来の住民税を別レーンへ置く。
- 十二本へ支給ID、対象期間、支払日、根拠資料、状態を表示し、午前0時の再生カウントを始める。

## 第2幕　五本の再生ヘッドは同じ六月を指さない

- 6月12日の残業を6月給与へドラッグし、承認、締め、支払の各ヘッドが違う位置で止まる。
- 労働発生日、確定日、締切日、支払月、制度適用月を五本の再生ヘッドとして分ける。
- 概算で先に音を置き後で波形を合わせる案を、過不足、本人説明、監査履歴、再計算の四つのずれで壊す。
- 時間外、休日、深夜が重なる仮想勤怠を区間へ切り、各割増の対象時間を途中式つきで計算する。
- 締切後イベントを削除せず翌月タイムラインへ移し、本人からも見える説明マーカーを置く。
- T02を同期し、時計のずれを遅延や不正と即断しない。

## 第3幕　同じ基本給へ同じエフェクトを掛けない

- 昇給後基本給へ一つの率を一括適用し、社会保険の標準報酬月額・改定時期と同期しない。
- 税、社会保険、雇用保険、住民税を、算定基礎、決定主体、適用時点、丸めの四属性で別レーンにする。
- 固定給変更と随時改定、定時決定を、現金の変化と保険料の変化が遅れて聞こえる例で追う。
- 住民税を会社が再計算する案を、自治体通知という外部音源と徴収経路で止める。
- 会社損失を給与控除へ混ぜる案を、全額払い、法令・協定・本人同意、別債権の区別で壊す。
- T03〜T05を同期し、計算式だけでなく「誰の決定をいつ再生しているか」を言語化する。

## 第4幕　賞与は月給の音量を上げたものではない

- 賞与へ月給と同じ税率・保険の端数処理をコピーし、税と保険で別の位置へずれる。
- 標準賞与額、社会保険対象、税の前月給与参照、現物評価を独立レーンで計算する。
- 同じ500,500円を税、保険、振込から逆向きにたどり、どの段で丸めたかを検算する。
- 源泉徴収を最終税額と思い、年末調整を「前年の編集ミス修正」と決めつける。
- 年間所得・控除が支払時点では未確定なため、仮徴収と後の精算が必要だと再発見する。
- T06の表示を「確定税」でなく「今回徴収」へ直す。

## 第5幕　無音の月にもイベントはある

- 休職、育休、欠勤、有休、傷病、現物・手当を「給与波形なし＝処理なし」で消す。
- 支給の有無と、資格、保険料、給付申請、住民税、会社立替、復職予定を別イベントにする。
- 月途中入退社の日割、欠勤控除の規程、最低保障を、同じ日数比のフェードで済ませない。
- 最終給与、未払残業、退職手当を一本へ合成し、課税経路と必要書類の違いで分離する。
- 退職日と資格喪失日の一日のずれを、保険料と空白月の具体例で検算する。
- T07〜T09のうち資料不足の一本だけ再生を止め、無音と未処理を区別する。

## 第6幕　一人に二社と二つの国の時刻が重なる

- 兼業者の主従区分を社会保険へそのまま複製し、税と保険の制度を混ぜる。
- 複数事業所の給与、標準報酬、按分、通知を、他社給与を自社明細へ漏らさず同期する。
- 海外勤務を183日のマーカー一個で判定し、居住者、勤務地、国内勤務日、給与負担、租税条約を落とす。
- 日本口座への入金と国内源泉を同一視する案を壊し、シャドーペイロールと支給IDを導く。
- 為替レートを結果が良くなるフレームで選ばず、目的と基準日を先に固定する。
- T10・T11は専門家への引渡し条件を揃え、推測で無音区間を埋めない。

## 第7幕　マスター音量が同じでも誤差は消えない

- 振込総額が前月と一致して合格とし、過大支給と過小支給が逆位相で打ち消し合っている。
- 行レベル、本人レベル、会社合計、納付先合計、前年・前月差分を別の検算波形へする。
- 同じ差引支給額246,830円になる三候補を、金額でなく根拠資料、算定経路、決定主体から二つ落とす。
- 一人で編集・承認・最終出力する案を、職務分離、変更履歴、再実行、アクセス権で壊す。
- 確定、差戻し、停止、引渡しの四状態と、再生を再開する解除条件を作る。
- T12だけが外部回答待ちで赤い停止線を残す。

## 第8幕　午前0時に一本の再生を止める

- 銀行締切直前、T12の無音区間を前年率で埋めれば全トラックが緑になる誘惑が来る。
- T12の不足資料、最悪の過不足、訂正可能性、本人生活への影響、法定期限をタイムライン上へ並べる。
- 十一件は期限どおり出力し、T12は本人への説明、暫定対応、専門家への引渡しを付けて止める。
- 止めたことを編集者の失敗でなく、二人の照合が働いた証拠として変更履歴へ残す。
- 翌朝の回答で国内外勤務日を配分し、同じT12へ停止解除と根拠を追記する。

## 終幕　十二本目の同期音

- T12本人へ遅れと根拠を説明し、やる夫は「正確に払った」でなく、何が確定し何を誰へ渡したかを述べる。
- T01の翌年6月を再生し、前月プロジェクトの複製ではなく五本のヘッドを一つずつ確認する。
- 午前0時に鳴らなかった同期音が翌朝に鳴り、停止線は消去せず次年度の検算開始点として残す。
- 新しい勤怠イベントが届くと、やる夫が確定ボタンより対象期間を拡大し、やらない夫が自分のトラックも例外扱いするなと返して閉じる。

## 依存と検算

- T01〜T12、五本の再生ヘッド、支給ID、赤い停止線、午前0時を固定する。
- T01の遡及と住民税は第1幕の同期外れ、第3幕の決定主体、終幕の翌年6月へ戻る。
- 「無音を埋める」は第1・2・5・6幕で反復し、第8幕で埋めずに止める選択へ反転する。
- 逆位相の誤差は第1幕で音の違和感、第7幕で総額一致の罠、第8幕で個別停止の根拠へ回収する。
- 四状態は第7幕で命名するが、第2・5・6幕で必要性を先に経験させる。
- 終幕は実務が完全になったとせず、基準年・制度改正・個別事実の確認を開いたまま閉じる。
