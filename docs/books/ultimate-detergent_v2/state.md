## 到達点・現在位置

- 第1幕：泡と洗浄力を分離し、事件票・失格条件・七枚を固定する。
- 第2幕：乳化、界面、CMC、水質、界面活性剤の電荷を再発見する。
- 第3幕：ビルダー、分散・再付着防止、洗浄四要素、剤形を工程として組む。
- 第4幕：酵素の選択性と窓、漂白と洗浄、遅延評価を分ける。
- 第5幕：皮膚バリア、保湿、頭皮と毛髪、ラベルを追加質問へ変える。
- 第6幕：保存不良を原因別に診断し、使用操作と簡易LCAを設計に入れる。

- 第8幕：処方を知らない三人の引継ぎ試験で、騒音・手袋・設備低下の下でも選択、停止、再開、翌日評価を渡せる運用へ直す。

## 定義済み用語・記号

- 界面：乳化、両親媒性、界面自由エネルギー、界面活性剤、ミセル、CMC。
- 条件：硬水、カルシウム石鹸、曇点、アニオン／カチオン／ノニオン／両性界面活性剤。
- 複合処方：ビルダー、金属封鎖、分散剤、再付着防止剤、洗浄四要素、剤形。
- 選択反応：プロテアーゼ、リパーゼ、アミラーゼ、マンナナーゼ、失活、漂白、発色団。
- 人体：角層、湿潤剤、閉塞剤、エモリエント、TEWL、キューティクル。
- 保存・運用：保存安定性、容器適合性、加速保存試験、塩曲線、ライフサイクル思考、品質保証。
- D-01〜D-07、試作ラインX、事件票、大時計、七枚カルテを全編で反復済み。
