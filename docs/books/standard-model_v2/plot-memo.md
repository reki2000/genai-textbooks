# `standard-model_v2` ブロックメモ

## 制約と到達点

- 8幕＋終幕、約10万〜12万字。粒子名鑑ではなく、一つの衝突事象を複数の理論層で説明する推理劇にする。
- 数式は対称性、保存則、横質量、群の生成子、ヒッグス機構、期待事象数の判断に使い、飾りにしない。
- 旧版は事実と式の参照に限り、幕順、事件、比喩、台詞、発見順は新しくする。

## 人物設定

- やる夫：科学館の生解説員。E-17は未知粒子だと賭け、観客を驚かせる演出と粒子カードの暗記で先走る。
- やらない夫：巡回中の検出器保守技師。E-17は読出し故障だと賭け、異常を機械側へ寄せすぎる対戦相手。
- できる子：公開判定のデータ解析者。数値、誤差、対立仮説だけを読み上げ、二人のどちらにも肩入れしない。
- できる夫：科学館の映像演出家。賭けの賞品にした「未知粒子発見」と「故障確定」の両字幕を毎幕小さく直す。

## マクガフィンとトイ

- 事象E-17：電子候補 $p_T=46\,\mathrm{GeV}$、欠損横運動量 $44\,\mathrm{GeV}$、方位角差 $2.20\,\mathrm{rad}$ で横平面の反対側という仮想データ。全編で固定する。
- 八角形の事件盤：検出器層、保存量、場、対称性、相互作用、真空、統計、限界の八欄。
- 三色リボン：色荷、グルーオン自己相互作用、閉じ込めを身体的に演じる。
- 位相時計二台：局所位相と接続を、針の基準合わせとして何度も使う。
- 空の証拠椅子H：第7幕まで座らせない。終幕では未知の四席へ増える。

## 伏線と回収

- E-17の縦方向の帳尻が合わない。第3幕で陽子内部のパートン分率が未知だから横成分を使うと回収。
- 電子札の裏にL/Rがある。第6幕で弱い相互作用のカイラリティへ回収。
- 三色リボンは強く引くほど切れず別の輪ができる。第5幕でハドロン化へ回収。
- H椅子の脚が四本なのに座面は一つ。第7幕で四自由度から三縦偏極＋一ヒッグスへ回収。
- できる夫の看板に小さく「候補」と印刷されている。第8幕で科学的主張の階層へ回収。

## 繰り返すギャグ

- やる夫が粒子札をポケモンの属性相性表にしようとし、毎回「群作用は相性表じゃない」と止められる。
- できる夫の二択速報が「発見！／故障！」→「発見？／故障？」→「候補／要調査」へ同時に弱くなる。
- 三色リボンを解こうとするほど展示台が巻き込まれる。第5幕以後は結ばず観察する。
- やらない夫が「まず帳尻を閉じろ」と言うたび、やる夫が画面の空白をCGで塗りつぶそうとする。

## 緩急と息抜き

- 第1幕は公開前夜の事故を高速で始め、第2幕は暗い展示室で場の直観を作る。
- 第3・4幕は事件盤と位相時計の手作業、第5幕は三色リボンの身体ギャグで息を抜く。
- 第6幕でE-17の正体へ迫り、第7幕を数式と真空の知的クライマックスにする。
- 第8幕は統計で一度熱を冷まし、終幕は来館した子供の質問で余韻を作る。

## ブロック運用

各節は、観測事実、仮定、計算、代替説、暫定判定の五札で閉じる。技法名や粒子名を先に教えず、E-17の一欄が埋まらない困りごとから導く。核心式は記号定義、途中操作、単位または極限の検算を入れる。理論上の粒子と検出器オブジェクトを同一視しない。

## 状態台帳の初期値

- E-17の数値、検出器の仮想構成、時刻、看板文言を固定する。
- 実在実験の一件をE-17と誤認させず、仮想の教育用較正事象と明示する。
- 5σ、粒子質量、結合定数など外部数値には確認済み参考文献だけを付け、未確認URLを置かない。
- 「標準模型の外」を列挙する場面では、未発見の具体模型を確定事実のように扱わない。
