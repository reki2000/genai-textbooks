# 寸評：やる夫が脱炭素でブランディングする ── 意識か、勘定か

約127KB／全6幕＋終幕。中小メーカーの4代目社長が、採用のための「宣言」から出発して、物理・経済・国際制度・自社の帳簿を6夜で掘り下げ、最後に面白みのないプレスリリースへ着地する教材。

## 良い点

**曾祖父の幽霊という設定が、理論の要求と3か所で噛み合っている。** (a) 101年分の累積排出表（501–508行目）は「気温は累積に比例する」を自社の帳簿で体感させる装置、(b) 1974年の重油炉→電気炉の切り替え（986–991行目）はスコープ2を導入するための最良の反例、(c) 1972年の集塵機（1593–1613行目）は「意識と勘定は時間の長さが違うだけ」（1621行目）という終幕の主張を実話として支える。舞台装置が飾りではなく論証の器になっている。

**「うち一社の削減は誤差」という誤りを、教材が追跡して3回殺す。** やる夫が自力で $4.5\times10^{-8}\ \mathrm{℃}$ を計算して「何もしなくていい」に到達し（435–437行目）、やらない夫が「その計算を、消すな。数字は全部正しい」（440–442行目）と保存する。3-1で共有地の悲劇の正体として回収され（591–597行目）、5-2で「四捨五入で消えるお」と再発した際にやる夫自身が「$3$ 回目だお」と数える（1100–1106行目）。同じ誤りの再来をカウントする仕掛けは、単発の反例より学習効果が高い。

**三つの宿題が全部外れる構造。** 205–213行目で(1)強制か意識か (2)最大の塊はどこか (3)一番早く反応するのは誰か を裏紙に書かせ、(2)は5-2（1067行目「炉は $3.5\%$、材料が $75\%$」）、(3)は6-1（1426行目「完全に逆」）、(1)は6-2（1470–1495行目）で採点する。しかも(1)だけは○×がつかず、「上流に意識があって、下流に勘定がある」（1494行目）という分解に落ちる。タイトルの問いが最後に構造として答えられている。

**経営者の道具だけで理論を殴っている。** 品質管理の $3\sigma\to2\sigma$ で不良が17倍（465–468行目）は「平均は誰も気づかず裾だけ跳ねる」の最短証明。証書代330円に対し太陽光20万円で「$606$ 年」（1165行目）は追加性の一撃。LEDが「$2.2$ 年で回収、稟議は $2$ 年基準、$0.2$ 年オーバーで却下」（1255–1258行目）は、省エネが実行されない理由を環境問題から社内規程の問題へ移す。どれも読者が既に持っている物差しで計算されている。

**数値が長距離で一貫している。** 774 t は第1幕で係数だけ渡された段階の試し計算（264行目）→5-2でスコープ2の実値（1058行目）→5-4で(1)(2)(4)を引いた残り604 t（1266行目、$774-19-52-99=604$）と、3か所で整合する。95,700 t の累積（501–508行目）も年1,000 t×100年の概算と桁が合う。

**参考文献が29点、本文対応つきで付いている（1744–1805行目）。** 冒頭（1746行目）で「やる夫商事の数値は架空の事例」と明記しており、実在の係数（1053行目）と架空の帳簿の境界がはっきりしている。

## 欠点

**やる夫が要所で強すぎる。** 301–307行目の放射平衡は、受光面 $\pi R^2$ と放射面 $4\pi R^2$ の切り分けから4乗根まで、32歳の部品屋の社長がヒント無しで完走している。より深刻なのは5-1で、「線を**一本**引こうとするから詰まる」というほぼ答えそのものの一言（1007行目）だけで、スコープ1・2・3の三層を過不足なく言い当てる（1010–1013行目）。ここは教材の中核概念で、GHGプロトコルが実際に長い議論を経て決めた区分である以上、最も抵抗があるべき場所が最も軽い。651–653行目の排出量取引の再発明、718–720行目のCBAMの再発明も同型。

**「やる夫が儲け話を思いつく → 自分で即座に潰す」の型が10回以上繰り返される。** 空気清浄機（348–357行目）、冷却部品が売れる（478–480行目）、世界政府（825行目）、町工場とだけ商売（962–963行目）、会社分割（1035–1043行目）、誤差だからバレない（1100行目）、クレジットで全部相殺（1186–1187行目）。やらない夫の受けも「おっと、気が早いぞ」（602・755・1039・1438行目）、「そこに気づいたか」（258・375・561・1029行目ほか）と定型句化しており、後半になるほど反証の重みが落ちる。読者は「また潰されるな」ではなく「また同じ段取りだな」と感じ始める。

**やる夫が本当に立ち往生する場面が一度も無い。** 明示的に詰まるのは1007行目の「いい所で詰まった」だけで、それも一言のヒントで解決する。反証はすべてやらない夫の口から出るため、構造として説教から逃れられていない。同リポジトリの熱力学教材が「できる子」に測定値だけを読ませて、教師が反論しない形を作ったのと対照的で、この教材には数字を突きつける第三者がいない。工場長も経理も設計課も名前で言及されるだけで、一度も喋らない。

**発端の危機が中盤で無効化され、以後は何も駆動しない。** 内定辞退6人（18–22行目）が動機だが、6-1で「単体では効かない」（1404行目）と正面から否定される。判断としては誠実だが、代わりに置かれた期限（10月の調査票、11月の銀行面談、1414–1416行目）は物語内で一度も切迫しない。6夜のあいだ、電話が鳴ることも、取引先が催促してくることも、誰かが反対することもない。熱力学教材の「横断幕を刷ってしまった」に相当する不可逆な失点が存在せず、圧力は全て「いつか来る」の形をしている。

**構成の改訂痕跡が本文と脚注に残っている。** 233–234行目でやらない夫が「今夜から毎晩の習慣を一つ作る」と宣言し、1551行目で「帳簿を読む、は今夜で終わりだ」と締めるのに、`### 帳簿を読む` の見出しは(1)（230行目）しか存在しない。しかも脚注[^29]（1803行目）は「本文『帳簿を読む(5)』」、[^30]（1805行目）は「本文『帳簿を読む(4)』」を、[^25]（1796行目）は存在しない「演習2」を参照している。節番号の参照も、[^5]が2-4（実際は2-3）、[^7]が3-2（実際は3-1）、[^13]が3-4（実際は3-3）、[^23][^24]が5-5（実際は5-3）とずれており、[^28]は欠番。読者が出典を辿れない状態になっている。

**5-3の「$5{,}900\ \mathrm{t}$」が時系列上あり得ない。** 1185–1187行目でやる夫は「計算してきたお。できることを全部やっても何千 t か残る」と言い、1211行目で残余を $5{,}900\ \mathrm{t}$ と確定させる。だがこの時点では5-4の限界削減費用曲線も、再生アルミの $1{,}275\ \mathrm{t}$（1316行目）もまだ登場していない。$7{,}600-210-1{,}275=6{,}115$ とも合わず、この数字だけが導出のないまま置かれている。

**第2幕の物理が、幕の重さに対して薄い。** 331–339行目の温室効果の説明は「対称な分子は電気的な偏りが変わらないので参加しない」で止まっており、なぜ $0.04\%$ が $33\ \mathrm{℃}$ も効くのか（吸収帯、光学的厚み、濃度に対する対数的な効き方）には触れない。累積比例則も「二つの効果が打ち消し合う」（416–418行目）と天下りで渡され、やる夫が検算するのは $2.4\times0.45=1.08$（422行目）だけ。物理を扱う幕で、やる夫が自力で潰した素朴案は「$0.04\%$ は誤差」の一つしかない。

## 改善案

1. **5-1の三層を、やる夫に一度失敗させてから作らせる。** 1007行目のヒントを渡す前に、やる夫の折衷案を1つ挟む。例えば「自分で燃やした分＋買った電気」の二層で線を引かせ、そこへやらない夫が「では鋼材を自社で作っている会社と、外から買っている会社を並べて比べろ」と投げる。二層では垂直統合の度合いだけで数字が変わってしまうと自分で見つけさせれば、三階の必要性が「ヒントで言われた」ではなく「二層が壊れたから」になる。20〜30行で済み、教材の中核概念の獲得コストが正常化する。

2. **反証の口を、やらない夫以外にも与える。** 工場長（ガスの伝票と炉の実測）と経理担当（稟議規程と回収年基準）を、台詞のあるキャラクターとして2〜3回だけ登場させる。特に1255–1258行目のLED却下は、経理が「規程どおりです」と一行言うだけで、やる夫の敵が地球でも曾祖父でもなく自社の紙であることが劇として立つ。同様に1332–1336行目の「客先の承認に1〜2年」は、設計課の一言にすると重みが出る。

3. **期限を物語内で一度だけ実際に切らせる。** 第4幕あたり（例えば929行目の直後）に、ドクオ自動車部品の購買から「調査票の期限を10月から8月に前倒しします」という電話を1本入れる。これだけで残りの幕に「あと何日」が乗り、6-1の3点セット（1443行目）が間に合うかどうかという緊張が生まれる。分量増は10行程度。

4. **脚注と見出しの参照を全面的に整合させる。** 「帳簿を読む」を(1)のみに揃えるなら1551行目の言い回しと[^29][^30]の記述を直す。逆に習慣として通すなら、各幕末の帳簿パート（496–520行目、746–785行目、940–968行目など）に(2)〜(5)の見出しを実際に付ける。あわせて[^5]→2-3、[^7]→3-1、[^13]→3-3、[^23][^24]→5-3 に修正し、[^25]の「演習2」の記述を削除、[^28]の欠番を埋めるか繰り上げる。

5. **「儲け話 → 自壊」の型を3回ほど別の形に置き換える。** 特に後半（962行目の逃げ切り戦略、1035行目の会社分割）は、やる夫に自壊させず、一度は本気で実行に移させてから外の誰かに潰させる方が効く。例えば会社分割案は、翌朝やる夫が顧問税理士に相談し「その手はもう何社もやって、購買部が最初に見る項目になっています」と返される形にすると、コメディとしても情報としても新しくなる。

6. **2-1に温室効果の定量を一段だけ足す。** 339行目の後に、「$255\ \mathrm{K}$ と $288\ \mathrm{K}$ の差を作るには、地表が出す赤外線の何割が捕まって戻ればよいか」を $\sigma T^4$ の比で概算させる（$(288/255)^4\approx1.63$）。やる夫の得意な「割り算で意味を出す」型に乗るうえ、「$0.04\%$ で $6$ 割を捕まえるのか」という驚きが自前の計算から出る。さらに一言、濃度に対して効き目が対数的であること（倍にしても線形には増えない）を添えれば、後段の炭素予算がなぜ「累積」で効くかの物理側の裏づけになる。

7. **5-3の $5{,}900\ \mathrm{t}$ を5-4以降へ移す。** 1185–1187行目のやる夫の台詞を「できることを全部やっても、たぶん何千トンか残るお」と量を伏せた形に留め、$45{,}000$ 円／t との突き合わせ（1210–1211行目）は5-4の表が完成した後、6-1の直前に置く。残余量が対策リストから導かれる順序になり、オフセットが「入口ではなく出口」（1342行目）という結論が数字の順序でも裏打ちされる。
