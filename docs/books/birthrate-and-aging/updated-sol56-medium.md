# 改訂メモ

`review-opus-medium.md` の具体的な改善案6点を、本文の主張と伏線を残したまま反映した。

- 第1幕では、やる夫を「全員から同率で削減」から「資産3000万円で一律に削減」へ進ませ、生活への影響、自宅評価額と現金所得、金融資産の把握という別々の問題で二度失敗させた。結論を即答させず、所得・資産・流動性を組み合わせる必要を自分で言語化させた。
- 第4幕では、100人の町に水道管20km、更新費1m当たり10万円、40年更新という計算用の仮定を置いた。100人なら年50万円、50人なら年100万円という一人当たり負担をやる夫自身に算出させ、「維持するものを選ぶ」根拠を数値化した。
- できる夫を第4幕へ前倒しし、記録・請求・入力の一本化を有効な案として採用した。第7幕では、その成功を完全自動介護住宅へ過剰拡張して失敗する構造に変え、単発の当て馬ではなく、長所と過信の両方を持つ人物にした。
- 第9幕の5連続発言を、やらない夫、できる子、できる代、できる夫から反論と確認が入る政策協議へ変更した。各柱に評価指標、実施順序、本人同意、導入後測定を加え、既出論点の再掲から統合と選択の場面へ変えた。
- 検討会に「今日17時、次年度予算査定に間に合う答申案」という期限を設けた。第9幕を残り90分から始め、16時58分の提出まで進めることで、「全部やれば勝てる」が通用しない実務上の圧力を作った。
- 総務省の空き家統計、厚生労働省の介護職員必要数、国土交通省の立地適正化計画、出入国在留管理庁の特定技能制度を脚注として追加した。本文では、数字や制度が直接必要になる箇所に脚注を置いた。

既存教材を横断して話し方を確認し、できる子は観測・条件・限界を短く提示する調子、できる夫は高い熱量で技術案と測定を語る調子に寄せた。できる代との血縁の伏線、政策の4枚レンズ、「私はいつ了承したんだい」、成功だけで採点しない最終幕は維持した。新規のト書きは入れていない。
