## 工夫した点・主な変更

- **数値の背骨を「余裕率」として1本通した（指摘1）。** 1-2 の要求条件列挙の直後に、設計荷重 1000 N × 安全率 1.5 = **標準試験片1本あたり 1500 N** を必要値として置き、以後この値で割った比を余裕率と呼ばせた。効果が最も大きかったのは開幕の 1200 N / 900 N の読み替えで、「勝ったほうも 0.80 倍で落ちている」となる。順位争いが最初から無意味だったことが、教材の1ページ目に遡って効く。以後、3-1（浸透量と層厚の表）、5-2（工程管理でばらつき 800 N → 120 N）、7-1（粗さ3水準）、8-1（重ね長さ3水準と継手4形式）、9-2（O/F/N の初期・湿熱後）で更新し、最終報告を「Oは新品で余裕率 0.83、湿熱後 0.35。飛ぶ前から要求を満たしていなかった」で締めた。

- **数字を出すたびに「順位ではなく合否」を反復させた。** 5-2 では平均が 0.88 → 1.17 に上がったことより、ばらつきが縮んだことを重視させ、「翼は当たりの1本では飛ばない。いちばん悪い1本で飛ぶ」と言わせた。8-1 では表面処理の効き（1.4倍）と継手形状の効き（1.8倍）を直接比較させ、「3週間ずっと瓶の中身の順位を争っていた」という自己診断に着地させた。数値を入れる目的が、検算可能性だけでなく主題（最強ランキングは誤り）の補強になるようにしている。

- **7-2 を口頭反証から実験反証へ全面的に書き換えた（指摘2）。** やらない夫が4回否定するだけだった箇所を、3つの測定に置き換えた。(a) 雲母の劈開面（$R_a$ 0.005 μm）で 1900 N が出て、機械的かみ合わせ説が死ぬ。ここで 7-1 の粗さ効果が「かみ合わせ」ではなく「弱い層の除去」だったと読み替えさせている。(b) 脱脂のみとカップリング剤処理で接触角も初期強度も同一（18°、2100 N）なのに、60 ℃・95%RH・1000 時間後に 900 N と 1950 N へ分かれ、分子間力単独説が死ぬ。(c) 化学結合を作った面の上に離型剤 0.2 μm を挟むと 400 N まで落ち、破断面が離型剤内部に出て化学結合単独説が死ぬ。最後の6項目リストは「並べた知識」ではなく「3つ殺したあとの生き残り」として書き直し、弱い境界層の導入もこの第3の試験の結論として吸収した。

- **ぬれ判定をやる夫の発明にした（指摘3）。** 「ぬれる君」という前任教授の遺産を削除し、「見た目で区別がつかない2枚の違いを、装置なしで確かめる方法を考えろ」に置き換えた。やる夫は息の曇り（差が出ない）、チョークの引きずり（人によって変わる）を試して落とし、水滴を選ぶ。選定理由を「差が出るから」ではなく「写真に撮れて角度が測れるから、感想ではなく数字になるから」と言わせた。以後この水滴は 7-1 の粗さ3水準と 7-2 の(b)で再利用され、教材中でやる夫が唯一所有する計測法として機能する。「借り物ばかりの中で水滴1個だけがやる夫のもの」という自覚も1行入れた。

- **残日数を各幕の冒頭に置いた（指摘4）。** 第2幕から第9幕まで、19・17・15・12・9・7・5・3 日を最初の発言に織り込んだ。単なるカウンタにせず、第6幕では「硬化に24時間かかる接着剤であと何本試験片が作れるか数え始めた」ところへできる夫の高速硬化剤が現れる形にして、速さの誘惑に日程の重みを持たせた。9-1 の傾斜接着層の断念は、一般論ではなく 72 時間の内訳（Tの硬化24時間＋Hの硬化24時間＋剥離と熱サイクル24時間で予備ゼロ、治具の図面もなし）で押し、採用案の内訳（本番硬化24時間＋非破壊検査半日＋環境試験36時間＋予備11時間半）まで書かせた。締めの一言は「捨てたのは最善ではなく、確かめられない最善だ」。

- **できる子を第3幕へ前倒しした（指摘5）。** 初登場を 3-1 の乾燥速度比較へ移し、急速乾燥側の内部含水率 6%／緩速側 0.4% という「表面硬度は同じ、内部は同じではない」判定を担当させた。「いつからいたんだお」のネタもここへ移動し、元の第5幕での登場は「また黙って壊してから出てきた」「壊す前に言うことはない」という短い応酬に差し替えて重複を避けた。

- **「最適値がある」の1回を探索に変えた（指摘6）。** 3-1 の浸透を、やらない夫が結論を告げる形から、「浸透量をどう測るか、装置は買えないと思え」という問いに変えた。やる夫は塗布質量と硬化後の残存層厚から $m_{\text{浸透}} = m_{\text{塗布}} - \rho t_{\text{層}} A$ を組み立て、粘度3水準で浸透率 88/45/9%、層厚 0.01/0.08/0.16 mm、破断荷重 620/1450/780 N の表を作る。低粘度側の弱さが「層が残っていない」という測定値で言えるようになる。締めに「最適値がある、と言われるのと、最適値を挟むのとでは全然違う。測り方を持っていないと最適値は永遠に他人の言葉だ」を置き、以降3回繰り返される同型の結論に、探索の型が先行しているという構造を作った。

- **事故原因を1つ最後まで伏せた（指摘7）。** 接着層厚さの記録不足を第7幕・第8幕からは削り、9-2 で破断した旧継手Oを解体したときに初めて発見される形にした。できる子が重ね部20か所を測り、0.02 mm から 0.61 mm、30倍のばらつき、管理値も測定値も記録なし、と報告する。やる夫がここで「1本の継手の中でAとBを同時にやっていた」と 1-1 の最初の試験へ戻り、やらない夫が「3週間前に見せた。証拠は最初から机の上にあった。読める目がなかっただけだ」と返す。最終報告が既知情報の再掲ではなく、最後のピースを埋める場面になった。

## 残した判断

- ペタゴンの6面、石器時代の混ぜ物 → 靱性化、石器の結束併用 → ハイブリッド接合という回収構造、「外せることも性能」の 3-2、できる夫が用途選定の誤りへ着地する結末は、レビューで評価された骨格なので手を入れていない。

- 数値はすべて学習用の架空データで、実在の材料や規格の値ではない。本文冒頭の免責文と参考文献の位置づけは既存のままとし、新しい一次資料は追加していない。物理的な傾向（有効接着長さの飽和、湿熱後の界面劣化、弱い境界層の支配性）は既存の参考文献が扱う範囲に収め、数値の大小関係がその傾向と矛盾しないように設定した。

- 教材末の「UBS」の名前オチはそのまま残した。3週間の日程と余裕率で締め上げた直後に、やる夫が最後まで名前で失敗する落差が、教材全体の緊張を一段下ろす役に立っているため。
