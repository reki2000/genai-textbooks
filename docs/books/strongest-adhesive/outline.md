# やる夫と最強の接着剤 の骨格

ドローンの翼が剥がれた事故調査＋3週間後の公開試験、というカウントダウン構成（残り19日→17日→15日→12日→9日→7日→5日→3日）。前任教授の遺産である3つの道具（**くっつく君**＝試験機、**どこで死んだ君**＝破断面判定ルーペ、**ペタゴン**＝被着材/表面/接着剤/継手形状/硬化工程/使用環境の6面体）が全編の枠組み。第7幕でやる夫が初めて自分の測定法（水滴＝接触角）を作る。

判定は全編 **余裕率＝破断荷重／1500 N**（設計荷重1000 N×安全率1.5）。1.0未満は候補ですらない。

## 第1幕　翼が剥がれた日
- 1-1　「3倍厚く塗る」を A 1200 N 対 B 900 N で潰す（気泡と未硬化部）。カタログ値の万能性を、せん断と剥離の同面積比較で潰す。**この厚さの試験が、9-2 で事故原因そのものだったと判明する**。
- 1-2　H/S/F を静的・衝撃・疲労・クリープ・環境後で順位が入れ替わることを見せ、翼の要求条件10項目を列挙。**余裕率**を導入し、1-1 の1200 Nが0.80、900 Nが0.60＝「勝ったほうも落ちている」と読み替える。ペタゴンと石器時代の標本箱で歴史をたどる方針が決まる。

## 第2幕　石器人の複合接合
- 2-1　「粘るものが接着剤」を、柔らかい試料が1時間で流れ、硬い試料が隙間に入らないことで潰す。**塗布時は液体・使用時は固体という時間で分ける発明**へ。標本の混ぜ物（赤い鉱物粉と繊維）を不純物と誤認し、衝撃試験で繊維が亀裂を止めるのを見て複合材料だと気づく。接着剤＋結束の併用＝ハイブリッド接合とフェイルセーフ（8-2 で回収）。
- 2-2　「混ぜるほど強い」を、目分量配合の1号だけが再現できない失敗で潰す。「1度の最高値より100回作った最低値」。各成分に利益と代償があり、配合は性能の交換。

## 第3幕　乾けば固まる
- 3-1　「水が接着力を持つ」を否定し、水は運び屋。浸透しすぎ／しなさすぎの両方が弱いと分かった後、**やる夫が装置なしで浸透量の測定法を自作する**（$m_{浸透}=m_{塗布}-\rho t_{層}A$）。低/中/高粘度で88%/45%/9%、層厚0.01/0.08/0.16 mm、620/1450/780 N の表。「最適値がある、と言われるのと最適値を挟むのとでは全然違う」。次に急速乾燥と緩速乾燥で、できる子が内部含水率6%対0.4%を報告し、表面硬化と内部固化の区別へ。
- 3-2　「水に戻る接着剤は劣等生」を、木製くっつく君の交換式木枠の修理で潰す。可逆性・再作業性・部品交換も性能。製品の一生（塗布→位置調整→固定→硬化→使用→点検→修理→分解→再利用）。最後にテープを見せられ、「液体か固体かの二分が粗い」と指摘される。

## 第4幕　柔らかいものが剥離に勝つ
- 4-1　「硬いほど強い」を、引張ではH、剥離ではSという逆転で潰す。強度（応力）と靱性（亀裂を進めるエネルギー）の区別。ゼリー案はクリープで潰れ、**粘弾性**（時間と温度で応答が変わる）へ。感圧接着剤のtack／剥離抵抗／凝集力の三すくみ。金属と複合材の熱膨張差を接着層が受け入れる必要性。
- 4-2　「強く押すほど付く」を、圧力の役割＝実接触面積を増やすこと、で修正。押す時間・剥がす速度・温度・厚さ・裏材の剛性で値が変わり、**第1幕のカタログ値問題が別の形で戻る**。「接着剤の性質は瓶の中で完結しない」。

## 第5幕　分子の網と構造用接着剤
- 5-1　架橋密度L/M/Hで、静的強度と靱性が逆向きに動く。硬い網に柔らかい粒子を散らす＝**2-2 の混ぜ物が現代の靱性化として戻る**。反応熱と収縮による残留応力、「接着層は完成時点で無応力とは限らない」。
- 5-2　4人が同じ接着剤で作ると強度が2倍ばらつく。原因候補10項目、接着剤の性能と接着工程の能力の区別。できる子が破断面（凝集破壊対界面破壊）と数値を報告し、やる夫が**「平均が0.88→1.17に上がったことより、ばらつきが800→120に縮んだことが重要」「翼は当たりの1本では飛ばない、いちばん悪い1本で飛ぶ」**と読む。ここで**できる夫が10秒硬化の新接着剤を持って登場**。

## 第6幕　速さの誘惑
- 6-1　10秒＝取扱可能時間であって最終性能到達時間ではない（10秒／10分／1日の比較）。硬化の引き金（水分・混合・熱・光・空気遮断・冷却・溶媒移動）が継手内部の全域へ届くか。速い反応は作業余裕を減らす。
- 6-2　環境試験で順位が逆転（F1位→界面から大剥離）。できる夫の「後出し」という抗議を、「飛行環境は要求仕様に最初から入っている」で退ける。できる子が油状有機物と離型剤由来の弱い表面層を検出し、**接着鎖**（母材→表面処理層→界面→接着剤→界面→表面層→母材）の最弱点で壊れるという見方へ。促進試験は魔法ではないという留保。

## 第7幕　敵は界面にいる
- 7-1　「見た目がきれいなら清浄」を、装置なしで見分けろという課題で崩す。息の曇り（差なし）、チョーク（再現しない）を自分で棄却し、**水滴＝接触角**へ到達（新品25°対事故翼78°）。「案3だけは人によらない、数字になる」。教材中でやる夫が自作した唯一の測定法。次に粗さ $R_a$ 0.1/2/12 μmで接触角40/18/12°、荷重1500/2100/1700 N。**いちばんよくぬれる12 μmが弱い**ことから「ぬれの良さは必要条件だが十分条件ではない」（深い谷に空気が残る、応力集中、削り粉）。できる子が事故記録（洗浄確認方法なし、開放棚2日保管、素手接触）を報告し、「犯人でなく工程の修正」。
- 7-2　接着機構を**3つの測定で順に殺す**。(1) 雲母の劈開面（$R_a$ 0.005 μm）で1900 N → 機械的かみ合わせ説の死。(2) カップリング剤ありなしで初期は同じ2100 N、60℃95%RH 1000時間後に900対1950 → 分子間力だけ説の死。(3) 化学結合の上に0.2 μmの離型剤で400 N、破断面が離型剤内部 → 化学結合単独説の死＝**弱い境界層**。「どの機構が主役でも弱い境界層があれば全部無効」。

## 第8幕　接着剤を強くするより形を変えろ
- 8-1　重ね長さ12.5/25/50 mmで面積4倍・荷重1.95倍、平均せん断応力6.1/5.1/3.0 MPa。応力可視化で端部集中＝有効接着長さ。単純重ねは荷重線のずれでモーメントが生じ剥離が加わる。**同じ接着剤・同じ面積625 mm²**で単純重ね3200／2重重ね4700／段付き5400／スカーフ5900 N＝形だけで1.8倍。「第7幕の表面処理の1.4倍より形の効きが大きい」「3週間ずっと瓶の中身の順位を争っていた」。
- 8-2　「ボルトは敗北」を 2-1 の石器時代の併用で崩す。役割分担（接着＝面で分散、締結＝位置決めとフェイルセーフ）と、併用が自動的に強くはならない（剛性差で荷重分担が偏る）注意。非破壊検査、「検査で品質は作れない、工程管理が本体」。

## 第9幕　最強の接着剤は瓶の外にある
- 9-1　傾斜接着層（中央H・端部T）という理論上の最善を、**残り72時間の日程計算**（確認試験片の硬化48h＋剥離熱サイクル24h＝予備ゼロ、治具の図面もない）で自ら却下。「捨てたのは最善でなく、確かめられない最善」。全体を靱性型Tにし、継手形状とフィレットで応力を下げる案の72時間内訳を示す。最終仕様を全項目読み上げる。
- 9-2　O（旧継手）／F（高速硬化）／N（統合継手）の最終比較。初期静的はF 6300／N 5900／O 1250（余裕率4.20/3.93/0.83＝**事故翼は新品でも1.0未満**）。剥離・衝撃・環境後（O 520／F 2900／N 4800）で N が残る。ここで**できる子が最後の証拠を出す**：Oの接着層厚さが1本の中で0.02〜0.61 mm＝30倍、管理値も測定値も記録なし。やる夫が「1-1でやったAとBを1本の継手の中で同時にやっていた」「1-1は前置きでなく事故原因そのものだった」と気づき、やらない夫が「証拠は最初から机の上にあった、読める目がなかっただけだ」と締める。事故の最終報告（単一原因でなく共犯）、「最強の接着剤は瓶の中には存在しない」、接着技術の歴史の総括。落ちはUBSという略称の失敗。

## 依存
- **余裕率**（÷1500 N）は 1-2 で定義され、1-2（0.80/0.60）、5-2（0.88→1.17）、7-1（1.00/1.40/1.13）、8-1（2.13〜3.93）、9-2（4.20/3.93/0.83、湿熱後3.20/0.35）で一貫して使われる。1500 Nを変えると全表が連動する。
- **1-1 の接着層厚さ**は本編最大の伏線。9-2 で「事故原因そのもの」として回収され、やらない夫が「3週間前に見せた」と明示する。1-1 を前置きに弱めると 9-2 の山場が消える。
- **7-1 の水滴（接触角）**はやる夫が自作した唯一の測定法で、7-1 の粗さ表、7-2 の第2の試験、9-2 の事故報告（78°）で3回使われる。「くっつく君もペタゴンも借り物、水滴だけがやる夫のもの」という台詞が対応。
- **2-1 の接着剤＋結束の併用**は 8-2 で「石器時代の標本を思い出せ」と名指しで回収される。2-2 の混ぜ物は 5-1 の靱性化で回収される。
- **7-2 の第2の試験**（初期同じ・湿熱後に2倍差）は 9-2 の環境後試験で継手規模に再現され、やる夫が明示的に対応づける。
- 第1幕のカタログ値問題は 4-2 で「別の形で戻ってきた」と再演される。
- できる夫は 5-2 で登場し、6-1・6-2 で敗れ、9-1 で用途を限定して復帰、9-2 で自ら正しくまとめる、という一貫した成長線を持つ。彼の高速硬化剤は「敗者」でなく「用途選定の問題」として決着する。
- できる子は 3-1・5-2・7-1・9-2 で、必ず黙って測ってから結論だけ述べる役。9-2 の厚さ30倍が最後の一撃になる。
- ペタゴンの6面（被着材／表面／接着剤／継手形状／硬化工程／使用環境）は 1-2 で提示され、第2〜8幕が1面ずつ対応し、8-2 末で「6面が揃った」と宣言される。幕を増減するならこの対応も直す。
- カウントダウン（19日→3日）は各幕冒頭に置かれ、9-1 の72時間計算で判断材料そのものになる。日数を変えるなら 9-1 の内訳も直す。
