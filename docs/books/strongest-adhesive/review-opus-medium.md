# 寸評：やる夫と最強の接着剤

約69KB／全9幕。ドローンの翼剥離事故を起点に、「最強の接着剤」という素朴な目標が、接着剤・表面・継手形状・工程・環境・検査という6面へ分解されていく過程を、接着技術史をなぞりながら再発見する教材。

## 良い点

**開幕10分で読者の常識が数値で壊れる。** 「3倍の厚さで塗ればいい」に対し、A=1200N、B=900N（52–54行目）という逆転を即座に突きつける。しかも破断面（64–66行目：気泡と未硬化部）で理由まで見せるので、「厚い＝強い」の誤りが原理として残る。導入として非常に効率が良い。

**「ペタゴン」の6面が全体の骨組みとして機能している。** 204–215行目で被着材・表面・接着剤・継手形状・硬化工程・使用環境の6面が提示され、以降の各幕がどの面を扱っているか読者が常に位置を把握できる。1398行目「ペタゴンの6面が揃った」で明示的に閉じ、1605行目の結論文がその6面の言い換えになっている。設計として綺麗。

**歴史の並べ方が「何に失敗して何を追加したか」になっている。** 230–233行目でその方針を宣言し、実際に石器時代の混ぜ物（318–324行目）が第5幕の靱性化（776–778行目「石器時代の混ぜ物が、現代の靱性化として戻ってきた」）へ、石器の結束併用（330–341行目）が第8幕のハイブリッド接合（1339–1342行目）へ回収される。年表の暗記になっていない。

**「外せることも性能」という視点。** 3-2で摩耗部品の木枠修理（513–536行目）を通じ、可逆性・再作業性・部品交換を性能として立てる。接着教材が普通は書かない側面で、しかも539行目「では、すぐ外れる接着剤が常に優れているか」で即座に逆側からも締めており、単なる価値観の押し付けになっていない。

**できる夫の敗北が「用途選定の誤り」に着地する。** 1058–1061行目で自ら限界を認め、1478–1479行目で点検カバー仮固定という適所を得て、1568–1571行目で「僕の接着剤が敗北したのではなく、用途選定を誤れば優れた材料も失敗する」とまとめる。負けキャラを潰さずに主題（最強ランキングが誤り）を補強している。

**参考文献が本文対応つきで8点。** 1680–1687行目。Neandertal のタール（PNAS 2019）から Hart-Smith の継手解析、NASA の工程仕様まで、各項に「本文第◯幕に対応」が付く。1678行目の免責文も適切。

## 欠点

**数値が事実上ゼロ。** 定量的な値は 1-1 の 1200N/900N（53–54行目）と 30MPa の暗算（89–91行目）だけで、以降 1600行にわたり「Hが上」「順位が逆転した」（1004–1009行目）「大きく増えた／少ししか増えていない」（1267–1268行目）という順序関係しか出てこない。数式も 8-1 の $\tau_{avg}=F/A$（1290行目）1本のみ。有効接着長さ、粘弾性の時間温度換算、応力集中の程度――どれも「そういう傾向がある」で終わり、読者は差の大きさを検算できない。教材の背骨になる単位（thermodynamics のワッシャー0.098Jに相当するもの）が最後まで現れない。

**やる夫が「言われて即座に正解を言う」場面が多すぎる。** 最悪なのは 7-2 の接着機構で、やらない夫が4回口頭で否定した（1170–1201行目）だけで、やる夫が機械的かみ合わせ・分子間相互作用・化学結合・相互拡散・浸透・静電を6項目そろえて列挙する（1204–1212行目）。ここは接着学で最も論争的な部分なのに、実験による反証が1つもない。9-1の傾斜接着層（1417–1421行目）も、その却下理由（1425–1432行目）も一発で正しく、抵抗がない。

**やる夫が測定器を一つも発明しない。** くっつく君（42行目）、どこで死んだ君（63行目）、ペタゴン（204行目）、ぬれる君（1086行目）はすべて前任教授の遺産としてやらない夫から与えられる。特に 1086行目のぬれ判定は、「表面がきれいかどうかを現場でどう確かめる？」と問えばやる夫が水滴を思いつける題材なのに、道具が先に出てくる。「自ら再発見する」という趣旨に照らして、この受動性は全体の手触りを弱めている。

**「最適値がある」という同型の結論が繰り返される。** 接着層厚さ（76行目）、浸透量（465–471行目）、テープ厚さ（711–714行目）、粗さ（1116–1119行目）が全部「多すぎても少なすぎてもだめ、適度が最強」で終わる。469行目で本文自身が「また最適値だお」と自覚しているが、自覚しても4回目は退屈で、しかも何がその最適値を決めるのかは毎回示されない。

**3週間の期限が物語を駆動していない。** 25行目で提示されるが、中盤で残日数が更新されず、976行目のできる夫の煽りで一度触れられるだけ。9-1で複雑な塗り分けを断念する判断（1429–1432行目）は本来「日程と製造能力」で押されるべき場面なのに、根拠は「作れなければ絵だ」という一般論に留まる。事故→試験という強い骨格を持ちながら、締切の圧力を最後まで使い切っていない。

**できる子が半ばまで不在。** 人物紹介（10行目）にいるのに初登場は869行目で、全体の半分を過ぎている。876–880行目の「いつからいたんだお」はネタとして成立しているが、破断面という最重要の証拠を扱う役が前半5幕まるごといないため、その間の判定はすべてやらない夫の口頭説明になっている。

**最終報告がサスペンスになっていない。** 1580–1586行目の事故原因は、汚染（1104行目）も継手形状（1322–1323行目）も第7幕・第8幕で既に判明済みの再掲で、新情報がゼロ。事故調査という導入を持つ以上、最後まで1つ伏せておく余地があった。

## 改善案

1. **数値の背骨を1本通す。** 1-2 の要求条件の列挙（181–192行目）の直後に、やらない夫から「翼付根の設計荷重は◯◯N、安全率込みで接着部が受け持つのは◯◯N」を出させ、以降の各幕末に「今の候補は必要値の何倍か」を1行で更新する。1200N/900N がその比で語れるようになり、9-2の最終試験（1504–1566行目）が「全部を必要値と比べる」表として成立する。

2. **7-2 を口頭反証から実験反証へ変える。** 1170–1201行目のやらない夫の4回の否定を、それぞれ実測に置き換える。(a) 原子レベルで平滑な劈開面同士でも接着する試験でかみ合わせ説を殺す、(b) 同じ接着剤・同じぬれで表面処理だけ変え、初期強度は同じなのに湿潤後の耐久性だけ変わる測定で「分子間力だけ」説を殺す、(c) 弱い表面層の上に強固な化学結合を作って層ごと剥がす。やる夫の仮説が測定で死ぬ形にすれば、1204–1212行目の6項目リストが「並べられた知識」から「生き残った仮説」へ変わる。

3. **ぬれ判定をやる夫に発明させる。** 1084–1088行目のぬれる君の提示を削り、代わりに「事故翼の金属面と新品の面、見た目は同じだ。違いを現場で確かめる方法を考えろ」とだけ言わせる。やる夫が水滴・息の曇り・チョークの引きずりなどを試し、水滴が最も再現性が高いと自分で選ぶ往復を10〜15行入れる。教材中で唯一やる夫が計測法を持つ場面になる。

4. **残日数を各幕の頭に置く。** 25行目の「3週間後」を受け、第2幕以降の各幕冒頭に「残り◯日」を1行入れる。そのうえで 9-1（1429–1432行目）の塗り分け断念を、「確認試験片の硬化に24時間、非破壊検査に半日、残りは3日」という具体的な日程で押す。理論的最善と実行可能解の差が、キャラクターの判断として立つ。

5. **できる子を第3幕へ前倒しする。** 3-1 の急速乾燥・緩速乾燥の比較（477–480行目）で、内部の水分残存を測る役として初登場させる。876–880行目の「いつからいたんだお」のネタは、そこで一度使えばよい。以降、5-1の硬化発熱（791–794行目）の温度分布も彼女の担当にできる。

6. **「最適値」の4回のうち1回を探索の型に変える。** 3-1 の浸透（459–471行目）を、やる夫が「浸透量をどう測るか」から考える形にする（塗布質量と、硬化後に剥がして残る層の厚さの差など）。最適が「示される」のではなく「探される」1回があるだけで、他の3回の反復が伏線に見えてくる。

7. **事故原因を1つ最後まで伏せる。** 例えば接着層厚さの記録不足（1582行目）を、9-2の最終試験の途中で旧継手Oを解体したときに初めて発見される形にする。1580–1586行目の総括が、既知情報の再掲ではなく最後のピースを埋める場面になる。
