# 寸評：やる夫の天気予報 ── 最先端の予報術を再発明する

約50KB／全6幕。持続予報からGenCast・AIFSまでを、素朴案を殺し続ける形式で一本の道に通した教材。

## 良い点

**「素朴案 → 反例 → 修正」のリズムが最後まで崩れない。** 第4幕は 4-1 CNN → 球面歪み、4-2 局所MP → ホップ数律速、4-3 1ステップ訓練 → 分布シフト、4-6 乱数足し → ボケ残存／GAN → モード崩壊、と5連続で同じ型を回している。読者が「次も何か死ぬぞ」と身構える状態を作れており、道具箱が天下りにならない。

**一本の具体例を教材全体の背骨に使っている。** 第1幕の「晴れ22℃か前線通過で12℃か、五分五分」（32行目で明示的に「何度も戻ってくる」と宣言）が、4-4のMSE最小化＝17℃、4-5のU字ランクヒストグラム、4-6の拡散サンプル、第6幕の較正確認まで5回再登場する。抽象的な「確率予報が必要」を、毎回同じ数字で殴り直す構造は強い。

**やる夫が手を動かす計算が、全部意味のある結論に着地している。** $\log_2 200 \approx 7.6$ → 2週間の壁（113行目）、$1.7\times10^8 \times 0.86\times10^8 = 1.5\times10^{16}$ → 全結合即死（301行目）、$\cos 60°$ → 極の潰れ（356行目）、$3000/200 = 15$ホップ（418行目）。どれも「計算させるための計算」ではなく、案が死ぬ理由そのものになっている。

**第5幕の一意化と「核心は損失関数」の落とし。** 7条件を並べて候補を順に殺し、最後に「アーキテクチャは同じ球面GNN、分けたのは損失関数」（729–748行目）へ収束させる構成が見事。しかも第6幕でAIFSがMSE版とCRPS版の2製品として実在すると知らされ（830–835行目）、読者が導いた分岐が現実に立っているという報酬が用意されている。

**留保4点と未解決の問いで終える誠実さ。** ERA5依存、極端の過小評価、保存則の不保証、データ同化の物理依存（795–807行目）を明示し、最後に「理解しているのか、上手い内挿か」（865–869行目）を開いたまま置く。宣伝で終わらない。

## 欠点

**やる夫が強すぎる。** 「サッカーボール……正20面体を細分化したメッシュだお」（380行目）、「これ、画像生成でみた拡散モデルだお」（636行目）は、ヒントの薄さに対して跳躍が大きい。特に4-6は、やらない夫の「汚す過程の逆を学ばせたら？」というほぼ答えそのものの誘導に対して即答しており、再発見というより台本の読み合わせに見える。冒頭の人物紹介で「CNN・勾配降下法は履修済み」と予防線を張ってはいるが、拡散モデルは履修済みリストに入っていない。

**「苦労の過程」が第4幕以降で薄い。** 第1幕〜第2幕はやる夫が実際に詰まる（「ぐぬぬ」29行目、「何も分かってないお……」288行目）が、第4幕以降は素朴案が1往復で死んで即座に正解が出る。反例で殺される回数は多いのに、一つの反例の前で長く立ち往生する場面がない。結果として、幕が進むほどテンポは上がるが体温が下がる。

**ドラマ・コメディの要素がほぼない。** 登場人物2名、舞台設定なし、時間的な制約や利害関係もなし。純粋な問答形式で、第2幕のリチャードソン145 hPa（171行目）のような史実の逸話が唯一の起伏になっている。同リポジトリの熱力学教材のような「期限」「宣伝してしまった横断幕」に相当する物語的圧力は存在しない。

**数値の出典と精度が不揃い。** 「20〜35%も過小評価」「HRESの10〜15%」（536行目）、「1320項目の97.2%」（774行目）、「約1000分の1」（788行目）など具体的な数字が多用されるが、参考文献セクションがない。同ディレクトリの他教材（thermodynamics など）は脚注で出典を列挙しており、揃っていない。

**第2幕の「保留C」が回収されているようで浅い。** 782–789行目の回収は、CFL条件とパラメタリゼーションの再掲＋「約1000分の1」で終わっており、第2幕で仕込んだ「16倍」の計算がここで効いてこない。保留A・Bに比べて保留Cだけ格が落ちる。

**CRPSがほぼ名前だけ。** 739–741行目で「予報した確率分布と実際に起きた1つの値との食い違いを測る」と一文で片付けられている。第5幕の核心が「MSEかCRPSか」である以上、MSEに対して 17℃ を手計算させたのと同じ扱い ── 五分五分の例でCRPSを最小化すると何が最適になるか ── を一度やらないと、分岐の片側だけが体感されていない状態になる。

## 改善案

1. **4-6の拡散モデルの前に、やる夫を一度長く詰まらせる。** 4-5末尾（598行目）の「どうやったら平均に逃げずに鋭いサンプルを出せるんだお」の後に、やる夫の失敗案をもう1つ挟む（例：出力を離散化して各格子点で分布を出す → 格子点ごとに独立に引くと空間的に破綻した場になる）。「サンプル間の空間的整合性が要る」という制約を先に自分で発見させておけば、拡散モデルへの跳躍が「思い出した」ではなく「要請から絞り込んだ」になる。

2. **CRPSにMSEと同じ計算を1回させる。** 5幕で、22℃/12℃の五分五分に対し「17℃と断言する予報」「50%/50%と言う予報」の2つをCRPSで採点させ、後者が勝つことをやる夫に手計算で確かめさせる。「MSE→平均、CRPS→分布」が標語ではなく実感になる。

3. **保留Cを第2幕の「16倍」で回収する。** 782行目の回収時に、「解像度を2倍にすると物理は16倍、MLの推論コストは何倍か」を問い、格子点数に比例する程度（8倍、しかも時間刻みの縛りがない）だと数えさせる。第2幕で計算させた16倍が最終盤で効く形になる。

4. **参考文献を追加する。** GraphCast（Lam et al., Science 2023）、GenCast（Price et al., Nature 2024）、NeuralGCM（Kochkov et al., Nature 2024）、Lorenz 1963、Richardson 1922、ECMWF AIFS運用化アナウンス、Van den Dool のアナログ予報見積もり。本文中の具体的な数値（97.2%、9日前のハリケーン・リー、1000分の1）に脚注を付ける。

5. **やる夫の「履修済み」設定を拡散モデルまで広げるか、逆に狭める。** 冒頭6行目に生成モデル（VAE/GAN/拡散）を明記して 636行目の即答を正当化するか、あるいは履修済みから外して、やらない夫がノイズ除去過程を組み立てる側に回す。現状は中間で、跳躍の妥当性が判定できない。

6. **軽い物語的圧力を入れる余地がある。** 全面的な改稿は不要だが、例えば第1幕冒頭に「明後日の屋外イベントの決行判断を任された」程度の設定を置き、第6幕で「その判断に確率予報をどう使うか」に着地させるだけで、確率予報の必要性が学術的動機から実務的動機へ変わる。分量増は数十行で済む。
