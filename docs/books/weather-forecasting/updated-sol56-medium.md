# 改稿メモ

## 工夫した点

- 冒頭に「翌日の屋外観測会を決行するか」という期限付きの判断課題を置き、終幕で確率予報を意思決定へ使う場面として回収した。
- 4-6では、格子点ごとの独立サンプリングによる市松模様、平均場への乱数加算、GANのモード崩壊を順に試し、「鋭い・多様・場全体で整合」という要請から拡散モデルへ進むようにした。
- 正二十面体メッシュは名称を即答させず、正多面体の比較と細分化から導いた。
- CRPSを22℃／12℃の五分五分の例で手計算し、17℃の点予報が5、真の二峰分布が2.5になることを示した。CRPSによる評価・学習と拡散モデルの学習は同一ではないことも明記した。
- 保留Cでは、解像度を各方向2倍にしたときの物理モデルの概算16倍と、CFL由来の追加倍率がないML推論の概算8倍を対比した。

## 主な変更

- やる夫の履修設定から生成モデルを外し、拡散モデルへの唐突な既知知識による跳躍を解消した。
- 極端降水の過小評価に関する出典不明の細かな比率は一般的な傾向の記述へ改めた。
- GraphCast、GenCast、NeuralGCM、AIFSなどの具体的主張に脚注を付け、末尾に参考文献を追加した。
- GenCastの公表年はオンライン公開とNature巻年を区別した。

## 残した判断

- 既存の6幕構成、22℃／12℃の反復例、素朴案を反例で修正する教材の骨格は強みとして維持した。
- 4-2〜4-5の短めの節にはlintの会話量warningが残るが、各節の論点は明確で、分量を機械的に増やすより現状のテンポを優先した。
