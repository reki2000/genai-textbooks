# やる夫と名前の溶けた標本庫 ── 生き物の境界を引き直す の骨格

七島自然史館の標本庫、午前0時〜朝9時の開館まで。漏水で棚の紙ラベルが全部溶け、特別展「似ている？ 似ていない？」の壁画と案内を請け負った美大生やる夫が、絵描きの目で棚を並べ直すところから始まる。姿→点数→交配→名前→骨→DNA→ドメイン→環境DNA→生命の定義と物差しを替えるたびに、一つずつ「見ないことにするもの」を選んでいく。最後に、やる夫にだけ聞こえる声やらない夫の正体が、やる夫の家系のゲノムに書き込まれた内在性レトロウイルスだと分かる。

人物：やる夫（犬好きの美大生、アルバイト、くしゃみが止まらない）／やらない夫（やる夫にだけ聞こえる目のない声。「幽霊じゃない、似たようなもんか」）／できる子（分子実験室の技術員、池の水から希少ドジョウを探す。空のチューブを持ち歩く）。

小道具：溶けたラベル／補助札／「1935」の白い粒の小瓶／黒い液体の試験管（POND・500 mL・filter）／壁の前任者の下絵の細い横線／「生命を七つの王国へ」のポスター／灰緑色のかさぶたの二枚札／脚の折れたタイプ標本の甲虫／床のマスキングテープの輪／漏水のバケツ／できる子の空のチューブ。

## 第1幕　午前零時、名前の溶けた標本
- 1-1　姿で棚を決める：大小の頭骨を別棚、流線形を魚、膜の翼を鳥、くちばしの毛皮を鳥、小瓶を石の棚（「そこでいい。今のところはな」）、試験管を素手で魚の棚。声の登場「お前の親父にも、その親父にも同じことを言われた」「俺には目がない、お前の目で見ている」。補助札でイルカ・コウモリ・カモノハシ、チワワ2 kg・デーン80 kg（40倍でも犬）とオオカミ。似ていないものが近く、似ているものが遠い。
- 1-2　十項目の採点でサボテン×トウダイグサ8点が最高→棘・太い茎・小さな葉は乾燥という一つの事情の三票（形質の非独立）、サメとイルカも収斂。リンネも同じ壁。壁の下絵の細い横線を「消し忘れ」と一本白で塗る（6-5 で回収）。はがれたラベルに「その枝の支持値はゼロだな」（4-4 で回収）。
- 1-3　全部DNAで決める案を、案内係が受ける問い（キノコ食べられる？／新種の名前／クジラの親戚／羽の持ち主／保護予算）で崩す：同定・命名・系統推定・保全の意思決定、それに分類からの予測。試験管は「不明」で魚の棚の奥へ。種は何で決まるのか。

## 第2幕　種という鍵
- 2-1　交配できれば同種→犬とオオカミは同種に（*Canis lupus familiaris*）。ウマ64・ロバ62・ラバ63本、奇数でペアが組めない算数で不稔を導き、「繁殖できる子孫を続けて残せる」＝生物学的種概念。化石・細菌に鍵穴がない、輪の予告。
- 2-2　ネアンデルタール人の複製頭骨。人種ごとに別種案を自分で棄却（人類はチンパンジー一亜種より均一）。非アフリカ系ゲノムの約2%がネアンデルタール由来＝交配の濃淡、境界はグラデーション。「時間の途中が見えないだけ」と反論。
- 2-3　床にマスキングテープで輪。*Ensatina* のリング種：隣同士は交配、南端の両端は別種＝推移律が成り立たない「同じ」。種は箱でなく輪。閾値50%→60%…で境界が動く、研究者間で今も割れる。線はやる夫の側にある。南端のテープで転ぶ。
- 2-4　できる子登場（独り言を不審がる、空のチューブ「空。だから大事」＝7-3 の伏線）。形態で分ける案をクジャクの雌雄・オタマジャクシ・隠蔽種で崩し、四本の物差し（形態・生物学・系統・生態）は測る対象で使い分ける。三つの池（東西北）のドジョウ、保護予算300万：1種なら100万ずつ、3種なら調査申請80万×3で西の工事対策に60万、まとめると北の池の特殊な食性が平均に埋もれる。分類上の種数と保全の管理単位は別の欄。

## 第3幕　名前は住所か
- 3-1　「見れば分かる」名前→dog/Hund/chien、英米で別の鳥のロビン、館の三枚の「ヤマドリ」。やる夫虫とbjörk虫で知識が積み上がらない。ラテン語の学名、二語で近さを出す＝二名法（属名＋種小名）。「標本分類ス・完璧ウス」は学名でない。学名が合っても同定が違えば届かない。
- 3-2　脚の折れた赤札の甲虫を取り替えようとする。タイプ＝典型でなく名前を実物に打つ杭＝ホロタイプ。脚を小袋に入れて戻す。岩の灰緑色のかさぶたの二枚札（キノコの名・藻の名）を書き損じと疑うが「保留」（6-6 で回収）。
- 3-3　先取権（格好よさ投票は揺れる）、同物異名は残す、アフリカゾウの分割。*Canis familiaris* と *Canis lupus familiaris* で犬は変身しない。*Homo sapiens* とリンネの *Homo troglodytes* の席に後の *Homo neanderthalensis*。
- 3-4　七段（界門綱目科属種）をイヌでたどり、壁画に七本の横帯を引く（ポスターの「七つの王国」とぴったり）。ネコ科約40種・約1000万年とラン科2万5000種超・数千万〜1億年近くで「科」の深さがそろわない。なぜ七段か、今は二十段以上。
- 3-5　リンネもクジラを1735年初版で魚、1758年第10版で哺乳綱へ。イルカを哺乳類の棚へ移すと試験管が出てきて POND＝池と気づく（重さのポンドしか知らなかった）。できる子へ届け、試料と空チューブを並べて開けたところでくしゃみ（7-3 の伏線）。クジラが哺乳類のどこかは未解決。

## 第4幕　骨で家系図を推理する
- 4-1　頭骨が似ていれば近い案→イルカ・サメ、フクロオオカミ・フクロモグラの収斂。コウモリとハトの翼は腕の骨の並びが相同、飛ぶ面は相似。どこから来た共通点かを問う。
- 4-2　棚名（魚類・爬虫類）は側系統群：爬虫類から鳥を抜いた穴あき、肺魚・シーラカンスが四肢動物に近い。祖先と子孫全部＝単系統群（クレード）。鳥は恐竜。哺乳類は合格、クジラの枝は未定。
- 4-3　共通点の多さでまとめる案を、コウモリとツバメ（翼）対コウモリとウマ（毛・乳・耳小骨）で崩し、共有派生形質と原始形質（ヘニッヒ、分岐学）。背骨は深さ次第。羊膜卵の向きを外群カエルで決める（0と1は昔と後の印）。
- 4-4　4形質×4分類群の最節約法で木B（ワニ＋ハト＝主竜類）4回対6回。コウモリを加え翼・恒温を足すとハト＋コウモリの木が7回対8回で勝つ（トカゲ・ワニの置き方3通り同点）→翼と恒温は飛ぶ暮らしの二票（サボテンと同じ）と自分で気づき、こめかみの二つの窓・下あごの窓を足して10対11で逆転。最節約は自然法則でなく物差し。バケツで8枚カードの復元抽出を10回＝ブートストラップ、支持値70%（正しい確率ではない）。1-2 の「支持値ゼロ」の意味がやっと通じる。
- 4-5　名札のない化石の羽毛・毛・恒温を0と書き、ハトから押し出す→見えないとなかったは違う、`?` にする＝欠測。0で埋めると保存の偏りが進化の証拠に化ける（分からないものを魚の棚に入れるのと同じ病気）。クジラは骨の手掛かりが少なく独立目扱いだった、`?` ばかり。できる子から呼び出し。

## 第5幕　DNAが描き、また騙す
- 5-1　三つの池の12文字の配列で距離 $d$（東西1/12、東北3/12、西北2/12）。一匹ずつでは池内の違いと池間の違いを比べられない。北は別単位で守る理由が一票増えるだけ。
- 5-2　一万文字でDNAは完全な時計、案→同じ場所の二度の変化が隠れる多重置換・飽和。文字盤だけでは何周したか分からない。
- 5-3　クジラに最も近いのはカバ、偶蹄目の内側に入る（入れ子で単系統）→鯨偶蹄目（1997）。DNA計算違いを疑う→2001年、脚のある約5000万年前のクジラ化石の距骨が両端滑車型（偶蹄類の一度きりの発明）。別手段の証拠の一致。SINE/LINE の挿入は抜けない家紋、クジラとカバが共有。やらない夫が「急によくしゃべる」「こっちの話の方が性に合う」（7-4 の伏線）。イルカの札「鯨偶蹄目。カバに近い」。
- 5-4　遺伝子ごとに木が食い違う。硬貨で不完全系統ソーティング、遺伝子系統樹と種系統樹。DNAは裁判官でなく強い証人。
- 5-5　壁画の七本の帯にクジラが描けない。ランクは連続した枝分かれに人が引いた横線、単系統群は実在・ランクは目盛り（系統命名法の動き）。帯を消すと下が透ける＝ペンティメント、間違えた線を残す。ランクは m の目盛りのような便利な道具。引き出しの温泉の微生物マット写真、今夜は動物の話しかしていないと気づく。

## 第6幕　生命の樹に横線が入る
- 6-1　動く／動かないの二界→キノコ・ミドリムシ・粘菌で崩れ、ホイタッカーの五界説。モネラ界だけ分け方が違う。
- 6-2　核の有無が一番深い分かれ目か→「ないこと」は発明の印でなく原始形質かもしれない（背骨のない動物と同じ）。rRNA で全生命を同じ物差しに、ウーズ（1970年代）が古細菌を発見。三ドメイン。
- 6-3　根はどこか、全生命の外群はいない→共通祖先以前の遺伝子重複で片方をもう片方の外群に（1989年の二研究）。根は細菌側、古細菌と真核生物が姉妹。真核生物は古細菌の内側から、という見方が有力。
- 6-4　細菌の種はANI約95%。二系統の耐性遺伝子が数百文字一致＝収斂ではなく横に飛んだ。プラスミド、水平伝播。
- 6-5　接合・形質転換・形質導入（手渡し・落とし物拾い・宅配便、止め方が違う）。やらない夫「運び屋の仕事は地味だが確実」。壁の細い横線は遺伝子が枝から枝へ飛んだ線だったと気づき描き戻す（「好きにしろ」しか言ってない）。
- 6-6　ミトコンドリアは自前の輪状DNAで分裂する別会社＝取り込まれた細菌、葉緑体はシアノバクテリア、細胞内共生。真核生物の枝は根元でつながってできた。二枚札のかさぶたは地衣類（学名は菌に付ける）、はがさなくてよかった。どこからどこまでが一匹か、生き物か。

## 第7幕　試験管の中の池
- 7-1　6時半、黒い試料から魚・カエル・菌・細菌・ウイルスらしい配列。取り違えではなく、容器の数を生き物の数と思っていた。紫外線でラベル「POND-4 / 500 mL / filter」＝北の池の水を濾した環境DNA。「この試験管は何の種か」が問いの立て方違い、魚の棚が空になる。
- 7-2　希少ドジョウと99.2%一致、記録は途絶えていた。データベースは希少種12匹・近縁2匹・未命名近縁なし、82文字では種まで言えない。前に3回くんで出なかった：検出率0.4なら3回全部見逃す確率 $0.6^3=0.216$（独立でなければもっと高い）。配列の本数は個体数でない。出た→いる、出ない→いない、多い→たくさん、の三つとも言えない。
- 7-3　空のチューブ＝陰性対照から人のDNA、原因は素手とくしゃみのやる夫。除外できるのは対照を置いたから。「ウイルスらしい配列」の一部も人由来＝内在性レトロウイルス（ゲノムの約8%）、チンパンジーと同じ場所の挿入（クジラとカバと同型）。やる夫のは持つ人の少ない型、家族も持つ。
- 7-4　伏線を並べて気づく：親父にもその親父にも／子どものころから／目がない／風邪は三日で出ていく／挿入は抜けない話だけ楽しそう／運び屋の肩を持つ→やらない夫はやる夫の家系のゲノムに書き込まれた昔のウイルス。「気づいたか」。できる子「少し寝た方がいい。本当に」。

## 第8幕　生き物とは何か
- 8-1　増える（炎・結晶が入り、ラバが出る）、代謝（炎も）、設計図と写し間違いの選択＝進化。「ダーウィン型進化ができる自立した化学系」。ラバは集団として、休眠種子も自分で回り始める。
- 8-2　ウイルスは進化するが自立しない。石の棚の小瓶は「タバコモザイクウイルス結晶（複製）」、1935年スタンリー（後に針状の束・RNA含有と判明）。瓶の中ではモノ、葉の中では増える＝「今のところはな」の回収。巨大ウイルス、生き物とモノの線もグラデーション。札には「なぜそこに置いたか」を書く。
- 8-3　やらない夫は生き物かモノかやる夫の一部か、本人にも分からない。胎盤の合胞体層を作るシンシチンはレトロウイルス由来、ネズミ類は別のウイルスから別々に＝水平伝播で起きた収斂。「お前が母親の腹にいたとき、俺の仲間が壁を作っていた」。答えは何のために聞くかで変わる（宇宙探査／病院／展示の札）＝作業定義。生き物かどうかの欄は `?`、0でも1でもない。

## 終幕　開館ベル
- できる子が6時に刷った見出し「希少魚、発見」を、やる夫が「DNAが見つかった／今生きている／増えている」は別の段と止め、「希少ドジョウに似たDNA、北の池で検出。追加調査へ」へ。できる子「書いたら、もう一度水をくむ理由がなくなる」。来館者役のできる子に18秒で説明する練習。チワワとデーンは同じ棚、オオカミはすぐ隣（亜種か別種かで並び順は変わらない）。変わったのは頭骨でなく「何を見ないことにしたか」。ポスターを「更新中の生命史」へ貼り替え、七本の帯の跡の上に枝分かれを描き、前任者の横線をなぞり直し、最後に名前のない小さな印から哺乳類の枝へ細い一本（ウイルスから遺伝子が渡った線、やる夫にはもう一つの意味）。「名前を呼ぶ生き物なら誰でも毎日分類をしている。名前を呼ぶ口も持たないものを除いて」。「独り言じゃないお。……いや、独り言だお」。

## 依存
- やらない夫の正体（7-4）への伏線：1-1「親父にも、その親父にも」「目がない、お前の目で見ている」「幽霊じゃない、似たようなもんか」／2-4「子どものころから、たまに」／3-1「風邪の連中は三日で出ていく」／5-3 挿入の話だけ饒舌「性に合う」／6-5「運び屋の仕事は地味だが確実」／7-3 持つ人の少ない型・家族も持つ。どれかを削ると正体明かしの手掛かりが減る。8-3 のシンシチンと終幕の細い一本が回収。
- 試験管：1-1 素手で魚の棚 → 1-3「不明」で魚の棚の奥 → 3-5 POND＝池と気づき届ける・くしゃみ → 7-1 環境DNA → 7-3 陰性対照に素手とくしゃみの人DNA。3-5 のくしゃみと素手を消すと 7-3 が成り立たない。
- 空のチューブ：2-4「空。だから大事」→ 3-5 並べて開ける → 7-3 陰性対照。
- 小瓶「1935」：1-1「石の棚でいい。今のところはな」→ 8-2 タバコモザイクウイルス結晶で回収。
- 壁の横線：1-2 で一本塗る（やらない夫「消すのか」）→ 6-5 遺伝子が枝から枝へ飛んだ線と気づき描き戻す → 終幕でなぞり直し＋一本追加。3-4 の七本の帯 → 5-5 消してペンティメント → 終幕で跡の上に描く。
- 「支持値ゼロ」（1-2）→ 4-4 ブートストラップで意味が通じる。支持値の定義を変えたら両方直す。
- 収斂の反復：1-2 サボテン／トウダイグサ・サメ／イルカ → 4-1 → 4-4 翼と恒温の二票 → 6-4 耐性遺伝子（収斂ではなく水平伝播）→ 8-3 シンシチン（水平伝播による収斂）。
- 二枚札のかさぶた：3-2 で保留 → 6-6 地衣類で回収。脚の折れた甲虫（3-2）はホロタイプ。
- 三つの池のドジョウ：2-4 保護予算300万・1種か3種か → 5-1 12文字の距離 → 5-2 → 7-2 北の池の希少ドジョウ99.2% → 終幕の見出し。300万・80万・西の池の工事の数字は 2-4 だけで使うが、終幕の申請の話とつながる。
- 4-4 の形質表と回数（木B 4対6、コウモリ追加後 8対7、窓2行追加後 10対11、ブートストラップ10回中7回）は表の値と連動。形質を足し引きしたら全回数とブートストラップ表をやり直す。
- 欠測 `?`（4-5）は 8-3 の「生き物かどうかの欄は `?`」で再使用。「分からないものを魚の棚に入れる」病気（1-3・4-5）とも対。
- 四つの問い（1-3 同定・命名・系統・保全・予測）は 2-4（保全単位）、3-1（命名）、4-5〜5-3（系統）、7-2（同定の限界）、8-3（作業定義）で順に使う。
- 外群（4-3）は 6-3 で「全生命の外群はいない」→ 遺伝子重複で回収。
- チワワ・デーン・オオカミの頭骨：1-1 で別棚 → 2-1 犬とオオカミ → 3-3 学名の揺れ → 終幕で並べ直し。
