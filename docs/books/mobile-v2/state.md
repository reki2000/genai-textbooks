# mobile-v2 執筆状態台帳

## 制約

- 新規長編。高校数学の対数、ベクトル内積、簡単な確率を会話内で足場づくりする。
- 地の文なし。状況、作業、感情は台詞で示す。
- 技術史は比較判断に必要な範囲だけにし、全体の15%以内。
- 追跡対象はG-01から舞台監督きらきーの端末までの12秒音声。

## 固定トイと数値

- 架空会社名：星環通信。
- G-01：金色の診断端末。初期表示は電波5本、`scheduler wait` 点滅。
- 原音：「もしもし、焼きそばは塩。星図を開いてください」。長さ12秒。
- 12ビット列：`101101001011`。
- 会場5万人、初期割当帯域20 MHz。
- 五地点：会場中央、地下通路、丘裏、移動バス、沖の連絡船。
- 利用者A：12秒音声、B：写真、C：動画。後半で制御信号と緊急連絡を追加。
- 12升の資源盤：時間4列×周波数3行。

## 幕ごとの到達点と現在位置

- 第1幕：品質指標と五層追跡票を作る。完了。
- 第2幕：標本化、量子化、変調、SNR、シャノン容量。完了。
- 第3幕：伝搬、フェージング、ISI、ドップラー、OFDM、MIMO。完了。
- 第4幕：誤り検出、ARQ、FEC、インターリーブ、サービス別判断。完了。
- 第5幕：FDMA/TDMA/CDMA/OFDMA、公平性、QoS。完了。
- 第6幕：セル、再利用、配置、ハンドオーバ、コア網、復旧。完了。
- 第7幕：世代を共通基盤と移行可能性で比較し、相互接続と調達を判断。完了。
- 第8幕：GEO/LEO、スポットビーム、地上・非地上網の束ね方。完了。
- 終幕：既知の道具だけで三重障害を切り分け、12秒を届ける。完了。

## 定義済み用語・記号

- 品質：受信電力、接続成功率、開始遅延、完走率、同時利用者、電池、復旧時間を分離。
- 五層追跡票：音声、ビット、無線ブロック、パケット、セッション。
- $\lambda=c/f$。900 MHzの波長約0.333 m、半波長約16.7 cm。
- 標本化定理：帯域上限$B$に対し$f_s>2B$。8 kHz×8 bitで64 kbpsのPCMトイ。
- 64 kbps PCMは12秒768,000 bit、12 kbps音声圧縮は144,000 bit。音質・遅延と交換。
- BPSK、QPSK、QAM、適応変調、SNR。
- シャノン容量：$C=B\log_2(1+S/N)$。1 MHz、S/N=10で約3.46 Mbit/s。
- 対数距離モデル：$P_r(d)=P_r(d_0)-10n\log_{10}(d/d_0)$ dB。会場実測$n\approx3.3$。
- 900 MHz半波長約16.7 cm、3.5 GHz半波長約4.29 cm。
- 丘裏の追加遮蔽トイ：900 MHz 18 dB、3.5 GHz 27 dB。回折と帯域の条件を分離。
- ISI、OFDM、CP。有効記号10 μs+CP 3 μsで有効率約0.769。
- 最大ドップラー$f_D=(v/c)f_c$。40 km/hで900 MHz約33.3 Hz、3.5 GHz約129.5 Hz。
- MIMO：$\mathbf y=\mathbf H\mathbf x+\mathbf n$。本数と空間ランクを区別。
- ARQトイ：BER 0.001、1000 bitで一回成功約0.368、平均送信2.72回。
- パリティ、ハミング距離、FEC、インターリーブ、時間・周波数・空間ダイバーシチ。
- 率1/2畳み込み符号トイ：$(u_k,u_k\oplus u_{k-1})$。LDPCとポーラは構造の直観まで。
- 12升：時間4×周波数3。A音声、B写真、C動画。
- CDMAトイ：a=(1,1,1,1), b=(1,-1,1,-1)、内積0。近遠問題と同期ずれ。
- OFDMA、スケジューラ、比例公平、QoS。最大速度配分の飢餓を反例化。
- 7セル同周波数再利用トイ：理想4,200人相当、実測2,730人相当。
- 20 MHz、S/N=10の理想上限69.2 Mbit/s。5万人均等で1人1,384 bit/s。
- 会場配置トイ：マクロ2、スモール6、丘裏小局1、地下DAS。1億8,400万円。
- 複信：FDDとTDD。開場30秒を上り8/下り4へ寄せ、隣接セルと同期。
- ハンドオーバ：測定→報告→目標準備→指示→同期・経路切替→解放。3 dB/500 msトイ。
- RANとコア網を分離。加入者識別、認証、移動管理、セッション、ルーティング、方針。
- 縮退運転：光断から23秒で音声再開、動画31%、写真待ち42秒。
- 世代比較：音声→デジタル→データ→IPパケット統合→サービス分化の設計境界として扱う。
- 調達三案：甲41.25、乙86.25、丙71.25点。重みは判断条件の露出用。
- GEO：高度約35,786 km、真下片脚約119 ms、地上間一方向最小約239 ms、対話往復約477 ms。
- LEOトイ：高度550 km、真上片脚約1.83 ms、上下二脚最小約3.67 ms。
- 自由空間損失：$L_{FS}=20\log_{10}(4\pi d/\lambda)$ dB。
- 可用性：99%は年87.6時間、99.9%は8.76時間の停止許容。共通原因も検査。
- 最終障害：中央写真2.4倍、主光断、船の衛星ビーム境界。既知の道具だけで解決。

## 伏線

- `scheduler wait` → 第5幕で資源待ちとして回収、第6幕でコア網待ちとの切り分けを追加。
- 六角形ステッカー → 第6幕のセル設計で回収。
- 連絡船だけ遅れる録音 → 第8幕の衛星経路で回収。
- 地下の反射で音が良い一点 → 第3幕の空間ランクで回収。
- 「最高音質より12秒全部」 → 第4幕と終幕の縮退判断で回収。
- `G-02 月面中継` → 終幕最後。

## 反復ギャグ

- 6本目のアンテナを指で書き足そうとする。
- 出力10倍の請求書が、電池、干渉、免許、熱から届く。
- 大型LED予測盤の外れ値を体で隠そうとし、別画面へミラーされる。後半は自分から予測値と外れた理由を入力する。
- 誤りで焼きそばの味が変わる。終幕だけ「塩」が正しく届く。

## 幕末コーナーと幕間

- 同名コーナー：各主要幕終盤の「十二秒を追う」。過去の道具を累積適用する。
- 幕間1（第3幕後）：まとめ＋別事例への転移。
- 幕間2（第6幕後）：統合クイズ＋次の調達問題を起動。
- 第1幕「十二秒を追う」：中央のscheduler wait、バス1ビット誤り、パケットとセッション未観測。
- 第2幕「十二秒を追う」：標本化→ビット→変調記号を追跡。丘裏の伝搬問題を次へ。
- 第3幕「十二秒を追う」：地下・バスの伝搬を改善、丘裏と船遅延は未解決。
- 幕間1：駅コンコースへ伝搬診断を転移。機能2を実施。
- 第4幕「十二秒を追う」：バスの味噌→塩を訂正。中央のscheduler waitは残る。
- 第5幕「十二秒を追う」：scheduler waitをOFDMAとQoSで23.1秒→3.9秒。
- 第6幕「十二秒を追う」：コア網と回線断を含め中央4.4秒。船の0.6秒と相互接続が残る。
- 幕間2：三障害カードの統合クイズ。機能1・3を実施。調達問題を起動。
- 第7幕「十二秒を追う」：他社端末の能力交換・認証・ローミングで4.9秒完走。
- 第8幕「十二秒を追う」：五地点すべて開始5秒以内、完走、意味誤りなし。
- 終幕：音声→無線→予備回線→冗長コア→地下相手、船はLEO A→B。塩を正しく回収。
