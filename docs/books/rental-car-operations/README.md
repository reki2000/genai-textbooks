# やる夫が業務改善室を半年で根付かせるようです ── レンタカー業務のBPR・失敗学・自動化・AI・CoE

---
## 登場人物

**やる夫**：
ホライゾンレンタカー法人車両運用チームの事務担当。
予約変更、車両状態、法人契約、月次請求の間を走り回っている。
社内で一番処理が速く、Excelとマクロに強い。

**やらない夫**：
本社で事故調査を担当している。
元店舗責任者。
肩書を嫌う。

**できる子**：
空港店の配車リーダー。
空港店・駅前店・郊外店の三店舗で車を融通する調整も担っている。

**できる夫**：
エンジニア部門のリードエンジニア。
決済基盤とセキュリティ更新を抱え、いつも開発枠が空いていない。

## 第0幕　一番速い男が室長になる

---
### 0-1　返した車が、まだ走っている ── 四つの現実

**やる夫**：
終わったお。
北斗フーズの宮本さんから、朝一番で怒りの電話だお。
7月31日に返した営業車に、返却後もまだ料金が付いてる。
しかも今朝、同じ車を別の営業さんに使わせようとしたら、店に「まだ貸出中だから出せない」と言われたらしいお。
請求と配車が同時に壊れるなんて、逆に芸術点が高いお……。

**やらない夫**：
朝から芸術鑑賞とは優雅だな。
事故調査の依頼票が俺のところにも回ってきた。
「北斗フーズの車」とだけ書いてある。
それで、どの車だ。

**やる夫**：
契約番号は `HKT-2407-008`、車両は `CAR-0427`、青いミニバンだお。
電話メモでは、7月30日に一日延長して、返却は7月31日。
提携先の返却画面では、7月31日18時12分に返却済み。
でも資産管理システムはまだ貸出中、会計は8月分の課金を続けてて、やる夫のExcelは予定どおり返却済みだお。

**やらない夫**：
一台の車に、四つの現実があるわけだ。
どれが本当だ。

**やる夫**：
現物の車は空港店にあるから、返却済みが本当だお。
なら資産管理と会計を直して、請求書を再発行すれば終わりだお。
やる夫の高速修正術で10分、宮本さんの怒りも10分で鎮火、今期の社長賞はやる夫のものだお！

**やらない夫**：
もう受賞式か。
直すのは止めない。
ただ、10分で直した後、来月も同じ電話が来ない理由はあるか。

**やる夫**：
誰かが更新を忘れたからだお。
たぶん提携先の返却を見た担当者が、資産管理の「返却確定」を押し忘れたんだお。
人間の注意不足だお。
押し忘れた人を見つけて、注意すれば来月は来ないお。

**やらない夫**：
犯人を一人にすれば話は早いな。
ところで、7月30日に延長の電話を受けたのは誰だ。

**やる夫**：
……やる夫だお。
CRMにメモしたお。
予約SaaSの返却日も延ばしたお。
提携先の画面にはやる夫の権限がないから、Slackで空港店に「延長です、お願いします」と連絡したお。

**やらない夫**：
店は何と返した。

**やる夫**：
スタンプが一個付いてるお。
これは……見た、了解、処理済みのどれだお？
うぐぐ、意味が決まってないお。
やる夫、スタンプ一個で安心して、その先を見てなかったお。

**やらない夫**：
注意不足という説明が、自分の足元から崩れたな。
もう一つ聞く。
提携先の返却データは、何時に社内へ入る。

**やる夫**：
毎晩2時の一回だけだお。
で、7月の請求締めは7月31日の22時……あっ。
返却は18時12分、締めは22時、返却データが社内に入るのは8月1日の2時。
**返却データが届く前に、請求を確定してる**お。
しかも2時に届いても、資産管理の返却確定は朝に人が手で押す仕組みだお。

**やらない夫**：
押し忘れた担当者は、今朝の9時に出勤したばかりかもしれないな。

**やる夫**：
犯人扱いしかけた人は、まだ押す機会すらなかったかもしれないお……。
電話、Slack、夜2時の取込、22時の締め、朝の手作業。
時刻が噛み合わない仕事を、誰かが覚えて橋渡しする前提で回してたお。

**やらない夫**：
では請求の訂正は俺も見る。
訂正額は、延長を含めて7月31日まで、それ以降の課金は取消。
顧客への連絡は──。

**やる夫**：
あれ、内線だお。
……はい、法人車両運用チームのやる夫だお。
……社長室？
今すぐ？
やらない夫も一緒に？

### 0-2　室長やる夫と、兼務の男 ── 速い人に集まる仕事

**やる夫**：
社長室から戻ったお。
信じられないお。
今朝の経営会議で、業務を良くして自動化も進める新しい組織を作ると決まったお。
名前は「業務改善室」。
社長は横文字で「うちにもCoEが要る」と言ってたお。
そして室長は……やる夫だお！

**やらない夫**：
社長が理由を言っていただろう。

**やる夫**：
「社内で一番処理が速いと聞いた。一番速い者に任せる」だお！
ついにやる夫の時代だお。
改善室は全社の難問を解く帝国になり、やる夫は初代皇帝、名刺も「CoE初代皇帝」で刷るお。

**やらない夫**：
俺は事故調査から兼務で出される。
週の半分だ。

**やる夫**：
やらない夫が部下……いや、年も経験も上だし、室長の椅子はやらない夫のほうが似合うお。
譲るお？

**やらない夫**：
要らん。
肩書は嫌いだ。
兼務で十分だ。

**やる夫**：
即答だお。
それと、社長は条件も付けたお。
猶予は半年。
来年1月の取締役会で成果を示せなければ、改善室は解散。
代わりに外部コンサルが出している「基幹システムの一括更改と事務の委託」の案へ切り替えるらしいお。
5年で総額約14億円、事務チームの大半は委託先へ移る案だお。

**やらない夫**：
つまり、お前の古巣のチームも賭け金に載っている。

**やる夫**：
……そうなるお。
だから半年で結果を出すお。
作戦は決めてあるお。
四つのシステムからCSVを落として、やる夫のExcelへ集めるお。
車両IDで突合するマクロを書けば、今朝の `CAR-0427` みたいな食い違いを赤く塗れるお。
全社分をやる夫が毎朝回せば、改善室の成果は初週から出るお！

**やらない夫**：
赤く塗るところまでは悪くない。
そのExcelを、お前が休んだ日は誰が回す。

**やる夫**：
隣の席の同僚に頼むお。

**やらない夫**：
マクロが止まったら。

**やる夫**：
やる夫へ電話だお。
リゾート地からでも直せるお。
世界を救うエンジニアみたいで格好いいお。

**やらない夫**：
休暇中まで呼ばれるのを格好いいと思えるうちは幸せだな。
お前は今、四つのシステムの間にあった手作業を、五つ目のシステム、つまりお前個人へ集めようとしている。
それで会社の力は上がるか、それともお前への依存が上がるか。

**やる夫**：
……依存が上がるお。
でも、やる夫が一番速いんだから、任せるのが効率的だお。

**やらない夫**：
今朝の件を調べるついでに、お前のチームの業務ログを借りた。
昨日のお前は8時間のうち、請求の修正に2時間、問い合わせに2時間、検索と確認に2時間、通常の処理に2時間だ。
通常の処理は一件5分だな。

**やる夫**：
8時間全部を通常処理に使えたら96件、実際は2時間だから24件だお。
一番速いやる夫が、一日の四分の一しか速い仕事をしてないお。

**やらない夫**：
残りの6時間は、どこから来た。

**やる夫**：
問い合わせが多いから……いや、それは言い換えただけだお。
請求の修正も、確認も、「やる夫なら分かる」って回ってくるやつだお。
速く処理するほど、食い違いの確認や直しがやる夫へ集まってくるお。
やる夫が速いせいで、何でもやる夫待ちになってるお。

**やらない夫**：
社長は、取締役会で何を問うと言っていた。

**やる夫**：
三つ言ってたお。
手帳に書いたお。
一つ目、「一番速い担当者がいるのに、なぜ仕事は遅れるのか」。
二つ目、「確認欄を三つ増やしたのに、なぜ誤請求は減らないのか」。
三つ目、「CoEとは、できる人が仕事を代行する中央部隊なのか」。
三つ目の答えは「はい」だと思ってたお。
やる夫が全部の難問を解けば……一つ目と同じ匂いがしてきたお。

**やらない夫**：
その匂いを覚えておけ。
答えは今は要らん。
それより、社長室の帰りに総務から鍵を渡されただろう。

**やる夫**：
改善室の部屋だお。
地下の倉庫の隣だお。
さっそく片付けに行くお。

**やらない夫**：
段ボールの山だな。
前の住人の置き土産か。

**やる夫**：
段ボールの奥から、何か出てきたお。
木の表札だお。
「業務改革推進室」。
埃だらけで、字もかすれてるお。
うちの会社、昔にも似た部屋があったのかお？

**やらない夫**：
捨てとけ。

**やる夫**：
即答だお。
8年前の日付の紙も挟まってるお。
遺跡だお。
まあいいお、新しい表札はやる夫が作るお。
入口の貼り紙は、やらない夫が書いてくれたお？

**やらない夫**：
「相談はここへ」とだけ書いた。

**やる夫**：
やらない夫の字、手偏がやたら長くて、「推」も「掃」も読みにくいお。
まあ、読めればいいお。

**やらない夫**：
読めれば十分だ。
今日はもう帰れ。

**やる夫**：
一夜明けて、宮本さんからメールが来たお。
読み上げるお。
「昨日の訂正はありがとうございました。ただ、九月の法人契約の更新では、他社への切替も比較します。車が使えず、請求も説明できない状態が続くなら、価格だけでは継続を判断できません」。

**やらない夫**：
北斗フーズの営業車は12台だったな。

**やる夫**：
うちの法人顧客で一番大きいお。
取締役会の前に、九月の締切が来たお。
改善室の最初の案件は、北斗フーズの延長一件を、電話から請求まで追うことにするお。
