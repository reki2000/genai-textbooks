# やる夫がキリスト教の教材をつくるようです ── 「愛と分裂」を読み解く

---
## 登場人物

**やる夫** ── 出版社の新企画を任された編集者。宗教は初詣、墓参り、クリスマスを適当に組み合わせればよいものだと思っている。複雑な話をすぐ3分類にまとめたがる。

**やらない夫** ── 世界史教材の監修者。宗教を信仰の当否ではなく、歴史と制度として扱う。

**できる子** ── 統計、史料、教義用語を確認する調査担当。

**できる夫** ── 歴史再現映像の演出担当。理解は速いが、大河ドラマと少年漫画の名場面を、時代も地域も無視して持ち込みたがる。

**マリア** ── フィリピン出身のカトリック信者。口癖は「うちのナナイ（母）が言うには」。教皇を尊敬しているが、日常でははるかに家族と村の教会の方が近い。

**ニコラオス** ── ギリシャ出身の東方正教会信者。誇り高く、芝居がかった大声。時間の単位はいつも「千年」。正教会を「教皇のいないカトリック」と説明されると本気で傷つく。

**テクレ** ── エチオピア正教会の信者。声は小さく、間が長い。答えではなく質問を返す。

**ハンナ** ── ドイツ出身のルター派信者。徹底した史料主義。ルターを尊敬しているが、欠点を隠す気は一切ない。

**グレース** ── ナイジェリア出身のペンテコステ派信者。声が大きく、感情の振れ幅も大きい。理屈より、自分が見てきたことを先に語る。

**ダビデ** ── ユダヤ教徒。皮肉屋で、質問には質問で返す。「その話、うちでは2000年やっています」が口癖。

## 第1幕　キリスト教徒を数えたら100%を超えた

---
### 1-1　世界最大の宗教なら、3つに分ければよい

**できる夫**：
新企画、発表します！
題して、高校世界史副教材、世界最大の宗教を60分で完全理解！
冒頭では巨大な円グラフが回転し、中央から教皇が登場します！

**やる夫**：
完璧だお！
キリスト教はカトリック、プロテスタント、正教会の3つだお。
世界のキリスト教徒を赤、青、緑に塗れば終わりだお！

**やらない夫**：
数字は調べたのか。

**やる夫**：
調べたお。
世界のキリスト教徒について、比較しやすい2010年基準の調査では、カトリックがおよそ50%、広い意味のプロテスタントが37%、正教会が12%、その他が1%だお。
ほら、100%になったお！
美しいお！[^1]

**できる子**：
分類名に注意。
その調査の「プロテスタント」は、歴史的な宗教改革系教会だけを指していない。
聖公会、独立教会、その他の西方キリスト教系集団を広く含む場合がある。

**やる夫**：
広い意味なら広いほど便利だお。
細かいものは全部プロテスタント箱に入れるお。

**テクレ**：
……一つだけ、伺ってよいですか。
その3色の円の、どこに私の教会が入りますか。

**やる夫**：
エチオピア正教会だから、緑の正教会だお。
ギリシャ正教会やロシア正教会の仲間だお。

**テクレ**：
仲間ではありません。
エチオピア正教会は、一般に東方正教会と呼ばれる教会群とは別の、東方諸教会に属します。
カルケドン公会議を受け入れたかどうかという、5世紀以来の違いです。

**やる夫**：
正教会の中に、正教会じゃない正教会があるのかお！？

**ニコラオス**：
まず、訂正させてください。
中に入っているのではありません。
別なんです。
日本語訳が似ているだけで、英語では Eastern Orthodox Churches と Oriental Orthodox Churches を区別します。
ギリシャ、ロシア、セルビアなどの教会と、コプト、アルメニア、エチオピア、シリアなどの教会は、千五百年ほど別の交わりにありました。

**やる夫**：
じゃあ正教会を2つに割ればいいお。
カトリック、プロテスタント、東方正教会、東方諸教会の4つだお。

**グレース**：
ねえ、聞いてください。
私はペンテコステ派です。

**やる夫**：
はい、プロテスタント箱だお。

**グレース**：
たいていはそう分類されます。
でも、ペンテコステ派と同じように祈り、聖霊の働きを求める人たちは、カトリックの教会にも聖公会の教会にもいるんです。
私の従姉がそうです。
彼女はカトリックのまま、私たちと同じように手を上げて祈ります。

**やる夫**：
カトリックなのにペンテコステ的……？
1人を赤と青の両方に塗るのかお？

**ハンナ**：
福音派も同じです。
ルター派、改革派、バプテスト、聖公会、無教派を横断します。
その円グラフは、切り口の違う分類を一つの円に混ぜています。

**やる夫**：
待つお。
教派と運動が別軸なら、福音派を足したら100%を超えるお。

**できる子**：
超えて当然。
所属教会、神学的伝統、礼拝形式、運動、個人の自己認識を、同じ排他的カテゴリーとして加算している。

**やらない夫**：
お前はソフトウェアを、プログラミング言語だけで分類するか。

**やる夫**：
しないお。
OS、言語、フレームワーク、ライセンス、運用主体は別軸だお。

**やらない夫**：
宗派も同じだ。
カトリックと東方正教会は、大規模な教会共同体の系列だ。
ルター派やバプテストは教派の家系だ。
福音派は複数の教派を横断する傾向だ。
ペンテコステ派は教派でも運動でもあり得る。
無教派教会にも、実際には歴史的な神学の系譜がある。

**やる夫**：
つまり、円グラフ1枚で完全理解という企画が、開始5分で死亡したお……。

### 1-2　宗派の数は、なぜ資料ごとに違うのか

**やる夫**：
なら宗派一覧を作るお。
世界には数万の宗派がある、と書けば複雑さが伝わるお。

**できる子**：
その数字も定義次第。
国ごとに別法人の同一教派を別宗派として数える統計もある。
逆に、内部差が大きくても一つの世界教会として数える場合もある。

**やる夫**：
じゃあ「宗派数」は、GitHubのリポジトリ数みたいなものかお。
同じソフトの各国ミラーを別プロジェクトとして数えたら、一気に増えるお。

**やらない夫**：
近い。
さらに、フォークした後に再統合した教会、合同教会、独立した地域教会、同じ名称でも無関係な教会がある。

**マリア**：
カトリックは巨大な一つの教会と言えます。
ただ、中はラテン典礼だけではありません。
東方典礼の諸教会もあって、同じ教皇との交わりにありながら、典礼も教会法も聖職者の慣習も違います。
うちのナナイは、隣町のその教会のミサに行って、途中で自分の教会と全然違うことに気づいて固まったそうです。

**ニコラオス**：
東方正教会は、コンスタンティノープル総主教を全世界の支配者とは考えません。
ギリシャ、ロシア、セルビア、ルーマニアなどの独立教会が、共通の信仰と秘跡を持ったまま、それぞれ自分を治めます。

**やる夫**：
本社が支社に命令するカトリックと、本社のないフランチャイズの正教会だお。

**ニコラオス**：
まず、訂正させてください。
その比喩だと、私たちが契約でブランドを共有している会社に見えます。
私たちにとって一致とは、商標ではありません。
同じ信仰、同じ聖餐、司教同士の交わりです。

**やる夫**：
比喩が3行で壊れたお。

**ハンナ**：
プロテスタントも「教皇に反対する人々」という一枚岩ではありません。
ルター派は宗教改革以前の典礼や信条を多く保持します。
改革派は神の主権や説教を強調します。
聖公会は司教制度と典礼を保ちつつ、宗教改革の影響を受けています。
バプテストは本人の信仰告白に基づく洗礼と地域教会の自治を重視します。
メソジストは信仰が生活の変化へ結びつくことを強く求めます。
メノナイトなどは非暴力と共同体倫理を重視します。

**グレース**：
私たちの入口は、まず文書ではありません。
回心、癒やしを求める祈り、自分に起きたことを人前で語ること、体ごと参加する礼拝。
そこから信仰が実感になります。
ただし、うちの教会と、隣の州のペンテコステ教会で、政治の話も運営のやり方も全然違います。
一つにまとめられると、こちらも困ります。

**やらない夫**：
整理しろ。
世界のキリスト教を理解する最低限の地図は何だ。

**やる夫**：
こうだお。

| 分類軸        | 例                        |
| ---------- | ------------------------ |
| 大きな教会共同体   | カトリック、東方正教会、東方諸教会        |
| 宗教改革後の教派家系 | ルター派、改革派、聖公会、バプテスト、メソジスト |
| 横断的運動      | 福音派、カリスマ運動               |
| 礼拝・霊性の傾向   | 典礼的、福音派的、ペンテコステ的、修道的     |
| 統治方式       | 教皇中心、司教会議、教派本部、地域会衆自治    |
| 生活上の所属     | 熱心な実践者、文化的所属、名目的所属、無所属   |

**やらない夫**：
それなら、1人が複数の欄に入っても矛盾しない。

**やる夫**：
キリスト教徒は3色の円グラフではなく、多次元データだったお……。

### 幕間I　ニケーア公会議――神学者の言葉遊びだったのか

**できる夫**：
再現映像、紀元325年！
場面はお白洲です！
白砂に引き出されたアリウス、上段の間に皇帝コンスタンティヌス！
桜吹雪の彫り物をちらりと見せて、これにて一件落着！

**やらない夫**：
遠山の金さんをニケーアへ連れて行くな。

**できる夫**：
親しみやすさのためです！
皇帝が扇を振り下ろして叫びます。
アリウス派、異端。
全員、島流しである！

**ハンナ**：
史料にはありません。
公会議は皇帝の一喝で終わっていません。
数か月がかりの議論と交渉があり、追放された指導者は数年後に呼び戻されてもいます。

**できる夫**：
……尺が、削れます。

**やらない夫**：
尺の前に中身だ。
そこで何が争われていた。

**できる夫**：
キリストが父なる神と同一の本質か、似た本質かです！
ギリシャ語では、イオタが1文字入るかどうかの差です！

**やる夫**：
1文字かお。
その1文字のために、帝国中の司教を旅費つきで集めたのかお。
昔の神学者は暇だったんだお。
やる夫なら両方の綴りを併記して、注釈で逃げるお。

**やらない夫**：
お前は日曜の朝、誰に向かって膝をついてる。
そういう問いなんだよ。

**やる夫**：
神に祈るお。

**やらない夫**：
では、イエスに祈るという行為は何だ。
イエスが神に造られた最高の存在にすぎないなら、お前は今、何を拝んでいる。

**やる夫**：
……あ。
造られたものを拝んでるお。
唯一神を信じてるつもりで、被造物を神の席に座らせてたことになるお。
それ、この宗教で一番やってはいけないやつだお。

**ハンナ**：
反アリウス側にとって、それは学説の勝ち負けではありませんでした。
イエスが完全な神でなければ、毎週の礼拝がそのまま偶像崇拝になる。
神だけが人を救えるのなら、救いの根拠そのものが抜け落ちます。

**ニコラオス**：
まず、訂正させてください。
私は暇つぶしの1文字を歌っているのではありません。
父と同一本質。
私はその文を、日曜ごとに歌います。
千年ではききません。
1700年、同じ言葉を、同じ旋律で。

**やる夫**：
……ごめんだお。

**マリア**：
うちのナナイが言うには、祖母が息を引き取る前に唱えていたのも、その信条だったそうです。
意味を全部説明できた人ではありません。
それでも、最後に握って離さなかった言葉が、あの会議で決まった一文だったんです。
……そういうものなんです。

**ニコラオス**：
一方で、アリウス側にも守りたいものがありました。
父なる神が唯一で、絶対的で、何にも由来しないこと。
彼らを「イエスを見下した悪役」にすると、この論争の張りつめた感じが全部消えます。

**テクレ**：
……一つだけ、伺ってよいですか。
私の教会も、同じニケーアの信条を唱えています。
第1幕で私たちが別の交わりだと申し上げたのは、この公会議ではありません。
その次の、カルケドンです。

**やる夫**：
待つお。
ここは分裂の起点じゃなくて、今も全員が共有してる床の方だったのかお。

**できる子**：
皇帝の動機も純粋な神学だけではない。
帝国内で拡大した教会が割れれば、統治の統合にも響く。
公会議は教義を定める場であると同時に、帝国秩序の問題でもあった。

**やる夫**：
上段の間の一喝じゃないお。
毎週祈ってる相手が誰なのかという信者の問題が先にあって、そこが割れると帝国まで割れるから、皇帝が会議の費用を出したお。
神学と政治が別々の話なんじゃなく、同じ一枚の紙の表と裏だったお。

**やらない夫**：
高校世界史では「アリウス派を異端とした」の一行で終わる。

**やる夫**：
その一行の下に、膝をついた人が何百万人もいるお。
……台本、書き直すお。

### 2-1　善行ポイントを貯めれば天国へ行けるのか

**やる夫**：
宗派は複雑でも、教えの中心は簡単だお。
悪いことをせず、良いことをして、死後に天国へ行く。
世界共通の道徳ポイント制度だお。

**やらない夫**：
では、十分なポイントは何点だ。

**やる夫**：
殺人は大幅減点、親切は加点、寄付も加点、日曜礼拝は連続ログインボーナスだお。

**マリア**：
その説明だと、神は採点機です。
賽銭箱に硬貨を入れると点が出てくる機械です。

**やる夫**：
宗教なんだから採点するんじゃないのかお。

**ハンナ**：
キリスト教が最初に言うのは、努力すれば合格点に届くという話ではありません。
逆です。
人間は自分の努力だけでは、神との壊れた関係を直しきれない、という診断から始まります。

**やる夫**：
最初から全員不合格なのかお。
厳しすぎるお。

**やらない夫**：
何が不合格なのかを考えろ。
罪とは犯罪一覧だけか。

**やる夫**：
嘘、盗み、暴力、不倫みたいな禁止事項だお。

**やらない夫**：
それだけなら、法律を守る人間は神を必要としない。

**グレース**：
罪は、やった行為の一覧ではありません。
自分を人生の最終決定者の席に座らせている状態のことです。
その席に座り続けた結果が、他人の利用、傲慢、無関心、恐怖、支配として出てきます。

**やる夫**：
OSの設定が根本からずれていて、その上で動くアプリにも不具合が出る感じかお。

**やらない夫**：
その比喩なら使える。
個別の悪事はログに現れた障害だ。
根には、神、他者、自分、世界との関係の破損がある。

**マリア**：
だから救いは、善行ポイントで代金を払うことではありません。
神の側から先に手が伸びる。
順番が逆なんです。
うちのナナイの言い方だと、勘定を済ませてから家に入るんじゃなくて、玄関で抱きしめられてから話が始まるんです。

**やる夫**：
それなら悪いことをしても、最後に赦してくださいと言えば得だお。

**やらない夫**：
謝罪と赦しを、処罰回避コマンドだと思っているな。
お前が誰かを傷つけ、口で謝っただけで同じことを続けたら、関係は回復したと言えるか。

**やる夫**：
言えないお。
被害の認識、方向転換、償いが要るお。

**ハンナ**：
キリスト教でも、赦しは悪事を無かったことにする免許ではありません。
神の恵みを受けた人間が、悔い改め、他者との関係を変えていくことが求められます。

**やる夫**：
善行は救いを買う料金じゃなく、救いを受けた結果として現れる、という順番なのかお。

**やらない夫**：
そこが宗教改革で激しく争われ、今も宗派によって説明の重点が異なる点だ。

### 2-2　十字架と復活は何を解決するのか

**やる夫**：
でも十字架は分かりにくいお。
神が全能なら、普通に赦せばいいお。
なぜイエスが処刑される必要があるんだお。

**やらない夫**：
お前は、赦しには費用がかからないと思っているのか。

**やる夫**：
言葉で「いいよ」と言えば無料だお。

**やらない夫**：
会社の重大事故で、被害者への補償をせず「許してください」と言えば済むか。

**やる夫**：
済まないお。
誰かが損失を引き受けるお。

**マリア**：
十字架の説明は、一つではありません。
罪の結果をキリストが引き受けたという説明。
悪と死の力に勝ったという説明。
神の愛を見せて人間を変えるという説明。
人間と神を和解させるという説明。
どれか一つだけが正解、という形にはなっていません。

**ニコラオス**：
東方では、罪を法廷の有罪判決としてだけ語りません。
病であり、死の支配です。
ですから救いも、無罪放免ではなく、治療であり、人が神の生命に与ることです。
私たちの復活祭の歌は、こうです。
死を、死によって踏みにじり。

**ハンナ**：
西方では罪責、義認、赦しという法廷の言葉が強く出ます。
ただし、西方にも癒やしと一致の伝統はあります。
どちらが本物かではなく、どの語彙が前に出るかの違いです。

**やる夫**：
同じ十字架でも、裁判、医療、戦争、和解の比喩が重なっているのかお。

**やらない夫**：
そして十字架だけで終わらない。
復活がなければ、正しい人が国家権力に殺されて終わった話になる。

**グレース**：
復活は、死と悪に最終決定権はない、という宣言です。
アーメン！
だから私たちの希望は、魂だけがこの世界から避難することではありません。
神が人も世界も建て直すという期待です。
葬式で歌う歌が、勝利の歌になるのはそのためです。

**やる夫**：
日本人の感覚だと、宗教は心を落ち着かせたり、死者を供養したり、人生を受け入れたりするものに見えやすいお。
キリスト教は、壊れた世界が最後に修復されるという、歴史全体の話なのかお。

**やらない夫**：
そうだ。
創造、破損、契約、キリスト、救済、完成という直線的な物語を持つ。

**やる夫**：
人生相談サービスだと思っていたら、宇宙史の再建プロジェクトだったお。

### 幕間II　迫害された宗教が帝国の宗教になる

**できる夫**：
次の映像です！

キリスト教徒は宗派で細かく分かれすぎだお。

2023年の調査では、日本の成人の85%が家族の墓を持ち、79%が過去1年間にその墓を清掃したと回答した。祖先に関わる実践は、特定宗教に所属しない人々にも広く見られる。[^2]

**やる夫**：
墓掃除は信仰じゃなくて家族の責任だお。

**やらない夫**：
その「家族の責任」と宗教を分ける発想自体が、日本的な分類かもしれないぞ。

うちも墓へ行きます。
11月には親戚が総出で墓地に集まって、蝋燭を立てて、食べて、夜まで話します。

私たちも、他の宗教の友人の結婚式には行きます。
喜んで行きます。
ただ、そこで別の神への礼拝を求められたら、席に座ったまま動かない人もいます。

**やる夫**：
礼儀として頭を下げればいいお。
郷に入っては郷に従えだお。

**グレース**：
ねえ、聞いてください。
あなたにとっては礼儀の動作でも、私にとっては、誰を神とするかの旗を上げる動作になり得ます。

**やる夫**：
同じ動作でも意味が違うのかお。

日本の宗教実践は、所属宣言より、家、地域、季節、人生儀礼と結びつきやすい。

## 第4幕　誰が正しい教えを決めるのか

### 4-1　聖書だけ読めば答えは一つになるのか

**やる夫**：
宗派対立の解決方法を思いついたお。
全員、教会の伝統を捨てて聖書だけ読めばいいお。
同じ仕様書を読めば、実装は一つに決まるお。

**やらない夫**：
同じ仕様書から、実装が一つに決まった経験があるか。

**やる夫**：
ないお。
曖昧な要件は解釈が分かれるお。

**ハンナ**：
史料に基づいて言えば、宗教改革者は「各人が好きに読めばよい」とは言っていません。
教会の教えを聖書で検証し、聖書を最高の規範とせよ、と求めました。
その上で、ルター、ツヴィングリ、カルヴァン、再洗礼派は、読み方でただちに割れています。

**やる夫**：
何で割れたんだお。

**ハンナ**：
聖餐で、パンとぶどう酒にキリストがどう臨在するか。
幼児洗礼は有効か。
教会は国家とどう関わるか。
礼拝から聖像や古い儀式をどこまで削るか。
救いにおいて人間の意志はどこまで働くか。

**やる夫**：
仕様書は1冊なのに、実装が4つ出てきて全部が「これが正しい実装だ」と言ってるお。

**やる夫**：
「聖書のみ」と言っても、読む集団は消えないお。

**マリア**：
カトリックは、聖書と教会の伝統を切り離しません。
そもそも、どの文書を聖書とするかを決めたのが古代教会です。
だから、聖書と、使徒から受け継いだ伝統と、司教団と教皇による教導職を、束ねて考えます。

**ニコラオス**：
正教会も、聖書を聖伝の中心として読みます。
ただし、教皇が一人で全教会に裁定を下す仕組みは認めません。
公会議、教父、典礼、司教たちの合意。
急ぎません。
千年かけて確かめることもあります。

**やる夫**：
カトリックは中央裁判所、正教会は合議制、プロテスタントは仕様書優先だお。

**やらない夫**：
また会社にしすぎだ。
だが「答えが割れたとき、最終的に誰が決めるか」という軸は重要だ。

### 4-2　教皇は全キリスト教徒の上司なのか

**やる夫**：

千年、認めていません。

**ハンナ**：
プロテスタントも認めません。

**テクレ**：
東方諸教会も同様です。
……そのニュース原稿、誰が書いたのか伺ってよいですか。

**やる夫**：
最大宗派のトップではあるけど、全キリスト教のトップではないのかお。

**マリア**：
カトリックにとって教皇は、ローマ司教であり、ペトロの後継者として普遍教会に特別な責任を持ちます。
しかし、教皇が毎日すべてのカトリック信者へ個別命令を出すわけではありません。

**やる夫**：
カトリック信者は、教皇が言ったことを全部そのまま実行するんじゃないのかお。

**マリア**：
違います。

それに、私が仕事や子どものことで相談するのは、教皇ではありません。
ナナイと、教区の神父さんと、教会の友だちです。

同じ教えを持った人が、同じ国の同じ年に、協力する側と獄につながれる側に分かれたのかお。
……なら、これは聖書がどっちを命じたかを当てるクイズじゃないお。

**やらない夫**：
では聞く。
同じ文章なら、どの読みも同じ価値か。

**やる夫**：
違うお。
検証できるお。
誰が得をする解釈か。
誰の被害が視界に入っているか。
聖書全体の中心をどこに置いているか。
そしてその読みが、目の前の生身の人間をどう扱うか。

**ハンナ**：
そこは譲れません。
宗教は善にも悪にも使える、と言って終わらせると、責任が誰のものでもなくなります。
どの制度が、どの指導者が、どの解釈が、誰を傷つけたのか。
名前を出して見る必要があります。

**マリア**：
うちのナナイなら、もっと短く言います。
その説教を、鎖につながれている人の前でもう一度言えますか、と。

**やる夫**：
……それ、この教材の最終チェック項目にするお。
やる夫が書いた一行を、その場にいた一番弱い立場の人の前で、声に出して読めるか。
読めないなら、書き直しだお。

## 第9幕　ユダヤ教はキリスト教の旧版なのか

---
### 9-1　旧約聖書の次に新約聖書がある

**やる夫**：
最後にユダヤ教との関係を書くお。
ユダヤ教が旧約版、キリスト教が新約版。
古い契約をイエスがアップデートしたんだお。

**ダビデ**：
なるほど。
すると私は、更新通知を2000年間バツで消し続けている人ですね。

**やる夫**：
うぐっ。
……で、でもキリスト教側では旧約、新約と言うお。

**ダビデ**：
それはキリスト教の分類です。
私たちは自分の聖典を「旧約聖書」とは呼びません。
タナハと呼びます。
並び順も区分も、あなたの言う旧約聖書とは違います。
最後の書も違う。
質問に質問で返しますが、他人の本棚に、勝手に「旧」と書いた札を貼るのは、どういう作業ですか。

**やらない夫**：
イエスは何教徒だった。

**やる夫**：
キリスト教徒……じゃないお。
イエスも弟子もユダヤ人だお。

**ダビデ**：
初期のイエス運動は、第二神殿時代のユダヤ教の内側から始まっています。
しかも当時のユダヤ教が一枚岩ではありません。
神殿、律法、復活、メシア。
どれについても、意見の違う集団がいくつもありました。
議論好きなのは、昔からです。

**やる夫**：
キリスト教が完成品として突然現れたんじゃなく、ユダヤ教内部の論争から始まったお。

**ハンナ**：
大きな争点は、イエスが約束されたメシアか、復活したか。
異邦人が神の民へ加わる際、割礼や食事規定を含む律法をどこまで守る必要があるかでした。

**ダビデ**：
私たちの側から見ると、単純な話です。
メシアの時代に来るはずの世界平和も正義も、まだ来ていません。
新聞を開けば分かります。
それに、イエスを神とすることや三位一体は、私たちの唯一神理解とは両立しません。
これは理解不足ではなく、結論です。
その話、うちでは2000年やっています。

**やる夫**：
「同じ証拠を見ればユダヤ人もイエスを認めるはず」という話ではない。
神、メシア、律法、歴史の読み方が違うお。

### 9-2　姉妹宗教なのに、なぜ迫害したのか

**やる夫**：
聖典も神も共有してるなら、仲の良い親戚になりそうだお。

**ダビデ**：
親戚だからこそ、揉めるという説もあります。
いずれにせよ、歴史はそうなりませんでした。

**やらない夫**：
なぜだ。

**やる夫**：
ユダヤ人がイエスを処刑したから、キリスト教徒が怒ったお。

**ダビデ**：
……その一文が、どれだけの葬式を出したかご存じですか。

**やる夫**：
えっ。

**ダビデ**：
十字架刑を執行した国家権力はローマです。
当時の一部の指導者との対立を、全時代の全ユダヤ人の責任へ広げることはできません。
私の家族の姓は、その広げられた責任のせいで三度、国を移っています。

**マリア**：
しかしキリスト教社会では長く、「ユダヤ人がキリストを殺した」という集団責任の非難が使われました。
さらに、教会がイスラエルに完全に取って代わり、ユダヤ人の契約は意味を失ったという理解が、軽蔑の背景になりました。

**ダビデ**：
ユダヤ人は改宗を拒む頑固な民、神に捨てられた民として描かれました。
職業制限、居住制限、追放、強制改宗、暴力が繰り返されました。

**やる夫**：
近代のナチズムもキリスト教の教義なのかお。

**やらない夫**：
同一ではない。
近代の反ユダヤ主義には、人種理論、民族主義、陰謀論が加わった。
洗礼を受けても「人種としてユダヤ人」と分類する点は、宗教的反ユダヤ主義と違う。

**ダビデ**：
ただし、何世紀もの宗教的軽蔑や差別が、近代の反ユダヤ主義を受け入れやすくした面を無視してはいけません。

**マリア**：
……この話になると、私は自分の教会の側の歴史を、言葉を選ばずに言わなければなりません。
ホロコースト後、多くの教会が教えと歴史を検討し直しました。
カトリックの第2バチカン公会議による『ノストラ・エターテ』は、イエスの死を当時または現代の全ユダヤ人の責任とせず、ユダヤ人への憎悪や迫害を退け、キリスト教とユダヤ教の深い結びつきを確認しました。[^6]

**やる夫**：
現代では完全に解決したのかお。

**ダビデ**：
していません。
文書は出ました。
文書は本気だと思っています。
それでも、反ユダヤ的な陰謀論は今も流通しています。
その上で一つ言わせてください。
次の言葉を混ぜて使うと、議論はその場で壊れます。

* ユダヤ教という宗教
* ユダヤ人という民族的・文化的共同体
* イスラエル国民
* イスラエル国家
* イスラエル政府
* シオニズム
* イスラエル政府の個別政策への批判
* 反ユダヤ主義

**やる夫**：
政府への政策批判を全部反ユダヤ主義と呼ぶのも間違い。
逆に、ユダヤ人全体へ責任を負わせる主張を、ただの政策批判と呼ぶのも間違いだお。

**ダビデ**：
その区別が必要です。
……初めてです。
この話を日本の方から先に言われたのは。

**やる夫**：
……やる夫は今日まで、その8つを全部ひとまとめにして、触らないようにしてただけだお。
触らないのは、尊重じゃなかったお。

## 終幕　全員が納得する教材は作れない

---
### 10-1　違いを消せば平和になるのか

**できる夫**：
最終編集案です！
宗教はすべて愛を教えています。
細かい違いを気にしなければ、みんな同じです！

**やる夫**：
以前なら採用していたお。
でも、それでは違いを尊重したことにならないお。

**やらない夫**：
なぜだ。

**やる夫**：
カトリックにとって教皇権は小さな作法じゃない。
正教会にとって教皇の普遍的統治を拒むことも小さな作法じゃない。
ユダヤ教徒にとってイエスを神と認めないことは、未理解じゃなく信仰上の結論だお。
ペンテコステ派にとって聖霊体験は飾りじゃない。
宗教改革の信仰義認も、当事者には救いの確かさの問題だったお。

**マリア**：
細かい違い、と言われるとき。
私たちは、大事にしてきたものを細かいと言われています。
うちのナナイの前で、その台詞は言えません。

**ニコラオス**：
一致とは、違いが無いふりをすることではありません。
それは一致ではなく、上書きです。

**テクレ**：
……一つだけ、伺ってよいですか。
その「みんな同じ」の絵に、私の国の1600年は入っていますか。

**グレース**：
それに、その台本には歌がありません。
みんな同じですと言った瞬間、誰の歌でもない歌になります。

**ダビデ**：
ユダヤ教とキリスト教を「表現が違うだけで結局同じ」とまとめることも、私たちの否定を聞かない態度になり得ます。
私たちは、まだ答えていないのではありません。
答えたのです。

**やる夫**：
……でも、違いが本物なら、もう争うしかないのかお。

**やらない夫**：
同意しないことと、相手の権利を否定することは別だ。
自分の信仰を真実だと考えたまま、強制改宗を拒み、他人の自由を守り、共同の課題で手を組むことはできる。

**ハンナ**：
宗派間の対話も、「全部同じでした」を目指してはいません。
何に合意でき、何には合意できず、その違いが一緒に暮らすことを妨げる必要があるのか。
そこを確認する作業です。

**やる夫**：
……分かったお。
違いを消した平和は、一番声の小さい人の分を消して作るお。
やる夫の企画書がやろうとしてたのは、それだったお。

### 10-2　やる夫の最終ナレーション

**できる夫**：
録音を始めます！
やる夫さん、最終ナレーションをどうぞ！

**やる夫**：
キリスト教は、善人になるための規則集ではないお。
人間が神、他人、自分自身、世界との関係を壊しているという診断と、神からの赦し、和解、復活によってそれを回復するという物語だお。

**やる夫**：
厳しい教えが生まれた理由は、古代人が残酷だったからだけではないお。
唯一神への忠誠、共同体を守る境界、欲望への警戒、終末への緊張、社会秩序、教会制度の権力化が重なったお。
その厳格さは弱者を守ることもあれば、人を排除する道具にもなったお。

**やる夫**：
キリスト教は一つの組織ではないお。
カトリック、東方正教会、東方諸教会、ルター派、改革派、聖公会、バプテスト、メソジスト、メノナイト、福音派、ペンテコステ派、独立教会などがあるお。
しかも教派、運動、礼拝形式、統治方式は別軸なので、単純な宗派一覧や円グラフでは実態を表せないお。

**やる夫**：
日本人は無宗教だからキリスト教徒を理解できない、という話でもないお。
日本では宗教が、家、地域、季節、冠婚葬祭へ分散し、所属を明言せず複数の儀礼へ参加しやすいお。
キリスト教では、誰を礼拝するかが人格的な忠誠と真理の問題になり、儀礼だけを自由に組み合わせにくいお。
ただし、欧米にも文化的なだけのキリスト教徒がいて、日本にも強い宗教所属を持つ人がいるお。

**やる夫**：
高校世界史の事件も、教皇と皇帝の勝敗表ではないお。
カノッサでは、皇帝は王位を守るため赦しを求め、教皇は政治的な敵を司祭として赦す矛盾に直面し、諸侯は自立の機会を見て、司教は王と教会の間で引き裂かれたお。
宗教改革では、救いを求める良心、教会の一致、領邦政治、印刷市場、農民の要求が衝突したお。
三十年戦争では、教義、領邦自治、王朝、国際政治、傭兵経済が絡み合ったお。

**やる夫**：
宗教は戦争を自動的に起こす物質でも、平和を自動的に生む薬でもないお。
敵味方を分け、権力を正当化し、被害記憶を保存することもあるお。
同時に、人間の尊厳、赦し、非暴力、和解の根拠にもなるお。
何を教えているかだけでなく、誰が、どの立場から、何のために解釈したかを見る必要があるお。

**やる夫**：
ユダヤ教はキリスト教の古い版ではないお。
両者は古代イスラエルの伝統を共有し、イエスと最初の弟子たちもユダヤ人だったお。
しかし、イエスをメシア、神、復活した者と認めるか、律法と契約をどう理解するかをめぐり、別々の宗教共同体として発展したお。
キリスト教徒が自分たちの視点からユダヤ教を未完成と扱った歴史は、差別と迫害へ結びついたお。

**やる夫**：
教義、制度、政治、一般信者の日常は同じではないお。
教皇の文書と、地域司祭の説教と、普通のカトリック信者の行動は一致するとは限らないお。
正教会の総主教、プロテスタントの牧師、ペンテコステ教会の指導者についても同じだお。

**やる夫**：
だからこの教材は、全員が同じだと結論しないお。
誰が何を信じ、なぜ譲れず、どこで協力できるのかを描くお。
理解するとは、違いを消すことじゃないお。
相手が自分とは違う理由を、相手の内側から説明できるようになることだお。

**できる夫**：
録音、終了です。

**マリア**：
……最後の一行、いいと思います。
ナナイに聞かせたら泣きます。
たぶん意味は半分も伝わらないまま泣きます。
うちの母は、そういう人なので。

**ニコラオス**：
訂正は、ありません。

**やる夫**：
えっ。
初めてだお。

**テクレ**：
……一つだけ、伺ってよいですか。
第1章の地図に、私の国は載っていますか。

**やる夫**：
載ってるお。
一番前だお。

**テクレ**：
……ありがとうございます。

**グレース**：
アーメン！

**ダビデ**：
質問に質問で返しますが、続編はいつですか。
うちの分が、まだ2000年分ほど残っています。

**ハンナ**：
史料は、私が確認します。
できる夫さんの絵コンテも、私が確認します。

**できる夫**：
……つまり最後は、宗教を超えて愛が勝利する感動映像ですね！

**やる夫**：
また単純化したお。

**やらない夫**：
最初よりは、間違いに気づくのが速くなっただろ。

第1幕のやる夫は、円グラフ1枚で世界を塗れると思ってたお。
