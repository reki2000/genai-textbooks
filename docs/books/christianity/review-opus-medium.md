# 寸評：やる夫がキリスト教の教材をつくるようです ── 「愛と分裂」を読み解く

約100KB／全10幕＋幕間8本。編集者やる夫が「60分で完全理解」の副教材を作ろうとして、5宗派の当事者と歴史家に企画を叩き潰され続ける構成。教義史ではなく、分類の失敗を軸に据えた点が特徴。

## 良い点

**テクレの問いが全編を貫く一本の梁になっている。** 「その3色の円の、どこに私の教会が入りますか」（60–71行目）に始まり、「その画面に、私の国は映っていますか」（531–535行目）、「その7つの箱の、どこにエチオピアが入りますか」（1323–1333行目）、「私の教会には、その船が着く1000年以上前から司教がいました。あなたの企画書の第何章に入りますか」（1540–1546行目）と反復され、終幕の「第1章の地図に、私の国は載っていますか」「載ってるお。一番前だお」（2285–2294行目）で回収される。同じ形式の問いが5回、そのつどやる夫の企画書の別の欠陥を照らす。この教材で最も設計が効いている装置。

**幕間Iが「教義論争は言葉遊びか」への最良の解答になっている。** やる夫が「1文字のために帝国中の司教を集めた、昔の神学者は暇だった」と嘲る（249–253行目）直後、やらない夫が「お前は日曜の朝、誰に向かって膝をついてる」（256–257行目）と問い、やる夫自身が「造られたものを拝んでるお。唯一神を信じてるつもりで、被造物を神の席に座らせてた」（266–270行目）に到達する。抽象的な説明ではなく、読者自身の行為の意味に翻訳して再発見させている。しかも「ここは分裂の起点じゃなくて、今も全員が共有してる床の方だった」（305–307行目）と、公会議の位置づけまで反転させる。

**カノッサの読み替えが鮮やか。** 「教皇は政治的には絶対に赦したくない。でも司祭としては、頭を下げて来た者を追い返せない。自分の宗教的権威が、自分の政治戦略の首を絞めた」（771–775行目）と、「ハインリヒの土下座は反乱側から大義名分を抜き取る手」（786–789行目）。勝敗表を6当事者の問いに置き換える着地（856–861行目）と、「カメラの位置を変える」（866–869行目）という編集者らしい結論が噛み合っている。

**やる夫の失言が、痛い形で返ってくる。** 修道院解散を「万々歳だお」（1275–1277行目）と言った直後、マリアの「12歳で生涯を神に捧げて40年そのとおり生きた人が、ある朝あなたの一生は迷信でしたと言われる」（1279–1283行目）が来て、やる夫が「自分の口を縫いたいお」（1285–1288行目）と黙る。安易な発言のコストを、説教ではなく具体的な一人の生涯で払わせている。

**批判の刃が最後にやる夫自身へ向く。** 「6問全部から逃げるために『無宗教です』の一言を使ってきたのは、やる夫の方だった」（1450–1452行目）、「触らないのは、尊重じゃなかったお」（2145–2147行目）。他者を理解する教材が、途中から自分を診断する教材に変わる。

**参考文献の質が高い。** 10点（2335–2353行目）すべてに一次資料名と、本文のどこでどう使ったかの説明がある。宗教年鑑は報告値を実数まで（2339行目）、Pew は基準年と「比較可能な基準例として使用した」という但し書きまで付いている。

## 欠点

**「再発見」がほとんど起きていない。** やる夫が自力で組み立てる場面が事実上なく、9人の証人が正解を述べ、やる夫が要約する構造。1-1の分類表（200–207行目）も3-2の比較表（699–706行目）も、「表にするお」の一言のあと完成品が出るだけで、軸を立てて失敗し組み直す過程がない。この教材で本当に難しいのは「複数軸の地図を作ること」なのに、その作業そのものが省略されている。

**ビートが徹底して同型。** 「やる夫が単純化 → 誰かが訂正 → やる夫が『……だったお』と学ぶ」の1パターンが、第1幕から終幕まで数十回反復する。キャラクターの口癖もテンプレ化しており、ニコラオスの「まず、訂正させてください」だけで76・168・277・504・936・991行目と続く。個性付けとして始まったものが、後半では次の展開の予告になっている。

**9人を集めておいて、彼ら同士が一度も衝突しない。** マリア（カトリック）とニコラオス（正教会）は教皇の普遍的統治をめぐって根本的に対立する立場のはずだが、1030–1039行目でも「ローマ側から見ると」「東方側は」と交互に穏当な説明をして終わる。分裂を主題にした教材で、当事者同士の緊張が一度も画面に出ないのは大きな取りこぼし。全員が親切な解説者として横並びになっている。

**できる子の「数式」が機能していない。** 1590–1603行目の「紛争 == 教義 + 集団アイデンティティ + 国家権力 + 土地・資源 + 過去の被害記憶」、1683–1698行目の「政治姿勢 ==== …」。加算に演算としての意味がなく、`==` や `====` が何を表すかも不明。数式ブロックで組む必然性がゼロで、箇条書きより情報量が落ちている。

**物語的な圧力が設定されていない。** 冒頭の企画（32–36行目）から終幕の中止（2325行目）まで、入稿日も予算も上司も競合もない。できる夫の「……尺が、削れます」（239行目）が唯一の実務的抵抗で、それも4回同じ形で繰り返される（239・538・998・1723行目）。企画を中止する判断に実際の損失が伴わないため、終幕の決断が痛みを持たない。

**教義の中身に入る場面が少ない。** 聖餐が分裂の主要因として2度挙がる（898行目、1046行目）が、実体変化・共在説・象徴説の中身は最後まで説明されない。三位一体も幕間Iの「同一本質」以上に踏み込まない。「違いがある」ことの列挙は徹底しているが、「何がどう違うのか」が薄い箇所が残る。100KBの分量に対して、教義的な密度は低い。

**数値の出典に穴がある。** 1765行目の「激しかった地方では人口の3分の1以上が失われた」、1246行目の農民戦争「死者は数万人規模」に脚注がない。他の数値（601行目、647行目、971行目、1343行目）はすべて脚注付きなので、この2箇所だけ基準が緩い。

## 改善案

1. **マリアとニコラオスを一度正面衝突させる。** 1030–1039行目の交互説明を、相互承認を問う応酬に書き換える。ニコラオスに「では伺いますが、あなたの教会は私たちの聖餐を有効と認めますか」と言わせ、マリアが答えに詰まる場面を作る。やる夫が慌てて「細かい違いだお」と仲裁して両方から冷たい目を向けられれば、終幕の「細かい違い、と言われるとき、私たちは大事にしてきたものを細かいと言われています」（2174–2177行目）が伏線の回収になる。

2. **1-1の分類表を、やる夫の作業として書き直す。** 200–207行目でいきなり6軸の完成表を出すのをやめ、やる夫が3軸の表を出す→テクレとグレースがそれぞれ自分を当てはめて両方とも収まらないことを実演する→やる夫が軸を足す、という2往復にする。20行増やす価値がある。この教材で唯一「やる夫が自分で作る」べき成果物がここだから。

3. **数式ブロックを廃す。** 1590–1603行目と1683–1698行目を箇条書きに落とす。残すなら、できる子に「これは足し算ではない。北アイルランドでは教義の項がほぼゼロで、集団アイデンティティと過去の被害記憶が大半を占める」と重み付けを語らせ、ハンナの北アイルランドの記述（1608–1613行目）と接続する。

4. **企画に締切と損失を与える。** 第1幕冒頭（32–36行目）に、印刷所の枠と納品日、そして「巨大な円グラフの3DCGはすでに発注済み」といった既成事実を置く。幕間ごとにできる夫が「その修正はもう間に合いません」と抵抗すれば、幕間IIの「冒頭の演出、変えるお」（562–565行目）以降の書き直しが、そのつど何かを捨てる判断になる。

5. **聖餐を1節で扱う。** 4-1（898行目のリスト）を分解し、幕間を1本足すか5-2に節を作る。「同じパンを前に、実体変化・共在・象徴の3人が同じ食卓に座れるか」をマリア・ハンナ・グレースに実演させ、やる夫に「どこまでなら一緒に食べられるか」を線引きさせる。「仕様書1冊で実装4つ」（905行目）が、抽象論から手触りのある対立に変わる。

6. **できる夫の型を一度だけ崩す。** 幕間VIIIで企画を「作るな」と止められた（1916–1924行目）直後に、彼が初めて自力で代案を出す場面を1つ置く。8回同じ型を繰り返した後の1回の変化なら、終幕の「宗教を超えて愛が勝利する感動映像ですね！」（2307–2308行目）というオチも、単なる不変ではなく揺り戻しとして効く。

7. **1765行目と1246行目に脚注を付す。** 三十年戦争の人口損失推計と農民戦争の死者数。他の数値がすべて出典付きである以上、ここだけ無出典なのは目立つ。
