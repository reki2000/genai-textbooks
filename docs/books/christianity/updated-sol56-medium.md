# 改訂記録（sol56-medium）

`review-opus-medium.md` の指摘を基に、本文の事実関係と既存の主要な回収線を保ちながら、次の改訂を行った。

## 再発見の作業を本文へ出した

第1幕の分類表は、やる夫が完成した六軸表を一度に提示する形をやめた。まず「所属・統治・礼拝」の三軸表を作り、テクレを東方正教会と混同し、グレースとカトリックの従姉を説明できない失敗を経験させた。その失敗から、教会共同体、教派家系、横断的運動、礼拝・霊性、統治、生活上の所属という六軸をやる夫自身が取り出す構成にした。

第7幕の二つの疑似数式は廃止した。紛争の五要因は同じ重みで加算できない確認欄とし、北アイルランドでは教義の重みがほぼゼロに近いことを、やる夫が事例から判断する。政治姿勢も、教義解釈、歴史経験、地域・階級・民族、国家との距離を因果的に説明するチェック項目へ変えた。要因そのものは削除していない。

## 当事者間の対立と教義の中身を追加した

第4幕では、ニコラオスがカトリックによる正教会の秘跡承認を問い、それでも聖餐を通常は共にできない理由を教皇の普遍的統治と教会一致の理解へ結びつけた。マリアもペトロの後継者との交わりを譲らず、やる夫の「細かい制度の違い」という仲裁を二人が同時に拒む。終幕の「細かい違い」という台詞を、実際に起きた衝突の回収にした。

第5幕に「同じパンを前に、何をしているのか」を新設した。カトリックの実体変化、ルター派の真の現存、ペンテコステ派の記念と告知を説明したうえで、やる夫が作る「実体変化・共在・象徴」の三箱を当事者がそれぞれ壊す。教義は物質の説明だけでなく、キリストの現存、記念、共同体、聖餐参加の境界まで変えることを示した。一次的な教義文書を脚注 `[^13]` に追加した。

## 企画上の圧力と損失を実体化した

冒頭で入稿日時、印刷所の枠、発注済み3DCG、返金されない着手金を設定した。各幕間では、背景美術、年表アニメ、ハンマー撮影、二色の合戦映像を直すたびに、時間または費用を失わせた。第7幕でやる夫は誤った映像を守るための印刷枠を自分で捨て、終幕では予算残六割と一か月の延期を引き受ける。企画中止を無償の正解ではなくした。

## できる子・できる夫の声を調整した

既存教材の `statistics`、`supply-chain`、`rental-car-operations`、`birthrate-and-aging` を `rg` で調べた。できる子は短い発話で前提、比較、根拠の欠落を止める人物、できる夫は理解と実装が速く、親切や熱意が確認より先へ走る人物として共通していた。この傾向に合わせ、できる子は「足し算ではない」「三軸では不足」など短い診断を置き、できる夫は発注や代案を即座に実行する声へ直した。

ニコラオスの「まず、訂正させてください」は初出だけに残し、以後は傷ついた点や具体的な反論から話し始めるよう変えた。できる夫は幕間VIIIで初めて、制止された後に自力で三者の読みを並べる代案を出す。終幕では従来の単純化へ一度戻るが、自分で気づいてカットする揺り戻しにした。
