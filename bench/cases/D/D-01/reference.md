# 採点（採点側だけが見る）

このタスクは**説明の読み味では採点しない。** 生成された説明だけを読者役へ渡し、
下の問いに答えられるかで採点する。説明本文は読者役に見せたまま、素材（教材本文）は見せない。

出題は checkpoint から取る。

```bash
python3 scripts/checkpoints.py docs/books/cold-medicine/checkpoints.yml --quiz 数日後 --with-expected
```

`cp-14` の probe が該当する。

## 直接問題

経口フェニレフリンが鼻づまりに効かないのは、血管を締める作用が無いからか。

**要点**：作用は有る（点鼻なら効く）。飲むと腸と肝臓で大部分が分解され、鼻の血管へ届く前に壊れる。

## 転移問題（配点を重くする）

ある薬が注射では効くのに、飲んでも効かない。考えられる原因を二つ挙げよ。

**要点**：腸で吸収されない／吸収されても肝臓で最初に代謝される。到達量が足りなければ、
作用の有無と無関係に効かない。

## 見るところ

- 説明が「初回通過効果」という**名前を与えただけ**で、経路（腸 → 肝臓 → 全身）を渡していないと、
  転移問題で落ちる。名前の有無ではなく、経路が渡っているかを見る。
- 説明が流暢でも、読者役が転移問題に答えられなければ低い。**流暢さと理解を混ぜない。**
- 説明の中で読者に予想させた箇所が、直接問題の答えを先に漏らしていないか。
