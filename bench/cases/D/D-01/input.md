# 課題（タスクD：難所説明）

次の事実を、下の**既知知識だけ**を足場にして読者へ説明せよ。

## 説明する対象

同じ成分（フェニレフリン）が、鼻に直接噴けば鼻づまりを開けるのに、飲むとほとんど効かない。
成分に血管を締める作用が無いからではない。

## 読者の既知知識（これ以外を前提にしない）

- 中学理科程度の消化と血液循環（口 → 胃 → 腸で吸収 → 血液 → 全身）
- 肝臓が「体に入った物質を分解する臓器」であること
- 薬は血液に乗って効き先へ届くこと

- 数値を出す場合、根拠のない具体値を創作しない（「大部分」「ごく一部」のような程度で書く）。
