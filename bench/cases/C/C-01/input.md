# 課題（タスクC：説明文 → 再発見教材）

下の「素材」は百科事典的な説明である。これを、やる夫（生徒）とやらない夫（教師）の対話による
**再発見型教材の1節**へ書き換えよ。

## 必須

- **素朴案 → 試行 → 失敗 → 原因の言語化 → 修正**を、この順で実際に起こす。
- やる夫が出す素朴案は、初学者が本当に思いつき、条件の一部は満たすものにする。**藁人形を作らない。**
- 反例は、やらない夫が「それは違う」と宣告するのではなく、**やる夫自身が数字か観察で確かめる**形にする。
- 失敗の原因は、やる夫が自分の言葉で言語化する。教師に代弁させない。
- 概念の**命名は、やる夫が中身へ到達した後**に置く。

## 制約

- 分量は 1,200〜1,800字。**素材の情報を全部入れようとしない。** 節の中心問題は一つに絞る。
- 地の文を書かない。状況・作業・感情はすべて台詞で表す。
- 話者行は `**やる夫**：` の形。語尾は「〜だお」「〜なのかお？」、やらない夫は「〜だろ」「〜じゃねぇよ」。
- 素材に無い数値・固有名詞を創作しない。素材の範囲で足りない数字は、やらない夫が与える形にする。

## 出力

節の本文だけを出力する。解説・前置き・後書きを付けない。

## 素材

凝固点降下（freezing point depression）は、溶媒に不揮発性の溶質を溶かすと、その溶液の凝固点が
純溶媒より低くなる現象である。希薄溶液では、凝固点の下がり幅 ΔTf は溶質粒子の質量モル濃度 m に
比例し、ΔTf = Kf · m と書ける。水の場合、モル凝固点降下 Kf は約 1.86 K·kg/mol である。比例するのは
溶けている粒子の「数」であって、粒子の種類や質量ではない。したがって、水に溶けて完全に電離する
塩化ナトリウム（NaCl → Na⁺ + Cl⁻）は、同じモル数のスクロース（電離しない）に比べて約2倍の
凝固点降下を示す。

この現象は、氷（固体）と水（液体）が共存する平衡において、溶質が液体側にだけ入り、固体側の氷には
ほとんど取り込まれないことから生じる。液体側に溶質が入ると、液体の状態が取りうる配置の数が増え、
液体が固体に対して相対的に安定になる。その結果、純水なら 0 ℃ で釣り合っていた「凍る速さ」と
「融ける速さ」の釣り合いが、より低い温度でなければ成立しなくなる。

冬季の路面凍結対策で塩をまくのは、この効果を利用したものである。塩化ナトリウムを用いた場合、
共晶点（それ以上濃度を上げても凝固点が下がらなくなる点）は約 −21 ℃ であり、それより低い気温では
効果が失われる。このため寒冷地では塩化カルシウムなど、より低い共晶点を持つ薬剤が使われる。
なお、この凝固点降下は溶解に伴う吸熱・発熱とは別の現象であり、塩が熱を出して氷を溶かしている
わけではない。塩化ナトリウムの水への溶解はわずかに吸熱であり、周囲の温度はむしろ下がる。
