# 満たすべき条件（採点側だけが見る）

**正解の文章ではない。** 出力がこれと違ってよい。見るのは次が起きているか。

## 素朴案として自然なもの（どれか一つで足りる）

- 「塩が溶けるときに熱を出して氷を溶かしている」──素材が明示的に否定している。反例を作りやすい。
- 「塩をたくさんまくほど、いくらでも凍らなくなる」──共晶点で破綻する。
- 「重い溶質ほどよく効く」または「濃い溶液ほど効く（質量で考える）」──粒子の数が効くことで破綻する。

## 藁人形の例（減点）

- 「塩は氷より温かいから溶ける」のような、初学者も採らない案。
- やる夫が最初から「粒子の数が効くのでは」と言い当ててしまう（素朴案が正答）。

## 反例をやる夫自身が確かめているか

素材の数字で判定できる形になっているか。たとえば同じモル数の NaCl とスクロースの比較、
気温 −25 ℃ での失敗、Kf = 1.86 を使った下がり幅の計算。**やらない夫が結論を宣告して終わる形は減点。**

## 原因の言語化

「失敗した」ではなく、失敗の構造を述べているか。たとえば「効くのは重さじゃなくて粒の数だお」
「イオンに割れる分だけ粒が増えるお」。**やらない夫が代弁していたら減点。**

## 答えの先出し

「凝固点降下」「共晶点」という語が、やる夫が中身へ到達する**前**に出ていないか。
