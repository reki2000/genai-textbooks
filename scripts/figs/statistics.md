# statistics シリーズ 図版記録

`scripts/figs/statistics.py` 1本で3巻（statistics / statistics-2 / statistics-3）の図を描き、図番号の幕で巻の `figs/` へ振り分ける。

## 選定

図のスロット（どの節に何の問いの図を置くか）は旧図の選定を踏襲した。旧図は形が一様（幅760の横長）で、焦点と答えが図の中に無かったので、各節の本文を読み直し、形・大きさ・構図だけを選び直した。数値は旧スクリプトの `assert`（本文と照合済み）を引き継いでいる。

主な変更：

| 図 | 旧 | 新 |
|---|---|---|
| 1-2 | 横長の点列 | A の塊を拡大枠で見せる |
| 3-3 | 2本の梁 | 案A・見積もり・案Bの3本（標準偏差0・2,230・2,710円） |
| 5-1 | 横長 | 縦長で個体（100人の格子）と推定値（標本分布）を上下に |
| 6-2 | 横長に20本 | 縦長に20本 |
| 7-1 | 左右2パネル | 上下2パネルで x を共有 |
| 11-2 | 密度曲線 | 最小値の累積分布。210時間の縦線で 2%・18%・87% を直接読む |
| 12-1 | 横長 | 2x2 の小さな多数（軌跡／分布 × 収束の種類） |
| 21-3 | 横長 | 縦長で追跡線と生存曲線を上下に |
| 24-1 | 面積図 | 端末型ごとの傾きグラフ（層内は上がり、合計は下がる） |
| 25-4 | 2段 | 縦軸を共通にした2段（均した柱がほとんど見えないこと自体を見せる） |
