### 1. `fig1-bistable-lineage.png`

この図が答える問い：
部品が3回替わっても、同じままだった配線の位相は何か。

該当本文：
"""
そして2個のCMOSインバータを交差結合すれば……

あ。

またEccles-Jordanだ。

物理部品は真空管からMOSFETへ変わったのに、
**帰還で2安定状態を作る論理構造は生き残ってる**。
"""

構図：
- 横に3パネルを等幅で並べる。3枚とも「左に素子A、右に素子B、その間をたすき掛けに2本の帰還線が結ぶ」という完全に同じ位相・同じ座標で描く。
- 左パネル：自己保持リレー。コイルと接点、接点から自分のコイルへ戻る帰還線。
- 中パネル：真空管2本の交差結合。Aの陽極からBの格子へ、Bの陽極からAの格子へ。
- 右パネル：CMOSインバータ2個の交差結合。片方の出力がもう片方の入力へ。

必須要素：
- 3パネルで、たすき掛けの2本の帰還線がまったく同じ形・同じ角度であること。これがこの図の唯一の主張である。
- 素子だけがパネルごとに違い、配線の位相は変わらないこと。
- 帰還線は青 #1f6fd0。素子と電源記号は灰 #8d8d8d。

ラベル（この表記に完全一致）：
- 「リレー」
- 「真空管」
- 「CMOSインバータ」
- 「交差帰還」
- 「A」
- 「B」

禁止：
- 3パネルで帰還線の引き回しを変えない。
- セット端子・リセット端子の動作順序や波形を描かない。
- SRAMのアクセストランジスタを足さない。
- 真空管の内部電極の詳細、リレーの機械構造の詳細を描き込まない。素子は簡略な記号でよい。

### 2. `fig2-place-vs-time.png`

この図が答える問い：
ビットを場所に置くのと、時間に置くのとで、何が入れ替わるのか。

該当本文：
"""
長い管を用意して、
パルスを順番に飛ばす。

1、0、1、1、0……

出口に着いたら読み、
増幅して、
また入口へ戻すお。
（中略）
**時間的位置**でビットを区別する。

1本の線の中にパルス列を循環させるお。
（中略）
でも135番目のビットを読みたいとき、
135番目が出口へ来るまで待つのかお。
（中略）
容量は増えた。
でもアクセス時間が位置で変わる。
"""

構図：
- 上下2パネル。上「場所でビットを持つ」、下「時間でビットを持つ」。
- 上パネル：横一列に同じ大きさの記憶素子を8個並べる。どの素子にも読出し口から同じ長さの線が届く。
- 下パネル：横長の管を1本描き、その中に「1 0 1 1 0 1 0 0」のパルス列を左から右へ等間隔で並べる。管の右端が出口、そこから増幅器を経て管の左端の入口へ戻る循環経路。

必須要素：
- 下パネルで、出口にいちばん近いビットと、出口からいちばん遠いビットを橙 #e07b1f で区別し、後者に「待ち」が生じることが位置で分かること。
- 循環経路（出口→増幅器→入口）が閉じていること。青 #1f6fd0。
- 上下でビットの個数を同じ8個にすること。

ラベル（この表記に完全一致）：
- 「場所でビットを持つ」
- 「時間でビットを持つ」
- 「読出し口」
- 「出口」
- 「増幅」
- 「入口」
- 「いま出口にいるビット」
- 「出口まで待つビット」

禁止：
- 水銀、音波、材料名を描写しない。
- 遅延時間の数値や「135」という番号を書かない。
- EDSACなど実機の外観を描かない。
- 上パネルの素子ごとに線の長さを変えない。どれも同じであることが対比の前提。

### 3. `fig3-core-coincident-current.png`

この図が答える問い：
半分ずつの電流で1個だけを選び、しかも読むと消えるとはどういうことか。

該当本文：
"""
じゃあXだけに$I/2$。
Yだけにも$I/2$。

どちらか1本だけ通るコアは反転しない。

交点だけ$I/2+I/2=I$。

そこだけ反転するお！！
（中略）
なら選んだコアへ、試しに0方向の磁界をかける。

元が0なら変化しない。

元が1なら1→0へ反転するから、
センス線（検出線）に磁束変化のパルスが出る。
（中略）
選択
→ 破壊読み出しセンス
→ レジスタへ一時保存
→ 元の語を書き戻す
（中略）
0を書きたいビットまで1にならないよう、
禁止線で逆方向の磁界を足して反転閾値を超えないようにする。
"""

構図：
- 左に大きく、コア配列の平面図。4行4列の小さなリング（フェライトコア）を格子状に並べる。
- 横方向にX線が4本、縦方向にY線が4本走り、各リングを貫く。
- 右に細い縦長の欄を置き、読出しの4段階を上から下へ並べる。

必須要素：
- 選ばれたX線1本とY線1本を青 #1f6fd0 の太線にし、その交点のコア1個だけを橙 #e07b1f で塗る。
- 選ばれた線上にあるが交点ではないコア（同じ行・同じ列の残り6個）は灰 #8d8d8d の輪郭のままにし、反転しないことが色と塗りの有無で分かること。
- X線とY線の脇に電流の大きさを線の太さで示し、交点だけが合計で反転に達することが見えること。
- 配列を斜めに横切るセンス線1本と禁止線1本を、X線・Y線とは違う線種（破線）で描く。センス線と禁止線は互いに交差させない。
- 右の欄に、読出しが「選択→センス→一時保存→書戻し」の4段で、最後にコアの値が元へ戻ることを、同じコア1個の色の変化で示す。

ラベル（この表記に完全一致）：
- 「X線 I/2」
- 「Y線 I/2」
- 「交点 I」
- 「選択されたコア」
- 「反転しない」
- 「センス線」
- 「禁止線」
- 「選択」
- 「破壊読み出し」
- 「一時保存」
- 「書き戻し」

禁止：
- ヒステリシス曲線（B-H曲線）を描かない。
- コア1個の断面や磁区を描かない。
- 一致電流の数式の導出を書かない。図中の数式は「I/2」「I」だけ。
- 配列を4行4列より大きくしない。個数が増えると選択の位相が読めなくなる。

### 4. `fig4-two-diodes-vs-npn.png`

この図が答える問い：
ダイオード2個を背中合わせにしてもトランジスタにならないのはなぜか。

該当本文：
"""
じゃあ中央も半導体のまま端子を出す。
接合をもう1個足して、NPダイオードとPNダイオードを背中合わせに接続する。見た目はN-P-Nだお。
（中略）
2個の別々の結晶を金属線でつないだだけだ。
一方から入ったキャリアは、連続した薄い半導体層を通って他方へ届かない。
（中略）
左が電子を大量に出す**エミッタ**。
中央の薄いp型が**ベース**。
右のn型が、抜けてきた電子を集める**コレクタ**かお。
（中略）
単なるダイオード2個では、
この**薄いベースを横切るキャリア輸送**がない。
"""

構図：
- 左右2パネル。左「別々の2結晶を線でつなぐ」、右「1つの結晶の中に作る」。左右のパネルは同じ高さ・同じ横幅・同じ端子位置で描く。
- 左パネル：n型ブロックとp型ブロックの塊が2個、間を金属線で接続。左端から入った電子が、金属線に到達したところで止まる。
- 右パネル：1つの連続した結晶ブロックの中に、左からn型、薄いp型、n型の3層。左端から入った電子が薄いp型層を横切って右端まで抜ける。

必須要素：
- 右パネルの中央p層が、左右のn層に比べて明らかに薄いこと。
- 電子の経路は青 #1f6fd0 の矢印。左パネルでは経路が途中で切れ、切れた箇所を赤 #cf3b2d の×印で示す。右パネルでは経路が左端から右端まで一続きであること。
- 右パネルの左側n層だけを濃い塗りにして、他のn層より高濃度であることを示す。
- 右パネルで、一部の電子がp層内で消える分岐を細い矢印で1本だけ描き、大部分が通過することを矢印の太さの差で示す。

ラベル（この表記に完全一致）：
- 「別々の2結晶」
- 「金属線」
- 「キャリアが届かない」
- 「1つの結晶」
- 「エミッタ n型 高濃度」
- 「ベース p型 薄い」
- 「コレクタ n型」
- 「大部分が通過」
- 「一部は再結合」

禁止：
- 回路記号のトランジスタ（丸に矢印）を描かない。断面の材料図だけにする。
- 増幅率やドーピング濃度の数値を書かない。
- 空乏層の内部（固定イオンの並び）を描かない。
- 左右のパネルで端子の位置や高さを変えない。

### 5. `fig5-mosfet-channel.png`

この図が答える問い：
nMOS の、どこが n 型なのか。

該当本文：
"""
p型基板へ、高濃度n型のソースとドレインを離して作れ。
（中略）
その隙間の表面へ絶縁体のSiO₂を置き、さらに金属のゲート電極を重ねる。
（中略）
電流は流さなくても電界は届く。
ゲートへ正電圧をかけると、p型表面の正孔が追い払われ、電子が引き寄せられる。
さらに電圧を上げると表面の多数キャリアが反転し、ソースとドレインの間にn型チャネルができる。
（中略）
つまりnMOSという名前なのに、
基板全体がn型なんじゃなくて、ゲート直下にできるチャネルがn型なんだお。
"""

構図：
- 上下2パネル。同じ断面を同じ座標で2回描き、ゲート電圧だけを変える。
- 上パネル「ゲート電圧なし」、下パネル「ゲート電圧あり」。
- 断面は下から、広いp型基板。その上面の左右に離して高濃度n型の領域が2つ。2つの間の表面に薄いSiO2の層、その上に金属ゲート。

必須要素：
- 上パネルでは、2つのn型領域の間の表面がp型のままで、ソースとドレインがつながっていないこと。
- 下パネルでは、SiO2直下のごく薄い層だけが青 #1f6fd0 のn型チャネルになり、その下の基板は依然としてp型のままであること。チャネルが基板全体ではないことがこの図の主張。
- ゲートからSiO2を越えて電流が流れないことを、ゲートとチャネルの間に電流の矢印を一切描かないことで示す。電界の作用は破線で示す。
- 下パネルでソースからドレインへ流れる電子の矢印を青 #1f6fd0 で1本、チャネル内に描く。

ラベル（この表記に完全一致）：
- 「ゲート電圧なし」
- 「ゲート電圧あり」
- 「金属ゲート」
- 「SiO2」
- 「ソース n+」
- 「ドレイン n+」
- 「p型基板」
- 「つながっていない」
- 「反転チャネル n型」

禁止：
- pMOSやCMOSを同じ図に描かない。
- しきい値電圧のグラフを描かない。
- 立体的なFinFETやゲートオールアラウンド構造にしない。平面の断面図にする。
- 基板全体をn型に塗らない。この図の主張が反転する。

合計6個。

これが6T SRAMかお。
（中略）
そもそも1ビットを保持するために、

### 7. `fig7-dram-charge-sharing.png`

この図が答える問い：
DRAM を読むと、なぜセルの値が消えるのか。

該当本文：
"""
ビット線を事前に中間電圧へ準備し、ワード線を入れろ。

セルの小さなコンデンサと、ずっと大きなビット線容量をつないだら。
（中略）
電荷が分け合われる。

ビット線電圧がほんの少し上か下へ動く。
（中略）
その小差を検出増幅器で0Vか1Vへ増幅する。

セル側には何が残る。
（中略）
セルの電荷をビット線と分けたから、元の値はもう残っていないお。
（中略）
検出増幅器が判定した値を使って、
そのままセルへフルレベルを書き戻す。
"""

構図：
- 左から右へ4段の状態を並べる。1「プリチャージ」、2「ワード線を上げる」、3「検出増幅器で判定」、4「セルへ書き戻す」。
- 各段の下部に、同じ位置で小さなセルコンデンサと大きなビット線容量を描く。両者の面積比が、そのまま容量比を表すこと。ビット線容量のほうが明確に大きい。
- 各段の上部に、ビット線の電圧の高さを縦棒で示す。中間電圧の水平な基準線を4段すべてに同じ高さで引く。

### 16. `fig16-3d-nand-hole.png`

この図が答える問い：
300層を一本の穴で貫くと、なぜ上下でセルが揃わないのか。

該当本文：
"""
3D NANDでは、まず多数の薄膜をウェハ上へ交互に積み、まとめて深い穴を開ける。
（中略）
穴の中央へ垂直チャネルを通す。

穴の側壁と各ワード線が交わる高さごとに、電荷を蓄えるセルを作る。
（中略）
上の直径を1とし、下へ行くほど0.2%ずつ細くなる架空の食刻を、300段続けろ。
（中略）
底は上の約55%しかない。

セルごとのチャネル形状が高さで変わり、読出し電流としきい値も揃わないお。
"""

- 左右2パネル。左「理想」、右「実際」。同じ高さ、同じ層数で描く。
- 両パネルとも、水平な薄膜を交互に積んだ縦の断面。層は12段に簡略化する。
- その積層を上から下へ1本の穴が貫き、穴の中央に垂直チャネルが通る。穴の側壁と各層が交わる高さにセルができる。

必須要素：
- 左パネルの穴は、上端と下端の直径が完全に同じ垂直な形。
- 右パネルの穴は、上端が太く下端が細いテーパ形。上端と下端の直径の差がはっきり見えること。
- 右パネルで、上端のセルと下端のセルを取り出して大きさの違いを示す。上端のセルを青 #1f6fd0、下端のセルを赤 #cf3b2d にする。
- 交互の薄膜のうち、ワード線として働く層を灰 #8d8d8d の実線、間の層を灰の薄い塗りにして、交互であることが見えること。
- 層数を左右とも12段に揃える。

- 「実際」

### 17. `fig17-hbm-tsv-stack.png`

この図が答える問い：
HBM はどこに何を積んで、1024本をどう出しているのか。

該当本文：
"""
なら今度はメモリをGPUのすぐ隣へ置き、一本を魔法の速度にせず、短い線を大量に並べるお。
（中略）
DRAMダイを薄くし、シリコンを縦に貫くシリコン貫通電極（through-silicon via, TSV）で積み、基準ダイを介して1024ビット級の広い接続規格を外へ出す。

GPUや演算加速器とはシリコン中間基板などの微細配線で結ぶ。

これが高帯域幅メモリ（High Bandwidth Memory, HBM）だ。
"""

構図：
- パッケージの断面図1枚。下から上へ、パッケージ基板、その上にシリコン中間基板、その上に演算ダイとHBM積層体を左右に並べて載せる。
- 演算ダイは中央左に1個の厚い直方体。HBM積層体は中央右に、薄いDRAMダイを4枚重ね、いちばん下に基準ダイを置く。
- 主方向は左右。演算ダイとHBM積層体の間の接続が主役。

必須要素：
- 薄いDRAMダイ4枚を、演算ダイよりも明らかに薄く描くこと。
- TSVが、積み重ねた4枚のDRAMダイと基準ダイを縦に貫いていること。TSVは青 #1f6fd0 の細い縦線を等間隔に複数本。
- 基準ダイから演算ダイへ、シリコン中間基板の中を通る水平な配線を多数本描く。本数の多さが「広い」ことを表すので、10本以上を等間隔で、交差させずに引く。この配線は青 #1f6fd0。
- 演算ダイとHBM積層体の水平距離が短いことが見えること。距離の短さに寸法線を1本添える。
- パッケージ基板とシリコン中間基板は灰 #8d8d8d。

ラベル（この表記に完全一致）：
- 「パッケージ基板」
- 「シリコン中間基板」
- 「演算ダイ」
- 「DRAMダイ」
- 「基準ダイ」
- 「TSV」
- 「微細配線」
- 「短い距離」
- 「広い接続」

禁止：
- 3D NANDの垂直セルストリングを描かない。これは別の図。
- 帯域の計算式や1024、36GBなどの数値を書かない。
- DRAMダイの枚数を8枚や12枚にしない。4枚に固定する。
- 中間基板の配線どうしを交差させない。

### 18. `fig18-sneak-current.png`

この図が答える問い：
一素子だけのセルにすると、なぜ「選択」が壊れるのか。

該当本文：
"""
絶縁膜の中に導電filamentを作れば低抵抗、切れば高抵抗。

縦横配線の交点へ置くcross-point配列なら高密度だお。
（中略）
選ばないセルを通る二素子直列の経路が63本あり、各経路を20kΩとする単純模型なら。
（中略）
選択セルの31.5倍が脇道を流れるお！！

読みたい100μAが埋もれる。
"""

構図：
- cross-point配列を1枚。横方向の配線4本と縦方向の配線4本を格子状に交差させ、その16個の交点それぞれに抵抗素子を1個置く。
- 左上の1本の横配線と、左端の1本の縦配線を、選ばれた線として太くする。

必須要素：
- 選ばれた行配線と列配線の交点にある素子1個を橙 #e07b1f にする。そこを通る電流経路を青 #1f6fd0 の太い矢印で1本描く。
- 加えて、非選択セルを2個以上直列に通って迂回する脇道の経路を、赤 #cf3b2d の矢印で3本描く。各経路は、選ばれた行から非選択セルを経て非選択の線を渡り、別の非選択セルを経て選ばれた列へ戻る形にする。
- 脇道の矢印3本を合計した太さが、本流の青い矢印より明らかに太いこと。太さが電流の比を表す。これがこの図の主張。
- 非選択の素子は灰 #8d8d8d の輪郭のままにする。
- 脇道の矢印どうしを交差させない。3本を上下にずらして配置する。

ラベル（この表記に完全一致）：
- 「選択行」
- 「選択列」
- 「選択セル」
- 「読みたい電流」
- 「非選択セル」
- 「回り込み電流」
- 「脇道は1本ではない」

禁止：
- 63本、3.15mA、31.5倍、100μAという数値を書かない。
- 1S1R（選択素子を直列に置く修正案）を描かない。それは別の話。
- 配列を4行4列より大きくしない。
- 本流の矢印を脇道より太く描かない。主張が反転する。

### 19. `fig19-die-size-yield.png`

この図が答える問い：
同じ欠陥密度で、なぜ大きいダイのほうが不利なのか。

該当本文：
"""
別の架空工場で$D=0.20\ \mathrm{cm^{-2}}$としよう。

同じ有効ウェハ面積400cm²へ、4cm²の論理ダイを100個、1cm²のメモリダイを400個描く。
（中略）
同じウェハ面積でも、大きいダイは一個が欠陥を踏む確率が高いお。

- 左の円を粗い格子で区切り、大きい正方形の区画にする。右の円を細かい格子で区切り、小さい正方形の区画にする。右の区画1辺は左の半分にする。

必須要素：
- 欠陥点の座標が左右の円で完全に一致していること。これがこの図の唯一の主張であり、ここがずれたら図として成立しない。欠陥点の個数は左右とも20個で固定する。

- 欠陥点を1個以上含む区画を、左右とも赤 #fbeae8 で塗る。含まない区画は白のまま。
- 結果として、左の円は塗られた区画の面積の割合が大きく、右の円は小さく見えること。
