# `chinese-history` 図版選定記録

## 方針

歴史教材向けに `/zuhan` の「層」を史料層・空間層・同時代層へ読み替えた。
約23万バイトの長文だが、人物の装飾画を各王朝へ均等配分せず、本文だけでは
復元しにくい「実物の史料」「領域の広がり」「他地域との時間的ずれ」を優先した。
外部資料は生成・複製せず、Wikimedia Commons のファイルページと表示用画像を
直接参照する。

配色は、決定的に描画する比較年表に限り、青を中国の政体、橙を同期点、灰を
他地域の政体・時代区分へ割り当てる。引用史料の色は原資料を改変しない。

## 図にしなかった重要候補

- **秦始皇の定番肖像**：本人と同時代の肖像ではなく、本文の秦制理解より後世の
  暴君像を強めやすい。唐太宗像で「後世の人物表象」を一度きちんと扱う方を選んだ。
- **各王朝の最大版図を10枚並べる案**：異なる基準年と支配関係を同じ種類の国境として
  読ませ、王朝が全期間その形だったとの誤解を生む。漢・唐・元・清の論点が異なる
  4枚だけに絞った。
- **有名な戦争場面の生成イラスト**：戦場や人物の容貌を創作して史料のように見せるため
  不採用。現存する同時代写真がある第二次アヘン戦争だけを採用した。
- **毛沢東の建国宣言写真**：近現代だけ視覚資料が過密になり、旗と写真が同じ
  「建国」の説明を重複する。政治記号を読ませる十八星旗を残した。
- **シルクロード一本線の矢印図**：本文が中継地と複数経路を強調するのに、一本の
  東西ルートへ単純化してしまう。

## 検査メモ

- 引用資料は各 Commons ファイルページの作者・制作年代・ライセンスを API の
  `extmetadata` で確認した。
- 9枚の比較年表は各節の時間幅へ拡大し、本文に登場する地域・政体を年代値から帯の幅へ変換する。`check_figure.py` の機械検査後、原寸と360px幅でレンダリングして目視する。
- キャプションでは、制作時点と描写対象が異なる肖像・絵画、および一点の領域図を
  史実全体へ一般化しないよう明記した。
