# memory-engram 図版記録

## 方式

2026-09 に、外部の画像生成（ChatGPT）で作った PNG 12枚を破棄し、`scripts/figs/memory-engram.py` で自力描画した SVG に置き換えた。
図のスロット（どの節に何を描くか）と描く内容は、本文と照合済みだった旧図を踏襲した。形・構図を選び直し、各図に読み順の番号か結論の注記を置いた。

色：青＝主信号・増強（AMPA受容体・Na・LTP）、橙＝一致検出・修飾・選択（NMDA受容体・Ca・ドーパミン・ノルアドレナリン・タグ・ミクログリア）、赤＝抑制・弱化・回収・除去、灰＝膜・核・構造。

## 参考写真

実物の顕微鏡像（ゴルジ染色の錐体細胞、スパインの電子顕微鏡像など）を「実物＋模式図」として引用する予定だったが、
作業環境のネットワーク方針で commons.wikimedia.org への接続が拒否され、ファイルページでライセンスを確認できなかった。
確認できない画像は使わない規則なので、今回は引用していない。接続できる環境で `/zuhan` の Phase 2 から追加する。
