# rhetoric：統合改訂プラン

## 1. 方針

- **前提読者と前提知識**：大学生・社会人。弁論術・論理学・統計の予備知識は要らない。割合と四則演算ができればよい（第6幕の割引計算は一行の式で済ませ、年金現価係数は使わない）。
- **中心の問い（catalog の question 案）**：「正しいことを言ったのに、議論で負けるのはなぜか。言葉で人を動かす技は、何を得るために、どこまで使ってよいのか。」
  - v1 の問いに「どこまで使ってよいのか」を足す。開示の線（5-4）と、訂正・謝罪（新設）が答えの半分を担うため。
- **扱う範囲**：v1 の全範囲（聴衆と判定者、三つの説得手段、争点、勝利条件、藁人形・滑り坂・ギッシュ・ギャロップ・立証責任・人身攻撃、対話の六型、交渉〔BATNA・立場と利害・不完全理論化合意〕、誠実な非回答・答弁術・追及と情報収集、コミットメント・フレーミング・アンカリング・産婆術・誘導と操作の線、相対／絶対リスク・基準率・チェリーピッキング・軸の切断、スティールマン・要・説明深度の錯覚・接種・探究と熟議、四つの問い）。
  - v2 から足すもの：省略三段論法、争点の「原因」の階、二択をほどく、修辞状況（場が変わると同じ言葉が別の仕事をする）、配列（序論〜結び）と置き場所の実験、比喩・対句・修辞疑問、平易化、媒体と切り抜きへの耐性、小標本の不確実幅、自己選択の調査と設問文、平均と分布、期間の取り方で変わる費用比較と偽の精度、利益相反の開示、当事者の話を使うときの同意、その場にいない当事者の問い、実行条項、謝罪の主語と評価権、原文を消さない訂正。
- **土台**：v1（先行評価の結論を維持）。v2 の筋への載せ替えは検討したうえで採らない（理由は §2 冒頭）。
- **目標分量**：本文 約78,000〜85,000字（v1 は約72,000字）。v1 の節末の総括・幕間(2)の要約・6-4 の講義を削って約8,000字を空け、v2 由来の場面に約15,000字を使う。
- **幕数**：8幕＋幕間2＋演習・解答＋終幕（v1 と同じ骨格）。第4幕と第6幕、第8幕で節が増える。

## 2. v2 のプロット・設定の再考

### 載せ替えを採らない理由

v2 の筋（虹見橋の7日間の市民会議、店主やる夫と送迎運転手やらない夫の利害対立、自分の12秒が害を生む）は、一つの公共判断に全員の利害が集まり、時間の圧力も強い。v1 の筋より良い点は確かにある。ただし次の理由で、v1 の学習内容を載せ替えない。

1. v1 の主題は「同じ技でも場によって得点にも失点にもなる」（3-5「符号を決めているのは場の方だ」）。これを発見するには、配信・取引先・恋人・説明会という**性質の違う場を渡り歩く**筋が要る。一つの会議に閉じると、判定者の有無や関係の継続が変わらず、四つの問いが育たない。
2. v1 最大の仕掛け（やらない夫が予告して誘導し続け、4-5で回収し、5-4の開示の線で裁かれ、終幕の38冊で本人の過去に返る）は、やらない夫が利害のない教師であることに依っている。v2 のやらない夫は対岸の当事者なので、この線が成り立たない。
3. v2 の「教師も誤る」（6-1のやらない夫の藁人形、8-1の相互謝罪）は、v1 では38冊の告白がより重い形で担っている。

そのうえで、v2 の筋のうち **v1 の場面へ吸収すると v1 の弱点を埋めるもの**を次の表で拾う。

## 4. 幕ごとの構成

各節とも、v1 の「分かったのは…残った疑問は…」の締めを外し、次の行動や余波で閉じる。

### 第1幕　812対88

**1-1　正しかったのに、負けた** ── 議論には三人目がいる
- 出来事：v1 どおり。声が原因かと疑い、アーカイブを見直し、900人に採点されていたことに気づく。
- 学ぶこと：判定者と見物人。「900人・3分・深夜・投票ボタン」を場の条件として台詞に残す（修辞状況の種。名前は付けない）。
- 流用元：v1:L18-99 を流用。L101-106 の総括は削り、「その900人に何を持って帰ってほしかったんだ」への沈黙で閉じる。
- 伏線：その問い（→8-1で回収）。机を叩く2分12秒（→2-2で回収）。

**1-2　同じ中身を、違う口で** ── ロゴス・エートス・パトス、省略三段論法
- 出来事：v1 どおり、できる夫の5文を数え、事実ゼロの30秒で失敗する。新規に、やる夫が「できる夫は一度も『罰則を付けろ』と言っていない」ことに気づく。結論を言わずに聴衆に補わせていた。
